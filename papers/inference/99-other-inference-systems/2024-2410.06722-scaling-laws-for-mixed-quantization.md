# Scaling Laws for Mixed Quantization：混合量子化の比率・粒度・モデル規模を結ぶ経験則

## 概要

低bitのLLM推論では、すべての重みや活性を同じ低精度へ変換するより、精度低下に敏感な部分を高精度で残す混合量子化が有効になる場合がある。しかし、どの程度の割合を低精度化できるか、何要素ごとにスケール係数を共有するべきかは、モデル規模と数値形式に依存する。著者らは、低精度化するパラメータの割合 `Qr`、量子化ブロックサイズ `Qb`、モデル規模 `N` を明示的に変数とする経験的スケーリング則を提案する。

LLaMA、Qwen-1.5、Qwen3、独自事前学習の小型CLM系列を含む17モデル（60M〜14B）に対し、合計54,600個の量子化チェックポイントを評価した。混合量子化による損失増加は、概ね `exp(A·Qr) × N^(-γN) × (Qb+d)^γc` の積で表せるとし、最適割当とランダム割当の期待値の両方を扱う。MXINT-4の弱い法則では最適損失の当てはまり `R²=0.98`、期待損失 `R²=0.99`、ブロック粒度を含む強い法則ではそれぞれ `R²=0.95`、`R²=0.98` を報告する。

中心的な示唆は、同じ低精度化割合ならモデルが大きいほど量子化損失の増分が小さくなること、モデル規模が十分大きければ極端に小さいブロックを使う利益が小さくなることにある。ただし70B超の数値例は最大14Bまでの実験からの**外挿**であり、推論速度、VRAM、電力を測定した性能倍率ではない。

## 問題設定

従来の量子化スケーリング則は、事前学習時と事後量子化時のビット幅、モデルパラメータ数、学習トークン数から全体の損失を説明する。しかし混合量子化では、一部の層や行列演算をBF16に残し、残りを4bitなどへ変えるため、同じ平均ビット幅でも配置によって損失が変わる。また、同じ4bitでも32要素ごとにスケールを共有するか、256要素ごとに共有するかで誤差とハードウェアの制御費用が変わる。

著者らが明確にする二つの変数は、`Qr = 低精度に割り当てたパラメータ数 / 総パラメータ数` と、同じスケール係数を共有する要素数 `Qb` である。`Qr=0.9` はパラメータの90%を低精度へ割り当てるという意味であり、平均ビット幅が0.9bitという意味ではない。`Qb` が小さいほど細かな量子化スケールを設定できるが、スケール値の保存とハードウェアの管理が増える可能性がある。

同じ `Qr` と `Qb` でも、どの層を高精度で残すかによって損失はばらつく。したがって著者らは、配置をランダム変数とみなし、その期待損失と、探索で見つかる最小損失の二つを別々に予測する。これは単一の最適な層配置を直接出力するアルゴリズムではなく、モデル規模と量子化設計空間の大まかな関係を説明する法則である。

## 手法

### 1. 損失を事前学習成分と量子化悪化成分へ分ける

基礎となる式は、Chinchilla型の言語モデル損失 `aN^-α + bD^-β + E` に、事後量子化による損失増加 `Δ(N,Qr,Qb)` を加えるものである。`N` はパラメータ数、`D` は事前学習トークン数、`Δ` は量子化の影響だけを表す。モデルごとに学習済み重みを固定しているため、量子化の探索中に `D` や元の事前学習条件は変えない。

論文の式(3)と式(4)では、探索で得られる最小悪化量 `δopt` とランダム割当の期待悪化量 `E[δ]` を、それぞれ係数が異なる積型の式で表す。代表形は `C exp(A·Qr) N^-γN (Qb+d)^γc` である。低精度化率が高まると損失悪化が指数的に増え、モデル規模が大きいとべき乗的に減り、ブロックが大きいほど悪化が増える傾向を仮定する。係数は数値形式と実験系列から当てはめるため、普遍的な定数ではない。

`Qb` を固定するとブロックの項は定数に吸収され、`Qr` と `N` だけの弱い法則になる。`Qb` も変える場合は強い法則として粒度項を残す。式の構造を分けることで、モデル規模を増やしたときに低精度化率をどこまで増やせるか、ブロックを細かくする価値がどの程度残るかを、同じ枠組みで検討できる。

### 2. 混合配置のランダム探索

混合量子化では、各層または各行列演算を高精度BF16か低精度の数値形式へ割り当てる。論文は層単位と行列積単位の二つの粒度で配置を探索する。層単位ではTransformer層全体を低精度にし、行列積単位では各線形演算の精度を個別に決める。細かい配置は選択肢を増やす一方、実装上は異なる数値形式の切替えと管理が必要になる。

特定の `Qr` と `Qb` の組合せについて100回のランダム試行を行い、各試行で量子化を実施し、損失悪化を計測する。観測した悪化量の平均から期待値を推定し、試行中の最小値から最良配置の近似値を得る。全組合せを厳密に列挙するのではなく、限られた探索から統計量を推定する点が重要である。最良値は探索回数や探索分布に依存し得るため、真の大域最適値が保証されるわけではない。

`Qr` の実験値は0.5、0.6、0.7、0.8、0.9、0.95、0.975である。`Qb` は16、32、64、128、256を比較する。低精度形式の主条件は重み・活性ともにMXINT-4であり、追加でMXINT-2、重みのみのMXINT-4、重みのみのHQQ-4bitを調べる。数値形式が変われば当てはめ係数も変わるため、ある形式で学習した係数を別形式へ無条件に流用しない。

### 3. モデル規模と量子化比率の独立効果

弱い法則では `δ ∝ exp(A·Qr) N^-γN` を考える。`Qr` が一定ならモデル規模を増やすと悪化が減り、`N` が一定なら低精度化率を上げると悪化が増える。両者が積として現れるという仮説に基づき、許容悪化量 `δ=l` を固定すると、`log N = (A/γN)Qr + 定数` という関係が得られる。

これは「モデルが大きくなるほど、同じ損失悪化予算の範囲で低精度化できる割合を増やせる」という解釈につながる。モデルの大きさが低精度化率を無限に増やすわけではなく、`Qr` は最大1で頭打ちになる。実際の設計では、許容NLL悪化量、量子化形式、量子化配置を決めたうえで比率を選ぶ必要がある。

### 4. ブロック粒度の寄与

強い法則は `(Qb+d)^γc` の項を追加する。ブロックが大きいほど同じスケールを共有する要素が増え、値の分布を細かく追えなくなる。一方、ブロックを小さくするとスケールの保持量や回路構造が複雑になり得る。著者らは、この精度上の利得が大規模モデルで逓減すると主張する。

ここでの `Qb` は低精度ブロック内の共有スケール単位であり、CUDAカーネルのタイル寸法やKVキャッシュのページサイズではない。量子化ブロックを細かくする利得が減るという結果から、一般の推論カーネルのタイルサイズまで最適化できるわけではない。また、論文は数値形式をエミュレーションするため、実ハードウェアでのスケール読み出し費用と演算性能を直接測定してはいない。

### 弱い法則の当てはまり（Figure 1）

MXINT-4の層単位配置では、CLM系列とQwen3系列について実測の損失悪化曲線と予測曲線を比較する。最小悪化量の当てはまりは `R²=0.98`、期待悪化量は `R²=0.99` である。ここでの `R²` は同じ研究内で得た量子化構成の損失悪化に対する適合度であり、未知の400Bモデルや未知のハードウェア性能を予測した精度ではない。

最適配置の悪化量と平均的な配置の悪化量を分けたことにも意味がある。最良の層を高精度に残せる設計なら最小値を目標にできるが、実際の実装制約や配置探索の費用が大きい場合は期待値の方が参考になる。100試行の最良値が全配置の真の最小値を表すとは限らず、探索戦略が変われば定数や観測値も変わる可能性がある。

### 強い法則の当てはまり（Figure 2）

CLM-200MとCLM-1.1Bを中心に、`Qb=16,32,64,128,256` でブロック粒度を変えたときの悪化量を比較する。最適悪化量の予測適合度は `R²=0.95`、期待悪化量は `R²=0.98` である。小さいブロックによる改善は存在するが、モデルが大きくなるにつれてその相対的な重要性が減る、という粒度項の形を支持している。

この評価はMXINT形式の精度悪化を中心にしたものであり、ブロックサイズ32と128の間で実機の演算速度が何倍違うかは測定していない。ブロックサイズが小さいと回路が複雑になるという示唆は、実際のチップ設計費用やGPU実装の測定値ではなく、精度と設計複雑性のトレードオフに関する考察である。

### 他の数値形式への一般化（Figure 3）

主実験は重み・活性MXINT-4だが、著者らは重み・活性MXINT-2、重みのみMXINT-4、重みのみHQQ-4bitでも類似の損失悪化曲線を確認している。ただし、低精度のビット幅や方式が変わると係数が大きく変化する。したがって「同じ指数・係数であらゆる量子化方式を予測できる」わけではなく、積型の関数形を再利用できるという範囲での一般化である。

| 評価の焦点 | 主な結果 | 解釈 |
|---|---|---|
| 弱い法則・最小悪化量 | R²=0.98 | `Qr` と `N` の積型関係が実験範囲で適合 |
| 弱い法則・期待悪化量 | R²=0.99 | ランダム配置の平均的な悪化にも適合 |
| 強い法則・最小悪化量 | R²=0.95 | `Qb` を追加した粒度依存の近似が成立 |
| 強い法則・期待悪化量 | R²=0.98 | ブロックサイズによる平均的悪化を近似 |
| 別数値形式 | 同じ関数形で再適合 | 係数は数値形式ごとに異なる |

### 大規模モデルへの外挿と負の結果

Figure 4では、CLM系列から得た係数を用い、70Bを超えるモデルでは低精度化率 `Qr>0.9` でも損失悪化 `δ<0.5` と予測する。また50B超では `Qb=32` と `Qb=128` の損失悪化差が0.5未満と推定する。これらは測定済みの70B・50Bモデルの実測値ではない。最大14Bまでの結果からの外挿であるため、設計上の仮説として扱い、実機で追認する必要がある。

負の結果として、低精度化率を高めればモデルが大きくても悪化は増える。またブロックを細かくすれば常に実装が得になるわけではなく、精度上の利得が逓減し得る。重み・活性両方を量子化するMXINT-2と重みのみHQQでは当てはめ係数が異なり、量子化形式をまたいだ単純な数値比較は成立しない。実機性能を無視して最小損失だけで最適な数値形式を選ぶこともできない。

## 既存研究との差

従来のPrecision Scaling Lawsは、学習時・事後量子化時の精度とモデル規模を扱うが、同一モデル内で高精度・低精度を混在させる割合と、スケール共有ブロックの粒度を独立変数として十分には扱わない。本論文は `Qr` と `Qb` を加え、同じモデルでも精度割当によって損失が確率的にばらつくことを明示する。

AWQやQuIPなどの個別の量子化アルゴリズムは、重要重みの選択や量子化誤差の補償により特定モデルの品質を改善する。本研究は特定の量子化アルゴリズムを上回る新しいカーネルではなく、設計空間を跨いだ損失悪化の傾向をモデル化する。100回のランダム配置試行で得た統計量を関数に当てはめるため、最適なレイヤー選択の具体的手順をそのまま返すわけではない。

## 限界と実装上の注意

第一に、モデル規模の実測範囲は60M〜14Bである。50B、70B、400Bに関する数値は外挿であり、MoEの専門家分布、層ごとの異質性、KVキャッシュ精度、推論時の動的ルーティングを含む保証ではない。論文自身も400BやMoE、三値形式への拡張を今後の課題として挙げる。

第二に、量子化は主にエミュレーションで実施され、実機のMXINT4/MXFP4カーネルで速度・電力を測ったわけではない。実際の推論基盤では、数値形式の変換費用、スケール係数の帯域、演算器の対応、低精度・高精度の切替えが速度を左右する。論文の `R²` を実機スループット予測の精度と読み替えてはならない。

第三に、損失悪化の指標はSlimPajamaの1,000例に対する言語モデル損失・パープレキシティが中心であり、指示追従、数学的推論、長文脈、コード生成などの下流性能は同じ密度で評価されていない。低い損失悪化が特定タスクの品質を完全に保存することは別途確認が必要である。

第四に、54,600チェックポイントは多様な割当を網羅するが、全組合せの厳密探索ではない。特に最小悪化量はランダム探索で観測された最良値に依存し、探索回数、割当単位、数値形式、モデル系列が変わると再推定が必要である。

第五に、モデルが大きいほど低精度化割合を高められるという傾向は、個別モデルの実装可能な平均ビット幅やVRAM削減率を直接示さない。重みだけでなくKVキャッシュ、活性、推論ワークスペース、スケール係数を考慮して初めて実際のメモリ使用量を見積もれる。RTX 4070 SUPER 12GBのような小型GPUでの効果を評価するには、具体的な量子化フォーマットと推論エンジンで測る必要がある。
