# ADMMを用いた事後枝刈り後の重み更新

## 概要

大規模言語モデルの重みを事後的に枝刈りする際には、重要度の低い重みをゼロにするだけでは、各層の出力が元モデルからずれてしまう。Wandaは重みの絶対値と入力活性の大きさから削除候補を選び、SparseGPTは二次情報を利用して重みの更新を近似する。いずれも大規模モデルを再学習せずに圧縮する方式だが、削除後の残存重みを短時間で十分に調整できるかが品質を左右する。

本論文は交互方向乗数法（Alternating Direction Method of Multipliers、ADMM）を使い、指定された疎性マスクの下で層出力の再構成誤差を小さくする重み更新を提案する。固定マスクの下では問題を凸最適化として扱えるため、行列の逆行列を一度計算して再利用し、少ない反復で高品質な更新を得る。さらに削除する重みを一度に決めず、疎性を段階的に高めながら更新を繰り返す方式を組み合わせる。

LLaMA-7Bの60%疎性ではWikiText2困惑度がSparseGPTの10.51に対して提案方式の9.22へ改善する。一方、全体の枝刈り時間はSparseGPTの850秒に対し869秒で、総処理時間が短いわけではない。80%疎性では困惑度69.46まで悪化する。したがって、本研究は「枝刈りの準備時間を必ず短縮する」方式ではなく、同程度の準備時間で品質を改善する重み更新方式として評価するのが適切である。

## 問題設定：固定マスクの下で層出力を再構成する

事後枝刈りでは、事前学習済みの重み行列と、少量の校正データから得た入力活性が与えられる。削除する重みを示す二値マスクを固定したとき、残す重みの値を調整して、元の層出力と枝刈り後の層出力の差を最小化する。出力ニューロンごとに独立した最小二乗問題を解く方法もあるが、ニューロンごとに異なる行列の逆行列を計算する必要があり、大規模モデルでは現実的でない。

勾配降下法を使えば各反復の計算は比較的軽いが、収束まで多数の反復を必要とする。SparseGPTは二次情報を近似することで実用的な計算時間を実現するが、近似のために残る再構成誤差がある。Wandaは単純なマスク選択で良好な性能を得るものの、削除後の重み更新を行わない。著者は、マスク選択と重み再構成を分けて考え、後者をより正確に解くことを狙う。

この問題で重要なのは、マスクを固定した場合と、削除する位置そのものを最適化する場合の違いである。固定マスクの下では許される重みの集合が凸集合になり、ADMMの収束理論を適用できる。一方、どの重みを削るかを同時に最適化する一般のゼロノルム制約は非凸であり、同じ理論保証をそのまま主張することはできない。

## 手法

### ADMMによる重みの再構成

元の重みをW、校正入力をX、残す位置を示す二値マスクをMとする。目的は、元の出力XWと、削除位置をゼロに固定した新しい重みで計算した出力との差を最小化することである。ADMMでは重みの更新用変数と、マスク制約を満たす変数を分け、両者が一致するようにペナルティと双対変数を更新する。

重み更新の主要な計算は、入力の共分散行列と単位行列に正則化を加えた行列の逆行列を使う形になる。原著式(5)では、入力の二次統計、元の重み、現在のマスク付き変数、双対変数から次の重みを求める。校正入力が同じなら逆行列を反復ごとに計算し直す必要はなく、最初に一度計算して再利用できる。マスク制約への射影は、削除位置の重みをゼロにするだけで済む。

この設計によって、ニューロンごとに異なる逆行列を計算する費用を避けつつ、固定マスクの下での最適な層出力再構成に近づける。著者はADMMが少数の反復でほぼ収束することを示し、一般的な勾配法より多くの反復を省けるとする。ただし逆行列の計算自体は必要であり、行列の幅が大きい場合の準備費用とメモリ使用量が消えるわけではない。

### 活性に基づく正規化とマスク選択

著者はWandaの重要度基準を参考に、各入力特徴の活性ノルムで重みを正規化し、校正入力を逆向きに正規化する。こうすると、正規化した重みの絶対値に基づく選択が、元の重みと入力活性ノルムの積に基づく選択に対応する。枝刈り後に重みを元の尺度へ戻すため、元の層演算の意味を保てる。

Wandaは出力ニューロンごとに一定数の重みを残す制約を使うが、本論文では層全体から重要度の高い重みを選ぶ方がわずかに良かったと報告する。したがって、同じ50%疎性でも削除位置の分布が比較方式と完全に同じとは限らない。マスク選択の違いと、固定マスクに対する重み更新の違いを区別して評価する必要がある。

### 段階的な枝刈り

一度に目標疎性まで削除すると、残る重みの再構成が難しくなる。著者は、反復回数に応じて疎性を三次関数的に増やし、初期には少数の重みだけを削除し、後半で目標疎性へ到達させる。各段階でマスクを更新し、ADMMの重み再構成を繰り返す。これにより、途中の誤差を補償しながら最終的な削除位置を決められる。

2:4の構造的疎性にも拡張し、四つの重みのうち二つを残す制約を守りながら段階的に削除する。実験では20回のADMM反復のうち15回でマスクを更新し、残りの反復で重みを収束させる。層を順番に処理するので、70B規模のモデルでも一度に全層をGPUへ載せる必要はない。ただし「1回の前向き処理で枝刈りする」という表現は、層内部で反復を行わないことを意味しない。

## 評価条件と主要結果

| 項目 | 原著の設定 |
|---|---|
| 校正データ | C4の128サンプル |
| モデル | LLaMA-7B、LLaMA-2の7B・13B・70B |
| GPU | Quadro RTX 5000 16GBを2基使用 |
| 最適化 | ADMM20反復、マスク更新15回、正則化0.1、ペナルティ1 |
| 比較 | Wanda、SparseGPT、固定マスクのADMM、段階的ADMM |
| 品質 | WikiText2困惑度、7種類のゼロショット課題 |

### LLaMA-7Bの枝刈り品質

| 疎性 | Wanda | SparseGPT | 段階的ADMM |
|---|---:|---:|---:|
| 50% | 7.26 | 7.22 | 7.06 |
| 60% | 10.66 | 10.51 | 9.22 |
| 70% | 85.77 | 26.30 | 18.66 |
| 80% | 約5000 | 154.75 | 69.46 |
| 2:4 | 11.53 | 11.00 | 9.90 |

原著Table 1。提案方式は各疎性で比較方式より困惑度が低いが、80%疎性の69.46は元モデルの5.68から極端に悪化している。相対的な改善が大きくても、生成品質が実用的な水準に保たれているとは限らない。

固定マスクの重み更新だけを比較した原著Table 2では、Wandaマスクに対してSparseGPT型更新の困惑度10.86、ADMM更新9.96となる。SparseGPTマスクに対してもSparseGPT更新10.51、ADMM更新9.92であり、マスク選択と独立にADMMの重み更新が有利な条件がある。ただし段階的マスク更新を含む最終方式の9.22とは、異なる比較条件である。

### 処理時間とゼロショット品質

| 方式 | LLaMA-7Bの総枝刈り時間 |
|---|---:|
| Wanda | 245秒 |
| SparseGPT | 850秒 |
| 固定マスクADMM | 832秒 |
| 段階的ADMM | 869秒 |

原著Table 3。ADMMの各反復は勾配法より速く収束するが、総処理時間では最も単純なWandaより大幅に遅く、SparseGPTよりもわずかに遅い。したがって「高速」は主に重み更新の収束効率を指す。実際のモデル推論速度を測った結果でもない。

原著Table 4の7課題ゼロショット平均は、LLaMA-7Bの50%疎性でWanda54.21、SparseGPT54.39、段階的ADMM55.18。60%疎性では50.43、51.93、52.43となる。ただしRTEではADMMが常に優れるわけではなく、60%疎性のRTE正答率はSparseGPT62.09に対しADMM58.84へ悪化する。著者はRTEの評価例が277件と少なく、結果が不安定になりやすいと述べる。

### LLaMA-2の規模別比較

LLaMA-2の60%疎性でのWikiText2困惑度は、7BではSparseGPT9.58に対してADMM8.70、13Bでは7.80に対して7.09、70Bでは4.98に対して4.81である。2:4疎性では70BのSparseGPT5.40に対してADMM5.19と改善するが、Wanda5.16にはわずかに及ばない。したがって、すべてのモデル・疎性で絶対的に最良というわけではない。

## 限界と実用上の判断

固定マスク下での再構成問題は凸最適化として扱えるが、削除する位置まで含めた問題は非凸であり、段階的マスク選択の最適性が保証されるわけではない。著者自身も、ゼロノルム制約をADMMへ直接適用する方法はヒューリスティックで、ペナルティ設定によって循環して収束しない場合があると説明する。本研究の理論保証を、一般の疎性マスク最適化全体へ広げて解釈してはいけない。

さらに、更新計算では密な行列を扱うため、枝刈りによる疎性を計算中の速度・メモリ削減に利用していない。推論時も疎行列に対応したカーネルやハードウェアがなければ、重みをゼロにしただけで高速化するとは限らない。著者は一度の校正で枝刈りできる点を強調するが、処理時間は単純なWandaより長い。高疎性で品質が大幅に崩れるという限界も残る。

本研究の位置付けは、少量の校正データで事後枝刈りを行う際、重みを削除した後の層出力をできるだけ保つための最適化手法である。採用判断では、目標の疎性で品質が十分か、実際の推論エンジンが疎性を活用できるか、枝刈り準備の時間とGPUメモリを許容できるかを別々に測る必要がある。
