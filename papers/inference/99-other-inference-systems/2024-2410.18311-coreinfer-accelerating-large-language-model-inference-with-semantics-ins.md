# CoreInfer: Accelerating Large Language Model Inference with Semantics-Inspired Adaptive Sparse Activation

## 概要
TransformerのFFNでは、入力ごとに寄与の大きいニューロンが一部へ偏るため、重要ニューロンだけ計算する疎活性推論が可能である。しかし既存方式はトークンごとに補助MLPで活性集合を予測することが多く、予測計算に加え、毎トークン異なる重み断片を呼び出すため実機では理論疎性ほど速くならない。

CoreInferは「同じ文の中では重要ニューロン集合が安定し、意味が近い文では集合も似る」という観測を利用する。prefillで文単位core neuronを決定し、後続生成では同じ集合を固定して使う。補助MLPを毎トークン実行しないため、疎計算の管理費と不規則な重み呼び出しを減らす。

## 問題設定
PowerInfer等の適応疎活性は、各トークンの活性を予測して必要FFN重みだけ計算する。予測精度を高めるほど予測器自体の費用が増え、活性マップが頻繁に変わるほどGPU/CPU間やメモリ階層の重み取得も細粒度になる。

論文はニューロン重要度を文単位で見ると、トークン単位より集合が安定することを実測する。そこで「毎回正確に予測する」代わりに、文意味から十分良い共通集合を一度選ぶ設計へ変える。

## 手法
### sentence-wise core neuron
各文に対してFFNニューロンの寄与を集約し、その文で継続的に重要な集合をcore neuronと定義する。文内トークン間で重要集合の重なりが高いことを利用し、後続トークンごとの再予測を省く。

### 意味に基づく予測
core neuronと文意味の相関を使い、入力条件に応じた2種類の予測経路を設計する。prefill段階で入力文の意味表現からcore neuron集合を決め、その後のencoding/generation段階では集合を固定する。これにより毎トークンの補助MLP費をゼロに近づける。

固定集合は重みアクセスの規則性も高める。対象ニューロンが頻繁に入れ替わらないため、疎FFN実行で必要な重みを再利用しやすくなり、資源制約GPUで特に利得が出る。

## 評価
|項目|内容|
|---|---|
|ハードウェア代表例|NVIDIA TITAN XP|
|比較|HuggingFace密実装、PowerInfer|
|評価軸|モデル一般化、タスク一般化、推論速度、品質|
|対象|複数モデル・複数言語タスク|

|比較|高速化|読み取り|
|---|---:|---|
|HuggingFace実装|10.33倍|疎FFNと固定活性集合により密計算を大幅削減|
|PowerInfer|2.72倍|トークン別予測・活性切替を減らすことが実速度へ寄与|

論文はモデル・タスクを跨ぐ一般化も評価し、core neuronの意味依存性が単一データセットだけの現象ではないことを確認する。一方、headlineの10.33倍はTITAN XPという資源制約の強いGPU条件であり、最新GPUへ同倍率を一般化すべきではない。

## 既存研究との差
従来の適応疎活性はトークン単位の細かな活性予測を重視する。CoreInferは予測粒度を文単位へ上げ、意味的安定性を利用して集合を固定することで、予測器とメモリアクセスの実装費を削る。疎性そのものを増やすより、疎性を実ハードウェアで安く使うことが中心である。

## 限界
文の途中で話題や生成方向が大きく変わる場合、prefill時に固定したcore neuronが後続トークンへ最適とは限らない。速度利得はGPUの計算能力・メモリ帯域と疎重み取得実装に依存する。評価はTITAN XPを主要headlineとし、現行データセンターGPUでの絶対性能は別途検証が必要である。
