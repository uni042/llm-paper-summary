# TopK-Guided: Adaptive, Budget-Aware Activation Sparsity for Efficient LLM Inference

## 概要

自己回帰型大規模言語モデルのデコードでは、各層の大規模な射影が活性値と重み行列の積を計算する。学習済みモデルでは射影入力の活性値に小さいものが多く、その値をゼロにすれば対応する重み列との積を省ける。TEALは校正後の固定しきい値で、入力分布に合わせてトークンごとに疎性を変えるが、実現疎性は目標からずれる。WINAは重みを考慮した順位づけで上位の活性値を選び、目標疎性を満たす一方、全トークンへ同じ疎性を適用する。両手法はさらにTransformer層間へ一様な疎性予算を与え、疎化への耐性が異なる層を区別しない。

TopK-GuidedはWINAへ二つの学習不要な変更を加える。第一に、TEALのしきい値で現在のトークンにおける「自然な疎性」を見積もり、その値を目標疎性の±1パーセントポイントへ制限してから上位要素を選ぶ。これによりトークンごとの調整を残しつつ、実現疎性を目標近傍へ制限する。第二に、少量の校正入力で各Transformer層を疎化した時の相対出力誤差を測り、感度の高い層には小さい、低い層には大きい疎性予算を割り当てる。層内の射影間配分はWINAの貪欲手順を維持する。

論文のC4評価では、Llama-2-7BとLlama-3-8Bの目標疎性30%、50%、70%で、TopK-GuidedはTEALおよびWINAと比べperplexityと8課題平均正解率の両方で全条件最高だった。70%疎性での改善が最も大きい。これらは同一目標疎性での品質・演算回数比較であり、実時間の速度改善を示す結果ではない。

## 問題設定と先行手法

活性値疎化は推論入力ごとに小さい活性値をゼロ化し、対応する射影計算を省く。重み自体を削除する枝刈りとは異なり、トークンごとに残す座標を選び直す。TEALは射影別に校正したしきい値を使うためトークンごとの適応性を持つが、活性値分布に応じて実現疎性が変わり、目標演算削減を保証しない。WINAは各活性値の絶対値と対応する重み列のL2ノルムの積で候補を順位づけし、目標数の要素を残す。その実現疎性は一定だが、トークンごとの分布差を利用しない。

もう一つの問題は、各Transformer層へ同じ疎性目標を割り当てることである。Figure 1ではLlama-2-7BとLlama-3-8Bの層別感度が一様でなく、前段の層がより敏感な傾向を示す。したがって一律の予算では敏感な層を過剰に疎化し、より頑健な層の余地を使い切れない。関連する先行手法として、論文は重み外れ値に基づいて層別疎性を配るOWL、重み列を回転して活性値疎化に使うWINA、およびモデル出力を保存する回転前処理のSliceGPTを挙げる。TopK-GuidedはWINAの順位づけ・回転および層内の貪欲配分を引き継ぎ、トークン別予算制御と層感度に基づく配分を追加する。

## 手法

### トークンごとのTopK-Guidedマスキング

校正時に求めた射影別しきい値 \(\tau\) と現在の活性値 \(h^{(t)}\) から、\(\hat{s}^{(t)}=d^{-1}\sum_j 1[|h_j^{(t)}|<\tau]\) を計算する。これはそのトークンでしきい値以下となる成分の比率である。次に、目標疎性 \(s\) に対して

\[
s^{*(t)}=\min(s+\delta,\max(s-\delta,\hat{s}^{(t)})),\quad \delta=0.01
\]

とし、\(k^{(t)}=\max(1,\lfloor d(1-s^{*(t)})\rfloor)\) 個の活性成分を上位要素の選択で残す。WINAの重み列を考慮した順位づけを保ち、\(\delta=0\) ならWINAの固定疎性になる。しきい値との比較・範囲制限・quickselectを合わせた選択計算はトークンあたりO(d)とされる。Appendix BのLlama-2-7B、目標50%、各データ500サンプルでは、TopK-Guidedの実現疎性/perplexityはWikiText-2で49.39%/7.20、C4で49.52%/7.32、cc100で49.46%/10.24だった。TEALは同条件で48.14%、48.36%、47.64%となり、目標50%を下回った。

### Block感度に応じた予算配分

各層 \(i\) の感度 \(e_i\) は、小さな校正集合 \(D\) で測定用疎性 \(\bar{s}\) を適用した層出力と疎化前の出力との相対L2誤差を平均して求める。平均感度を \(\bar e\) とすると、層別予算を

\[
s_i=\min(0.95,\max(0.05,s+\lambda(\bar e-e_i)))
\]

とする。平均より敏感な層は \(s_i<s\)、頑健な層は \(s_i>s\) となり、上下限を5%と95%に制限する。測定用疎性 \(\bar{s}\) は感度測定専用で、実運用時の予算ではない。\(\bar{s}\) と \(\lambda\) は調整対象である。Figure 1では測定用疎性0.2、0.4、0.6、0.8で層ごとの誤差を比較する。

層内部のQ/K/V/Oおよびgate/up/down射影への配分はWINA既存の貪欲校正を使用する。各行列へ計算量に応じた刻み幅を試し、疎化前の層出力との再構成誤差が最小となる行列へ疎性を順に割り当て、計算量加重予算別の参照表を作る。論文は校正を一回実施すると記すが、実行時性能や校正コストの実測値は示していない。

WINAと同様に、射影重みを特異値分解で得た右特異ベクトルへ回転し、列を直交化して活性値選択スコアの交差項を抑える。回転は隣接層の重みへ吸収し、モデル出力を変えず、推論時の回転演算を追加しない。TopK-Guidedの疎化はデコード段階のみ。

## 評価条件

- モデル: Llama-2-7B、Llama-3-8B。デコーダーのみを持つ最大80億parameterのモデル。
- Hardware: 単一NVIDIA A100 SXM4、40 GB。
- 目標疎性: 30%、50%、70%。
- Perplexity: C4 validationの500 sample。
- 下流評価: ARC-Easy、WinoGrande、HellaSwag、BoolQ、SciQ、MMLU、GSM8K、LAMBADAのzero-shot正解率をlm-evaluation-harnessで測定し、8課題平均を報告。
- 比較手法: TEALはthreshold maskingで回転なし、WINAは重み回転と重み列を考慮するTopK。TopK-GuidedはWINAの回転を引き継ぐ。
- 調整方法: 測定用疎性 \(\bar{s}\) と \(\lambda\) を別データで選択し、報告データへ固定して適用。C4結果はWikiText-2で選択。Appendix Fは逆方向として、WikiText-2結果にC4選択parameterも示す。測定用疎性・予算再配分の強さは各0.2、0.4、0.6、0.8から選ぶ。
- 計算量: 射影の理論演算数削減を同じ目標疎性で比較。全体の処理速度、応答遅延、消費電力は評価していない。

## 定量結果

### C4 perplexity / 8課題平均正解率

各セルは `PPL / 正解率 (%)`。Table 1より抜粋。

| Model | Method | 30% | 50% | 70% |
|---|---|---:|---:|---:|
| Llama-2-7B | TEAL | 6.92 / 64.46 | 7.57 / 61.88 | 15.85 / 50.19 |
| Llama-2-7B | WINA | 6.90 / 64.63 | 7.34 / 63.33 | 10.72 / 56.54 |
| Llama-2-7B | TopK-Guided | **6.89 / 64.71** | **7.32 / 63.42** | **10.15 / 56.80** |
| Llama-3-8B | TEAL | 9.05 / 73.56 | 10.49 / 69.84 | 24.09 / 52.64 |
| Llama-3-8B | WINA | 9.05 / 73.59 | 10.52 / 69.79 | 27.78 / 55.34 |
| Llama-3-8B | TopK-Guided | **9.04 / 73.88** | **10.46 / 70.02** | **21.55 / 57.85** |

12通りすべてでTopK-Guidedが両指標の最良値となる。Llama-3-8B・70%疎性ではWINAに対しPPLが27.78から21.55、平均正解率が55.34%から57.85%へ変化する。一方、同条件でTEALはWINAよりPPLが低い（24.09対27.78）が正解率は低く（52.64%対55.34%）、perplexityだけでは下流精度の順序を表せないと著者は指摘している。

### Ablationと感度分析

Llama-2-7BのC4、70%疎性では、WINAのPPL 10.72に対し、感度配分のみ10.25、TopK-Guided maskingのみ10.66、両方を使用した場合10.15だった（Table 6）。各変更は単独でも多くの条件でWINAと同等以上で、組合せは各疎性水準で最良と報告される。

Appendix EのLlama-2-7B WikiText-2 parameter sweepでは、70%疎性の16組合せすべてがTEAL (17.90) を下回り、15組がWINA (10.79) 以下だった。\(\bar{s}\in[0.2,0.6]\)、\(\lambda\in[0.2,0.4]\) の範囲が全疎性水準で安定して良好と報告され、広範囲な探索を必要としない傾向が示される。

## 既存研究との差

TEALはthresholdによるトークンごとの適応を持つが目標疎性の逸脱を許し、WINAは重み列scoreによる上位要素選択で疎性を厳守するがトークン間で固定する。TopK-Guided maskingは両者の性質を範囲制約付きで組み合わせる。層別予算配分はOWLと同じく一様でない疎性を使うが、OWLの重み外れ値指標ではなく、校正入力上で測った層出力感度に基づく。WINAから継承する特異値分解回転はSliceGPTに基づく計算不変な前処理で、本文はQuaRotのような回転ベース量子化と同じ回転済みモデル上での併用可能性を今後の方向として挙げる。これらの比較を独立した新実験として実証したものではない。

## 限界と実装状況

- 評価はLlama-2-7BとLlama-3-8Bの2モデルに限られる。他architectureやより大きなdecoder-only modelでの実証はない。
- 実時間の演算処理高速化ではなく、活性値疎化に対応する射影演算数を評価している。したがって表の品質改善から実際の高速化倍率は結論できない。
- λとprobe疎性はheld-out dataで選択する。sensitivity測定に使う校正集合の規模や校正処理時間の実測値は報告されていない。
- WINAと同様の特異値分解回転済み重みを前提とし、疎化はデコード段階に限る。未回転モデル、入力処理、実運用処理への適用性能はこの論文では検証されていない。
- 公開コードの場所、再現用artifact、運用導入の記載を確認できない。論文は実機向け演算処理の実装を今後の課題にしている。
