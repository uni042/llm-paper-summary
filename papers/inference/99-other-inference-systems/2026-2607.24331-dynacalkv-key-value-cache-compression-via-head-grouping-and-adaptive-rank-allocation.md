# DynaCalKV

## 概要
低ランクKV圧縮はキー・値投影を小さな行列へ分け、トークンごとに保存する中間表現を縮小する。DynaCalKVはReCalKVの固定4ヘッド群をやめ、キー側の注意ヘッドを中心化カーネル整合度（Centered Kernel Alignment; CKA）で動的に群分けし、各群の情報量に応じてランクを配る。値側は行列全体を特異値分解（Singular Value Decomposition; SVD）し、校正データ上の再構成誤差を減らす。

キー側パラメータはReCalKV比でLlama-3.2-1B-Instructが18.23%、Qwen1.5-1.8B-Chatが16.00%、SmolLM2-1.7B-Instructが65.23%少ない。標準6ベンチマークの平均精度差は小さい一方、LongBenchではGQAのLlama-3.2-1Bが平均-8.03ポイントと大きく悪化し、MHAのQwen1.5は-1.02ポイントに留まった。

## 問題設定
既存ReCalKVはキーの注意ヘッドを常に4個ずつまとめ、各群へ同じ圧縮率を与える。しかしヘッド間類似性は均一ではなく、似ていないヘッドをまとめたり、冗長な群へ必要以上のランクを与えたりする。

## 手法
層ごとのフィッシャー情報量（Fisher Information）で層間のランク予算を決める。キー側ではヘッド間CKA類似度を計算しクラスタ化する。群の大きさは固定しない。各群には特異値二乗和で測るエネルギーに比例して初期ランクを与える。

動的群分けでは固定群方式よりパラメータ数が増える可能性があるため、ランクを1減らした際のエネルギー損失を群サイズで正規化し、損失が小さい群からランクを削る。ReCalKV以下のパラメータ予算になるまで繰り返す。クラスタ数も、再構成誤差と未使用ランクへの罰則を合わせた目的関数で選ぶ。

値側は群分けせず全投影行列をSVDし、WikiText-2の校正活性値に対する出力再構成誤差を最小化する閉形式更新で左右因子を補正する。これらは一度だけ行うオフライン処理であり、ReCalKVに対する追加オンライン処理はない。

## 評価
Palu公式コードを基盤にReCalKVを再実装し、単一NVIDIA T4でLlama-3.2-1B-Instruct（GQA）、Qwen1.5-1.8B-Chat（MHA）、SmolLM2-1.7B-Instruct（MHA）を評価した。校正はWikiText-2、一般性能は6種QA、長文脈はLongBench 8タスク。

キー側パラメータ削減は18.23%、16.00%、65.23%。標準ベンチマーク平均差はそれぞれ-0.1533、-0.8100、+0.4433ポイント。一方LongBenchではLlama-3.2-1Bが-8.03、Qwen1.5が-1.02で、GQAへの動的群分けは安全とは言えない。SmolLM2のLongBenchは基盤方式を含む全方式がほぼゼロ性能のため比較対象外。

## 既存研究との差
PaluやLoRCは低ランク分解、AsymKV/ReCalKVはキーと値の非対称圧縮を行う。DynaCalKVはReCalKVの固定群・均一ランクという仮定を外し、類似度ベースの群分けと群別ランク配分を導入する。値を無圧縮で残す方式と異なり値側も校正付き低ランク化する。

## 限界・実装状況
評価は1〜2B級モデルと単一T4に限定される。特にGQA長文脈で大きな精度低下があり、大規模GQAへ一般化できる証拠はない。トークン毎秒や実測KV容量より、圧縮パラメータ数とタスク精度中心の評価である。
