# LatentHarness: Learning Latent Actions for Memory and Reasoning via Counterfactual Policy Distillation

> ループ型潜在推論の各ステップで、計算継続・メモリ想起・トークン発行の3行動を方策に選ばせ、全行動の1ステップ分岐で得た反実仮想利得で方策と書込みゲートを教える方式により、長文脈推論の精度を上げながら計算量を全深さの約55パーセントへ下げた。

## 概要

長文脈の推論には性質の異なる2種類の「長さ」がある。第1は入力の長さであり、答えに必要な証拠が長い入力や多ターンのやり取りの中に散らばっている。第2は推論の長さであり、課題を解くのに何段もの中間計算が必要で、その途中で証拠を取りに戻る必要も生じる。従来の研究はこの2つを別々に解いてきた。外部メモリを使うエージェントは遠方の証拠を保持して取り出すが、メモリはモデルの外にあり、読出しは文脈窓を通るため、取り出した内容は再びトークンとして処理される。潜在推論は逆に、中間計算を文章として書き出さず隠れ状態の中で進めることで計算の長さを圧縮するが、その計算は現在の隠れ状態から再構成できる範囲に限られ、隠れ状態に残っていない証拠は取り戻せない。

本論文はこの2つを1つの決定問題に統合する。土台は、1つの重み共有ブロックを最大で決められた回数だけ繰り返し適用し、深さを増やさずに計算量を伸ばすループ型の言語モデルである。これに、順伝播の中で書き込まれる高速重み型の連想メモリ、つまり勾配降下ではなく推論中の書込みで内容が決まる行列メモリを組み合わせる。生成の前にプロンプト全体をこのメモリへ書き込んでおき、各トークン位置では潜在ステップごとに方策が3つの行動から1つを選ぶ。計算を続ける行動、メモリから証拠や過去の計算結果を読み出す行動、次のトークンを発行する行動である。読み出しは行列とベクトルの積1回で済み、ブロック適用よりはるかに安い。学習の要は反実仮想方策蒸留であり、各潜在状態で許される全行動を1ステップだけ分岐させ、発行されるトークンの対数確率がどう変わるかを測って行動ごとの利得にする。この利得が方策に「今は計算より想起が得か」を教え、分岐した想起の変化をメモリ経由で微分することで、過去の書込みのうちどれが後の想起を助けたかを書込みゲートへも教える。

**代表結果:** 1.4B規模の基盤で、一般推論3課題の平均は最強の比較対象である潜在方式RLTTの54.3を55.8へ、長文脈推論3課題の平均はトークン空間メモリ方式Memory-R2の45.2を49.7へ上げた。相対では一般推論で2.8パーセント、長文脈で10.0パーセントの改善であり、長文脈の回答遅延はMemory-R2の17.7秒に対して3.0秒と5.9倍速く、計算量は全深さ基盤の48から62パーセントに収まった。

## 問題設定

問題を資源の観点で見る。ループ型の潜在推論は、隠れ状態へ同じブロックを繰り返し適用することで1トークンあたりの計算深さを伸ばす。しかし繰り返しには限界がある。論文の分析では、一般推論ではループの51パーセントが隠れ状態を実質的に変えておらず、長文脈では位置の33パーセントが何度繰り返しても安定した状態へ収束しない。収束しない理由は計算不足ではなく、その位置の予測に必要な証拠が隠れ状態の中に存在しないためであり、同じ状態へブロックを適用し続けても存在しない情報は生まれない。逆に、証拠を取り出す仕組みを外付けのメモリと文脈窓経由の読出しで作ると、読出しのたびにトークン列としての再処理が要り、計算量は基盤の3倍から4.5倍へ膨らむ。つまり、足りないのは「計算」か「情報」かを行動ごとに区別し、情報が足りない位置では安い読出しで補い、計算が足りない位置ではブロック適用を続ける配分である。

もう1つの問題は学習信号である。軌跡全体の正解・不正解という報酬だけでは、途中のどの行動が良かったか、どの書込みが後の助けになったかが分からない。密な潜在損失で各状態の予測を監督する方式はあるが、行動そのものへの信用は標本化された軌跡に依存する。方策がある行動へ集中すると、標本の中で行動が分かれなくなり、信用の勾配は消えてしまう。書込みゲートに至っては、実際に実行された想起の下流でしか勾配が届かず、学習初期は想起自体が稀なため、ほとんど学習が進まない。本論文は、行動と書込みの両方について、実行された経路ではなく全行動の反実仮想分岐から信用を得ることで、この2つの不足を同時に解こうとする。

## 手法のあらまし

処理の流れは、記憶、潜在ステップの反復、発行の3段である。まず生成に先立ち、共有ブロックを1回プロンプトへ適用し、その過程で全プロンプトトークンを単位の書込み強さでゼロ行列のメモリへ順に書き込み、入力の証拠を保持する。次に各トークン位置では、隠れ状態とメモリと、その位置で使った計算ステップ数からなる潜在状態を保持し、方策が行動を選ぶ。計算継続を選ぶと共有ブロックを1回適用し、その結果をキーと値に射影してデルタ則でメモリへ書き込む。書込みの強さは学習されたゲートが決め、より多くの計算ステップを経た結果ほど強く書く傾向を学習する。想起を選ぶと、現在の隠れ状態から作ったクエリでメモリを1回読み、得られたベクトルを隠れ状態へ加える。メモリは書き換わらない。発行を選ぶと、その時点の隠れ状態から次のトークンを出し、次の位置へ進む。計算ステップ数と想起回数には位置ごとの上限があり、両方が上限に達すると発行が強制される。推論時は方策の最確率行動を選び、学習時は軌跡報酬による強化学習と反実仮想方策蒸留を組み合わせて方策とゲートを更新する。

## 手法

### 1. 高速重みメモリと3行動 — 書く対象と読む対象を同じ行列に置く

この機構が観測するのは、各潜在ステップにおける隠れ状態と、メモリへ何が書かれてきたかである。保持する状態は、隠れ状態、次元が隠れ次元と等しい正方行列のメモリ、計算ステップ数の数え上げの3つである。メモリへの書込みはデルタ則で行う。書込み前の隠れ状態から正規化したキーを作り、ブロック適用後の隠れ状態から値を作り、現在のメモリがそのキーに対して保持する内容との差分に、ゲートが決めた強さを掛けて加える。これにより、似たキーの内容は上書き的に更新され、無関係な内容は残る。行う選択は3行動の配分である。計算継続はブロック適用で隠れ状態を深め、同時にその結果をメモリへ書く。想起はメモリを変更せず、クエリとキーが似た保存値の重ね合わせを読み出して隠れ状態へ注入する。発行は現在の隠れ状態でトークンを出す。減るボトルネックは2つある。1つは、証拠が無い位置でブロックを空転させる無駄な計算であり、もう1つは外部メモリ方式が読出しのたびに払う文脈窓経由の再処理である。追加で消費する資源は、メモリ行列そのものと、キー・値・クエリ・出力の各射影、そして方策の小さな線形ヘッドであり、追加パラメータは基盤の1.0から1.8パーセントにとどまる。失敗条件は、メモリの容量が固定の正方行列であることによる干渉である。後の書込みが前の書込みのキーと重なると、古い証拠が書き換わって保持が崩れる。論文の分析では、書込み時刻だけを目標に学習したゲートでは生成が2千トークン進んだ後の証拠保持率が0.64まで落ち、利得連動で学習したゲートの0.91と差が付いた。

### 2. 潜在行動方策 — 読む前に読みの見込みを覗く探針

方策が判断に使うのは、隠れ状態そのものと、保留中の読みに対する探針である。探針とは、実際に想起を実行する前に、現在のクエリでメモリを読んだ場合のベクトルの大きさと、隠れ状態との余弦類似度を計算した2つの数値である。読みのベクトルが大きく、かつ隠れ状態と方向が違うほど、その読みは現在の計算では得られない新しい方向を足す見込みが高い。方策は隠れ状態とこの探針を連結した入力への線形ヘッドであり、3行動への確率を出す。保持する追加状態は持たず、探針の計算自体は潜在ステップとして数えない。なぜ効くか。想起すべきかどうかは、読みを実行してみるまで分からないのが普通だが、探針により読みの「効きそうさ」を実行前に安く見積もれる。論文の測定では、実際に想起が選ばれた状態では保留中の読みの相対的な大きさが0.58、保留中の計算更新との余弦が0.12だったのに対し、計算継続が選ばれた状態では0.14と0.36であり、想起は大きくて計算と重ならない読みがあるときに選ばれている。誤りの場合の挙動として、方策が前進を誤認することはあり得るが、行動は確率的に学習されるため、後の反実仮想信用が誤った選択を修正する方向に働く。資源不足時の挙動は上限によるマスクであり、計算回数や想起回数が位置ごとの上限に達した行動は選択肢から外れ、両方が尽きれば発行が強制されるため、1位置の潜在ステップが無限に伸びることはない。

### 3. 反実仮想方策蒸留 — 全行動を1ステップだけ分岐させて利得を測る

この機構が観測するのは、各潜在状態で許される全行動について、その行動を1ステップだけ実行したときに発行トークンの対数確率がどう変わるかである。保持する状態は持たず、学習時にだけ分岐を計算する。各行動の利得は、この確率変化から行動の費用を差し引いたものに、軌跡全体の優位を掛けて作る。費用は計算継続を1、想起をそれ未満、発行を0とし、正の優位の軌跡でのみ差し引く。短い失敗が長い成功より上になることを防ぐためである。これらの利得をソフトマックスで分布化したものが教師となり、方策はこの教師分布へ近づくよう蒸留される。なぜ効くか。標本化された行動への信用は、方策が集中すると行動の分かれ目が消えて勾配も消えるが、反実仮想の教師は方策の標本に依存せず全行動を常に比較するため、信用が薄れない。論文では、通常の軌跡報酬だけの学習では方策のエントロピーが200ステップ以内に0.21ナッツまで落ちたのに対し、本方式では0.68を保った。また分岐は1ステップで打ち切るため、行動を最後まで実行して評価する方式の約3分の1の学習計算で済む。追加で消費する資源は学習時の分岐計算であり、訓練計算は通常の強化学習の1.1倍にとどまる。失敗条件は、分岐が1ステップの効果しか見ないことである。複数ステップ先で初めて効く行動は過小評価され得るが、軌跡報酬による学習が下流の信用を補う併用構造になっている。選ばれなかった分岐は書込みを確定させず、選ばれた分岐の次状態だけが再利用されるため、分岐による状態の汚染はない。

### 4. 利得連動の書込み学習 — 後の想起を助けた書込みだけを残す

この機構が観測するのは、全潜在状態における想起分岐の確率変化であり、想起が実行された状態だけでなく、想起が許される全状態で測る。学習対象は書込みゲートの重みと、計算ステップ数に応じて書込みを強める係数だけであり、キーや値の射影は通常のトークン損失が学習する。行う動作は、正の優位を持つ軌跡について、想起の確率変化の平均を大きくする方向へゲートを更新することである。ある書込みへの信用は、内容の寄与と宛先の寄与の積に分解できる。内容の寄与は、その書込みの値が後の予測をどれだけ改善するかであり、宛先の寄与は、途中の書込みを経ても後のクエリがそのキーへ届くかである。どちらかがゼロなら信用はゼロになり、後の予測を悪化させる書込みには負の信用が付く。なぜ効くか。書込みの価値は書いた時点では決まらず、後に読まれて初めて決まる。この学習はまさにその「後に読まれて助けたか」でゲートを評価するため、再利用される派生状態にはゲートが開き、読まれない書込みには開かなくなる。論文では、後に再利用された書込みの58パーセントでゲート値が0.7を超えたのに対し、読まれなかった書込みでは6パーセントだった。失敗条件は、負の優位の軌跡をこの信号から外していることであり、有害な書込みを積極的に消す学習は行われない。設計上の選択として、負の重みを付けるとゲートが雑音を書いて想起の変化を下げる方向へ倒れ得るため、正の軌跡だけに限定している。

| 高速重みメモリ | プロンプトと各計算結果 | デルタ則でキーと値の対を書き込み、クエリで重ね合わせを読む | 証拠の喪失と外部メモリの再処理 | 固定容量の干渉で古い証拠が上書きされ得る |
| 潜在行動方策 | 隠れ状態と保留中の読みの探針 | 計算継続・想起・発行の確率を出す | 計算と情報の取り違え | 探針は2数値のみで読みの内容までは見ない |

### 5. 1トークンの流れ — 記憶済み証拠と派生状態の再利用

1つのトークン位置は次のように進む。位置の開始時点でメモリにはプロンプト全体と、それまでの位置で書かれた派生状態が入っている。方策が探針を見て、証拠が足りなければ想起が選ばれ、メモリから根拠となる文章片や前段の計算結果が隠れ状態へ足される。計算が足りなければ計算継続が選ばれ、ブロックが1回適用されて結果がメモリへ書かれる。この往復が数回続いた後、発行が選ばれてトークンが出る。複数ホップの質問では、ホップ数が増えるほど位置あたりの想起回数が増え（2ホップで0.24回、4ホップで0.50回）、想起の中身もプロンプトの証拠だけでなく、前のホップで書かれた派生状態の割合が29.5パーセントから40.8パーセントへ増える。つまりメモリは証拠の保管庫であると同時に、中間結果の引き継ぎ場所としても働く。本方式は生成内容を近似する方式ではないが、方策の判断が軌跡そのものを変えるため、結果の品質は学習された方策の出来に依存する近似的な制御である。

## 評価

結論は3点である。第1に、本方式は一般推論と長文脈推論の両方で全ての比較対象を上回り、特に長文脈での伸びが大きい。第2に、精度の向上と計算量の削減が同時に起きており、全深さの約55パーセントの計算で最強の比較対象を上回る。第3に、除去実験により、想起という行動そのもの、状態単位の反実仮想信用、利得連動の書込み学習のそれぞれが独立に効いていることが示された。評価は学習を伴う実測であり、正確一致と回答F1による課題品質が中心で、推論基盤としてのスループット評価は論文の主対象ではない。

## 既存研究との差

トークン空間のメモリ方式は、メモリをモデルの外に置き、読み書きを生成テキストとして行う。本論文はメモリを潜在計算の中へ移し、読出しを文脈窓経由の再処理から行列積1回へ替えた。潜在推論の系譜では、Coconutが隠れ状態を思考として戻し、Ouroが重み共有ループの深さを学習し、RLTTが軌跡報酬から各潜在状態へ密な信用を与えた。本論文はこれらに、メモリを読むという第3の行動と、その行動への反実仮想信用を追加した。信用割当ての観点では、分岐を完走させて評価する方式や状態を群化する方式に対し、1ステップ分岐で全行動を常時比較することで、学習計算を抑えながら信用の消失を防いだ点が異なる。

## 限界・実装状況

論文は進行中の研究と位置付けられており、著者ら自身の明示的な限界節はない。読み手の注意点として、第1に、土台が重み共有ループを持つ特殊な基盤であり、通常のTransformerへそのまま移せるかは未検証である。第2に、メモリは固定サイズの正方行列であり、入力がさらに長くなれば干渉による証拠の上書きが進むはずだが、64千トークンを超える長さは未評価である。第3に、残存誤りの中心がメモリの宛先付けの精度であり、クエリとキーの射影の改善なしには多ホップ品質の頭打ちが近い。実装状況としては、公式コードの公開は一次資料に見当たらず、再現は基盤であるOuroの公開実装と論文の記述に依存する。

## 一般的な実装上の含意

計算を足すことと情報を取りに行くことは別の行動であり、推論時の配分はこの区別を信号として持つべきである。特に、読みを実行する前に読みの見込みを安く見積もる探針のような仕組みは、検索や道具呼び出しの配分にも転用できる。また、書込み型メモリの学習では、書いた時点の損失ではなく「後に読まれて予測を助けたか」で信用を返すと、保持すべき内容と捨てるべき内容の区別が学習できる。信用割当てについては、標本化された経路への依存は方策の集中とともに信号を細らせるため、全選択肢の反実仮想評価を1ステップでも挟むことが安定化に効く。
