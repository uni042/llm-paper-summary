# OmniQuant: Omnidirectionally Calibrated Quantization for Large Language Models

> ブロック単位でLWCとLETだけを学習して外れ値と量子化範囲を調整し、LLaMA系をW2A16〜W4A4まで低ビット化して推論メモリと計算を削減する。

## 概要
LLMの後学習量子化（post-training quantization; PTQ）は、学習済みモデルを再学習せず低ビット化できるが、2〜4ビットまで下げると重み・活性値の外れ値に量子化範囲を取られ誤差が急増する。OmniQuantは元の全精度重みを固定し、量子化に必要な少数パラメータだけを勾配で調整する。学習可能な重みクリッピング（Learnable Weight Clipping; LWC）と学習可能な等価変換（Learnable Equivalent Transformation; LET）を組み合わせ、量子化対応学習に近い精度をPTQの小さな校正コストで狙う。

## 問題設定
既存PTQではSmoothQuant等の移動強度やAWQ等のスケールを手設計・探索するため、極低ビットで最適値から外れやすい。一方、量子化対応学習は全モデルを扱うためデータ・GPU時間が大きい。OmniQuantは「全重みを学習せず、量子化パラメータだけを微分可能にする」ことで両者の間を埋める。

## 手法
各Transformerブロックについて、全精度出力と量子化後出力の誤差を最小化するようLWCとLETのパラメータだけを順番に最適化する。モデル全体を同時に最適化しないため解空間とGPUメモリを抑え、LLaMA-2 7B〜70BをA100 40GB 1枚、128サンプルで1〜16時間で処理できる。

LWCは重みの上限・下限に対するクリッピング強度を学習し、極端な重み値のために量子化刻みが粗くなる問題を抑える。LETはチャネル単位のスケーリングとシフトを使い、活性値の外れ値を重み側へ数学的に等価な形で移す。線形層だけでなく注意演算にも適用し、KVキャッシュ量子化にも寄与する。

校正後、LETのスケール・シフトは隣接する正規化層や線形層へ吸収でき、LWCの閾値も量子化済み重みに反映できる。そのため最終量子化モデルへ追加パラメータや追加演算を残さない。

## 評価条件・主要結果
OPT、LLaMA、LLaMA-2、LLaMA-2-Chat、Falconの125M〜180Bを対象に、W4A16、W3A16、W2A16、W6A6、W4A4を評価する。LLaMA-13BのW2A16ではOmniQuantのWikiText2パープレキシティが13.21なのに対しGPTQは3832まで悪化し、極低ビットで学習可能な校正パラメータが重要であることを示す。

| 観点 | 結果 |
|---|---|
| 校正資源 | LLaMA-2 7B〜70BをA100 40GB 1枚、128サンプル、1〜16時間 |
| 対応設定 | W4A16 / W3A16 / W2A16 / W6A6 / W4A4 |
| LLaMA-13B W2A16 | PPL 13.21、GPTQは3832 |
| 配備 | 校正パラメータを融合でき追加推論演算なし |
| 実機 | 推論速度向上とメモリ削減を報告 |

## 既存研究との差
SmoothQuantの固定的な等価変換やGPTQ/AWQの手設計・探索中心のPTQに対し、LWCとLETをブロック再構成誤差から直接学習する。全重みを更新する量子化対応学習より校正対象を大幅に限定する。

## 限界
校正は完全な学習不要ではなく、モデル規模に応じて最大16時間程度を要する。極低ビットでの品質はモデル系列・タスクに依存し、量子化カーネルが対応しなければ理論上の低ビット化がそのまま実機高速化になるとは限らない。
