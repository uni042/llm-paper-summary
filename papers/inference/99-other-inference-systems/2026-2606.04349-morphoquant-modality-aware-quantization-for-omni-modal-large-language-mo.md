# MorphoQuant：全モダリティLLMに対する分布適応型W4A4量子化

## 概要

画像・動画・音声を扱う全モダリティ大規模言語モデルでは、入力形式によって活性値の分布が大きく変わる。言語だけを扱うモデル向けに設計された一律の4ビット事後量子化を適用すると、まれに現れる大きな活性値を切り詰める誤差と、多数の小さな活性値を粗い格子に丸める誤差の両方が生じる。画像・音声・動画の各経路で外れ値の出現傾向が異なるため、同じ閾値と尺度を使うと情報が失われやすい。

WuらはMorphoQuantを提案し、外れ値の切り詰め残差を別経路で補償するDABCと、残った密な活性分布に合う量子化境界を調整するMDQFOを組み合わせる。重み・活性とも4ビットのW4A4を対象とし、Qwen2.5-Omni-3Bで画像質問応答、動画理解、音声理解を評価する。

ScienceQAは76.63%、MMMUは45.11%、Video-MMEは54.33%、AIR-Benchは65.09であり、比較したW4A4方式を上回る。ScienceQAとMMMUではW4A16のQLoRA参照よりも高い。しかし原著Table 1のメモリはMorphoQuantが6.07GB、QLoRAが5.54GBであり、「W4A4だから必ずW4A16より省メモリ」という結論は成立しない。実機のトークン毎秒やエンドツーエンド推論時間の比較も十分ではなく、精度上の改善と速度上の改善を区別する必要がある。

## 問題設定と従来量子化の限界

一様なkビット量子化では、浮動小数点の活性値を尺度で割り、丸めと範囲外の切り詰めによって整数格子へ写す。量子化範囲を広くすると大きな外れ値を残せる一方、密集した小さい値の間隔が粗くなり、丸め誤差が増える。逆に範囲を狭くすると多数の小さい値は精密に表せるが、少数の外れ値が大きく切り詰められる。

全モダリティモデルでは、言語・画像・動画・音声が同じ活性分布を持つわけではない。特にまれな大振幅のチャネルは、単純な平均二乗誤差に基づく較正で強く影響し、量子化境界を必要以上に広げる。外れ値を高精度のまま保持する混合精度方式は精度面で有利でも、密な4ビット行列積に16ビット演算を混在させると、カーネルの実装やメモリアクセスが複雑になる。

MorphoQuantの狙いは、外れ値の保護と多数派の値の細かな表現を別の処理に分けることである。外れ値が多いチャネルを見つけて切り詰め残差を補償し、そのうえで残りの活性に合う対称量子化格子を探索する。したがって、単純な一律クリップやチャネルごとのビット幅増加とは異なる。

## 手法

### DABC：チャネル分散度に基づく外れ値の識別

各活性チャネルの最大値と最小値の差を、そのチャネルの平均絶対値で正規化した分散度スコアを計算する。値域が大きい一方で普段の活性が小さいチャネルは、まれに大きな外れ値が出現している可能性が高い。スコアを降順に並べ、上位の少数チャネルを外れ値補償の対象とする。原著の主実験では128件のマルチモーダル較正サンプルを使い、上位5%のチャネルをマスクする。

補償対象のチャネルに対して、元の活性Xと量子化後の活性X_Qとの差のうち、対象マスクが立っている部分を残差として取り出す。量子化重みW_Qで密なW4A4行列積を実行する経路と、この残差をW_Qで射影して加える経路を分離する。概念的には `Y = W_Q X_Q + b + W_Q((X−X_Q)⊙m)` である。

重要なのは、補償項が入力活性の残差に依存することである。単なる静的な定数バイアスへ常に吸収できると考えてはならない。原著はこの項を高精度の疎な補正計算として実行し、密な4ビット行列積と分離する設計を述べる。補償対象を少数チャネルに限定することで、全チャネルを高精度に戻す費用を避ける。

### MDQFO：密な活性分布に合う量子化境界の探索

外れ値の残差を別経路で保護すると、主経路で扱う多数の活性はゼロ付近に密集したほぼ対称な分布として扱いやすくなる。MDQFOは対称区間[−α_c, α_c]を量子化範囲とし、クリップ境界α_cを学習可能なパラメータとして最適化する。外れ値の大きさだけに引きずられず、多数派の活性を細かく離散化できる境界を探す。

目的関数は活性の再構成誤差だけではない。元の浮動小数点活性と量子化・補償後の活性のベクトル方向を保つため、コサイン類似度に基づく損失を追加する。原著では再構成側の損失と方向整合損失を重み付きで組み合わせ、境界を反復的に更新する。これにより、絶対値の大きさだけでなく、モダリティ間の意味的な特徴方向も保つことを狙う。

外れ値のマスクと境界探索は互いに影響する。補償する残差が多すぎると疎な補正の費用が増え、少なすぎるとクリップ誤差が大きくなる。そこで補償対象の閾値と量子化境界を協調させ、密な4ビット経路と高精度補正経路の分担を決める。

### 推論時の処理経路と費用

較正時には128件のサンプルでチャネル分散度と量子化境界を求める。推論時には入力活性を4ビットに量子化し、量子化重みとの密な行列積を行い、補償対象の外れ値残差だけを高精度で追加計算する。原著の設計意図は、密な4ビット行列積を標準的なTensor Core系カーネルに載せ、補償経路を軽量に保つことである。

ただし補償項が存在する以上、演算回数やメモリアクセスの追加がゼロになるわけではない。原著の精度比較から、特定GPUでの実際の速度改善やエネルギー効率を定量的に確定することはできない。外れ値比率、カーネルの疎行列処理性能、バッチサイズによって費用は変わり得る。

## 評価

### 評価設定

| 項目 | 原著の条件 |
|---|---|
| 対象モデル | Qwen2.5-Omni-3B |
| 量子化 | W4A4、比較用W4A16、FP16 |
| 重み量子化 | W4A4各方式でQLoRA由来の同一4ビット方式を使用 |
| 活性量子化 | DABC＋MDQFOと各比較方式 |
| 較正 | マルチモーダル128例、分散度上位5%チャネルを保護 |
| 画像理解 | ScienceQA、MMMU |
| 動画理解 | Video-MME |
| 音声理解 | AIR-Bench |
| メモリ | ScienceQA実行時の重みと活動バッファのGPU VRAM |

異なる評価指標を混同してはならない。ScienceQA・MMMU・Video-MMEは正答率、AIR-Benchは総合スコアであり、同じ「%」として平均してはいけない。原著のメモリ値はScienceQA上でのモデル重みと活動バッファの使用量で、純粋な重みサイズだけではない。

### ハイパーパラメータ感度：原著Figure 6

コサイン損失の重みλ_cosは4ビット条件で重要であり、原著では0.75付近が良い。0.5未満では方向整合性の拘束が弱く、1.0を超えると方向の整合に偏り、値の大きさの再構成が悪化する。8ビットではこの感度が小さく、4ビット特有の粗い離散化に対応した調整が必要である。

補償対象の閾値を広げる係数γを1.0から2.0へ増やすと、補償される活性の割合が減る一方、ScienceQAの精度は約77%から約70%へ下がる。原著はγ=1.5付近を交換条件の良い設定とする。補償対象を少なくすれば常に良いわけではなく、外れ値保護と追加計算の費用を両立させる必要がある。

## 既存研究との差

従来の一律量子化は外れ値の切り詰め誤差と多数派の丸め誤差を同じ格子で処理しようとする。混合精度方式は一部のチャネルを高精度に保つが、密な演算に異なるビット幅を混在させる負担がある。MorphoQuantは密な4ビット演算を維持しながら、少数の外れ値残差だけを別経路で補償し、残りの活性に合う対称量子化境界を探索する。

さらに、量子化後のベクトルの方向を保つ損失を導入することで、画像・音声・動画にまたがる意味的な表現の整合を狙う。これが単純な平均二乗誤差の最小化や、重みだけの量子化と異なる点である。もっとも、実際に改善したことを示す主な証拠は評価ベンチマークであり、活性分布のPCA可視化だけで因果関係を確定することはできない。

## 限界と実務上の判断

実験モデルはQwen2.5-Omni-3Bに限られ、他の全モダリティモデル、異なるモデル規模、長文脈生成、同時要求のサービングへの一般化は未検証である。較正例は128件で、チャネル上位5%の選択と境界最適化はモダリティの分布に依存する。実運用で入力分布が変わると、同じマスクが適切とは限らない。

原著は密な4ビット演算と疎な補償を分離する設計を説明するが、補償の実装コストを含むGPU実測のトークン毎秒、TTFT/TPOT、P99遅延、消費電力の包括的な比較は示していない。Table 1のVRAMではW4A16 QLoRAより多く、メモリ最小化を達成したと断定できない。FP16を超えるMMMUの小差についても、統計的な有意性や複数シードの再現性が十分に示されているとは限らない。

実務では、W4A4化による精度劣化を抑えたい場合に検討する価値があるが、メモリや速度の改善を期待する場合は、補償経路を含む実カーネルの測定が不可欠である。異なる量子化方式と比較する際には、モデル重みだけでなく活動バッファ、外れ値補償の追加メモリ、較正費用を同じ条件で計測する必要がある。
