# Maglev: Sliding Recurrent Memory

## 概要

Maglevは、スライディング窓注意（SWA）のKVキャッシュを固定長のまま維持しつつ、窓から押し出された過去の情報を**各トークンで更新する潜在記憶**に蓄積する言語モデル構造である。推論で使う復号器Pは全履歴を直接参照しない。代わりに、直前の記憶ベクトルを鍵・値（K/V）に混ぜ、通常の局所注意演算を通じて情報を次の記憶へ引き継ぐ。全履歴を参照できる訓練専用の前処理器Qが、時刻ごとの記憶の教師信号を並列に作る点が中心的な工夫である。

435M規模、学習43.52Bトークン、最大系列長2048という制御された比較で、最良の**Q/P分離パラメータ、整合損失重みλ=1**は、通常の局所窓Transformerに対してFineWeb-Edu検証のビット/バイト（BPB）を0.7413から0.7251へ低下させ、下流精度平均を54.1から56.4へ改善した。比較対象の潜在再帰Transformer（LRT、局所窓型）のBPB 0.7331、平均55.0も上回る。ただしこれは**モデル品質の比較**であり、推論レイテンシが何倍になったという実測ではない。本文にある窓サイズ一定の計算・記憶量の主張は構造的性質で、2048を超える長さでの精度維持は別途検証が必要である。

## 問題設定と設計のねらい

全注意Transformerでは過去の全トークンをKVとして保持するため、文脈が伸びるほど記憶容量と注意演算が増加する。SWAは直近W個のKVだけを残すので推論時の注意窓を固定できるが、窓外の情報は参照できない。ブロック単位の再帰記憶方式では更新境界が人為的に決まり、トークン単位で記憶を再編集する仕組みが弱い。一方、各トークンの状態を非線形Transformerで再帰更新すると、学習時には前時刻の記憶が決まるまで次時刻を計算できず、系列方向の並列化を失う。

Maglevは「学習では全時刻を並列処理し、配備時には直前の潜在記憶から再帰推論する」という相反する要件を分離する。各時刻tで記憶m_tを更新し、保持する記憶窓をm_{t-W+1:t}に限定する。トークン窓と記憶窓の長さはWで固定し、専用の記憶トークンや別の無制限キャッシュは追加しない。長期履歴の情報がどの程度保持されるかは、有限次元の潜在状態への圧縮品質と自己帰還の安定性に依存する。

## 手法

### 1. 全履歴を参照する訓練専用prefiller Q

訓練入力x_{1:T}に対し、Q_φは因果的に各位置の目標記憶m'_1,...,m'_Tを**一度の系列並列パス**で生成する。未来トークンを参照しない因果注意でありながら、復号器より広い過去を参照できることが教師としての役割である。実験のQは局所窓Sと全注意Lを交互に配置した「SLSL」層構成を用い、局所窓512、学習文脈2048の全履歴へ到達できる。Qは配備時に不要なので、教師信号の品質のために全注意の訓練コストを支払う設計となる。

Qの出力は単なる正解トークンの確率ではなく、復号器が次時刻へ渡すべき**各位置の最終正規化後の潜在状態**である。Qの時刻tの状態をPへそのまま渡すと、Pの時刻tが自身の入力より新しい情報を参照する危険があるため、Pには1時刻ずらしたm'_{0:T-1}（m'_0=0）を与える。Qが因果的に生成したm'_{t-1}はx_{≤t-1}から計算され、推論時に利用できる情報範囲と整合する。

### 2. ずらした記憶で並列学習するdecoder P

P_θは「SSSS」、すなわち全層が窓512の局所注意である。訓練時にはQが先に出力した記憶列が確定しているため、各時刻のPは自身が直前に出した記憶を待つ必要がなく、全トークン位置をまとめて計算できる。Pは次トークンx_{t+1}の予測分布と、自身が生成した記憶m_tの両方を出力する。これにより本来は逐次的な非線形再帰を、Qの1パスとPの1パスという二つの系列並列処理へ持ち上げる。

学習目的は次トークン交差エントロピーと記憶整合損失の和で、論文式(5)では各位置の整合項が **λ‖m_t−m'_t‖₂/√d** と定義される。二乗ノルムではなくL2ノルムである。λは整合性をどの程度強く強制するかを制御し、実験では0.1と1.0を比較する。Q/Pが同じTransformerブロックを共有する設定では、同一のパラメータが教師信号と学習対象の両方へ関わるため、λを強めれば常に良いわけではない。別のQスタックを持つ設定では教師の表現力が高まる一方、学習時のパラメータ容量と計算が増える。

### 3. 再帰記憶を既存KVへ注入する仕組み

各層ℓの通常のトークン由来の局所鍵k_t^ℓ、値v_t^ℓに、直前の記憶m'_{t-1}から投影した再帰特徴を加える。再帰鍵はRMSNorm(W_k^rec m'_{t-1})、再帰値はW_v^rec m'_{t-1}である。さらに層別の局所ゲートと再帰ゲートを残差流a_t^ℓから計算し、それぞれ **2σ(G_loc^ℓ a_t^ℓ)** と **2σ(G_rec^ℓ a_t^ℓ)** とする。係数2はゲートの入力が0のとき重みが1となるようにするためで、両経路を独立に増減できる。

混合鍵は g_loc⊙k_local + g_rec⊙k_recurrent、混合値も同じ形式で構成する。位置埋め込みRoPEが有効な場合は、局所鍵と再帰鍵の双方へ適用してから混合する。局所窓注意は、通常のK/Vではなく、この**混合済みK/Vを直近W件**だけ参照する。過去時刻jの混合キャッシュには、その時刻の局所トークン情報だけでなく、時刻j−1までの記憶が畳み込まれているため、専用記憶トークンを追加せず過去の圧縮情報を読み出せる。

Pの最終RMS正規化後の状態m_tは、言語モデルの出力ヘッドの入力になると同時に、次時刻の再帰入力として利用される。層ごとの隠れ状態を永続保存する設計ではなく、最終状態から作った再帰K/Vを通常キャッシュへ埋め込む設計である。したがってKVの件数はWで抑えられるが、追加の投影・ゲート演算は発生する。窓長が同じでも、標準SWAと厳密に同じ演算時間になるとは論文は証明していない。

### 4. 訓練と推論で異なる記憶入力

訓練中のPはQが出したm'_{t-1}を受けるが、推論ではQを破棄し、**自分が前時刻に生成したm_{t-1}**を再帰投影へ渡す。これが式(10)の閉ループ推論である。学習時には教師信号を与えることで系列並列化できる反面、推論時に小さな記憶誤差が積み重なれば、後続の混合K/Vや予測分布に誤差が伝播する可能性がある。整合損失が局所的に小さいことと、長い系列の閉ループ状態が安定することは同値ではない。論文はこの長期ドリフトを独立の実験指標として測定していない。

## 主要結果

論文のTable 1に基づく。FW BPBとLAMBADA PPLは小さいほど良く、下流平均は高いほど良い。数値は同じ435M規模・43.52Bトークン学習条件での比較である。

| 方式 | FW BPB ↓ | LAMBADA PPL ↓ | 下流精度平均 ↑ |
|---|---:|---:|---:|
| Transformer（SLSL、全注意を含む） | 0.7373 | 8.44 | 54.5 |
| SWA（SSSS） | 0.7413 | 8.54 | 54.1 |
| LRT（SSSS） | 0.7331 | 7.92 | 55.0 |
| Maglev 共有Q/P、λ=0.1 | 0.7295 | 8.06 | 56.2 |
| Maglev 共有Q/P、λ=1 | 0.7320 | 8.27 | 53.9 |
| Maglev 分離Q/P、λ=0.1 | 0.7276 | 7.73 | 56.0 |
| Maglev 分離Q/P、λ=1 | **0.7251** | 8.06 | **56.4** |

**SWAとの差**：分離Q/P、λ=1ではBPBの絶対差は−0.0162（0.7413→0.7251）、平均精度は+2.3ポイント（54.1→56.4）。LRT SSSSに対してもBPBは−0.0080、平均精度は+1.4ポイントである。LAMBADA PPLだけを見ると分離Q/P、λ=0.1の7.73が最良であり、λ=1が全指標を支配するわけではない。表の「平均」は論文に載る下流タスク精度の算術平均で、BPBやPPLを混ぜた総合スコアではない。

**共有と分離の逆転**：共有Q/Pではλを0.1から1へ増やすとBPBが0.7295→0.7320へ悪化し、平均精度も56.2→53.9へ低下する。分離Q/Pでは同じ増加でBPBが0.7276→0.7251へ改善し、平均精度が56.0→56.4へ上がる。この対照は整合損失の強さが教師と生徒の表現力・パラメータ共有に依存することを示す。強い整合を無条件に推奨できないという負の結果である。

**個別タスクの差**：分離Q/P、λ=1のARC-Challengeは42.7で、SWAの40.1を上回る。BoolQは64.0対56.2で大きく改善する。一方、LAMBADA精度は47.4対46.2で改善幅は小さく、PIQAは72.6対70.5、WinoGrandeは57.4対57.1である。下流タスクごとの改善量が一様ではないことに注意が必要である。

**推論の資源上限と実測の区別**：Pが使う注意窓は512のままなので、各時刻のKVキャッシュ件数は文脈長Tとともに増えない。ただし、学習時のQは全注意を含み、Pも再帰投影・ゲートを追加する。論文の表は品質指標を中心とし、同じGPUでのtoken/s、TTFT、メモリ実測、消費電力を並べたものではない。固定窓の構造から即座に「SWAより高速」と結論することはできない。

## 既存研究との差と研究上の意義

Transformer-XLやブロック再帰Transformerはセグメントまたはブロック境界で状態を引き継ぐ。Maglevはトークンごとに最終隠れ状態を再帰更新し、その記憶を局所KVへ混ぜるため、専用記憶トークンを必要としない。Mambaや線形注意のような構造化された線形・アフィン更新とも異なり、記憶更新には通常のTransformerの非線形深さが介在する。

最も近いLRTも再帰K/Vを使うが、Maglevは全履歴を参照するQの目標記憶列を用意し、Pが前時刻の**自分の出力を逐次生成せずに**全時刻で整合学習できることを新規性とする。比較表でLRT SSSSよりBPBと下流平均が改善するのは、この訓練方式を採用した場合の有効性を示す。ただし、別Qを追加した場合の学習資源差が完全に統制されているわけではなく、改善を整合損失だけに因果帰属することはできない。

## 限界・未評価・再現上の注意

第一に、実験の学習・評価系列は最大2048で、窓512を超える記憶の効果はある程度試せても、長文脈を何万トークンも保持できるという主張を裏付ける試験ではない。固定容量は長文脈への拡張可能性を示す構造条件であり、長文脈での検索・コピー・回想の精度保証ではない。第二に、訓練ではQの正しい過去記憶を入力するが、推論ではPの自己生成記憶を入力する。閉ループでの誤差蓄積を測定するには、例えば2048を超える連続生成でm_tとm'_tの乖離を追跡する追加実験が必要となる。

第三に、Q/P二経路を訓練するので、同一トークン数でも学習FLOPsや壁時計時間は標準SWAと一致しない。分離Q/Pの最良値は教師スタックの追加パラメータを利用する結果であり、学習効率の優越を直接示さない。第四に、報告は435M級の単一規模に集中しており、7B/30B級の大規模モデルやMoEで同じ差が得られるかは未知である。第五に、品質評価の反復数・分散や速度計測が十分に示されていないため、数ポイントの差を再現性や実運用SLOの改善と同一視できない。

この研究は**学習済み既存LLMに後付けで適用するKV圧縮**ではない。再帰K/V投影と整合訓練を含む新規モデル構造であり、既存の量子化済みモデルへ推論設定だけで導入できる手法ではない。運用上は、固定窓のキャッシュ上限と、モデル再学習の必要性を明確に分けて評価すべきである。
