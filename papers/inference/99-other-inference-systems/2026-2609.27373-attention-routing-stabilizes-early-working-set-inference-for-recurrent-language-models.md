# Attention Routing Stabilizes Early: Working-Set Inference for Recurrent Language Models

## 一覧用要約

再帰型言語モデルでは表現更新が続いていても注意機構の参照先が早期に安定することを利用し、WISEは初期段階だけ全域注意を行い、その後は発見済みのブロック単位作業集合へ注意計算を限定する。再学習なしで再帰深度を維持しつつ、4K文脈で注意計算を最大1.76倍、32段全体を1.36倍高速化する。

## 書誌情報

Ke Wan, Chen Chen, “Attention Routing Stabilizes Early: Working-Set Inference for Recurrent Language Models,” arXiv:2609.27373, 2026年9月23日投稿。主分類は計算と言語（Computation and Language; cs.CL）、副分類は機械学習（Machine Learning; cs.LG）。公開コードあり。

## 問題設定

再帰型言語モデルは同じネットワークブロックを複数回適用し、潜在表現を段階的に洗練する。この方式では追加の再帰段数を推論時計算量として投入できる一方、標準実装は各再帰段で文脈全体への自己注意を毎回計算する。線形射影や全結合層の計算が系列長 n に対して概ね線形に増えるのに対し、全域自己注意はクエリとキーの全組合せを扱うため n の二乗で増える。したがって長文脈では、後半の再帰段でも全域の参照先探索を繰り返すことが大きな無駄になる。

著者らの観測では、隠れ状態や注意出力そのものは後半まで変化し続ける一方、「どの位置を参照するか」を表す注意支持集合と注意分布はかなり早い段階で安定する。つまり、モデルは「情報をどう加工するか」をまだ更新している時点で、「どこを見るか」はほぼ決め終えている。この時間尺度の差を利用し、後半だけ参照範囲を狭められないか、というのが本論文の中心問題である。

## 手法

提案法WISE（Working-set Inference with Support Exploitation）は、再帰推論を「探索」と「再利用」の二段階に分ける。初期の再帰段では従来どおり文脈全体へ制限なしの注意を計算し、重要な参照位置を発見する。その後は発見済みの作業集合だけを注意計算の候補として残す。ただし、隠れ状態、クエリ、キー、値、および残した集合内部の注意重みは毎段再計算する。したがって注意重みそのものを固定する方式ではなく、「参照可能な場所」だけを固定する方式である。

GPUで不規則なトークン単位疎行列を効率良く扱うのは難しいため、WISEは系列をブロックへ分割する。既定設定ではブロック長32、再帰深度32、探索深度12、累積注意質量の閾値0.95を使う。各クエリブロックから各キーブロックへ流れる注意質量を集計し、95%の質量を覆う最小のキーブロック集合を求める。さらに探索終了直前の4段、すなわち9〜12段目で得た集合の和を作業集合とする。単一段の偶然の揺れで重要ブロックを落としにくくする保守的な設計である。

13段目以降は作業集合外のキーをマスクし、集合内部だけで注意を再計算する。作業集合の平均キー数を m、元の系列長を n とすると、後半の注意計算は O(n²d) から O(nmd) へ減る。重要なのは再帰段数を削らない点である。早期終了型のように後半の表現更新自体を捨てるのではなく、後半も32段まで計算しながら、既に安定した全域探索だけを省く。

## 評価条件

主評価には再帰深度32のHuginnを使用し、一般性確認として再帰化したLlama-3.2系モデル（Recurrent-Llama-T32）でも再現実験を行う。機構解析にはHotpotQAとGSM8K、行動評価にはHotpotQAと2WikiMultiHopQAを用いる。通常のベンチマーク比較は入力と再帰初期化を揃えた100例、収束機構の診断は固定30例で実施する。

品質はトークン単位F1、回答変化、教師強制時の正解損失などで評価し、効率面では作業集合のブロック密度、後続の全域注意質量をどれだけ保持するか、GPU上の注意カーネル実行時間を測る。WISEの設定はベンチマークや文脈長ごとに調整せず、ブロック長32、探索深度12、質量閾値0.95を固定している。

## 主要結果

機構解析では、注意支持集合や注意分布が隠れ状態・注意出力より早く安定するという分離がHuginnだけでなくRecurrent-Llama-T32でも確認された。これは、後半の表現洗練を維持したまま参照範囲だけを再利用する設計の根拠になる。

下流品質は2K文脈までは全域注意に概ね近い水準を維持する一方、4Kでは測定可能な品質低下が現れる。文脈が長くなるほど発見される作業集合の相対密度が下がるため、計算削減余地はむしろ増える。最適化した疎注意実装では4K文脈で標準FlashAttentionに対して注意計算を最大1.76倍高速化し、32再帰段の注意軌跡全体でも1.36倍の高速化を報告する。

## 限界

最大の境界条件は、探索段階で将来必要になる参照先を十分に発見できることに依存する点である。参照先の安定が遅い入力では、12段目で作業集合を固定すると後半で必要になる情報を除外し得る。4K文脈で品質低下が観測されることも、この速度と品質の交換条件が無視できないことを示す。

また、計算量上の削減がそのまま実時間高速化になるわけではなく、ブロック疎注意を効率良く実行できるGPUカーネルが必要である。評価対象は再帰型言語モデルに限定され、通常の層を一度ずつ通過するTransformerへそのまま適用できる方式ではない。既定の探索深度や質量閾値も、異なるモデル規模・タスク・文脈分布で最適とは限らない。

## 関連研究との差分

早期終了や計算深度適応は、入力に応じて後段の層・再帰段そのものを省く。WISEはこれと直交し、再帰深度を保ったまま注意の参照範囲だけを縮める。したがって後半の表現洗練が重要な再帰モデルでも利用できる。

KVキャッシュ圧縮や長文脈向け疎注意は、保持するキー・値やプリフィル時の注意計算を減らすことが主眼である。一方WISEは、同じ共有ブロックを反復する再帰モデル特有の「段をまたいだ参照先の安定」を利用する。また、注意重みを層・段間で丸ごと共有する方式と異なり、WISEは支持集合だけを再利用し、集合内部の注意重みを毎段更新するため、後半の表現変化をより多く残す。

## 実装状況

学習不要の推論時手法で、著者による公開コードが存在する。論文ではブロック疎注意用の最適化実装を用いて実測高速化を確認している。
