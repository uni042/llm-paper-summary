# Reformer: The Efficient Transformer

## 概要
Reformerは、長系列Transformerで支配的になる二つの資源問題を別々の機構で解く。第一は自己注意（self-attention）が系列長Lに対してL×Lのscore matrixを作るため、計算量・メモリ量がO(L²)になる問題である。Reformerは局所性鋭敏ハッシュ注意（Locality-Sensitive Hashing Attention; LSH Attention）により、queryと類似するkey候補だけをハッシュbucketから取り出し、注意計算を概ねO(L log L)へ下げる。第二はN層の学習で各層activationを逆伝播用に保存するため、深さNに比例してメモリが増える問題である。これは可逆残差層（reversible residual layer）で出力から入力activationを再構成し、層ごとの保存を不要にする。

さらに、フィードフォワードネットワーク（feed-forward network; FFN）を系列方向にchunk処理して大きな中間activationを一度に保持しない。この三つを組み合わせることで、論文はenwik8で64K token、imagenet64で約12K tokenを扱い、最大20層級Reformerを単一coreに載せる。LSHは近似なのでhash回数と品質・計算量に交換条件がある一方、reversible化とFFN chunkingはattention近似とは独立したmemory削減である。

## 問題設定
標準attentionではQK^Tが[batch, heads, L, L]となる。論文の例ではL=64Kなら、batch 1の64K×64K行列だけでも32-bit floatで16GBになり、1層のattention scoreだけでアクセラレータmemoryを使い切り得る。score matrixを完全materializeせずqueryごとに再計算するmemory-efficient baselineも作れるが、計算量自体はO(L²)のままで長系列ほど遅くなる。

もう一つの問題は、attention以外のactivation memoryである。Transformer学習では各層の入力をbackpropagationのため保持するため、b·L·d_model·Nのように層数Nへ比例する。FFNの中間幅d_ffは通常d_modelより大きく、b·L·d_ff·Nがさらに重い。したがってattentionだけ疎化しても、深いモデルでは層activationとFFN中間値がmemory bottleneckとして残る。

Reformerは「比較するtoken pairを減らす」「層activationを保存しない」「FFN中間activationを一括生成しない」を分離して設計するため、長さ方向と深さ方向の双方へ効く。

## 手法
### 共有query-keyとLSH Attention
LSHでqueryとkeyを同じ空間で比較できるよう、Reformerはqueryとkeyの射影を共有してQ=Kとする。keyは長さを正規化し、tokenが自分自身だけを強く選ぶ問題をmaskで避ける。論文のablationではshared-QK自体による品質劣化は観測されず、enwik8ではむしろわずかに速く学習する。

ハッシュは角度近傍を拾うrandom projection型である。random matrix Rにvectorを射影し、正負の投影 [xR; -xR] の最大成分からbucketを決める。近いvectorほど同じbucketになる確率が高いので、softmaxで大きなdot-productになりやすいkeyだけを候補化できる。

GPU/TPUで不均一bucketをそのまま処理するとbatchingしにくいため、tokenを「bucket番号→元position」の順にsortし、固定長chunkへ分割する。各chunkは同じchunkと一つ前のchunkを候補としてattentionを計算し、causal maskや異なるbucketをmaskする。これにより不規則なnearest-neighbor探索を、sort後の規則的なblock attentionへ変換する。sortがO(L log L)なので全体も概ねO(L log L)になる。

### 複数hash roundによるrecall回復
一回のLSHでは、本当に近いquery/keyがbucket境界の違いで分離されることがある。そのため独立なhashを複数回行い、各roundで得た候補attentionを正規化して統合する。hash回数n_roundsを増やすほどfull attentionに近づくが、同じtokenを複数roundで処理するため計算量も比例して増える。

synthetic duplication taskではfull-attention学習モデルをLSHへ置き換えて評価すると、LSH-1は52.5%、LSH-2は76.9%、LSH-4は92.5%、LSH-8は94.8%だった。一方LSH-4で学習したモデルは評価時LSH-4で99.9%、LSH-8で100%となり、近似を前提に学習することと評価時hash数を増やすことの双方がrecallを補える。

### 可逆残差層
通常のresidual layer y=x+F(x) は出力yだけからxを一意に復元できない。Reformerはactivationを二つ x1, x2 に分け、
y1 = x1 + F(x2)
y2 = x2 + G(y1)
と更新する。逆向きには
x2 = y2 - G(y1)
x1 = y1 - F(x2)
で入力を再構成できる。TransformerではFをattention、GをFFNに対応させる。

このためforward時に各層activationを保存せず、backward時に上位層出力から必要な入力を再構成・再計算できる。memoryから層数Nの係数を取り除く代わりに、backwardでF/Gを再実行する計算費用を払う。論文の学習曲線では同じparameter数の通常Transformerとreversible Transformerの品質差はほぼ見られない。

### FFNと出力lossのchunking
reversible層でN依存を消しても、FFNのd_ff次元中間activationは大きい。FFNはpositionごとに独立なので、系列をc個のchunkへ分け、一つずつFFNを計算してpeak activationを下げる。同じ考えで大語彙のlog-probability計算も系列chunkごとに行い、出力層の巨大tensorを一括保持しない。

このchunkingは数学的には通常FFNと同じ計算を分割するだけで、近似を入れない。したがって品質との交換条件があるLSHとは異なり、主な代償はkernel呼出しや逐次化などの実装overheadである。

## 評価条件
主な長系列評価はenwik8-64Kとimagenet64である。enwik8は2^16=64K tokenごとのsequence、imagenet64はpixel/channel系列として約12K長を扱う。ablation用3層モデルはd_model=1024、d_ff=4096、8 heads、total batch 8、Adafactorで学習し、通常Transformer、shared-QK、reversible、LSH hash回数を比較する。全実験は8 GPUまたは8 TPU v3 coreへ並列化した。

WMT14 English-Germanでは通常の文が128 tokenより短く、典型LSH chunk size 128の利点がないため、**LSHを使わず**reversible Transformerだけを評価する。これはLSHが常に有利という主張ではない。長系列側ではfull attention baselineをmemory-efficient実装で比較し、系列長を伸ばしたときのattention実時間も測定する。

large-model試験ではenwik8/imagenet64で最大20層級Reformerを学習する。通常Transformerはこの条件で遅すぎ、memory消費も大きいため同規模baselineを走らせられず、Reformer内部で層数を増やしたときの品質改善とfit可否を確認する。

## 主要結果
shared-QKとreversible residualのablationでは、enwik8・imagenet64のheld-out bits-per-dimension曲線が通常Transformerとほぼ重なり、memory削減のための構造変更自体は大きな品質損失を生まなかった。WMT14 En-Deでもreversible Transformer base 100K stepはBLEU 27.6、500K stepは28.0、big 300K stepは29.1で、原論文Transformer base 27.3 / big 28.4やOtt et al. big 29.3と同程度である。

LSHではhash roundを増やすほどimagenet64のfull attentionへ近づき、8 roundでほぼ同等の学習曲線になる。代わりにhash数に比例して計算量が増えるため、2/4/8/16 hashesは品質と速度の明示的な調整つまみである。評価時だけhash数を増やして精度を回復できることもsynthetic taskで示す。

速度実験では、total token数を一定にしてsequence lengthを伸ばすとfull attentionのseconds/stepは急増する一方、LSH attentionはほぼflatに推移する。これは短いsequenceではsort/hashの固定costがあるが、長くなるほどO(L²)回避の利点が支配的になることを示す。

大規模Reformerは最大20層までenwik8/imagenet64でmemoryに収まり、通常Transformer baselineは同条件で「too slow and memory-hungry」として実行できなかった。enwik8では12層、20K step、dropout 0.1で1.19 bits/dim、より長い学習と調整で12層モデルが1.05 bits/dimに到達する。論文の主張は単に理論複雑度を下げただけでなく、64K系列と深いモデルを実際に学習できる領域へ移した点にある。

## 既存研究との差
固定local windowや手作業のsparse patternでは、距離が遠いが内容的に類似するtokenを拾えない。Reformerはcontent similarityをLSHで近似し、系列上の距離ではなくrepresentation空間の近さから候補を作る。これはexact attentionのkernel最適化ではなく、attention graph自体を近似的に疎化する方式である。

またReformerのmemory削減はLSHだけではない。可逆層で深さ方向activationを消し、chunkingでFFN/出力層のpeakを抑えるため、attention score以外の主要memory源も同時に対象にする。この組合せが単なる「LSH Transformer」との違いである。

## 限界
LSH attentionは近似であり、hash collisionしない関連tokenは候補から落ちる。hash roundを増やせばfull attentionへ近づくが、その分sort・attention計算が増える。短系列ではこの固定overheadが相対的に大きく、論文自身もWMT14では典型sentenceが128 token未満なのでLSHを使っていない。

可逆残差層の主利得は**学習activation memory**である。逆伝播しない自己回帰推論では層activation保存問題が同じ形では存在しないため、現代LLMサービングのKV cache容量を直接削減する機構ではない。またactivation再構成にはbackward中の再計算が必要で、memory節約を無償で得るわけではない。

大規模20層試験では通常Transformerが実行不能で、同規模・同training budgetでの厳密な品質/速度比較はない。実験も2020年時点のGPU/TPUとattention実装を基準にしており、FlashAttentionのような現代的exact-attention kernelとの比較は論文範囲外である。従ってO(L log L)という漸近優位を、そのまま現在の短〜中contextにおけるwall-clock優位へ読み替えるべきではない。
