# Pruning Large Language Models via Accuracy Predictor

## 概要
構造枝刈りでは、全体の削減率が同じでも「どの層のAttentionやMLPをどの割合で削るか」によって品質が変わる。既存法では層ごとの枝刈り率を人手で固定することが多いが、大規模言語モデル（large language model; LLM）では候補構成を一つ実評価するだけでも高価なので、全組合せ探索は現実的でない。本研究はこの層別枝刈り率決定をニューラルアーキテクチャ探索（neural architecture search; NAS）として扱い、少数の「枝刈り構成→実測品質」対から軽量な精度予測器を学習して多数候補を順位付けする。

予測器には別のニューラルネットワークではなく、表形式データへ強い勾配ブースティング決定木（gradient boosting decision tree; GBDT）を使う。Llama-2-7Bで525個の構成・品質対だけを作り、学習したGBDTで10,000候補を予測し、上位18構成だけを実際に評価する。予測器の特徴重要度を使って探索範囲そのものも狭めるため、単に「全候補の代理精度を出す」だけでなく、次の探索でどの層へ枝刈り率自由度を与えるかも調整する。

## 問題設定
Llama-2-7Bには32個のDecoder layerがあり、本論文は主にlayer 3〜29のLlamaAttentionとLlamaMLPへ層別枝刈り率を割り当てる。候補率は初期探索で0.1〜0.5、刻み0.1で、隣接4層を同一率に束ねる候補400個と、束ねない候補125個、合計525構成を生成する。各構成を実際に枝刈りしてWikiText-2、PTB、MMLUで評価すれば学習データになるが、この実評価を数万候補へ繰り返すことがボトルネックである。

枝刈り対象パラメータの重要度自体は、損失変化の一次Taylor近似を使う。二次Hessianまで使えば情報量は増えるが、LLMでは追加メモリ・計算が大きいので、BookCorpusから10標本を使った逆伝播で一次勾配を得る。したがって本手法の新規性は個々の重み重要度ではなく、**同じ重要度規則の上で層別枝刈り率をどう配分するか**をGBDTで探索する点にある。

## 手法
### 構成・品質対の作成
各候補 (X_i) はAttention/MLP各層の枝刈り率を特徴量とする。枝刈り後モデルを三つの能力指標で評価し、WikiText-2のperplexity、PTBのperplexity、MMLU 5-shot平均accuracyを目的変数 (Y_i) とする。このため予測器は単一スカラー精度ではなく、生成モデリング品質と知識・問題解決能力を同時に予測する多出力回帰器になる。

525組を7:3で学習・検証へ分けてGBDTを訓練する。検証集合ではMSE 0.1743、RMSE 0.3861、MAE 0.2088、決定係数 (R^2=0.8040) を報告し、未観測構成の相対順位付けに利用できる精度を確認する。

### 特徴重要度で探索空間を再設計
GBDTの特徴重要度を品質指標ごとに調べると、Attention層はMLP層より重要度が高く、perplexityでは先頭・末尾寄りの層、MMLUでは中間層の重要度が高い。一方、layer 19〜25付近は測定した指標に対する重要度が低い。論文はこの情報を次の探索範囲へ反映する。

具体的には重要度の高いAttention範囲（layer 3〜6、11〜18、26〜29）の枝刈り率を0.1〜0.3へ狭め、重要度が低いAttention/MLP layer 19〜25は0.2〜0.7へ広げる。こうして全体枝刈り率を保ちつつ、品質に敏感な層へ強い枝刈りを割り当てにくくする。

### 10,000候補の代理評価
再設計した空間から10,000構成をランダム生成し、GBDTで三指標を予測する。全候補を実モデルで測らず、全体枝刈り率の異なる領域ごとに予測上位だけを残し、最終的に18構成を実評価する。出力は「枝刈り率の異なる層別構成」であり、同じglobal pruning ratioでも各層を均一率に削るbaselineとは異なる。

### QLoRAによる回復
枝刈り構成選択後、52,000命令標本を使う量子化低ランク適応（Quantized Low-Rank Adaptation; QLoRA）も追加実験する。単一GPU・2 epoch・約4時間で回復微調整し、表3では多くの構成でWikiText-2/PTB perplexityが大きく下がり、MMLU accuracyも回復する。ただしこれは「予測器だけで品質を維持できる」という主実験とは別の後処理であり、追加学習費用を伴う。

## 評価条件
| 観点 | 条件 |
|---|---|
| モデル | Llama-2-7B |
| 枝刈り対象 | Decoder layer 3〜29のLlamaAttention / LlamaMLP |
| 重要度 | BookCorpusから10標本、一次Taylor勾配 |
| 初期探索 | 枝刈り率0.1〜0.5、525構成 |
| 予測器 | 多出力GBDT、学習/検証=7:3 |
| 本探索 | 再設計空間から10,000候補を予測し、18構成を実評価 |
| 品質 | WikiText-2 zero-shot perplexity、PTB zero-shot perplexity、MMLU 5-shot平均accuracy |
| baseline | LLM-Prunerベースで各層の枝刈り率を同一にした構成 |
| 回復実験 | 52k命令標本、QLoRA、単一GPU、2 epoch、約4時間 |

## 主要結果
予測器の検証決定係数は (R^2=0.8040) で、10,000候補から選んだ上位構成の実測値も予測値と相関する。これは高価なLLM実評価を全候補へ行わず、数百の学習対と少数の最終評価へ置き換えられることを示す。

ほぼ同じ全体枝刈り率で比較すると、GBDT選択構成は均一層別率のbaselineに対しWikiText-2 perplexityを約9.48%、PTBを約5.76%低下させ、MMLU平均accuracyを約6.28%改善する。したがって利得は「より少なく枝刈りしたから」ではなく、同程度のglobal pruning ratioで削減量を層間へ再配分したことから得られる。

特徴重要度は指標ごとに異なる。perplexityでは先頭・末尾側が重要で、MMLUでは中間層の重要度が高い。単一の層重要度順位だけで全能力を代表できないことが、複数出力のaccuracy predictorを使う理由にもなっている。layer 19〜25の重要度が低いという観測について、論文自身は「今回評価していない能力を担っている可能性」を明記しており、低重要度を普遍的な冗長性と解釈してはいけない。

QLoRA回復表では、例えばglobal pruning ratio 25.50%の構成がWikiText-2 23.50→16.80、PTB 91.43→58.43、MMLU 0.0942→0.1917へ改善する。一方で構成によってMMLUの回復幅にはばらつきがあり、30.52%構成では0.0000→0.0109に留まる。強く能力を失った枝刈り構成を少量微調整だけで常に戻せるわけではない。

## 既存研究との差
SparseGPTやWandaの中心問題は、所定の疎性で「どの重みを落とすか」である。本研究はその一段上で、Attention/MLP層ごとに「何割落とすか」を探索する。一般的なニューラル精度予測器を使うNASと違い、LLMでは数万件の構成・品質対を作ること自体が高価なので、数百件でも扱いやすく解釈可能なGBDTを選び、特徴重要度を探索空間の再設計にも使う。

## 限界
実験はLlama-2-7B一系列だけで、MoE、より大規模なdenseモデル、異なる深さ・幅へ予測器を転用できるかは示していない。GBDTは525個の初期構成が覆う範囲で学習されるため、強い外挿では予測順位が崩れる可能性がある。実評価コストは10,000件から18件へ絞れるが、予測器を作る最初の525構成は実際に枝刈り・評価する必要があり、初期費用は小さくない。

特徴重要度はWikiText-2/PTB/MMLUという選んだ評価指標への寄与であり、コード、長文脈、安全性など未評価能力の重要度を保証しない。論文自身も低重要度層が未測定能力を担う可能性を挙げる。また構造枝刈り率の改善は品質結果であり、実際の壁時計高速化やGPUカーネル効率は測定していない。選ばれた疎構造が同じ割合で推論時間を短縮するとは限らない。
