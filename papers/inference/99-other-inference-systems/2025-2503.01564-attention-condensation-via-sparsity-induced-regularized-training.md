# Attention Condensation via Sparsity Induced Regularized Training

## 概要

本研究は、Transformerの注意行列を推論時に疎化する際の品質劣化を、**学習時に注意確率を少数の要素へ集中させておく**ことで抑える手法を提案する。推論時に重要な注意先を推定するアルゴリズムだけを工夫するのではなく、そもそも上位の注意先だけで十分な予測ができるモデルを学習する発想である。通常の言語モデリング損失に、注意確率の上位`k`要素がほぼ全確率質量を担うよう促す正則化項を加える。

12層GPT-2をOpenWebTextで学習した実験では、全学習後の通常モデルに上位65要素だけを残す理想的なマスクを適用すると、検証交差エントロピー損失は**2.8570から5.3025**へ悪化した。一方、通常モデルを短期間だけ正則化付きで追加学習したモデルは、全注意2.8620、上位65要素のみ2.8722で、疎化の追加損失は0.0102にとどまった。これは学習後の疎注意耐性を示す結果であり、生成速度が何倍になったかを測った結果ではない。

論文は理想的な上位kマスクに加え、実際に注意先を予測するHIP AttentionとHyper-Attentionも比較している。理想マスクでの精度維持と、低コストのマスク予測器が同じ結果を達成できるかは別問題であり、Hyper-Attentionでは正則化モデルの方が悪い条件も存在する。実用上の判断ではこの負の結果が重要になる。

## 問題設定

標準の自己注意では、系列長`n`の各問い合わせトークンが他の多数のトークンを参照し、注意スコアの計算と記憶が長文脈で負担となる。計算対象を少数の注意先へ絞れば演算量を減らせるが、もとのモデルが多くの注意先へ確率を分散していた場合、上位だけ残すと重要な情報が失われる。特に学習後のモデルへ突然疎なマスクを適用する方法は、注意行列の分布と出力の変化に対する耐性が十分でない。

この論文の中心的な問いは、推論時の近似方式を学習前から想定し、各問い合わせに対する注意の確率質量を`k`個程度へ集めておけば、予測品質を保ったまま疎化できるか、というものである。推論中に毎回注意先を正確に探索する方式と異なり、学習側で「疎化されやすい注意分布」を形成する。したがって新たな学習コストを必要とするが、学習済みモデルへ短い追加学習を適用する道も示す。

関連研究との関係では、BigBirdなどの固定的な疎パターンはどの注意先を残すかを構造的に決め、HIP AttentionやHyper-Attentionは入力に応じて重要な注意先を近似探索する。FlashAttentionは厳密な注意をGPU上で効率的に実行するものであり、注意先を削除すること自体は主眼ではない。本研究はこれらと競合する新しいカーネルを提案するのではなく、疎なマスクが適用されたときのモデル品質を学習によって改善する。

## 手法

### 出力と注意確率の関係

単一注意ヘッドの出力は、問い合わせ`Q`、鍵`K`、値`V`から`P=softmax(QK^T/√d)`を求め、`O=PV`と計算する。`d`はヘッド内の特徴次元である。各問い合わせ行の出力ベクトルは、値ベクトルを非負かつ総和1の注意重みで混ぜた凸結合となる。このため、注意重みが多くの要素に分散していると、単純に上位kだけ残したときの出力誤差が大きくなりやすい。

著者らはCarathéodoryの定理を動機として挙げる。この定理は`d`次元空間の凸包にある点を、最大`d+1`個の点の凸結合として表せることを述べる。ただしこれは**元のsoftmaxで重みが最大の`d+1`個を残すだけで必ず出力を厳密再現できる**という意味ではない。再構成に必要な点の選び方や重みが元の上位注意重みと一致する保証はない。論文はこの理論的着想を利用し、実装しやすい上位k注意確率へ学習時から質量を集中させるという別の操作を採用する。

実験でのGPT-2は埋め込み次元768、12ヘッドなので1ヘッドの次元は64であり、`k=d+1=65`を基本値とする。これは系列長が128から1024まで変わっても保持する注意先の数を65にする設定である。`k`を64や128に変えるマスク予測器の実験も別途行われているため、全実験を65固定と解釈してはいけない。

### 上位k質量を集中させる正則化

各問い合わせ行の注意確率のうち、スコア上位k要素だけを1、その他を0とするマスク`M`を考える。`P`と`M`の要素積を`P̃=M⊙P`とし、残った確率質量の和が1に近づくように損失を設計する。原著の式(2)は概念的に、各行について`−log(Σ_j P̃_ij)`を合計する形であり、上位kに入らない注意確率へ質量が流れると損失が増える。言語モデル本来の交差エントロピー損失にこの項を加え、予測能力と注意の集中を同時に学習する。

この正則化は、推論時に使用する正確な疎注意カーネルの内部実装に依存せず、学習時に注意分布を変える点に特徴がある。学習後、理想的な上位kマスクで注意を切り落としても、ほとんどの確率質量が残るように誘導する。単に注意行列の非ゼロ要素を減らすだけではなく、予測損失が大きく悪化しないよう元の学習目的を同時に保つ。

注意確率を上位kに集中させるだけでは、どのk要素を推論時に計算せずに見つけるかという探索問題は残る。理想的な上位kを知るには通常、全注意スコアを求める必要がある。そこで論文は、理想マスクで得られる品質の上限に近い結果が、実際の近似探索器でも得られるかを別の評価で調べている。

### 早期・後期の正則化適用

Early condensationはモデルの事前学習時から正則化を加える方法である。実験では通常のGPT-2と正則化付きGPT-2をそれぞれ30,000反復学習し、まだ十分に収束していない段階での注意分布と品質を比較した。正則化付きモデルは、学習の初期から疎な注意に適した分布を獲得することを狙う。

Late condensationは、すでに通常の損失で十分学習したGPT-2へ正則化付き追加学習を行う方法である。著者らは通常の全学習600,000反復に対して、追加学習6,000〜12,000反復、すなわち元の学習反復の約1〜2%を試した。元の学習が16 GPUで約4日、追加学習が数時間という記述は、特定のGPT-2学習条件に対するものであり、任意のモデルで同じ追加費用になるという保証ではない。

事前学習済みモデルを再びゼロから学習し直さずに疎化耐性を与えられる点は、後期適用の実務上の利点である。ただし元モデルの全注意での品質を完全に保持するとは限らず、正則化が強過ぎれば学習目標との競合が生じ得る。実際の表1では、通常の全学習モデルの全注意損失2.8570に対し、追加学習後の全注意損失は2.8620とわずかに悪化している。

### 実行時のマスク予測と構造化疎性

論文は、推論時のマスク予測としてHIP AttentionとHyper-Attentionを比較する。HIP Attentionは階層的な探索により重要な注意位置を探す方式であり、マスクに残す要素数`mask-k`を変えて評価する。Hyper-Attentionは局所性鋭敏型ハッシュやブロック近似、標本化を利用し、`block-size`、`sample-size`、ハッシュ射影数などの設定に結果が依存する。いずれも、全注意を正確に計算してから上位kを選ぶ理想マスクとは異なる。

さらに著者らは、任意位置に散在する疎な注意はGPU上で不規則なメモリアクセスを生みやすいと指摘し、ブロック単位の疎性を促す正則化版にも言及する。ただし公開原著の中心的な数値表は主として注意品質・マスク近似品質を示しており、ブロック疎カーネルのエンドツーエンド実測速度が体系的に報告されたと解釈してはいけない。規則的な疎性の必要性はシステム実装上の重要な制約である。

## 評価

### 実験設定と指標

| ヘッド次元・基本マスク | 64、理想上位k=65 |
| データ | OpenWebText、学習約90億トークン、検証約400万トークン |

| 早期正則化 | 30,000反復の通常学習・正則化学習を比較 |
| 後期正則化 | 通常学習600,000反復後、6,000〜12,000反復追加 |
| 学習 | ウォームアップとコサイン学習率、最大学習率`5×10^-3` |
| 主要品質指標 | 検証交差エントロピー損失（CE、低いほど良い） |
| 疎性指標 | 各注意行の上位65要素が占める確率質量（top-k energy） |
| 実行時近似器 | oracle top-k、HIP Attention、Hyper-Attention |

### 理想マスクの主要結果

| 学習条件 | 全注意CE | oracle top-65 CE | 疎化によるCE増分 |
|---|---:|---:|---:|
| 通常・部分学習（30,000反復） | 2.9971 | 5.2185 | +2.2214 |
| 正則化・部分学習（30,000反復） | 2.9473 | 2.9485 | +0.0012 |
| 通常・全学習（600,000反復） | 2.8570 | 5.3025 | +2.4455 |
| 正則化・追加学習後 | 2.8620 | 2.8722 | +0.0102 |

この表は原著表1に対応する。通常モデルの注意は、上位65以外の多数の位置にも質量を持っているため、突然65要素へ切り詰めるとCEが大幅に悪化する。正則化モデルは同じ理想マスクでもCE増分が小さく、学習側で疎化に耐える分布を作ったという主張を直接支持する。ただし理想マスクの作成費用を含まないため、推論速度の改善倍率を意味しない。

系列長依存も重要である。原著表3の通常全学習モデルでは、系列長128で全注意3.1921・理想マスク3.2402だが、1024では2.8570・5.3024と大きく乖離する。一方、正則化追加学習モデルは128で3.1958・3.1951、1024で2.8620・2.8722と近い。長文脈ほど、通常モデルの上位65要素だけでは情報が不足する傾向が明瞭になる。

### 層別の注意集中

原著表4と表5は各層のtop-65確率質量の平均と標準偏差を報告する。部分学習モデルの第0層では、通常モデルが平均0.495・標準偏差0.250に対し、正則化モデルは0.999・0.002である。全学習モデルの第0層でも、通常モデル0.558・0.238に対し、後期正則化モデル0.985・0.024となる。第0層を含め、正則化により注意質量が少数の位置へ集まることが確認できる。

この結果は、通常モデルでは浅い層ほど注意が広く分散するため最初の数層を密なまま残す必要がある、という経験則に対して、学習時の正則化で浅い層も疎化に適した分布へ変えられる可能性を示す。ただし表のtop-k energyは**確率質量の集中度**であり、実装したGPUカーネルがどれだけメモリ帯域や時間を削減したかを示す測定ではない。

### 現実的なマスク予測器の負の結果

原著表6ではHyper-Attentionを使い、`lsh-num-projs=7`、`min-seq-len=128`の条件で、ブロックサイズと標本数を変えた検証CEを報告する。例えば`block-size=32`、`sample-size=128`では通常部分学習モデル3.3546に対し正則化部分学習モデル3.7314と悪い。`block-size=128`、`sample-size=256`でも通常3.2734、正則化3.3893である。著者らはHyper-Attentionが重要なtop-k位置を十分に予測できないと解釈している。

この負の結果は、学習後の注意が疎であっても、探索器が正しい位置を外すと品質を保てないことを示す。正則化によって理想マスクへの耐性が向上しても、近似マスクの検索誤差に対する頑健性まで保証されるわけではない。実際のシステムでは、正則化手法とマスク探索器を一体で評価する必要がある。

HIP Attentionの表7では`dense-q=0`の設定で、`mask-k=64`の通常部分学習モデルCE4.0627に対し正則化部分学習モデル3.0004、`mask-k=128`では通常3.6532に対し正則化2.9738だった。HIPの探索はこの条件で正則化モデルの利点をよりよく利用できている。ただし著者らが用いたのはHIP Attention version 0であり、新しい実装の最適化を完全には試験していないと明記されている。

### 実測高速化について言える範囲

この論文の主要表は交差エントロピーと注意確率の集中度であり、実機GPUでの疎注意カーネル単体の時間、モデル全体のトークン毎秒、TTFT、TPOT、同時実行数、VRAMピーク使用量を同一条件で定量比較したものではない。従って、上位65要素だけ残すことから理論的な演算対象数の削減可能性は議論できても、実測で`n/65`倍速くなるとは言えない。注意先を探す計算と不規則メモリアクセスの費用が残るためである。

また、公開原著での検証はGPT-2規模のOpenWebTextであり、LlamaやQwenなどの現代的な大規模デコーダモデルで同じ正則化がどの程度働くか、長文脈生成での精度・速度・品質の交換条件がどうなるかは未評価である。著者ら自身も他のモデル構造への拡張を今後の課題と位置付けている。

## 既存研究との差

FlashAttentionは密な注意を数学的に変えずにGPUのメモリ階層を使って高速化する。HIP AttentionとHyper-Attentionは推論時にどの注意先を選ぶかを近似探索する。これらに対し本研究は、学習損失へ上位k質量の集中を促す項を加え、モデル自身の注意分布を疎化に適したものへ変える。理想マスクだけでなく実際の探索器との組合せを比較した点が、単なる注意重みの疎性観察とは異なる。

また、Carathéodoryの定理を用いる説明は、注意出力が値ベクトルの凸結合であることを手掛かりにするが、著者らの正則化は値ベクトルを直接最適化するのではなく、上位k注意確率の和を大きくする。理論的な表現可能性と、元の注意分布の上位kだけで実用的な近似が成立することを同一視しない。モデルを疎注意に適応させる追加学習と、実行時に効率的な疎マスクを選ぶことの二段階が必要である。

## 限界と実装上の示唆

最も強い結論は「通常のGPT-2では上位65マスクで大きくCEが悪化するが、正則化したGPT-2では理想マスクでのCE悪化をほぼ抑えられる」である。実際の疎注意予測器を使うとHyper-Attentionのように不利な設定があり、性能の一貫性はマスク探索精度に依存する。ブロック単位の疎性を考慮しないと、GPUではランダムアクセスによる効率低下が生じ得る。

学習費用も無視できない。後期正則化は通常学習に比べ約1〜2%の追加反復で済む実験設定だが、既存の大規模モデルにそのまま適用できるとは限らない。疎化したモデルの検証損失が小さくても、下流タスク、推論サービングの実測速度、長文生成の安定性、異なる注意実装との相互作用は別途確認が必要である。コード公開については著者の公式実装URLを確認できなかったため、既存実装を推測で公式扱いしない。
