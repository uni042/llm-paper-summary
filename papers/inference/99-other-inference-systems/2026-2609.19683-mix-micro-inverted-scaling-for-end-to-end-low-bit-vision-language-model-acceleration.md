# MiX: Micro-Inverted-Scaling for End-to-End Low-Bit Vision-Language Model Acceleration

> VLMのマルチモーダル外れ値に対し、要素別指数＋共有仮数へマイクロスケーリングを反転し、4bit級の端から端までの量子化と乗算器不要のシフト加算PEを同時に実現する。

## 概要
MiXは、視覚言語モデル（VLM）の視覚トークンとテキストトークンの大きな動的範囲差により、通常のマイクロスケーリングで共有指数が外れ値に支配され周辺値が消える問題を扱う。複数仮数で指数を共有する従来方式を反転し、要素ごとの指数差を持たせつつ小グループで仮数を共有するMicro-Inverted-Scalingを提案する。重み側のMX形式と組み合わせることで共有仮数をブロック内積の外へ因数分解し、処理要素（PE）の乗算器をシフタと整数加算木へ置換する。Qwen2-VL、LLaVA-OneVision、MiniCPM-V等の端から端までの量子化評価とTSMC 28nm合成では、4.5-bit級でNVFP4相当以上の精度を保ちつつ、NVFP4比でPE面積効率25%向上、Focus比で最大4.5倍高速化・2.9倍省エネルギーを報告する。

MiXは通常の『共有指数＋要素別仮数』を逆転し、『共有仮数＋要素別の相対指数』とする。MiX-4.25bは32要素で4bit最大指数と3bit共有仮数、各要素に符号1bit＋相対指数3bitを持つ。MiX-4.5bでは共有仮数を細分化して精度を上げる。活性をMiX、重みをMXINT/MXFPで表す二形式構成により、MiX共有仮数をブロック内積の外へ因数分解できるため、各要素の積を汎用乗算器で計算せず、符号処理・右シフト・整数加算木・最後の小さな共有スカラー処理へ変換できる。

代表結果として、VLM平均精度はMiX-INT4g16、4.5-bit級、6 VLMベンチマークでNVFP4に対してQwen2-VL 69.3%、MiniCPM-V 61.9%、LLaVA-OneVisionでNVFP4比+0.6pt。共有指数を要素別指数へ反転しても低ビット精度を維持し、VLMではNVFP4と同等以上になる。
## 問題設定
VLMの端末推論では、巨大な重みだけでなく高解像度画像が生む大量の視覚トークンとKVキャッシュがメモリ帯域・容量を圧迫するため、重みだけを4bit化するW4A16では十分でない。一方、視覚特徴はテキスト特徴より動的範囲が極端に広く、Qwen2-VLの例では平均絶対値に約34倍の差がある。通常のMX形式はブロック内で指数を共有するので、一つの視覚外れ値が共有指数を押し上げると小さなテキスト値がアンダーフローし、注意行列を壊す。NVFP4などは多段スケールで精度を補うが、複雑なスケール処理や乗算器がエッジ向けPEの面積・電力を増やす。
## 新規性
MiXは通常の『共有指数＋要素別仮数』を逆転し、『共有仮数＋要素別の相対指数』とする。MiX-4.25bは32要素で4bit最大指数と3bit共有仮数、各要素に符号1bit＋相対指数3bitを持つ。MiX-4.5bでは共有仮数を細分化して精度を上げる。活性をMiX、重みをMXINT/MXFPで表す二形式構成により、MiX共有仮数をブロック内積の外へ因数分解できるため、各要素の積を汎用乗算器で計算せず、符号処理・右シフト・整数加算木・最後の小さな共有スカラー処理へ変換できる。
## 手法
### 手法のあらまし
端から端までの処理は、VLMの視覚エンコーダ、プロジェクタ、LLMバックボーンを較正し、重みブロックをMX、活性ブロックをMiXへ量子化するところから始まる。MiXではブロック最大指数Emaxを基準に各活性の指数差Δeを3bitで保持し、仮数だけを小グループで共有する。この表現により、大きな視覚外れ値と小さな言語特徴を同じ低ビットブロックへ残せる。

注意計算ではQ/K/Vの外れ値方向が異なる実測に合わせて量子化方向を選ぶ。特にKeyはチャネル平均を引いて外れ値範囲を縮めるが、平均はプリフィル時に一度だけ計算してデコード中は固定する。これにより、毎ステップ過去Key全体を読み直して再量子化する処理を避けながら、動的平均とほぼ同じ精度を維持する。

推論時にはMX重みの符号・整数仮数とMiX活性の符号・ΔeをPEへ供給する。各重み整数をΔeだけ右シフトし、32要素を整数加算木で一つの部分和へ集約する。その部分和へMiXの共有仮数をブロック単位で適用し、EmaxとMX共有指数からFP指数を構成してFP32累積器へ加える。

したがって、入力の低ビット量子化、注意外れ値の中心化、低ビットメモリ転送、シフト加算内積、FP32累積、次層への出力という全推論経路が一続きになる。要素単位の高精度乗算を除去する計算側の利得と、重み・活性・KVを4bit級で保持するメモリ側の利得を同じMiX-MX表現で同時に得ることが、この方式の端から端までの機構である。

### MiX数値形式
32要素ブロックの最大指数を基準に、各要素へ符号と3bit相対指数差を与え、仮数はブロックまたは小グループで共有する。相対指数が要素ごとに残るため、一つの巨大外れ値が存在しても他要素が同じ共有指数へ押し込まれてゼロ化するMXの崩壊を避ける。

4.25bit型では共有フィールドを含め平均4.25bit/要素に収める。4.5bit型では共有仮数をさらに小さなグループへ分けて表現精度を上げる。ビット予算を要素別の指数差へ優先配分することで、視覚とテキストが混在する広い動的範囲を低ビットのまま保持する。

### MiX-MX二形式量子化
活性は外れ値耐性を優先してMiX、重みはMXINT4またはMXFP4系で表す。活性側ではブロック最大指数と要素別指数差、重み側では共有指数と低ビット仮数を保持するため、両者を掛け合わせたときの指数処理と仮数処理を分離できる。これは二形式を単に保存容量削減のために併用するのではなく、内積式そのものをハードウェア向けに変形するための役割分担である。

具体的にはMiX側の共有仮数を32要素の積和の外側へ因数分解し、MX側の共有指数はブロック出力の指数構成へ回す。各要素で残る処理は符号と相対指数に応じた整数シフトになるため、浮動小数点乗算器を32本並べる必要がない。MXFP重みの場合も要素指数をシフト量へ合成し、同じシフト加算構造へ寄せる。

この構成を線形層だけに限定せず、Q/K/VとKVキャッシュを含むVLM全体へ適用する。視覚エンコーダ、プロジェクタ、LLMバックボーンを同じ低ビット系統で処理することで、従来のVLM量子化のように一部をFP16へ残してメモリ帯域削減効果を失うことを避ける。

結果として、NVFP4のFP8ブロックスケールとFP32テンソルスケールの階層や、AMXFP4の複数FP8スケールをPE内で処理する構成より単純なデータパスになる。MiX-INT4g16はNVFP4と同等級の有効ビット幅でVLM精度を保ちながら、PE面積効率と電力効率を同時に高めるため、数値形式と演算器設計が一体化した機構になっている。

### 静的K平均
Key行列はチャネル方向の強い外れ値を持つため、各チャネルの平均を引いて量子化範囲を狭める。動的に平均を更新すると、デコードで新しいKeyが加わるたびに過去系列の平均が変わり、全Keyキャッシュの再読込と再量子化が必要になる。

そこでプリフィル時のNトークンからチャネル平均を一度だけ計算し、以後のデコードではその値を固定する。表IIIではQwen2-VLとMiniCPM-Vの複数4bit形式で動的平均との差が1ポイント未満に収まり、精度崩壊なしにデコード中の全系列再処理を取り除ける。

### シフト加算PE
各要素ではMX重み整数を活性符号に応じて反転し、MiXの3bit相対指数をシフト量としてバレルシフタで右シフトする。32本の結果を整数加算木で一つの部分和へまとめるため、要素ごとの汎用乗算器は不要になる。

集約後に共有MiX仮数だけを部分和へ一度適用し、EmaxとMX共有指数を加えて一時FP値の指数を作る。内部19bit仮数を保持してFP32累積器へ加算することで精度を確保する。乗算器中心のPEからシフタ・加算木中心へ置き換わることが、同じ低ビット級のNVFP4より面積・電力効率を高める直接要因である。

### 全体のデータ／制御の流れ
アクセラレータはMiX/MX量子化器、K平滑化器、MiX対応シストリック配列、オンチップSRAMと外部DRAMを組み合わせる。量子化済み重みと活性を低ビットのままメモリ階層から配列へ供給し、PEでシフト加算内積を処理する。

等面積比較では各形式の合成PE面積に応じて同じチップ面積へ置けるPE数を変え、各層についてそのPE数での計算サイクルと外部DRAM転送サイクルの大きい方を実遅延とする。視覚エンコーダやプリフィルのような計算律速区間では小型PEを多数置けるMiXが大きく高速化する一方、長いデコードでは重み再読込が支配して全4bit形式がDRAM帯域限界へ近づく。このモデルにより、演算器の面積削減が効く領域とメモリ圧縮が支配する領域を分けて端から端まで評価する。
## 評価条件
- **ハードウェア**: MiX、MXINT4/MXFP4、NVFP4等のPEをTSMC 28nm CMOSで実装・合成し、面積と電力を比較する。Artifact AppendixではSynopsys Design CompilerとVCS、28nm標準セルライブラリを用いる15種類のシストリック配列、量子化器、K-smootherのRTL評価を説明する。精度評価は14BまでRTX A6000 48GB、32B/72BではB200 180GBを想定する。
- **ソフトウェア**: Python 3.10、PyTorch 2.3.0/CUDA 12.1、Transformers 4.57.6等で量子化と精度評価を行う。ハードウェア側はSystemVerilog RTL、Design Compiler、VCS、SAIF電力評価を使用し、解析モデルはNumPy/Matplotlibで合成面積・電力とワークロードを結合する。
Qwen2-VL、LLaVA-OneVision、MiniCPM-Vを中心にChartQA、TextVQA、VizWiz、OCRBench、MMMU、SEED-Bench-2+の6ベンチマークを評価し、FP16、INT8、MXINT4、MXFP4、NVFP4、MXFP4+、AMXFP4、Focus等と比較する。Qwen2.5-VL 3B/7B/32B/72Bで規模一般化、Llama-3.1-8B、Mistral-7B、Qwen2.5-7B/14Bでテキスト専用一般化も検証する。VLM較正はCOCO由来128画像、LLM較正はPile 2,048区間。速度は等面積条件でPE数を面積比に合わせ、計算サイクルとDRAMサイクルの大きい方を層遅延とする。
速度・エネルギーの主要値は実チップ実測ではなく、28nm RTL合成と解析モデルを組み合わせた評価である。長いデコードはDRAM帯域律速となり、PE面積削減による速度差が小さくなる。MiXはVLMの大きな動的範囲へ最適化され、テキスト専用LLMではNVFP4に劣るタスクがある。32B/72Bの再現にはB200級GPUと大容量システムRAMが必要で、ハードウェア再現には商用Synopsys環境と28nmライブラリが必要である。
## 主要結果
4.5-bit級のMiX-INT4g16はVLM精度でNVFP4と同等以上を維持しながら、より単純なシフト中心PEを実現する。Qwen2-VLでは平均69.3%対NVFP4 69.7%とほぼ同等、MiniCPM-Vでは1.9ポイント、LLaVA-OneVisionでは0.6ポイント上回る。PEでは同等4.5bit級NVFP4より面積効率25%、電力効率15%向上する。等面積の端から端までの評価ではMiXはFocusに対してモデル・ベンチマークにより2.3〜4.5倍高速化、1.4〜2.9倍省エネルギーを示す。

- VLM平均精度 / Qwen2-VL 69.3%、MiniCPM-V 61.9%、LLaVA-OneVisionでNVFP4比+0.6pt (比較対象: NVFP4; 条件: MiX-INT4g16、4.5-bit級、6 VLMベンチマーク) — 共有指数を要素別指数へ反転しても低ビット精度を維持し、VLMではNVFP4と同等以上になる。

- PE効率 / NVFP4比で面積効率+25%、電力効率+15% (比較対象: NVFP4 PE; 条件: TSMC 28nm、同じ4.5-bit有効ビット幅級) — 要素積の乗算器をシフト加算へ置換した代数的単純化がPPAへ直接反映される。

- 等面積速度 / MiX-INT4g16平均9.77倍/8.09倍、MiX-INT4 11.29倍/8.72倍対FP16 (比較対象: FP16; 条件: LLaVA-OneVision-7B / MiniCPM-V-2.6、6ベンチマーク) — 短い生成では小型PEを多く配置できる利得が大きい。

- 端から端までのエネルギー / MiX-INT4でFP16比約0.152倍/0.178倍 (比較対象: FP16; 条件: LLaVA-OneVision / MiniCPM-V) — 4bit級圧縮によるDRAMエネルギー削減と乗算器除去によるコア削減が重なる。

- モデル規模一般化 / FP16との差 8.0→4.1→2.4→2.3pt (比較対象: FP16; 条件: Qwen2.5-VL 3B/7B/32B/72B、MiX-INT4g16) — モデル規模が大きいほど量子化精度差が縮まり、7B以上ではNVFP4を0.2〜2.4pt上回る。

- 静的K平均 / 動的平均との差1pt未満 (比較対象: 全系列を毎回再計算する動的K平均; 条件: Qwen2-VL / MiniCPM-V、複数4bit形式) — デコード中のKey再読込・再量子化を避けても精度崩壊しない。

### 負の結果・境界条件
- MiXの利得は万能ではない。テキスト専用LLMではNVFP4より弱く、Mistral/Qwen2.5の推論タスクで1.3〜1.7ポイント程度平均的に劣り、ARC-Challengeでは3〜4ポイント差が出る一方、WinoGrandeでは逆に有利になる。長いMMMU生成では全4bit形式がDRAM帯域律速となり、PE面積差による速度向上は約3.8倍のメモリ上限へ収束する。また主要な速度・エネルギーは実シリコン測定ではなく合成＋解析モデルであり、標準セルライブラリにより絶対値は変わる。

### 結果の読み方
MiXの本質は、VLMで支配的な外れ値耐性とハードウェア単純化を同じ表現変更で同時に得ることにある。従来MXは外れ値対策を追加スケールや高精度化で補うためPEが複雑化するが、MiXは指数を各要素へ移して共有仮数を因数分解可能にする。このため精度改善がPEコスト増ではなく、むしろ乗算器削減と両立する。
## 品質への影響
VLMではNVFP4と同等以上の精度を保つが、FP16との差は残り、特に小型モデルで大きい。モデル規模増加に伴い差は縮む。テキスト専用では精度依存性が強いため、MiXを一般LLM量子化の無条件な置換とみなすべきではない。
## 既存研究との差
MXFP4やMXINT4がブロック共有指数を使うのに対し、MiXは共有仮数と要素別指数差へ役割を反転する。NVFP4はFP8ブロックスケールとFP32テンソルスケールの階層を使うが、MiXはより単純なシフト中心データパスを狙う。MXFP4+やAMXFP4は外れ値精度を改善する代わりに拡張仮数や複数FP8スケールでPEを大きくする。MicroScopiQは外れ値へ高精度を割り当て、別要素のビットを回収するため不規則な多精度処理を必要とする。Focusは視覚トークン削減で計算を減らすが重みビット幅とFP16演算器は残るため、MiXとは直交的である。
## 限界
第一に、速度・エネルギーの主要評価はTSMC 28nm向けRTL合成と解析モデルであり、製造チップ上の測定ではない。長いデコードではDRAM帯域が支配し、MiXの小型PEを増やしても速度は約3.8倍の4bitメモリ転送上限へ収束する。第二に、VLM向けの動的範囲耐性を重視した表現なので、テキスト専用LLMではNVFP4に劣るタスクがあり、精度重視の用途へ一律適用できない。第三に、32B/72B精度再現にはB200 180GBや最大約500GBのシステムRAM、RTL再現には商用Synopsys環境と28nm標準セルライブラリが必要で、完全再現の設備要件が高い。
## 実装状態
Artifact Appendixは、精度評価コード、各ベンチマークのYAML設定、SystemVerilog RTL、15種類のシストリック配列テストベンチ、Design Compiler/SAIFスクリプト、面積・電力解析モデルまでを含む再現パッケージを説明する。各RTLテストベンチはブロック内積の正しさをPASSで検証し、解析モデルは精度JSONと合成CSVから速度・エネルギー図を再生成する。ただし今回確認したarXiv本文には公開リポジトリURLが明示されていないため、コード公開先は未確認とする。
## 研究上の位置づけ
低ビット推論研究の中でも、量子化アルゴリズムだけでなく数値形式とPEマイクロアーキテクチャを同時設計する系統に位置する。特にVLMではKVキャッシュと活性も含めた端から端までの低ビット化が必要であり、重みのみ圧縮するLLM向け方式よりメモリ帯域削減への直接性が高い。階層メモリ・オンデバイス推論の観点では、4bit級への圧縮でDRAMトラフィックを減らすためCPU/SSDオフロードの必要帯域も下げ得る一方、長文デコードでは依然DRAM帯域律速が残るという結果が、計算圧縮とメモリ階層最適化を併用すべき境界を示す。
