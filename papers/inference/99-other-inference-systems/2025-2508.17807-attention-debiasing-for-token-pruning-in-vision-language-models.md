# Attention Debiasing：視覚トークン剪定の位置偏りとpadding sinkを分離して補正する

## 概要

Vision–Language Model（VLM）では、画像エンコーダが出力する数百〜数千の視覚トークンを言語モデルへ渡す。多くの視覚トークンが冗長なので、言語モデルの初期層で重要度の低いトークンを捨てれば、以後のattentionやKV保持の負荷を下げられる。FastVをはじめとする剪定法は、言語トークンが各視覚トークンへ向けるattentionを重要度の代理として用いる。しかしこのスコアは**内容だけを表すわけではない**。後ろに現れるトークンほど高く評価されるrecency biasと、意味のない画像paddingが過大attentionを集めるattention sinkが混入する。

本研究は、attentionを使う剪定法の構造やモデル重みを変更せず、**ランキング前のスコアを補正**する。第一のPositional Debiasing（PD）は、位置に応じて増える平均attentionを指数曲線で推定し、その値で個別attentionを割る。第二のPadding Attention Suppression（PAS）は、画像の余白を埋めるpaddingに対応する視覚トークンのスコアをゼロにする。両方を適用したスコアで上位トークンを残す。実装は軽量で再学習不要とされる。

原著v2のTable IIでは、LLaVA-v1.5-7BのFastVに追加すると10ベンチマークの論文定義平均が**59.6→62.5**、HiMAPは**59.0→61.4**となる。13Bでも6種類の既存法すべてで平均値が上昇する。一方、個別課題では性能が低下する条件があり、動画では改善が小さい。論文は一定トークン予算下の**品質改善**を主に検証しており、同一環境のTTFT、TPOT、tokens/sを比較するエンドツーエンド速度表は提示していない。

**版の注意**：arXiv:2508.17807のv1は旧題「PoRe: Position-Reweighted Visual Token Pruning for Vision Language Models」で、位置補正を中心とした暫定結果だった。2026-01-16付v2は「Attention Debiasing for Token Pruning in Vision–Language Models」へ改題され、padding sink対策、画像・動画の拡張評価、著者一覧も更新されている。本稿は**v2の本文・表**を基準とし、v1の表と混ぜない。

## 問題設定

### 視覚トークンを「高attentionなら重要」とみなす危うさ

視覚トークンの剪定では、最終の言語トークンや選択された言語トークンから画像パッチへのattention weightを集約し、高スコアの画像位置を残すことが多い。これは指示文に関連する物体や文字が高く評価されるという期待に基づく。しかしautoregressiveな言語モデルは、学習された順序効果によって後方のトークンを過大評価しうる。画像がラスタ順に並ぶ場合、系列後半は画像下側に対応し、意味的に不要でも下部のパッチが残りやすい。

同じ画像内容でも、視覚トークンの配置順やアスペクト比が変われば、attention由来のランキングが変わる。下部が常に重要とは限らないので、recency biasは上位K個の枠を無駄に使い、質問に必要な領域を削除する原因となる。重要度スコアの順位が間違えば、剪定後の層で失った情報を通常は回復できない。

### paddingのattention sink

画像を一定の入力形状へ合わせるために追加するpadding領域は、意味的な情報を持たない。にもかかわらず、LLaVA-v1.5ではpaddingに対応する視覚トークンの隠れ状態の一部が極端に大きくなり、attention weightも高くなる現象が観測される。これはBOSなどに生じるattention sinkに似ている。画像の下端や左右の余白が高いattentionを持つと、重要な物体や文字よりも余白が保持される。単に画像のpadding値を別の値に変えるだけでは、必ずしもこの現象を除けない。

本研究の問題設定は、**剪定アルゴリズムが同じK個を残すなら、意味のあるK個を選べるようにする**ことである。新たな視覚トークン圧縮率を提案することではない。元の剪定法と同じ保持予算を使うので、主要な比較は品質の差になる。

## 手法

### 1. 入力と出力：attention scoreから選択集合まで

入力は、既存の剪定法が生成する視覚トークンごとの非負attention score `a_i`、視覚トークン総数`L`、画像paddingの位置情報、そして位置依存の補正曲線である。出力は、位置・paddingの偏りを除去したスコア`a_hat_i`であり、元の剪定法はそのスコアに従って上位K個を選ぶ。画像エンコーダ、言語モデル、attentionの本体、学習済みパラメータを更新する必要はない。

この点が重要で、提案法は**スコアリングの後処理**である。FastVの単一層剪定、PyramidDropの複数層剪定、SparseVLMの言語トークン選択、HiMAPの階層的剪定など、既存の異なるランキング計算をそのまま残し、得られた視覚トークン重要度を補正する。スコアの入力元は各方式で異なるため、完全に同じattentionを使うわけではない。

### 2. 位置偏りの分解

著者らは観測attention `a_i`を、位置だけで決まる偏り`b_i`と、画像内容に依存する理想的な重要度`a_hat_i`の積としてモデル化する。`a_i = b_i * a_hat_i`である。ここで`i`は視覚トークンの系列位置を表す。位置偏りは個々の画像に固有ではないと仮定し、多数の画像にわたる位置別attentionの平均を推定する。

単純な補正なら、位置iの平均attentionで当該サンプルのattentionを割ればよい。しかし実際の平均曲線はサンプル数やパッチ数の影響を受けてノイズがあり、異なる視覚トークン長へそのまま移植しづらい。著者らは平均曲線の直接利用を採用せず、**滑らかな指数関数**で位置トレンドを近似する。元のattention scoreをその関数で割ると、位置だけで大きくなっていたスコアを抑えられる。

### 3. 指数曲線によるPositional Debiasing

位置を`x=i/L`で0〜1に正規化し、`f_{mu,sigma}(x)=mu * exp(sigma*x)`を当てはめる。`mu`はスケール、`sigma`は後方位置に対する偏りの強さを表す。複数サンプルと全視覚位置にわたる二乗誤差を最小化して二つのパラメータを推定する。各画像の推論時には、元のスコアを`f(i/L)`で割り、補正済みスコアを得る（原著式(4)〜(6)）。

この操作は、画像下部にあるという理由だけで高いattentionを得ていた位置を相対的に下げる。逆に前半位置のトークンを無条件に選ぶわけではなく、補正後も画像内容や指示文に由来する差が残ることを狙う。指数関数の引数を`i/L`にすることで、視覚トークン数が異なる場合でも相対位置に基づく曲線を使える。ただし、モデル・前処理・視覚tokenizerが異なる場合に同じ`mu,sigma`を再利用できるとは限らず、校正集合での再推定が必要になる可能性がある。

また、これは注意行列の内部演算をすべて書き換える方法ではない。剪定の**順位付け**を補正するのであり、モデルの全層でattentionを完全に位置非依存へ変換するわけではない。実際の意味的関連性を直接観測するoracleが存在するわけでもないため、補正が常に正しい順位を復元する保証はない。

### 4. Padding Attention Suppression

位置補正だけでは、意味を持たないpadding位置がattention sinkになる問題が残る。PASは、画像前処理からpaddingに対応する視覚トークン位置を特定し、その位置のランキングスコアをゼロにする。実装順序はPDを先に適用し、続いてPASでpadding位置を除外する（原著式(7)）。その後に既存剪定法のtop-K選択を実行する。

paddingは入力画像のアスペクト比やパディング方式に依存するため、画像パッチとpaddingの対応関係を誤ると、本来の画像領域を誤って除外してしまう。PASの前提は、**本当に無意味なpaddingトークンを識別できること**である。パディングに鏡像など意味を持つ視覚構造を埋める場合、無条件の除外が常に適切とは限らない。原著ではmean/constant/random/mirror paddingを比較し、単に値を変えるだけでは偏りを十分に消せないと報告する。

### 5. 六種類の既存剪定法への接続

FastVは比較的浅い層のoutput-to-visual attentionを使う単層剪定、PyramidDropは層ごとに段階的にトークンを減らす複数層剪定である。SparseVLMは選択した言語トークンからのtext-to-visual attentionを利用し、HiMAPは浅層の言語→画像attentionと深層の画像→画像attentionを使い分ける。TokenCarveはattentionとSVD由来の情報量を組み合わせ、iLLaVAは剪定とtoken mergingを組み合わせる。

提案法は各方式の元のランキング規則を置き換えるのではなく、そこから得たattentionにPD/PASを追加する。これにより、同じ保持予算・同じ剪定位置で、**スコアの偏りを除いた効果**を比較できる。SVDによるmergeや多層剪定など、元のアルゴリズム固有の追加計算は残る。補正の計算自体は小さいが、実装上のトークン再配置やKV更新のコストは方式ごとに異なる。

## 評価条件

### 画像理解のベンチマークと環境

原著v2の画像実験はLLaVA-v1.5-7BとLLaVA-v1.5-13Bを対象とする。両モデルはVicuna系言語モデルとCLIP系視覚エンコーダを用い、**単一NVIDIA A100 80GB**上で推論する。視覚トークン保持予算は128個に固定する。評価はVQAv2、GQA、VizWiz、ScienceQA-Image、TextVQA、POPE、MME、MMBench、MMBench-CN、MM-Vetの10ベンチマークである。

| 項目 | 条件 | 解釈 |
|---|---|---|
| モデル | LLaVA-v1.5-7B、LLaVA-v1.5-13B | 画像側の同系統VLMでの規模差 |
| GPU | NVIDIA A100 80GB×1 | 同時要求・分散推論は未評価 |
| 視覚保持予算 | 128 tokens | 補正前後で保持数は同じ |
| 既存剪定法 | FastV、PyramidDrop、SparseVLM、HiMAP、TokenCarve、iLLaVA | それぞれに提案法を後付け |
| 画像タスク | 10種類 | 正答率系とMME等の異なるスケールが混在 |
| 動画 | Video-LLaVA、2048→512 tokens | MSRVTT、MSVD、TGIFの動画QA |
| 校正 | 複数画像の位置別attention平均に指数曲線をフィット | 校正集合の規模・再校正費用の検討が必要 |
| 速度 | 同一保持予算下の性能比較が中心 | TPS/TTFT/TPOTの定量表なし |

Table IIの`Acc.`は原著が報告する10課題の集約値である。MMEは約1,400〜1,500の値であり、他の課題の百分率と尺度が異なる。したがって**表の10個の数値をそのまま算術平均してAcc.を再現できるとは限らない**。以下では論文掲載のAcc.をそのまま記載し、独自に計算した値と混同しない。

### 動画の評価条件

動画実験ではVideo-LLaVAを用い、2048個の動画視覚トークンから512個を残す。MSRVTT、MSVD、TGIFの三つの動画質問応答ベンチマークでaccuracyとGPT評価scoreを測る。画像実験と動画実験ではモデル、視覚トークン数、タスク、評価スケールが異なるため、画像での+2.9ポイントと動画での+0.6ポイントを同一条件の比較として扱わない。

## 評価結果

### 1. 画像10ベンチマーク平均：7Bの六方式

原著v2 Table IIの`Acc.`列を抜粋する。

| 剪定法 | 補正前 | PD+PAS後 | 差（ポイント） |
|---|---:|---:|---:|
| FastV | 59.6 | **62.5** | **+2.9** |
| PyramidDrop | 60.5 | **61.6** | +1.1 |
| SparseVLM | 62.0 | **62.4** | +0.4 |
| HiMAP | 59.0 | **61.4** | **+2.4** |
| TokenCarve | 61.5 | **61.9** | +0.4 |
| iLLaVA | 59.7 | **61.7** | +2.0 |

最大の平均改善はFastVの+2.9、次がHiMAPの+2.4である。SparseVLMとTokenCarveは+0.4にとどまり、もともとのランキングが十分強い場合は追加効果が小さい。すべての剪定法で同じ幅だけ改善するわけではない。非剪定LLaVA-v1.5-7BのAcc.は**63.1**であり、FastV+提案法の62.5はそれに近づくが、無条件に非剪定を超えるわけではない。

FastVの課題別ではVQAv2が73.2→**76.6**、GQAが55.8→**59.3**、POPEが72.0→**83.1**、MM-Vetが25.2→**30.6**へ改善する。POPEは物体幻覚への頑健性を測る指標であり、paddingや位置に偏ったトークン保持を減らす効果と整合的である。ただし、ScienceQA-Imageは69.1→69.1で変化せず、すべての指標が上がるわけではない。

### 2. 画像10ベンチマーク平均：13Bへの一般化

| 剪定法 | 補正前 | PD+PAS後 | 差（ポイント） |
|---|---:|---:|---:|
| FastV | 64.3 | **65.2** | +0.9 |
| PyramidDrop | 64.1 | **64.8** | +0.7 |
| SparseVLM | 65.2 | **65.3** | +0.1 |
| HiMAP | 63.2 | **64.2** | +1.0 |
| TokenCarve | 65.4 | **65.8** | +0.4 |
| iLLaVA | 63.9 | **64.9** | +1.0 |

13Bでも6方式すべての平均が上がるが、7Bより改善幅は全体に小さい。SparseVLMは+0.1ポイントで、統計的不確実性の範囲を論文から十分に判断できない。非剪定LLaVA-v1.5-13BのAcc.は66.0であり、TokenCarve+提案法の65.8はそれに近い。7Bと13Bで共通の傾向があることは示すが、異なるVLM系統（Qwen-VL、InternVL、動画モデルなど）への同じ強さの一般化を証明するものではない。

### 3. 個別課題の負の結果

平均が改善しても、個別ベンチマークでは下がる場合がある。7BのPyramidDrop+提案法ではScienceQA-Imageが69.0→**68.0**、SparseVLMではVizWizが50.2→**50.1**、ScienceQA-Imageが68.7→**68.5**へ低下する。TokenCarveでもScienceQA-Imageが69.4→**69.0**、TextVQAが58.1→**57.9**となる。

13BではFastVのScienceQA-Imageが74.1→**73.9**、MM-Vetが34.9→**34.0**へ低下する。SparseVLMのMM-Vetは37.9→**37.0**、HiMAPのScienceQA-Imageは72.5→**72.1**、TokenCarveのScienceQA-Imageは73.4→**73.3**である。これらは補正が全ての指示・画像・タスクに対して必ず改善をもたらすわけではないことを示す。

「6方式すべてで平均が改善」と「各方式の全タスクで改善」は異なる主張である。特にOCR、細部認識、画像の端に重要情報がある場合、位置補正でランキングが変わることが有利にも不利にも働く。正答率の標準偏差や複数seedの信頼区間は表から十分に分からないので、+0.1ポイントのような小さな差を統計的に有意な改善と断言しない。

### 4. 動画QAでの効果

原著Table IIIでは、Video-LLaVAの2048→512トークンの条件で次の平均accuracyを報告する。

| 剪定法 | 動画QA平均Acc.補正前 | 補正後 | 差 |
|---|---:|---:|---:|
| FastV | 57.3 | **57.9** | +0.6 |
| PyramidDrop | 57.8 | **57.9** | +0.1 |
| SparseVLM | 57.6 | **58.2** | +0.6 |
| HiMAP | 58.1 | **58.4** | +0.3 |

FastVのGPT scoreは3.54→3.58、SparseVLMは3.55→3.59へ上がる。ただし個別の動画タスクでは、PyramidDropのMSVD accuracyが70.1→**70.0**、HiMAPのTGIF accuracyが47.2→**46.9**へ下がる。動画では時系列位置と画像内位置が混在するため、画像で見た位置偏りをそのまま動画全体へ拡張するのは慎重であるべきだ。

**原著表の整合性注意**：Table IIIの非剪定Video-LLaVA行の`Avg. Score`が**4.60**と印字されているが、同じ行のMSRVTT/MSVD/TGIF scoreは3.50/3.90/3.40であり、算術平均は**3.60**となる。明らかな表内不整合があるため、この4.60を性能比較の基準値として使わない。剪定法の補正前後については各行の値をそのまま記録した。

### 5. 二成分のablation

原著Table IVはFastVとPyramidDropについて、VQAv2/GQA/TextVQAの3課題平均を比較する。10課題平均とは異なる列である。

| 方式 | PD | PAS | 3課題平均 |
|---|---|---|---:|
| FastV | なし | なし | 62.0 |
| FastV | あり | なし | 64.0 |
| FastV | なし | あり | 64.2 |
| FastV | あり | あり | **64.6** |
| PyramidDrop | なし | なし | 62.7 |
| PyramidDrop | あり | なし | 63.6 |
| PyramidDrop | なし | あり | 63.8 |
| PyramidDrop | あり | あり | **64.0** |

PD単独でもPAS単独でも改善するが、両方を併用したときに最も高い。したがって位置偏りとpadding sinkは同一の問題ではなく、補正する対象が異なることが裏付けられる。ただし、単独改善量を足せば併用改善量になるわけではない。FastVではPD単独+2.0、PAS単独+2.2なのに、併用は+2.6である。両成分の効果は部分的に重複している。

### 6. 指数近似、保持予算、剪定層の感度

Table VではFastVの10課題平均が59.6、位置別平均を直接割る式(2)では59.8、指数曲線の式(5)では**61.7**、PD+PAS全体では**62.5**となる。平均曲線の直接除算はノイズに敏感で、指数近似が安定した補正となるという設計根拠を支持する。一方、式(2)で全課題が改善するわけではなく、MMEは1442.3→**1383.5**へ下がる。曲線近似の有無は実際の性能に影響する。

Table VIでは、TextVQAで保持64トークンのFastVが55.1→**57.1**、128トークンが56.9→**58.0**、256トークンが57.5→**58.1**となる。保持数が小さいほど補正の相対的重要性が高まる傾向があるが、全方式で単調に同じ改善幅が出るわけではない。Table VIIでは剪定層1/2/4/8/16を比較し、深い層では改善幅が小さくなる。たとえばFastVの層16は58.0→**58.1**である。すでに多くの情報が統合された深層では、初期層のトークン選択を変える利点が限定される可能性がある。

### 7. padding値を変えるだけでは解決しない

原著Table IXではFastVのVQAv2/GQA/TextVQAの3課題平均がmean paddingで62.0、constant 62.0、random 62.2、mirror 62.3である。一方、padding位置を明示的に除外するPASは**64.2**に達する。余白を別の値で埋めるだけではattention sinkが十分に解消しない。画像に対応するpadding maskを持ち、剪定ランキングから除くことが重要になる。

Table VIIIでは、元のFastVのVQAv2におけるattention位置偏り係数σが0.91、選択頻度側のσが2.56で、剪定によって偏りが増幅されることを示す。補正後はそれぞれ−0.01、−0.10となる。これは選択頻度が後方に極端に偏らなくなる証拠だが、**偏り係数がゼロに近いこと自体が意味的正しさの完全な保証ではない**。位置分布が均等でも、指示に必要な局所情報を取り逃がすことはあり得る。

## 既存研究との差

### FastV/PyramidDrop/SparseVLMとの関係

FastVは浅層でのattentionランキングを使う単純なトークン削除、PyramidDropは層をまたぐ段階的削除、SparseVLMは言語トークンの選別と回収を含む。これらの手法は「どのトークンが重要か」を異なる入力信号から推定するが、その信号に位置偏りが含まれる点を十分に扱っていない。提案法は剪定の新しい配置スケジュールや圧縮率の最適化ではなく、**元のスコアの系統誤差を除去する共通の前処理**として接続できる点が特徴である。

### 視覚特徴だけで選ぶ方式との関係

画像だけから重要度を推定する方式は、言語モデル由来のrecency biasを避けやすい。しかし、ユーザーの質問が画像のどの部分を必要とするかという指示依存性を失う可能性がある。PDは言語→画像attentionの指示依存信号を残しつつ、位置の影響を割り引くことを目標とする。したがって「視覚だけで選ぶ」方式と「言語のattentionを補正して選ぶ」方式は設計上異なる。原著の比較は主に既存attention剪定法への追加効果であり、全ての視覚特徴選択法に対する優位性を証明するものではない。

### RoPE除去との比較

先行研究には、RoPEの影響を除いて位置偏りを減らそうとする方式がある。原著Table Vでは、FastVにRoPE除去を適用した10課題平均が**58.4**となり、元のFastV 59.6より低い。PD+PASは62.5である。recency biasが位置符号化だけで決まるわけではなく、学習された注意パターンやモデルの内部統計にも依存するという著者の解釈と整合する。ただし、これは特定の再実装と評価設定での比較であり、すべてのRoPE修正法が劣るという結論ではない。

## 限界・負の結果・実装上の注意

第一に、実験の画像モデルはLLaVA-v1.5の7Bと13Bに限定される。InternVL、Qwen2-VL、Qwen3-VL、解像度が非常に高いタイル型モデル、動的パッチ数のモデルで同じ指数曲線が成立するとは限らない。校正集合の画像分布、アスペクト比、パディング方式、tokenizer、画像の走査順が変われば、位置別attentionの平均曲線も変わりうる。

第二に、padding位置を確実に識別できることが前提である。画像が実際に意味のある黒い背景を持つ場合、単純な画素値からpaddingと背景を区別するのは危険である。画像前処理段階のmask情報を引き継ぐ必要がある。画像のアスペクト比が多様な場合、画像→視覚トークンの対応関係を誤ると、重要なパッチを削除してしまう。

第三に、補正曲線はオフラインで統計的に推定する。追加学習不要でも、位置ごとのattentionを校正データで集計し、指数曲線をフィットする工程が必要である。校正データの必要枚数、推定の安定性、モデル更新時の再校正、異なる保持予算への移植の費用は、配信システムへの統合前に検証するべきである。推論中の除算は軽量でも、前処理全体が完全なゼロコストとは言えない。

第四に、品質改善と高速化を混同してはいけない。画像の保持トークン数128、動画512は補正前後で同じであり、計算量の主要部分は元の剪定法が決める。PD/PASは**同じトークン予算での品質を改善**する手法である。本文にはA100上でのエンドツーエンドTTFT/TPOT、decode tokens/s、バッチサイズ別スループット、GPUメモリ実測の比較表がない。スコアの補正が追加計算を伴うため、実測レイテンシが不変であることも示されていない。

第五に、平均値の改善は個別タスクの改善を保証しない。13BのSparseVLMでMM-Vetが37.9→37.0へ下がるような例は、画像理解の種類によって補正の影響が異なることを示す。重要な領域が画像の下側に偏る業務データでは、recency biasの補正が過剰となる可能性もある。安全な採用判断には、実ワークロードでの正答率と失敗例の確認が必要である。

第六に、Table IIIの非剪定Video-LLaVAのAvg. Score=4.60は同じ行の三課題scoreと算術的に整合しない。原著の表記不整合をそのまま性能改善の根拠に使わず、個別の数値と定義を確認する必要がある。加えて、v1とv2では題名・著者・結果表が異なるため、異なる版の数値を一つの実験として混ぜない。

## サーベイへの位置づけ

本研究は「VLMの視覚トークン剪定」における**importance scoreの補正**という系統に置くのが適切である。既存FastV/PyramidDrop/HiMAP等のtoken budget・剪定層・token mergingの設計とは独立に、スコアへ混入するrecency biasとpadding sinkを分離して抑える。LLM推論基盤の観点では、視覚トークン削減によるprefill/attention/KV削減を行う際に、**どのトークンを残すかの品質**を改善する補助機構とみなせる。

直接裏付けられるのは、単一A100上でのLLaVA-v1.5系とVideo-LLaVAにおける固定保持予算下の品質改善である。GPUサーバのTPS改善、メモリ削減率、複数要求のスケジューリング、異なるVLM系列への一般化は別途評価が必要となる。実装上は、画像前処理から正確なpadding maskを取得し、校正済み指数曲線を既存のattention rankingへ挿入する構成が現実的である。
