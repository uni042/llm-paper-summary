# 窓型注意は線形注意への変換より強い比較基準になるか

## 概要

大規模言語モデルの全注意は、生成が進むほど過去の鍵と値のキャッシュが増え、新しいトークンを処理する際に参照する過去トークンも増える。線形注意は固定サイズの再帰状態に集約することで、この増加を抑える。しかし、事前学習済みの全注意モデルを線形注意へ置き換えるには追加学習が必要で、元モデルの品質を完全には回復できないことがある。

本論文は、学習後の線形注意変換を評価する際、注意シンクを保持した単純な窓型注意（Sliding Window Attention; SWA）が十分に強い比較基準として使われていないことを指摘する。先頭4トークンと直近の一定範囲だけを参照するよう注意マスクを変更し、重みの追加学習なしで一般知識、数学・コード生成、長文検索、推論速度、メモリを比較する。

窓64・先頭シンク4の方式は、一般知識6課題平均で元モデルの99.0%を回復し、11の比較例のうち9例で元モデルを除く最高の平均値を得た。一方、数学の生成課題では窓64で正解率がほぼゼロになるモデルもあり、窓512でも全注意との差が残る。長文検索では線形注意変換より強い条件が多いが、全注意には大きく及ばない。結論は「窓型注意が常に無損失」ではなく、固定キャッシュ容量を得るための追加学習不要の比較基準が、従来考えられていたより強いというものである。

## 問題設定と比較の意義

通常の自己注意は、各トークンの問い合わせとそれ以前の全トークンの鍵から注意重みを求め、値の加重和を計算する。自己回帰生成では過去の鍵と値を保存して再計算を避けるが、保存量は文脈長に比例し、新規トークン一つの注意計算も文脈長とともに増える。長文脈サービスではGPUメモリ容量と帯域が制約となる。

線形注意は特徴写像を通じて注意の和を再帰的に更新できる形式へ変え、系列長に依存しない状態を保持する。ただし、有限サイズの状態へ情報をまとめると、過去のどの情報を残し、何を忘れるかが品質上の課題となる。既存の学習済みモデルをこの形式へ変換する研究では、LoLCATsやQRWKVなどが追加学習を行い、元モデルの品質を回復しようとする。

窓型注意は線形注意とは違い、ソフトマックスによる重み付けを維持したまま、参照する過去トークンを直近の一定範囲に制限する。窓から外れた古い情報は直接読めなくなるが、キャッシュの容量上限が固定される。従来の単純な窓型注意には、最初の数トークンを窓から除くと品質が急落する問題がある。元モデルが先頭トークンを注意確率の受け皿として使う「注意シンク」の現象を無視した比較は、窓型注意の能力を過小評価する。

## 手法：注意シンク付き窓型注意と公平な比較

### 先頭シンクと直近窓の保持

論文では窓型注意を `SWA(w,s)` と表し、窓の総サイズ `w` を64、128、256、512などに変え、先頭の注意シンク数 `s` は4に固定する。例えば `SWA(64,4)` では先頭4トークンと直近60トークンを参照し、直近64トークンに4トークンを追加した68個ではない。モデルの重み、ソフトマックス注意、出力射影はそのままで、注意マスクを変更するだけである。

先頭シンクを残す理由は、学習済みモデルが初期位置へ不要な注意確率を割り当てる振る舞いを保持するためである。窓が移動しても先頭4個は常に参照でき、残りの容量は新しいトークンへ割り当てる。中間の古いトークンはキャッシュから外すため、保存量は窓を超えて増えない。反面、長距離の特定事実を再取得するには、他の層を介して情報が残っていなければならず、全注意と同じ検索能力は保証されない。

### 学習後変換との費用比較

LoLCATsは線形注意と局所注意を組み合わせ、既存モデルを追加学習で近似する。QRWKV系も元モデルの注意を再帰型へ変換する。これらは固定状態によるメモリ削減を目指すが、追加学習のトークン数、特殊な演算カーネル、近似誤差が導入費用となる。SWAは追加学習0トークンで既存モデルに適用できるため、線形化の改善を主張する研究に対して、導入費用も含めた比較の基準になる。

著者らは元の全注意モデルを教師とし、その重みを変えずに窓型注意へ切り替えた場合と、線形注意へ変換した既存研究の結果を比べる。知識・推論の多肢選択課題と、生成中の履歴が重要な数学・コード課題を分け、さらに長文から事実を探す課題を確認する。多肢選択の得点だけでは、生成中の記憶保持や長距離検索の欠陥が隠れるためである。

### メモリと速度の測定条件

窓型注意は保持する鍵値が `w` 個で頭打ちになるが、線形注意は別の固定次元の再帰状態を保持する。両者のメモリ上限が固定であっても、実装のカーネルや行列演算の構成は異なる。速度比較では全注意と窓型注意にFlashAttention、線形注意にThunderKittensを使用する。4層、隠れ次元1024、16ヘッド、各ヘッド次元64の小規模Transformerを用い、16ビット、バッチ1、RTX PRO 6000 Blackwell Max-Qで文脈長を128から256Kまで変えて測る。大規模な本番モデルの推論速度をそのまま測定した条件ではない。

## 評価：対象モデル・データセット・条件

| 評価軸 | 原著の設定と指標 |
|---|---|
| 一般知識・推論 | MMLU、ARC-C、ARC-E、HellaSwag、PIQA、WinoGrandeの6課題平均。窓64、シンク4 |
| 数学・コード生成 | GSM8K（5例提示、厳密一致）、HumanEval（0例提示、pass@1）。窓64〜512 |
| 短めの長文検索 | 単一の隠れた事実を探す課題、文脈0.5K〜4K。窓128〜512 |
| 長文推論 | BABILong、LongBench、LongBench-v2、RULER。追加の8K・16K評価あり |
| 比較方式 | 元モデルの全注意、SWA、LoLCATs、Liger-GLA、QRWKV系列、その他線形注意変換 |
| 速度・容量 | 4層・隠れ次元1024・16頭・バッチ1・16ビット、RTX PRO 6000 Blackwell Max-Q |

原著の表1・2は複数のモデル系列を比較し、モデルの規模は1.3Bから72Bまでに及ぶ。短文脈の比較には他研究から引用した線形化方式の結果が含まれるため、すべての方式が著者らの同一実装で再測定されたとは限らない。長文検索の一部も既存研究の数値を参照している。表5のBABILongは最初の5課題平均であり、表6の8K・16K条件は20課題平均なので、数値を同じ母集団として直接比較しない。

## 評価結果：一般知識の回復率

窓64・シンク4では、一般知識6課題の平均得点が元モデルの99.0%に達し、MMLUの回復率は93.2%である。11比較例のうち9例で、窓型注意が元モデルを除く最高の平均値を得た。LoLCATsがPhi-1.5で62.5点、SWAが62.4点となる例外と、Qwen2.5-32B-InstructでQRWKV6が77.3点、SWAが76.6点となる例外を原著は示す。従って全モデル・全方式に対する無条件の優位ではない。

Llama-3.1-8Bでは、6課題平均が全注意72.5点、SWA(64,4)71.8点、LoLCATs70.3点である。Qwen2.5-7B-Instructでは全注意73.7点、SWA73.0点、QRWKV6系などの変換方式は条件によりさらに低い。SWAの主要な利点は、近い平均品質を追加学習なしで得られることであり、元モデルの重みを改変しない導入の簡単さにもある。ただしこの平均値は生成品質を測っていない。

## 評価結果：数学・コード生成の負の結果

原著表3では、Qwen2.5-7B-InstructのGSM8K正解率が全注意75.6%に対し、SWA(64,4)で0.0%、SWA(128,4)で1.7%、SWA(256,4)で25.4%、SWA(512,4)で41.7%となる。HumanEvalのpass@1も全注意64.0%、窓64では12.8%、窓512でも39.6%である。一般知識の平均が高くても、長い生成過程では短い窓の情報損失が致命的になり得ることを示す。

別のモデルでは回復度合いが異なる。Llama-3.1-8BのGSM8Kは全注意50.8%、窓512で49.2%と近づく。QwQ-32Bでは全注意74.0%、窓512で58.8%である。窓512は比較した学習不要方式と線形注意変換方式の中で各基盤モデルの数学・コード生成平均が高いが、全注意との隔たりはモデルごとに残る。これは窓長を小さくすれば一律に高速・高品質という結論を否定する重要な評価である。

## 評価結果：長文検索と長文推論

Llama-3.1-8Bの単一事実検索では、文脈4K・窓512・シンク4のSWAが、原著表4の難しい配置条件で23.0%を示す。同条件のLoLCATsとLiger-GLAは大幅に低く、線形注意変換との比較ではSWAが強い。しかし、窓型注意でも多くの事実を見失い、全注意に比べれば品質が低い。窓128では同じ配置条件のSWAは17.2%であり、窓を増やしても長距離検索の完全な解決にはならない。

BABILongの最初の5課題平均では、4K文脈でSWA(256,4)15%、LoLCATs3%、全注意60%である。0KではSWA55%、LoLCATs56%とわずかに逆転する。長文脈での相対優位を短文脈の全条件へ一般化してはならない。v2の8K・16K追加評価では、Qwen2.5-7B-Instructの集約平均が全注意57.1点、SWA(512,4)28.2点、QRWKV7 23.1点である。Llama-3.1-8Bでも全注意40.8点、SWA18.8点、LoLCATs6.4点となる。固定メモリ方式の中でSWAは良いが、全注意との差は非常に大きい。

## 評価結果：実測速度とメモリの範囲

原著図2の4層モデル実験では、全注意の鍵値キャッシュは文脈長に比例して増え、文脈が長くなるほど生成速度が低下する。SWAは窓が満ちるとキャッシュ容量が頭打ちになり、生成速度もおおむね横ばいで、実験した方式の中では最速だった。窓64は窓512より速く、保存容量も小さい。一方、窓64での数学生成の品質低下は前述のとおり大きく、資源削減と品質は交換条件になる。

線形注意も固定サイズの状態を保持するが、比較では専用カーネルの実装と状態次元が異なる。実測はRTX PRO 6000 Blackwell Max-Q上の小規模モデル、バッチ1であり、70B級の本番サービス、複数GPU、継続バッチ、同時要求の待ち行列まで含む速度比較ではない。図2の曲線をそのまま大規模言語モデル全体の処理率倍率として転記してはならない。

## 既存研究との差

線形注意への学習後変換は、既存のソフトマックス注意を別の演算形式へ置き換え、追加学習によって元モデルの挙動を近似する。窓型注意は元のソフトマックスを保ち、古いトークンを参照しないことでメモリと演算量を制限する。両者は固定メモリを達成し得るが、何を忘れるか、どれだけ追加学習が必要か、どのカーネルが必要かが異なる。著者らの貢献は新しい窓型注意の発明ではなく、注意シンクを保持した既知の方式を適切な比較基準として再評価した点にある。

線形化研究がシンクなしの窓型注意とだけ比較すると、窓型注意の既知の崩壊を理由に線形化の改善が過大に見える。先頭4トークンを残すだけで短文脈の平均品質は高くなるが、長距離の直接検索では全注意に劣る。追加学習済みの窓型注意、重要度に基づく高度なキャッシュ削除、全注意層を残す混合方式との優劣は、本研究の評価だけでは確定しない。

## 限界：一般化範囲と比較の制約

短文脈の線形注意変換方式の一部は既存研究の報告値を使っており、訓練条件・評価実装・カーネルが完全に統一されているわけではない。長文検索ではSWAも全注意から大幅に劣化し、特に小さな窓は生成課題の数学的な推論を破綻させる。窓を広げれば品質は回復するが、保持する鍵値と注意計算量は増える。窓長の最適値はモデル、課題、要求する品質、利用可能なメモリに依存する。

速度測定は4層の小規模モデルであり、各種70B級モデルを同じ条件で直接比較したものではない。注意演算以外の計算、複数GPU通信、サービスのスケジューリング、負荷変動は測定の対象外である。また、全注意層を一部残す混合方式や、学習を伴う窓型注意、高度なキャッシュ削除方式を網羅的に比較していない。したがって窓型注意があらゆる推論基盤で最良だとは結論できない。
