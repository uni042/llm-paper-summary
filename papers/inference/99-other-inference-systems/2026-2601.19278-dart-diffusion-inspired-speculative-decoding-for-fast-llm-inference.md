# DART: Diffusion-Inspired Speculative Decoding for Fast LLM Inference

> 対象LLM特徴から未来ロジットを1回で並列予測しN-gram木刈り込みを行い、EAGLE3より平均約30%高い投機デコード高速化を得る。
## 書誌情報
- **著者**: Fuliang Liu, Xue Li, Ketai Zhao, Yinxi Gao, Ziyan Zhou, Zhonghui Zhang, Zhibin Wang, Wanchun Dou, Sheng Zhong, Chen Tian
- **著者・所属**: Nanjing University; Alibaba Group
- **公開**: arXiv / ICML submission
- **種別**: プレプリント
- **対象**: 投機的デコーディング、並列ドラフト、拡散型言語モデル、N-gram、木検証
- **実装**: SGLang SpecForgeを基盤に学習し、Flex Attention、C++/OpenMP木刈り込み、CPU RAM上の3-gram trieを用いる公開実装。
## 概要
DARTは投機的デコーディングのドラフト段階を自己回帰ロールアウトから並列多位置予測へ置き換える。対象LLMの複数中間層特徴を再利用する単一軽量Transformer層が、固定長マスクブロックに対して複数未来位置のロジットを1回で出力し、N-gram連続性を用いた木刈り込みで検証候補を構成する。Qwen3系等で自己回帰基準比2.03〜3.44倍、EAGLE3比平均約30%高い速度向上を報告する。

DARTは拡散型言語モデルそのものを利用するのではなく、複数のマスク位置を並列に予測する原理だけをEAGLE3型の対象モデル結合下書き器へ移植する。対象LLMの低層・中層・高層の隠れ状態を連結・射影し、単一のカスタム復号層へ接頭辞とd-1個のマスクを入力してd位置のロジットを一度に生成するため、下書き長に比例した自己回帰前向きを除去する。さらに早い位置の誤りほど受理長へ強く効く性質を、位置ごとにgamma^(t-1)で減衰する対象モデル分布とのKL学習へ組み込む。独立位置ロジットの組合せ爆発には3-gram連続性を確率スコアへ混ぜたビーム木刈り込みを用い、N-gramを単独予測器ではなく低遅延な整合性制約として再利用する。

代表結果として、エンドツーエンド 高速化倍率はQwen3/LLaMA2、7 ベンチマーク、主にバッチ=1 H20-3eでvanilla autoregressive デコードに対して2.03×〜3.44×。並列draftで対象モデル呼出回数削減の利得をdraft オーバーヘッドに食われにくくする。
## 問題設定
投機的デコーディングでは軽量な下書きモデルが複数候補を提案し、大きな対象モデルがまとめて検証することで対象モデルの呼び出し回数を減らす。しかしEAGLE3のように受理率を高めた特徴ベース下書き器も複数段の自己回帰生成を残しており、下書き前向き計算だけで総推論時間の20〜40%を占める場合がある。小型Qwen3-1.7Bを通常の下書きモデルにするとQwen3-14B/32Bで下書きが総時間の75%/60%以上を占める例もあり、平均受理長だけを伸ばしても高速化が頭打ちになる。一方、既存の拡散型LLMをそのまま下書き器にすると双方向の全文復元目的と接頭辞条件付き投機生成が不一致で、モデル自体も大きいため低遅延にならない。さらに各未来位置を独立に並列予測すると候補の組合せが指数的に増え、位置間の意味的連続性が失われる。
## 新規性
DARTは拡散型言語モデルそのものを利用するのではなく、複数のマスク位置を並列に予測する原理だけをEAGLE3型の対象モデル結合下書き器へ移植する。対象LLMの低層・中層・高層の隠れ状態を連結・射影し、単一のカスタム復号層へ接頭辞とd-1個のマスクを入力してd位置のロジットを一度に生成するため、下書き長に比例した自己回帰前向きを除去する。さらに早い位置の誤りほど受理長へ強く効く性質を、位置ごとにgamma^(t-1)で減衰する対象モデル分布とのKL学習へ組み込む。独立位置ロジットの組合せ爆発には3-gram連続性を確率スコアへ混ぜたビーム木刈り込みを用い、N-gramを単独予測器ではなく低遅延な整合性制約として再利用する。
## 手法
### 手法のあらまし
DARTの一巡は、まず対象モデルが通常の事前充填または前回の投機候補検証を行うところから始まる。この対象モデル計算の途中で、著者らは第1層付近、中間層付近、末尾から数層前という複数段階の隠れ表現を取得する。これらを連結して全結合層で対象モデルの隠れ次元へ射影し、対象モデル自身の埋め込み層から得た一トークンずらしの埋め込みと結合して、接頭辞各位置の下書き入力表現を作る。次に未来d個を自己回帰的に一個ずつ生成する代わりに、接頭辞末尾の後ろへd-1個の学習可能マスク表現を並べ、単一のカスタムTransformer復号層を一回だけ実行する。接頭辞最後の出力を第1未来トークンの分布、各マスク位置の出力をそれぞれ次の未来位置の分布として読む「ずらしロジット予測」により、d個の未来分布を一回の前向きで同時に得る。注意マスクは拡散モデルのような双方向ではなく厳密な因果構造を保つので、全未来分布は既知の接頭辞だけに条件付けられる。学習時には一つの系列から多数の接頭辞位置を作り、それぞれに専用マスクブロックを付ける。異なるブロック間の注意を禁止し、各ブロックは自分の接頭辞とブロック内過去位置だけを見るようにして、複数の学習例を一回の疎注意計算へ詰める。教師信号は対象モデルが真の過去トークンを見たときの分布であり、未来位置が遠いほど不確実になるため、位置tのKL損失へgamma^(t-1)を掛ける。推論で得られたd個の位置別ロジットはそのまま組み合わせると指数的な候補木になるため、各深さで上位25 トークンだけを取り、現在までの部分系列に対する3-gram条件付き確率と下書きロジット確率を合成して枝を採点する。各深さでは上位20部分系列だけを残し、最終木全体も59 nodeへ制限する。こうして得た小さな候補木を対象モデルへ木注意で一括投入し、通常の投機検証規則で連続する正しい候補だけを受理する。棄却時には対象モデル分布に従う補正を行うため最終生成分布は通常自己回帰と一致する。この一連の設計により、従来は複数回必要だった下書きモデル前向きを一回へ固定しつつ、N-gramで独立位置予測の連続性低下を補い、対象モデルの厳密検証で品質を保持する。

### 対象モデル特徴を再利用する単一層並列下書き器
DARTは独立した小型言語モデルを丸ごと動かすのではなく、対象LLMが事前充填または候補検証のためにすでに計算した複数中間層の隠れ状態を再利用する。第1層付近、中間付近、末尾近くの特徴を連結して全結合層で圧縮し、対象モデルの埋め込みと組み合わせて単一のTransformer復号層へ入力する。未来長dに対して接頭辞後ろへd-1個の学習可能マスクを付加し、接頭辞末尾を第1未来位置、各マスクを第2以降の未来位置として一回の前向きで全ロジットを出す。従来EAGLE3では軽量一層であっても次の特徴を出してから次stepへ進む自己回帰依存が残るが、DARTでは未来位置間の生成依存を前向き経路から取り除くため、下書き前向き遅延が下書き長とともに増えない。対象モデルと埋め込みを共有し、学習対象を全結合層・復号層・言語モデル頭・マスク表現へ限定することで、大型拡散LLMを別途動かす方式より軽量に保つ。

### ずらしロジット予測と接頭辞共有マスク学習
通常のマスク言語モデルではマスク位置の出力を同じ位置のトークン予測として読むが、DARTは各位置の出力を一つ先のトークン予測として解釈する。このずらしにより接頭辞最後の通常位置も教師信号へ使え、投機検証で最重要な第1未来位置の予測精度を高める。実験ではQwen3-4Bで第1位置精度が57.7%から71.1%へ13.4ポイント向上した。学習効率を上げるため、一系列から多数の接頭辞を取り出して個別に前向きするのではなく、複数のマスクブロックを同じ計算へ配置する。各マスクブロックは対応する接頭辞だけを参照し、ブロック内部は推論時と同じ因果注意、異なるブロック間は完全に遮断する。この非常に疎な注意構造をFlex Attentionで実装し、未来の正解トークンを漏らさずに多数の接頭辞条件付き多トークン予測を同時に教師化する。

### 位置重要度を反映する減衰KL学習
投機検証では候補を先頭から順番に受理するため、第1位置を外すとその後ろにどれだけ良い候補があっても同じ巡回では受理できない。したがって未来位置を等価に学習すると、予測困難な遠い位置が損失を支配して重要な近距離精度を損なう可能性がある。DARTは一hot正解だけではなく、対象モデルが真の過去トークン列に条件付けて出す分布を教師とし、各未来位置の下書き分布とのKL距離を最小化する。その際、位置tの重みをgamma^(t-1)として指数的に下げ、近い未来へ学習容量を寄せる。HumanEval上のgamma ablationでは0.5から1.0を比較し、gamma=0.6が平均受理長3.63で最大となった。小さすぎるgammaは遠距離精度を落とし、大きすぎるgammaは第1位置の精度を弱めるため、受理順序そのものを損失設計へ組み込んだ点が重要である。

### 3-gram連続性を用いる候補木刈り込み
並列下書き器が出すd個の位置別分布は互いに完全な自己回帰条件付けを持たないため、各位置の上位トークンを直積すると指数的な木になり、個々には高確率でも並べると不自然な枝が大量に生じる。DARTは各深さで位置ロジット上位25候補だけを展開し、部分系列末尾に対する3-gram条件付き確率を下書きロジット確率へ加えて枝を採点する。深さごとに上位20部分系列だけを残し、最終検証木も59 nodeへ制限するため、対象モデルの木検証費用を制御できる。3-gramはDolma 3 Mixからtrieとして構築され、約13億node、disk約43.5GB、実行時CPU RAM約100GBを使うが、C++実装と同一NUMA nodeへのthread bindingによりwarmup後の検索は約6マイクロ秒である。N-gramなしと比べ平均受理長は評価4集合で0.48〜0.74増え、低遅延な統計的連続性情報が並列神経予測の弱点を補う。

### 全体のデータ／制御の流れ
DARTはGPU側の対象モデル検証、対象特徴を使う一回の軽量並列下書き、CPU側の大容量3-gram辞書とC++木刈り込みを役割分担する。対象モデルの一巡が終わるたびに、その計算済み特徴から約1.5msの下書き前向きを行い、約2msの木刈り込みで小さな候補木へ変換し、次の対象モデル呼び出しでまとめて検証する。平均受理長をEAGLE3とほぼ同等に保ちながら、従来20〜40%を占めた逐次下書き時間を大きく削るため、対象モデルが大きくメモリ帯域律速であるほど固定的な数ms削減がエンドツーエンド速度へ反映される。
## 評価条件
- **ハードウェア**: 主環境は8×NVIDIA H20-3e 141GB、90 CPU cores、900GB RAM。追加のクロスハードウェア評価は単一NVIDIA A100-40GB。
- **ソフトウェア**: PyTorch 2.8.0。DART学習はSGLang SpecForgeを基盤とし、Flex Attentionでprefix-shared sparse maskを実装。tree 枝刈りと3-gram trieはC++、OpenMP/NUMA bindingを使用。Qwen3-1.7B/4B/8B/14B/32BおよびLLaMA2-Chat-7Bを対象とする。
通常バッチ size 1、DART/EAGLE3のdraft length 8で、MT-Bench、HumanEval、Alpaca、Math500、CodeAlpaca、LiveCodeBench、MBPPを評価する。指標は自己回帰基準に対する実wall-clock 高速化倍率、平均受理長tau、draft forward/tree search 遅延。EAGLE3、SPS、Medusa、Hydra、Lookahead、PLD等と比較する。学習はcontext 6400、AdamW lr 2e-5、3 epochs、ShareGPT+UltraChat約280K例。shifted logits、N-gram、KL減衰gammaをablationし、バッチ size 2〜64とA100でも速度傾向を検証する。
無損失 speculative デコードの速度評価が中心で、生成品質は最終分布が対象モデルと一致するため別途報告しない。主結果はH20-3eでバッチ size 1に最適化された状況であり、大バッチではcompute-bound化して利得が縮小する。DiffuSpec/SpecDiffは実装非公開のため直接比較していない。
## 主要結果
DARTはQwen3系とLLaMA2-Chat-7Bで標準自己回帰デコード比2.03〜3.44倍のwall-clock 高速化倍率を示し、EAGLE3より平均約30%高い高速化を得た。Qwen3-14Bではdraft forwardが約1.5msでEAGLE3比6.8倍、SPS比53.3倍高速、tree 枝刈りは約2msだった。平均受理長tauはEAGLE3と概ね同等で、ドラフト遅延削減が総スループット差を生む。

- エンドツーエンド 高速化倍率 / 2.03×〜3.44× (比較対象: vanilla autoregressive デコード; 条件: Qwen3/LLaMA2、7 ベンチマーク、主にバッチ=1 H20-3e) — 並列draftで対象モデル呼出回数削減の利得をdraft オーバーヘッドに食われにくくする。

- EAGLE3比平均高速化 / 約30% higher 高速化倍率 (比較対象: EAGLE3; 条件: 主評価全体) — tau最大化だけでなくdraft 遅延最小化が重要であることを示す。

- Qwen3-14B draft forward 遅延 / 1.5 ms、EAGLE3比6.8×、SPS比53.3×高速 (比較対象: EAGLE3 / Qwen3-1.7B SPS; 条件: H20-3e、draft length 8 (SPSは5)) — 自己回帰rollout除去が直接draft stage ボトルネックを削る。

- N-gram 枝刈り効果 / tau +0.48〜+0.74 (比較対象: N-gramなし; 条件: HumanEval/Alpaca/Math500/CodeAlpaca) — 独立位置logitの組合せに短距離連続性を入れることで受理可能なtreeを増やす。

- shifted first-position accuracy / 57.7% → 71.1% (+13.4pt) (比較対象: unshifted logits; 条件: Qwen3-4B ablation) — 最重要の先頭draft位置を改善し、早期rejectを減らす。

- large-バッチ Qwen3-4B 高速化倍率 / バッチ 64で1.45× (EAGLE3 1.22×) (比較対象: autoregressive / EAGLE3; 条件: HumanEval H20-3e) — バッチ増加で利得は縮小するが4Bでは大バッチでも優位が残る。

### 負の結果・境界条件
- バッチ増加で投機デコードの利得は縮小する。Qwen3-8Bではバッチ 64でDART 1.01×、EAGLE3 0.98×とほぼ利得が消える。DARTの3-gram trieはdisk約43.5GB、実行時CPU RAM約100GBを必要とし、サーバ級ホスト メモリを前提とする。DARTのtauは常にEAGLE3を上回るわけではなく差は概ね0.2以内で、優位性は主に低draft 遅延から生じる。

### 結果の読み方
DARTは『より正確な自己回帰ドラフタ』の延長ではなく、受理長を多少犠牲にしてもdraftを一回の並列forwardへ変換する設計点を選ぶ。対象モデルが大きくメモリ-boundでバッチが小さいほど、この固定的な数msのdraft オーバーヘッド削減がwall-clockへ効く。CPU RAMをN-gram辞書へ使う点はGPU以外の余剰資源を高速化へ転換する実装上の特徴でもある。
## 品質への影響
通常の投機的検証でtarget distributionを厳密に保つため生成品質は標準自己回帰デコードと同一。DART/N-gramは候補提案だけを変え、reject時の補正規則を変えない。
## 既存研究との差
EAGLE3は対象モデルhidden featureを使う軽量一層drafterだが未来トークンを自己回帰的に複数step生成する。DARTは同じ『target-coupled lightweight drafter』の利点を残しつつ、mask blockの未来位置logitを単一forwardで並列生成する。Medusaの独立multi-head予測よりも対象分布KLと中間特徴を用いて精度を高め、独立位置の不整合はN-gram tree 枝刈りで補う。DiffuSpec等が独立した大きなdiffusion LLMをdraft modelとして使うのに対し、DARTはdiffusionの並列mask予測原理だけを小型専用層へ移し、tokenizer/モデル可用性とdraft 遅延問題を避ける。Lookahead/PLDのN-gram方式とは、N-gramを主予測器ではなくneural parallel logitsの枝整合性フィルタとして使う点が異なる。
## 限界
投機高速化はメモリ-boundな小バッチで最大化し、バッチが大きくcompute-boundになるほど縮小する。Qwen3-8Bではバッチ 48〜64でほぼ1倍まで低下する。連続性補正に使う3-gram trieは約1.3B nodes、disk 43.5GB、CPU RAM約100GBを消費し、ホスト メモリが小さい環境には重い。draft modelは対象モデルごとにShareGPT/UltraChat等で3 epoch学習する必要がありtraining-freeではない。DiffuSpec/SpecDiffなど一部の直接競合はclosed-sourceのため同一実装環境で比較されていない。
## 実装状態
公式コードはfvliang/DARTで公開。学習はSGLang SpecForgeを基盤とし、Flex Attention、C++/OpenMP tree 枝刈り、NUMA-aware 3-gram trieを含む。arXiv v1 (2026-01-27)でICML表記のプレプリント。
## 研究上の位置づけ
投機的デコーディング研究におけるボトルネックを『target verification回数』から『drafter自身の逐次forward』へ移して捉えた研究である。拡散型言語モデルの非自己回帰並列性、EAGLE系のtarget-feature reuse、N-gram/lookup系の低コスト連続性情報を組み合わせ、受理長とdraft 遅延の二目的設計として整理できる。特に大規模target・バッチ 1のオンライン生成で有効な系統である。
