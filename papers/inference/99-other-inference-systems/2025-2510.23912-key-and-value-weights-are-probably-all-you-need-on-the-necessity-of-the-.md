# Key and Value Weights Are Probably All You Need：Query射影の冗長性を理論と小規模事前学習で検証する

## 概要

標準的な自己注意は、入力表現にQuery、Key、Valueの三つの学習可能な線形射影を適用し、さらに注意出力の射影を持つ。各射影が表現力に独立して必要なのかは、モデルのパラメータ数・学習時の最適化・推論時のメモリ使用量を考えるうえで重要である。本論文は、**Query射影の重み行列`W_Q`を恒等行列`I`に固定し、残る`W_K`と`W_V`などのパラメータで同等の機能を表せる条件**を解析する。

理論の出発点は、注意機構が元の入力`X`を直接見るのではなく、`XW_Q`、`XW_K`、`XW_V`という射影後の値に依存する点である。可逆な基底変換を入力と重みへ同時に適用すれば、この三つの積を保存できる。ただし実際のTransformerでは、層間の残差接続、LayerNorm、MLP、重み共有、学習時のweight decayがある。論文はそれらを一度に「すべて厳密に等価」とはせず、単一ヘッド、単一層、残差構造を限定した多層モデル、共有重みモデルへ段階的に定理を拡張し、完全なGPT型モデルについては別に実験で検証する。

OpenWebTextで約29.5Bトークン、60kステップを学習したGPT型モデルでは、通常モデルの非埋込パラメータ84.95M、validation loss 2.944に対し、`W_Q=I`の77.88Mモデルも2.944だった。これは**非埋込パラメータ約8.3%削減**であり、総モデルパラメータが25%減るわけではない。削減分をMLPの幅へ再配分すると、通常モデルと同程度の非埋込パラメータ84.95Mでloss 2.929となる。一方、比較は約117〜124Mパラメータ規模であり、70Bモデルの実測や推論サーバーTPSは示されていない。

## 問題設定と理論的背景

入力系列を`X∈R^{n×d}`、ヘッド数を`h`、ヘッド幅を`d_k=d/h`とする。ヘッドごとの注意logitは`(XW_Q^i)(XW_K^i)^T / sqrt(d_k)`であり、softmaxの重みを`XW_V^i`へ掛ける。最後に各ヘッドを連結し`W_O`を適用する。通常の実装では`W_Q`、`W_K`、`W_V`、`W_O`は学習可能であり、正方の総射影行列を想定すると、四つのうち一つを固定することは注意射影パラメータの約25%を省くことに相当する。

単一ヘッドの場合、logitに現れるのは`W_Q W_K^T`という積であり、値側の出力は`W_V W_O`という積に依存する。したがって`W_Q`と`W_K`を別々に保持せず積を別の重みへ吸収でき、同様に`W_V`と`W_O`を一つにまとめられる。しかし**多ヘッドではヘッドごとの分割があり、層をまたぐ残差経路も基底変換を制約する**。単一ヘッドの結果をそのまま全層・全ヘッドへ当てはめることはできない。

既存のGQA/MQAは複数QueryヘッドがKey/Valueを共有し、KVキャッシュと射影の規模を減らす。LoRAは重みの低ランク更新、量子化は重みや活性の精度を減らす。提案の`W_Q=I`は**Query射影の学習可能な自由度そのものを削るアーキテクチャ変更**であり、GQA/MQAや量子化とは削減対象が違う。推論時に既存checkpointの`W_Q`だけを単純に削除してよいという意味でもない。

## 手法

### 1. 再パラメータ化補題：入力と重みの基底を一緒に変える

原著Lemma 3.1は、関数が`g(XW_Q, XW_K, XW_V)`という形で表されるなら、可逆行列`Θ`に対して`X→XΘ`、各重み`W→Θ^{-1}W`を同時に行っても三つの積は変わらないと示す。特に`W_Q`が可逆なら`Θ=W_Q`を選び、Query重みを`I`へ、KeyとValueを`W_Q^{-1}W_K`、`W_Q^{-1}W_V`へ変換できる。この補題の重要な条件は**入力表現自体も`XW_Q`へ基底変換する**点である。

一層の注意だけを切り出せばこの等価性は直観的だが、実際のモデルでは入力がembeddingと前層から渡される。`X`を変えたなら次層のMLP、残差、出力headまで整合するよう重みを変更しなければ、モデル全体の出力は保存されない。したがって補題は**基底変換を吸収できる構造がある場合**の数学的道具であって、任意の事前学習済みTransformerの`W_Q`を無条件で消せる証明ではない。

### 2. 単一ヘッドの厳密な冗長性

Proposition 4.1は単一ヘッド注意に対し、`W_Q`と`W_O`を恒等にし、`W'_K=W_K W_Q^T`、`W'_V=W_V W_O`とすれば、任意の入力に対して同じ注意出力を得られると示す。ここでは注意logitの積と値側の積が保存されるため、LayerNormや残差接続の存在をこの局所的な等価変換の条件に含める必要がない。これは**学習済み重みの後処理でも実施し得る**結果である。

ただしweight decayを掛けてゼロから学習する場合、元の四行列に対する二乗ノルム罰則と、積へ吸収した二行列に対する罰則は同じでない。したがって関数の表現力が等価でも、学習過程と最終lossが等価になる保証はない。論文はこの違いを、数学的な再パラメータ化と最適化の性質を分けて説明する。

### 3. 多ヘッド・単一層・多層へ進む際の制約

多ヘッドではヘッドごとのKeyとQueryの基底変換が可能だが、Proposition 4.2が示すのはヘッド単位のブロック対角変換に対する不変性であり、`W_Q`全体を消せるという強い主張ではない。Theorem 4.1は正規化なし・embeddingと出力headの重みを共有しないTransformerについて、**任意の一層の`W_Q`を恒等へ変換してもモデル出力を厳密に保てる**とする。ただし全層を同時に消すためには、各層の異なる基底変換を次層へ伝播させる必要がある。

MLPの残差接続は`X + MLP(X)`という入力・出力の基底を同じに結び付けるため、層ごとに異なる`Θ_i`を自由に選びにくい。論文は全層削減を示すため、(a)MLP周りのskipを除くか、(b)層間で重みを共有し同じ基底を使う、という単純化された条件を分析する。通常のpre-LayerNorm・MLP残差・層別非共有重みをすべて持つGPTで、全層`W_Q`の**厳密な後処理削除が証明されたわけではない**。Table 1の理論・実験対応表は、この境界を明示している。

### 4. 実用GPT型でのW_Q=Iアーキテクチャ

実験では学習済みcheckpointから`W_Q`を無理に消すのでなく、**最初から`W_Q=I`を固定したモデルをスクラッチで学習**する。通常の12層12ヘッド・hidden 768・MLP幅3072に対して、Queryの線形層を学習対象から外し、入力をヘッド幅に切り出した値をQueryとして使う。KeyとValue、output射影、LayerNorm、MLP、残差は維持する。

Queryを学習射影から直接の座標切り出しへ変えると、初期状態でattention logitの標準偏差が通常モデルの約1.8倍になるため、標準の`1/sqrt(d_k)`の代わりに`1/(2 sqrt(d_k))`でスケールする。初期softmaxの飽和を避けるための補正であり、単に重みを削るだけでは同じ学習挙動にならない。さらにQuery/Keyの積に依存する通常logitに対し、削減後は主にKey側の一つの学習行列へ依存するため、著者らは高めの学習率を使用する。

### 5. 同一パラメータ数と同一構造の二つの比較

削減の価値を調べるには、(i)MLP幅を固定してパラメータを減らしたモデルと、(ii)削減したQuery重み分をMLPへ再配分し総パラメータを揃えたモデルを分ける必要がある。前者は圧縮の可能性、後者は同じ予算で性能を改善できるかを見る。さらに標準モデル側でMLPを細くした場合とhidden dimensionを減らした場合を比較し、単にパラメータが少ないだけでlossが変わるのか、Query重みの削減が特別なのかを切り分ける。

## 評価条件

| 項目 | 原著の条件 |
|---|---|
| モデル | NanoGPT由来GPT-2/GPT-3-small型、12層、12ヘッド、hidden 768、context 1024、MLP 4dを基準 |
| 学習データ | OpenWebText、約29.5Bトークン、60,000ステップ、1ステップ約49万トークン |
| GPU | NVIDIA RTX 5090 1基、FlashAttention使用 |
| optimizer | AdamW、β1=0.9、β2=0.95、weight decay 0.1、gradient clipping 1.0 |
| LR | 標準6e-4→6e-5、削減型1.6e-3または2.2e-3→2e-5、cosine・2k warmup |
| 評価 | 1000ステップごと、検証2400系列（約2.5Mトークン）の平均loss |
| 公平性 | 全モデルで同一seedから生成した学習・検証batch indexと順序を共有 |
| 限界 | 単一モデル系列・単一GPU・同一データ分布。複数seed、7B以上、下流ベンチは未実施 |

学習データ量はこのモデル規模のChinchilla最適付近より約12倍多く、比較は60kステップの学習率減衰を完了した状態で行う。短時間だけ学習したモデルの一時的なloss差ではない。ただし総学習トークン数が大きいことと、大規模LLMでの性能が証明されたことは別である。

## 評価結果

### 1. 主要validation lossとパラメータ数（Table 2）

| 方式 | 総パラメータ | 非埋込パラメータ | MLP幅 | 60k step val loss |
|---|---:|---:|---:|---:|
| 標準GPT（MLP 4d） | 124.37M | 84.95M | 4d | **2.944** |
| 標準GPT・MLP縮小 | 117.30M | 77.88M | 3.5d | 2.955 |
| 標準GPT・hidden縮小 | 117.92M | 79.73M | 4d | 2.956 |
| **W_Q=I（MLP 4d）** | **117.30M** | **77.88M** | 4d | **2.944** |
| **W_Q=I（MLP 4.5d）** | **124.37M** | **84.95M** | 4.5d | **2.929** |

通常モデルからQuery重みを外すと非埋込パラメータは84.95M→77.88M、差7.07M、約8.3%減となる。総パラメータは124.37M→117.30Mで約5.7%減である。**注意の射影重み25%削減、非埋込約8.3%削減、モデル全体約5.7%削減は別の分母**である。`W_Q=I`の同MLP幅モデルは通常GPTとloss 2.944で一致し、同じ77.88Mの標準MLP縮小モデル2.955より良い。

MLP幅を4.5dへ拡大した`W_Q=I`モデルは、非埋込84.95Mでloss 2.929となり、同パラメータ予算の通常モデル2.944を0.015改善する。ただしこの差は**単一の学習条件におけるvalidation lossの差**であり、MMLUやコード生成の正答率向上、推論速度改善を直接示さない。原著Figure 1は学習曲線を示すが、複数seedのばらつきは報告していない。

### 2. 学習率補正と収束（Section 5・6）

| 設定 | 標準 | W_Q=I（通常MLP） | W_Q=I（拡大MLP） |
|---|---:|---:|---:|
| peak LR | 6×10^-4 | 1.6×10^-3 | 2.2×10^-3 |
| min LR | 6×10^-5 | 2×10^-5 | 2×10^-5 |
| weight decay | 0.1 | 0.1 | 0.1 |
| attention logit scale | 1/sqrt(d_k) | 1/(2sqrt(d_k)) | 1/(2sqrt(d_k)) |

削減型はpeak LRが約2.7〜3.7倍高い。これは`W_Q=I`の方が必ず学習が速いという比較ではなく、**最良の学習率スケジュールが異なる**ことを意味する。min LRも標準より低く、終盤の深い減衰が必要だったと著者らは説明する。よって同一学習率で比較した「Queryは不要」という結果ではなく、学習率を調整した場合の実証である。

### 3. 理論の範囲と実証の範囲（Table 1）

| 対象 | 厳密に言えること | 言えないこと |
|---|---|---|
| 単一ヘッド注意 | W_QとW_Oを積へ吸収し同じ出力を作れる | weight decay付き学習軌跡の同一性 |
| 正規化なし・untied・単一層 | 一層のW_Qを変換して全体出力を保存可能 | 全層W_Qを同時に自由削除できること |
| 正規化なし・MLP skipなし等の多層 | 基底変換を層間へ伝播できる条件を導出 | 標準GPTの全構成を含む一般定理 |
| 実用GPT型のスクラッチ学習 | W_Q=Iで同等のvalidation lossを達成 | 既存checkpointを後処理で同等出力へ変換できること |

特に多層Transformerで残差接続をどう扱うかが数学的な境界である。単一層の「free lunch」を根拠に、全層のQuery重みを単純に消しても元のモデルと出力が一致する、と解釈するのは誤りである。

## 既存研究との差

GQA/MQAはKey/Valueのヘッド共有によってKVキャッシュや射影の重複を減らす。FlashAttentionは注意のメモリアクセスを効率化し、量子化・剪定は学習済みの重みや活性を低精度化・削除する。本研究は**attentionの線形射影に本質的な自由度があるか**を問うもので、計算カーネルを改良するのではなくアーキテクチャのパラメータ化を変える。QとKの積を一つの行列に吸収する単一ヘッドの既知の性質を、多ヘッド・残差・正規化・学習実験へ接続した点が主眼である。

従来の層削除・低ランク圧縮では、学習済みの情報を近似して削るため品質低下と補正学習が課題となる。`W_Q=I`は最初からその自由度を持たずに学習できるかを実験する。したがって事後圧縮ではなく**新規モデル設計の候補**として捉えるのが適切である。LoRAや量子化との併用可能性は理論的に直交するが、併用後の性能を本論文は定量測定していない。

## 限界・負の結果・実装上の示唆

第一に、厳密な理論は可逆性、正規化、MLP skip、重み共有、embedding/headの結合条件に依存する。標準のpre-LayerNorm・層別非共有・MLP残差を持つすべてのTransformerを同一関数へ変換する一般証明ではない。第二に、実証は約117〜124MのGPT型モデル、OpenWebText、単一RTX 5090であり、複数seedの統計、7B以上、MoE、GQAの実機学習、下流タスクの品質比較はない。

第三に、loss 2.944の一致はトークン予測の平均損失が同じという意味であり、個々の生成文、数学推論、コード、長文脈retrievalが一致するわけではない。第四に、`W_Q=I`で必要なlogitスケーリングと高い学習率を調整しなければ、通常GPTの学習設定をそのまま流用した比較にならない。第五に、非埋込パラメータを減らしてもKVキャッシュの長さ・ヘッド数を直接減らすわけではない。推論時のVRAM節約、prefill時間、TTFT、decode TPS、消費電力は未測定である。

モデルを新規に事前学習する場合には、Query射影の削減分をMLP幅や他の構造へ再配分する設計余地がある。一方、既存Llama/Qwenをローカル推論する場合、単に`W_Q`を削除するパッチで同じ結果になるという根拠はない。GQA/MQA、RoPE、QK normalizationなどとの数学的な整合性と、実機の品質・速度は分けて検証する必要がある。
