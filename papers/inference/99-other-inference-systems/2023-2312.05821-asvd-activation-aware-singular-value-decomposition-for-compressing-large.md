# ASVD: Activation-aware Singular Value Decomposition for Compressing Large Language Models

## 概要
活性認識特異値分解（Activation-aware Singular Value Decomposition; ASVD）は、学習済みLLMのlinear weightを再学習なしで低rank化するpost-training compressionである。通常SVDはweight matrixそのもののFrobenius errorを最小化するが、LLMの実際の誤差は `(W_hat-W)X`、すなわち入力activationとの積で決まる。activationにはchannelごとに大きなscale差とoutlierがあるため、weight-spaceでは小さな近似誤差でも重要channelへ掛かると出力を大きく壊す。

ASVDはactivation統計から可逆な列scaleを作り、重要activation channelに対応するweight columnを一旦拡大してからSVDする。さらに各layerを同一rankで切るのでなく、少量calibration sampleで「このlayerをこのrankまで落とすとperplexityがどれだけ悪化するか」を測り、全体parameter budgetの下で層別rankを探索する。LLaMA/LLaMA-2 7B〜13Bで10〜30%のmodel圧縮を示し、K/V projectionにも同じ低rank構造を適用して中間の低次元activationをcacheすることで、KV cacheを50%までほぼ品質低下なしに削減する。

## 問題設定
weight matrix `W∈R^{m×n}` をrank `k` にtruncateする通常SVDは、
`W ≈ U_k Σ_k V_k^T`
としてweight reconstruction error `||W-W_hat||_F` を最小化する。しかしneural networkで重要なのは、calibration input `X` に対するoutput error
`||W_hat X - W X||_F²`
である。activation channelのscaleが一様なら両者は近いが、LLMでは一部channelにoutlierが集中するため、weight-only SVDの「小さい誤差」が実際のfeature spaceでは大きく増幅される。

もう一つの問題はlayer感度差である。論文のprobingではMulti-Head Attention（MHA）のprojectionは比較的低rank化へ強く、MLP layerは敏感な傾向がある。同じcompression ratioを全linear layerへ配ると、敏感layerを削り過ぎる一方、鈍感layerの圧縮余地を使い切れない。

## 手法
### 1. activation-aware weight transform
ASVDはSVDの前に可逆matrix `S` を挿入し、
`W X = (W S)(S^{-1} X)`
と書き換える。まず `W S` をSVDしてtruncateし、最後に `S^{-1}` を右factorへ吸収するため、rankを落とさない極限では元linear transformationと等価である。

最も単純なASVDでは `S` をdiagonalとし、入力channel `i` のcalibration activation絶対値平均から
`S_i = (mean_j |X_{ij}|)^α`
を作る。主実験では `α=0.5`。activation magnitudeの大きいchannelに対応するweight columnを拡大してからSVDすることで、そのcolumnの誤差がtruncated spectrumへ埋もれにくくなる。SVD後にinverse scaleを戻すため、追加trainable parameterを導入するわけではない。

改良版ASVD+ではdiagonal magnitude scaleだけでなくactivation covarianceを使う。 `XX^T = L L^T` のCholesky factor `L` をtransform matrixとして用い、channel間相関まで含むfeature-space metricをweight decompositionへ写す。高compressionではこのASVD+が単純ASVDより安定する。

### 2. 感度別truncation rank探索
各linear layerについて、残存parameter ratio候補を0.1〜0.9等で試し、そのlayerだけ一時的に低rank化したmodelをsmall calibration setへ通してperplexity増加を測る。これによりlayerごとに「rankをどこまで削るとどれだけ悪くなるか」というsensitivity curveを作る。

その後、全体parameter targetを満たすようbinary searchでthresholdを調整し、低感度layerには強いcompression、高感度layerには高rankを割り当てる。各layer effectが概ね独立という近似に基づくためglobal optimum保証ではないが、全layerへ一律rankを与えるnaive SVDより大幅に安定する。実験では32 sample × 2048 tokenのWikiText calibrationだけを用いる。

### 3. KV cache圧縮
key/value projection `W_K,W_V∈R^{N×N}` をrank `r` の二factorへ分解する。通常は各past tokenについて完成したK/V vector `R^N` をcacheするが、factorization後は第一factorまで計算した中間activation `R^r` を保存し、attentionで必要になったとき第二factorを適用する。

系列長を `L` とすると、通常K/V cacheはそれぞれ `L×N`、ASVD後は `L×r` でよく、理論上channel dimension部分を `N/r` 倍圧縮できる。長contextやlarge batchではcache memory/bandwidthが支配的になるため、weight圧縮とは別にinference memoryへ効く。一方、後段factorをattention計算へ組み込む追加演算・kernel実装が必要で、cache容量削減率がそのままlatency改善率になるわけではない。

### 4. 量子化との組合せ
ASVDはmatrixのshape/rankを変える構造圧縮で、weight bit widthを下げる量子化とは直交する。論文ではまずASVDでdecomposeし、そのfactor weightへRTN INT8、AWQ INT8/INT4、NF4を適用する。8-bitでは追加劣化が小さい一方、4-bitでは低rank化とquantization errorが重なり、強いrank compressionほどperplexity劣化が大きくなる。

## 評価条件
対象はLLaMA-7B、LLaMA-2-7B、LLaMA-2-13B。layer sensitivity calibrationにはWikiTextから32 samples、各2048 tokensを使う。品質はWikiText2とPenn Treebank（PTB）のperplexity、MMLU 0-shotを中心に評価する。

parameter compressionではnaive SVD、感度探索だけを追加したSVD*、activation-aware ASVD、covariance-aware ASVD+を比較する。KV cacheではK/V projectionだけをASVD化し、cache ratio 1.0から0.2まで変えてperplexityを測る。量子化併用ではFP16、INT8 RTN/AWQ、NF4、INT4 AWQを比較する。

## 主要結果
### parameter圧縮
naive SVDはわずか5%のparameter削減でも破綻する。LLaMA-7Bでparam ratio 0.95のWikiText2 perplexityはoriginal 5.68に対しnaive SVD 2800、sensitivity rankだけを使うSVD*でも136.05。activation-aware ASVDは5.78まで回復し、MMLUもoriginal 30.76%に対し30.26%を維持する。

LLaMA-2-7Bではoriginal WikiText2 5.47に対し、ASVDはparam ratio 0.95/0.90/0.85で5.64/5.93/6.74。LLaMA-2-13Bはoriginal 4.88に対し4.94/5.12/5.54で、同じratioなら大きいmodelの方が圧縮へ比較的強い。

高compressionではASVD+のcovariance情報が効く。LLaMA-2-13Bでparam ratio 0.70の場合、SVD-LLM 8.00、単純ASVD 20.82に対しASVD+ 7.82。7Bでも0.70でSVD-LLM 10.67、ASVD 159.21、ASVD+ 10.62となり、magnitude-only transformは30%超の強いcompressionで急激に崩れる条件がある。論文の「10〜30%圧縮」は、品質要求に応じてこの安定領域を選ぶという意味である。

### 層別感度
probingではMLP layerの方がMHA projectionより概ね高感度で、layer間にも大きな差がある。最終割当ではweight matrixごとのrank削減量が10〜90%までばらつく。均一ratioではなくこの非一様性を利用することが、同一parameter budgetでperplexityを抑える中心機構である。

### KV cache
LLaMA-2-7BのWikiText2 perplexityはcache ratio 1.0で5.47、0.7で5.50、0.5で5.67、0.4で5.94、0.3で6.55。LLaMA-2-13Bは4.88→4.91→4.96→5.08→5.33。50% cacheでも変化は小さいが、40%未満へ削ると劣化が目立ち始める。

PTBでも7Bは20.82→22.16（ratio 0.5）、13Bは29.21→31.69で、完全無損失ではないが50%近辺までは比較的安定する。したがって「最大50%削減・性能低下なし」というabstract表現は、perplexity変化が小さい範囲を指し、極端な0.2〜0.3 ratioまで安全という意味ではない。

### 量子化併用
LLaMA-2-7B、param ratio 0.90ではWikiText2がFP16 5.93、INT8 RTN 5.94、INT8 AWQ 5.82で、8-bit量子化の追加影響は小さい。NF4 6.20、INT4 AWQ 6.21では劣化が増える。13B同条件はFP16 5.12、INT8 RTN 5.11、INT8 AWQ 5.15、NF4 5.31、INT4 AWQ 5.43。低rank化と8-bit quantizationは比較的独立に重ねられるが、4-bitでは誤差budgetが厳しくなる。

### 計算量
factorized linear layerのmultiply cost比は `(km+kn)/(nm)` で、parameter ratioと一致する。したがって理論上はweight storage・transferだけでなくGEMM計算も減る。ただし論文は専用kernelを用いたend-to-end tokens/sの詳細benchmarkを中心にはしておらず、このFLOP削減が実hardwareで同倍率のspeedupになるとは示していない。

## 既存研究との差
従来SVDはweight reconstruction errorを最小化し、通常はdecomposition後fine-tuningで性能を戻す。ASVDはactivation distributionを可逆transformへ吸収し、calibrationだけでoutput-relevant errorへ近づける。SVD*の結果が示すようにlayer-wise rank allocationだけでも不十分で、activation-aware transformとsensitivity searchの両方が必要になる。

またKV cacheを値そのもののbit量子化で圧縮するのでなく、K/V projectionを低rank化して**保存するvector dimensionそのものをNからrへ減らす**点が特徴である。

## 限界
training-freeだがdata-freeではなく、layer sensitivityとactivation scaleを得るcalibration sampleが必要である。chat modelでは実際のchat distributionに合ったcalibrationが必要で、公式実装も専用calibration datasetがないとsuboptimalになり得ると注意している。

magnitude-based ASVDは強いcompressionで急激に崩れる場合があり、ASVD+のようなcovariance-aware transformが必要になる。layer effectの独立性を仮定したrank searchはglobal interactionを完全には扱わない。低rank化が本質的に合わないweight matrixではcompression余地も小さい。

KV cache方式は容量を減らす代わりに低rank factorをattention pathへ組み込む必要があり、実kernelのthroughput・latency評価は容量結果ほど十分でない。量子化と併用できるが4-bitでは誤差が累積する。したがって10〜30% parameter削減、50% KV削減はmodel・quality targetに依存する安全域であり、任意modelへ無条件に同じ割合を適用できるものではない。
