# ASVD: Activation-aware Singular Value Decomposition for Compressing Large Language Models

## 概要
活性認識特異値分解（活性値-考慮型 特異値分解; ASVD）は、学習済みLLMの線形 重みを再学習なしで低ランク化するpost-学習 圧縮である。通常SVDは重み 行列そのもののFrobenius 誤差を最小化するが、LLMの実際の誤差は `(W_hat-W)X`、すなわち入力活性値との積で決まる。活性値にはchannelごとに大きな規模差とoutlierがあるため、重み-spaceでは小さな近似誤差でも重要channelへ掛かると出力を大きく壊す。

ASVDは活性値統計から可逆な列規模を作り、重要活性値 channelに対応する重み columnを一旦拡大してからSVDする。さらに各層を同一ランクで切るのでなく、少量較正 sampleで「この層をこのランクまで落とすとperplexityがどれだけ悪化するか」を測り、全体パラメータ 予算の下で層別ランクを探索する。LLaMA/LLaMA-2 7B〜13Bで10〜30%のモデル圧縮を示し、K/V 射影にも同じ低ランク構造を適用して中間の低次元活性値をキャッシュすることで、KV キャッシュを50%までほぼ品質低下なしに削減する。

## 問題設定
重み 行列 `W∈R^{m×n}` をランク `k` にtruncateする通常SVDは、
`W ≈ U_k Σ_k V_k^T`
として重み reconstruction 誤差 `||W-W_hat||_F` を最小化する。しかしneural ネットワークで重要なのは、較正 入力 `X` に対する出力 誤差
`||W_hat X - W X||_F²`
である。活性値 channelの規模が一様なら両者は近いが、LLMでは一部channelにoutlierが集中するため、重み-only SVDの「小さい誤差」が実際の特徴 spaceでは大きく増幅される。

もう一つの問題は層感度差である。論文のprobingでは複数-ヘッド 注意（MHA）の射影は比較的低ランク化へ強く、MLP 層は敏感な傾向がある。同じ圧縮 比率を全線形 層へ配ると、敏感層を削り過ぎる一方、鈍感層の圧縮余地を使い切れない。

## 手法
### 1. activation-aware weight transform
ASVDはSVDの前に可逆行列 `S` を挿入し、
`W X = (W S)(S^{-1} X)`
と書き換える。まず `W S` をSVDしてtruncateし、最後に `S^{-1}` を右factorへ吸収するため、ランクを落とさない極限では元線形 変換と等価である。

最も単純なASVDでは `S` をdiagonalとし、入力channel `i` の較正 活性値絶対値平均から
`S_i = (mean_j |X_{ij}|)^α`
を作る。主実験では `α=0.5`。活性値 magnitudeの大きいchannelに対応する重み columnを拡大してからSVDすることで、そのcolumnの誤差がtruncated spectrumへ埋もれにくくなる。SVD後にinverse 規模を戻すため、追加trainable パラメータを導入するわけではない。

改良版ASVD+ではdiagonal magnitude 規模だけでなく活性値 covarianceを使う。 `XX^T = L L^T` のCholesky factor `L` をtransform 行列として用い、channel間相関まで含む特徴-space 指標を重み 分解へ写す。高圧縮ではこのASVD+が単純ASVDより安定する。

### 2. 感度別truncation rank探索
各線形 層について、残存パラメータ 比率候補を0.1〜0.9等で試し、その層だけ一時的に低ランク化したモデルをsmall 較正 setへ通してperplexity増加を測る。これにより層ごとに「ランクをどこまで削るとどれだけ悪くなるか」というsensitivity curveを作る。

その後、全体パラメータ targetを満たすようbinary searchで閾値を調整し、低感度層には強い圧縮、高感度層には高ランクを割り当てる。各層 影響が概ね独立という近似に基づくため大域 optimum保証ではないが、全層へ一律ランクを与えるnaive SVDより大幅に安定する。実験では32 sample × 2048 トークンのWikiText 較正だけを用いる。

### 3. KV cache圧縮
キー/値 射影 `W_K,W_V∈R^{N×N}` をランク `r` の二factorへ分解する。通常は各past トークンについて完成したK/V ベクトル `R^N` をキャッシュするが、factorization後は第一factorまで計算した中間活性値 `R^r` を保存し、注意で必要になったとき第二factorを適用する。

系列長を `L` とすると、通常K/V キャッシュはそれぞれ `L×N`、ASVD後は `L×r` でよく、理論上channel dimension部分を `N/r` 倍圧縮できる。長文脈やlarge バッチではキャッシュ メモリ/帯域が支配的になるため、重み圧縮とは別に推論 メモリへ効く。一方、後段factorを注意計算へ組み込む追加演算・カーネル実装が必要で、キャッシュ容量削減率がそのまま遅延改善率になるわけではない。

### 4. 量子化との組合せ
ASVDは行列のshape/ランクを変える構造圧縮で、重み bit widthを下げる量子化とは直交する。論文ではまずASVDでdecomposeし、そのfactor 重みへRTN INT8、AWQ INT8/INT4、NF4を適用する。8-bitでは追加劣化が小さい一方、4-bitでは低ランク化と量子化 誤差が重なり、強いランク 圧縮ほどperplexity劣化が大きくなる。

## 評価条件
対象はLLaMA-7B、LLaMA-2-7B、LLaMA-2-13B。層 sensitivity 較正にはWikiTextから32 samples、各2048 トークンを使う。品質はWikiText2とPenn Treebank（PTB）のperplexity、MMLU 0-shotを中心に評価する。

パラメータ 圧縮ではnaive SVD、感度探索だけを追加したSVD*、活性値-考慮型 ASVD、covariance-考慮型 ASVD+を比較する。KV キャッシュではK/V 射影だけをASVD化し、キャッシュ 比率 1.0から0.2まで変えてperplexityを測る。量子化併用ではFP16、INT8 RTN/AWQ、NF4、INT4 AWQを比較する。

## 主要結果
### parameter圧縮
naive SVDはわずか5%のパラメータ削減でも破綻する。LLaMA-7Bでparam 比率 0.95のWikiText2 perplexityはoriginal 5.68に対しnaive SVD 2800、sensitivity ランクだけを使うSVD*でも136.05。活性値-考慮型 ASVDは5.78まで回復し、MMLUもoriginal 30.76%に対し30.26%を維持する。

LLaMA-2-7Bではoriginal WikiText2 5.47に対し、ASVDはparam 比率 0.95/0.90/0.85で5.64/5.93/6.74。LLaMA-2-13Bはoriginal 4.88に対し4.94/5.12/5.54で、同じ比率なら大きいモデルの方が圧縮へ比較的強い。

高圧縮ではASVD+のcovariance情報が効く。LLaMA-2-13Bでparam 比率 0.70の場合、SVD-LLM 8.00、単純ASVD 20.82に対しASVD+ 7.82。7Bでも0.70でSVD-LLM 10.67、ASVD 159.21、ASVD+ 10.62となり、magnitude-only transformは30%超の強い圧縮で急激に崩れる条件がある。論文の「10〜30%圧縮」は、品質要求に応じてこの安定領域を選ぶという意味である。

### 層別感度
probingではMLP 層の方がMHA 射影より概ね高感度で、層間にも大きな差がある。最終割当では重み 行列ごとのランク削減量が10〜90%までばらつく。均一比率ではなくこの非一様性を利用することが、同一パラメータ 予算でperplexityを抑える中心機構である。

### KV cache
LLaMA-2-7BのWikiText2 perplexityはキャッシュ 比率 1.0で5.47、0.7で5.50、0.5で5.67、0.4で5.94、0.3で6.55。LLaMA-2-13Bは4.88→4.91→4.96→5.08→5.33。50% キャッシュでも変化は小さいが、40%未満へ削ると劣化が目立ち始める。

PTBでも7Bは20.82→22.16（比率 0.5）、13Bは29.21→31.69で、完全無損失ではないが50%近辺までは比較的安定する。したがって「最大50%削減・性能低下なし」というabstract表現は、perplexity変化が小さい範囲を指し、極端な0.2〜0.3 比率まで安全という意味ではない。

### 量子化併用
LLaMA-2-7B、param 比率 0.90ではWikiText2がFP16 5.93、INT8 RTN 5.94、INT8 AWQ 5.82で、8-bit量子化の追加影響は小さい。NF4 6.20、INT4 AWQ 6.21では劣化が増える。13B同条件はFP16 5.12、INT8 RTN 5.11、INT8 AWQ 5.15、NF4 5.31、INT4 AWQ 5.43。低ランク化と8-bit 量子化は比較的独立に重ねられるが、4-bitでは誤差予算が厳しくなる。

### 計算量
factorized 線形 層のmultiply コスト比は `(km+kn)/(nm)` で、パラメータ 比率と一致する。したがって理論上は重み storage・transferだけでなくGEMM計算も減る。ただし論文は専用カーネルを用いたエンドツーエンド トークン/sの詳細ベンチマークを中心にはしておらず、このFLOP削減が実ハードウェアで同倍率の高速化倍率になるとは示していない。

## 既存研究との差
従来SVDは重み reconstruction 誤差を最小化し、通常は分解後fine-tuningで性能を戻す。ASVDは活性値 分布を可逆transformへ吸収し、較正だけで出力-relevant 誤差へ近づける。SVD*の結果が示すように層-wise ランク allocationだけでも不十分で、活性値-考慮型 transformとsensitivity searchの両方が必要になる。

またKV キャッシュを値そのもののbit量子化で圧縮するのでなく、K/V 射影を低ランク化して**保存するベクトル dimensionそのものをNからrへ減らす**点が特徴である。

## 限界
学習不要だがデータ不要ではなく、層 sensitivityと活性値 規模を得る較正 sampleが必要である。chat モデルでは実際のchat 分布に合った較正が必要で、公式実装も専用較正 データセットがないとsuboptimalになり得ると注意している。

magnitude-based ASVDは強い圧縮で急激に崩れる場合があり、ASVD+のようなcovariance-考慮型 transformが必要になる。層 影響の独立性を仮定したランク searchは大域 interactionを完全には扱わない。低ランク化が本質的に合わない重み 行列では圧縮余地も小さい。

KV キャッシュ方式は容量を減らす代わりに低ランク factorを注意 経路へ組み込む必要があり、実カーネルのスループット・遅延評価は容量結果ほど十分でない。量子化と併用できるが4-bitでは誤差が累積する。したがって10〜30% パラメータ削減、50% KV削減はモデル・品質 targetに依存する安全域であり、任意モデルへ無条件に同じ割合を適用できるものではない。
