# SANE：極端な長文脈で再帰状態の局所発散を抑えるチャンク境界の状態圧縮

## 概要

SANE（State Anomaly Neutralization、状態異常の中和）は、差分規則（Delta Rule）に基づく再帰型言語モデルの**固定サイズ状態が数千万トークンの入力後に数値発散し、推論能力を失う**現象を診断し、その発生を抑える研究である。Transformerの鍵・値キャッシュ（KV cache）は入力長に比例して増えるが、RWKV-7のようなモデルは固定サイズの行列を更新して過去の情報を保持する。そのため保存量は文脈長に依存しない。ただし、記憶容量が一定であることは状態値が有限のまま推移する保証にはならない。

著者らはRWKV-7の約4億パラメータのモデルで、学習時の4096トークンを大幅に超える系列を流し、行列の一部のヘッド・チャネルだけが大きくなることを観測した。状態全体が一様に飽和するのではなく、小さな値が多い背景の上に局所的な異常値が形成される。SANEはこの形状に合わせ、**各チャンク末尾の状態行列を、入力に応じたヘッド別のしきい値で滑らかに圧縮**する。チャンク内部の並列計算を変えず、次チャンクへ渡す状態だけを修正する。

元のRWKV-7は約2000万トークンで状態ノルムが10の19乗を超え、評価中に数値オーバーフローした。対してSANEを導入したモデルは、約1億トークンを読ませた後でも、しきい値係数3～5の範囲で数学推論11課題の平均正答率33.46～35.56を示した。短文脈での基準モデルの平均正答率は43.88であり、**超長文脈でも完全な精度維持ではない**。さらに係数8以上では数値上は安定しているのに正答率が0.15以下へ崩壊した。論文の重要な結論は「数値発散を防ぐこと」と「情報を利用して推論できること」を別々に測らなければならない点にある。

## 問題設定：一定容量の状態が発散する理由

### 固定サイズの再帰状態とチャンク並列性

再帰型モデルは、時刻`t`で行列`S_t`を保持し、前時刻の状態に遷移行列`M_t`を掛けてから、現在のトークンに由来する情報`K_t`を加える。原著の基本式は`S_t = S_{t-1} M_t + K_t`である。行列の大きさが一定なら、何トークン処理しても過去の全トークンのKV対を保存する必要はない。これは保存量についての性質であり、行列の各要素の絶対値が有界であるという主張ではない。

この更新は、二つの連続した変換を`(M_a M_b, K_a M_b + K_b)`に合成でき、結合法則が成立する。チャンク内部では、この合成を並列前置走査（associative scan）で計算できる。原著のRWKV-7実装ではチャンク幅は16トークンで、チャンク末尾の状態を次チャンクの初期値へ引き継ぐ。SANEが割り込むのは**この引継ぎ点だけ**である。したがって16トークン内の並列計算を保持できるが、非線形圧縮をまたいで複数チャンクを一つのアフィン変換に畳み込むことはできない。

RWKV-7の遷移行列は`M_t = diag(w_t) + z_t^T b_t`、注入項は`K_t = v_t^T k_t`である。対角減衰`diag(w_t)`は既存状態を縮小し、二つの外積はそれぞれ階数1の遷移補正と注入を行う。小さな更新しか受けない方向は減衰で小さく保たれる一方、特定方向に注入が集中し、遷移の増幅が減衰を上回れば、局所的に状態値が蓄積する。この説明はオンライン確率的勾配降下法とL2正則化との類推に基づく**機構解釈**であり、すべての差分規則モデルで同じ疎な背景が必ず成立するという証明ではない。

### 原著の診断観測

学習長4096トークン以内では、状態行列の大半の値は絶対値0.1未満で、一部のみ10～20程度になる。約52.8万トークンでは特定ヘッドに高い値が現れ、150万トークンではその領域が強まり、1000万トークンでは表示上限100を超える値が複数層へ広がった。基準モデルの状態フロベニウスノルムは約2000万トークン付近で10の19乗を超え、数値オーバーフローが起きた。局所的な言語モデルの困惑度（perplexity、低いほど予測がよい）も悪化する。状態ノルムの大きさと推論機能の低下は同時に観測されるが、両者の因果関係を全モデルについて証明したわけではない。

ここでいう「相対的な疎性」はゼロ要素の多さではない。小さい値の背景と、非常に大きな少数の値が同居する分布の偏りを指す。したがって全要素を一律に小さくすればよいわけではない。大きい値の中には学習済みの有効な特徴もあり、それを消すと短文脈の能力を壊す可能性がある。この二面性がしきい値の設計と評価の核心になる。

## 手法

### 1. チャンク境界の滑らかな圧縮

SANEはチャンク`c`の終了時、各ヘッド`h`の状態行列`S_end^(c,h)`に対し、要素ごとに`S̃ = τ_h tanh(S/τ_h)`を適用する。`τ_h`は正のしきい値である。絶対値がしきい値より十分小さいとき`τ tanh(S/τ)`はほぼ元の`S`に等しく、`|S|/τ=0.1`では相対誤差は約0.3%である。大きい値は徐々に圧縮され、極端な値では出力が`±τ`に近づく。符号を保ち、硬い切断点を持たずに状態の異常な増大を弱める。

この変換は行列の各要素に独立して作用し、同じヘッド内ではしきい値を共有する。ヘッド間では異なるしきい値を選べるため、観測された「異常値の集中位置がヘッドごとに異なる」という現象に対応する。**状態の重要度を学習して個別要素を削除する枝刈り手法ではない**。入力と状態値の大きさから、次チャンクへ渡す数値を非線形に変形する安定化機構である。

### 2. 入力依存のしきい値生成

しきい値は、現在チャンクの最後のトークンの隠れ表現`x_τ`と学習可能な射影`W_τ`から`τ_h = α softplus(x_τ W_τ^(h)) + 1`で計算する。`softplus`と定数1により正の値を確保し、`α`が圧縮の強さを調整する。`W_τ`はゼロ初期化されるので初期値は約`0.69α+1`である。教師あり微調整により、チャンクの入力表現に応じて各ヘッドのしきい値が変わる。

係数`α`が小さいと圧縮が強く、大きいと大きな状態値をそのまま通しやすい。強すぎる圧縮は本来必要な高活性を損ない、弱すぎる圧縮は初期の異常値を十分に抑えられない。原著は`α=1,2,...,10`の10構成を同じ基盤モデル・学習データ・評価条件で比較し、この妥協点を実験的に決めた。推奨域3～5は実験結果から選ばれた範囲であり、別モデルでも自動的に成立する保証ではない。

### 3. チャンク計算との接続と境界での上界

処理順は、入力16トークンを通常のRWKV-7のアフィン再帰で処理し、チャンク末尾の状態と最終トークン表現を得て、ヘッド別の`τ_h`を算出し、状態行列に`tanh`圧縮を施し、圧縮済み状態を次のチャンクへ渡す、というものである。圧縮はチャンクの**内部**の遷移式を変更しないため、並列前置走査の計算深さ`O(log C)`は維持される。

`tanh`の絶対値が1以下であることから、変換後の行列要素は`|S̃_ij|≤τ_h`、`d×d`行列のフロベニウスノルムは`||S̃||_F≤dτ_h`を満たす。ただし`τ_h`自体は入力依存の`softplus`から生まれ、全入力に共通する固定上界を持たない。この不等式は**実際に算出されたしきい値に対するチャンク境界での局所的な制約**であり、任意の系列長・入力に対する厳密な一様有界性の証明ではない。さらに、上界の存在は数学的な推論能力の保持を保証しない。

### 4. 追加計算とメモリ

追加パラメータは各層の`d_model×H`射影行列としきい値枝のトークンシフト係数で、RWKV-7 0.4Bでは約39万、元モデルの0.1%未満である。チャンクあたりの追加演算量は`O(d_model H + H d²)`、トークンあたりに均すと`O((d_model H + H d²)/C)`となる。状態を置換する実装なら系列長に比例したキャッシュは不要だが、しきい値`H`個と一時的な状態サイズの作業領域は必要になり得る。

この論文は理論的な計算量と追加パラメータ数を示す一方、**実際の端から端までのトークン処理速度、GPU使用率、遅延増分を詳細には実測していない**。したがって「ほぼ追加費用なし」を速度測定済みの結果として扱うことはできない。チャンク間の非線形処理は、実装によってはGPUカーネル起動や同期の費用を生む可能性がある。

## 評価

### 評価設定

実験は同じ事前学習済み`RWKV-7-0.4B-G1D`から開始した基準モデル1個とSANEの`α=1～10`の10モデルで行う。学習環境はNVIDIA RTX 4090を4基、Keras 3とJAXを使用し、混合bfloat16精度で教師あり微調整する。学習用データは数学推論を中心に約237万の教師あり事例から構成し、系列長は4096（自己回帰学習の入力・目標のずれを含めて4097）を上限とする。学習は1エポック、バッチサイズ48、学習率は`1e-7`から最大`5e-5`へウォームアップして余弦減衰する。元モデルとSANEの違いは追加モジュールと`α`に制御されている。

超長文脈の入力は、DeepMath-103Kから作った約1000万トークンの英語数学文書列`english_math_chat`と、DeepMath-103Kと中国語の数学推論データを混合した約1億トークンの`mixed_chat`である。**1億トークンを丸ごと正確に記憶できるかの試験ではない**。長い前置き入力で状態を更新した後に、別の数学問題を解けるかという、推論機能の生存試験である。

数学推論はGSM8K、MATH-500、ASDiv、SVAMP、CMATH、CollegeMath、GAOKAO Math QAなど合計11課題で評価する。復号は`top-p=0.8`、`top-k=20`、温度1.0の確率的サンプリングで、問題ごとに8回答を生成し多数決（maj@8）で最終回答を決める。報告値は11課題の平均正答率であり、単発の貪欲復号精度ではない。基準モデルが1億トークン時点でNaNになるため、その条件では数値比較できる基準正答率は存在しない。

### 評価結果

### しきい値と短文脈・1億トークン後の推論品質

原著表1の11数学課題の平均正答率を、短文脈と約1億トークンの前置き入力後で対応付ける。`—`は基準モデルが数値発散して評価不能であることを表す。

| モデル・係数 | 短文脈の平均正答率 | 1億トークン後の平均正答率 | 主な読み取り |
|---|---:|---:|---|
| 基準RWKV-7 | 43.88 | — | 長文脈では数値オーバーフロー |
| SANE α=1 | 41.53 | 37.40 | 長文脈で最も高いが短文脈の劣化が有意 |
| SANE α=2 | 42.68 | 35.77 | 短文脈で有意な劣化 |
| SANE α=3 | 43.58 | 35.56 | 短文脈の有意差なし、推奨域で最高 |
| SANE α=4 | 43.75 | 34.72 | 短文脈の有意差なし、長文脈でも機能保持 |
| SANE α=5 | 43.46 | 33.46 | 短文脈の有意差なし、長文脈でも機能保持 |
| SANE α=6 | 43.30 | 24.48 | 長文脈の推論能力が急落 |
| SANE α=7 | 43.88 | 18.45 | 数値安定でも機能低下が大きい |
| SANE α=8 | 44.14 | 0.15 | 数値発散しないが推論機能はほぼ消失 |
| SANE α=9 | 44.16 | 0.03 | 同上 |
| SANE α=10 | 44.23 | 0.03 | 同上 |

短文脈では係数3以上の構成と基準モデルとの対応のあるt検定において、いずれも有意差は報告されていない（`p≥0.154`）。対して係数1は`p<0.001`、係数2は`p=0.006`で有意な悪化がある。ただし「有意差なし」は厳密な非劣性の証明ではなく、11課題の平均値の比較において差を検出できなかったことを意味する。論文は係数5と10の短文脈精度差について`p=0.038`も報告し、圧縮が有効特徴に影響する可能性を指摘している。

長文脈では、係数1は最も高い37.40を示すが、短文脈の劣化を伴う。短文脈を大きく損なわない範囲で見ると、係数3が35.56で最良であり、係数4が34.72、係数5が33.46と続く。係数6と7ではそれぞれ24.48、18.45へ急減し、係数8以上では0.15以下となる。この結果は単に大きな状態値を抑えれば十分なのではなく、**異常な値が蓄積する初期段階で適切に圧縮する必要**があることを示唆する。

### 困惑度と状態値の推移

原著図4では、基準モデルの1000万トークン級`english_math_chat`で累積困惑度が約175まで上昇し、1億トークン級`mixed_chat`では約2000万トークンを超えるとNaNが生じる。SANEの係数5は1億トークンまで累積困惑度がほぼ横ばいで、状態の大部分が絶対値1未満に収まる。係数10でも困惑度は有限のままだが、係数5より高い水準に落ち着き、最終的な数学推論はほぼ不能になる。**困惑度の有限性と、推論の正答率は別指標**として扱うべきである。

状態の可視化（図2、図5）では、基準モデルは52.8万→150万→1000万トークンの進行に伴って一部ヘッドの高活性領域が拡大する。SANE係数5では約1000万トークンでも大きな発散領域が現れない。図だけではすべてのヘッドの機能的重要度を特定できず、局所異常値が直接どの推論誤りを引き起こしたかの介入的因果実験までは示されていない。

### 構成要素と感度の解釈

本論文で主要な感度評価は`α=1～10`の10点走査である。別の状態圧縮関数、しきい値を固定した場合、ヘッド共有しきい値、チャンク幅変更を体系的に並べた比較表は、読解した原著の評価節には示されていない。したがって「入力適応」「ヘッド別」「tanh」の個々の寄与を完全に切り分けたとまでは言えない。係数8以上は、**数値安定だけでは品質を保証できない**という破壊的な対照条件として重要である。

## 限界・負の結果と適用条件

第一に、検証はRWKV-7の0.4Bモデルに限定される。別の差分規則モデル、数十億パラメータ規模、Transformerとの混成構成、商用サービング負荷への外挿は未実証である。特に元のDelta-Netのように同じ減衰構造を持たない方式で「小さな背景と局所発散」という状態分布が成立するかは不明である。

第二に、長文脈の試験は数学テキストを大量に連結した合成系列を用いる。実際の長い会話やコードベースを正確に検索・記憶する能力を示したものではなく、長文脈入力後に数学問題を解けるかという機能維持に主眼がある。約1億トークンの処理は、4096トークンの学習長の約2万4000倍以上に相当するが、**利用可能な意味的記憶容量が2万4000倍へ増えたことは意味しない**。

第三に、SANEは事前学習済みモデルへ教師あり微調整で導入しており、無学習で適用する方式ではない。追加パラメータの規模は小さいが、学習データと計算資源を要する。論文は学習開始時からSANEを組み込んだ場合の優劣を測っていない。推論処理量・遅延の端から端までの実測もなく、既存のRWKV推論器へ適用する際の性能損益は未確定である。

第四に、係数8以上では数値的に安定でも推論精度が0.15以下に崩れる。係数1～2では短文脈精度が有意に低下する。従って係数3～5の選択は単なる数値安定性の基準ではなく、短文脈精度と超長文脈での機能維持の双方を測った結果である。実運用で異なる入力分布やモデルを使う場合は、この感度曲線を再取得する必要がある。

第五に、論文の分析節では相対的な疎性について**機構的解釈であって一般保証ではない**と明記する一方、限界節ではSGD+L2の部分集合で「疎な背景の理論的保証」を示唆する記述がある。提示された観測・式から他モデルでの厳密な疎性保証を独立に導くことはできないため、本稿では一般化可能性を未検証と扱う。この表現差を、他のDelta-Ruleモデルへの効果が既に証明されたものと解釈しない。

## 既存研究との違い・サーベイでの位置づけ

Transformerの長文脈研究では位置埋め込みの外挿、疎注意、KVキャッシュ圧縮が主要な論点になる。SANEはこれらと異なり、**文脈長に依存しない固定サイズの再帰状態が時間発展の中で数値的に不健全になる**問題に焦点を当てる。チャンク内部の並列計算を維持しながら、チャンク間で運ぶ状態だけを非線形に補正する設計は、差分規則型モデルの推論・学習実装へ直接関係する。

本研究を「長文脈の記憶性能改善」や「KVキャッシュ削減」と同一視すべきではない。保存量はもともと系列長に依存しないため、主な貢献は**固定容量状態の安定化と、機能的な生存性を測る評価設計**にある。特に、係数10で数値発散を防いでも数学推論がほぼゼロになる結果は、長文脈推論基盤の検証において、NaNの有無や困惑度だけでなく、前置き入力後の具体的な課題性能を測る必要を示している。
