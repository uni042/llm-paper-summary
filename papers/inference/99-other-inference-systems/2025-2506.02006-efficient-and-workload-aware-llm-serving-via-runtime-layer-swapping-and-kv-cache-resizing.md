# MorphServe: Efficient and Workload-Aware LLM Serving via Runtime Quantized Layer Swapping and KV Cache Resizing

> 負荷ピーク時だけ低影響層を低ビット版へ非同期交換し、空いたGPUメモリをKVキャッシュへ振り替えることで、平均SLO違反を92.45%削減しP95初回トークン遅延を2.2〜3.9倍改善する。

- **著者**: Zhaoyuan Su, Zeyu Zhang, Tingfeng Lan, Zirui Wang, Haiying Shen, Juncheng Yang, Yue Cheng
- **著者・所属**: University of Virginia; Harvard University
- **公開**: arXiv preprint; MLSys 2026 Oral
- **種別**: 会議発表 / プレプリント
- **対象**: LLMサービング、実行時量子化、KVキャッシュ、GPUメモリ弾力化、サービス品質目標
- **実装**: 論文ではSwiftLLM上に約2,200行のPythonと約500行のC++/CUDAで実装したと説明する。一方、公開GitHubリポジトリは2026-09-14確認時点でREADMEとライセンス中心で、完全な実装コードは公開準備中と明記されている。
## 概要
動的でバースト性の高いLLMサービングでは、固定フル精度構成はピーク時にGPUメモリを重みが占有してKVキャッシュ不足と待ち行列を招く一方、静的量子化は低負荷時にも品質低下を払い続ける。MorphServeは、負荷上昇時だけ影響の小さいTransformer層をFP16からW8/W4等へ非同期交換し、解放したGPUメモリをKVキャッシュへ再配分する。負荷低下時には高精度層を戻し、品質低下を必要な期間とトークンへ限定する。Azure LLM InferenceとBurstGPTの実負荷トレース、Vicuna/Llama/CodeLlama系モデルで、平均SLO違反を92.45%削減し、精度重視設定でもP95初回トークン遅延を2.2〜3.9倍改善した。

MorphServeは量子化を固定モデル変換ではなく一時的な実行時資源操作として扱い、重み精度とKV容量を同じGPUメモリ予算内で交換する。オフラインで層重要度スコア（層 Importance Score; LIS）を作り、負荷上昇時に影響の小さい層からFP16をW8/W4等へ段階的に交換する。重み縮小で生じた空きメモリをKVResizerが即座にPagedAttentionのKVページへ転用し、負荷低下時には逆方向へ戻す。層交換とKV再割当は別CUDAストリームで進め、処理中要求のKV状態と生成位置を維持するため、モデルのフラッシュや再プリフィルを不要にする。
## 問題設定
実運用のLLMトラフィックは到着率、入力長、出力長が時間とともに大きく変動する。固定フル精度構成ではモデル重みがGPUメモリを恒常的に占有するため、低負荷時には十分な空きがある一方、負荷ピークでKVキャッシュ用ページが不足すると新規プリフィルが待たされ、デコード中要求もプリエンプトされてKV退避や再計算を招く。単純にKV領域を大きく予約すればモデル配置や並列度を圧迫し、逆にモデルを静的INT4へ量子化するとピーク以外の大半の時間まで恒常的な品質低下を受ける。最悪負荷に合わせてGPU台数を過剰配置する方法はSLOを守れてもコスト効率が悪く、KV圧縮や固定メモリ区画だけでは『品質を保ちたい平常時』と『容量を増やしたいピーク時』を同一構成で満たしにくい。必要なのは、既に進行中の要求やKV状態を壊さず、重み精度とKV容量の境界を負荷圧力に応じて実行中に動かし、圧力が去れば元の高精度状態へ戻せる仕組みである。
## 新規性
MorphServeは量子化を固定モデル変換ではなく一時的な実行時資源操作として扱い、重み精度とKV容量を同じGPUメモリ予算内で交換する。オフラインで層重要度スコア（層 Importance Score; LIS）を作り、負荷上昇時に影響の小さい層からFP16をW8/W4等へ段階的に交換する。重み縮小で生じた空きメモリをKVResizerが即座にPagedAttentionのKVページへ転用し、負荷低下時には逆方向へ戻す。層交換とKV再割当は別CUDAストリームで進め、処理中要求のKV状態と生成位置を維持するため、モデルのフラッシュや再プリフィルを不要にする。
## 手法
### 手法のあらまし
事前準備では、対象モデルの各Transformer層について層変換感度、量子化層置換感度、モデル全体の劣化感度を校正データ上で測定し、それらを重み付き合成したLISを作る。これにより、品質影響の小さい層から先にFP16→W8→W4へ交換できる順位を決める。同時に各精度の重みバリアントと対応カーネルを準備し、CPUの固定済みメモリへ保持する。実行開始後はServing MonitorがGPUメモリ使用量、KVページ使用率、待ち行列深度、初回トークン遅延、トークン間遅延などを継続観測し、平滑化した指標をMorphing Controllerへ渡す。負荷が低い間は全層を高精度のまま実行する。圧力が閾値を超えるとControllerは必要な追加メモリ量を見積もり、LIS順位に従って影響の小さい層を一つずつ低精度バリアントへ切り替える。LayerSwapperは選択層の低精度重みをCPUからGPU上の事前確保済み同一位置へcudaMemcpyAsyncでコピーし、専用CUDAストリーム上で通常のデコード計算と重ねるため、モデル全体のアンロードやポインタ再構築を行わない。交換が完了すると、その層で不要になった重み領域分だけGPUメモリが解放される。KVResizerはこの空き容量をPagedAttentionのページプールへ追加し、新規プリフィルを受け入れるページや進行中デコード要求の将来KVページとして利用する。これにより待機要求を早く開始でき、KV不足によるプリエンプションと再計算も減らす。さらに負荷が上がれば追加層を段階的に低精度化し、必要以上に品質を下げない。反対に待ち行列とKV圧力が下がると、余剰KVページを安全に回収し、そのメモリを高精度重みへ戻して低ビット層を逆順に復元する。各変形はトークン境界で行われ、既存要求のKV内容と生成位置を保持するため、同一要求が平常時はFP16、ピーク区間だけ低精度、圧力解消後は再びFP16で継続することもできる。この閉ループにより、入力となる実負荷観測から精度段階の選択、非同期層交換、KV容量拡張、要求処理、負荷低下時のKV縮小と高精度復帰までを一つの実行時制御として結び付ける。

### 層重要度に基づく交換順
すべての層を一様に量子化すると、同じ節約メモリでも品質低下が大きい層まで早期に低精度化される。MorphServeは層変換感度、量子化層置換感度、モデル全体の劣化感度を余弦類似度などから計測し、LIS=0.25LTS+0.25LRS+0.5MDSとして順位を作る。実行時にはこの順位を使って品質影響が比較的小さい層から段階的に交換し、必要なメモリが確保できた時点で止める。完全なプロファイルは32層モデルで単一GPU約15分未満と報告され、オンライン制御では再計算せず固定順位を参照する。プロファイルがない新規モデルでは前方から後方への単純な順位へ退化できるため、最適性と展開容易性を分離している。

### 非同期同一位置レイヤ交換
実行時にモデル全体を再ロードすると秒単位の停止やポインタ更新が発生してサービングへ使えないため、MorphServeはFP16、W8、W4など複数精度の層バリアントをCPUの固定済みメモリへ待機させ、GPU側では各層の最大サイズに合わせた領域を事前確保する。変形時は対象層だけをcudaMemcpyAsyncで同じGPUアドレスへ上書きし、別CUDAストリームでデコードと重畳する。精度別計算カーネルも事前に用意されるため、交換後は対応カーネルへ切り替えるだけで処理を続けられる。Llama 2 7BのINT4層では完全交換が約6msとされ、全モデル停止を避けながら数層ずつ段階的にメモリを回収できる。

### 圧力対応KVキャッシュ伸縮
量子化で生まれた空きメモリを単なる未使用領域にせず、PagedAttentionのKVページプールへ即時に転用するのがMorphServeの容量改善の中心である。KVResizerは利用中ページを保持したまま追加ページを割り当て、新規要求のプリフィルや進行中デコードの将来トークンへ使える容量を増やす。これにより待機時間だけでなく、KV不足で既存要求をプリエンプトして退避・再計算する頻度も減らす。圧力が下がると未使用ページから回収して重み復元用の領域へ戻すため、KV容量は固定の予約値ではなく現在負荷に連動する。KV内容そのものを量子化・圧縮しないので、容量節約は重み側から捻出し、既存セッション状態の表現を変更しない。

### 負荷監視制御ループ
変形を常時行うとPCIe転送と品質低下が無駄になるため、Serving MonitorがGPUメモリ、KV使用率、待ち行列深度、TTFT、TPOTを継続収集し、短時間ノイズを平滑化した圧力指標をControllerへ渡す。Controllerは閾値とヒステリシスを使って量子化段階を上げ下げし、必要容量が増えた時だけ次の層を低精度化する。負荷が解消すればKVページを減らして高精度層を復元し、低負荷期間に静的INT4の品質損失を払い続けることを避ける。トークン境界で変形するため、進行中要求を破棄せず同じセッションの途中で精度段階を変更できる。制御は将来需要の予測ではなく現在圧力への反応型であり、誤予測モデルを必要としない。

### 全体のデータ／制御の流れ
監視器、全体制御器、各GPUの実行器からなる。CPU側を複数精度重みの待機階層、GPU側を実行重みとKVキャッシュが共有する可変容量階層として使い、負荷に応じて両者の境界を動かす。
## 評価条件
- **ハードウェア**: NVIDIA L4 24GB、NVIDIA A100 80GB、CPU DRAM 256GB/2TB
- **ソフトウェア**: SwiftLLMベースのMorphServe、PagedAttention拡張、FlashAttention互換、AWQ INT4重み
- **モデル**: Vicuna 7B v1.5、Llama 2 7B、Llama 3 8B、CodeLlama 34B
- **データセット／トレース**: GovReport、QMSum、DuReader、Multi-News、BookSum Chapters
- **比較対象**: フル精度FP16固定サービング、静的AWQ INT4、静的一様INT4
- **正確性・品質**: 形態変換中も処理中要求のKV状態と生成位置を維持するため、再プリフィルやセッション破棄を伴わない。一方、低精度層を通過したトークンには量子化誤差があり完全無損失ではないため、F1とROUGE-Lで品質を明示的に測定する。
- **実負荷再生**: Azure LLM InferenceとBurstGPTから各72秒区間を使い、ハードウェア規模に合わせ到着率をそれぞれ4.75倍、1.75倍に縮小してバースト負荷を再現する。
- **モデル別長さ設定**: Vicuna 7B/Llama 2 7Bでは入力512・出力256トークン、Llama 3 8B/CodeLlama 34Bでは入力1024・出力512トークン。追加の混合精度品質試験ではBookSum Chaptersの6K入力/2K出力も用いる。
- **評価指標**: TTFTのP95、TPOTの平均/P95/P99、SLO違反率、飽和処理量、KV容量、F1、ROUGE-Lを測り、遅延・容量・品質の三者を同時比較する。
- **層交換プロファイル**: LISを用いた交換順をヒューリスティックな前方順、後方順、ランダム順と比較し、WikiText-2校正からC4への一般化も評価する。
異なる注意機構とモデル規模を含む4モデル、2種類の実トラフィック、複数の要約・読解データセットを組み合わせ、負荷上昇に対する遅延とSLOだけでなく、動的量子化が生成品質へ与える影響と各機構のアブレーションを測る。
主評価は単一GPU上の7B〜34B級モデルで、分散実行への適用は議論に留まる。数百B級モデル、MoE、異種GPU群、低帯域PCIe環境は直接評価していない。
## 主要結果
MorphServeは、負荷ピーク時だけ品質影響の小さい層を低精度へ切り替え、その瞬間に空いたGPU重み領域をKVキャッシュへ振り替えることで、固定フル精度構成より同時実行容量を増やし、待ち行列とKV不足プリエンプションを減らす。4モデルとAzure/BurstGPT実負荷を用いた評価では平均SLO違反を92.45%削減し、精度重視設定でもP95初回トークン遅延を2.2〜3.9倍改善、飽和処理量を最大1.83倍へ高めた。単なる低ビット計算の高速化ではなく、負荷に応じて重み精度とKV容量の間でGPUメモリを可逆的に移すことが主要な効果である。低負荷時には高精度層へ戻るため、静的INT4のように常時品質低下を支払う必要がなく、DuReaderではFP16に近いF1を保ちながら大幅なTTFT短縮を実現した。

- 平均SLO違反 / 92.45%削減 (比較対象: フル精度固定サービング; 条件: 4モデル、Azure/BurstGPT負荷) — 動的KV容量拡張により待ち行列とプリエンプションを抑制した。

- P95初回トークン遅延 / 2.2〜3.9倍改善 (比較対象: フル精度固定; 条件: MorphServe精度重視設定) — ピーク時に追加KVブロックを確保し、新規プリフィルの待ち時間を減らした。

- 飽和処理量 / 最大1.83倍 (比較対象: フル精度固定; 条件: 要求到着率を増加させる負荷試験) — 量子化で空いた重み領域をKVへ再配分することで同時実行可能量が増えた。

- TPOT末尾遅延 / P99最大1.23倍改善 (比較対象: フル精度固定; 条件: Azureトレース) — KV不足による退避・再計算の長い停止を減らした。

- Llama 2 7B DuReader品質/遅延 / AWQ静的INT4 F1 25.55、MorphServe 27.33、FP16 27.68; P95 TTFT 1.2420秒対5.5223秒(FP16) (比較対象: 静的AWQ INT4およびFP16; 条件: BurstGPTトレース) — 静的INT4よりフル精度に近い品質を保ちながら、FP16より大幅にTTFTを短縮する。

- 層交換費用 / Llama 2 7BのINT4層で完全交換約6ms (比較対象: 同期的なモデル再構成; 条件: PCIe Gen4、別CUDAストリーム) — 交換を通常デコードへ重ねられるためTPOTへの追加費用が小さい。

### 負の結果・境界条件
- 複数精度の重みをCPUに保持するためホストメモリ使用量が増え、論文では通常モデルサイズの2倍未満とする。負荷適応は予測型ではなく圧力検出後に反応する。層単位より細粒度な注意機構/MLP単位の変換は未実装で、極端な持続高負荷では低精度化だけで容量不足を解消できない可能性がある。

### 結果の読み方
主要な効果は低ビットGEMMそのものの高速化だけではなく、重み用の固定GPUメモリを必要時だけKV容量へ変換してプリフィル待ちとデコード中断を減らす点にある。静的量子化との差は、負荷が下がった時にフル精度へ戻り恒常的な品質損失を避けることである。
## 品質への影響
低精度層を通過する一部トークンには品質低下が生じるが、LISによる層選択と負荷期間だけの適用により静的INT4より小さく抑える。したがって完全無損失方式ではなく、SLO維持のため一時的で制御された精度低下を許容する方式である。
## 既存研究との差
静的量子化は起動前にモデル精度を固定し、節約と品質損失を常時受ける。MorphServeは同一要求の実行途中でも選択層だけ低精度へ交換し、圧力低下後にフル精度へ戻せる。PagedAttentionはKVページを効率管理するが通常は重み用メモリとの境界を固定しており、本方式は量子化で解放した重み領域をKVページへ動的に移す。全面的なCPU/SSDオフロードとも異なり、通常計算はGPUに残し、必要な層バリアントだけCPUから短時間転送する。
## 限界
実行時交換のためフル精度と量子化版の重みをホスト側に保持する必要があり、CPUメモリ使用量が増える。評価はL4/A100と7B〜34B級モデルが中心で、巨大MoE、異種GPU、低帯域接続、多ノードでの層交換費用は直接検証されていない。MorphServeは負荷急増を予測せず、監視指標の悪化を見てから反応する。適応単位もTransformer層であり、注意機構やMLP単位のより細粒度な容量交換は将来課題である。
## 実装状態
論文ではSwiftLLM上に約2,200行のPythonと約500行のC++/CUDAでLayerSwapper、KVResizer、監視制御を実装したと報告する。公式GitHubリポジトリはMITライセンスで公開されているが、2026-09-14確認時点のREADMEでは完全コードは公開準備中と明記され、リポジトリ内容はまだ限定的である。
## 研究上の位置づけ
GPUメモリを『重み』と『KVキャッシュ』の固定用途へ分割せず、SLOと品質に応じて実行時に交換可能な資源として扱う弾力的サービング系統に位置する。特にCPU側の複数精度層を待機階層として利用し、GPU上の重み縮小分を動的KVへ渡すため、階層メモリ・オフロード研究との接点が強い。論文自身も将来課題としてSSDからホストへのオンデマンド層ストリーミングやGPUDirect Storageを挙げており、SSD階層を追加した発展余地が明確である。
