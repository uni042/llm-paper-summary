# M-ANT: Efficient Low-bit Group Quantization for LLMs via Mathematically Adaptive Numerical Type

> グループ分布ごとに数値型を適応選択し、重み・KV量子化と復号計算を専用処理要素へ統合して既存LLMアクセラレータ比平均2.99倍高速化・2.81倍省エネルギー。

## 概要
グループ単位量子化では64値程度の小区間を独立に圧縮することで精度を保ちやすいが、グループごとの分布形状はテンソル全体より大きく変化する。M-ANTは、この局所分布差を固定INT/FP形式ではなく数学的適応数値型（Mathematically Adaptive Numerical Type; MANT）で表現する。さらに静的な重みだけでなく、生成時に増え続けるKVキャッシュもリアルタイム量子化し、専用処理要素（Processing Element; PE）とシストリック配列へ統合するハードウェア・アルゴリズム協調設計である。

## 問題設定
既存の適応数値型はテンソル全体や大きな領域の分布には対応できても、小グループごとに最適形式が変わる条件では選択肢が不足する。またKVキャッシュは事前に量子化しておけず、生成中に量子化・復号を行う必要があるため、低ビット化が新しい実行時オーバーヘッドを生む。

## 手法
MANTはグループごとの値分布を表せる可変な数値符号化を用意し、各グループに適した型を割り当てる。狙いは単に量子化誤差を下げることではなく、復号処理を後続の積和計算と融合しやすい形式へ制約することにある。

重み側はオフラインでグループ別形式を決定する。一方KVキャッシュはトークン生成中に値が確定するため、リアルタイム量子化ユニットが統計と符号化を処理する。MANT対応PEは低ビット値を復号しながら演算へ投入し、明示的な高精度展開を避ける。これらをシストリック配列へ組み込み、重みとKVの双方を一つのデータパスで扱う。

## 評価条件・主要結果
| 項目 | 結果 |
|---|---|
| 比較 | 当時の最先端LLMアクセラレータ |
| 性能 | 平均2.99倍、最大4.46倍高速化 |
| エネルギー | 平均2.81倍、最大4.10倍削減 |
| 圧縮対象 | グループ化重み + 動的KVキャッシュ |
| 実装 | MANT PE、リアルタイム量子化器、シストリック配列を含むアクセラレータ評価 |

速度向上は数値形式だけの効果ではなく、低ビット化で減るデータ移動、復号・計算融合、専用PEを合わせたシステム効果である。したがって汎用GPU上のソフトウェア量子化と直接同倍率で比較する値ではない。

## 既存研究との差
固定INT4やFP4をグループごとにscale調整する方式に対し、MANTは表現形式そのものをグループ分布へ適応させる。重み専用の量子化アクセラレータと異なり、実行時に生成されるKVキャッシュの量子化も同じハードウェアへ含める。

## 限界
主要な速度・エネルギー結果は専用アクセラレータ構成に基づくため、CUDA GPUへそのまま移植して得られる値ではない。グループごとの型選択metadataとリアルタイムKV量子化器が必要で、実装複雑性が増す。また量子化品質はモデル・層・グループ分布に依存する。
