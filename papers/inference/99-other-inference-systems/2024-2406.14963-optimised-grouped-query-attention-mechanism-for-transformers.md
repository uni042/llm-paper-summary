# Optimised Grouped-Query Attention Mechanism for Transformers

## 書誌
- 正規識別子: `arXiv:2406.14963`
- 著者: Yuang Chen, Cheng Zhang, Xitong Gao, Robert D. Mullins, George A. Constantinides, Yiren Zhao
- 公開日: 2024-06-21
- 採択先: ICML 2024
- 一次資料: https://arxiv.org/abs/2406.14963

## 概要
多頭注意 (multi-head attention; MHA) は各クエリ頭 (query head) に独立したキー・値頭 (key/value head) を持つため、自己回帰デコードでは過去トークン分のキー・値キャッシュ (KV cache) を全頭について保持・読み出す必要がある。グループ化クエリ注意 (grouped-query attention; GQA) は複数のクエリ頭でキー・値頭を共有し、キャッシュ容量とメモリ帯域を減らせるが、既存のMHAチェックポイントをGQAへ変換する際に「番号が隣接する頭を同数ずつまとめる」だけでは、機能的に異なる頭を強制共有させて精度を失う。

AsymGQAは、校正入力で観測した注意頭の活性 (activation) から頭間の類似度を測り、同じ共有キー・値頭数という予算の中で、似たクエリ頭を同じグループへ配置する。さらに全グループの大きさを同一にする制約を緩めた非対称グループ化 (asymmetric grouping) を探索する。変換後は短い全パラメータ微調整または低ランク適応 (Low-Rank Adaptation; LoRA) により共有化で生じた誤差を回復する。したがって狙いはGQAそのものを新しくすることではなく、**既存MHAからGQAへ移すときの頭の割当てを改善し、同じ推論時KV予算で品質損失を小さくすること**にある。

## 問題設定
通常のGQA変換では、例えばグループサイズ4なら連続する4個のクエリ頭を1個のキー・値頭へまとめる。しかし頭番号は意味的・機能的な近さを保証しない。論文は、事前学習済みTransformerの注意頭に冗長性はあるものの、その冗長性が規則的な隣接配置になっていないことを問題とする。

ここで最適化対象は、各層で「どのクエリ頭を同じキー・値頭へ共有させるか」という離散割当てである。共有数を減らせばKVキャッシュとパラメータ数、浮動小数点演算量 (FLOPs) は減る一方、異質な頭をまとめるほど精度が落ちる。このため、固定した圧縮予算の下で似た頭を集約することが品質維持に直結する。

## 手法
### 活性に基づく頭間類似度
校正データを元のMHAモデルへ通し、各注意頭の出力活性を取得する。2つの頭の類似度は、対応する活性行列について行ごとのコサイン類似度を取り、片方向だけの最近傍一致に偏らないよう双方向に集約して算出する。論文は重み行列そのものの類似度も比較するが、変換後の性能では活性を使う方法が概して良く、実際の入力に対して似た機能を果たす頭を捉える信号として採用する。

### 対称グループ探索
各層を独立に扱い、まず指定グループサイズを維持したまま頭の組合せを探索する。現在の割当てから頭 (a) を選び、そのグループ外にある類似度上位 (k) 個の候補から頭 (b) を選ぶ。グループサイズを保つため、(b) 側のグループから交換相手 (b') を選び、頭を入れ替えた候補配置を評価する。

探索を単純な貪欲法にすると局所解へ固定されるため、精度が改善した候補は受理し、改善しない候補も小さな受理確率で残す。また一定確率でそれまでの最良配置へ戻すリセットを入れる。論文の標準設定では各層10反復、悪化候補の受理確率0.1、リセット確率0.1、類似上位3頭から候補を選ぶ。この探索の出力は、各層ごとのクエリ頭→共有キー・値頭グループの割当てである。

### 非対称グループ探索
対称版では各共有キー・値頭が同数のクエリ頭を担当するが、実際には似た頭が多数集まる領域と、独立性を保ちたい頭が混在する。AsymGQAは交換時にグループ間のサイズ差を許し、一定の保存確率パラメータを使って非対称なグループ構成も探索対象へ含める。これにより「全グループを同じ大きさにする」という人工的制約を外し、同じ総共有予算の中で冗長な頭はより強く共有し、異なる頭は分離しやすくする。

探索後、同じグループに割り当てられた元キー・値投影を共有GQA構造へ変換する。そのままでは変換誤差が残るため、論文では3エポックの全体微調整とLoRA微調整の両方を評価する。したがって追加費用は、校正活性の取得、層ごとの組合せ探索、変換後の短い微調整であり、完全な学習不要変換ではない。

## 評価条件
| 観点 | 条件 |
|---|---|
| モデル | OPT、LLaMA、LLaMA-2。規模は125Mから7Bまで |
| 代表モデル | LLaMA-2-7B |
| タスク | SST-2、QNLI、MNLI、MMLU |
| 比較対象 | 隣接頭を等分する標準GQA、活性類似度を使う対称グループ化、AsymGQA |
| 微調整 | 全パラメータ微調整とLoRAを別々に評価 |
| 反復 | 主設定では各層10回の探索、3回の独立実行を集計 |
| 圧縮軸 | グループサイズ2、3、4、6など。サイズ増加ほど共有キー・値頭数が減る |

## 主要結果
LLaMA-2-7BのMMLUでは、元MHAが39.8である。グループサイズ2を全パラメータ微調整した場合、隣接GQAは34.5まで低下するのに対しAsymGQAは39.3で、元MHAとの差を0.5ポイントに抑える。グループサイズ4では隣接GQAが29.0、AsymGQAが36.5で、同じ共有予算のまま7.5ポイント差が付く。サイズ6でも26.4対33.8であり、圧縮を強くした条件ほど単純な隣接共有の損失が大きい。

論文本文はLLaMA-2-7Bで、隣接GQAに対するAsymGQAの改善を最大12.5%、MMLU平均6.3%、SST-2平均2.8%と報告している。したがって効いているのは「キー・値頭数を増やしたから」ではなく、**同じGQA圧縮率で共有相手を変えたから**である。

構成要素除去実験 (ablation) では、まず隣接配置から活性類似度ベースの対称配置へ変えるだけでも性能が上がり、そこへ非対称グループを許すとさらに改善する。重み類似度と活性類似度の比較では活性側が多くの設定で優れるが、全タスク・全グループサイズで必ず勝つわけではない。例えばOPT-125Mの一部SST-2/MNLI条件では重み類似度がわずかに高い。この負の例は「活性指標が万能な重要度指標」という解釈を避ける材料になる。

またグループサイズを大きくするとモデルパラメータ数とFLOPsは下がる一方、品質低下が急になるため、論文はサイズ2〜3付近を品質・効率の妥協点として示している。これは共有率を強めれば常に得という結果ではなく、圧縮率と精度のパレート関係 (Pareto trade-off) があることを示す。

## 既存研究との差
標準GQAは共有キー・値頭数を決めても、クエリ頭の割当てを位置順・同サイズで固定することが多い。AsymGQAは、既存MHAの機能的冗長性を校正活性から観測して割当て自体を最適化し、さらに共有グループの大きさも不均一にできる点が異なる。したがって新しい注意演算カーネルを導入する方式ではなく、既存チェックポイントをより損失少なくGQA構造へ変換する手法である。

## 限界
第一に、校正データと探索、変換後の微調整が必要であり、既存モデルへ瞬時に適用できる後処理ではない。第二に、評価の主眼はタスク精度、パラメータ数、FLOPsで、実際の推論提供基盤における初回トークン時間 (time to first token; TTFT)、トークン間時間 (time per output token; TPOT)、KV帯域、壁時計速度を直接測った研究ではない。そのため「GQA化で構造的にKV量が減る」ことと「特定GPUで何倍高速になる」ことは分けて扱う必要がある。第三に、探索は層ごとに離散的に行うため、より大規模なモデルや頭数が多いモデルでは探索・校正費用自体が増える。さらに強い圧縮ではAsymGQAでもMHAとの差が残り、頭割当ての改善だけで品質損失を完全には消せない。
