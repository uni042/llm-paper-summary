# ST-Veto：拡散型マルチモーダルLLMの時間・画像根拠に基づくトークン確定

## 概要

拡散型言語モデル（diffusion language model; dLLM）は、自己回帰（autoregressive; AR）モデルと異なり、まだ確定していない多数のトークン位置を各反復で同時に予測し、一部の位置を確定（unmask）する。拡散型マルチモーダルLLM（diffusion multimodal LLM; dMLLM）は画像と文章を条件としてこの処理を行う。通常は現在の確信度が高い位置から確定するが、部分的にしか復元されていない文章の中では「今は高確信でも次の反復で不安定になる」位置がある。また文章としてもっともらしくても、画像内容に十分な根拠がない語を先に確定すると、後の反復で修正しにくくなる。

ST-Veto（Spatio-Temporal Token Veto）は、現在の確信度上位k位置をいったん候補として取り出し、**時間方向の確信度安定性**と**画像トークンへの注意量**の二つを使って危険な候補を拒否する。代わりに、上位kの境界に近い確信度を持ち、両指標が良好な位置を確定する。モデル本体の重みを更新せず、追加の生成呼び出しや反復回数を必要としない。LaViDa-ReasonとMMaDA-8B-MixCoTで評価し、画像付きScienceQAのLaViDa・長い生成設定では正答率40.06%から48.54%へ8.48ポイント改善した。

重要なのは、この方式が主に**同じ生成予算での品質改善**を狙う点である。投機的復号のようにモデル実行回数を減らしてトークン/秒を直接増やす手法ではない。統計計算や注意の参照に追加処理はあるが、原著は既存の拡散反復へ組み込むことで処理時間がほぼ変わらないと報告する。

## 背景・問題設定

離散拡散型言語モデルは、特殊なマスク記号で隠されたトークンをモデルが予測し、反復ごとにマスク数を減らしていく。自己回帰型では既に出力した前方の文章を固定して次トークンを予測するため、思考連鎖（chain-of-thought; CoT）を段階的に出力する方策が自然に働く。これに対し拡散型では、各位置の予測が部分復元状態に依存し、文章全体の複数位置が同時に変わる。ARモデルで使われる「先に中間推論を書き、その結果を固定した条件として最終回答を作る」という2段階手順をそのまま移植すると、追加呼び出しが必要になり、拡散型の並列復元の利点が薄れる。

原著はLaViDaとMMaDAの二種類を対象とする。LaViDaは連続画像特徴を条件としてテキストのマスクを復元し、MMaDAは画像とテキストを離散トークン列として統合する。視覚条件の表現方式は異なるが、いずれも反復ごとに複数のテキスト位置の確信度を観測できる。ST-Vetoはこの観測を使い、現在の最高確信度だけでなく、過去数反復での確信度の推移と、画像トークンに注意が向いているかを判断する。

## 手法

### 1. 時間方向の確信度予測と残差

現在の反復をt、位置iでモデルが予測したトークンの確信度を `c_i^(t)` とする。ST-Vetoは同じマスク位置の過去の確信度履歴から、有限差分で変化速度と加速度を推定し、次の確信度をテイラー近似（Taylor prediction）する。原著は二次の予測を用い、4ステップ履歴を基本とする。現在観測した確信度と予測値の差 `e_i=c_i^(t)-ĉ_i^(t)` をテイラー残差と呼ぶ。予測より大きく低下した場合、e_iは負に振れ、その位置の確信度が時間方向に不安定だと解釈する。

現在の絶対確信度が高いだけでは安全とは限らない。例えば未確定位置の周囲が後から復元されると、先に「正解」と思われた語が文脈と矛盾し得る。過去の傾向に比べて急に確信度が落ちた位置を避ければ、誤った早期確定を減らせる可能性がある。ただし有限差分の予測は確信度が滑らかに推移することを暗黙に利用しており、文脈変化によって不連続に予測が変わる場合には誤判定し得る。履歴を長くすると計算・状態管理が増え、論文は4ステップの二次予測を主な費用対効果の良い選択としている。

### 2. 画像注意比率による根拠の判定

時間方向に安定している語でも、文章の慣用表現として出やすいだけで画像の根拠が弱い場合がある。ST-VetoはTransformerの中間層で、候補トークン位置iが画像トークン集合Iへ割り当てる注意重みの割合を計算する。層ℓの注意行列をA^(ℓ)とすると、`ρ_i^(ℓ)=Σ_{j∈I} A^(ℓ)_{i,j} / Σ_p A^(ℓ)_{i,p}` である。層の1/3、1/2、2/3付近を選び、それらの平均 `m_i` を画像根拠指標とする。

画像に注意が向いていることは正しい根拠の十分条件ではないが、視覚に依存すべき回答で画像への参照が乏しい語を優先確定しないための実用的な代理指標となる。単一層だけでは層ごとに注意の意味が異なるため、複数の中間層を平均する。論文の層別比較では、いずれか一層のみを使う場合も多くの条件で基準方式を上回るが、どの層が最良かは課題に依存する。三層平均は全体として安定した改善を示した。

### 3. 拒否・交換（Veto-and-Swap）方策

標準の確信度順選択が確定しようとする上位k位置の集合をT_kとする。ST-Vetoは、時間残差eと画像注意比率mのそれぞれについて、現在の候補群の中央値μと中央値絶対偏差（median absolute deviation; MAD）σを計算する。位置iが `e_i<μ_e−σ_e` **または** `m_i<μ_m−σ_m` なら拒否候補にする。一方、代替候補は `e_i≥μ_e+σ_e` **かつ** `m_i≥μ_m+σ_m` の両方を満たす必要がある。拒否はどちらか一つの弱さで発動し、安全判定は両方の強さを要求する非対称な規則である。

上位kの境界確信度をc_(k)とすると、交換先は上位kの外側で `|c_i−c_(k)|≤MAD(c)` の近傍に限る。安全だからといって、確信度が著しく低い位置を無理に確定させるわけではない。交換可能な安全候補の数が拒否数より少ない場合は部分的な交換だけを行い、強制的な全置換をしない。選択後は通常の拡散スケジュールに従って確定位置とマスク位置を更新する。生成トークンそのものの確率分布を厳密に保存する方式ではなく、確定順序を変更して最終品質を改善するヒューリスティックである。

### 4. 実装上の処理順

各反復でモデルがマスク位置のロジットと確信度を計算したら、過去履歴から時間残差を求める。次に中間層の注意重みから画像への注意比率を集約し、両信号の中央値とMADを計算する。確信度上位k位置を仮選択し、危険な位置を拒否し、上位k境界付近の安全候補と交換して、最終的な確定位置を選ぶ。この処理は通常の拡散復元ステップ内で完結し、別の言語モデル呼び出しや追加の反復を発生させない。実際の実装では中間層注意の取得方法、注意ヘッド平均、マスク位置の追跡、4ステップ履歴の保持、同点時の選択順序が再現性に関わる。

## 評価条件

| 項目 | 条件 |
|---|---|
| モデル | LaViDa-llada-reason、MMaDA-8B-MixCoT |
| 課題 | M3CoT、MMBench、ScienceQA画像条件（SQA-IMG）、V*Bench |
| 生成長・反復回数 | L/T=128/64および256/128の二条件（Lはトークン上限、Tは復元反復回数） |
| 復元方式 | 確信度による標準マスク復元（Low-conf）を基準とし、決定論的argmax選択 |

| 評価回数 | 3乱数種の平均 |
| 構成要素除去 | 時間残差なし、画像根拠なし、有限差分の次数、注意層、MAD閾値 |
| 主要指標 | ベンチマーク正答率と同一ハードウェア条件の推論費用 |

原著本文には「L/Tの比を0.5に固定」と書かれる一方、主表は128/64と256/128であり、文字どおりのL/Tはどちらも2である。反復数/生成長T/Lなら0.5となるため、**本文の比の向きに表記不整合がある**。本解説では実験表に記された実数値L=128,T=64とL=256,T=128を採用する。

### 処理費用の検証

原著Table 2ではMMBenchでの処理費用として、LaViDaの128/64条件で基準4.87、ST-Veto4.89、DDCoT9.89、256/128条件で基準12.88、ST-Veto12.92、DDCoT22.95と記載する。MMaDAでは128/64条件で基準5.68、ST-Veto5.73、DDCoT10.87である。ST-Vetoの数値差は小さく、AR型の2段階呼び出し方式はほぼ2倍の費用となる。ただし表見出しは「inference per second」「samples per second」と説明する一方、本文では大きい数値を追加費用と解釈しており、**単位と大小の解釈に内部不整合がある**。本解説ではこれらを単位確定済みのトークン/秒とは扱わず、同じ表内の相対的な費用比較としてのみ利用する。

また「追加の生成費用なし」は、同じ復元反復数・同じモデル呼び出し回数という意味であって、MAD計算や中間層注意取得が計算資源を全く使わないという意味ではない。注意行列を明示的に取得する実装ではメモリ使用量が増える可能性があるため、フラッシュ注意（FlashAttention）等で注意重みを通常は保持しない推論エンジンへ組み込む場合は、取得費用を別途計測すべきである。

時間残差だけ、画像根拠だけでも多くの条件で基準を上回るが、両方を使う方式が最良となる。これは両信号が異なる失敗を補っていることと整合する。時間信号は一貫しない候補を、画像信号は見かけ上もっともらしいが視覚的裏付けの弱い候補を抑える。ただしMMaDAの構成要素除去表（Table 3）のSQA-IMG値は、主表（Table 1）の値と一致しない箇所がある。例えばMMaDA・128/64のST-Vetoは主表36.55に対して構成要素除去表35.55である。このため上表は不一致のないLaViDa値を中心に示し、MMaDAの厳密な比較には原著の訂正確認が必要である。

### 感度分析

有限差分の次数を変える実験では、LaViDaのMMBench 128/64で基準33.96、残差差分のみ36.98、一次37.38、二次38.05、三次38.11となる。三次がわずかに良い場合もあるが、256/128では二次38.25が三次38.12を上回る。ScienceQA長い生成条件では二次48.54、三次47.55となり、二次が有利である。したがって二次を「すべての条件で最高」と断定せず、追加履歴と計算費用を考慮した費用対効果の選択として扱う。

画像根拠に使う層については1/3、1/2、2/3付近の各層で改善が見られるが、課題により最良層が異なる。三層平均が全体として安定している。MAD閾値を0.5倍、1倍、1.5倍と変える比較では、標準の1倍がほぼすべての条件で最良または同等であり、交換候補を緩めすぎると不安定な確定が増え、厳しくしすぎると有益な交換が起きなくなる。

## 既存研究との差

自己回帰型の思考連鎖方式は、先に生成した中間結果を固定して次の段階の条件へ渡す。拡散型では複数位置を同時に更新するため、同じ形式の推論を実現するには追加呼び出しや別の段階設計が必要になる。ST-Vetoは中間推論文を別に生成するのではなく、同じ拡散復元中のトークン確定順序を変更する。標準の確信度、マージン、エントロピーに基づく復元は現在時点の予測だけを使うのに対し、ST-Vetoは時間履歴と画像根拠の両方を参照する。

通常の信頼度調整やロジット補正と異なり、モデルの出力確率自体を直接書き換えず、確定する位置の集合を入れ替える点も特徴である。学習不要であるため、追加データやモデル重みの更新は不要だが、確信度履歴と注意情報が推論実装から取得できることが必要になる。

## 限界と実装上の注意

- **モデルの範囲。** LaViDa-ReasonとMMaDA-8B-MixCoTの二種類での評価であり、すべての拡散型LLM、特に画像を持たないテキスト専用モデルで同じ利得が出る保証はない。
- **時間予測の仮定。** 確信度の履歴から次の値を外挿するため、局所的に滑らかでない推移や履歴不足では残差が信頼できない。生成初期のウォームアップ時にどう扱うかは実装で明示する必要がある。
- **画像注意の限界。** 画像への注意比率は視覚的正しさの証明ではない。高い注意でも誤った画像領域を見ている場合があり、逆に言語的知識だけで正しく答えられる語が低く評価され得る。
- **確率分布非保存。** 確定順序を変更するヒューリスティックであり、元の復元方策と厳密に同じ生成分布を保証しない。改善はベンチマークでの経験的結果である。
- **速度の解釈。** 追加のモデル反復はないが、統計計算と注意抽出の費用は存在する。原著の処理費用表には単位表記の不整合があり、無条件の速度改善を主張できない。
- **原著内の表記不整合。** L/T比率の記述、MMaDAの構成要素除去表の一部値、処理費用表の単位に注意する。引用時には表番号と条件を明記すべきである。
- **コード。** ST-Veto固有の公式公開リポジトリは今回の確認範囲で見つからなかった。復元ループの実装により注意行列の取り出し費用が大きく変わる可能性がある。
