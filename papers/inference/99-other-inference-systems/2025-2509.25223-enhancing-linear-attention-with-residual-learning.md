# Residual Linear Attention：予測誤差を補助再帰状態で蓄積する

## 概要

線形attentionは、履歴のkey/valueを固定サイズの状態行列に集約し、系列長に対して線形時間・一定の再帰状態メモリで生成できる。一方、状態容量に制限があるため、古い情報の上書きや複雑な依存関係の保持でsoftmax attentionに劣ることがある。*Enhancing Linear Attention with Residual Learning*は、既存の状態行列Sがkeyからvalueを予測したときの**予測残差**を、別の状態行列Rに累積し、出力時に補正するResidual Linear Attention（RLA）を提案する。DeltaNet系へ応用したResidual Delta Net（RDN）も実装する。

約1.5Bパラメータを100B tokenで学習した比較で、RDNはGated DeltaNet（GDN）のWikiText PPL 17.27から**16.57**へ、8課題平均正解率46.03%から**47.20%**へ改善した。RLAはsGLAに対してPPL 17.63→**17.35**、平均45.79→**46.44**である。NIAHではRLAが83.6、RDNが79.2となり、同実験のTransformer 70.5を上回る（原著Tables 2,3）。ただし、補助状態の更新は追加計算を要し、標準Transformerを全指標で上回るわけではない。

## 背景・問題設定

### 線形attentionの状態容量

通常のsoftmax attentionは過去のkey/valueを保持してqueryとの対応を計算する。長い系列ではKV cacheとattention演算が増える。線形attentionはkey/valueの外積を状態Sへ累積し、query qに対して`S q`を計算する。これにより履歴長に依存しない状態サイズと、トークンごとの一定規模の更新が可能になる。Gated Linear Attention（GLA）やDeltaNetは忘却・修正を工夫するが、基本的には単一の状態で多くの関係を表現する。

この単一状態には、異なるkeyに紐づくvalueの競合が起きる。あるkeyを入力したときSが期待valueを正しく再構成できなければ、次の出力にも系統的な誤差が残る。従来のdelta ruleはその時点の誤差に応じて状態を修正するが、**過去の誤差を独立した記憶として長期蓄積する**わけではない。著者らは、base predictionとcorrectionを分けることで表現能力を高める。

### Online learningとしての解釈

線形attentionの状態更新は、keyからvalueを予測するオンライン学習に類似する。key k_tに対するbase状態の予測をS_{t-1}k_tとすると、残差は`r_t = v_t - S_{t-1} k_t`である。二乗誤差の局所的な最適修正はこの残差方向に対応する。著者らはこの残差をその場限りの補正に使うのではなく、別の状態Rへ記憶する。これによりbase状態が何を取りこぼしてきたかという履歴を追加の特徴として利用できる。

## 手法

### 1. 基本RLAの二状態更新

入力は時刻tのq_t、k_t、v_tと前時刻のbase state S_{t-1}、補助state R_{t-1}である。まず`r_t = v_t - S_{t-1} k_t`で残差を計算し、`R_t = R_{t-1} + r_t k_t^T`として補助状態へ蓄積する。出力は`o_t = S_{t-1} q_t + R_t q_t`であり、base predictionと残差補正を合算する。base状態は`S_t = S_{t-1} + v_t k_t^T`で更新する（原著§3.1）。

重要なのはRが**過去の残差の総和**を記憶する点である。通常の線形attentionは現在のvalueをそのままbase stateへ書き込む。RLAは、その時点のbaseがすでに説明できる部分を差し引いた残差を別状態へ書くので、baseと補助状態が異なる情報を担う。Rがなければ標準線形attentionに戻り、Rを現在トークンの残差だけに制限すると一段のdelta ruleに近づく。原著はこの二つを特別な場合として説明する。

### 2. Gatingと専用補正係数

単純に残差を無限に足し続けると、長い系列で状態ノルムが増大する可能性がある。著者らは忘却係数α_t、更新係数β_tを導入し、base stateと補助stateの保持・更新を制御する。さらに補助状態からの補正寄与を独立に調整する係数γ_tを持たせ、`o_t = α_t S_{t-1} q_t + γ_t R_t q_t`のように組み合わせる。γをβへ結び付けると更新量と出力補正量が同時に変わってしまうが、独立のγなら現在の予測誤差に応じて補正の強さを学習できる。

この係数は単なる追加のMLPではなく、recurrent stateをどの程度保持し、queryに対してどの程度出力するかを調整するためのものだ。原著Figure 3では独立γが検証損失を改善する傾向を示す。一方、γなしでも残差stateの追加自体が性能を改善するため、核心は係数の数ではなく**誤差を累積する状態**である。

### 3. Delta-ruleへの適用：RDN

Residual Delta Net（RDN）は、既存のdelta-rule型状態更新へ残差補助状態を導入する。DeltaNet系はkey-valueの予測誤差を使って主状態を更新するが、RDNでは補助Rにも誤差履歴を蓄積し、query出力の補正へ使う。これによりbase状態の一回の修正だけでは表現しきれない関係を別経路で学習する。RLAとRDNの性能差は、主状態の更新規則と補助状態の相互作用に依存する。

原著は、既存の高効率線形attentionカーネルを利用し、系列長に対して線形な時間・メモリスケーリングを維持すると説明する。ただし補助stateの保存・更新が増えるため、同じ系列長の通常GLA/GDNより必ず軽いという意味ではない。カーネル単体の曲線はFigure 2で示されるが、絶対TPSの表がない条件で倍率を推測しない。

### 4. 正規化と残差clipping

RLAの補助状態は誤差を蓄積するので、状態ノルムの爆発が起きやすい。著者らは正規化と残差clippingを組み合わせて学習を安定させる。原著Figure 4のablationではRLAからこれらを除くとactivation normが大きくなり、学習損失が悪化する。RDNはdelta rule自体が一定の安定性を持つため、残差clippingへの感度が小さい。よって同じ補助stateでもbase update ruleによって必要な安定化策は異なる。

### 5. 出力合成のablation

出力をgatedに合成する方式と単純加算を比較した原著Table 5では、50B token学習のRLA平均はgated **43.30**、単純加算**43.81**で、単純加算が僅かに良い。RDNはgated **44.65**、単純加算**43.96**で逆の結果となる。したがってgatingの優位性は全モデルに一様ではなく、RLAの中核的改善を「gated outputだけの効果」と説明するのは誤りである。

## 主要結果

### 1. 言語モデルと常識・推論の比較

原著Table 2はWikiText PPLと8課題平均正解率を報告する。

| モデル | WikiText PPL↓ | LAMBADA PPL↓ | 8課題平均↑ |
|---|---:|---:|---:|
| Transformer | 17.33 | 19.53 | 46.51% |
| sGLA | 17.63 | 18.06 | 45.79% |
| GDN | 17.27 | 15.76 | 46.03% |
| **RLA** | **17.35** | **15.59** | **46.44%** |
| **RDN** | **16.57** | **14.93** | **47.20%** |

RLAはsGLAよりWikiText PPLが0.28低く、平均正解率が0.65ポイント高い。RDNはGDNよりPPLが0.70低く、平均正解率が1.17ポイント高い。RDNはTransformerより平均0.69ポイント高いが、Transformerの一部個別タスクが優れている。RLAはTransformerの平均46.51%に対して46.44%で僅かに下回る。

例えば原著Table 2ではRDNのARC-C 32.1、ARC-E 58.7に対しTransformerは30.2、55.7で改善する一方、WinograndeはRDN **49.5**、Transformer **53.5**と4ポイント悪化する。RLAのWinograndeも49.7である。平均値だけを見て「すべての推論能力が改善」と解釈しないことが重要である。

### 2. 記憶・検索タスク

原著Table 3の7タスク平均とNIAHを比較する。

| モデル | 7タスク平均↑ | NIAH↑ | DROP↑ | FDA↑ |
|---|---:|---:|---:|---:|
| Transformer | **48.31** | 70.5 | 26.9 | **63.0** |
| sGLA | 45.06 | 76.6 | 25.7 | 51.8 |
| GDN | 44.99 | 75.7 | 25.9 | 47.4 |
| **RLA** | **46.73** | **83.6** | 26.5 | 51.5 |
| **RDN** | **47.11** | **79.2** | **27.8** | 57.5 |

RLAはNIAHでsGLAより+7.0ポイント、RDNはGDNより+3.5ポイントである。RDNのDROPはGDN 25.9→27.8、FDAは47.4→57.5へ改善する。しかし7タスク平均はTransformer 48.31よりRDN 47.11、RLA 46.73が低い。特にFDAではTransformer 63.0に対してRDN 57.5であり、長文記憶能力を完全に取り戻したわけではない。

### 3. 残差蓄積の必要性

原著Table 4は50B token学習のRLAから過去残差の蓄積を取り除き、現在トークンだけの補正へ置き換える。

| 指標 | RLA | 残差蓄積なし |
|---|---:|---:|
| 学習損失 | **2.22** | 2.26 |
| WikiText PPL | **18.76** | 20.19 |
| LAMBADA PPL | 23.44 | **22.50** |
| GSM8K PPL | **3.92** | 6.85 |
| HumanEval PPL | **9.61** | 16.23 |

WikiTextやGSM8K/HumanEvalのPPLは悪化するが、LAMBADA PPLは蓄積なしの方が小さい。従って全データで単調に改善するわけではない。またGSM8K/HumanEvalの値は**perplexity**であり、数学問題の正答率やコードのpass@1ではない。原著の主要評価100B tokenとこのablationの50B tokenは別条件である。

### 4. Kernel効率の評価範囲

原著Figure 2では、RLA/RDNのattention kernel時間が系列長に対して概ね線形に増え、FlashAttentionの長系列における二次的な増加と対照的である。長文では高速化の可能性がある一方、残差stateの追加更新による一定のオーバーヘッドが存在する。絶対的なtokens/s、同じGPU上のバッチ・系列長別の詳細数値を本文の図から一律に読み取れないため、**サービングのTPS改善倍率やTTFT改善率は未確定**として扱う。学習100B tokenの品質比較と、attention kernelの単体比較も別の実験である。

## 既存研究との差

GLAはgateで過去の情報を忘却しながら状態を更新し、DeltaNet/GDNはkeyに対する予測誤差を利用して状態自体を修正する。RLAはbase stateの予測を保持したまま**残差を別の補助状態へ累積**する。RDNはdelta-ruleのbase updateとこの補助記憶を組み合わせる。単純に一段の更新率を調整するだけでは表現できない、過去の系統誤差を明示的に扱う点が違いである。

TitansやTTT-MLPはより強力な非線形記憶を導入するが、状態更新・学習の並列化や実行費用が増える。RLA/RDNは行列状態を追加するだけなので線形再帰を維持しやすい。ただし状態が一つから二つになる分、メモリと演算の定数因子は増える。モデルを重くして表現力を得る方法と、履歴長に対する計算量を減らす方法の折衷として位置づける。

## 限界・負の結果

第一に、補助状態Rの保存・更新は追加コストであり、同じ系列長のsGLA/GDNより常に速いとは限らない。長文でFlashAttentionより線形スケーリングが有利でも、短い系列、低バッチ、特定GPUでは定数オーバーヘッドが支配的になる可能性がある。論文のFigure 2を全サービング環境のTPS保証へ拡張できない。

第二に、品質の優位性は一様でない。RLAはTransformerの8課題平均を僅かに下回り、RDNのWinograndeはTransformerより4ポイント低い。NIAHでの改善がすべてのQA・推論能力の改善を意味するわけではない。記憶タスクの7課題平均でもTransformerを下回る。

第三に、RLAは正規化と残差clippingを外すと状態ノルムが爆発し、学習が不安定になる（Figure 4）。RDNではclippingの感度が小さいが、これは同じ設定で全モデルが安定するという意味ではない。gateと専用補正係数の有効性もRLA/RDNで異なり、単純加算の方が良いablationがある。

第四に、主実験は約1.5B・100B token学習であり、7B/70B級、既存の学習済みTransformerを変換する場合、128K〜1M長文、MoE、マルチモーダル、分散推論への一般化は未実証である。通常のsoftmax TransformerのKV cacheをそのまま置換するドロップイン手法ではなく、線形attentionの状態更新を組み込んだモデルを学習する必要がある。

第五に、GPU VRAM、モデル全体の学習費用、推論TTFT、decode TPOT、連続バッチのスループット、P95/P99遅延について、通常のサービングフレームワークと同条件の詳細測定はない。RLA/RDNの理論的な線形計算量をそのまま実運用の速度倍率とみなさない。

## サーベイへの位置づけ

線形attentionと再帰状態の表現力改善に位置づける。特に「base predictionの残差を別の再帰記憶へ蓄積する」という機構は、有限状態の線形attentionが古い情報を失う問題への設計指針になる。現時点では約1.5Bの事前学習モデルの品質改善が主な実証であり、vLLM/SGLangなどへ即座に導入できる推論時のKV圧縮ではない。採用判断では追加状態の定数メモリ・演算費用と、実際の長文検索精度の両方を測る必要がある。
