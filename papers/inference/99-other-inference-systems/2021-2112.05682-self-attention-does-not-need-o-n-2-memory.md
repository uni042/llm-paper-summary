# Self-attention Does Not Need O(n^2) Memory

> 注意行列を保存せず安定な逐次ソフトマックス集約とチャンク化で厳密な自己注意を計算し、16,384トークン推論時の注意メモリを59倍削減する。

## 概要
標準自己注意は注意スコア行列を明示的に保持する実装が一般的で、系列長に対して二次のデバイスメモリを消費する。本論文は、注意の出力自体は二次メモリを必要とせず、ソフトマックスの分子・分母を逐次集約すればよいことを示す。単一クエリ注意は系列長に対してO(1)、自己注意は理論上O(log n)メモリで計算でき、アクセラレータ向け実装では並列性との折衷としてO(sqrt(n))メモリを使う。

## 問題設定
長系列Transformerでは計算量だけでなく、中間の注意行列がGPU/TPUメモリを占有するため、計算能力が残っていてもメモリ不足で系列長を伸ばせない。近似注意で情報を削る方法とは異なり、本論文は標準ソフトマックス注意と数学的に同じ結果を保ったまま中間状態だけを減らす。

## 手法
単一クエリでは、各キーとの指数化スコアと値の重み付き和を逐次加算し、最後に正規化する。指数のオーバーフローを避けるため、処理済み要素の最大スコアを保持し、新しい最大値が出たとき既存の分子・分母を再スケールする。これにより全スコアを保存せず数値安定性を保つ。

実機ではクエリとキー・値をチャンクへ分割する。クエリチャンクを順次処理し、各キー・値チャンクの部分集約を並列計算してから最大値をそろえて統合する。キー側チャンクを概ねsqrt(n)にすることでメモリと並列性を釣り合わせる。

逆伝播では中間値を保持する代わりに再計算するチェックポイント法を用いる。このため学習では追加計算が生じるが、推論では厳密な注意をほぼ標準実装の実行時間で低メモリ化できる。

## 評価条件・主要結果
系列長16,384では自己注意のメモリオーバーヘッドを推論で59倍、微分で32倍削減した。実用実装の実行時間は標準注意から数%程度の差に収まり、二次の時間計算量は残るものの、メモリ律速で処理不能だった長系列を可能にする。

| 条件 | 結果 |
|---|---|
| 系列長16,384・推論 | 注意メモリオーバーヘッド59倍削減 |
| 系列長16,384・微分 | 32倍削減 |
| 実用実装の空間量 | O(sqrt(n)) |
| 時間計算量 | O(n^2)のまま |
| 数値結果 | 標準ソフトマックス注意と同じ計算を保持 |

## 既存研究との差
疎注意や低ランク近似のように注意そのものを変更せず、計算順序と再計算だけでメモリを削減する。後の入出力認識型の厳密注意カーネルへつながる「注意行列を物理的に保持する必要はない」という設計点が重要である。

## 限界
計算量は二次のままなので、系列長が非常に大きいと計算時間が支配的になる。学習時は再計算のため推論より大きな速度ペナルティがある。論文の実装・評価は後年のLLMサービング環境を直接対象としていない。
