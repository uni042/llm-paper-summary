# Attentionの何が不可欠か：簡略化と標準層のハイブリッドを検証する

## 概要

標準Transformerのattentionは、現在のトークンが過去のトークンから情報を集めるために、現在層のhidden stateからQ・K・Vを生成し、QK内積をsoftmaxで正規化してVを混合する。ここには、(1)トークン間混合、(2)入力系列に応じた重み、(3)内積とsoftmaxという数式形、(4)現在層の状態からQ/Kを導くこと、という異なる設計原理が同時に含まれている。著者らはどれが必須なのかを調べ、各原理を一つずつ緩めたattentionを、全層で置き換える場合と標準attention層を交互に残す場合で比較した。

結論は「簡略化したattentionを単独で使えるか」と「標準attentionと混ぜて使えるか」は異なる、というものである。トークン間混合を全層で失うMLPは500MモデルのWikiText困惑度993.5と著しく悪いが、標準attentionを交互に配置すると81.3まで回復する。softmax内積を2次Taylor近似するApproximateは全層で47.9、ハイブリッドで39.4となり、標準attentionの38.1に近い。一方、内積構造を大きく崩したNon-approximateは全層で困惑度9025.9と破綻するが、ハイブリッドでは39.3まで回復する。**推論システムへの直接的な貢献は、線形時間・キャッシュ削減・固定attentionスコアの事前計算が可能な設計空間を明らかにしたこと**であり、実際のGPU速度改善を測定した研究ではない。

## 問題設定

線形attentionやSSMと標準attentionを混在させるハイブリッドモデルは、KVキャッシュと演算量を減らす可能性がある。しかしどの簡略化を何層へ配置すべきか、標準attentionが何を補っているかは、モデル構造・パラメータ数・学習データ量が異なる実験では分離しにくい。著者らは同程度のパラメータ数と学習予算を維持し、attentionの機能だけを変える制御実験を設計した。

主設定では約500MパラメータのモデルをSlimPajama最大15Bトークンで事前学習し、同じ学習予算で全層代替（uniform）、偶数層だけ標準attentionを残す交互配置（hybrid）、hybridから代替層を学習後に取り除く（skip）を比較する。言語理解7タスクの正解率、WikiText・LAMBADAの困惑度、attentionのエントロピー・集中度・head多様性・sink傾向を観測する。追加の70M・160MモデルやGQAでの検証も含む。

## 手法

### 1. attentionを四つの設計原理へ分解する

標準attentionではQ=HW_Q、K=HW_K、V=HW_Vから注意行列A=softmax(QK^T/√d_h)を作り、AVでトークン間情報を混ぜる。入力系列Hが変わるとQ/Kも注意重みも変わり、各層で独自の情報を選べる。この仕組みを一度に別のモデルへ置き換えると、品質変化がトークン混合の喪失によるのか、softmaxを失ったためか、入力依存性を失ったためかを切り分けられない。

そこで、各代替方式がどの原理を保ち、どの原理を外すかを明示する。全層で使うuniformは単体で成立するかを検証し、hybridは標準attentionが代替層の弱点を補えるかを調べる。skipはhybridの代替層を単に削除して同じ効果が得られるかを調べる対照であり、学習済み代替層が有効な情報変換を行っているかを確認するための実験である。

### 2. MLP：トークン間混合を完全に失わせる

MLP代替は、各位置を独立に変換することでattentionのトークン間混合を取り除く。これにより、モデルは入力系列中の離れたトークンの関係を直接扱えず、過去の文脈を利用した予測に不利になる。uniform MLPは大半のNLUタスクでほぼ偶然水準となり、WikiText困惑度は993.5となる。ハイブリッドでは標準層がトークン間情報を伝えるため、代替MLP層が各位置で特徴変換を担当できるが、長文脈の表現力は他の代替方式より低い。

この比較は、attentionの全ての複雑な機能が必須なのではなく、少なくともネットワークの一部でトークン間の情報混合を行う必要があることを示す。uniform MLPが局所統計をある程度学習できても、長い文脈を統合する能力の代わりにはならない。

### 3. ApproximateとNon-approximate：内積softmaxを緩める

Approximateはsoftmaxの指数関数を2次Taylor近似することで、attentionを低次の特徴量積へ置き換え、系列長に対して線形の計算形を得る。過去のK/Vに関する0次・1次・2次の集約統計を更新する再帰形を導けるため、標準attentionのように全トークン分のK/Vを保持せずに推論する設計が可能となる。代償として、2次の統計を維持する計算・状態容量が必要であり、全てのモデル規模で高速になるとは限らない。

Non-approximateは内積とsoftmaxの形からさらに離れ、同じhidden stateから得たQとKの要素積を自己ゲートとして用いる。QへSiLUを適用し、時間方向の正規化を行う。これも再帰形を持ち、Approximateより小さい状態で実装できるが、正規化の分母が時間とともに単調増加するため、後続トークンが大きな注意重みを得にくい。uniformでは言語モデルとしてほぼ破綻するが、hybridでは標準層が表現を安定化させ、驚くほど品質が回復する。

### 4. RndEmbQK・FixedSeqQK：入力依存の注意重みをなくす

RndEmbQKはランダムな固定埋込みから、FixedSeqQKは固定の自然言語トークン列からQ/Kを作る。両方式とも入力系列が変わっても注意重みは変わらず、現在の入力に応じて変化するのはV経路である。固定トークン列はFineWeb-10BTから取得した最初の2048トークンを用い、固定Q/Kに弱い構文的な先験情報を与える狙いがある。

この構造では注意スコアを事前計算・キャッシュし、生成時に毎回QKを計算しなくてよい可能性がある。ただし固定注意は実際の質問や文脈へ柔軟に反応できないため、uniformでは性能が下がりやすい。RndEmbQKは固定自然言語列の先験情報も持たないため、FixedSeqQKより一般化が弱い条件がある。著者らは、固定注意の事前計算がCPU/GPU協調prefetchや先行した値の追い出しへつながる可能性を述べるが、これらは実装済みのオンライン最適化結果ではない。

### 5. StaticEmbQK：現在層の状態ではなく静的埋込みからQ/Kを作る

StaticEmbQKは入力トークンの静的埋込みからQ/Kを作り、現在の層で変化したhidden stateではなく元の入力に依存させる。したがって系列間の入力依存性は残すが、層を進むたびにQ/Kを再構成する必要を緩める。attentionスコアの一部を先に計算し、層間でprefetchできる余地がある。ただし、層固有の文脈表現を使えないため、注意行列が中間層で似通い、柔軟性を失う可能性がある。

StaticEmbQK自体の漸近計算量は標準attentionと同じ場合があり、単にQ/Kの由来を変えただけで線形attentionになるわけではない。性能と実装上の事前計算可能性は別の軸で評価すべきである。

### 6. hybrid・skipによる層間協調の検証

標準attentionを偶数層に、簡略化した方式を奇数層に配置するhybridを作る。さらに、学習済みhybridから簡略化層を除去したskipを評価する。もしhybridの改善が標準層だけによるものならskipも同程度の性能になるはずだが、実際にはskipの品質が大きく悪化する。これは簡略化層が標準層に依存しながらも有効な情報変換を担っていることを示す。

追加の配置実験では、標準attentionを25%程度残すだけでも一部の簡略化方式が競争力のある精度を維持する。標準層を1～2層だけ残す極端な条件では、簡略化方式自体の表現力がより重要になる。したがって「標準attentionは少しあれば常に十分」という単純な結論ではない。

|---|---|
| 主モデル | 約500Mパラメータ、同程度のパラメータ数へ揃えた各attention変種 |
| 追加検証 | 70M・160M級、GQA構成での確認 |
| 学習 | SlimPajama最大15Bトークン、50K英語中心BPE、系列長2048、バッチ約500Kトークン |

| 指標 | WikiText・LAMBADA困惑度、7種NLU正解率、attention entropy/concentration/head diversity/sink/local focus |

学習済みの標準Transformerを後から置換して測る研究ではなく、各変種を同じ予算で新規事前学習した比較である。この違いは、既存の公開LLMへ無学習で適用できるかを判断する際に重要である。

## 評価結果

### 500M級・WikiTextの文脈長別困惑度

| attention方式 | 128トークン | 512トークン | 2048トークン |
|---|---:|---:|---:|
| 標準attention | 69.9 | 47.8 | 38.1 |
| uniform MLP | 993.5 | 993.5 | 993.5 |
| uniform Approximate | 81.7 | 57.2 | 47.9 |
| uniform Non-approximate | 10023.7 | 9173.5 | 9025.9 |
| uniform RndEmbQK | 107.1 | 89.6 | 84.8 |
| uniform FixedSeqQK | 100.5 | 83.6 | 79.1 |
| uniform StaticEmbQK | 104.8 | 85.5 | 79.9 |
| hybrid MLP | 81.3 | 57.0 | 45.8 |
| hybrid Approximate | 71.8 | 49.3 | 39.4 |
| hybrid Non-approximate | 69.0 | 48.0 | 39.4 |
| hybrid RndEmbQK | 72.4 | 49.4 | 39.3 |
| hybrid FixedSeqQK | 69.0 | 48.0 | 38.5 |
| hybrid StaticEmbQK | 70.1 | 48.4 | 38.7 |

論文の文脈長別評価表に基づく。uniform Non-approximateの2048トークン困惑度9025.9に対して、hybridは39.4となる。uniform Approximateは47.9で、全層を単純化する中では比較的良い。FixedSeqQKはuniform 79.1だがhybrid 38.5まで改善し、標準38.1に接近する。これらの値は**別々に学習したモデルの困惑度**であり、同じモデルを量子化した前後の精度差ではない。

### 言語理解と簡略化層の寄与

論文Table 1では、uniform MLPの7種NLU平均は約40.0%で偶然水準39.9%に近い。hybrid MLPは約49%まで改善する。uniform Non-approximateも39.3%で偶然水準に近いが、hybridでは大幅に改善する。標準層と簡略化層の協調を確かめるskipでは、多くの条件でNLU平均が偶然水準を下回り、言語モデルの困惑度も爆発する。簡略化層を単に削除して標準層だけ残すことではhybridの品質を再現できない。

GQA構成でも、標準・Non-approximate・RndEmbQKを同じ15Bトークンで学習した比較から、標準層を交互に混ぜると簡略化方式の性能が回復するという傾向が維持される。ただしすべての方式・全モデルサイズで完全に標準attentionと同等ではない。学習の安定性、attention entropy、head多様性、sinkの分析から、標準層が活性分布の偏りや表現の崩壊を緩和している可能性が示唆されるが、因果機構を完全に特定したわけではない。

### 推論計算量とキャッシュに関する理論比較

標準attentionの全系列計算は入力長Lに対して概ねO(BL²d+BLd²)の項を含む。Approximate・Non-approximateは再帰形を使うことでattention部分を系列長に線形化でき、過去のトークンごとのK/Vをすべて保持する方式とは異なる状態表現を持つ。付録の推論時キャッシュ比較では、標準方式が概ね4BLdに比例するのに対し、Approximateは6Bd+4Bd²/h、Non-approximateは2Bd+4Bhに比例する状態で表現される（Bはバッチ、dはhidden幅、hはhead数）。ただしApproximateは2次統計を持つため、d²/hの項が大きいモデルでは必ずしも小さくならない。

RndEmbQK・FixedSeqQKは入力に依存しない注意スコアを事前計算できるため、計算とキャッシュの配置を工夫できる可能性がある。StaticEmbQKも入力の静的埋込みに基づく注意スコアを層間で事前計算できるが、漸近計算量自体が線形化するわけではない。**ここで報告された計算量・メモリ量は数式ベースの推定であり、実際の推論サーバーのGPU使用量やTPS改善率ではない**。

## 既存研究との差

既存のlinear attentionやSSMと標準attentionのハイブリッドは、実装上の速度と品質を改善することを主目的とする場合が多い。本研究は、標準attentionの複数原理を一つずつ外す制御実験を行い、uniformとhybridで結論が反転することを示した。とくにuniformで破綻するNon-approximateがhybridでは良い困惑度を示し、skip対照で簡略化層自身の寄与も確認する点が特徴である。推論システムの設計にとっては、単体の代替attentionの精度だけで採用可否を決めるべきでないという知見になる。

## 限界

第一に、主モデルは約500Mパラメータ、最大15B学習トークンで、現在の数十B～数百Bパラメータの実運用LLMへ一般化する証拠は限定的である。単一の英語中心BPE、系列長2048で学習しており、多言語、数十万トークン、MoE、推論特化学習モデルで同じ結果が得られるとは限らない。

第二に、簡略化したattentionを含むモデルを新規事前学習している。既存の標準attentionモデルへ同じ変種を後付けで差し込んで、同等の品質を得る方法ではない。代替層を削除したskipの性能悪化は、ハイブリッド構造を学習時から設計する必要性を示す。

第三に、推論時のKVキャッシュとFLOPsの式は理論解析であり、MI300X上の実測TPS、TTFT、P95遅延、実メモリ、カーネル実装の速度を直接検証していない。線形attentionは長文脈で有利でも、短文脈では定数項や状態更新費用が勝る可能性がある。固定注意スコアの事前計算もCPU/GPU間転送やキャッシュ管理の実装費用を含まない。

第四に、標準層の配置比率を変えた結果は方式ごとに異なり、標準attentionを25%残せば全ての代替方式が安全という一般則ではない。極端な1～2層の標準配置では簡略化方式の表現力不足が再び顕在化する。トークン混合の欠如を補える標準層の数もタスクに依存する。
