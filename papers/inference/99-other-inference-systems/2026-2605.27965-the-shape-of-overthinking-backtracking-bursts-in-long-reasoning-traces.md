# The Shape of Overthinking：長い推論過程における後戻りの群発と選択的早期終了

## 概要

本研究は、推論型大規模言語モデル（reasoning Large Language Model、reasoning LLM）が長い推論過程を生成するとき、**有用な自己修正と、解答の改善につながりにくい繰り返しの再検討を区別できるか**を調べる。着眼点は単純な推論の長さではなく、途中で結論を撤回する、仮定を見直す、導出をやり直すといった後戻り（backtracking）の強さ、発生時点、局所的な群発（burst）である。早い段階に孤立して現れる後戻りは正解の推論にもよく現れる。一方、中程度以上の後戻りが推論後半に繰り返し群発する軌跡は、誤答に偏る傾向がある。

主要実験はQwen3-8Bの明示的な思考モードで生成した、AIME2024・AIME2025各3000本、計6000本の数学推論軌跡である。行単位に分割した推論文へ、別の注釈実行で「継続・停滞・後戻り・終了」の確信度を割り当て、後戻りの強度に閾値を設ける。後戻りの開始位置が500語以内で連続するものを一つの群発として集計する。正答と誤答の群発数、初回後戻りの位置、総長で正規化した位置分布を比較した後、観測済みの推論接頭部分（prefix）だけから不安定さを予測し、選択的に終了する規則を構成する。

論文の重要な数値は、2000語時点の早期終了評価である。固定2000語の打切りでは残存軌跡の正解率がAIME2024で10.0%、AIME2025で6.7%になるのに対し、接頭部分の後戻り特徴で選別すると73.5%・64.5%となり、それぞれ21.7%・27.0%の軌跡を終了対象にできる。**ただし、この値は実際のサービング基盤に組み込んだオンライン測定ではなく、完成済みの推論軌跡を用いた事後再生の選別結果である。**また、12000語のような比較的緩い固定上限は強力で、すべての設定で提案手法が優位ではない。推論トークンの削減率、最終回答精度、実行時間を同一視してはいけない。

## 問題設定と既存方式の限界

推論時の計算量（test-time compute）を増やすと、難しい問題で正答率が上がる場合がある。しかし生成長を増やすほど常に得をするわけではない。ある推論は初期の計算ミスを一度訂正した後に正しい方向へ進む。他の推論は、同じ前提を何度も疑い、既に捨てた仮説に戻り、最後まで答えを安定させられない。固定の長さ上限は両者を区別せず、推論がまだ回復可能な場合も切ってしまう。

本論文の問題設定は、後戻りの存在を一律に悪い兆候とせず、**いつ・どれほど重く・どの程度まとまって発生するか**で状態を判断することである。単に「後戻りを何回したか」を数えると、長い推論ほど数が増えやすいという交絡がある。そこで著者は、初回発生時刻と推論全長に対する相対進行度を区別し、完成済み軌跡を20等分した相対位置で比較する。さらに、局所的に連続する重い後戻りの群発を数えることで、偶発的な訂正と反復する不安定さを区別する。

同時に、推論の終了判定で将来の情報を使ってはいけないという制約がある。完成した推論の総長で正規化した位置や、最終的に何回後戻りしたかは、実行中の推論器には分からない。従って論文は、完了軌跡の説明用の診断と、実行中に使える接頭部分だけの特徴量を明確に分ける。前者で見えた規則を後者へそのまま流用し、将来情報を漏らして精度を過大評価しないことが重要である。

## 手法

### 推論軌跡の分割と後戻り強度の付与

主要データはAIME2024とAIME2025から各30問、計60問を選び、各問題につき100本ずつ生成した6000本の軌跡である。生成器はQwen3-8B、温度は0.6、明示的思考を有効にした。各軌跡の推論部分を空行以外の行ごとに区切り、文字オフセットと語数を保存する。後から各行を同じ基盤モデルの非思考モードで分類し、継続（continue）、停滞（stall）、後戻り（backtrack）、終了（exit）の四つの行動ラベルと確信度分布を得る。

重要なのは、最頻ラベルが後戻りであるか否かと、後戻りの確信度が一定以上か否かは同じではないことだ。論文では後戻り確信度を強度の代用指標として用い、閾値τ以上の行だけを「該当後戻り事象」とする。閾値10は軽微な再確認まで広く拾う。20・30・40は中程度の後戻り、50・60は重い後戻り、70は極端な後戻りを見るための群である。これらは人手で保証された意味尺度ではなく、モデルの注釈スコア上の閾値である。

### 局所的な群発の定義

該当する後戻り事象の開始深さを、推論中に出力した語数でd1 < d2 < … < dnとする。隣接する事象の開始深さの差が500語以下なら同じ群発にまとめる。この規則で一つの軌跡をJ個の群発B1…BJに分割する。群発に含まれる事象が2個以上なら複数事象群発、3個以上なら密な群発と呼ぶ。

一つの軌跡から、2個以上の群発の数K、該当後戻り事象のうち2個以上の群発に含まれる割合S、事象数と群発数の比ρ=n/J、最大群発サイズm_maxを計算する。該当事象がない場合はこれらをゼロとする。これにより、後戻りが全体に散発的に出る場合と、短い区間で何度も再考が連鎖する場合を別の数値で表せる。

例えば同じ4回の後戻りでも、2000語ごとに独立して現れれば群発は単発四つである。ところが100語、150語、200語の間隔で続けば一つの4事象群発となり、同じ回数でも強い局所的な不安定さとして扱う。群発幅500語は実験上の設定であり、付録で幅への感度も検討している。これを全モデルに共通する最適値と考えてはいけない。

### 相対進行度と初回発生時点の比較

完成した推論を20等分し、各区間に属する行について該当後戻り事象の発生確率を計算する。これによって「誤答は単に長いので後戻り回数も多い」という説明だけで差が消えるかを検証する。また、最初に閾値を超える後戻りが何語目に現れるかを比較する。早い自己修正が正答と両立するなら、初回後戻りが早いという理由だけで打ち切るのは誤りになる。後半まで繰り返し重い後戻りが現れるという時間的形状を別に測る必要がある。

### 観測済み接頭部分だけを使う早期終了

実行中の判定では、2000語、5000語、8000語、12000語といったチェックポイントdに到達した時点で、そこまでの推論文を行単位に分割する。閾値20・40・50に対する後戻り頻度、群発への集中度、群発の大きさ、初回発生深さなど、接頭部分だけで計算できる特徴量x(d)を抽出する。学習済みスコア関数f_dから、現在の軌跡が最終的に誤答となる確率に相当する値p_wrong(d)を出し、閾値c_d以上なら終了または別経路への振り分け対象にする。

2000語では、閾値20以上の後戻り事象が2個未満なら無条件で継続する保護規則がある。これは、初期の単発修正を誤って異常扱いしないための制約である。特徴量は完成後の全長や将来の後戻りを参照しない。論文の実験では、終了対象を除外した残りの軌跡について正答率と除外率を報告する。終了時に部分回答を返す、別モデルへ切り替える、再サンプリングする、といった後段の処理は運用上の選択肢であり、ここで実測した完成パイプラインではない。

### 再現上の重要な分離

推論の「語数」はトークナイザのトークン数ではない。生成時間やGPU計算量へ変換する際に語数をそのままトークン数として使ってはいけない。注釈は元の推論生成とは別パスで行われ、元の生成器は思考モード、注釈器は非思考モードである。さらに、正誤は最終回答を抽出し、記号の軽い正規化を行って完全一致で判定する。各問題から同数の軌跡を抽出しているので、AIMEの全体正答率は問題ごとの平均正答率にもなる。

AIME2024の基準正答率は73.2%、平均推論長8743語、中央値7309語である。AIME2025は正答率64.5%、平均9646語、中央値9288語であり、後者の方がこの実験では難しい。中央値の行数は前者330、後者405である。いずれも語数と行数は注釈済みの推論部分から算出し、基準正答率は元の軌跡から算出するという集計上の違いがある。

### 評価結果

### 初回後戻りは正答の方が早い場合がある

中程度の閾値群では、AIME2024の正答軌跡の初回該当後戻り中央値は約2000語、誤答軌跡は約3000語である。AIME2025では約1700語と約2500語になる。より重い閾値群でも、AIME2024は正答約2500語、誤答約3500語、AIME2025は約2100語と約3500語となる。**最初の後戻りが早いこと自体は失敗の印ではない**。正答に至る推論ほど、早い段階で局所的な問題を見つけて修正する場合がある。

一方、推論全体のどこかで後戻りが発生した軌跡の割合は、誤答の方が高い。中程度の閾値群では、AIME2024の正答軌跡で約93.0～95.8%、誤答で99.8～99.9%が該当する。つまり「一回あったか」という二値判定ではほとんど区別できない。初回の早さと、その後も継続して後戻りを起こすかどうかを分ける必要がある。

### 推論長をそろえても誤答は後半の後戻りが多い

推論全体を20分割して比較すると、誤答の後戻りは最終区間で高頻度になる。中程度の閾値群の最終区間の該当確率は、AIME2024で正答0.040～0.050、誤答0.213～0.247、AIME2025で正答0.027～0.034、誤答0.130～0.151である。これらは総語数で正規化した相対進行度上の比較であり、単に誤答の推論が長いから発生回数が多いという説明では消えない差である。

ただし、相対進行度は完成後の総長を知って初めて計算できる。この診断をそのままオンライン早期終了の特徴量にするのは将来情報の漏洩である。著者は、相対進行度の分析を現象の説明に使い、実行時の判定では現在までの絶対語数と接頭部分の群発統計に置き換えている。

### 群発構造が単純な後戻り回数より有用

中程度の閾値群で、AIME2024の一軌跡あたり複数事象群発の平均個数は、正答1.793～1.897、誤答4.711～4.776である。AIME2025では正答2.140～2.260、誤答4.427～4.522である。後戻り事象のうち群発に属する割合も、AIME2024で正答0.695～0.734、誤答0.922～0.929と開く。これは誤答が単に後戻り回数を多く含むだけでなく、**近接した位置で再検討を繰り返す**ことを示す。

重い閾値群でも同じ傾向が残る。AIME2024の複数事象群発数は正答1.154～1.215、誤答3.911～3.989であり、AIME2025では正答1.293～1.424、誤答3.266～3.363である。群発の始まりを相対進行度で比較しても、誤答は後半に新たな群発を始めやすい。極端に緩い閾値ではほとんどの事象が巨大な群発へつながるため識別力が落ち、極端に厳しい閾値では事象が少なすぎる。中程度の強度を複数比較する設計が必要になる。

### 完成軌跡の事後選別と固定長制限

| 事後選別 | AIME2024残存正答率 | AIME2025残存正答率 | 除外率AIME2024/2025 |
|---|---:|---:|---:|
| 選別なし | 73.2% | 64.5% | 0.0% / 0.0% |
| 固定12000語 | 80.6% | 71.7% | 29.9% / 38.7% |
| 固定10000語 | 82.9% | 68.0% | 38.6% / 50.0% |
| 固定8000語 | 71.9% | 54.4% | 49.9% / 61.5% |
| 群発だけの選別 | 77.8% | 68.0% | 47.4% / 55.6% |
| 複合構造選別 | 77.4% | 65.0% | 44.8% / 73.0% |

固定8000語のように厳しい条件と比べれば、群発だけの選別はAIME2024で+5.9ポイント、AIME2025で+13.6ポイントの残存正答率を示す。ただし除外率は完全一致ではないので、厳密な同一運用点の比較ではない。固定12000語や10000語はなお強力で、完成軌跡を全部見られる条件では提案した複合構造選別が常に優位というわけではない。論文はこの負の結果を明示しており、構造特徴の主な用途を**途中で判定しなければならない場合**に絞っている。

### 接頭部分だけの選択的早期終了

| 判定深さ | 固定打切り残存正答率 AIME2024/2025 | 接頭部分選別残存正答率 AIME2024/2025 | 接頭部分選別の除外率 AIME2024/2025 |
|---|---|---|---|
| 2000語 | 10.0% / 6.7% | 73.5% / 64.5% | 21.7% / 27.0% |
| 5000語 | 45.7% / 35.9% | 68.2% / 60.2% | 64.6% / 49.1% |
| 8000語 | 71.9% / 54.4% | 73.9% / 64.1% | 42.7% / 45.2% |
| 12000語 | 80.6% / 71.7% | 79.4% / 69.3% | 26.8% / 35.0% |

2000～8000語では、固定打切りより接頭部分選別が高い残存正答率を示す。12000語では固定上限が逆転する。これは、初期段階では固定長制限が回復可能な推論を大量に捨てる一方、群発構造に基づく選別は初期の単発修正を許容するためである。実際の運用では、残存正答率だけでなく、どれだけの要求を中止し、最終回答を失ったか、別経路へ回すコストがいくらかを同時に考える必要がある。

### 他モデル・他課題での傾向

AIMEのほか、Phi4RやQwen3.5-9B、GPQA-Diamond、OmniMathなど11の追加モデル・課題組合せで、誤答軌跡の方が長く、複数事象群発も多いという定性的な方向は保たれた。例えばAIME2024でPhi4Rの閾値20以上の群発数は正答0.62・誤答2.35、Qwen3.5-9Bでは正答2.61・誤答4.60となる。ただし注釈器のスコア分布はモデルによって大きく異なる。Qwen3.5-9Bではスコアが低域と高域に集中するため、同じ数値閾値を異なるモデルにそのまま流用できない。

OmniMathは問題あたり一軌跡であり、同一問題内の複数サンプルから学ぶ設定が成立しない。そのため論文の接頭部分選別の追加評価では、同問題の情報がなく全軌跡を残す設定が生じる。これは有効な早期終了が成功した結果ではない。GPQAの推論は比較的短く、固定打切りとの差も小さくなりやすい。定性的な群発傾向が複数課題で再現されたことと、同じ終了ポリシーが全課題で有効であることは別の主張である。

## 既存研究との差

LayerSkipや自己投機的復号（self-speculative decoding）などは、トークンを生成する各ステップの計算を軽くすることに主眼がある。予算制約付きの推論や回答安定性に基づく終了方式は、推論の長さを制御する。本研究はその間に位置し、**生成中の推論文の局所的な後戻りの配置を、計算継続の判断材料にする**。追加のドラフトモデルや新たな強化学習目的を前提とせず、注釈された推論文から特徴量を抽出して終了判断を学習する点が異なる。

この違いは計算資源の扱いにも現れる。各トークンの生成速度を速くする方式と、そもそも生成を打ち切る方式では、節約できる計算量の意味が異なる。後者は終了した要求の回答品質や再試行コストと不可分であり、単に平均生成語数が減っただけでは良いサービング方式と判定できない。著者の評価は推論途中で使える特徴量を明示した点で価値があるが、停止後の回答保証や代替モデルへの引継ぎは別途設計が必要である。

## 限界・負の結果・実装上の注意

第一に、最も統制された実験はQwen3-8BとAIMEの組合せである。追加11組合せではモデル、回答形式、問題数、サンプリング数、正誤判定方法が変わる。OmniMathの正誤判定にはGPT-4oによる評価も用いられる。結果の方向がそろっても、効果量や閾値を同じものとして比較できない。

第二に、後戻り強度は人手の確定ラベルではなく、モデルが行単位に付けた確信度である。異なる注釈器のスコアは同じ校正を持たず、しきい値20や50に絶対的な意味はない。行分割に依存するため、改行の少ない出力や非英語の推論文では、同じ規則が機能するか再検証が必要になる。論文は長さを語数で測り、トークナイザのトークン数とは区別している。

第三に、接頭部分の判定器は完成軌跡を再生して評価した。実際に推論を止めるオンラインシステムへ組み込んだわけではない。推論中に行を分類するための追加モデル呼出し、注釈待ち時間、バッチ分断、GPU利用率、KVキャッシュ保持量、失敗判定後の再サンプリング費用などを測っていない。分類器の計算負荷が大きければ、削減した生成計算よりも監視費用が高くなる可能性がある。

第四に、残存正答率は終了対象を除いた集合の正答率であり、元の全問題に対する解答率ではない。高い残存正答率と引換えに多くの軌跡を捨てる方式は、ユーザーに回答を返すサービスでは別のコストを生む。停止対象を再試行するのか、棄権するのか、別のモデルへ振り分けるのかによって、実際の品質と費用は変わる。論文の表4の数字を、そのまま「正答率を73.5%へ改善しながら計算を21.7%削減した」と読むのは誤りである。

第五に、完成軌跡の中程度の固定長制限は非常に強い基準であり、構造フィルタが全条件で勝つわけではない。12000語では固定制限が接頭部分方式を上回る。さらに、群発の幅500語やスコア閾値は実験的設定であり、他の生成温度、推論指示、モデル規模へ移植するには再校正が必要である。

## 推論基盤への位置付け

本論文は、長い推論過程に対する計算予算の適応制御と、推論時の早期終了に属する。GPUカーネル最適化や分散サービングの直接の高速化研究ではないが、長い推論を生成するモデルの要求処理量を減らすための判断信号を提供する。サービング基盤へ導入する場合、まず観測済み接頭部分から群発特徴を低費用で計算する方法、判定器の校正、停止した要求の扱い、同時要求下の待ち行列効果を設計しなければならない。

特に、生成中に全行を別の大規模モデルで注釈すると、追加の推論呼出しがボトルネックになりうる。より軽量な分類器、既存の隠れ状態の再利用、一定間隔での判定などは実装上の検討候補だが、原著がそれらを実証したと読み替えてはいけない。正答率を保証する停止器でもなく、誤答になりやすい軌跡を選択的に検出する予測器である。
