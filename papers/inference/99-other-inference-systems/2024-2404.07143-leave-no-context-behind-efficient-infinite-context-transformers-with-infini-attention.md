# Leave No Context Behind: Efficient Infinite Context Transformers with Infini-attention

## 概要

Infini-attentionは、入力文脈が数十万から100万トークンに達しても、過去の全トークンに対応する鍵・値（KV）を保存し続けずに情報を参照するための注意機構である。入力を固定長の区間へ分割し、現在区間では通常の因果自己注意を使って細かなトークン間関係を計算する。一方、処理済み区間のキーと値は、各注意ヘッドに固定サイズの連想行列Mと正規化ベクトルzとして集約する。次区間のクエリはMとzへ問い合わせ、過去情報の圧縮された読み出し結果を得る。二つの出力は学習可能なゲートで統合される。

この設計の特徴は、長期状態の容量が処理済みトークン数ではなく、各ヘッドのキー次元と値次元に依存する点にある。短距離の正確な注意と、長距離の損失を伴う圧縮記憶を同じTransformerブロックに置くことで、入力が長くなっても長期記憶そのものは増えない。通常のTransformerへ推論時に単純なキャッシュ置換を行う方式ではなく、注意ブロックを改変して継続事前学習・微調整するモデル設計である。

論文は、PG19の単語予測のパープレキシティをMemorizing Transformerの11.37から9.65へ改善し、比較対象の長期記憶パラメータ数183Mに対して1.6M、約114分の1を報告した。さらに1Bモデルのパスキー検索では、長さ5Kの入力で400ステップ微調整した後、最大1Mの入力を評価した。8Bモデルでは長さ32Kで微調整し、500Kの書籍全文要約を評価した。ただし「無限文脈」は過去情報を無損失に保持する意味ではなく、固定状態へ要約し続けられるという計算資源上の性質を指す。

## 問題設定と必要な背景

標準的な自己注意は、入力区間の各トークンについて他のトークンとの対応度を求める。長さLの区間全体へ注意をかける場合、注意得点の組合せは概ねLの二乗に増える。自己回帰推論では計算済みのKVを保存するため、長い会話や資料をそのまま保持するとKVキャッシュの容量も文脈長に応じて増える。区間を短く固定すれば計算量は抑えられるが、古い区間を破棄すると長距離の事実を参照できない。

Transformer-XLは直前区間の状態を再利用して窓を伸ばすが、保持する過去区間の数には限界がある。Memorizing Transformerは長期KVを検索可能な形で保持するため、参照可能範囲を伸ばすほど保存量が増える。圧縮要約を特別なトークンとして次区間へ渡す方式では、要約トークン数を増やさなければ品質が不足する場合があり、要約量と計算量の交換条件が残る。Infini-attentionは、過去区間を次々と同じ行列へ再帰的に取り込むことで、長さ方向に伸びない記憶を目指す。

圧縮行列はトークン単位の辞書ではない。過去のキーと値の対応を重ね合わせた連想メモリであり、現在のクエリと似たキーに対応する値を近似的に取り出す。複数の異なる事実が同じ容量へ蓄積されるため、時間が長くなるほど記憶干渉や細部の損失が起こり得る。この限界を前提に、近距離は通常注意、遠距離は圧縮メモリという二層構造を採用する。

## 手法

### 1. 現在区間の正確な因果注意

入力列を長さNの区間X_sへ分ける。各注意層は現在区間からクエリQ、キーK、値Vを通常の線形射影で生成する。局所注意は、未来位置を参照しないマスク付きの内積注意として、現在区間のQK転置の得点を正規化し、Vの重み付き和A_dotを出力する。この処理は標準の多頭注意に近いため、同一区間内の細かな語順や依存関係を保持できる。論文の主要実験ではN=2048を使用する。

Infini-attentionは各層・各ヘッドに長期状態を追加するが、局所注意のQ/K/V射影をもう一式作るのではない。現在区間のQ/K/Vを、局所注意と圧縮メモリの読み書きで共用する。この共用により、長期記憶のための追加射影を増やさず、既存Transformerの注意ブロックを比較的小さな変更で長文脈へ適応できる。

### 2. 連想行列Mと正規化ベクトルzからの読み出し

前区間までの記憶をM_(s-1)とz_(s-1)とする。Mはキー次元d_keyと値次元d_valueの積に相当する行列、zはキー次元のベクトルである。現在のクエリに要素ごとの非線形変換σを適用し、A_mem = σ(Q)M_(s-1) / [σ(Q)z_(s-1)] で過去情報を読み出す。論文はσとしてELU+1を用い、負値の扱いと正規化の安定性を確保する。

分子はクエリに適合する連想行列の成分を値空間へ写し、分母は蓄積キーの総量に応じて規模を調整する。zを省くと、過去区間を多数取り込むほどメモリの出力尺度が変化しやすい。Mとzの大きさはトークン数でなく特徴次元で決まるため、区間が増えても保存領域は一定である。一方、同じ容量へ多数のキーを重ね合わせるため、個別の過去トークンを無損失に復元できるわけではない。

### 3. 読み出し後のメモリ更新と差分規則

重要な処理順は「前区間までの記憶から現在区間へ読み出し、その後で現在区間を記憶へ書き込む」である。基本の線形更新（Linear）は、M_s = M_(s-1) + σ(K)^T V、z_s = z_(s-1) + Σ_t σ(K_t) とする。各トークンのキーと値の外積を足し込むため、Mの行列形状は変わらない。更新後のM_sとz_sを次の区間へ渡し、過去の全KV配列は保持しない。

差分更新（Linear+Delta）は、書き込む値Vから、現メモリに同じKで問い合わせて得られる予測値を差し引いてから外積更新する。すでに記憶されている対応を重複して強めるのではなく、予測しきれなかった差分を蓄積する意図である。式では M_s = M_(s-1) + σ(K)^T [V - σ(K)M_(s-1)/{σ(K)z_(s-1)}] と表せる。正規化項zは基本更新と同じ規則を使う。差分計算には追加の読み出しが必要だが、同じキー・値対応が繰り返される場合に不要な更新を抑える。

### 4. 局所情報と長期情報のゲート混合

各ヘッドは局所注意のA_dotと長期メモリのA_memを同時に得る。学習可能なスカラーβをシグモイド関数へ通し、A = sigmoid(β) A_mem + [1-sigmoid(β)] A_dot として二つを混合する。βはヘッドごとに1個の追加学習パラメータであり、区間ごとの情報を詳しく見るか、過去から圧縮して引き出すかをヘッド単位で調整する。

各ヘッドの混合出力を連結して通常の出力射影へ渡すので、後段のTransformer層が受け取るテンソルの形状は標準注意と同様になる。論文の可視化では、ゲートが0または1に近い「局所専用」「長期専用」のヘッドと、0.5付近で両者を混ぜるヘッドが現れた。各層に少なくとも一つの短距離ヘッドが残り、局所情報が上位層へ伝わる経路を確保している。

### 5. 位置埋め込みと学習時の時系列処理

長期メモリは区間を跨いだ全体情報を蓄積するため、メモリのキー・クエリへ直接位置埋め込みを適用しない。論文では圧縮メモリの読み書き後に、局所注意へ用いるQ/Kへ位置情報を適用する。これにより長期連想状態が特定区間の位置に固定されることを避ける。一方、位置の厳密な保存能力は圧縮によって制約されるため、長距離の位置特定を一般に保証するわけではない。

学習時は区間ごとの再帰状態を通じて誤差を逆伝播させる。時系列逆伝播（BPTT）を用い、区間ごとの勾配チェックポイントで活性値保存量を抑える。実装上は注意層の内部で入力を区間化し、区間を順次処理した後、出力を元の長さへ連結して次層へ渡す。推論時の長期状態は固定サイズだが、学習時の逆伝播や区間ごとの処理には追加の計算・管理費用がある。

### 6. 状態量と計算量の意味

1層・1ヘッドの長期状態はMのd_key×d_value要素とzのd_key要素であり、全層・全ヘッドではd_key(d_value+1)H lに比例する。ここに処理済み区間数Sは現れない。対照的に、過去区間のKVを保存する方式はN、S、保持区間数のいずれかに比例する記憶を要する。現在区間の局所注意はNに対する二乗の処理を残すが、Nを固定してストリーミング処理するため、過去すべてのトークンへ二乗注意を再実行する必要がない。

「無限に処理できる」という主張は、固定のNと固定サイズのM/zを用いて、区間を何回でも順次処理できることを意味する。各区間の計算費用は残り、総入力長に対する総計算時間まで定数になるわけではない。情報量が無制限に保存される保証でもない。固定サイズの連想行列へ多くの過去情報を重ねることによる干渉が、精度面の根本的な交換条件となる。

## 評価結果

### 予測精度と記憶量

| 方式 | PG19のPPL（低いほど良い） | Arxiv-mathのPPL | 長期記憶量 |
|---|---:|---:|---:|
| Transformer-XL | 11.88 | 2.42 | 50M |
| Memorizing Transformer | 11.37 | 2.26 | 183M |
| RMT | 13.27 | 2.55 | 2.5M |
| Infini-Transformer（Linear） | **9.65** | 2.24 | **1.6M** |
| Infini-Transformer（Linear+Delta） | 9.67 | **2.23** | **1.6M** |

この表は論文の表2に対応する。Memorizing Transformerと比べてInfini-TransformerはPG19のPPLを11.37から9.65へ下げ、Arxiv-mathも2.26から2.24へ改善した。記憶量は183Mから1.6Mへ減り、論文が報告する114倍の圧縮率となる。ここでの114倍は比較対象の「長期記憶パラメータ量」の比であり、モデル全体のGPUメモリや実機推論速度が114倍改善したという意味ではない。

差分更新は常に優位ではない。PG19では基本更新9.65に対して差分更新9.67とわずかに悪く、Arxiv-mathでは2.24から2.23へ改善する。100K系列で学習するとArxiv-mathのPPLは基本更新2.21、差分更新2.20まで下がった。長期情報を多く学習することの利得はあるが、差分規則の優劣は課題によって異なる。ゲート可視化も、すべてのヘッドが一律に長期情報を使うのではなく、局所・長期・混合の役割分化が起きることを示している。

| 32K | 14/13/98 | 100/100/100 | 100/100/99 |
| 128K | 11/14/100 | 100/100/100 | 100/100/99 |

この表の先頭・中央・末尾は、隠した数字の位置を表す。微調整前は末尾近くの数字はほぼ正確に回収できる一方、先頭や中央では多くを失敗しており、固定メモリが最初から完全な長距離検索を行うわけではない。5K長で400ステップ微調整した後、1M長でも基本更新は96/94/100%、差分更新は100/100/100%になった。従って、単にモデルへ圧縮メモリを付ければ即座に100万トークンを検索できるという解釈は誤りである。訓練と評価の長さを分け、短い微調整からの長さ外挿を確認した結果である。

この検索課題は繰り返した文章片へランダムな数字を埋め込む形式であり、多数の異なる事実を同時に保持する文書理解や、長い証明の論理的一貫性を直接測っていない。100万トークンの結果は合成検索への適応能力の証拠であって、任意の実文書の完全記憶を示すものではない。

| PRIMERA + Unlimiformer | 37.9 | 8.2 | 16.3 | 17.2 |
| Infini-Transformer（Linear） | 37.9 | 8.7 | 17.6 | 18.0 |

書籍要約では8Bモデルを8K入力で継続事前学習し、32Kで微調整してから最大500Kの本文を与える。差分更新は基本更新の総合18.0を18.5へ上げ、従来のPRIMERA+Unlimiformerの17.2も上回った。論文の図4は書籍から与える文字量を増やすほど総合ROUGEが改善する傾向を示す。ただし比較相手は専用の符号化器・復号器モデルであり、モデル規模、事前学習、推論計算量まで完全にそろえた公平な同一構成比較ではない。ここで示されたのは、圧縮メモリを備える8Bモデルが非常に長い書籍を取り込んで有効な要約を生成できるという実験結果である。

## 既存研究との差

Transformer-XLは直前区間のKVを保持して再利用するが、保持窓を超える過去は失う。Compressive Transformerは古い状態を別の圧縮キャッシュへ移すものの、古い圧縮状態をいずれ破棄する。Memorizing Transformerは検索対象のKVを蓄積し、広い過去を参照する代わりに記憶容量が系列長へ依存する。Infini-attentionは過去を区間ごとにMとzへ累積し、状態の次元を固定する点で異なる。

RMTやAutoCompressorのような要約トークン方式は、過去区間の内容を少数の特別トークンへ圧縮して次区間へ渡す。Infini-attentionはトークンとして要約を再投入せず、キー・値の連想行列として保存し、クエリによる線形読み出しで取り出す。したがって長期記憶の読み書きは注意層内部の演算で完結し、要約トークン数を増やすことによる系列長増大を避ける。

位置埋め込みを伸ばす方式や、長文を窓分割して処理するだけの方式とも異なる。位置表現の拡張だけでは過去全KVの保存費用が残り、窓分割だけでは古い内容が失われる。Infini-attentionは注意機構に圧縮記憶を追加し、継続学習によって古い情報の取り出し方そのものを獲得する。

## 限界と解釈上の注意

固定サイズのMとzには有限の情報量しかない。過去の全トークンを保存するのではなく、キーと値の統計的な結合を重ねるため、似たキーが多数現れたり、互いに干渉する細かな事実が大量に入ったりすると回収品質は保証されない。100万トークンのパスキー検索は微調整後の合成課題であり、実世界の100万トークン文書に含まれる全事実の厳密な検索を証明していない。

本方式は推論時に既存TransformerのKVキャッシュだけを入れ替える仕組みではない。注意層の演算と状態更新を変更し、継続事前学習・微調整を行っている。訓練時は区間間の時系列逆伝播と勾配チェックポイントが必要であり、長い系列を扱うための学習コストは残る。区間内の通常注意はNに対する二乗計算を行い、総入力を読み終える時間まで定数になるわけではない。

論文はメモリパラメータ量と予測精度を詳しく評価しているが、現代のLLMサービング環境における絶対トークン毎秒、GPUメモリ実測、複数要求同時実行、長文生成中のKVキャッシュ管理などを網羅的に比較したものではない。114倍という値は長期記憶の容量比較であって、実際のサービス全体のメモリ削減倍率ではない。最大500KのBookSumでのROUGE向上も、すべての要約評価指標や人手評価での優越を保証しない。
