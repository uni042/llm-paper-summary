# Beyond Classical Attention: Quantum Attention for Scalable Computation

## 概要

本論文はTransformer/LLMの注意計算を量子アルゴリズムで高速化できる条件を理論的に調べる。対象は QK^T の各行で、ある閾値τ以上の大きな要素が高々k個しかないという疎性を持つ注意である。

通常はn token間の全組合せ内積を扱うためn²項が現れる。提案法はGrover探索を使って各行の「大きな内積」だけを見つけ、その大要素からなる疎成分と、残りの小要素を近似する低ランク成分を組み合わせる。正規化softmax注意との差を∞ノルムで制御する保証を与える。

推論時の注意行列計算について、条件付きで概ね O~(n^1.5 k^0.5 d + nkd) の量子計算量を示す。さらにGrover部分を計算幾何データ構造へ置き換えた古典近似と、強指数時間仮説（SETH）に基づく古典的な大要素発見のn^(2-o(1))下界も示し、どこに量子優位が生じるかを分離する。

## 問題設定

注意はQ,K∈R^(n×d)から全token対の内積QK^Tを作り、指数化・行正規化して重みを得る。長系列ではn²個の組を扱うことが主要な計算量になる。

ただし実際の注意が「少数の強い結合と、多数の弱い結合」に分かれるなら、全要素を同精度で計算する必要はない。論文はこの性質を(τ,k)-goodという条件へ形式化し、各行でτ以上の要素が高々k個という仮定を置く。

課題は、大要素が疎でもその位置を探すために全n²要素を走査すれば高速化にならない点である。そこで量子探索で位置発見自体を高速化する。

## 手法

### Grover探索による大注意要素の発見

各query行について、keyとの内積が閾値τを超える位置をGrover探索で探す。古典的な全走査では各行n候補を見るが、量子探索は疎な該当位置を平方根的な探索費で見つける。

全n行で高々k個ずつ大要素があるという仮定を利用し、大要素集合S_iを列挙して疎行列を構成する。d次元内積の計算費も含めるため、単純な「√n」だけではなくn,k,dを含む複雑度になる。

### 疎成分と低ランク成分の分解

大きな注意値だけを残すと、softmax正規化の分母に多数の小要素が寄与するため単純top-kとは異なる誤差が生じる。提案法は近似行列Bを、k-row-sparseなB1と低ランクのB2へ分解する。

B1が大注意要素を保持し、B2が残りの背景寄与をまとめる。この構造により D(A)^(-1)A と D(B)^(-1)B の∞ノルム誤差をO(η)に抑える条件を証明する。ここでηは閾値未満の内積範囲を制約する量である。

### 推論注意への適用

近似注意Bが得られれば、値行列Vとの積を疎成分・低ランク成分それぞれで計算できる。大要素数がnkに制限されるため、密なn²注意行列を明示的に処理する費用を避ける。

論文の非形式的定理では、1回の推論注意行列計算を O~(n^1.5 k^0.5 d + nkd) 時間で行えるとする。これはkがnより十分小さく、疎性仮定が成立する領域でのみ二次計算に対する優位を持つ。

### 古典アルゴリズムと下界

量子探索だけを比較対象にせず、Grover部分を計算幾何のデータ構造へ置換した古典法も構成する。固定小次元dの条件で、O~_d(nk+n^(2-1/⌊d/2⌋))時間の近似を与える。

一方、大内積要素を見つける問題を最大内積問題（Max-IP）へ還元し、SETHの下では特定次元でn^(2-o(1))より速い厳密古典アルゴリズムが存在しないことを示す。量子法の価値を「既知GPU実装より何倍速い」ではなく、計算量クラスの差として位置付ける。

## 主要結果

|結果|計算量・保証|意味|
|---|---|---|
|量子推論注意|O~(n^1.5 k^0.5 d + nkd)|k≪nなら密なn²走査より漸近的に有利|
|古典近似|O~_d(nk+n^(2-1/⌊d/2⌋))|固定小dでは古典側にも部分的高速化余地|
|近似構造|k-row-sparse + rank-1|大注意と背景寄与を分離|
|近似誤差|∞ノルムO(η)|閾値外内積が小さいという仮定に依存|
|古典下界|n^(2-o(1))|SETH下で大内積の厳密発見に強い制約|

## 既存研究との差

Reformerや低ランク注意、KDEformer等は古典計算上で注意構造を近似・変換する。本論文は注意の疎な大要素を量子探索対象とし、その位置発見自体をGrover探索へ移す。

同時に古典近似と古典下界も提示するため、量子アルゴリズムだけを孤立して提案せず、同じ疎性仮定で古典計算がどこまで近づけるかを理論的に比較する。

## 限界

最大の制約は理論的な量子アクセスモデルと(τ,k)-good疎性仮定である。実際のLLMで各層・各head・各入力がこの仮定をどの程度満たすかを大規模実測しておらず、量子メモリへのQ/Kロード費や誤り訂正量子計算の定数費用も端から端まで評価していない。

したがって本論文の多項式高速化を現在のGPU推論に対する実測速度倍率として解釈してはいけない。実用性は量子データアクセス、kのスケーリング、閾値条件、量子ハードウェアの実装費に依存する。
