# Attention-Based Sampler for Diffusion Language Models

## 概要

本論文は、マスク拡散型大規模言語モデル（dLLM）の生成時に、**どの位置のマスクを先に確定するか**を注意行列から決める学習不要の復号法Attn-Samplerを提案する。自己回帰モデルは左から右へ一つずつ生成するが、マスク拡散モデルは複数位置の予測を反復して確定できる。既存の復号法は各位置の最大予測確率、確率差、エントロピーなど局所的な確信度を使うことが多い。しかし「その位置が他の位置からどれだけ参照されているか」という系列全体の依存関係を使わないと、先に確定すべき位置を誤る可能性がある。

著者は生成順序を、全ての他トークンが見える理想的な尤度と実際の確定順序に基づく尤度の差（permutation dependency gap）を最小化する問題として扱う。元の組合せ最適化はNP困難であるため、確定順位だけに依存する期待二乗誤差最小の近似を導き、その近似目的を最小にする順序が**注意行列の列和の降順**であることを示す。実装は各反復でマスク位置の注意列和を求め、優先度が高い位置を先に確定する。並列版では確信度と注意得点を組み合わせた動的閾値で同時に確定する位置を選ぶ。

単一NVIDIA A6000でのFast-dLLM v2 7B、GSM8K評価では、従来の確信度優先方式が約35トークン/秒・82.7%正答率であるのに対し、Attn-Samplerは95トークン/秒・84.2%、または107トークン/秒・82.6%を達成する。後者は同程度の正答率で約3.06倍の生成処理量に相当する。ただしこれは特定の拡散モデルと課題における実測であり、自己回帰LLM全般の高速化ではない。

## 問題設定：マスク確定順序の最適化

マスク拡散型LLMは、未確定位置をマスク記号で表し、モデルの前向き計算で各マスク位置のトークン分布を予測する。ある位置を確定すると、その内容が次の反復の文脈に入る。したがって確定順序は、後から予測する位置に提供できる情報を変える。単純に「現在の最大確率が高い位置」から確定すると、他の多数の位置の推論に重要なトークンを後回しにする可能性がある。

確信度優先は一つの位置の分布だけを見て、最大確率の高いトークンを確定する。余裕度優先は上位二候補の差、エントロピー優先は分布の不確実性を用いる。いずれも予測の局所的な信頼度には意味があるが、系列全体の依存を直接表さない。Attn-Samplerは、他の位置がその位置へ向ける注意の総量を、後続の予測へ影響する度合いの代理量とする。

確定順序を置換πと書くと、生成の対数尤度は各位置を確定した時点で既知の位置に条件付けした対数確率の和になる。著者は、もし対象位置以外の全ての真値が分かる理想状態で計算した対数尤度との差を定義する。理想状態は実際の推論では利用できないが、順序による情報欠損を解析する参照となる。この差を直接最小化するのは、各トークン対の前後関係が絡む組合せ問題となる。

## 手法

### 理論：NP困難な順序問題から列和の順位へ

一層・単一ヘッドのsoftmax注意を持つTransformerを考える。注意行列Aの要素`A_ij`は、位置iが位置jへどれだけ注意を向けるかを表す。著者は一次近似の下で、順序による尤度差の上界が、確定時点までに利用できる注意重みの組合せ和で表されることを示す。上界は各トークン対の相対順序に依存し、重み付き線形順序問題と同型になるためNP困難である。

そこで、位置jが何番目に確定するかという順位`π(j)`だけを固定し、残りの位置の順序を平均したとき、元の対依存項を最小二乗誤差で近似する関数を求める。この最適な順位依存近似は概ね`(π(j)-1)/(b-1) × Σ_{i≠j} A_ij`であり、`b`はブロック内のマスク位置数である。ここで`Σ_{i≠j} A_ij`は位置jへ他位置から向けられる注意の総量、すなわち対角成分を除いた列和である。

この近似目的は「順位の重み×注意列和」の和となる。注意列和の大きい位置を遅く置くと費用が増えるため、隣接する順序を交換して改善できることから、**注意列和の降順が近似目的の最適順序**と示せる。これは元のNP困難な目的そのものを大域最適化する保証ではない。また一層・単一ヘッドモデルと一次近似から導いた理論であり、実際の多層・多ヘッド拡散LLMで全ての入力の生成品質が必ず改善するという定理ではない。

### 逐次版の実装

逐次Attn-Samplerは、入力文脈の末尾へ長さbのマスクブロックを追加する。各反復でモデルを一度実行し、各位置のトークン予測確率と注意行列を取得する。マスク位置について対角成分を除いた注意列和を計算し、その値が最大の位置を選ぶ。その位置にはモデルの最大確率トークンを確定し、次の反復へ進む。ブロック内のマスクがなくなれば次のブロックへ進み、終了記号が出るまで繰り返す。

局所的な確信度が高いだけの位置ではなく、他位置が広く参照する位置を先に確定することで、残りのマスク位置により有益な文脈を与えることを狙う。学習済みモデルの重みは変更せず、生成時の位置選択規則だけを置き換える。従って既存のマスク拡散LLMへ後付けできる可能性があるが、内部の注意重みを参照できる実装が必要であり、注意行列の取得・集計費用は無視できると保証されていない。

### 並列版：確信度と動的注意閾値の組合せ

逐次版は一回の前向き計算で一位置しか確定しないため、品質が高くても生成速度が限定される。並列版ではまず各マスク位置の最大予測確率を調べ、確信度閾値τ以上の候補集合と、それ未満の非候補集合に分ける。論文の代表設定はτ=0.9で、速度・品質比較では0.9、0.8、0.7へ変化させる。

次に、非候補集合の注意列和の最大値を**動的な注意閾値γ**とする。候補集合のうち注意列和がγを超える位置を同じ反復で確定する。これにより、確信度の低い位置よりも依存上重要とみなせる位置を並列に確定し、重要度の低い候補は次回の文脈更新を待つ。固定個数を毎回選ぶ上位k方式や、一定の注意得点だけで判定する方式より、系列ごと・反復ごとの依存変化へ対応できる。

この手順には注意点がある。非候補集合が空のとき、γをその集合の最大値として定義する式はそのままでは未定義であり、境界条件を実装で処理する必要がある。原著の擬似コードだけからその境界処理を完全には確認できないため、再現時の監査項目となる。また、同時確定位置間の独立性を厳密に証明したわけではなく、注意列和を代理量として選ぶ経験的設計である。

## 評価

### 評価環境と比較方式

モデルはFast-dLLM v2の1.5B・7B、LLaDA-1.5 8Bを使用し、実験は単一のNVIDIA A6000 GPUで行う。課題は数学文章題のGSM8K、数学推論のMATH、コード生成のHumanEval、MBPPである。比較には確信度、余裕度、エントロピー、Fast-dLLMの並列化、EB-Sampler、KLASSなどを含める。品質は各課題の正答率・成功率の平均で比較し、生成速度はGSM8Kでのトークン/秒（TPS）を測る。

性能比較の際には、逐次版と並列版を混同しない。逐次版は品質の基準として有用だが、処理量改善は並列版で達成する。速度の曲線は確信度閾値を変えた複数の設定を比較したものであり、最高速度の一点だけを他方式の最高精度と比較してはいけない。

### 品質評価の定量結果

原著Table 1の4課題平均を抜粋する。数値はパーセントで、値が大きいほどよい。

| モデル | 比較方式 | 4課題平均 |
|---|---|---:|
| Fast-dLLM v2 7B | 確信度優先 | 54.66 |
| Fast-dLLM v2 7B | エントロピー優先 | 56.57 |
| Fast-dLLM v2 7B | Attn-Sampler逐次 | **57.67** |
| Fast-dLLM v2 7B | Attn-Sampler並列 | **57.66** |
| LLaDA-1.5 8B | 確信度優先 | 50.98 |
| LLaDA-1.5 8B | Attn-Sampler逐次 | **52.84** |
| LLaDA-1.5 8B | Attn-Sampler並列 | **52.80** |
| Fast-dLLM v2 1.5B | 確信度優先 | 39.69 |
| Fast-dLLM v2 1.5B | Attn-Sampler逐次 | **41.26** |
| Fast-dLLM v2 1.5B | Attn-Sampler並列 | **41.06** |

7BのHumanEvalでは確信度優先54.27%に対し並列Attn-Samplerは58.54%で、4.27パーセントポイント改善する。MBPPは確信度優先30.69%、並列Attn-Sampler35.98%である。7BのMATHでは逐次52.50%、並列51.88%と並列化で若干下がるが、GSM8Kは逐次84.00%、並列84.23%でわずかに上がる。従って「並列版が全課題で逐次版と完全に同一精度」という主張ではなく、平均が近いことを示している。

1.5BではMATHの並列版31.02%がエントロピー優先32.02%を下回る一方、GSM8Kは並列62.62%、確信度61.56%となる。論文の「全てで最良」という文章を読む際には、個別課題で負ける例があることを表から確認すべきである。

### 生成速度と品質の同時比較

Fast-dLLM v2 7B・GSM8Kの速度比較では、確信度優先が35 TPS・82.7%正答率、Fast-dLLMの並列化が95 TPS・82.1%、KLASSが51 TPS・83.2%である。Attn-Samplerは同じ95 TPSで84.2%を維持し、107 TPSでは82.6%を示す。95 TPSでFast-dLLMより約2.1ポイント正答率が高いこと、107 TPSで確信度優先とほぼ同じ正答率を保ちながら処理量を約3.06倍にすることが主要な利点である。

さらに固定個数上位kによる並列化では、処理量67から124 TPSへ上げると正答率が81.12%から65.35%へ低下する例がある。動的閾値を使うAttn-Samplerは118 TPSでも81.35%を維持し、固定個数方式の67 TPS時より高い正答率を示す。これは毎回同じ数のトークンを確定するのではなく、現在の依存構造と確信度で同時確定数を変える必要性を裏付ける。

ただし95 TPSと107 TPSは設定の異なる動作点であり、107 TPSで84.2%を達成したわけではない。トークン/秒は生成の処理量であり、初回トークン遅延や全要求の応答時間を同時に報告するものではない。単一GPU・GSM8Kにおける速度と品質の曲線を、長文生成や多要求サービングの処理能力へ直接一般化しない。

### 構成要素除去：注意層・ヘッドの集約

Attn-Samplerは注意行列をどの層・ヘッドから集約するかによっても品質が変わる。原著の実験では、最初の一層だけを使うとGSM8K正答率82.26%、最初の7層では84.08%、全層を平均すると最高の84.23%となる。ヘッドでも最初の1ヘッド83.32%、最初の7ヘッド84.0%、全ヘッドを用いると84.23%となる。局所の一部の注意だけでは系列全体の依存を十分に表せず、幅と深さの双方の集約が効果的である。

一方、全層・全ヘッドの注意情報を取得して平均する場合、既存の高速注意カーネルが注意行列を明示的に保存しない実装では追加の計算・メモリ負荷が発生し得る。論文はA6000で実測の生成処理量を示すが、注意抽出単体のメモリ増加、カーネル変更費用、別GPUでの性能を網羅的に分解していない。速度向上の再現には注意重みを得る実装経路が重要となる。

## 限界

### 理論保証の範囲と限界

注意列和の降順が最適という定理は、元の順序依存の尤度差ではなく、**順位だけに依存する最適な二乗誤差近似で置き換えた上界**について成り立つ。理論導出は一層・単一ヘッドのsoftmax注意と一次近似を利用する。多層Transformerへの適用は経験的検証であり、あらゆる入力で最大尤度を保証するものではない。実験で改善したのは特定のマスク拡散モデルの生成品質と処理量である。

著者が付録で明記する重要な制約は、**均一拡散（uniform diffusion）には直接適用できない**ことである。均一拡散では同じトークンを複数回更新し得るが、Attn-Samplerの順序最適化は各位置を一度確定するマスク拡散の構造に依存する。トークン再更新が必要な生成方式では、単純な順位付けで同じ理論は成立しない。

評価は単一A6000、3つのモデル規模、数学・コード課題が中心である。長文の事実性、多言語品質、対話一貫性、MoEや大規模並列環境、他のGPU世代への移植性は直接検証されていない。動的閾値の境界条件、全注意行列を得る費用、ブロック長やKVキャッシュ最適化との相互作用も運用上の追加監査が必要である。

## 既存研究との差と実務的含意

従来の確信度・余裕度・エントロピー優先方式はトークンごとの予測分布だけで順序を決める。Attn-Samplerは系列全体の注意構造を使い、他位置へ影響するトークンを早く確定するという別の情報を導入する。並列版では確信度で誤確定を抑えながら、動的な注意境界で同時確定数を選ぶ。学習なしで復号ポリシーを置き換える点が実装上の利点である。

ただし通常の自己回帰型LLMにこの順序をそのまま導入することはできない。対象は複数の未確定位置を持つマスク拡散型LLMであり、現在の自己回帰推論基盤へ組み込むには生成モデル側の対応が必要となる。学習不要という表現はモデル重みの再学習を要しない意味であり、注意取得・集計の追加処理が無料という意味ではない。
