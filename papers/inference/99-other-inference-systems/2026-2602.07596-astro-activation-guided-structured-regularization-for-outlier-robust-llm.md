# Astro：活性値の大きさに応じた重み再構成で低ビット量子化を安定化する

## 概要

Astroは、LLMの重みのみの事後量子化（weight-only PTQ）において、外れ値に由来する精度低下を抑えるための量子化前処理である。低ビット重みを均一な量子化格子へ丸めると、重みの一部に大きな値があるだけでスケールが広がり、多数の小さな値の分解能が下がる。さらに入力活性値が大きいチャネルに量子化誤差があると、その誤差が出力へ増幅される。Astroは、重み外れ値を一律に抑えるのではなく、校正データで活性値が大きい入力グループに対応する重みを重点的に平滑化する。

方法の核心は、元のモデルが学習損失の平坦な領域にあるなら、出力をほぼ維持しながら重みの数値分布を変える余地があるという考え方である。層ごとの出力再構成誤差を抑える条件の下、入力グループの活性値ノルムに比例した正則化係数で、対応する重みグループの最大絶対値を縮小する。各出力チャネルについて独立した凸に近い再構成問題を近接勾配法で解き、得られた重みを元重みと置き換えた後、GPTQなどの既存量子化を適用する。推論時に回転行列や外れ値用の分岐を追加しないため、元の量子化カーネルを変更せずに使える。

原著のLLaMA-2-7B、W3A16g128では、WikiText-2 PPLがAstro 5.95、MagR 6.00、OmniQuant 6.03と報告される。LLaMA-2-13Bや70Bでも改善する条件があるが、すべての課題・モデルで最良ではない。特に70BのMMLU 5-shotではAstro 66.9に対してOmniQuant 67.3であり、過度の正則化ではPPLが30を超えて崩壊する。平坦性の理論はHessianの低ランク性や局所二次近似に依存するため、「任意の重みを変えても品質が保証される」という意味ではない。

## 問題設定：重み外れ値と活性値外れ値の相互作用

線形層Y=XWを重みのみで量子化する際、Wを低ビットの格子へ写したQ(W)で置き換える。出力の差はX(W−Q(W))であり、重み誤差だけでなく入力活性値Xによって決まる。重みグループに大きな外れ値があれば、対称一様量子化のスケールは最大絶対値に引きずられる。例えば3ビット量子化では表現可能な段階が少なく、最大値に合わせた広いスケールでは普通の重みを粗く丸めることになる。

さらに同じ重み誤差であっても、対応する活性値の絶対値が大きいと出力誤差への寄与が大きくなる。通常のweight-only量子化では活性値自体を低ビットへ丸めないが、活性値の外れ値は重み誤差の増幅器として作用する。このため重みの最大値だけを一律に減らす方法では、重要な入力グループへ十分な圧力がかからず、重要度の低いグループを過剰に変形する可能性がある。

AWQやOmniQuantのようなチャネルスケーリング、QuaRotやSpinQuantのような回転変換は、重み・活性値の分布を変えて量子化しやすくする。ただし活性値側の逆変換が実行時に必要になったり、元の演算と融合するカーネルが必要になったりする条件がある。外れ値を別の高精度形式で保持する方法も不規則なメモリアクセスや追加分岐を伴う。Astroは新しい演算子を推論時へ持ち込まず、オフラインで重みそのものを再構成するという違いを持つ。

## 手法

### 1. 平坦な損失領域の利用と前提

原著は、過剰パラメータ化されたLLMの学習損失が、最適解の近傍で多数の低曲率方向を持つと仮定する。元の重みΘ_origにおけるHessianの固有値が、上位r個以外では絶対値γ以下と小さいなら、その低曲率固有ベクトルが張る部分空間に沿った摂動ΔΘについて、損失の二次近似の増加を小さく抑えられる。半径δ=√(2ε/γ)以内の摂動で二次近似の損失増加がε以内となるというTheorem 4.3を示し、近い品質を保ちながら量子化に有利な重みを探す動機とする。

ただし、この定理はHessianの実効ランク不足と局所二次近似を前提にしている。実際のLLMの全パラメータについて条件を直接証明したものではなく、全層の再構成が必ず元モデルと等価になる保証でもない。実装では全体の損失を直接最適化せず、層間の依存を無視する近似によって、各層の校正入力Xに対する出力再構成誤差を小さくする問題へ分解する。この近似により計算可能になる一方、層をまたぐ誤差蓄積は別途評価が必要である。

### 2. 活性値と重み最大値を結合した誤差上界

各出力チャネルjの入力方向を長さgのグループkに分け、X^(k)を対応する校正活性値、W^(k,j)をそのグループの重みベクトルとする。原著Theorem 4.5は、対称一様bビット量子化における層出力誤差のFrobeniusノルムを、`√g/[2(2^(b−1)−1)] × Σ_j Σ_k ||X^(k)||_F ||W^(k,j)||_∞`で上から評価する。この式では活性値のノルムと重みの最大絶対値が乗算されており、活性値の大きいグループに重み外れ値があるほど上界が大きくなる。

この上界から、グループごとの重み最大絶対値へ重み付き正則化をかける。係数α_kは、そのグループの活性値ノルムを全グループの平均活性値ノルムで割った値である。したがって平均より活性値の大きいグループではα_k>1となり、重み外れ値の縮小圧力が強まる。小さいグループではα_k<1となり、出力を維持するための自由度を残す。MagRのように全グループへ同じ係数を使う方式との差は、この活性値による適応的な重み付けである。

ここで最小化するのは実際の最終タスク誤差ではなく、出力誤差の上界を動機とした代理正則化である。活性値ノルムは校正データから得られるため、校正分布が本番と異なれば重要なグループの推定もずれる。また上界が小さいことは全ベンチマークで高精度を保証しない。理論の役割は、なぜ一律正則化より活性値に依存した正則化を選ぶのかを説明することにある。

### 3. 出力チャネル別の近接勾配最適化

原著は各出力チャネルの重みベクトルwについて、`J(w)=1/2 ||Xw−y||_2² + β Σ_k α_k ||w^(k)||_∞`を最小化する。yは元のFP16重みw_origで計算した出力であり、第1項は元モデルの局所出力を再現する条件、第2項は活性値が大きいグループの外れ値を抑える条件である。βは両者の強さを調整するハイパーパラメータとなる。

最適化は近接勾配法（PGD）で行う。まず出力再構成項の勾配に沿って重みを更新し、その後、グループ別の無限大ノルム正則化に対する近接演算で大きな重みを縮小する。出力チャネルを独立に処理できるため並列化しやすい。実験では各層200反復、W3/W4ではグループサイズ128、W2ではグループサイズ64を用いた。元重みを再構成してから既存のGPTQを適用するため、推論時の重み格納形式と計算カーネルはGPTQのまま使える。

オフラインの再構成時間は追加費用である。「推論オーバーヘッドゼロ」は実行時に新しい演算子を足さないという意味で、モデル変換の費用までゼロという意味ではない。また量子化後の出力は厳密には元のモデルと異なるため、再構成前後のPPLやタスク正答率を測定して品質維持を確認する必要がある。

## 評価

### 条件

| 項目 | 原著の設定 |
|---|---|
| モデル | LLaMA-2 7B、13B、70B。付録でLLaMA-3.1 |
| 校正 | WikiText-2訓練から128系列、各2048トークン |
| 量子化 | 重みのみ、W2A16g64、W3A16g128、W4A16g128 |
| 最適化 | 各層200回のPGD、βを感度分析で調整 |
| ハードウェア | NVIDIA A100 GPU |
| 比較 | RTN、GPTQ、AWQ、OmniQuant、SpinQuant、MagR。主なAstro結果はGPTQと組み合わせた前処理 |
| 評価 | WikiText-2 PPL、MMLU/TriviaQA/NQ（5-shot）、ARC-C/ARC-E/HellaSwag（zero-shot） |

AstroとMagRは主にGPTQへ接続する前処理として実装されるため、結果を「Astro単独の量子化器がGPTQを完全に置き換える」と解釈しない。比較方法ごとの学習・探索時間、追加の実行時変換の有無、量子化後の実際のカーネルを分けて読む必要がある。

### Perplexityと下流タスク

原著Table 1のLLaMA-2-7B、W3A16g128では、WikiText-2 PPLがAstro 5.95、MagR 6.00、OmniQuant 6.03、SpinQuant 6.01であった。Astroはこれらより低いPPLを示す。一方、同じモデルでも元FP16のPPLは5.47であり、量子化後に一定の悪化が残る。原著Table 2の7B、MMLU 5-shotはAstro 40.5%、OmniQuant 39.8%、MagR 37.3%で、元FP16の45.9%には届かない。ARC-ChallengeはAstro 43.3%、OmniQuant 42.2%、MagR 40.5%である。

13BのMMLUはAstro 52.2%、OmniQuant 51.0%、MagR 51.2%と改善するが、ARC-ChallengeはAstro 46.2%、OmniQuant 46.5%、MagR 47.4%で、Astroが最良ではない。70BのMMLUはAstro 66.9%、OmniQuant 67.3%、MagR 66.1%であり、OmniQuantに0.4ポイント劣る。70BのARC-ChallengeもAstro 54.8%に対してMagR 56.2%である。したがって「一貫して全課題で最良」という読み方はできず、量子化条件と課題によって方式の優劣が入れ替わる。

2ビット領域では表1でAstroがGPTQやAWQより安定したPPLを示す条件がある。例としてLLaMA-2-7Bの低ビットでGPTQがPPL 20.85、Astroが8.98という大きな差が報告される。ただし量子化条件ごとのグループサイズが異なること、元モデル・校正条件が同じかを確認したうえで比較する必要がある。W2の数値をW3やW4の結果へ混ぜて平均することはできない。

### 正則化強度と構成要素除去

原著Table 3ではLLaMA-2-7B、W3A16g128において、活性値で重み付けした正則化のβ=3×10^-5と5×10^-5がPPL 5.95、全グループ一律α_k=1では同じβで6.02、6.01だった。活性値に基づく重み付けが一律正則化より良い条件を示す。一方、β=5×10^-4では活性値重み付けでもPPL 34.91、一律では36.41へ崩壊する。強い正則化が元モデルの出力を保つ制約を破ることを示す重要な負の結果である。

Table 5では、活性値ノルムの最も大きいグループで重み最大値が0.100から0.062へ38.1%減少したのに対し、中央値グループでは0.118から0.104へ12.2%、最小活性値グループでは0.109から0.104へ4.6%の減少だった。これは設計通り、活性値が大きい場所の外れ値を重点的に抑えたことを示す。ただしこの三グループは代表例であり、全層・全チャネルの分布を完全に示すものではない。

### 再構成前後のFP16品質と費用

原著Table 4の量子化前の再構成重みをFP16で評価すると、LLaMA-2-7BはPPL 5.47から5.48、13Bは4.88から4.88、70Bは3.31から3.33へ変化する。校正後の重み再構成が元モデルの性能を概ね保っていることを支持するが、これは一つのPPL測定であり、全タスクで損失が厳密に同じという証明ではない。平坦領域の仮定を経験的に裏付ける観測と、理論的な全局保証は区別する。

量子化時間については原著Figure 3で、LLaMA-2-7BのW3A16g128では複雑な回転最適化方式より少ない前処理時間で良いPPLを得たと報告する。本文の「約1/3の時間」「50%以上短縮」は比較対象と測定条件に依存し、全モデル・全量子化設定の共通倍率ではない。推論時のレイテンシ追加がない点と、オフラインの200反復に必要な計算時間は別々の指標である。

## 既存方式との差

GPTQは量子化誤差をHessian近似に基づいて補正するが、Astroはその前に重みの数値分布を量子化しやすくする。MagRも重みの正則化を行うが、Astroは入力グループの活性値ノルムを係数に使い、出力誤差上界に対応する場所へ正則化を集中する。AWQ/OmniQuantのスケーリングやQuaRot/SpinQuantの回転とは異なり、重み自体を更新して置換するため、実行時の逆変換を要しない。

ただし回転やスケーリングが常に実行時オーバーヘッドを持つとは限らず、モデル構造と融合可能性に依存する。Astroの「ゼロ推論オーバーヘッド」は通常の量子化カーネルに対する追加演算がないという意味であり、量子化前の学習・再構成コストが不要という意味ではない。実運用では、同じモデルを長期間繰り返し使うほどオフライン前処理費用を償却しやすい。

## 限界と再現性

flat minimaに関する定理はHessianの数値的ランク不足を仮定し、層別最適化では層間の依存を無視する。大きなβでPPLが34.91まで悪化する実験は、平坦な領域内で重みを調整できるという仮定が無制限な正則化を正当化しないことを明確に示す。校正はWikiText-2の128系列であり、コード、数学、専門ドメイン、長文脈で同じグループ重要度になるとは限らない。

またモデル系列は主にLLaMA-2で、LLaMA-3.1は付録の追加評価である。Mixture-of-Experts、視覚言語モデル、特殊な重み形式、活性値の量子化を同時に行うW/A量子化などへの一般化は別途検証が必要である。今回の主要指標はPPLと正答率であり、実際のLLMサービングでのTTFT、TPOT、ピークメモリ、エネルギー効率の改善を測定した結果とは区別する。推論時に新たな演算を追加しないことは実装上の利点だが、実際の高速化倍率を示すものではない。
