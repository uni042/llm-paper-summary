# 能力誘導圧縮：機能的特徴を考慮した重み保持予算の割当

## 書誌と再監査範囲

Rishaank Gupta, *Capability-Guided Compression: Toward Interpretability-Aware Budget Allocation for Large Language Models*, arXiv:2603.16440v1、2026年3月17日。一次資料の全14ページを対象とし、第3〜4節の数式とアルゴリズム、第5節の表1・図1〜4、議論と限界、参考文献を確認した。2026年10月25日の再監査では、既存原稿の品質を確認したうえで、理論的主張と測定結果の境界、能力密度の正規化、保持率の上限制約、圧縮後の速度未評価をより明示する。対象は既存GitHub論文の同一パス修復であり、新規論文の別登録ではない。

## 概要

モデル圧縮では重みの絶対値、活性値、曲率や再構成誤差を基準に枝刈り・量子化の強さを選ぶ。しかし、それらの数値的重要度が、モデルの特定の能力を支える部品の機能的重要性と一致するとは限らない。例えば、まれな推論回路を担う注意ヘッドが平均的な活性値では目立たない場合、単純な枝刈りで重要な能力を失う可能性がある。本論文はこの問題を「能力を見ない圧縮」と位置付け、圧縮前に各部品の特徴活動を測定し、保持予算へ反映する能力誘導圧縮（Capability-Guided Compression; CGC）を提案する。

中核は疎自己符号化器（Sparse Autoencoder; SAE）が抽出する特徴活動から、特徴の種類の広さ、活動頻度の多様性、異なる入力間での特徴の一致度を統合した能力密度を作ることである。密度の高い部品ほど大きな重み保持率を割り当てる構想だが、著者が実際に検証したのはGPT-2 Mediumの384個の注意ヘッドに対する小規模な静的枝刈りである。従来のWanda重要度とのスピアマン順位相関は−0.054だったものの、ヘッド除去によるパープレキシティ悪化との相関は有意でなく、50%保持ではCGC-Lのパープレキシティ27.87が均一枝刈り27.57より悪化した。したがって、能力を保護するという理論的意図と、能力保持が実証されたという結論は区別しなければならない。

## 問題設定

枝刈りはモデルの重みや層を除去してパラメータ数を減らすが、何を残すべきかの判定が難しい。Wandaは重みの絶対値と入力活性値ノルムを組み合わせて重要度を計算し、SparseGPTは重み削除後の層出力の再構成誤差を抑える。これらは数値的な損失を小さくするための有効な代理指標だが、ヘッドが担う情報検索、文法処理、長距離依存、推論能力などの機能を直接ラベル付けしない。著者は、この差が高圧縮率での急激な性能低下を説明する可能性を検討する。

関連研究である圧縮の相転移解析は、ある圧縮率を超えると品質が急落する閾値を示している。CGCはモデル全体の安全な圧縮量を決める問題と、その圧縮量を各部品へどのように配分するかという問題を分離する。前者を既存の相転移回避枠組みに委ね、後者に能力密度を用いる。ただし相転移点を部品ごとに実測した実験は本論文にはなく、能力密度から実際の性能崩壊を予測できるという点は理論仮定に依存する。

モデルの重み容量、生成速度、消費電力は異なる評価軸である。CGCは重みの保持率を決める枠組みであり、実際のGPU推論カーネルの高速化や、重みの疎構造を利用した実測メモリ節約を示す研究ではない。圧縮前に部品ごとのSAEを学習するため、追加の校正データと計算も必要になる。

## 手法

### 1. 各注意ヘッドの活性化から疎な特徴を抽出する

まず学習済みTransformerへ校正用の文章を入力し、各層・各注意ヘッドの出力活性化を収集する。部品 `c` の活性化ベクトル `z^(c)` をSAEの符号器へ入力し、疎な特徴係数 `a^(c)` を得る。復号器は特徴係数から元の活性化を再構成する。学習では再構成誤差を抑えつつ、トークンごとに活動する特徴数を小さくするTopK方式を使う。こうして各トークンに対する特徴の活動表が得られ、部品ごとにどの特徴が頻繁に現れるかを計測できる。

実験ではGPT-2 Mediumの24層×16ヘッドの合計384個に独立したSAEを学習した。各ヘッドの活性化次元は64、辞書サイズは512、各トークンで活動する特徴は25、学習は5エポックである。各ヘッドで別々の辞書を学習するため、特徴の数や活動分布を比較することはできても、異なる辞書の同じ番号が同じ意味的能力を表すとは限らない。SAEの辞書特徴が人間の解釈する能力と一対一に対応する保証もない。特徴を「能力」と呼ぶこと自体が代理指標としての仮定である。

### 2. 特徴幅・活動エントロピー・入力間一致度を測定する

特徴幅 `β(c)` は、校正トークンのうち一定割合以上で活動した辞書特徴の個数である。幅が大きければ、部品がさまざまな特徴を使っていることを表す。活動エントロピー `H(c)` は各特徴の活動頻度から計算し、少数の特徴だけに活動が集中しているか、それとも広く分散しているかを測る。入力間一致度 `Ψ(c)` は異なる意味的入力から得た活動特徴集合のジャカード類似度を平均し、入力が変わっても共通して使われる特徴の割合を捉える。

能力密度 `δ(c)` は、特徴幅を辞書サイズで、エントロピーを辞書サイズの対数で正規化し、入力間一致度と合わせた幾何平均として定義される。等しい重みを使う記法では `δ(c)=[(β(c)/F)×(H(c)/log F)×Ψ(c)]^(1/3)` となる。三指標の一つが極端に小さければ密度も小さくなるため、広い特徴活動だけでなく、分布の多様性と入力をまたぐ安定性を同時に重視する。

ただし原著の第3.4節では特徴 `f` の活動頻度を `p_f=(1/T)Σ_t 1[a_{t,f}>0]` と書く。TopK=25なら通常 `Σ_f p_f≈25` となり、これは確率分布の和が1というシャノンエントロピーの標準的な前提を満たさない。`p_f` をさらに総活動数で正規化したか、実装上どう処理したかを本文の式だけから確定できないため、`H/log F` の値域や報告された密度の再現性には留保が必要である。本文の数値を独立に再計算したと誤認させないようにする。

### 3. 能力密度から部品ごとの保持率を割り当てる

部品 `c` の重み数を `|θ(c)|`、保持率を `ξ(c)`、モデル全体の目標保持率を `ρ` とする。最適化は `Σ_c ξ(c)|θ(c)| ≤ ρ|θ|` という総予算の下で代理損失を最小化する。CGCは部品ごとの能力密度から `ρ_max(c)` という上限を作り、`ξ(c)≤ρ_max(c)` を課す。密度の高い部品ほど上限が高くなるよう、密度の平方根を使った単調増加関数で制約を調整する。これが「密度の高い部品へ多く残す」という設計意図である。

ただし保持率に対する上限が大きいことと、実際に大きな保持率を割り当てることは同義ではない。上限制約だけでは高密度部品を削りすぎない下限保証にならない。論文の理論上の「保護」という表現を、すべての実行可能解で高密度部品が保持されるという数学的保証へ読み替えてはいけない。実際の割当は密度の平均に対する比と部品サイズを用いた初期化、および代理損失の探索に依存する。

### 4. 局所初期化CGC-Lと進化的探索CGC-F

CGC-Lは能力密度を平均密度で割った重みを作り、部品サイズと全体保持予算を考慮した初期保持率を決める。単純な密度比例だけではサイズの大きい部品へ過剰な予算が行くため、各部品の重み数を計算に入れる。上限を超える割当は切り詰め、全体の予算制約を満たす設定を構成する。この段階は部品ごとの特徴統計から計算できるため、圧縮の候補を多数試す前に割当の出発点を得られる。

CGC-FはCGC-Lの初期化を出発点とし、EvoPress型の進化的探索で保持率の候補を変更する。候補の設定が密度由来の上限に反すれば棄却し、代理損失が良い候補を残す。ここで追加される計算は、各候補の圧縮・評価と、事前のSAE学習である。原著はCGC-Fの大規模な実行結果を報告していないため、CGC-LのPPLをCGC-Fの達成性能として扱ってはいけない。

### 5. 全体の相転移回避と部品別配分を組み合わせる

著者は枝刈り、量子化、低ランク化を異なる圧縮次元とし、既存の相転移回避方式が全体の圧縮率を決めた後、CGCが各次元の部品別配分を担当する構想を示す。処理順は低ランク化、枝刈り、量子化とされる。全体の相転移閾値を超えないことと、部品の特徴を保護することを二層で管理する意図である。

ただし実験したのは注意ヘッドの出力射影重みの枝刈りであり、量子化に伴う精度損失、低ランク化の階数割当、KVキャッシュのトークン単位削減は検証されていない。静的なSAE特徴密度は動的なKVキャッシュの保持優先度を直接与えない。理論節の結果を、これらすべての圧縮手法へ実証済みとして拡張するのは不適切である。

## 評価

### 実験設定と比較の条件

| 項目 | 実際の条件 |
|---|---|
| モデル | GPT-2 Medium、約3.55億パラメータ、24層×16ヘッド |
| 実行装置 | NVIDIA T4 GPU 1基 |
| SAE | 各ヘッド独立の384個、入力64、辞書512、TopK=25、5エポック |
| 校正データ | WikiText-103訓練データ、128系列×512トークン＝65,536トークン |
| 評価データ | WikiText-103テストデータ、32系列×512トークン |
| 圧縮対象 | 注意ヘッドの出力射影重み。全体の50%を保持 |
| 比較方式 | 無圧縮、均一枝刈り、CGC-L、密度逆転割当 |
| 主指標 | パープレキシティ、密度とWanda重要度の順位相関、密度とヘッド除去影響の相関 |

「50%保持」は評価対象の注意ヘッド出力射影重みについてであり、モデル全体のパラメータ数が半減したという意味ではない。測定されたのは圧縮後の予測品質であって、実際の推論トークン毎秒やGPUメモリ削減率ではない。GPT-2 Mediumは近年の数十億パラメータ級LLMと構造・能力が異なるため、結果の一般化には制約がある。

### 能力密度の分布とWandaとの関係

384ヘッドの能力密度の平均は0.7465、最小は0.6289、最大は0.7977であり、分布の幅は比較的狭い。図1では層とヘッドごとの分布に局所的な低密度領域があるものの、大半のヘッドは0.63〜0.80へ集中している。著者はこれをモデルの部品が機能的に均一である可能性の根拠として扱うが、SAEの学習条件や密度定義によっても分布幅は変わるため、単独でモデルの真の機能均一性を証明するものではない。

Wanda重要度とのスピアマン順位相関は `ρ=-0.054`（384ヘッド）だった。これは二つの順位がほとんど単調に連動しないことを示す。一方、相関が零に近いことは統計的な独立性の証明ではなく、すべての既存重要度指標と直交することも意味しない。原著要旨の「statistically independent」「orthogonal to all existing importance metrics」という強い表現は、実験が直接示した範囲より広い。正確には、調べたWanda順位との単調相関が小さかったという結果である。

### 単独ヘッド除去と密度の予測力

各ヘッドの出力射影を一つずつ零化し、パープレキシティの変化と密度の関係を測定した。ピアソン相関は `r=-0.066`（p=0.20）、スピアマン相関は `ρ=-0.077`（p=0.13）で、いずれも有意ではなかった。高密度ヘッドを削るほど予測品質が悪化するという仮説を、この実験は支持しない。Wandaと異なる指標を構成できることと、その指標が実際の重要な部品を選べることは別の問いである。

著者はモデル規模の小ささ、パープレキシティの鈍感さ、SAEの学習不足を失敗理由の候補に挙げる。ただしこれらの仮説を分離して検証する対照実験はなく、LLaMA級モデルで同じ方法が改善するという実証はない。失敗理由はもっともらしい説明として読むべきであり、確定した原因ではない。

### 圧縮後のパープレキシティと負の結果

| 方式 | 出力射影の重み保持条件 | WikiText-103 PPL（低いほど良い） |
|---|---|---:|
| 無圧縮 | 元のGPT-2 Medium | 26.68 |
| 均一枝刈り | 各ヘッドを一様に50%保持 | 27.57 |
| CGC-L | 能力密度による非均一割当、総保持率50% | 27.87 |
| 密度逆転割当 | 高密度ヘッドをより強く削る対照、総保持率50% | 27.86 |

原著表1の結果では、CGC-Lは均一枝刈りよりPPLが0.30悪化し、密度逆転割当との差は0.01にとどまる。密度の高いヘッドを保護するという設計が、この評価では品質改善へつながらなかった。比較表のCGC-Lを提案の「勝利」として紹介することはできない。また、CGC-Fの進化的探索結果は示されていないため、探索を加えれば改善すると推定してはいけない。

実験では推論能力を直接測るGSM8KやARC-Challengeのような課題を実施していない。PPLの小さな差が推論能力の差を覆い隠す可能性は一般論としてあるが、この論文が「CGC-Lは推論能力を保持する」と実測したわけではない。評価の限界を述べることと、未測定の有利な結果を推測することを混同しない。

## 理論主張と検証の境界

第3.5節の定理1は、能力密度が高い部品ほど均一な構造枝刈りで活動特徴を破壊しやすいとする。証明の概略では、高い特徴エントロピーが復号方向の広い分散を意味し、重み削除がより多くの特徴方向に影響すると考える。しかし、特徴の活動頻度のエントロピーと、復号辞書ベクトルの幾何学的な広がりは一般には同値でない。部品が圧縮後に残った回路で機能を補う自己修復も考慮が必要であり、理論的関係を無条件の実証事実として扱うことはできない。

第4.5節の定理2は、密度に応じた保持率配分が均一配分より活動特徴の破壊を減らすとする。ただし、その概略は破壊量の凸性・凹性と密度の対応を仮定しており、一般のTransformerで検証されたものではない。さらに保持率の上限を与える形式と「高密度部品に必ず多く残す」という保証の間にも論理的な隔たりがある。定理の成立範囲と、実際のモデルの性能改善を分けて読む必要がある。

第6節で著者自身も、特徴エントロピーと復号方向の広がりの関係は厳密な同値ではないこと、自己修復が理論と実際の関係を複雑にすること、量子化やKVキャッシュ圧縮には直接適用できないことを認めている。これらの留保は論文の価値を否定するものではないが、理論の一般化と実装の成熟度を判断するうえで重要である。

## 既存研究との差

WandaやSparseGPTは数値的重要度または出力再構成損失を利用するのに対し、CGCは圧縮前にSAEを学習して特徴活動の代理指標から保持率を決める。OWLは活性値外れ値に基づいて層別の疎率を変えるが、CGCは特徴幅・エントロピー・入力間一致度を組み合わせる。EvoPressとの関係では、CGC-Fは既存の進化的探索を能力密度由来の制約で絞る設計であり、進化的探索そのものを新規に発明したわけではない。

ShortGPTやLLM-Prunerのように構造全体を削る方式と比較する場合、CGCの実験は出力射影の重み枝刈りであることに注意する。元モデルの機能を保持したまま実行時間を減らすことが実証されたわけではなく、圧縮後の実際の疎行列計算性能も未評価である。能力密度が将来有用な重要度指標になる可能性はあるが、現時点では実用上の優位を確立していない。

## 限界と再現性

第一に、SAEの学習は校正データ65,536トークン、5エポックと比較的浅く、得られた辞書が意味的な能力を十分に表すか未検証である。辞書サイズやTopKの設定を変えた感度評価も限定的で、活動頻度の正規化が曖昧な点は再現性に影響する。第二に、評価モデルはGPT-2 Mediumのみであり、7B以上のモデル、混合専門家モデル、推論能力課題での品質は確認されていない。

第三に、密度と単独ヘッド除去の影響に有意な相関がなく、50%保持では均一枝刈りよりPPLが悪化した。これは提案方式にとって明確な負の結果である。第四に、CGC-F、量子化、低ランク化、相転移回避との統合は構想にとどまり、圧縮後のトークン生成速度、GPUメモリ使用量、圧縮準備時間の定量比較もない。実装へ進む場合はSAE学習費用と圧縮探索費用を、配備後のメモリ・速度利得と別々に測定する必要がある。

第五に、相関がほぼ零であることを統計的独立性の証明としない。高密度部品の理論的な重要性と、実測のヘッド除去影響の関係は今回の評価で確認できなかった。導入判断では、同じモデルと校正集合でWanda、均一枝刈り、CGC-L、CGC-Fを公平に比較し、PPLだけでなく下流の推論能力と実機性能を併記することが不可欠である。
