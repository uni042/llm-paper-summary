# Nyströmformer: A Nyström-Based Algorithm for Approximating Self-Attention

## 概要
Nyströmformerは、標準自己注意が系列長 `n` に対して `n×n` の注意行列を作るため時間・メモリとも二次に増える問題を、Nyström行列近似で線形化する効率的Transformerである。単に完成済みattention行列から列をsampleするのではなく、softmaxを計算する前のquery/keyを少数のlandmarkへ集約し、`n×m`、`m×m`、`m×n` の3つのsoftmax行列の積で元の `n×n` attentionを近似する。

この「softmax前にlandmarkを作る」設計が本質的である。通常のNyström法をsoftmax attentionへ直接適用すると、sampleした列・行を得るためにも元の全 `QK^T` を計算する必要があり、二次計算量を消せない。Nyströmformerはlandmark query/keyを先に作ることで、全token対のscoreを一度も形成せずに近似attentionを得る。

## 問題設定
標準attentionは `softmax(QK^T/√d)V` を計算する。系列長が2倍になるとattention scoreの要素数は4倍になり、数千tokenではscore matrixの生成・softmax・保存が支配的になる。疎attentionは参照先を制限し、kernel近似はsoftmaxを別のfeature mapへ置換するが、Nyströmformerは「softmax attention行列が低rank的な構造を持つ」という観察を利用して、代表点から行列そのものを復元する。

一方、Nyström近似は本来、対象行列の一部の列・行をsampleして残りを再構成する。attentionの場合、softmax後の列を正確に得るには各queryと全keyのscoreが必要であり、そのままでは `O(n^2)` が残る。そこで本論文は近似対象を作る順序自体を変更する。

## 手法

### softmax前のlandmarkと3因子分解
入力から得た `Q,K,V` に対し、まず `Q` と `K` をそれぞれ `m` 個のlandmark `Q̃,K̃` へ縮約する。その後、近似attentionを概ね

`softmax(QK̃^T) · [softmax(Q̃K̃^T)]^+ · softmax(Q̃K^T)`

の3因子で構成し、最後に `V` を掛ける。中央の `m×m` 行列の `+` はMoore–Penrose擬似逆行列である。左因子は各token queryとlandmark keyの関係、右因子はlandmark queryと各token keyの関係、中央因子はlandmark同士の重複・依存を補正する。

出力は標準attentionと同じ `n×d_v` 形状なので、Transformer blockの他部分を大きく変えず置換できる。完全な `n×n` score matrixを保存しないため、`m≪n` なら長系列ほどメモリ削減効果が大きい。

### Segment-meansによるlandmark選択
landmarkを高価なk-meansで毎mini-batch選ぶと、その選択処理自体が新しいボトルネックになる。Nyströmformerは系列を `m` 個の連続segmentへ等分し、各segment内のquery/keyを平均してlandmarkを作るSegment-meansを採用する。

入力として `n` 個のquery/keyを一度走査するだけなのでlandmark生成は `O(n)` である。論文では64 landmarkで良い近似になる場合が多いと報告する。ただし最適な `m` はtask依存で、`m` を増やせば元attentionへの近似精度は上がりやすい一方、`n×m` 計算と中間memoryも増える。

### 擬似逆行列の反復近似
中央の `m×m` attention行列のMoore–Penrose擬似逆行列を特異値分解（SVD）で毎回求めるとGPU上で効率が悪い。そこで行列積だけで更新できる三次収束の反復法を使う。論文の実験では良い近似に約6 iterationで十分だった。

ここで計算対象は `n×n` ではなく `m×m` なので、反復の最悪計算量 `O(m^3)` は `m` を固定・小さくすれば系列長 `n` には依存しない。ただしlandmark数を大きくするとこの固定費も急増するため、極端に大きい `m` は線形化の利点を損なう。

### depthwise convolutionのskip connection
Nyström近似attentionと並列に、value `V` へ1次元depthwise convolutionを適用したskip connectionを加える。これは各channelの局所情報を低コストで直接出力へ運び、近似attentionだけでtrainingしたときの情報損失を補う。

したがってNyströmformerの実装は単なる行列式の置換ではなく、Segment-means、反復擬似逆行列、depthwise convolutionを一つのattention moduleとして組み合わせる。

### 計算量
論文の詳細解析では、landmark生成が `O(n)`、擬似逆行列が最悪 `O(m^3)`、残りの行列積が `O(nm^2 + nmd_v)` 等になる。memoryも `n×m` と `m×m` の中間表現が中心である。したがって `m` を系列長とは独立に小さく固定すれば、時間・memoryはいずれも `n` に対して線形になる。

## 評価

### 長系列での速度・メモリ
NVIDIA 1080 Ti上で、self-attention module単体をsequence length 512〜8192まで測定している。8192 tokenでは標準Transformerが10,233 MB、155.4 msであるのに対し、64 landmarkのNyströmformerは450 MB、12.3 ms、32 landmark版は383 MB、11.5 msだった。標準attention比でmemoryは約22.8〜26.7分の1、実行時間は約12.7〜13.4分の1である。

同じ8192 tokenでLongformer-257は455 MB、36.2 msなので、Nyströmformer-64はほぼ同等のmemoryで約3倍高速である。Linformer-256は635 MB、11.3 msで、Nyströmformer-64は実行時間が近いままmemoryを約1.4倍、32-landmark版なら約1.7倍少なくする。短い512 tokenではNyströmformer-64は35 MB・0.7 ms、標準attentionは54 MB・0.8 msで、長系列ほど差が広がる。

この結果は、`n×n` matrixを作らないという機構が実際の長系列memoryとruntimeへ反映されることを示す。一方、短系列では標準attentionとの差が小さく、反復擬似逆行列などの固定費が相対的に目立つ。

### GLUE・IMDB
BERT-base相当のtransfer learning設定でEnglish WikipediaとBookCorpus上のmasked language modeling（MLM）とsentence-order prediction（SOP）を行い、その後GLUEとIMDBへfine-tuneする。代表値では、SST-2がBERT-base 90.0に対しNyströmformer 91.4、MRPC 88.4対88.1、QNLI 90.3対88.7、QQP 87.3対86.3、MNLI matched/mismatched 82.4/82.4対80.9/82.2、IMDB 93.3対93.2である。

したがって全taskで標準attentionを上回るわけではなく、QNLIやMNLI matchedでは低下する一方、SST-2では改善し、IMDBではほぼ同等である。長系列化したIMDBでも512 tokenの93.2に対し1024 tokenで93.0とほぼ維持し、近似attentionが入力長を伸ばしただけで急激に崩れないことを確認している。

### Long Range Arena
Long Range Arena（LRA）では同じ2-layer、embedding 64、hidden 128、2-head構成で標準attention、Reformer、Linformer、Performerと比較する。Nyströmformerの各task精度はListOps 37.15、Text 65.52、Retrieval 79.56、Image 41.58、Pathfinder 70.94、平均58.95である。

標準attentionの平均58.77との差は+0.18 pointでほぼ同等である一方、Reformer 55.04、Linformer 55.59、Performer 53.63に対して、それぞれ+3.91、+3.36、+5.32 point高い。線形化による効率改善だけでなく、同一PyTorch実装条件で長距離taskの精度を保てることを示している。

## 既存研究との差
Linformerはsequence方向を線形projectionし、Performerはrandom featureでsoftmax kernelを近似し、Longformerは局所windowと一部global attentionへ参照を制限する。Nyströmformerはこれらと異なり、元のsoftmax attention matrixをlandmarkから再構成する。

特に一般のNyström法をsoftmax後へ直接適用すると全score計算が残るという問題を認識し、landmarkをsoftmax前のquery/key空間で作ることで `n×n` materializationを回避した点が方法上の差である。

## 限界
線形計算量はlandmark数 `m` を `n` より十分小さく保つ場合の性質であり、近似精度を求めて `m` を系列長とともに増やすと計算・memory利得は縮む。Segment-meansは単純で高速だが、連続区間の平均が必ず最適な代表点になる保証はなく、taskによって必要landmark数が変わる。

擬似逆行列はSVDを避けられるものの反復行列積という追加費用を持つ。512 token程度では標準attentionとの差が小さいため、短系列では専用の高最適化attention kernelに対する優位性が限定的になり得る。評価も2021年当時のBERT/LRA規模が中心で、現代LLMのautoregressive decodeやFlashAttention系kernelとの直接比較ではない。
