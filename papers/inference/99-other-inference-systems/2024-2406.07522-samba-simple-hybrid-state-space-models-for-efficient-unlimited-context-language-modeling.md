# Samba: Simple Hybrid State Space Models for Efficient Unlimited Context Language Modeling

> Sambaは、選択的状態空間モデル（Selective State Space Model; SSM）で遠い過去を固定サイズ状態へ畳み込み、スライディング窓注意（Sliding Window Attention; SWA）で直近トークンを正確に参照する。全履歴のキー・値キャッシュ（Key-Value Cache; KVキャッシュ）を保持するTransformerとは異なり、長さに対して線形の計算・有界な状態でストリーミングを続けられる点が中心である。

## 概要

全注意は文脈長が伸びるほど注意計算が二乗で増え、復号時にはKVキャッシュも文脈長に比例して増える。一方、Mamba系SSMは過去を再帰状態へ圧縮できるが、「直前の特定トークンをそのまま引く」ような局所検索では注意機構が有利である。

Sambaは両者を層単位で交互に配置する。SSM層は長距離情報を選択的に状態へ蓄積し、SWA層は有限窓だけに通常の注意を適用する。したがって、古い情報には圧縮された再帰経路、最近の情報には高解像度の注意経路を与える。

3.8Bまでのモデルを3.2Tトークンで学習し、学習文脈4Kのまま100万トークン級までの外挿を検証している。長文脈性能だけでなく、128K入力のスループットと64K連続生成も測定し、長さを伸ばしたときの実行効率へ接続している。

## 背景と問題設定

### 全注意とSSMは異なる弱点を持つ

全注意は任意の過去位置を直接参照できるが、系列長が増えるほどスコア計算とKV保持が重くなる。SWAは費用を窓幅へ制限できる代わりに、窓外の情報を直接検索できない。

SSMは系列を固定サイズ状態へ再帰的に要約するため、理論上は無制限にストリーミングできる。しかし圧縮状態だけで「何万トークン前の特定文字列」を精密に回収するのは難しい。Sambaは両方を一方へ統一せず、役割分担させる。

## 手法

### 1. Mamba層で長距離履歴を固定サイズ状態へ圧縮する

各トークンは選択的SSMへ入り、入力依存の更新則で再帰状態へ取り込まれる。出力は過去全トークンを再走査せず現在状態から計算できるため、系列が伸びても履歴保存量は線形に増えない。

### 2. SWA層で最近の情報を高解像度に保持する

別の層では有限幅のSWAを使う。現在トークンから近い範囲だけKVを保持して通常のsoftmax注意を行うため、局所的なコピー、構文、近距離の名称参照をSSM状態だけに押し込めずに済む。

### 3. 層を交互に積んで二つの経路を混ぜる

SSMの長距離圧縮とSWAの局所検索を同一ブロック内で複雑に融合するのではなく、単純なハイブリッド構成として積層する。ある層で得た長距離要約は次の局所注意層の表現へ入り、局所的に精密化された表現は後続SSMの状態へ取り込まれる。

### 4. 1トークン生成時の流れ

新しいトークンが入るたび、SSM側は再帰状態だけを更新し、SWA側は有限窓のKVだけを読み書きする。古い全KVを保持・走査しないため、64K、128Kと履歴が伸びても全注意ほど急激にデコード費用が増えない。

## 評価

### 評価条件

| 項目 | 条件 |
|---|---|
| 最大モデル規模 | 3.8B |
| 学習量 | 最大3.2Tトークン |
| 学習文脈 | 4K |
| 長文外挿 | 最大1M文脈のパープレキシティ、Passkey Retrieval、Phonebook |
| Passkey | 4Kで微調整し最大256Kを評価 |
| 効率評価 | 128Kユーザープロンプト、64Kトークンの連続生成 |
| 比較軸 | Transformer + グループ化クエリ注意（Grouped-Query Attention; GQA）、Mamba系など |
| 主指標 | パープレキシティ、検索精度、スループット |

### 主な結果

| 観点 | 結果 | 解釈 |
|---|---:|---|
| 学習長外挿 | 4K学習から最大1Mまで改善傾向のパープレキシティ | 位置長を学習長へ固定しない |
| Passkey Retrieval | 4K微調整から256Kまで完全想起を報告 | SSMだけでなくSWAを混ぜた精密検索能力 |
| 128Kプロンプト | GQA Transformer比 **3.73倍**スループット | 長文プリフィル/状態保持の差が実測へ現れる |
| 64K連続生成 | **3.64倍**高速化 | 履歴が増えても全KVを伸ばさない効果 |
| 最大規模 | 3.8B / 3.2Tトークン | 小規模玩具モデルだけの評価ではない |

ここで「unlimited」は無限長で完全に情報を保存できるという意味ではない。計算・状態サイズを文脈長に対して有界に保てる設計を指し、圧縮状態へ何を残せるかは学習・タスク依存である。

## 既存研究との差

純Mamba系に対しては、局所の正確な参照をSWAへ任せる。全注意Transformerに対しては、遠距離履歴を全KVとして残さずSSM状態へ圧縮する。固定窓Transformerに対しては、窓外情報がSSM経路を通って後続層へ残る点が異なる。

## 限界・実装状況

長距離情報は圧縮状態へ畳み込まれるため、任意の過去トークンを完全に再現する外部メモリではない。Passkeyのような検索成功が、すべての長文推論・多数事実同時保持を保証するわけでもない。

また、3.73倍/3.64倍は128K・64Kという長い系列での代表値である。短文ではSSM/SWA切替の固定費が相対的に大きく、同倍率を期待できない。
