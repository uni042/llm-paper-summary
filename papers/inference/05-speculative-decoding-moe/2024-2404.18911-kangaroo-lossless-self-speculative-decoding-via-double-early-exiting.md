# Kangaroo: Lossless Self-Speculative Decoding via Double Early Exiting

> Kangarooは別のドラフトモデルを持たず、対象LLMの浅い前半層を自己ドラフトとして使う。浅い表現を補正する小型アダプタと、低確信度になった時点でドラフト生成自体を打ち切る「二重の早期終了」により、追加パラメータと無駄なドラフト計算を同時に抑える。

## 概要

投機的復号（Speculative Decoding; SD）は小型ドラフトが候補を作り、大型対象モデルがまとめて検証する。別モデル方式は受理率を高くできるが、追加重みをGPUへ載せ、ドラフトKVも保持する必要がある。

自己投機方式では対象モデルの前半層をドラフトに再利用できるが、浅いネットワークは予測品質が低くなりやすい。また対象モデルの一部であるため、1ドラフトステップの費用も完全に無視できず、受理されにくい位置で長く先読みすると逆効果になる。

Kangarooは固定した浅い部分ネットワークの上に67Mパラメータのアダプタを置き、ドラフト分布を改善する。さらに各ドラフトトークンのtop-1確信度が閾値を下回れば、そのラウンドの先読みを終了する。

## 手法

### 1. 対象モデルの浅い層を自己ドラフトとして切り出す

入力トークンは対象モデルの先頭数層だけを通り、完全モデルより安価な隠れ表現を得る。別LLMを読み込まないため、重みメモリを増やしにくい。

### 2. 軽量アダプタで浅い表現と最終表現の差を補う

浅い層の出力だけでは次トークン分布が対象モデルとずれやすい。そこで小型アダプタを学習し、対象モデルに受理されやすい候補へ補正する。

### 3. ドラフト内でも早期終了する

固定でkトークンまで必ず生成せず、現在候補の確信度が閾値ηを下回ったらそこで先読みを止める。難しい位置に追加ドラフト時間を使わず、対象モデル検証へ早く移る。

### 4. 対象モデルがまとめて検証する

候補列は通常のSDと同様に完全モデルで検証し、規則に従って受理/棄却する。この検証を残すため、Kangarooは近似的に品質を落として速くする方式ではなく、元モデルの生成分布を維持する損失なし方式である。

## 評価

### 評価条件

| 項目 | 条件 |
|---|---|
| ベンチマーク | Spec-Bench |
| タスク | Translation、QA、Summarization、Math、RAG、MT-Bench |
| 代表モデル | Vicuna 7B / 13B |
| 比較 | 自己投機、Medusa-1、REST、Lookahead等 |
| 追加パラメータ | Kangaroo 67M、Medusa-1 591M |
| 指標 | 壁時計高速化、受理/圧縮率、追加パラメータ |

### 主な結果

| 条件 | Kangaroo | 解釈 |
|---|---:|---|
| Vicuna-7B 平均 | 約 **1.50倍** | 6カテゴリ平均 |
| Vicuna-7B MT-Bench | **1.68倍** | 代表的最大値 |
| Vicuna-13B 平均 | 約 **1.44倍** | モデル規模が変わっても利得 |
| Vicuna-13B MT-Bench | **1.66倍** | 高受理条件 |
| 追加パラメータ | **67M** | Medusa-1 591Mより**88.7%少ない** |
| 品質 | 損失なし | 完全モデル検証で元分布を維持 |

数学等のカテゴリでも速度は改善するが倍率にはばらつきがある。ドラフト確信度が低い区間では早く打ち切るため、常に長く先読みする方式より失敗コストを抑える。

## 既存研究との差

別ドラフトモデル型SDに対しては追加モデルを不要にする。従来の自己投機に対しては、浅い層の予測をアダプタで補正し、さらに「モデルから早く抜ける」だけでなく「ドラフト系列そのものから早く抜ける」二段目の早期終了を入れる。

## 限界・実装状況

67Mパラメータは小さいがゼロではなく、対象モデルごとにアダプタ学習が必要である。浅い層と最終層の分布差が大きいモデルでは受理率が下がりやすい。

また最大1.68倍は単一系列検証のSpec-Bench条件であり、高バッチ配信では対象モデル側の連続バッチ処理との相互作用を別途評価する必要がある。
