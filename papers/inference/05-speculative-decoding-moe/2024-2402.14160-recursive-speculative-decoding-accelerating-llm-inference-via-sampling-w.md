# Recursive Speculative Decoding: Accelerating LLM Inference via Sampling Without Replacement

> 投機木の候補を非復元抽出して枝の重複を減らし、固定LLM計算予算でも多くの条件で既存木型投機デコードを上回る。

## 概要

投機的デコードは小型モデルが候補を先読みし、大型対象モデルが複数候補を一括検証することで、大型モデルの逐次呼出し回数を減らす。候補を一本の列ではなく木へ広げれば、対象モデルが受理できる経路を増やせる。しかし既存木方式は各段で候補を独立に引くため、同じ高確率トークンや似た系列が木の別枝へ重複し、限られた検証予算を浪費しやすい。

再帰投機デコード（Recursive Speculative Decoding; RSD）は、候補を復元抽出せず木全体の多様性を増やす。並列なGumbel-Top-kを使うRSD-Cと、系列を非復元抽出し低確率枝を早期打切りする確率的ビーム探索版RSD-Sを示す。Llama 2-7Bと115MドラフトのXSumでは、自己回帰37.269 token/sに対しRSD-Cの代表的2-2分岐で56.609 token/s、ブロック効率2.398を得る。

## 問題設定

通常の投機的デコードでは一本の候補列が途中で拒否されると、その先の候補は使えない。木型方式は複数の次トークン候補を用意することで拒否に強くなるが、枝を独立サンプリングすると同一候補を何度も引く可能性がある。また、木を大きくすれば大型モデルへ渡す候補トークン数も増えるため、固定ドラフト長だけの比較では大型モデル側の計算量が公平でない。

本論文は「候補数を増やす」より「同じ検証予算で異なる経路を覆う」ことを重視する。そのため評価も固定ドラフト長と、対象モデルが処理するトークン数を揃えた固定計算予算の両方で行う。

## 手法

### 1. Gumbel-Top-kによる非復元候補

RSD-Cは各親ノードの次トークン分布へGumbel乱数を加え、上位k候補を一度に選ぶ。Gumbel-Top-kは同じカテゴリを重複して引かないため、独立サンプリングより少ないノードで異なる候補を覆える。分岐数は深さごとに指定でき、例えば2-2なら最初の段と次の段でそれぞれ2候補へ広げる。

作った木は対象モデルへまとめて渡し、注意マスクと位置符号化を使って各枝を一括評価する。検証後は棄却サンプリングにより対象モデルの分布を回復するので、木の多様化は最終分布を近似で変えるための操作ではない。

### 2. 確率的ビーム探索による系列非復元抽出

RSD-Sは確率的ビーム探索（Stochastic Beam Search）を使い、単一段のトークンではなく系列全体を非復元で抽出する。各ビームはGumbelで摂動した対数確率を保持し、親系列の上限を使って子のスコアを切り詰める。全親・全語彙の候補から上位W組を選び、次段のビームを作る。

重要なのは、低確率の枝を深い段まで展開しない点である。候補多様性を確保しながら、ドラフトモデル側の不要な計算も減らす。RSD-Cが固定分岐で並列性を取りやすいのに対し、RSD-Sは確率質量に応じて計算を有望枝へ寄せる。

### 3. 対象モデル計算予算を揃えた比較

木型方式は枝が多いほど一度に対象モデルが処理するトークンも増える。そこで論文はブロック効率だけでなく、メモリ律速を仮定した高速化指標、実測トークン率、精度を記録し、さらに対象モデルで処理するトークン数を変えた実験を行う。

これにより「大きな木だから多く受理できた」だけの改善と、「同じ対象モデル計算で候補配置が良い」改善を分離する。資源制約端末を想定する場合、この固定予算比較が特に重要になる。

## 評価

| 項目 | 代表設定 |
|---|---|
| 対象モデル | Llama 2 7B/13B/70B、Chat系列、OPT 13B/30B/66B |
| ドラフト | Llama系115M、OPT 125M/350M |
| 課題 | XSum、WMT、Dolly |
| 比較 | 自己回帰、通常投機、SpecTr、RSD-C、RSD-S |
| 指標 | ブロック効率、メモリ律速高速化、token/s、精度 |

| 条件 | 比較 | token/s | ブロック効率 | 読み取れること |
|---|---|---:|---:|---|
| Llama 2-7B / XSum | 自己回帰 | 37.269 | 1.000 | 基準 |
| 同上、通常投機 DL=2 | SD | 51.515 | 2.166 | 一本列でも大型モデル呼出しを削減 |
| 同上、RSD-C 2-2 | RSD-C | 56.609 | 2.398 | 非復元木で候補多様性を増やす利得 |
| Llama 2-13B / XSum、RSD-C 2-2 | RSD-C | 44.593 | 2.347 | 対象モデルが大きくても同傾向 |
| Llama 2-70B / XSum、RSD-C 2-2 | RSD-C | 16.033 | 2.322 | 大型対象でも自己回帰9.079 token/sから改善 |

精度はXSumの例で自己回帰0.141に対しRSD-C 2-2が0.143で、出力分布を維持する検証の意図と整合する。論文全体では固定ドラフト長で一貫して既存方式を上回り、固定対象計算予算でも大半の条件で優位と報告する。

## 既存研究との差

SpecTrやSpecInferも木を使うが、候補を独立に生成するため木の多様化を明示的に最大化しない。RSDは非復元抽出を木生成そのものへ組み込み、候補の重複を減らす。また、固定長だけでなく対象LLMが処理するトークン数を揃えて比較し、木を大きくした計算量増加を評価へ織り込む。

## 限界・実装状況

木を広げればドラフト計算と対象モデルの検証トークン数は増えるため、最適分岐は対象モデル、ドラフト速度、ハードウェアの並列性に依存する。RSD-Sは候補の選別計算も持つ。論文はLlama 2とOPTを中心に評価しており、MoEやマルチモーダルモデルへの一般化は直接検証していない。
