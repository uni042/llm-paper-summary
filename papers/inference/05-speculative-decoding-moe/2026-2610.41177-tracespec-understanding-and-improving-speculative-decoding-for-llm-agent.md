# TraceSpec: Understanding and Improving Speculative Decoding for LLM Agents

> エージェント軌跡を中間の判断単位で残すコーパスと再生評価で、集約受入の上昇の裏で遅い閲覧行動の受入が下がる逆転を示し、全ターンを教師候補にして状態条件付きの受入隔たりで固定予算を配る学習により、再生スループットを基盤より十二・五から二十二・六パーセント改善したと報告した。

## 概要

大規模言語モデルを使うエージェントは、一つの課題の中で推論し、道具を呼び、その返答を読んでまた推論するという呼び出しを何十回も繰り返す。各呼び出しの前に、それまでの推論と行動と道具の観測が履歴として積み上がるため、履歴は長くなるだけでなく、中身の役割も変わっていく。短い道具要求の直前もあれば、新しい証拠への振り返りの直前もあり、最終回答の直前もある。投機的復号（小さな下書きモデルがトークンを先に提案し、大きな対象モデルがまとめて検証することで、対象モデルの分布を保ったまま生成を速くする手法）では、下書きと対象の一致の度合いを表す受入長（検証一回あたりに受け入れられるトークン数）が効率を決める。ところが従来の測り方は、こうした異なる判断をすべて混ぜた平均で受入を報告するため、文脈が長くなると受入がどう変わるのか、その変化が一致そのものの変化なのか、呼び出しの混合の変化なのかが分からなかった。

本論文はまず測り方を作る。実際の対話的実行をそのまま走らせる動的実行と、保存した履歴をすべての方式へ同一に渡す固定接頭辞の再生という二つの手順を組み合わせ、学習用一万件と試験用二千五百件の軌跡状態を持つコーパスを用意した。各状態には仕事の種類、実行の段階、実際の接頭辞長、直前の道具とのやり取り、軌跡の中の位置が付いている。測定で目立つのは逆転である。動的実行の集約では、最も短い文脈区間から最も長い区間へ進むと受入は上がり、生成スループットは下がる。ところが同じ課題の中で二十歩目以降の閲覧行動だけを取り出し、課題と段階をそろえて比べると、受入は逆に下がった。仕事の種類でも傾向は分かれ、再生では閲覧系は文脈とともに受入が下がり、ソフトウェア工学系は上がった。

この診断を学習へつなぐのが提案の後半である。対象モデルが生成した訓練軌跡について、最終応答だけでなく中間の助手ターンすべてを教師候補の区間とし、固定した予測予算（学習で使う有効な予測事象の総量）の中で配分を決める。配分は、対象と下書きの分布の重なりから作る受入隔たりを、区間の長さや段階や仕事の種類や道具の状態で平滑化し、ブロックの早い位置での不一致を重く見る形で数え、隔たりの大きい区間へ寄せる。代表結果として、再生での生成スループットは基盤の下書き方式より十二・五パーセントから二十二・六パーセント高く、段階別の再生比較二十四件すべてで首位だった。四十億級の対象での除去実験では、中間ターンを加えること自体で受入長が三・九パーセントから十・二パーセント、適応配分でさらに三・三パーセントから十・〇パーセント伸びた。

## 問題設定

投機的復号の費用は二層に分かれる。一つは検証の層で、受入が良いほど同じ続きを出すのに要る検証の回数が減る。もう一つは課題全体の層で、各呼び出しには履歴を読み込む入力処理、道具の実行、その他の待ちが伴い、論文は課題の所要時間を、入力処理と下書き・検証と道具とその他の和として書いている。受入が上がっても、履歴処理が支配的な長い文脈では課題全体の時間はそれほど縮まらない。実際、動的実行では文脈区間が伸びるほどスループットは大きく落ちており、受入の改善がそのまま課題の速さにはならない。

もう一つの問題は集約の混同である。ある文脈区間の平均受入は、その区間に到達した課題と段階の寄せ集めを、検証回数で重み付けしたものである。受入の高い種類の呼び出しがその区間に多く含まれれば、個々の種類の中では受入が下がっていても平均は上がって見える。論文が課題をそろえた遅い行動で示した逆転は、まさにこの混同が実データで起きることの証拠である。したがって問題は、受入を文脈長だけで説明するのではなく、仕事の種類と段階と課題の進み具合を条件として保持したまま測ること、そして測った不一致の分布を、限られた教師の予算の配分へどうつなぐかにある。最終応答だけを教師にする従来の作り方では、中間の行動や振り返りは学習対象に入らず、その不一致は配分の信号にもならない。

## 手法のあらまし

流れは三段である。第一に、閲覧とソフトウェア工学の二つの仕事から軌跡状態のコーパスを作り、元の課題が学習と試験で重ならないよう分けたうえで、各状態に履歴と次の助手の続きと条件の注記を付ける。第二に、動的実行で実際に遭遇する呼び出しの分布を観測し、再生で同一の履歴を全方式へ渡して比べ、集約と、課題と段階をそろえた比較と、仕事と段階ごとの profile を並べて、どこで下書きが外れるかを読む。第三に、対象が生成した訓練軌跡を助手ターンごとの区間へ展開し、各区間について受入隔たりを状態条件付きで推定し、基礎の配分を保ちながら隔たりへ寄せた配分を、区間ごとの予測数で割って訪問確率へ直し、時代ごとに配分表を更新しながら基盤の下書きモデルを蒸留で学習する。下書きモデルの構造と蒸留の目的関数は基盤のまま変えない。

## 手法

### 1. 軌跡コーパス — 判断の直前の履歴を単位として残す

第一の仕組みは評価と学習の共通の単位を作ることである。入力は既存の軌跡集から集めたエージェントの実行記録であり、処理は、各助手の続きについて、その直前に利用可能だった履歴と続きそのものを一つの状態として切り出し、仕事の種類、計画・行動・振り返り・回答という四つの段階、実際の接頭辞長、直前の道具とのやり取り、軌跡内の位置を付けることである。出力は学習用一万件と試験用二千五百件の状態で、両者は元の課題が重ならず、二つの仕事へ均等に分かれ、二仕事と五つの文脈層と四段階の四十通りの組合せすべてを含む。この仕組みが減らすボトルネックは、比較の条件のずれである。再生では全方式が同じ保存履歴を受けるため、方式間の差は入力の差ではなく一致の差として読める。追加の費用はコーパスの構築と保管であり、道具の観測が接頭辞の文字数の大きな割合を占めることからも、履歴そのものが重い対象である。失敗条件として、元の課題の分け方を誤れば学習と試験が漏れるため、論文は課題単位の分割と、試験側の課題集合を訓練から除く照合を付録で詳しく述べている。

### 2. 三層の診断 — 集約、課題をそろえた比較、仕事と段階の profile

第二の仕組みは観測の分解である。観測するのは検証一回あたりの受入トークン数と、入力処理を含むモデル呼び出しのスループットであり、保持する状態は文脈区間、仕事、段階、課題の識別である。処理は三層に進む。まず動的実行の集約で文脈とともに受入とスループットがどう動くかを見て、次に二十歩目以降の行動だけを取り出し、同じ課題が両方の文脈区間に現れる場合だけを対にして差を取り、最後に再生で仕事と段階ごとに傾向を分ける。この処理が示したのは、集約の上昇と、そろえた遅い閲覧行動での低下と、仕事による傾向の逆転が同時に成り立つことである。この診断が減らすボトルネックは解釈の誤りであり、平均だけを見て文脈が長いほど下書きが易しくなると誤読する危険を避ける。追加の費用は、対にした推定のための再標本化などの統計処理である。失敗条件として、対にできる課題は両区間に到達した課題に限られるため、そろえた比較の対象は全体の部分集合であり、到達しなかった課題の傾向はこの比較からは分からない。

### 3. 全ターンの教師 — 最終応答の外側の判断を学習対象にする

第三の仕組みは教師候補の範囲である。入力は対象モデルが生成した訓練軌跡であり、処理は、その中の各助手の生成を、利用可能な履歴と本文または道具呼び出しの続きからなる区間として切り出すことである。各区間は、実際の接頭辞長、段階、仕事の種類、観測や失敗や再試行を含む直前の道具の状態という状態を持つ。出力は、固定配分でも適応配分でも共通に使われる区間の集合である。この仕組みが減らすボトルネックは教師の欠けであり、最終応答は軌跡の中の一判断にすぎず、計画や行動や振り返りの不一致はそこからは学べない。追加の費用は、区間数が増えるぶんの統計の保持と標本化の管理であり、予測の総量そのものは予算で固定されるため、範囲を広げることは配分の薄まりとの交換になる。失敗条件として、短い道具要求と長い推論応答では一回の訪問で得られる予測の数が大きく違うため、区間を均等に訪問するだけでは配分したつもりの教師量が実現しない。この問題は次の配分の仕組みが引き受ける。

### 4. 状態条件付きの受入隔たり — どこでどれだけ外れているかを数える

第四の仕組みは優先度の信号である。観測するのは、教師に沿って進めた下書きブロックの中で、位置ごとに対象と下書きの分布がどれだけ重なるかであり、重なりは全変動距離を一から引いた量として定義される。処理は二段で、まずブロック内の各位置について、その位置までの重なりの積を積み上げて正規化し、早い位置での不一致が後続の連続受入を絶つことを重く反映した隔たりを区間ごとに作る。次に、その隔たりを区間自身の移動平均と、状態の組でまとめた群の平均との間で、訪問の蓄積に応じた重みで縮小推定する。群は状態の属性を組み合わせて作り、疎な状態では粗い水準へ寄せる。出力は区間ごとの推定隔たりである。この仕組みが減らすボトルネックは、優先度の粗さである。全体の平均で縮小すると段階や仕事による違いが消え、位置ごとの単純平均では早い不一致の重さが消える。追加の費用はブロック単位の重なりの集計と群統計の保持である。失敗条件として、訪問の少ない区間は群の平均へ寄るため、珍しい状態の固有の不一致は初期には捉えにくく、学習が進んで下書きが変われば推定も古くなるため、時代ごとの更新が前提になる。

### 5. 予測予算での配分と事象正規化 — 配分を訪問へ正しく直す

第五の仕組みは配分の決定である。入力は区間ごとの推定隔たりと、接頭辞長の層と仕事ごとに割り当てた基礎配分であり、保持する状態は区間ごとの配分と、一回の訪問で得られる有効予測数の見積もりである。処理は、隔たりを全体の加重平均で割って上下を切り取った相対値を作り、基礎配分と、基礎配分へその相対値を掛けて正規化した適応分とを混ぜることで、各区間が基礎の一定割合を下回らない配分を得る。次に、その配分を予測数の見積もりで割って正規化し、訪問の確率へ直す。これにより、予測を多く出す区間は少ない訪問で、少ない区間は多い訪問で、狙った配分どおりの教師量になる。最初の時代は基礎配分で統計を集め、以降の時代の境目で配分表を更新する。配分の計算自体は学習の損失からは切り離され、標本化された区間には元の蒸留の損失がそのまま使われる。この仕組みが減らすボトルネックは、限られた予算の無駄遣いであり、すでに一致している区間への過剰な教師を、隔たりの大きい区間へ回せる。追加の費用は予測数の推定と時代ごとの表の更新である。失敗条件として、予測数の見積もりがずれれば実現する配分も狙いからずれ、隔たりの相対値の切り取り幅を狭くしすぎれば適応が効かず、広げすぎれば覆いが痩せるため、混ぜる割合と切り取り範囲が交換条件になる。論文の設定では混ぜる割合は〇・五、相対値の範囲は〇・五から二に置かれている。

### 6. 一つの区間が学習される流れ

対象が生成した軌跡が区間へ展開され、各区間は状態とともに候補に入る。時代の初めに配分表が、基礎配分と推定隔たりから配分を作り、予測数で割って訪問確率へ直す。訪問された区間では下書きブロックの重なりが測られ、隔たりの移動平均と群統計が更新される。時代の境目で配分表が作り直され、次の時代の訪問が変わる。学習が終わった下書きは、動的実行と再生の両方で、基盤を含む比較対象と同じ条件で測り直される。

|---|---|---|---|---|

## 評価

### まず見るところ

結論は、診断と学習の両方についてである。診断では、受入の文脈傾向は仕事と段階と課題の進み具合で変わり、集約の上昇はそろえた比較の低下と両立することが示された。学習では、提案方式は段階別の比較七十二件中六十八件で首位となり、再生の二十四件はすべて首位だった。速度では、再生のスループットが基盤より一貫して高く、検証の収量も再生で大きく伸びた。一方で課題全体の所要時間では基盤の下書き方式がなお最良の条件が多く、受入の改善が課題の速さへ直結しないことも同時に示されている。評価の強さは、百八通りの設定と、同一接頭辞の再生と、予算をそろえた除去実験を組み合わせた点にある。弱さは、対象が一つの系列に限られ、仕事量も二種であり、学習の切り分けが四十億級の対象に限られる点である。

### 感度・スケーリング・ストレス条件

温度を〇から一へ上げると、一致させた比較対象の受入は四十五件すべてで下がった。基盤方式の再生での低下は六・五パーセントから八・七パーセントで、他の方式より小さかった。文脈については、動的の集約と再生とで傾向が違い、再生では閲覧が下がりソフトウェア工学が上がるという仕事による逆転がある。対象の規模を変えても再生の利得は保たれたが、動的実行の段階別では四件の例外が出た。同時要求数やバッチを変えた感度、別のモデル系列での感度は論文では報告されていない。

### 立ち上がり・内部挙動

配分は最初の時代を基礎配分で走らせて統計を集めてから適応を始めるため、立ち上がりの時代は診断のための費用として必要である。内部の信号である受入隔たりは、下書きが学習で変わるにつれて時代ごとに更新され、優先度が固定されないことが設計上の前提になっている。学習の一例では、四十億級の対象で三時代、九千三百六十一回の更新を行い、訓練と検証と対象の提供を合わせて約九時間四十二分、二台分で十九・四一台時を要したと付録が報告している。

## 既存研究との差

下書きモデル側の先行研究は、対象の特徴を融合する方式、ブロックを並列に生成する方式、ブロック内の依存を扱う方式、固定費の並列下書き、履歴の下書き保持を外す方式など、提案の作り方と実行の改善が中心だった。エージェント向けの先行研究も、バッチ処理でのトークン配分や行動提案の学習など、実行側の工夫が中心である。教師の配分については、蒸留のデータと乖離の選び方、配備中の問い合わせへの適応、状態の占有を重みにする研究があるが、エージェントの軌跡では、選ぶ単位と、その単位が供給する予測の数が結び付いている点が扱われていなかった。本論文は、評価の単位を軌跡の中の判断へ下ろして集約の誤読を示したうえで、その単位をそのまま教師の選択単位にし、予測の数で正規化して予算配分へつないだ点が異なる。

## 限界・実装状況

- 対象は一つのモデル系列の三規模のみで、系列が変われば受入の profile も配分の効き方も変わり得る。再現は未評価である。
- 除去実験は四十億級の対象だけであり、より大きな対象で適応配分の利得が同じ規模で残るかは未評価である。
- 課題全体の所要時間では基盤方式が最良の条件が多く残り、入力処理や道具の費用が支配的な課題では、受入の改善が利用者の待ち時間へ届く割合は小さい。
- 配分は最初の時代の統計集めを前提とし、状態の群の縮小推定に依存するため、軌跡の数が少ない新しい仕事では群が粗くなり、固有の不一致を捉えにくい可能性があると設計から読み取れる。
- 公式のコードは公開先が示されている。基盤の下書きの構造と蒸留目的は変更しておらず、提案は教師候補の作り方と配分の層の追加として位置づけられる。

## 一般的な実装上の含意

集約指標の傾向は、その区間にどんな種類の仕事がどれだけ混ざっているかで反転し得るため、長い履歴を持つ反復型の負荷では、条件をそろえた比較を集約と必ず並べて見るべきである。教師の予算を配る際は、選ぶ単位が供給する予測の数が単位ごとに違うことを無視すると、配分したつもりの量と実際に届く量がずれるため、配分は訪問回数ではなく事象の数で数えるのが原則になる。また、連続受入のように早い失敗が後続を絶つ構造では、位置ごとの平均ではなく接頭辞の積のような順序を保つ得点が、直すべき場所を正しく指す。
