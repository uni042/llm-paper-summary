# Quantize-Sample-and-Verify: LLM Acceleration via Adaptive Edge-Cloud Speculative Decoding

## 概要
エッジ端末の小型言語モデルがドラフトを作り、クラウドLLMが検証するエッジ・クラウド投機的復号では、ドラフトtokenそのものだけでなく確率情報を通信すると帯域が律速になる。Q-SVは、量子化された確率情報からサンプルしてもクラウド側の目標分布を厳密に保存する量子化・サンプル戦略と、通信状態・意味的不確実性に応じてドラフト長と量子化精度を同時調整する制御を組み合わせる。通信遅延を含むスループットモデルに基づき、帯域が細い条件で固定精度・固定ドラフト長より有利になる。

## 問題設定
通常の投機的復号では高速なドラフトモデルが複数tokenを提案し、対象モデルが並列検証する。エッジ・クラウド構成ではこの分業が自然だが、端末からクラウドへ候補と確率情報を送る通信時間が対象モデル計算の節約を相殺する。確率を粗く量子化すれば通信量は減る一方、単純な量子化後サンプリングは生成分布を変え、投機的復号の「対象モデルと同じ分布」という性質を壊す。

さらに最適な設定は一定でない。無線帯域が悪いと送信bit数を減らしたいが、意味的不確実性が高いtokenでは粗い量子化が検証効率を下げる。長いドラフトはクラウド呼出し回数を減らせる一方、誤った候補が増えると無駄な検証と通信が増える。したがって量子化bit幅とドラフト長を独立固定するのではなく、通信と受理の双方を同じ目的関数で扱う必要がある。

## 手法
### 分布保存型の量子化・サンプル
Q-S（Quantize-Sample）は端末側のドラフト分布を量子化して送る際、量子化セルの代表値をそのまま確率として扱うのではなく、量子化情報から補正されたサンプリング・検証規則を構成する。入力はドラフトモデルのtoken確率と量子化精度、出力は候補tokenと圧縮された分布情報である。クラウド側の受理・補正と組み合わせた最終token分布が対象LLMから直接サンプルした分布と一致することを理論的に保証する。これにより通信量削減を品質近似と交換せずに済む。

### 通信込みスループットモデル
著者らは1サイクルを、端末ドラフト生成、候補情報のアップリンク、クラウド検証、必要な応答通信へ分解し、単位時間当たりに確定できるtoken数をモデル化する。ドラフト長を増やすと一度のクラウド検証で進める期待token数は増えるが、送信量と棄却時の無駄も増える。量子化bit幅を下げると通信時間は短縮するが、候補分布を表す情報が粗くなる。この交換条件を明示する点が、計算時間だけを見る通常の投機的復号モデルとの違いである。

### 適応制御
各サイクルでチャネル状態と意味的不確実性を観測し、候補ドラフト長と量子化精度を選ぶ。回線が細いと低bit化の価値が高まり、ドラフト分布が鋭い場合も少ない情報で候補を表しやすい。一方、不確実性が高い場合には精度を上げ、誤差による検証効率低下を抑える。出力は次サイクルのドラフト長・bit幅であり、固定設定では追従できない時間変動を吸収する。

## 評価条件
|観点|内容|
|---|---|
|方式|エッジSLM + クラウドLLMの投機的復号|
|評価|通信遅延を含む解析モデルとシミュレーション|
|変動要因|チャネル帯域、意味的不確実性、ドラフト長、量子化精度|
|比較|固定ドラフト長・固定量子化等の非適応構成|
|主要指標|token throughput、通信遅延、分布保存性|

## 主要結果
シミュレーションでは、Q-Sが通信情報を削減しながらクラウド対象モデルの出力分布を保存し、適応制御が現実的なエッジ・クラウド条件で復号効率を改善する。重要なのは単一の最大高速化倍率より、帯域と意味的不確実性が変わる条件で固定設定より高いtoken throughputを維持する点である。論文の主結果はシミュレーションであり、実スマートフォンと実クラウドGPUを結んだエンドツーエンド実測ではない。

## 既存研究との差
通常の投機的復号はdraft/targetの計算比と受理率を中心に設計する。Q-SVは端末とクラウド間の有限帯域を第一級の資源として扱い、送信する確率情報の量子化まで検証アルゴリズムへ組み込む。単なる低bit通信ではなく、量子化後も対象分布を保存する点が中核である。

## 限界
評価は主にモデル化とシミュレーションで、無線stackのjitter、クラウドqueueing、端末thermal throttlingなど実配備固有の変動は十分に実測されていない。適応器はチャネル状態と不確実性の観測を必要とし、推定誤差や制御overheadが大きい環境では利得が縮む可能性がある。
