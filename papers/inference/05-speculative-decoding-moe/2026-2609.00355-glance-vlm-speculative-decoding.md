# Vision Is Not Overhead: One-Pass Block Drafting for Lossless Speculative Decoding in Vision-Language Models

> GLANCEはfrozen VLM targetの融合済みvision-language stateからfuture token blockを1 passでdraftし、wide treeを1 target passで検証するlossless speculative decoder。grounded taskでautoregressive比最大2.93x。free-running textではchain drafterが優位となる境界も示す。
## 書誌情報
- **著者**: Jungseob Lee, Seongtae Hong, Dongyub Jude Lee, Chanjun Park, Jaehyung Seo, Sugyeong Eo, Heuiseok Lim
- **公開**: arXiv:2609.00355v1, 2026-08-31
- **種別**: arXiv preprint
- **対象**: speculative decoding、vision-language model、block diffusion、tree verification、lossless decoding
- **実装**: Official code: https://github.com/js-lee-AI/GLANCE. SGLang 0.5.6 production comparison.
## 問題設定
VLM speculative decodingはdrafterがautoregressiveなためdraft depthだけsequential passesが必要で、小型化すると毎stepでimageを処理できずvisionを圧縮・削除しがちである。しかしDoc/Chart系ではimageがnext tokenを強く拘束し、visionを失うと最もdraftしやすい部分で精度が落ちる。
## 新規性
GLANCEはtargetがprefillで既に作ったfused vision-language hidden statesをblock-diffusion headへcross-attentionで渡すので追加vision encoderを持たず、16-token blockをone passでdraftする。offset-wise marginalsからwide prefix treeを作り、ancestor-masked target passでtarget自身のgreedy pathだけをcommitする。
## 手法
### 手法のあらまし
frozen Qwen3-VL-8Bのlayers {1,9,17,25,33}からfused statesを取得し、5-layer 1.05B block headがblock size16のmasked future positionsへoffset-wise token marginalsを一度に出す。prefix probability productで候補prefixをrankしprefix-closed treeを固定budgetまで構成する。tree全nodeをancestor-only maskでtargetへpackして1 forwardで検証し、target greedy continuationと一致するlongest represented prefixをcommitし、最後のverified rowからbonus tokenを出す。draft headが誤っても受理長が短くなるだけでtarget outputは変わらない。trainingはtarget/vision towerをfreezeし、target自身のgreedy generations 16K rowsでheadだけ1 epoch学習する。

### Fused-state block drafter
targetのvision-language fusion済みhidden statesを再利用しraw image encodingなしで16-token blockをparallel draftする。

### Wide candidate tree
offset-wise marginalsのproduct scoreからprefix-closed treeを作り、one-pass draftのwidthをaccepted lengthへ変換する。

### Ancestor-masked verifier
tree nodeを1 target forwardへpackし各nodeでexact autoregressive conditionalを再現、target greedy pathだけをcommitする。

### Tie-aware losslessness gate
fp32ではargmax margin条件下でbitwise greedy equivalence、production bf16ではtie近傍をtarget tokenへdeferしてbyte identityを守る。

### Entropy-guided regime characterization
accepted lengthがtarget next-token entropyに強く支配され、grounded/copied spansほど長くなることをtask横断で定量化する。

### 全体のデータ／制御の流れ
prefillでtarget vision encoderとdecoder fusion→decode round root→block head 1 pass→candidate tree構築→target tree verification 1 pass→longest target-greedy prefix+bonus token commit→次round。autoregressive drafterのdepth分passを除去しつつtargetは無改造。
## 評価条件
- **Hardware**: same-card production comparisons; appendix includes NVIDIA A6000 forward-level measurements
- **Software**: SGLang 0.5.6、CUDA graphs、fp32 exactness audit、production bf16 with tie-aware gate
- **Model**: Qwen3-VL-8B-Instruct primary、Qwen3-VL-4B transfer、Llama-3.2-11B-Vision transfer
- **Dataset / Trace**: COCO captioning、TextVQA、InfographicVQA、DocVQA、ChartQA、ScienceQA boundary、speech/chat/code transfer probes
- **Baseline**: autoregressive target、n-gram lookup、classic two-model speculative decoding、EAGLE3-VL production、EAGLE-3 matched training、ViSpec、Medusa、GLANCE same head as width-1 chain
- **Correctness**: Greedy mode is lossless under verifier/margin assumptions and audited prompts reproduce target. Sampling preserves target distribution but byte identity is undefined.
- **same-engine head-to-head**: SGLang 0.5.6, one card, both speculative arms CUDA-graph captured, 32 draft tokens/round; EAGLE3-VL uses 8 sequential draft passes vs GLANCE 1.
- **training**: 8000 COCO + 8000 TextVQA target-greedy generations, 16K teacher-forced rows, one epoch, target and vision tower frozen.
- **block head**: 5 layers, 1.05B params, block size 16, fused target layers 1/9/17/25/33.
- **greedy correctness**: every greedy run gated on reproducing target decoding; fp32 theorem plus bf16 tie-aware production gate.
Five tasks ordered open-ended→grounded; same-engine/round-budget wall-clock comparison, matched-training drafter comparison, tree-vs-chain ablation, fused-state ablation, entropy fits, target/modality transfer, long-context checks.
Claims are batch-one and decode-only. Larger batches are unclaimed; cross-target fits partly use proxy drafters.
## 主要結果
Grounded image-anchored tasks favor one-pass block drafting, while free-running captioning/TextVQA favor autoregressive chain drafting. GLANCE reaches 2.93x AR speedup on ChartQA and exceeds production EAGLE3-VL on all three grounded tasks, but is slower on the two open tasks.

- same-engine ChartQA speedup / 2.93x over AR, 8.26 ms/token (比較対象: EAGLE3-VL 2.77x, 8.75 ms/token; 条件: 32 draft tokens/round, SGLang 0.5.6) — GLANCE +6.0% faster than production head.

- InfographicVQA/DocVQA margin / +7.6% / +5.4% vs EAGLE3-VL (比較対象: production EAGLE3-VL; 条件: same engine/card/budget) — all paired bootstrap intervals exclude zero.

- matched-training acceptance / 2.7x longer pooled; 4.0x on ChartQA (比較対象: EAGLE-3 head trained on same corpus; 条件: same frozen target/training framework/schedule) — block form provides acceptance advantage beyond data.

- tree-vs-chain / 1.36x geomean wall-clock advantage (比較対象: identical GLANCE head as width-1 chain; 条件: same harness) — wide-tree use of one-pass block output is independently valuable.

- entropy fit / pooled b1=0.63, R²=0.71 over 7,751 rounds (比較対象: task-wise slopes 0.46 caption→1.71 templated ChartQA; 条件: five main tasks) — lower next-token entropy predicts longer accepted blocks, increasingly with grounding.

- conditioning ablation / acceptance collapses to 1.11 when fused state zeroed (比較対象: full GLANCE; 条件: drafter context ablation) — head genuinely uses target context/vision grounding.

### 負の結果・境界条件
- **Free-running text loses**: captioning: GLANCE 1.81x vs AR but EAGLE3-VL 2.16x; TextVQA GLANCE 2.02x vs EAGLE3-VL 2.49x. Deep block candidates drift when token dependencies are not image-pinned.
- **Short-answer no amortization**: ScienceQA single-letter outputs fall below parity; method targets generation rather than classification.
- **Long context parity**: around 6.7K context same-engine CUDA-graph comparison is -2.3% with CI spanning zero; GLANCE acceptance declines more than EAGLE3-VL.
- **Graph capture dependency**: at 2K, CUDA graph converts saved draft passes to +5.8% margin; eager mode is roughly parity (-1.0%, CI spans zero).

### 結果の読み方
The speedup comes from removing sequential draft depth and exploiting low-entropy grounded spans with wide trees. Vision is an inherited source of predictability rather than repeated drafter overhead.
## 品質への影響
Greedy quality is unchanged by construction/audit; a weak draft affects only acceptance. Sampling preserves distribution rather than byte identity.
## 既存研究との差
- EAGLE/EAGLE3-VL drafts autoregressively and pays one drafter pass per depth; GLANCE emits the block in one pass so tree width does not add sequential draft steps.
- Prior VLM speculation compresses/prunes/hides vision or gives a small drafter its own vision path; GLANCE reads target fused states and incurs no second visual encoding path.
- Block-diffusion VLM methods modify the target itself and can change model outputs; GLANCE keeps target frozen and uses diffusion only in the auxiliary drafter plus exact verifier.
- Classic two-model speculation may accept more tokens but is slower because drafter cost per accepted token dominates; GLANCE emphasizes round cost rather than acceptance alone.
## 限界
- batch-one/decode-only claims; no larger-batch evidence.
- greedy bitwise theorem is fp32; production bf16 needs tie-aware gate.
- sampling rows preserve distribution, not byte identity, and use one run/temperature with small samples.
- two of three cross-target fits use proxy drafters rather than trained block adapters.
- grounding task ordering is architecture-scoped and inverts under cross-attention fusion.
- free-running text can favor autoregressive chain; ScienceQA has too little decode loop; long-context margin approaches parity.
- head is 1.05B vs EAGLE3-VL ~0.40B, although one-pass form avoids sequential depth cost.
## 実装状態
Official open-source repository: https://github.com/js-lee-AI/GLANCE. Primary implementation attaches a 5-layer 1.05B DFlash-family block head to frozen Qwen3-VL-8B; production comparison uses SGLang 0.5.6.
## 研究上の位置づけ
Speculative Decoding系。VLM speculative decodingのvision-access問題をdrafter小型化ではなくone-pass parallel block draftingで解消し、target fused multimodal stateをそのままdraft conditioningへ再利用する。lossless verifierを維持しながらgrounded generationの低entropy/copied spansを速度へ変換する。
