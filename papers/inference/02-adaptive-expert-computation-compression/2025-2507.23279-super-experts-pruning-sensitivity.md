# Unveiling Super Experts in Mixture-of-Experts Large Language Models

> 全専門家の0.5%未満しかないスーパー専門家が巨大活性と注意シンクの起点であり、Qwen3-30B-A3Bでは6144個中わずか3個を削るだけで推論課題平均が69.37から4.02へ崩壊することを示す。
## 書誌情報
- **著者**: Zunhai Su, Qingyuan Li, Hao Zhang, Weihao Ye, Qibo Xue, Yulei Qian, Yuchen Xie, Ngai Wong, Kehong Yuan
- **著者・所属**: Tsinghua University; Meituan; Xiamen University; Nanjing University; The University of Hong Kong
- **公開**: arXiv:2507.23279v3
- **種別**: プレプリント
- **対象**: MoE専門家重要度、専門家剪定、Super エキスパート、massive 活性値、attention sink、systematic outlier
- **実装**: 著者がSE自動profiling toolを公開。calibrationでMA形成層と各エキスパートのdown_proj最大出力を計測し閾値判定する。
## 概要
本研究はMoE内に全専門家の0.5%未満しか存在しないにもかかわらず、削除するとモデル機能が崩壊するSuper エキスパート（SE）を同定する。SEは初期層のdown_proj出力に極端な活性外れ値を作り、残差経路を通じてmassive 活性値を形成する。Qwen3-30B-A3Bでは6144専門家中3個（0.05%）だけがSEで、これらを動的枝刈りすると非推論9タスク平均が70.22から55.00へ低下し、推論モードでは平均69.37から4.02へ崩壊する。DeepSeek-R1でも平均75.64から1.81へ低下する。機構解析ではSEがsystematic outlierの起点となり、attention sinkを形成し、SE削除後のsink decay rateが約90%以上になることを示す。

中心的な発見は、初期の混合専門家層にある一部の専門家だけが、下降射影の出力で他より桁違いに大きな活性外れ値を作り、それが残差接続を介して層間の巨大活性へ発展することである。著者らはこの極少数をスーパー専門家と呼ぶ。調べたモデルでは全専門家の0.5%未満しかなく、Qwen3-30B-A3Bでは6144個中3個、DeepSeek-R1では15677個中10個にすぎない。それにもかかわらず、この集合だけを除くと性能が壊れる。

さらに本研究は、スーパー専門家を単なる高重要度項目として終わらせず、系統的外れ値の起点として説明する。先頭などの注意シンクとなるトークンが初期層でスーパー専門家へ強く割り当てられ、その下降射影が巨大な値を作り、その値が後続層へ残差伝播し、最終的に注意シンクを形成する。スーパー専門家を削ると巨大活性と注意シンクが同時に消え、推論モデルでは反復的で無内容な生成へ崩壊する。この因果鎖を複数モデル、複数データ領域、学習段階の異なる派生モデルで確かめた点が新しい。

代表結果として、Qwen3-30B-A3B SE sparsityはC4 profilingで全エキスパートに対して3 / 6144 エキスパート = 0.05%。極端に少数のエキスパートだけがSE条件を満たす。
## 問題設定
既存の専門家単位圧縮では、活性頻度、ルータ得点、再構成誤差、専門家間類似度などの経験的指標から重要度を推定し、剪定、統合、低ビット化、低ランク化の強さを決める。しかし、混合専門家モデルの中で重要度がなぜ大きく偏るのか、極少数の専門家がモデル内部のどの機構を支えているのかは十分に分かっていなかった。単に使用頻度が低い専門家を削る発想では、使用回数とは別の理由で不可欠な専門家を見落とし得る。

この理解不足は圧縮の安全性に直結する。総専門家数に対して削除割合がごく小さければ品質への影響も小さい、という直感が成立しない場合、数個の専門家を誤って削るだけでモデル全体が壊れる。本研究は、極端な活性値を生み出して後続層の内部状態と注意分布を安定化している専門家が存在するという仮説を立て、専門家の発見、位置の安定性、削除時の品質変化、注意機構への因果的影響まで一続きに検証する。これにより、圧縮率を上げる前に絶対に保護すべき専門家を識別するための機構的根拠を与える。
## 新規性
中心的な発見は、初期の混合専門家層にある一部の専門家だけが、下降射影の出力で他より桁違いに大きな活性外れ値を作り、それが残差接続を介して層間の巨大活性へ発展することである。著者らはこの極少数をスーパー専門家と呼ぶ。調べたモデルでは全専門家の0.5%未満しかなく、Qwen3-30B-A3Bでは6144個中3個、DeepSeek-R1では15677個中10個にすぎない。それにもかかわらず、この集合だけを除くと性能が壊れる。

## 手法
### 手法のあらまし
入力は解析対象の混合専門家モデルと較正用データである。処理の第一段階では、較正文をモデルへ通し、各デコーダ層の隠れ状態を観測する。通常値より何桁も大きい巨大活性が初めて形成される層を特定し、その形成に関与する初期層集合を得る。次に、その層集合に含まれる全専門家について、下降射影の出力絶対値の最大値を収集する。全専門家・全対象層の値から分布を作り、99.5百分位を超え、かつ全体最大値の10%以上という二条件を満たす専門家をスーパー専門家として抽出する。ここまでの出力は、層番号と専門家番号からなる保護対象集合である。

第二段階では、この集合が本当に不可欠かを動的剪定で検証する。通常のルータがスーパー専門家を選択した時だけその計算を飛ばし、元モデル、同じ個数を全層から無作為に削る条件、同じ層から無作為に削る条件と比較する。これにより、削除個数や層位置ではなくスーパー専門家そのものが性能差を生むかを判定する。非推論モデルでは一般知識・常識・数学を含む複数課題、推論モデルでは難しい数学、科学推論、コード生成を評価し、平均正解率、正解率、困惑度を測る。

第三段階では内部機構を追跡する。注意シンクとなるトークンとそれ以外のトークンでルータ得点を比較し、シンク側だけがスーパー専門家へ極端に強く割り当てられることを確認する。その専門家の下降射影出力、残差加算後の隠れ状態、後続注意層の注意得点を順に観測し、専門家の外れ値が巨大活性へ、巨大活性が注意シンクへつながる経路を確かめる。最後に剪定前後のシンク向け注意量から注意シンク減衰率を計算する。出力として、保護対象専門家集合、削除時の品質損失、巨大活性消失、注意シンク崩壊という一貫した証拠を得る。圧縮器はこの集合を剪定・統合・強い量子化から除外することで、極端な品質事故を避けられる。

### スーパー専門家の自動同定
まず較正入力をモデルへ通し、各層の隠れ状態を保存して巨大活性が形成される層を見つける。巨大活性は通常の活性より何桁も大きい少数の値として現れ、初期の混合専門家層から残差接続を通って後続層へ残る。形成層を限定した後、その層内の全専門家について下降射影後の最大絶対出力を集計する。これにより、単にルータが頻繁に選ぶかではなく、モデル状態へ極端な値を書き込む能力を直接測る。

判定では全対象専門家の最大出力分布の99.5百分位より大きく、さらに全体最大値の10%以上という二重閾値を使う。著者らは相補累積分布とべき分布当てはめで尾部が強い長い裾を持つことを確認し、閾値を変えた感度分析でも同じ専門家が残ることを示す。C4だけでなくWikiText-2、中国語評価、数学、コード、法律、医療の入力でも位置がほぼ不変で、基底モデル、指示調整版、思考版でも同じ位置が維持される。このため一度の較正で得た保護集合を継続利用できる可能性が高い。

### 動的剪定による重要度検証
重要度検証では重みを恒久的に削除せず、通常のルータが対象専門家を選んだ時だけその専門家の実行を飛ばす。この方法なら、モデル構造や他のルーティング挙動を保ったまま、スーパー専門家の寄与だけを除ける。比較条件には元モデル、全層から同数を無作為抽出する剪定、スーパー専門家と同じ層から同数を無作為抽出する剪定を置く。無作為条件は複数回実行して平均するため、偶然に重要な専門家を引いた影響を抑えられる。

非推論条件ではQwen3-30B-A3B、DeepSeek-V2-Lite、Mixtral-8x7Bを用い、九つの一般課題とWikiText困惑度を測る。推論条件ではDeepSeek-R1とQwen3の思考モードを使い、GPQA、MATH-500、AIME、コード課題を評価する。結果は極端で、同数の無作為剪定がほぼ無影響なのに、スーパー専門家だけを削ると一般課題平均が二割以上低下し、推論課題では正解率がほぼゼロになる。これにより、少数削除による単純な容量低下では説明できない特異的重要性が示される。

### 巨大活性から注意シンクへの因果追跡
機構解析では、注意シンクとなる先頭トークンと通常トークンを分けて、初期混合専門家層のルータ得点を比較する。通常トークンでは得点が複数専門家へ比較的均等に分散する一方、シンクトークンはスーパー専門家へ非常に大きな得点を持つ。選ばれたスーパー専門家の下降射影には重み・活性の外れ値があり、その積として巨大な出力が生成される。残差加算によりこの値は層間隠れ状態へ書き込まれ、後続層でも保持・増幅される。

巨大な成分を持つトークンは後続の自己注意で多くの問い合わせから高い注意を受け、注意シンクとして働く。スーパー専門家だけを削る実験では、対応する巨大活性が消え、後続層の注意地図からシンクも消える。逆に最終層にある極端な専門家を削っても、巨大活性形成の起点ではないため同じ崩壊は起きない。この対照により、単なる大きな値ではなく、初期層で系統的外れ値を作るスーパー専門家が注意分布の安定化へ因果的に関与していると解釈できる。

### 注意シンク崩壊の定量化
注意シンクがどの程度失われたかを定量化するため、各注意頭について剪定前にシンク集合へ向いていた注意得点の総量と、剪定後の同じ総量を比較する。各頭の保持率を平均し、一から引いた値を注意シンク減衰率とする。値がゼロならシンクは維持され、値が一に近いほど元のシンク向け注意が消えたことを意味する。Qwen3-30B-A3BをC4で測ると、スーパー専門家剪定後は後続層でおおむね90%以上という非常に大きな減衰が続く。

この測定は品質低下と内部機構を結び付ける。注意シンクは意味的に重要な単語でなくても、注意確率の余剰を受け止めることで分布を安定させ、全後続トークンへ共通する暗黙の偏りを与える。スーパー専門家を圧縮すると、その起点となる巨大活性が失われるため、一つの専門家出力だけでなく後続する多数の注意計算が連続的に変わる。その結果、数学推論で同じ句を繰り返し続けるなど、局所的な精度低下ではなく生成機構全体の崩壊として現れる。

### 全体のデータ／制御の流れ
これは新しい推論モデルを導入する方式ではなく、既存の混合専門家モデルを圧縮する前に実施する安全性診断である。公開された自動同定器は、較正データを用いた前向き計算から巨大活性形成層を見つけ、各専門家の下降射影出力極値を集計し、二重閾値で保護集合を返す。判定結果は専門家の層番号と番号として得られるため、既存の剪定器、統合器、量子化器、低ランク圧縮器へそのまま保護マスクとして渡せる。

実運用上の含意は、全専門家を同じ交換可能なキャッシュ単位として扱わないことである。スーパー専門家は極少数なので常駐・高精度保持しても容量負担は小さい。残りの大多数だけを強く量子化したり、CPUやSSDへ退避したり、キャッシュから追い出したりすれば、圧縮・階層メモリの利点を維持しながら重大な品質崩壊を避けられる可能性がある。論文自体はこの派生システムの速度を評価していないが、専門家キャッシュやオフロード方式に対して明確な保護優先度を与える。

## 主要結果
SEは調査したMoEすべてで0.5%未満だが、同数random エキスパートとは桁違いの重要性を持つ。Qwen3-30B-A3Bは6144中3 SEをpruneすると非推論平均70.22→55.00、Wiki PPL 8.70→59.86。DeepSeek-V2-Liteは60.27→43.90、Mixtralは67.84→49.38。一方random 枝刈りは平均をほぼ変えない。reasoningではさらに極端で、DeepSeek-R1の10 SE 枝刈りで平均75.64→1.81、Qwen3 thinkingで69.37→4.02となりAIME等のPass@1が0になる。

- Qwen3-30B-A3B SE sparsity / 3 / 6144 エキスパート = 0.05% (比較対象: 全エキスパート; 条件: C4 profiling) — 極端に少数のエキスパートだけがSE条件を満たす。

- Qwen3 non-reasoning average / 70.22→55.00, 21.68% drop (比較対象: random 70.36; LC random 70.21; 条件: 3 SE 動的 枝刈り, 9 tasks) — 同数random削除ではなくSE固有のcriticality。

- DeepSeek-V2-Lite average / 60.27→43.90, 27.17% drop (比較対象: random 60.30; 条件: 2 SE 枝刈り) — 異なるMoE設計でも再現。

- Mixtral average / 67.84→49.38, 27.21% drop (比較対象: random 67.82; 条件: 1 SE 枝刈り) — 1/256 エキスパートだけでも大幅崩壊。

- DeepSeek-R1 reasoning average / 75.64→1.81, 97.61% drop (比較対象: random 75.53; 条件: 10/15677 SE 枝刈り) — reasoning能力がほぼ消失。

- Qwen3 thinking average / 69.37→4.02, 93.62% drop (比較対象: random 69.33; 条件: 3 SE 枝刈り) — AIME24/25とHumanEval Pass@1が0。

- attention sink decay / 約90%以上 (比較対象: 枝刈り前sink attention; 条件: Qwen3-30B-A3B, C4) — SE 枝刈りがattention sink機構をほぼ消す。

### 負の結果・境界条件
- 最終層にも極端な活性値 outlierを持つエキスパートは存在するが、massive 活性値形成に寄与しないため初期層SEほどcriticalではない。SE位置はdomainやpost-trainingでほぼ変わらず、頻度依存の単純なdataset-specific現象ではない。研究はSEを保護した圧縮法そのものの最終compression ratio/遅延改善までは提示しない。

### 結果の読み方
エキスパート importanceは滑らかな連続分布として扱えず、少数のSEがMoE内部のsystematic outlierとattention sinkを支える構造的役割を持つ。したがってエキスパート 枝刈り/merging/量子化ではSEを別クラスとして保護し、それ以外のエキスパートで圧縮率を稼ぐ設計が必要になる。
## 品質への影響
SE圧縮の品質損失は削除率から予想できないほど大きい。0.05% エキスパート削除でQwen3 reasoning平均が93.62%低下するため、compression safety上のhard constraint候補である。
## 既存研究との差
従来エキスパート compressionは活性値 frequency、ルーティング score、reconstruction loss、similarityなどをimportance proxyとして用いる。本研究はdown_projの極端な活性値とmassive 活性値形成というmechanistic signalでエキスパートを分類し、SEがattention sinkの起点であることまで示す。単なるimportance rankingではなく、圧縮禁止に近いcritical subsetを定義する点が異なる。
## 限界
SEはQwen、DeepSeek、Mixtralなど複数系統で確認されるが、すべてのMoE設計や将来モデルに必ず同じ閾値で存在する保証はない。profilingはcalibration forwardと全エキスパートのdown_proj極値計測を必要とし、非常に大規模なモデルでは診断コストがある。主要評価はSEを完全skipする枝刈りであり、低bit 量子化、partial merging、low-rank化でどの程度精度を落とせるかの連続的なsafe budgetは未確立。GPU型・profiling時間・追加メモリの実測も主要HTML本文では明確でない。
