# DAPD：注意による依存グラフを用いた拡散LLMの並列復号

## 概要

拡散型大規模言語モデル（diffusion LLM、以下dLLM）は、出力文の複数箇所をマスクした状態から反復的に復元する。自己回帰モデルのように左から一つずつ確定する必要はないが、複数位置の予測を同時に採用すると、各位置では高確率でも互いに矛盾した文章が生じうる。これは学習済みモデルが各位置の条件付き周辺分布を出す一方、同時確定には位置間の同時分布が必要だからである。

DAPD（Dependency-Aware Parallel Decoding）は、既存モデルの自己注意重みを依存関係の近似指標として利用する。未確定位置を頂点、相互依存の強い位置対を辺とするグラフを構築し、辺で直接結ばれない位置集合を一度に確定する。さらに高次数の位置を先に処理し、後続ステップの依存構造を簡略化する。追加学習や補助の予測モデルは必要としない。

LLaDA-8B-InstructのHumanEvalでは、Fast-dLLMが92.1ステップ・51.4トークン/秒・正答率37.2%だったのに対し、DAPD-Stagedは45.2ステップ・106.0トークン/秒・36.6%を報告する。速度は改善するが正答率は0.6ポイント低下する。またLLaDAの主表では比較方式とDAPDのブロック構成が異なるため、速度差の全てを位置選択アルゴリズム単独の効果とみなせない。

## 問題設定

マスク集合を `V_t`、現在の不完全な出力を `x_t` とすると、学習済みdLLMは各マスク位置 `i` に対して `p_θ(x_i|x_t)` を予測する。しかし、二位置 `i,j` の同時分布が `p_θ(x_i|x_t)p_θ(x_j|x_t)` と一致するとは限らない。例えば「[国]の首都は[都市]」の二つの空欄を同時に埋めると、それぞれの候補は単独で高確率でも、国と都市の対応が崩れうる。この問題を著者は同時分布と周辺分布の不一致と呼ぶ。

既存のFast-dLLMは確信度閾値、KLASSは確信度と前ステップからの予測分布の安定性、EB-Samplerはエントロピー制約で同時確定位置を選ぶ。いずれも位置単独の信頼性に強く依存し、離れた二位置が独立か、同じ事実に依存するかを直接評価しない。結果として連続した領域を順次確定しやすく、拡散モデルの順序自由な生成能力を十分に利用できない場合がある。

dLLMでは通常、一回の復号ステップでモデルを一回前向き計算するため、前向き計算回数（NFE）が推論費用を左右する。同時確定位置を増やせばNFEは減るが、依存する位置まで同時に採用すると品質が損なわれる。DAPDはこの速度と品質の交換条件を、位置間の依存関係を使って制御する。

## 手法

### 1. 自己注意から未確定位置の依存グラフを作る

各復号ステップで、未確定位置集合 `V_t` を頂点とする無向グラフ `G_t=(V_t,E_t)` を作る。位置 `i` から `j` への自己注意重みを `a_ij` とすると、対称な相互作用強度を `s_ij=(a_ij+a_ji)/2` と定義する。閾値 `τ_t` より `s_ij` が大きい場合だけ辺 `(i,j)` を張る。辺がある位置対は強く依存すると判断して同時確定を避け、辺がない位置対を並列処理候補とする。

この考え方はマルコフ確率場（MRF）の条件付き独立性に着想を得ている。ただし、注意重みが小さいことは数学的な独立性の証明ではない。さらに二頂点間に直接の辺がなくても、別の頂点を経由する間接的な依存は残る。著者は完全な独立性を厳密検査すると選択集合が小さくなり計算費用も増えるため、直接の辺がないことを実用的な緩和条件として採用する。この近似が品質低下の潜在要因になる。

注意行列は全層を無条件に平均せず、主実験ではTransformerの最後の30%の層について全ヘッドを平均する。上位層の方が位置間の意味的依存を反映しやすいという仮説を、短い合成系列で検証している。注意重みを返さない高速な融合注意カーネルを利用する場合には、重み取得方法の変更や追加のメモリ・計算が必要となる。

### 2. 高次数を優先する貪欲な独立集合選択

頂点 `i` の重要度を、他の未確定位置への相互作用強度の和 `d̃_i=Σ_{j∈V_t,j≠i}s_ij` で近似する。これは閾値で定義された厳密な辺数ではなく、注意重みから求めた連続値の次数代理指標である。さらに最大予測確率 `conf_i` を掛けた `d̃_i·conf_i` で候補を降順に並べ、上位から走査する。既に選んだ位置と辺で結ばれていない位置だけを現在の独立集合 `S_t` に追加する。

一回のステップでできるだけ多く確定したいなら、低次数の頂点を優先する方が直感的である。しかしDAPDが狙うのは現在の集合の最大化ではなく、今後も含めた総復号回数の削減である。多くの位置と競合する高次数の頂点を先に確定すれば、次回以降のグラフから多数の競合が消え、残りの頂点を少ない並列グループで処理しやすくなる。この発想はウェルシュ＝パウエル法によるグラフ彩色に由来するが、グラフは復号のたびに再計算されるため、静的な最適彩色を求めているわけではない。

独立集合を決めたら、そこに含まれる全位置のトークンを同時に確定し、残ったマスク位置と更新後の注意重みで次ステップのグラフを構築する。つまり「モデル前向き計算→注意重みと確信度の取得→依存グラフ→独立集合選択→複数トークン確定」という処理を繰り返す。選択計算の費用がモデル実行の削減分を超える場合には実時間の改善が縮小するため、ステップ数と実測速度を分けて検証する必要がある。

### 3. 後半の確信度による加速と二つの復号設定

標準のDAPD-Stagedは、残りマスク率が50%未満になると確信度0.9超の位置を積極的に確定する規則を加える。前半は依存グラフで相互干渉を避け、主要な依存が解消されやすい後半には確信度を利用して復号を加速する。全ステップで同じ確信度閾値だけを使う方式と異なり、生成の進行段階に応じて選択方針を変える。

DAPD-Directは、各ステップで確信度が1.0の位置を先に確定し、残りを独立集合選択へ渡す。数学的に厳密な確率1の位置は他位置との同時確定で不整合を生じないという考えに基づくが、浮動小数点表示の1.0と厳密な確率1は同一とは限らない。DirectはStagedよりステップ数が少ない場合がある一方、課題によって正答率が低下する。

依存閾値 `τ_t` は復号進行とともに線形に増加させる。LLaDAのStagedでは数学課題に0.01～0.05、その他に0.01～0.15、Dreamでは通常0.005～0.05、IFEvalでは0.1～0.5の範囲を用いる。閾値を上げるほど辺が減り、同時確定できる位置が増えるが、真の依存を見逃すリスクも増す。モデル・課題ごとに閾値を調整しており、設定不要な万能アルゴリズムではない。

## 評価条件

| 観点 | 実験条件 |
|---|---|
| モデル | LLaDA-8B-Instruct、Dream-7B-Instruct |
| 主なGPU | NVIDIA L40S |
| 課題 | HumanEval、MBPP、GSM8K、Math500、IFEval。別途、独立質問を連結したTriviaQA |
| 比較方式 | Fast-dLLM、EB-Sampler、KLASS、逐次復号 |
| 主指標 | 正答率、前向き計算回数に対応する平均復号ステップ数、実測トークン/秒 |
| 注意選択 | 最後の30%のTransformer層の全ヘッドを平均 |
| ブロック | LLaDAの主表ではDAPDが主に1ブロック、従来法は早期終了問題を避けるため4ブロック。Dreamでは同一の1ブロック条件 |
| 補助検証 | 長さ9の合成マルコフ確率場、注意層の構成要素除去、出力長とブロック数の感度分析 |

LLaDAの比較では、従来方式を単一ブロックで動かすと終了記号の早期出力で著しく品質が悪化するため、主表では4ブロック構成が使われている。DAPDは単一ブロックで評価されるため、同じ生成位置選択だけを切り替えた厳密な同条件比較ではない。ブロック数を増やせばDAPD自身も品質と速度の交換関係が変わる。この条件差は主要結果を読む際に必ず保持する。

### 3. 出力長とブロック数を変えた感度分析

HumanEvalで出力上限を256、512、1024トークンに変えると、DAPD-Stagedの正答率は36.6%、32.9%、31.7%、ステップ数は45.2、55.9、67.5、スループットは106.0、106.6、93.6トークン/秒となる。出力上限が4倍でもステップ数は比例して増えないが、正答率は低下している。出力長の分布や停止条件も変わるため、上限値だけを独立変数とする単純な因果比較ではない。

DAPDのブロック数を1、4、8、16へ増やすと、HumanEvalの正答率は36.6%、37.8%、39.6%、41.5%へ上がる一方、実測スループットは106.0、57.1、43.6、34.6トークン/秒へ下がる。複数ブロックで生成順序の制約が強まり品質が上がる可能性がある反面、全域の独立位置を同時確定する余地が減る。この結果は、主表のブロック設定の不一致が速度比較へ与える影響を直接示す。

### 4. 注意重みが依存性を表すかという構成要素検証

著者は、独立に抽出した5変数 `X_1,...,X_5` と、隣接変数の和を3で割った余り `Y_i=(X_i+X_{i+1}) mod 3` からなる長さ9の合成系列を作る。既知の依存グラフは `(X_i,X_{i+1},Y_i)` を結ぶ四つの三角形からなる。8層のマスク拡散Transformerを学習し、注意重みから推定した辺と真の辺を照合する。

上位2層の注意による辺識別の曲線下面積（AUC）は0.928、真の辺と非辺の平均注意強度比は2.204、次数順位の逆転率（OVR）は0.04だった。全8層を平均した場合はAUC/OVRが0.87/0.15、最初の1層だけでは0.73/0.37となる。上位層の方が依存関係の順位推定に適するという設計根拠である。ただし合成の短い系列での検証であり、自然言語の任意の長い系列で真の条件付き独立性を保証するものではない。

五つの独立したTriviaQA質問を一つの入力へ連結した評価では、合計2,500質問について逐次復号52.64%・256ステップ、Fast-dLLM52.12%・124.4ステップ、DAPD52.08%・66.2ステップだった。ほぼ同程度の正答率で独立した質問領域を同時に進められることは、提案の「全域に分散した確定位置を選ぶ」という機構を裏付ける。ただし、人工的に独立質問を連結した条件を通常の連続した文章生成へそのまま外挿できない。

## 既存研究との差

Fast-dLLMは高確信度の位置を同時に確定し、KLASSは予測分布の安定性も加える。EB-Samplerはエントロピーで並列確定の危険を制限する。これらは位置単位の信頼性を中心に評価するのに対し、DAPDは位置間の依存グラフを明示的に構成する。高確信度であっても互いに強く依存する位置は同時に確定せず、離れた独立領域を同じステップで進められる点が差である。

同時期のDAWNも注意を使って依存を扱うが、既に高確信度で確定した位置の情報から別位置の確信度条件を調整するのに対し、DAPDは未確定位置同士のグラフ上で独立集合を直接選ぶ。さらに高次数を優先して後続グラフを単純化するというスケジューリング目的がある。補助モデルの学習や追加の確率予測器を必要としない一方、内部の注意重みを取得できることが前提になる。

## 限界と再現上の注意

自己注意の小ささは条件付き独立性の証明ではなく、直接の辺がない位置にも間接依存が残りうる。閾値が大きいと依存位置の同時確定による品質低下、小さいと並列性不足による速度低下が起きる。LLaDAとDreamで別の閾値範囲を使っているため、異なるモデル・課題への移植には調整が必要である。

注意行列の取得、対称化、次数計算、独立集合選択は追加の処理である。論文のL40S実測ではモデル前向き計算の削減が勝るが、注意重みを返さない高速カーネル、長系列、大規模バッチ、CPUへの重み転送が必要な基盤では同じ利得を期待できない。出力トークン/秒とステップ数を両方測定する必要がある。

LLaDAの主表ではDAPDと比較方式のブロック数が異なる。DAPD自身のブロック数を増やすと正答率は上がるがスループットが下がるため、単一ブロックの最大速度を同じ品質水準での速度と誤認してはならない。DreamのHumanEvalではKLASSに対して正答率が低く、方式の優位は課題ごとに変わる。

著者実装のREADMEと論文v2の一部の実行値には差がある。例えばLLaDAのDAPD-Direct単一ブロックHumanEvalは論文v2では37.2%・22.7ステップだが、公開実装READMEには34.2%・23.5ステップとある。原因を推測で確定せず、追試ではコード版、閾値、ブロック数、出力上限、評価スクリプトを固定する。対象はマスク拡散型LLMであり、自己回帰型LLMの逐次生成依存をそのまま解消する手法ではない。
