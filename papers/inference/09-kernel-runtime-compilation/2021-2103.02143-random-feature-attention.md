# Random Feature Attention

## 概要
Random Feature Attention（RFA）は、通常のsoftmax注意がqueryとkeyの全組合せを評価するため系列長に対して二次の時間・空間コストを持つ問題を、カーネル近似へ置き換えて解く。中心となる発想は、softmaxの核である `exp(q·k)` を有限次元のランダム特徴写像 `φ(q)·φ(k)` で近似し、結合則によってkey側の計算を先に集約することである。これにより、注意行列そのものを構築せずに出力を求められる。

RFAは単に漸近計算量を改善するだけでなく、通常のsoftmax attentionを置き換えられるよう設計されている。言語モデリング、機械翻訳、長文分類でTransformer基準と同等以上の品質を示し、特に自己回帰デコードと長系列で実効的な速度・メモリ利得が大きくなる。論文の解析では長さ2,048の出力で12倍のデコード高速化と10%未満のメモリ使用量を示す一方、512程度の系列では並列化可能なsoftmaxの方が十分効率的で、RFAの速度利得がほぼ出ない条件も明示している。

## 問題設定
標準attentionでは各queryに対して全keyとの内積、指数化、正規化を行う。入力全体が既知ならquery方向を並列化できるが、自己回帰生成では時刻tのqueryが過去t個のkey/valueを参照するため、生成が進むほど1 token当たりの走査量が増える。全系列では二次時間となり、注意重みを保持する場合はメモリも二次に増える。

RFAが狙うのは「どのtokenを見るかを疎に制限する」ことではなく、softmax類似度自体を集約可能な形へ変えることである。したがって全履歴の情報を固定サイズの統計へ畳み込み、現在queryからその統計を読む再帰計算へ変換できる。利得は系列が長く、softmaxを時刻方向に十分並列化できない自己回帰条件ほど大きい。

## 手法

### softmaxカーネルのランダム特徴近似
RFAはGaussian kernelに対するランダムFourier特徴の考え方を利用する。queryとkeyをL2正規化した表記では、`exp(q·k/σ²)` をランダム特徴 `φ(q)^T φ(k)` で近似する。ランダム特徴数をDとすると、近似分散はDを増やすほど下がるが、その分だけ演算量と状態量が増える。

この近似により、通常はqueryごとに計算する `Σ_i softmax(q·k_i)v_i` を、分子の `Σ_i φ(k_i)⊗v_i` と分母の `Σ_i φ(k_i)` に分離できる。key/valueに依存する部分をquery到着前に集約できるため、queryは集約済み行列・ベクトルとの積だけでattention出力を得る。RFAはこの変形をmulti-head attentionにも適用し、標準softmax attentionの置換として利用する。

### 因果デコードでの再帰状態
因果attentionでは、時刻tまでの履歴を `S_t = S_{t-1} + φ(k_t)⊗v_t` と `z_t = z_{t-1} + φ(k_t)` の2状態で更新する。出力は `φ(q_t)^T S_t / (φ(q_t)·z_t)` から得られる。新tokenが来るたびに現在のkey/value分だけ状態を更新するので、過去key/valueを再走査する必要がない。

この構造がデコード高速化へ直接つながる。標準attentionでは履歴長Mに比例するkey/value読み出しが必要だが、RFAの状態サイズは系列長ではなく特徴次元Dとhead次元dで決まる。一方、Dが大きすぎると特徴写像と `S_t` 更新の固定費が増え、短系列では標準attentionより有利にならない。

### 学習可能なrecency bias
RFA-Gateは、再帰状態へ学習可能なスカラーゲートを導入する。入力表現から `g_t=sigmoid(w_g·x_t+b_g)` を計算し、過去状態を `g_t` 倍、新しいkey/value寄与を `1-g_t` 倍して更新する。これにより古い履歴を指数的に減衰させ、最近の情報を優先する帰納バイアスを学習できる。

この機構はRFAがRNNに似た明示的状態を持つため自然に導入できる。追加パラメータはモデル全体の0.1%未満で、言語モデリングではゲート付きRFAが特に有効だった。

### 特徴写像と温度
論文はquery/keyを正規化し、softmax温度に対応する分散パラメータをデータから学習する。ランダムベクトル自体は固定しつつ、そのスケールを再パラメータ化して学習することで、単純な固定Gaussian近似より実用精度を高める。Gaussian特徴だけでなくarc-cosine特徴も検証し、両者が近い性能を示す。

## 評価

### 評価条件
評価は言語モデリング、機械翻訳、長文分類の3系統で行う。比較対象にはvanilla Transformerと当時の線形・疎attention系手法を含む。品質だけでなく、自己回帰デコード速度、系列長を伸ばしたときの実行時間、メモリ使用量を測定し、漸近計算量が実性能へ反映される条件を調べている。

### 品質とデコード速度
言語モデリングではRFAはTransformer基準と同等水準を保ち、WikiText-103ではゲート付きRFAが基準を上回る。機械翻訳でも品質を落とさず、head-to-head比較でデコードを約1.9倍（要旨では約2倍）高速化した。これは因果デコードで履歴keyを毎step再走査しないという機構と対応する。

長文分類3データセットでは、当時の効率的Transformer群と品質・効率の双方で競争力を示す。特に系列長が長くなるほど固定次元集約の利点が大きくなり、4,000 tokenの文脈では5.3倍の速度向上を観測した。

### 系列長に対する感度
論文の解析で重要なのは、RFAが常に高速ではない点である。512 token程度で入力全体を並列処理できる言語モデリング条件では、RFAは実質的な速度向上を示さない。ランダム特徴の生成と集約という追加仕事が、softmax attention削減分を相殺するためである。

一方、自己回帰出力を2,048 tokenまで伸ばした解析ではデコードが12倍高速になり、メモリ使用量はsoftmax attentionの10%未満となる。cross attentionの状態量は概ね `O(4D+2Dd)` で、softmax側の `O(Md)` と比べ、`2D << M` となる長系列ほど有利になる。著者らはDをhead次元dまたは2dで評価し、それ以上増やす利得は小さいとしている。

## 既存研究との差
疎attentionは接続するtoken対を選別して計算量を下げるのに対し、RFAは全履歴をランダム特徴空間の十分統計へ集約する。Linformerのような系列方向の学習射影とも異なり、softmaxをカーネルとして近似することが出発点である。

同時期の線形attentionは `ELU(x)+1` のような特徴写像を使うが、論文の統制比較ではその方式がTransformerとRFAの双方を下回り、特徴写像の選択が品質に重要であることを示す。Performerもランダム特徴でsoftmaxを近似する近接研究だが、RFAはquery/key正規化、学習可能な分散、cross/causal attention、recency gateを含め、sequence-to-sequenceを含む複数attention形態で置換可能性を検証している。

## 限界
ランダム特徴は近似なので、Dを小さくすると分散と近似誤差が増える。Dを増やせば品質は安定しやすいが、特徴写像・状態更新・メモリの固定費も増えるため、線形計算量だから無条件に高速というわけではない。論文自身が512 token条件で速度利得がないことを示しており、短〜中系列や高度に最適化されたsoftmax kernelでは損益分岐点がさらに長くなる可能性がある。

また評価は2021年時点のTransformer規模と実装環境であり、現代の大規模decoder-only LLM、FlashAttention系kernel、GQA/MQA、ページ化KV cache、連続バッチングとの直接比較はない。RFAは過去tokenを個別KVとして保持せず集約状態へ圧縮するため、厳密softmax attentionとは異なるモデルであり、既存LLMへ学習なしで適用するKV圧縮手法とも性質が異なる。
