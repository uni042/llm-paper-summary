# Parallax：学習可能な局所線形注意とGPU復号カーネルの共同設計

## 概要

Parallaxは、通常のSoftmax注意の「入力クエリに近いキーへ重みを置いて値を平均する」という計算に、**キーと値の局所的な相互共分散を使った補正**を加える注意機構である。元になった局所線形注意（Local Linear Attention; LLA）は、クエリごとに線形回帰を解くため、各トークンで共役勾配法（Conjugate Gradient; CG）による反復的な求解が必要だった。これは高速な行列積に適したGPUでも、何度もKV系列へアクセスするため大規模言語モデルの事前学習へ持ち込みにくい。Parallaxでは求解結果に相当する探査ベクトルを学習可能な追加射影から直接得ることで、反復ソルバーを不要にする。

推論の実装面では、Softmax注意の計算と共分散補正の計算を同じキー・値（KV）タイル上で進める。高帯域メモリ（High Bandwidth Memory; HBM）からKVを再読込せずに計算を追加するため、メモリ転送が律速となる復号条件では追加演算をGPUの余剰演算能力に載せられる。H200でのBF16復号カーネルの測定では、比較対象のFlashAttention 2/3の速い方に対し、測定したバッチ・文脈長の範囲で同等以上と著者らは報告する。これは**注意カーネル単体の比較**であり、学習時間、モデル全体のトークン生成速度、サービスの応答時間をそのまま意味しない。

学習では、Muon最適化器を使った0.6BモデルのLAMBADA困惑度がTransformerの22.15から18.56へ、九つの下流正答率指標の平均が54.54から55.99へ改善した。1.7BではWikiText困惑度18.11から17.08、同じ下流平均は61.43から62.45となった。一方、AdamWでは同等の利点が現れず、Parallaxが単に射影を増やしただけでは有効にならないことを、補正枝の大きさ・向き・重みの安定ランクから説明する。一次資料はarXiv v1の本文、表1〜4、図2〜7、付録である。

## 問題設定：注意を線形回帰として見ると何が不足するか

Softmax注意はクエリ $q_i$ と過去のキー $k_j$ の内積から正の重み $p_{ij}$ を作り、値 $v_j$ の加重平均を返す。統計的には、クエリ近傍の値を一定値で近似する局所定数回帰（Nadaraya–Watson推定）に相当する。キーと値の関係が近傍で傾いていると、境界付近の観測が片側に偏り、単純平均では系統的なずれが生じる。LLAは局所的な一次傾きを許すことでこの境界偏りを補正する。原著が引用する理論的な積分二乗誤差の優位性は、入力領域の滑らかさや境界勾配等の仮定の下で成立するもので、任意の実世界データに対する無条件の優位性ではない。

しかしLLAの補正方向は、各クエリに対してキーの重み付き二次モーメントと一次モーメントを用いて線形方程式を解かなければならない。正則化を強くすると解は安定する一方で補正がゼロに近づきSoftmaxへ戻る。弱くすると表現力を得られる反面、条件数が悪化して数値的に不安定になりやすい。さらにCG反復のたびにKV系列を走査する必要があり、低精度演算と高帯域メモリ転送を前提にしたGPU推論では実装負担が大きい。Parallaxの狙いは、局所線形の補正能力を残しつつ、**各クエリの反復求解と追加KV読み込み**を取り除くことである。

ここで「線形注意（Linear Attention）」との違いに注意したい。一般的な線形注意は、キーと値の積を再帰状態へ蓄積して系列長に対して軽い計算を目指す。一方、ParallaxはSoftmaxの重みを維持したうえで局所線形補正を付加するため、全系列に対するSoftmax型のKV参照を原則として残す。したがって、提案だけで文脈長に対する計算量が線形化した、あるいはKVキャッシュが定数容量になったと解釈してはならない。利点は、同じKV読み出しでより表現力のある計算を実行できる点にある。

## 手法

### 1. 局所線形解の代わりに学習可能な探査ベクトルを作る

原著の式7では、LLA出力を通常のSoftmax注意出力 $o_i^{SA}$ と、キー・値の重み付き相互共分散 $\Sigma_{KV}^{(i)}$ による補正との和差に書き換える。相互共分散は、各トークンのキーが局所平均からどちらへ動いたとき、値がどちらへ動くかを示す行列である。厳密なLLAでは補正方向 $\rho_i^*$ を $\Sigma_i^{-1}\mu_i$ として求める。これが各クエリにCG求解を要求する部分である。

Parallaxは層入力 $x_i$ から追加の学習可能行列 $W_R$ を通して $\rho_i=W_Rx_i$ を作る。これは通常のクエリ射影 $W_Q$ と並列の、**共分散をどの方向から読むかを決める探査射影**である。出力は原著式8の

$$o_i^{PLX}=o_i^{SA}-\Sigma_{KV}^{(i)}\rho_i$$

となる。Softmaxによる加重平均は残し、探査方向に沿って共変動する値の成分を差し引く。追加の $W_R$ は学習時に獲得されるため、推論時に各クエリの線形方程式を解かない。モデル構造上の追加パラメータ・追加演算はあるが、反復求解のI/O費用は回避する。

### 2. 補正の正規化を変え、発散条件を取り除く

厳密LLAには、クエリが局所的なキー分布の境界に近いとき補正を増幅する係数 $1+\eta_i$ が現れる。LLAの最適解なら $\eta_i\ge0$ という幾何学的解釈を持つ。しかし $\rho_i$ を学習射影に置換すると、その制約は保証されない。元の分母に現れる $1-\bar t_i$ がゼロに近づけば補正が発散し、1を越えれば符号が反転する。著者らはこの不安定さを避けるため $\eta_i=0$ とし、探査スコア $t_{ij}$ をSoftmax重み付き平均 $\bar t_i$ で中心化する。

このとき各値の係数は $s_{ij}=p_{ij}(1-t_{ij}+\bar t_i)$ となり、係数の総和は1のまま維持される。ただし通常のSoftmaxと違い、個々の $s_{ij}$ は負値や1を超える大きさを取り得る。これは不要な値成分を「重みを小さくする」だけでなく差し引ける表現力の源であるが、重みが確率分布ではなくなる点を明示する必要がある。原著図7では深層のMuon条件で重みが概ね±40に及ぶ例が示され、数値安定性と最適化器依存性を評価する理由にもなっている。

### 3. 一回のKV走査で二つの集約枝を融合する

原著式14・アルゴリズム1は、共分散を明示的に巨大な行列として作らず、二組のスコアと出力和で計算する方法を示す。クエリタイル $Q_r$ とキータイル $K_c$ の積から通常のSoftmaxスコア $S_1$ を計算し、オンライン最大値を使って安定な重み $P_1$ を更新する。並行して探査タイル $R_r$ と同じ $K_c$ の積 $S_2$ を求め、要素積 $P_2=P_1\odot S_2$ を作る。出力の累積和は $O_1\leftarrow O_1+P_1V_c$ と $O_2\leftarrow O_2+P_2V_c$ の二本である。実際にはタイル間の最大値更新に合わせた再スケーリングと二つの正規化和 $d_1,d_2$ を維持し、最後に $O_1/d_1\,(1+d_2/d_1)-O_2/d_1$ を計算する。

重要なのは、二つの枝が**同じ $K_c,V_c$ を再利用**し、追加のHBMからのKV転送を必要としない点である。FlashAttention型のオンラインSoftmax状態を共有し、追加の状態は主として $d_2,O_2$ となる。理論的な算術強度（Arithmetic Intensity; 演算回数をHBM転送バイト数で割った値）は、KV走査が支配的な条件でFlashAttentionのおよそ2倍になる。これは演算が半分になるという意味ではなく、転送1バイト当たりに行う計算を増やして、帯域律速を計算律速寄りへ移すという意味である。

### 4. Hopperの行列演算器の未使用行を使う復号カーネル

通常の一トークン復号ではクエリ行が1行しかないが、HopperのWGMMA行列積命令は最低64行のタイルを扱う。著者らのCuTeDSL実装は、標準注意の $QK$ 計算で使われずに余る行を $RK$ 計算に活用し、二組の $PV$ 積も同様に処理する。さらにKV方向の永続分割とカーネル内部の集約を組み合わせ、別カーネルへの書き戻しを抑える。

この最適化はHopperの命令粒度と、復号時のクエリが少ないことに依存する。クエリが多い事前充填、異なる行列命令を持つGPU、ヘッド次元やバッチの異なる構成へそのまま性能を外挿することはできない。また、追加の探査射影 $W_R$ と補正の算術費用自体が消えるわけではない。KV帯域が律速でなくなるほど高バッチになると、追加演算を隠蔽できる余地は縮小する可能性がある。

### 5. 最適化器が共分散補正の有効性を左右する

Parallaxの出力は、Softmaxの平均成分と、共分散による補正成分を足し合わせる構造である。補正が有効になるには、探査ベクトル $\rho$ の大きさが十分であり、かつキー・値の相関方向と整合していなければならない。著者らは補正対出力比（Correction-to-Output Ratio; COR）、共分散と探査方向の整合度（Covariance-Probe Alignment; CPA）、重み行列の安定ランクを測定した。Muon学習では深い層のCORが8を超えるのに対し、AdamWでは4未満にとどまる。これは単なる係数スケールの差だけではなく、探査方向の有効次元にも差があることを示す。

さらに学習可能なシグモイドゲートで補正を抑制できるようにすると、Muonはゲートを開いて補正を利用するが、AdamWではゲートが約0.26に収束し、Transformerと同程度の損失になる。表4では $W_R$ の安定ランクがMuonで134.0、AdamWの二条件で9.3と11.1となり、探査射影の表現力が大きく変わる。したがってParallaxの性能は注意式だけでは決まらず、**最適化器が追加射影を学習できるか**という学習・アーキテクチャ共同設計の問題となる。

### 内部指標：Muonが補正を使える理由

原著図5では、補正対出力比CORが深層ほど増え、Muonでは深層で8超、AdamWでは4未満となる。さらに探査ベクトルの方向整合を示すCPAと、キー・値相関の大きさもMuon側で高い。ゲート付き実験（図6）では、AdamWが補正ゲートを約0.26まで閉じる一方、Muonはゲートを開く。表4の探査射影 $W_R$ の安定ランクはMuon134.0、AdamWのCosine条件9.3、WSD条件11.1である。これらは「最適化器が追加射影を十分な次元で学習できているか」を調べる内部証拠であり、単純に重みノルムを大きくすれば改善することの証明ではない。

## 限界・再現性・位置づけ

第一に、事前学習による品質改善の検証規模は0.6Bと1.7B、文脈長4096である。7B以上のモデル、混合専門家（Mixture of Experts; MoE）、128K級の長文脈、学習済みTransformerからの追加射影による微調整が有効かは原著が今後の課題として挙げる。$W_R=0$ でSoftmaxと一致する初期化は可能だが、既存重みへ付け足せば直ちに品質が改善することは実証されていない。

第二に、カーネル測定はH200・BF16での注意演算に限られる。CuTeDSLとHopperのWGMMAの空き行を使う設計はGPU世代・精度・ヘッド次元に依存する。長文脈でのKV容量そのものを削減する仕組みではなく、メモリ帯域が十分に使える高バッチや別アクセラレータで同じ優位性を期待できるとは限らない。カーネル速度、モデル全体の生成速度、訓練計算時間、サービングのTTFT・TPOTを混同しない。

第三に、AdamW条件では困惑度が改善しても平均下流正答率が低下する設定があり、最適化器依存性の理論的な十分条件は未解明である。Muonの高い安定ランクと補正の活性化は観測的に整合するが、あらゆるモデル・学習率日程で再現されるという因果証明ではない。著者ら自身、Muon＋WSDが最適な組合せだとは主張していない。

第四に、Softmaxの補正後の係数は負にも大きな正にもなり得る。これは表現力と引き換えに、注意重みを確率として解釈できないことを意味する。論文は深層で極端な係数値を観測しているが、長期学習の数値的安定性や他精度形式での誤差伝播は十分に検証していない。疎注意・MLA等への構造的な適用可能性も述べるが、それらとの統合カーネルの実測は将来課題である。

**サーベイ上の位置づけ**は「局所回帰に由来する注意機構の表現力向上」と「メモリ転送再利用による復号カーネルの効率化」の接点である。線形注意やKV圧縮と異なり、Softmax系列走査を残して追加演算を同じI/Oに融合する設計であり、推論のシステム研究としてはGPU演算器の未使用能力を利用する一例となる。ただし、モデル全体の低遅延サービングを実証した研究と同列の速度倍率で比較すべきではない。
