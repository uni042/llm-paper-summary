# CacheWeave: Learning to Recompute for Efficient Position-Independent KV Caching

> 位置を問わない区画キャッシュの再利用へ適応したモデル自身で学習した選択器が、注意得点を使わずに再計算すべき区画を選ぶことで、予算百分の五で規則型二方式を全組で上回り完全な入力処理への相対低下を最大百分の八・三に抑え、初回トークン時間を最大十六・一倍、有効スループットを最大七・八倍にしたと報告した。

## 概要

検索で集めた文書を長い入力として渡す利用では、同じ文書の区画が別の要求で別の位置に現れる。前方一致でしか再利用できない通常の接頭辞キャッシュでは、この共有を取りこぼす。位置に依存しないキャッシュ（文書の区画ごとに鍵と値のキャッシュを独立に作り、どの位置へ組み立ててもよいとする再利用方式）はこの共有を拾うが、代償として区画をまたぐ注意の相互作用が消える。区画内のトークンは他の区画を見ずに符号化されるため、複数の区画を突き合わせて答える推論では精度が落ちる。

この落下への対策は二系統ある。モデルを再利用形式へ学習で適応させる系統と、推論時に一部のトークンだけを前文脈つきで再計算して相互作用を部分的に戻す系統である。本文の動機付けの測定では、どちらの系統も単独では完全な入力処理へ届かず、両者を単純に重ねると改善しないどころか精度が下がる組も出る。ところが、完全な入力処理の情報を前提にした理想的な選択器で再計算対象を選ぶと、同じ予算でも回復量が大きく伸びる。つまり不足しているのは再計算そのものではなく、どのトークンを戻すかの選択であり、しかもその選択は安くなければならない。注意得点を取り出す選択は、融合した注意カーネルが得点を返さないため割高で、再利用で得た高速化を大きく食うことが測定で示される。

本論文は、適応済みのモデル自身で学習した選択器でこの選択を行う。区画側は隠れ状態を低次元へ射影して区画ごとに平均したキーを蓄え、質問側は隠れ状態から読み手の頭部を作り、両者の照合で区画を採点する。選択の単位は鍵値区画へ整列した区画であり、再計算の断片化と共有時の複製を抑える。代表結果として、再計算予算百分の五で規則型の二方式を全十二組で上回り、完全な入力処理に対する相対低下は最大百分の八・三、文脈長二万四千での単一要求の初回トークン時間は完全な入力処理の最大十六・一倍速、有効スループットは最良の比較対象の最大七・八倍となった。

## 問題設定

通常の因果的な入力処理では、各トークンは自分より前の全トークンへ注意できる。位置に依存しない再利用では、区画内のトークンは同じ区画内だけを見て符号化され、質問だけが全体を見る。失われるのは区画同士の相互作用であり、単一区画で完結する課題では無害でも、複数の区画の証拠を組み合わせる課題では答えの根拠が欠ける。回転位置埋め込みについては、蓄えたキーを組み立て位置へ回転させることで位置合わせ自体はできるため、問題は位置ではなく相互作用の欠落に絞られる。

部分再計算は、選んだトークンだけを前文脈つきで計算し直し、その鍵と値を差し替えることで相互作用を部分的に戻す。予算は再計算する割合で制限される。ここで選択の規則が固定だと、適応済みモデルの内部表現とずれる。本文の測定では、学習なしモデル向けに設計された偏差の大きいトークンを選ぶ方式は、適応済みモデルへ重ねると複数区画の推論でほぼ効かず、質問の注意で選ぶ方式も検索課題以外では適応済みの水準を下回る組がある。理想的な選択器との差は、選択の質にまだ大きな伸びしろがあることを示す。

もう一つの問題は費用である。再計算の選択に質問と全トークンの注意得点が要る方式では、融合カーネルが返さない得点を別途計算するため、文脈長一万六千の測定で選択だけで四十三ミリ秒が加わり、再利用による高速化倍率は十四倍から三・一倍へ落ちる。粒度も効く。散らばったトークンを再計算すると処理が断片化し、共有キャッシュでは触れた区画全体の複製が必要になって増幅する。したがって要件は、選択が注意得点なしで安いこと、粒度が区画へ整列していること、選択器が適応済みモデルに合わせて学習されていることの三点になる。

## 手法のあらまし

処理は学習の二段階と、推論時の二段の入力処理からなる。学習の第一段では、基盤モデルが完全な入力処理で作った応答を目標に、再利用形式の注意の覆いのもとで基盤全体を自己蒸留し、区画の符号化と読み取りの両方を再利用形式へ適応させる。第二段では適応済みモデルを凍結し、そのモデルについて計算した理想的な選択器の出力を教師に、選択器だけを学ばせる。推論時は、まず質問だけを再利用キャッシュ上で処理して区画の得点を出し、予算内で上位の区画を選び、選ばれた区画のトークンと質問を前文脈つきで再計算してキャッシュを差し替えてから生成を始める。区画のキーは蓄えと一緒に保存され、選択と再計算は図形処理装置上で連続して行われるため、装置と主機の往復は挟まらない。

## 手法

### 1. モデル固有の選択器 — 蓄えた区画キーと質問の読み手で採点する

この機構が観測するのは、質問の入力処理で得られる隠れ状態と、区画ごとに事前に用意したキーである。保持する状態は、区画の隠れ状態を百二十八次元へ射影して区画内で平均したキーであり、区画のキャッシュと一緒に保存される。追加される保存量は小さく、全区画では鍵値保存量の約百分の〇・二と報告される。動作は、質問の隠れ状態から四つの読み手の頭部とその重みを作り、各層でキーとの照合を整流して重み付きで合計し、層ごとの分布を学習した重みで混ぜて区画の得点とすることである。選ぶ単位は連続したトークンの区画で、その境界は鍵値区画と原点を共有し、一つの選択区画が最大で一つの鍵値区画にしか触れないよう粒度を割り切れる値に取る。この機構が減らすボトルネックは選択の費用である。注意得点も完全な入力処理も要らず、採点は区画数の規模で済むため、質問とトークンの全対照合に比べて演算量が数百倍小さいと本文は見積もる。追加で消費する資源は選択器の重みであり、モデルの百分の一・五以下である。失敗時の挙動として、得点の低い区画に本当は必要な証拠があれば再計算から漏れて精度が戻らない。粗い粒度では、必要な一部を含む区画全体を再計算するため予算の使い方は荒くなるが、漏れは減るという交換がある。

### 2. 二段階の学習 — 適応と選択を分けて学ぶ

第二の機構は学習の進め方である。第一段が観測するのは基盤モデル自身が完全な入力処理で生成した応答であり、動作は再利用形式の覆いのもとでその応答を予測するよう基盤全体を微調整することである。読み手だけ、あるいは書き手だけを適応させる変形との除去比較では、全体の適応が大きく上回り、符号化と読み取りの双方が再利用形式に合わせて変わる必要があることが示される。第二段が観測するのは、適応済みモデルについて計算した二つの理想的な選択器である。一つは完全な入力処理での質問の注意を使うもので検索系に向き、もう一つは各トークンの鍵値を完全版へ差し替えたときの答えの尤度への影響を勾配と差分の内積で近似し、貪欲に複数回更新するもので複数区画の推論に向く。動作は、この理想分布と選択器の分布の乖離を、全体と上位付近へ絞ったものの二本立てで学ぶことであり、予算は学習時に範囲内で無作為に振るため、一つの選択器が複数の予算に対応する。この機構が減らすボトルネックは、選択の教師が無いことである。理想的な選択器は推論時には使えないが、学習時の教師としては使える。追加の費用は理想信号の計算を含む学習全体であり、推論時には残らない。失敗時の挙動として、教師の選択は開発用の課題で決めるため、課題の系統が変わればどちらの理想信号が合うかも変わり得る。

### 3. 提供基盤 — 私有と共有のキャッシュの上で選択と再計算を回す

第三の機構は実行側である。観測するのは要求が持つ区画の識別子と内容の要約値であり、保持する状態は二層の蓄えで、主機側に不変の区画キャッシュと選択キー、装置側に実行中の要求の実体を置く。動作は二段の入力処理で、第一段で質問を処理して得点を出し、第二段で選ばれた区画と質問をまとめて再計算する。共有方式では、他の要求が読んでいる区画は複製してから書き換える書き換え時複製を行い、私有方式では各要求が自分の複製をその場で書き換える。共有の節約は、触れる区画の割合で決まる。トークン単位の選択では触れる区画が全体の六割から九割に達して節約が保証できないのに対し、区画へ整列した選択では複製量の上限が選んだトークン数の二倍に抑えられ、共有率が高い条件で私有より最大で約二倍のメモリ節約が見込める計算が示される。この機構が減らすボトルネックは、再計算に伴う複製の増幅と、選択と再計算の間の往復である。追加で消費する資源は、受付時点で確保する最悪の場合の複製容量と、共有方式での位置の扱いの追加計算である。失敗時の挙動として、共有率が低い条件では共有方式が私有方式より遅くなり、本文の実装は既定を私有方式としている。混合注意のモデルでは、窓注意の鍵値を主機側に全量保持する必要があり、その保存量が接頭辞キャッシュの約十二倍になる点が議論節で明示される。

## 評価

### まず見るところ

結論は、再計算の成否は予算の大きさより選択の質で決まり、適応済みモデルに合わせて学習した選択器は、小さい予算で規則型の選択を全面的に上回る、ということである。百分の五の予算で全十二組に勝ち、百分の十以上では完全な入力処理の平均へほぼ届く。速度面では、選択を安くしたことで再利用の高速化が保たれ、粗い粒度でも精度がほぼ落ちないため、断片化の少ない実行を選べる。評価の強さは、動機付けの測定から理想的な上限、実方式、提供性能までを同じモデル群でつないだ点にある。弱さは、対象が四つの課題と三つのモデルに限られ、判定に別の大規模モデルを使う課題が含まれる点である。

## 既存研究との差

学習なしの選択的再計算は、偏差の大きさや先頭位置や質問の注意といった固定の規則で対象を選び、モデルは変えない。学習で適応させる系統は再計算を持たず、適応だけでは残る差を推論時に埋める手段がない。両者の単純な重ね合わせは、選択の規則が適応後の表現に合っていないため効かないか逆効果になることが本文の測定で示される。本論文は、選択器自体を適応済みモデルの一部として学習し、教師に推論時には使えない理想的な選択器を使う点、選択の採点に注意得点ではなく蓄えた低次元のキーと質問の隠れ状態を使う点、選択粒度を提供側の区画と複製の都合へ合わせて設計する点で異なる。

## 限界・実装状況

- モデルごとに自己蒸留と選択器の学習が必要であり、新しいモデルへの導入費用は小さくない。学習なしで使える方式ではない。
- 窓注意を持つモデルでは、その鍵値を全量保持する保存量が接頭辞キャッシュの約十二倍になり、主機側の容量を圧迫する。本文は再構成や層間共有を将来の方向として挙げるにとどまる。
- 共有方式は共有率が低いと私有方式より遅く、使い分けの判断は利用側に残る。
- 理想的な選択器のどちらを教師にするかは課題の系統に依存し、開発用データでの選択を前提とする。
- 公式のコード公開先は本文中に示されていない。提供基盤は既存の提供基盤の上に構築した研究実装である。

## 一般的な実装上の含意

再利用の近似で失われる情報を推論時に戻す設計では、戻す量より戻す場所の選択が支配的であり、その選択器は近似へ適応したモデル自身の表現に合わせて学ぶべきである。また、融合カーネルが内部量を返さない実行環境では、注意得点のような内部量へ依存する制御は割高になるため、隠れ状態のような露出している信号で制御を代替する設計が要る。選択の粒度は精度だけでなく、断片化と複製の増幅を通じて速度とメモリを決めるため、提供側の区画単位と最初から揃える価値がある。
