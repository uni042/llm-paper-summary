# Kaczmarz Linear Attention：鍵ノルムに基づく残差書込みで線形注意の記憶を安定化する

## 概要

Kaczmarz Linear Attention（KLA）は、線形時間の再帰型注意で、過去の情報を有限サイズの状態行列に書き込む際の更新量を、オンライン回帰の最小化から導く研究である。従来のゲート付き差分ネットワーク（Gated DeltaNet、GDN）は、現在の鍵に対応する値を状態から読み出し、その予測と正しい値との差だけを状態へ書き戻す。書込みの強さは学習されたスカラー係数で調整するが、鍵の大きさに応じた最適な補正量を必ずしも表さない。KLAはこの係数を鍵の二乗ノルムで正規化する。

原著の式(3)は、残差書込み係数を `β_t = η_t / (||k_t||_2^2 + ε)` と定義する。ここで `η_t` は入力から得る学習済みの緩和ゲート、`k_t` は当該トークンの鍵、`ε` はゼロ割りや極小ノルムでの不安定性を避ける定数である。更新の方向、再帰状態の形、忘却ゲート、チャンクごとの並列計算方式はGDNから変えない。**新しい注意行列や追加の長文脈キャッシュを作る方式ではなく、状態へ情報を書き込む係数を変更する方式**である。

0.4BパラメータのモデルをSlimPajamaの10億トークンで学習する比較では、KLAの検証困惑度（PPL）は8.09で、GDNの8.50、DeltaNetの8.26、GLAの8.42を下回った。32K文脈の単一バッチ復号の原著実測では3.54トークン/秒で、GDNの1.65トークン/秒に対し2.1倍だった。ただし、この速度値は原著の特定の測定系であり、一般的なGPU推論サーバの総スループットや別規模のモデルへの保証ではない。

## 問題設定：有限状態へ新しい鍵値関係をどう上書きするか

標準的な自己注意は、長さTの入力の各位置から過去位置を参照するため、単純な実装では注意計算がTの二乗に比例して増える。線形注意や状態空間モデルは、過去の情報を固定次元の状態へ畳み込み、各トークンで状態を更新することで系列長に対する計算量を抑える。ただし、過去の全鍵値を保持しないので、限られた状態のどこへ新しい対応を書き、既存の対応をどれだけ消すかが性能を左右する。

単純な線形注意は鍵と値の外積を加算する。似た鍵が何度も現れると、以前の対応を修正するより同じ方向へ書込みが累積しやすい。差分規則（delta rule）はこの問題に対し、状態が鍵から予測した値と新しい目標値の差、すなわち残差だけを書き込む。GDNはさらに状態を減衰させ、書込み係数を学習することで忘却と修正を調整する。

しかし、同じ係数で二乗ノルムの大きい鍵と小さい鍵を更新すると、前者は過度に補正され、後者は補正不足になり得る。これは鍵の方向だけでなく、鍵の大きさによって状態からの読み出しが変わるためである。KLAは、現在の鍵値対応を一つの線形制約として扱い、その制約を満たす状態のうち、更新前の状態に最も近いものを選ぶカルツマルツ射影（Kaczmarz projection）から更新量を導く。

## 手法：一つのトークンの入力から更新状態まで

### 1. 忘却状態と予測残差

入力は直前の状態 `S_{t-1}`、現在の鍵 `k_t`、値 `v_t`、問い合わせ `q_t`、忘却ゲート `α_t`、緩和ゲート `η_t` である。まず `\tilde S_{t-1}=α_t S_{t-1}` として過去の状態を減衰させる。続いて `e_t=v_t-\tilde S_{t-1}^T k_t` を求める。この残差は、現在の鍵で状態を読み出した結果が目標値からどれだけずれているかを表す。

従来のGDNはこの残差を鍵方向へ `η_t k_t e_t^T` だけ書き戻す。残差がゼロなら更新不要という点は合理的だが、鍵のノルムが大きいと、同じ残差を解消するのに必要な状態の変化量は小さくてよい。逆に小さい鍵では大きい補正が必要になる。学習ゲートだけではこのスケール調整が明示されない。

### 2. 最小距離射影による係数の導出

論文の式(1)は、制約 `S^T k_t=v_t` を満たす状態の中で、減衰後の状態からのフロベニウスノルム距離 `||S-\tilde S_{t-1}||_F^2/2` を最小にする問題を定義する。状態変更を `k_t c^T` の形に限定して制約へ代入すると、`c=e_t/||k_t||_2^2` が得られる。したがって厳密な射影は `S_t=\tilde S_{t-1}+k_t e_t^T/||k_t||_2^2` となる。

実装では `β_t=η_t/(||k_t||_2^2+ε)` とし、`S_t=\tilde S_{t-1}+β_t k_t e_t^T` を計算する。`η_t=1` かつ `ε=0` の場合だけ厳密な射影に一致する。実際には学習済みゲートが書込みの強さを緩和し、`ε` が数値安定性を担うため、毎トークンの制約を常に厳密に満たすわけではない。論文はこの緩和更新が正則化付き局所回帰の厳密解としても表せることを示す。

### 3. なぜ残差が増幅されにくいか

原著の命題2は、書込み後の残差が `e_t^+=[1-η_t ||k_t||_2^2/(||k_t||_2^2+ε)]e_t` になることを示す。`0<η_t≤1` であれば括弧内の係数は0以上1以下となり、少なくとも当該トークンの残差は増幅されない。これは状態全体の長期的な最適性を保証する定理ではないが、局所的な更新が鍵ノルムにより過大になるのを防ぐ根拠になる。

ここで重要なのは、従来のGDNが学習したスカラー `η_t` を捨てるわけではない点である。入力に応じた忘却と書込みの調整は維持しつつ、その値を鍵エネルギーで割る。係数の設計に数学的根拠を与える一方、どの情報を残すべきかという有限状態の容量制約そのものは解消しない。

### 4. 出力と次トークンへの接続

更新後の状態からは、問い合わせを正規化した `q_t/||q_t||_2` を使い、`o_t=S_t^T q_t/||q_t||_2` を出力する。出力は後続層へ渡され、状態 `S_t` は次トークンの入力になる。通常のKVキャッシュのように全過去トークンの鍵・値を追記するのではなく、同じ形状の状態行列を繰り返し更新する。文脈が長くなっても状態の要素数が増えないのが再帰型注意の利点である。

### 5. チャンク並列の計算経路を変えない

学習や入力処理では、トークンを逐次更新するだけではGPUの行列演算器を十分使えない。GDNはチャンク内の依存を下三角行列の連立方程式へまとめ、行列積と前進代入で並列化する。KLAはチャンクの各トークンについて `β_i` を計算し、対角行列 `B=Diag(β_1,…,β_C)` に格納するだけで、GDNと同じ連立方程式 ` [I+B(A^-⊙KK^T)]U=B(V-D_γKS_0)` を解く。

この方程式の左辺は対角が1の下三角行列であり、既存のチャンク解法を再利用できる。得られた補助行列Uからチャンク内の各出力とチャンク末尾の状態を復元する。追加されるのは鍵ノルム計算と係数の置換であり、新しい系列長依存の状態表現や別種の注意カーネルは必要ない。ただし、係数計算自体の費用が完全にゼロという意味ではなく、実測で入力処理時間が同程度かを確認する必要がある。

## 評価：構成要素除去と負の結果

原著表5は、正規化を外すとMQARの学習長での正答率が0.03%、8倍長で0.01%となり、書込みがほぼ機能しないことを示す。鍵ノルムだけで割る方式は8倍長MQARでは77.68%とKLAの73.84%より良いが、1億トークン事前学習後のPPLが3,809.71と極めて悪くなる。学習済みスカラーだけの方式はPPL 22,968.87となり、実際の言語モデルとしては不安定だった。**合成課題の一指標が良くても学習安定性が良いとは限らない**という重要な負の結果である。

忘却と書込みを一つのゲートへまとめる構成はMQARの8倍長で0.03%まで悪化する。二つのゲートを残すGDN参照方式は同条件で66.81%となる。値状態の拡張率を2、4、8、16へ変えると、合成課題の長期記憶は改善する場合があるが、事前学習PPLは単調には改善しない。例えば拡張率8ではMQARの8倍長正答率95.37%に対し、1億トークン学習後PPLは6,945.63である。状態容量を増やすだけでは正しい書込み係数の代わりにならない。

これらの除去実験のPPLは本評価の10億トークン学習ではなく、別の1億トークンの短い学習で測定した値である。したがってPPL 753.65（KLA既定）を表1の8.09と直接比較してはいけない。除去実験の目的は、各設計が同じ短い学習条件で安定に収束するかを調べることである。

## 既存研究との差と適用限界

通常の線形注意やゲート付き線形注意は、状態の加算・減衰の設計が中心であり、既存の鍵値対応の残差を解消する書込み方向は明示しない。DeltaNetは残差に基づく修正を導入し、GDNは忘却と更新のゲートを学習する。KLAはこのGDNの状態とゲートを保ったまま、鍵ノルムで正規化した係数を局所射影から導く。KDAのようにゲートをより細粒度にする方式とは、変更対象が異なる。したがってGDNに対する比較では、モデル構造や状態容量を増やした効果ではなく、更新係数の効果を比較しやすい。

第一の限界は有限状態の容量である。長文脈でも状態サイズは一定なので、異なる鍵値対応が同じ状態方向を取り合うと完全に記憶できない。第二に、射影の厳密性は `η_t=1`、`ε=0` に限定され、実際の緩和更新では局所残差を減らす性質と長期の記憶品質を区別する必要がある。第三に、鍵ノルムが非常に小さいと分母の `ε` の設定に敏感になる可能性があり、低精度計算では特に検証が必要である。

第四に、回文反転の最長設定ではGDNの80.74%がKLAの79.96%を上回る。長い順序情報を逆順で再生するような課題には、局所射影以外の機構が必要かもしれない。第五に、評価規模は0.4B・10億トークン学習が中心であり、7B以上の大規模モデル、複数乱数種の学習再現性、複数GPUサービング、長期運用中の状態変化は未実証である。

第六に、コードの公開については原著が匿名化された実装URLを示しているが、最新の実装状態や一般GPUへの移植状況を別途確認していない。KLAはGDNカーネルの対角係数を変えるだけで済む設計だが、既存のvLLM、SGLang、llama.cppへそのまま適用できるという意味ではない。対象モデルの再帰層の実装、学習済み係数、ゲート、チェックポイントが一致する必要がある。別のアーキテクチャに対し、係数だけを差し替えて同じ効果が出るとは保証されない。
