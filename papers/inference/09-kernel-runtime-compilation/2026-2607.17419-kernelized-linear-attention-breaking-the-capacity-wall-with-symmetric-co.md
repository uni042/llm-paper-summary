# KATA：対称錐の幾何から設計する高容量・高効率の線形注意

## 概要

ソフトマックス注意は過去の各トークンに対応するキーと値を保持し、クエリに応じて参照できる。一方、線形注意はキー・値の積を有限次元の累積状態へ畳み込むため、デコード時の状態容量を系列長に依存させずに済む。ただし、異なるキーが同じ有限状態へ書き込まれると干渉し、文字列や識別子の正確な再生に弱くなる。論文はこの「容量の壁」を単なる実装問題ではなく、特徴空間内で互いに区別可能なキー方向を何個置けるかという球面充填問題として扱う。

KATA（Kernelized Linear Attention Activations）は、注意重みの非負性を保証する対称錐の特徴写像を設計軸に置く。正の直交錐、ローレンツ錐、半正定値（半正定値）錐を比較し、とくに単位ベクトルuからランク1行列uuᵀを作る半正定値特徴に注目する。異なる二つの特徴の内積が元のキー方向の内積の二乗になるため、弱い重なりをさらに弱められる。理論では、許容干渉がWelch下限を上回る領域で、半正定値特徴の区別可能なキー数に投影次元に対する指数的下限が成立する。ただし「固定した状態サイズで無制限に記憶できる」という意味ではない。

実装では半正定値の行列特徴が大きくなる問題をブロック分割で抑え、Tritonで二次計算のflash型と厳密な線形状態型を実装した。H100上の特定カーネル前向き処理では、131Kトークンで線形状態KATA-M2がFlashAttention-2の約11倍の処理量を示す。一方、340Mパラメータの言語モデル事前学習ではソフトマックスより困惑度が悪化する。高速カーネル、合成検索能力、実際の文章生成品質を区別して評価すべき研究である。

## 問題設定

通常の因果ソフトマックス注意は各時刻tで過去の全キーに対してexp(qₜ·kᵢ)を計算し、値vᵢを重み付き合成する。系列長Tに対し事前充填の計算が概ねT²で増え、デコードのKVキャッシュもTに比例して増加する。線形注意では非負の特徴写像ψを使い、Sₜ=Σᵢ≤ₜ ψ(kᵢ)vᵢᵀ、Zₜ=Σᵢ≤ₜ ψ(kᵢ)を保持し、出力をψ(qₜ)ᵀSₜ / ψ(qₜ)ᵀZₜとする。保存量は系列長ではなく特徴幅nψと値次元dvに依存し、状態はnψ(dv+1)程度になる。

この固定状態化は、キーが似ていると一つの問い合わせへ無関係な値が混入するという問題を生む。特にUUIDのような高エントロピー文字列では、意味的に近い語を選ぶだけでは正解にならない。Gated DeltaNetなどは学習可能な忘却ゲートや上書き規則を導入して対処するが、キーの特徴写像そのものの幾何がどれほどの干渉を許すかは別問題として残る。

論文が固定する理論条件は、注意重みの非負性、入力方向の回転に対する整合性、特徴錐内部の均質性である。これらを満たす自己双対・均質錐を対称錐と呼び、Koecher–Vinbergの分類を手掛かりに普通の実数の場合の直交錐、ローレンツ錐、半正定値錐を比較する。複素・四元数・例外型の全分類を実装したわけではない。幾何上の容量保証は特定の理想化した読み出し・干渉閾値の下で成立し、学習済みモデルの汎化保証とは区別される。

## 手法

### 1. 正規化線形注意と学習不要の出力ゲート

非負特徴を用いた正規化線形注意では、時刻tの分母Dₜ=ψ(qₜ)ᵀZₜが正であるとき、出力を直前の累積状態からの読み出しと現在値vₜの凸結合として書き直せる。係数はDₜ₋₁/Dₜとcₜ/Dₜで、cₜ=ψ(qₜ)ᵀψ(kₜ)であり、両者は非負で和が1となる。これは学習パラメータを増やさないクエリ依存の**出力側**ゲートである。

ここでのゲートはGated DeltaNetのように過去の状態を乗法的に減衰させる**書込み側**ゲートとは異なる。KATAの単純な加法状態更新は可換なのでチャンクのprefix-sumで並列化できるが、同じキーへの古い値を自動的に消去することはできない。この違いが後述の上書き実験で重要になる。

### 2. 半正定値ランク1写像と球面充填容量

単位方向uに対してψ(u)=uuᵀを作ると、ψ(u)とψ(v)のFrobenius内積は(uᵀv)²となる。したがって、原空間で弱く相関する二つのキーは半正定値空間でさらに弱く干渉する。ランク1の半正定値行列は常に半正定値であり、非負の注意重みを自然に保証する。ローレンツ錐の特徴と異なり、uとvの符号付き方向がほぼ直交していれば干渉を抑えられる。

著者はT個の単位特徴の最大ペア内積を最小化する相互コヒーレンスμを定義し、干渉上限εを満たす最大のTを容量Cεとする。半正定値のランク1特徴では、キーの内積絶対値が√ε以下なら特徴干渉がε以下になる。球面キャップの充填からCε(S⁺p) ≥ 1/2·(1−ε)^−(p−1)/2という下限を得る。ただしWelch下限より厳しいε<1/pではTに線形次元依存の上限が残るため、指数的容量を主張できるのは**固定許容干渉がWelch下限を上回る領域**に限られる。

論文はさらに、相互不偏基底からの実数化辞書とDeVore多項式辞書を具体的構成として挙げる。前者は指定の素数冪次元で有限の最悪干渉保証を与え、後者は疎な辞書を作れる代わりに許容干渉と次元の交換がある。これは任意の学習済みクエリ・キー投影が自動的に理想配置へ収束するという主張ではなく、**幾何的に実現可能な容量**の解析である。

### 3. 半正定値状態を分割する二つの特徴族

完全なランク1半正定値写像はヘッド次元d=64で生の行列4096要素、対称性を利用しても2080個の独立要素を要する。さらに各特徴へ値次元dvを掛けて累積状態Sを持つため、単にキーの投影パラメータが少ないだけでは高速・省メモリにならない。著者はdをg個の長さm=d/gのブロックへ分割し、状態サイズを制御する。

KATA-Σgは各ブロックの外積を同一の半正定値行列へ加算し、特徴の行列幅を一つにまとめる。KATA-Mgはブロックごとに独立した半正定値因子を保持し、それらの直積を特徴空間とする。Σ型は圧縮を重視し、M型はブロック別の識別力を保持する。gを増やすほど一つの因子は小さくなるが、全特徴の相互作用が変わるため、容量・学習のしやすさ・計算量が同時に変わる。

KATA-M1はd=64の一つの半正定値因子を使い、KATA-M2は32次元の二因子へ分割する。合成MQARではM1の大きな状態が優位な条件がある一方、340M事前学習後のUUID再生ではM2の方が高精度となる。幾何上の理論容量だけで実際の学習可能性を判断できないことを示す具体例である。

### 4. チャンク分割・Triton融合・木構造走査

系列を長さCのチャンクに分け、チャンク内は因果マスク付きの行列積をテンソルコアで処理する。チャンク間はSとZを前チャンクから加算更新し、クエリは過去チャンクのS・Zと現在チャンクの局所注意を合わせて正規化する。局所の因果計算と大域の累積状態を分離するため、系列全長のT×T行列を常に生成する必要がない。

論文は二つの動作点を実装する。一つは行列積に適した二次計算のflash型前向き処理/backwardで、短〜中系列の学習に向く。もう一つは半正定値特徴の加法的な厳密状態更新を用いる線形計算型で、長系列の前向き処理に向く。前者の「flash」はFlashAttention-2と同一のソフトマックスを計算するという意味ではなく、半正定値カーネルに対するタイル化実装を指す。

加法更新ではチャンク間状態の合成に結合則が使える。一次特徴の連想走査（tree scan）により、逐次チャンク更新の深さO(T/C)をO(log(T/C))へ短縮する。比較対象は同じ線形注意の逐次チャンク実装であり、学習モデル全体の速度向上倍率と混同してはいけない。Delta接頭辞の方式は、同じキーへ新しい値を書き込む際に以前の読み出しを差し引く内容依存の修正を行い、Gated接頭辞は時刻ごとの乗法減衰を加える。これらは基本KATA-Mgの無ゲート加法更新とは異なる追加機構である。

## 評価

### 評価系と比較条件

評価は、(a) Zoology環境の合成連想記憶・同一キー上書き・誘導課題、(b) 340Mパラメータの言語モデル事前学習と長文検索、(c) GPU上の注意カーネルの三系統に分かれる。合成MQARでは学習系列T=256、同時キー数最大64とし、評価ではT=512〜4096、キー数128〜1024へ拡張する。4096は学習長の16倍である。学習率は3候補を探索し、各方式の最良結果を報告する。ソフトマックス、Mamba2、GLA、DeltaNet、Gated DeltaNet、RWKV7と半正定値特徴族を比較し、状態要素数とパラメータ数を併記している。

340M事前学習は24層・隠れ次元1024・16ヘッド、SlimPajama 150億トークン、学習文脈2048で実施し、トークン混合層をソフトマックス、Gated DeltaNet、KATA-M1/M2、DeltaKATA-M1などへ入れ替える。RULERの単一needle課題は単語、7桁数値、128ビットUUIDをそれぞれ1K/2K文脈へ埋め込み、各長さ500件で貪欲復号し正規化部分文字列一致で採点する。位置外挿と純粋なキー容量を混同しないため、主比較は学習文脈内の1K/2Kに限定している。

この表は原著Table 3と4からの抜粋である。KATA-M2はUUID検索でM1を上回るが、LAMBADA困惑度は51.8と最も悪い。状態が大きいM1は合成連想では優れる一方、実際の事前学習で一つの64次元球面因子をうまく学習することが難しい可能性がある。M2は二つの32次元因子へ分割して学習しやすくしたと著者は解釈するが、これは因果的に単独証明されたわけではない。

RULERのUUIDは高エントロピーで厳密一致が要求されるため、Gated DeltaNetの1K/2Kとも0.004という負の結果が鮮明になる。とはいえソフトマックスは0.956/0.930であり、KATA-M2の0.910/0.616を上回る。KATA-M1の2K UUIDは0.458まで下がり、正確な文字列検索を全条件で保証するわけではない。KATA-M2のRMS正規化を外すと2K UUIDは0.616から0.224へ落ち、位置埋込みを短い畳込みへ替えると0.530となる。特徴幾何だけでなく正規化と位置表現も結果を左右する。

文脈を解釈して回答候補を選ぶBasedのcloze課題では、KATA-M1のSWDEが0.375と固定状態方式中で高い一方、SQuADは0.041にとどまり、KATA-M2は0.240、DeltaKATA-M1は0.353である。部分文字列一致は長い生成ほど正答文字列を偶然含む可能性があり、SQuADの平均生成長はKATA-M1約11トークンに対しDeltaKATA-M1約202トークンと大きく異なる。論文自身もこの指標を純粋な検索能力とは扱わず、文脈的選択と生成文体の混合として解釈している。

### GPUカーネルと学習時間

GPUカーネルの速度測定はNVIDIA H100、bf16、バッチ8、ヘッド16、ヘッド次元64などの条件で行われる。flash型のKATA-Mgは短い系列でFlashAttention-2と競合し、前向き処理単体で最大約1.6倍の処理量を報告する。線形状態KATA-M2は16K付近で自身の二次型と同等となり、32K以降で優位、131KでFlashAttention-2の前向き処理比約11倍になる。これは**注意カーネル単体**の前向き処理処理量であり、340Mモデル全体のトークン生成速度ではない。Gated DeltaNetのカーネルはなお速い条件がある。

同じ加法状態の逐次チャンク実装と比較した木構造走査は、平均約2.4倍の処理量を報告する。対して340Mモデルの150億トークン学習では、ソフトマックスがH100で188千tok/s/GPU・22.2 GPU時間、flash型KATA-M1/M2が190千tok/s/GPU・21.9 GPU時間、Gated DeltaNetが144千tok/s/GPU・28.9 GPU時間、DeltaKATA-M1が77千tok/s/GPU・54.1 GPU時間となる。Deltaによる内容上書きは検索を改善するが、学習計算が安くなるわけではない。理論的な状態の利点と実装コストを切り分けて読む必要がある。

## 既存研究との差

従来のELU+1などの非負特徴は正の直交錐へ入る写像と見なせる。KATAは非負性と等方性を満たす特徴空間の設計を対称錐という共通枠で説明し、ローレンツ錐の制約と半正定値ランク1特徴の二乗干渉を同じ容量指標で比較する。これは単に学習可能なゲートを追加して性能を上げるGated DeltaNetの方向とは異なる。さらに、分割半正定値特徴をGPUで動かすための二次型・線形型のTritonカーネルを提供し、幾何的な主張がハードウェア上で実行可能かを検証した。

ただしKATAがDeltaNetやGated DeltaNetを全面的に置き換えるわけではない。実際、同一キーの上書きでは内容消去のdelta規則が有効で、位置外挿ではGated DeltaNetの乗法ゲートが強い。半正定値の特徴幾何、状態更新規則、位置表現は独立した設計軸であり、論文はそれらを組み合わせる余地を示している。

## 限界

最大の制約は、理論容量と学習後の精度が同一ではない点である。半正定値の指数的充填下限は許容干渉・幾何的仮定の下での存在保証で、実際の投影がその配置を獲得する保証ではない。半正定値特徴は投影次元に対して行列サイズが二乗で増えるため、分割をしても状態容量がGated DeltaNetの数倍から数十倍になる条件がある。MQARのM1は266,240状態要素でGDNの8,192要素を大幅に上回る。単純に「線形注意だから小容量」と呼ぶのは誤りである。

第二に、実モデルの流暢性は改善されていない。340MモデルでソフトマックスのLAMBADA困惑度38.6に対しKATA-M2は51.8、KATA-M1も43.5である。特に長いUUIDの正確な検索と、自然言語の次トークン予測の双方で最高性能を達成する構成は示されていない。RoPEを使う構成は学習長を超えると外挿が崩れるため、主RULER評価を1K/2Kに制限した。これは長文推論一般の頑健性を示す実験ではない。

第三に、最大11倍という値はH100上の注意前向き処理カーネルとFlashAttention-2との比較である。モデル全体のprefill、decode、KVメモリ転送、分散サービングのエンドツーエンド性能は同倍率では示されていない。CUDA/Tritonの実装、bf16、ヘッド形状、系列長、ハードウェアが変われば優劣も変わる。論文の340M事前学習は150億トークンであり、7B以上の大規模LLMへの直接的な品質・速度一般化は未検証である。

第四に、Based clozeの部分文字列一致は長い回答を有利に採点するため、方式間の正答率を純粋なメモリ容量の順位とみなせない。論文は高エントロピーneedleを主たる容量証拠と位置付ける。GatedKATAの340M規模の事前学習とRoPEの相互作用、複素・四元数の対称錐への拡張なども今後の課題として残る。
