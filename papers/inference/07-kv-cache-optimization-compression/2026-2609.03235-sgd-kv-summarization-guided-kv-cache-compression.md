# SGD-KV: Summarization Guided KV Cache Compression

> 長いcontextの要点を保持しやすいattention headへ多くのKV容量を配り、重要度の低いheadでは強くKVを削ることで、最大75%のKV cache削減でも品質を保つ手法。

## 書誌情報

- 公開日: 2026-09-03
- 状態: NeurIPS 2026 Efficient Reasoning Workshop Accepted
- arXiv: 2609.03235
- 著者: Zeyu Liuほか
- 主題: KV cache compression / head別budget allocation

## 概要

SGD-KVは、すべてのattention headへ同じKV容量を与えるのではなく、**長いcontextの要点を少ない情報へまとめる能力が高いheadほど多くのKVを残す**圧縮方式である。

同じKV budgetでも、headごとに必要な過去token数は異なるという前提に立つ。重要なheadを一律圧縮から保護し、冗長なhead側で多く削ることで、全体のKV memoryを減らしながらlong-context性能を維持する。

## 手法

### 1. Headごとの「長文の要点を保持する能力」を測る

長い入力を複数chunkに分け、その内容を要約する診断taskを使い、各attention headが要点を保つのにどれだけ役立つかを測る。

この結果からheadごとのscoreを作る。論文名の `Summarization Guided` は、**通常のattention量だけではなく、この要約能力をKV容量配分の手掛かりにする**ことを指す。

### 2. 総KV budgetをhead間で不均等に配る

利用できるKV cache総量は固定したまま、summarization scoreが高いheadへ多く、低いheadへ少なく割り当てる。

したがって「全headを75%削減」のような一律圧縮ではなく、**重要なheadは比較的多く残し、その分ほかのheadを強く圧縮する**。

### 3. 各headの中ではattention scoreで残すtokenを選ぶ

headごとのbudgetが決まった後、そのheadの中でどの過去tokenを残すかはattention scoreを使って決める。

つまり二段階で、

1. headごとに何token分のKVを残すか
2. その範囲でどのtokenを残すか

を決める。

追加のモデル学習は必要なく、既存modelへ後付けできる。

## 評価

Qwen2.5-7B-Instruct-1MとQwen3-32Bを用い、MRCR、ETHIC、BABILongなどで最大1M contextを評価している。

- 最大 **75%のKV cache memory削減**を報告。
- 25% budget条件でも、ETHIC平均はQwen3-32BでFullKV **28.53** に対し **28.38** とほぼ維持。

この結果は、同じ圧縮率でもheadごとの役割差を考慮した方が品質を保ちやすいことを示す。

## スコープと制約

- 主眼はhead間のKV budget allocationであり、weight offloadやMoE expert residencyは扱わない。
- CPU offload、SSD / NVMe offload、CXL memory、HBFは対象外。
- summarization診断taskで高いscoreを持つheadが、すべてのdownstream taskでも必ず重要とは限らない。
- 主な効果はKV memory削減とlong-context品質維持で、end-to-end serving throughputの改善量はhardware/runtimeにも依存する。

## 実装上の含意

KV cacheをheadごとに同じ長さへ揃える必要はない。serving engineへ実装する場合は、**head別のKV budgetを管理し、そのbudget内でtoken selectionを行えるcache manager**が必要になる。

重要度がheadごとに大きく違うmodelでは、uniform compressionより同じmemory量を有効に使える可能性がある。
