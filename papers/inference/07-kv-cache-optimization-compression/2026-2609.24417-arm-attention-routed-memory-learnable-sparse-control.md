# ARM: Attention with Routed-Memory for Learnable Sparse Control

> ARMは階層ルーターで固定容量の記憶スロットを読み書きする注意機構を学習し、Llama-3.1-8BのRULER平均を8.01から15.12へ高める一方、LongBenchでは改善が小さいことも示す。

## 概要

長い入力を処理すると、各トークンのキー・バリュー（KV）を層ごとに保持するため、KVキャッシュの量が文脈長に比例して増える。一般的な対策は、古いトークンや重要度の低いトークンを捨てる、低精度に圧縮する、あるいはGPUメモリから別の場所へ移す方法である。しかし、保存対象を削る方法では、あとから必要になる情報を失う危険が残り、退避方式では転送時間が発生する。ARMは、入力トークンごとのKVをそのまま積み上げる代わりに、固定数の記憶スロットへ情報を集約し、入力ごとに必要なスロットを読み出す注意機構を提案する。

論文の中心的な発想は、すべての過去トークンを個別に参照する必要はないが、何を残すべきかを固定の規則だけで決めるのも難しい、という点にある。そこでARMでは、記憶の容量をあらかじめ固定しつつ、記憶への書き込みと読み出しをモデルの学習対象にする。つまり、保存量は入力長に応じて増えない一方、どの情報を記録し、後段の処理で何を取り出すかはタスクに合わせて変化する。この設計により、単純な最近傍保持と比べて、長距離の依存を記憶へ残せる可能性を持たせている。

## 手法

ARMは通常の注意機構のKVキャッシュに代わり、固定サイズの階層メモリを各層で使う。入力を処理する際、現在の隠れ状態がルーターへ渡され、記憶のどの領域を更新するかを決める。ルーターは一度にすべてのスロットを書き換えるのではなく、階層的に候補を絞り込む。こうすることで、メモリ容量を固定したまま、現在の入力に関係する領域へ情報を配置することを目指す。

書き込み側では、選択されたスロットに新しい状態を加える量をシグモイド型のゲートで調整する。ゲートが小さい場合、既存の記憶を保ち、新しい入力の影響を弱める。ゲートが大きい場合は、現在の情報でスロットの内容を更新する。ルーティングの選択と更新量を分けることで、「どこへ書くか」と「どれほど上書きするか」を別々に学習できる。これは、毎回無条件に上書きする方式よりも、既に有用な情報が格納されている場合にその内容を維持しやすくする狙いがある。

階層ルーターは、まず大きな記憶群を選び、その後に群の内部から具体的なスロットを選ぶ。全スロットを同時に比較する代わりに段階的に選択するので、メモリ規模が大きくなった場合の探索を抑えられる。また、選択を学習可能にするため、論文はGumbel-Softmaxを使った微分可能な近似を導入する。通常の離散選択だけでは選ばれた経路まで学習信号を戻しにくいが、この近似によって訓練時に選択の影響を最適化できる。

読み出し側では、現在の入力状態と記憶スロットの関連度を使い、参照する候補を選ぶ。ARMの読み出し幅は固定ではなく、入力と層の状態に応じてTop-M個の記憶を選ぶ。必要な情報が少ない状況では読み出し数を小さくし、より広い履歴が必要な状況では選択数を増やす設計である。各層が同じスロット群を機械的に同じ幅で読むのではなく、層ごとの役割や入力の違いを反映できるため、計算と記憶の利用量を状況に合わせられる。

この構造は、古いKVを捨てるだけの方式と異なり、記憶スロットが過去の表現を集約し直すことを許す。一方、固定容量である以上、長い履歴をすべて損失なく保存するわけではない。保持対象を選ぶ段階で重要性の誤りがあれば、必要な詳細がスロットへ残らないことがある。ARMはこの誤差を学習で減らそうとするが、訓練で見ていないタスクや情報形式に対する保証を与えるものではない。

## 評価

論文はLlama-3.1-8Bを評価モデルとして用い、一般的な言語理解ベンチマークに加えて、長文脈で情報の検索・統合が必要なRULERとLongBenchを調べている。文脈長は最大128Kまで扱い、通常の全注意、窓幅を制限する方式、ストリーミング型の方式、KVの量子化やCPUオフロードなどと比較する。したがって、報告値は単一の短い入力での速度比較だけではなく、長文脈での精度と記憶量を含む評価として読む必要がある。

RULERの平均スコアは、比較対象の8.01からARMの15.12へ上がった。これは、固定容量の記憶に置き換えても、長文脈の特定の検索課題で情報を取り出せることを示す。ただし、この値だけからすべての長文タスクで倍近く良くなると結論づけることはできない。RULERは長距離の検索能力を測る課題群であり、実際の文章理解や指示追従の全体を代表するものではない。

LongBenchの平均は17.09から18.02へ改善したが、その差はRULERより小さい。長い文書の要約、質問応答、複数箇所の情報利用などを含む設定では、記憶を固定長に圧縮する利点と、細かな文脈を捨てる損失の両方が現れる。特定のデータセットや文脈長では比較対象がARMを上回る結果もあり、性能向上は一様ではない。したがって、ARMの代表結果は「長文脈なら常に優れる」ことではなく、固定メモリ設計が検索系課題に有効な一方、課題依存性を持つことにある。

## 限界と適用範囲

ARMは既存モデルに後付けするKV圧縮器ではなく、メモリ読み書き機構を含むモデルを学習・評価する方式である。このため、すでに運用中の任意のLLMへそのまま適用できると考えてはならない。また、報告された評価はLlama-3.1-8Bを中心としており、より大きいモデルや異なる注意機構、別の訓練データで同じ品質差が得られるかは別途検証が必要である。

固定容量化はメモリ使用量の伸びを抑える一方、記憶スロットが増えないという制約を受ける。多数の事実を同時に保持する課題、厳密な逐語引用、非常に長い入力で離れた情報を正確に結び付ける課題では、圧縮による衝突や取りこぼしが問題になる可能性がある。論文中の平均値を運用要件へ移す際は、実際に必要な文脈長とタスク分布で再評価し、平均点だけでなく課題ごとの下振れを確認すべきである。

さらに、読み出し数を入力・層ごとに適応させる構成は、固定幅の注意より柔軟だが、選択とルーティングを実装する追加演算を伴う。実際の効率を決めるには、メモリ使用量だけでなく、ルーター計算、選択演算、バッチ処理時のばらつき、GPUカーネルの実装効率まで測る必要がある。論文の精度改善だけを見て、既存の高速推論基盤上でも同じ速度上の利得が得られると推定することはできない。

## まとめ

ARMは、入力ごとのKVを無制限に保持する代わりに、階層ルーター、ゲート付き書き込み、適応型Top-M読み出しを組み合わせ、固定容量のメモリを学習する注意機構である。最大128K文脈の評価ではRULER平均が8.01から15.12へ改善し、LongBench平均も17.09から18.02へ上がった。一方で、後者の改善は小さく、課題によって比較方式が勝つ場面もある。したがって本研究の意義は、長文脈の全KVを保つ以外の設計空間を示した点にあり、実運用での適用可否は対象タスク、許容誤差、推論基盤を含めて判断する必要がある。
