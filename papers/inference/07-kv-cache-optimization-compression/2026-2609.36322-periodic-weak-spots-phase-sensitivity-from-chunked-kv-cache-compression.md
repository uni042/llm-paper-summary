# Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression

> チャンク型KV圧縮が窓境界に対する位置位相を新たに作り、同じ情報の検索精度を最大40ポイント変動させる周期的弱点を生むことを実証する。

## 概要

固定ストライドで連続トークンをまとめるチャンク型KVキャッシュ圧縮では、同じ情報でも圧縮窓境界からの相対位置（phase）が違うだけで検索精度が周期的に変わる。本論文はこのphase sensitivityを大規模open-weightモデルで測定し、位相間で長文検索精度が最大40ポイント異なる条件を報告する。複数のKV圧縮設計でTransformerを事前学習して現象を再現し、因果介入から注意成分が位相ごとに役割分化するphase specializationを示す。

この研究の焦点は、モデル品質だけを上げることではなく、実際のLLM推論で支配的になる計算・メモリ・API費用を、モデル内部またはサービング経路の選択によって減らす点にある。以下では論文固有の処理順と評価条件を分けて整理する。

## 問題設定

チャンク型KV圧縮は連続トークンを固定幅windowごとに少数の表現へまとめるため、メモリとattention計算を減らせる。しかし圧縮境界は元Transformerにはない周期構造を導入する。本論文は、情報の意味や絶対位置を変えなくてもwindow内の相対位置だけで検索性能が変わることを問題にする。

## 手法

著者らは圧縮window境界に対するトークン位置をphaseと定義し、同じneedle情報を異なるphaseへずらして長文検索精度を測る。平均スコアでは隠れる周期的な谷をphase sensitivityとして可視化する。

さらに複数のKV圧縮設計を持つTransformerをゼロから学習し、既存open-weightモデル固有の癖ではなく圧縮構造から現象が再現するかを検証する。注意成分への因果介入では、特定成分を除去・操作したときのphase別検索性能を比較し、異なるattention componentが異なるphaseの情報回収を担当するphase specializationを示す。理想化した検索モデルの解析では、勾配流がこの専門化を強め得ることを説明する。

## 評価条件・主要結果

大規模open-weightモデルを含むチャンク型KV圧縮モデルで、同一情報の検索精度がphase間で最大40 percentage points変化する。重要なのは平均長文ベンチマークが高くても、特定の周期位置に体系的な弱点が残り得ることである。scratch学習した複数設計でも現象を再現し、因果介入が単なる測定ノイズではないphase specializationを支持する。

## 既存研究との差

既存KV圧縮研究の多くは平均精度、圧縮率、メモリ削減を比較する。本研究は新しい圧縮器ではなく、固定stride圧縮が作る隠れた位置座標を独立の評価軸として提示する。

## 限界・実装状況

結果はchunk boundaryを持つ圧縮方式に直接対応する。連続的・内容依存の圧縮や非圧縮attentionで同じ周期性が出るとは限らない。対策法そのものより診断と機構分析が主貢献である。
