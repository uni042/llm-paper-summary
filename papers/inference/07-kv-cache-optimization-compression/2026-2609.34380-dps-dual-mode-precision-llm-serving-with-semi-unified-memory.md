# DPS: Dual-Mode Precision LLM Serving with Semi-Unified Memory

> KV圧力が高いときだけ入れ子型の低精度実行へ切り替え、残差の重みメモリをKVブロックへ転用することで、バースト時のプリエンプションとSLO違反を抑える二重精度サービング方式。

## 概要

サービング基盤は、KVキャッシュのメモリをページ式に仮想化し、断片化を減らして共有する工夫を重ねてきた。一方で重みのメモリは起動時に決めたきり固定である。30B級モデルを80GBのGPUで出す例では、重みがメモリの71.2パーセントを占め、KVキャッシュは15.5パーセントしかない。ところが実際の詰まりは、依頼が集中するバーストの瞬間にKVキャッシュが足りなくなり、実行中のリクエストを追い出すプリエンプションや、サービス品質目標（SLO）違反として現れる。配分の固定が、最もメモリが要る瞬間に最も融通が利かない構造を作っている。

本論文のDPSは、重みメモリを実行時に動く弾力的な資源へ変える。通常負荷では全精度（FP16）のモデルで出すフルモードで動かし、KV圧力が高まると、同じ保存物から得られる入れ子型の低精度（FP8）版で出すファストモードへ切り替え、残差の重みが使っていたメモリをKVブロックへ転用する。圧力が引けば重みを戻してフルモードへ復帰する。代表結果として、静的なFP16実行に比べて持続スループットが2.1〜3.3倍になり、Qwen3-30B-A3Bの到着率4.5毎秒の条件では実効pass@1が56.4パーセント対15.2パーセントと41.2ポイント上回った。低負荷の条件では精度も遅延も静的FP16とほぼ並んでいる。

## 問題設定

なぜ低精度版を別に持つのではなく入れ子にするかが鍵である。FP8の重みはFP16の重みから、指数部と仮数部の上位ビットを残す形で直接導出でき、逆に残差を足せばFP16へ戻せる。この性質を使うと、1つの保存物を低精度の本体と残差に分けて持てる。本体は常に必要だが、残差は「精度を上げるための追加分」であり、メモリが逼迫したときだけ手放せる部分になる。従来の量子化は精度を固定してしまうため、この手放せる部分という見方ができない。

詰まりの連鎖も具体的に押さえる必要がある。KV容量が足りないと、基盤は一部のリクエストを止めて後でやり直すか、待ち行列を伸ばす。論文の測定では、静的FP16のQwen3-30B-A3Bは到着率1.0毎秒で平均TTFTが428ミリ秒だったものが、2.0毎秒で21.0秒まで膨らんでいる。品質自体は落ちていないのに、SLOに間に合わなかったリクエストが実効指標では0点になるため、実効pass@1が崩れる。つまり解くべきは計算の速さではなく、ピーク時の容量である。

## 手法のあらまし

土台は半統一メモリ（SUM）という抽象化である。重み領域を、低精度の本体が常駐する部分と、残差の重みとKVブロックが入れ替わる共有領域に分ける。共有領域は物理単位と仮想テンソルを分けて持ち、CUDAの仮想メモリ管理で対応付けを実行時に付け替えるため、ページ式KV管理からは通常のブロックとして見える。その上でスケジューラがKV圧力を監視し、閾値を超えたらファストモードへ移って共有領域をKVへ回し、圧力が下がれば残差を背景で戻してフルモードへ復帰する。FP16からFP8への移行はデータを動かさずに済み、逆向きの復帰だけがホストからデバイスへの転送を伴うため、その転送を別のコピー用ストリームで計算と重ねて隠す。モード切替はバッチの境界に合わせて行い、実行中のリクエストをブロックしない。

## 手法

### 1. 半統一メモリ — 残差とKVブロックの共有領域

この機構が管理するのは重み領域の用途である。入力は入れ子分解された重み、つまり低精度の本体と残差であり、出力はその時々の用途に応じて残差にもKVブロックにもなる物理メモリである。物理単位は連続した物理メモリで、仮想テンソルは基盤から見える連続した仮想アドレス範囲であり、両者の対応を実行時に付け替えることで、同じ物理メモリを重みとしてもKVとしても見せられる。これで減るボトルネックは、配分を固定したことによるピーク時のKV不足であり、追加で消費するのは対応付けの管理状態と監視の費用だけである。失敗条件は、共有領域をKVへ回している間はフル精度で計算できないことで、これは次の二重精度実行が品質側の受け止めを担う。ページ式管理と互換に作ってあるため、既存のブロック割当やプリフィックス共有の仕組みはそのまま使える。

### 2. 二重精度実行 — 非対称な切替と背景復帰

実行側の機構は、フルモードとファストモードの切替である。観測するのは現在の精度状態と空き状況で、選ぶのはどちらの重み表現で次のバッチを計算するかである。切替の費用は非対称で、低精度化は残差を使わないと決めるだけなのでデータ移動がなく即時に行える。逆の復帰は残差をホスト側から戻す転送が必要で、Qwen3-30B-A3Bでは1回あたり約24.7秒、GLM-4.7-Flashでは約8.5秒の復帰遅延が測られている。ただしこの転送は専用のコピー用ストリームで進行中の低精度計算と重ねられ、利用者から見える影響は小さいとされる。効く理由は、切替が必要になるのは圧力上昇時であり、その方向は無費用で、費用のある方向は圧力が引いた後の余裕のある時間に背景で済ませられるからである。失敗条件は、圧力の上下が激しく切替が頻発する場合で、論文の窓内測定では対象モデルで切替は最大でも往復2回にとどまっているが、より細かい変動への追随は未検証である。

### 3. KV圧力感知スケジューリング

スケジューラはKVキャッシュの占有と圧力を継続的に見て、切替の判断を行う。早すぎる切替は無駄に精度を落とし、遅すぎる切替はプリエンプションを防げないため、圧力の上がり方を見てスラッシングを避ける方針を取る。論文の内部状態の追跡では、DPSのKV占有はQwenで0から0.93、GLMで0から0.54の間をバーストに合わせて動き、圧力の帯域でちょうどファストモードへ入っていることが示されている。判断の出力はモード切替と共有領域の用途変更であり、その結果として大きな有効バッチを保ち、ステップあたりの重み読みを償却できる。追加の費用は監視と制御のオーバーヘッドで、低負荷のPhi-3.5-MoEの条件では精度と遅延に測れる悪化は出ていない。

## 評価

結論は、低負荷では静的FP16とほぼ同じ、圧力が効く条件では静的FP8と並ぶ容量を持ちながら精度の支払いをその時間帯だけに限定できる、というものである。実効pass@1の差の大半は生成品質ではなくSLO到達の差であり、論文は無条件のpass@1も併記してこの点を正直に分けている。

TPOTの階層も結果の理解に欠かせない。静的FP8が13〜24ミリ秒で最も速く、DPSは再構成の費用のため22〜30ミリ秒、静的FP16は21〜35ミリ秒であり、DPSの1トークンあたりの遅延は静的FP16と大きく変わらない。対照的に、KVをホストへ退避する方式はデコードのたびに取得が走って71ミリ秒まで膨らみ、重み退避は常時60ミリ秒を超える。同じ容量対策でも、不足分をどこから持ってくるかでデコード側の代償がまったく違うことが分かる。DPSの復帰転送がデコードの主経路から外れている設計は、この対比で裏付けられている。

読み方として、静的FP8はスループットとSLO到達ではDPSに並ぶ唯一の比較対象だが、精度の費用を常時払う。DPSが静的FP8を実効pass@1で上回る分（GLMで1〜3ポイント程度）は、低負荷時にフルモードで過ごした時間の寄与であり、到着率が上がってファストモードの時間が増えるほど差は消えることが率ごとの分析で示されている。切替費用の表では、対象期間中にファストモードで過ごした割合がQwenで79.2パーセント、GLMで47.1パーセントであり、Phiは切替なしだった。評価の注意点として、実効指標はSLOの定義（プリフィル2秒など）に依存し、到着過程もガンマ分布の合成条件が中心である点は割り引いて読む必要がある。

## 既存研究との差

vLLMやSGLangの系譜はKV側の管理を進化させてきたが、重み側の配分は固定だった。本論文の差は、配分の境界そのものを実行時に動かした点にある。入れ子型の多精度表現を持つ先行研究は、2精度を持てること自体を示したが、メモリを二重に使うためサービングの容量は増えなかった。DPSはその表現を半統一メモリと結び付け、残差の置き場をKVと共有させることで初めて容量の利得に変えている。KVをCPUへ退避する方式や重みを退避する方式との差は、退避先が低速なホストメモリではなく同じGPU内の再配分であり、デコードのたびに取得が発生しない点にある。KV量子化との差は、KV側を圧縮するのではなく供給側を増やす点である。

## 限界・実装状況

- 復帰の転送量は大きく、1回あたり数秒から約25秒の背景転送を伴う。圧力の変動が速いワークロードでは切替頻度と転送の競合が増える可能性がある。
- 前提として、FP16からFP8へ直接導出でき残差で戻せる入れ子型の表現が必要で、任意の量子化済みモデルや任意の精度組合せにそのまま使えるわけではない。
- 評価はH100とMoEモデル3件が中心で、密なモデルでの詳細や他のGPU、長い文脈での条件は限定的である。
- 公式コードの公開先は論文中に示されておらず、vLLMへの上流統合済みという位置付けではない。研究実装としての評価である。

## 一般的な実装上の含意

第一に、メモリ配分は起動時の定数ではなく、負荷に応じて動かせる制御変数として設計できる。重みのように一見固定の資源でも、精度の分解によって手放せる部分と常駐部分に分けられる場合がある。第二に、精度の犠牲は常時ではなく必要な時間帯だけに局所化できる。切替費用が非対称なら、無費用の方向へは即時に倒し、費用のある復帰は背景化する設計が有効である。第三に、新しいメモリ抽象は既存のページ式管理と互換に作ることで、周辺の最適化を壊さずに入れられる。互換性は性能機構の導入条件そのものである。

## 引用関係

ページ式KV管理の土台としてvLLM（PagedAttention）を前提とし、入れ子型の多精度表現の先行研究を重み表現の基礎に置いている。比較対象としてKV退避、重み退避、KV量子化、静的な二つの精度設定を同じ条件で測っている。
