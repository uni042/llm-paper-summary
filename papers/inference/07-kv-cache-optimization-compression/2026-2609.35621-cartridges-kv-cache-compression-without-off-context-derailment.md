# Cartridges++：圧縮した長文記憶が無関係な質問を汚染する問題と二つの対策

## 概要

同じ長い文書へ繰り返し質問するサービスでは、文書を毎回入力し直す事前充填（prefill）と、文書長に比例する鍵値キャッシュ（Key–Value cache、KVキャッシュ）の保存・読み出しが負担になる。文書を一度だけ処理し、少数の仮想KV位置へ圧縮した記憶を複数の質問で再利用できれば、デコード時に参照するKV長を減らせる。既存のCartridgesは、凍結した言語モデルの内部で文書ごとに少数のKV状態を直接最適化する。文書に関する質問では、単純に元のKV位置を間引く方式より高い文書利用性能を保つ場合がある。

しかし、サービスへの質問が保存文書に関係するとは限らない。たとえば患者記録を記憶したモデルに天文学の一般問題を尋ねたとき、圧縮記憶が無関係な患者情報を回答根拠として持ち込むことがある。本論文は、**文書内の忠実度（context fidelity）**と**文書外の能力保持（capability preservation）**を分け、学習済みの圧縮記憶が文書内の回答を保ちながら一般知識・指示追従・回答根拠の独立性を悪化させることを示す。これはキャッシュを長く保持したこと自体の悪影響と、学習したKV状態に特有の干渉を区別して評価した結果である。

対策は二つある。第一に、文書関連の自己学習例へ少量の文書外指示データを混ぜ、**文書が不要なときの元モデルの振る舞い**も蒸留する。第二に、質問を受けた時点で文書との関連性を判定し、関連する質問だけ圧縮KVを読み込む。主要なQwen3長文3課題で、後者の関連性ルータは文書内質問の90%超を受理し、文書外質問の90%超を拒否した。著者らはGemma系列と短めのQuALITY文書にも傾向が及ぶことを報告する。ただし、これはルータの分類率であり、システム全体の推論速度が90%改善したという意味ではない。

## 問題設定：同じ圧縮記憶に二種類の要件がある

文書を $x$、長さを $L$、圧縮後の仮想KV位置数を $m$ とすると、圧縮率は $\rho=m/L$ である。文書を処理した通常のTransformerは層ごとに鍵行列と値行列を保持するが、Cartridgesは文書固有の学習可能な鍵・値を $m$ 位置だけ作る。長文を繰り返し読み直さない運用では、この短い状態を固定して次々の質問に供給できる。理論的には参照KV長が $L$ から $m$ に減るが、実際の応答時間はルータや再事前充填を含む実装に依存し、単純な $L/m$ 倍にはならない。

原著は質問を、文書を必要とする $\mathcal{Q}_x^+$ と、文書に関係しない $\mathcal{Q}_x^-$ に分ける。前者では圧縮記憶付きの出力分布が元の全文付きモデルに近いことを求める。後者では圧縮記憶付きの出力分布が**文書なしの元モデル**に近いことを求める。前者の乖離を $R^+$、後者の乖離を $R^-$ と呼び、文書全文を保持しただけでも生じる干渉を比較基準 $R^-_{\mathrm{full}}$ として別に置く。重要なのは、文書を必要としない質問では「全文付きと同じ回答」よりも「文書なしの元モデルと同じ能力」が望ましい点である。

従来のCartridgesは、文書の一部を教師モデルに与えて質問回答を作り、文書の一部を入力した教師の次トークン分布と、圧縮KVを入力した生徒の分布とのKLダイバージェンスを最小化する。この教師信号は文書関連の質問に偏る。無関係な質問で元モデルの能力を保つための損失が明示されないので、圧縮KVがいつも文書の話題へ引っ張るよう最適化されても学習目標上は直接罰せられない。

元のKV位置を残す間引き方式は、質問に関係のない鍵への注意を弱くする余地を持つ。対して文書特化で最適化された仮想KVは、元のキーの選択ではなく新しい状態なので、文書に関係しない質問にも強く反応し得る。著者らはこの違いを、単なる長文回答精度の比較ではなく、一般知識、指示追従、文書根拠の誤帰属の三軸で検証する。

## 手法

### 1. 比較対象となる文書専用Cartridgeの生成

Cartridgesは文書 $x$ を512〜4,096トークン程度の部分文書へ切り分け、凍結モデルから一問一答の自己学習例を作る。部分文書を与えたモデルのトークン分布を教師、文書を与えず圧縮KVを付けた同一モデルの分布を生徒として、モデル重みは凍結したまま仮想KVだけを更新する。QuALITYでは短い512〜1,024トークンの部分文書を使う。文書を変えるたびに別の圧縮KVを学習するため、共通エンコーダで任意の文書を一度に圧縮する方式ではない。

各学習済み記憶は、後の評価質問を知らない時点で構築し、質問群を処理する間は固定する。元の長文の再事前充填を質問ごとに繰り返さないことが狙いである。一方、文書ごとの自己学習例の生成とKV最適化という前処理費用があるため、文書を一度しか使わない場合は有利とは限らない。圧縮率を変える実験では仮想KV位置数を変え、元文書に対する記憶容量を制御する。

### 2. 学習時の文書外データ混合：$C_{++}^{D}$

第一の対策は、文書関連の自己学習データ $\mathcal{D}_x$ に、Dolci-Instruct-SFTから抽出した文書外の一般指示例 $\mathcal{D}^-$ を混ぜる。混合率 $\gamma$ は**教師が採点するアシスタント側トークン全体に占める文書外例の割合**であり、ミニバッチごとの例数割合ではない。文書関連例の教師は元どおり部分文書を入力したモデルである。一方、文書外例の教師は文書もCartridgeも持たない凍結元モデルであり、圧縮KV付き生徒に「記憶が無関係なら通常の回答分布を保つ」ことを教える。

これにより同じ仮想KVが二つの役割を学ぶ。$\gamma=0$ は従来の文書専用学習、$\gamma=1$ は文書関連の教師信号を含まない学習になる。実験では $\gamma=0.01,0.05,0.10$ を主要設定とし、広い範囲も感度分析した。文書内例を削除して文書外例へ置換するのではなく、文書内の自己学習コーパスを維持しつつ文書外トークンを加える。学習の更新回数は従来方式と揃え、追加の最適化回数だけで改善したように見せない。

この方式は質問時の追加判定器を必要とせず、推論経路を変えない。その代わり、文書外の例を増やし過ぎると、限られた仮想KVが文書専用の情報を表現する能力を失う。原著は5%を実用的な妥協点として主図に採用し、1%でも文書外の悪化が改善し始める一方、高い混合率では文書内性能が低下することを示す。

### 3. 推論時の関連性ルーティング：$C_{++}^{R}$

第二の対策は、学習済みCartridge自体を変更せず、質問 $q$ に対して文書 $x$ が必要かどうかを二値で判定する関連性ルータ $r_x(q)$ を追加する。関連ありなら元のCartridgeを使い、関連なしならCartridgeを**完全に外して**文書なしの凍結モデルで回答する。したがって関連なしと正しく判定された場合は、学習した圧縮記憶が引き起こす干渉経路を遮断できる。関連ありの判定を誤ると必要な文書情報を失うため、ルータの偽陰性が新たな品質リスクになる。

主要実装では、Cartridgeを付けずに質問を事前充填し、モデルの第18層の質問トークン隠れ状態を平均して正規化する。文書ごとの自己学習質問を正例の参照集合として保持し、質問埋め込みと最も近い10件の余弦類似度の平均を関連性得点とする。文書外のDolci例で得点の閾値を較正し、閾値以上の質問にだけCartridgeを付ける。閾値は留保した文書外例のスコア分布に対して $\alpha=0.05$ を使うが、**未知の質問分布でも偽受理率が必ず5%以下になる保証ではない**。

ルータ用の文書内正例には自己学習質問2,000件、文書外負例には別のDolci質問2,000件を使う。正例は85%を訓練側、15%を留保側へ分け、評価用TinyMMLU、MMLU-Pro、IFEvalはルータ学習・閾値調整に使わない。著者らは近傍数5/10/20、ロジスティック回帰、隠れ層の深さ、平均・末尾・後方重み付きプーリング、外部のMiniLM文埋め込みも比較した。文書の言語や課題により最良の分類器は変わり、MTOBではロジスティック回帰が比較的強い条件がある。

### 4. 実際のリクエスト処理順と追加費用

本体モデルの隠れ状態を使うルータでは、まず**Cartridgeなしで質問を事前充填**して関連性を判定する。関連なしならその状態から生成を続ける。関連ありなら圧縮KVを付けて質問をもう一度事前充填してから生成する。二度目に処理するのは質問トークンであり、長い元文書全体ではない。従ってルータによる余分な事前充填は、短い質問と長い出力の条件では相対的に小さくなるが、極端に短い応答や関連質問がほとんどの負荷では無視できない。

外部の小型MiniLMで質問埋め込みを計算する変種では、本体モデルの最初の事前充填に先立って関連性を判定できる。この場合、本体モデル側の質問事前充填は選んだ経路の一度で済む代わりに、小型符号器の実行と文書ごとの参照集合照合が追加される。原著は分類器の実装と経路を記述するが、あらゆる実配信負荷に対する一律の端から端までの速度倍率を主張していない。

### 5. 干渉を独立に測る評価設計

文書に関係する質問では、元文書をすべて与えたモデルを基準として、各課題固有の正答率・翻訳指標・参照回答の対数困惑度を測る。無関係な質問では、文書を与えない元モデルを基準に、一般知識の正答率と指示追従の合格率を測る。さらに回答の説明が無関係な文書から引用したふりをする、あるいは文書が答えを与えたと誤認する割合を「文脈干渉」として別に評価する。

干渉判定には主にgpt-oss-20bを用い、回答の正誤とは独立に説明を採点する。単に文書へ言及しただけでは干渉にせず、文書にない引用を捏造した、または無関係な文書を回答の根拠とした場合に数える。判定モデルをgpt-oss-120bとgemma-3-27b-itに変更した再評価でも、学習型Cartridgesと間引き方式の相対的な差は保たれた。ただし、これは採点器の一致を補強するもので、実世界の全種類の文書誤用を網羅するものではない。

|---|---|---|---|
| Qwen3長文脈の標準Cartridgesと間引き系の比較 | 文書内の忠実度と文書外の一般能力 | Cartridgesは極端な圧縮時に文書内性能で優位だが、無関係な質問では一般知識・指示追従・根拠独立性が悪化 | 文書内だけの精度ではキャッシュ再利用の安全な運用を評価できない |
| データ混合、$\gamma=0.01$ | 文書外正答率・干渉 | 1%の混合から改善が現れる | 少量の文書外教師信号が片側だけの蒸留目的を補正する |
| データ混合、$\gamma=0.05$ | 文書内性能と文書外能力の両立 | 主図で文書内性能の低下が小さい、または認められず、文書外悪化が大きく緩和 | 推論時の追加経路なしで妥協点を作れる |
| データ混合、$\gamma$が大きい条件 | 文書内の忠実度 | 文書内性能が低下する条件がある。$\gamma=1$では文書専用情報を学習しない | 文書外能力の回復と文書記憶の専門化は競合する |
| Qwen3のQASPER・LongHealth・MTOB、余弦$k$NN-10ルータ | 文書内受理率・文書外拒否率 | **両方とも90%超**（図5の主要3課題） | 質問の関連性で圧縮KVの有無を選び分けられる |
| ルーティング後のQwen3 | 文書外正答率と干渉 | 文書なしの基準に近づき、文書内の忠実度はおおむね維持 | 文書外質問ではキャッシュを完全に外す設計が有効 |
| Gemma-4-E4B-it、QuALITY-20 | 異なるモデル系列・文書長 | 両方の緩和方式の傾向が再現 | 特定のQwen長文脈だけの現象ではない |
| 標準Cartridgesの学習時間延長 | 文書外能力 | 後期チェックポイントでも悪化が自然回復しない | 単純に蒸留を長く続けるだけでは解消しない |

上表の「改善」は、論文の図が示す傾向を条件付きで整理したものである。原著が一律の端から端までの推論速度倍率や、全課題を一つにまとめた正答率の絶対値を示していない箇所へ、推定数値を補っていない。90%超は関連性ルータの二つの分類率であり、生成品質や速度の改善率ではない。混合率5%も全トークンに対する割合ではなく、**学習時に教師を与えるアシスタント側トークンの割合**である。

### 構成要素の切り分けと負の結果

関連性ルータでは、Qwenの第18層平均プーリングが全体として良好で、近傍数10を主要設定とする。第18層と第24層、平均と後方重み付き平均は英語の質問回答では近い傾向を示すが、翻訳課題MTOBでは表現選択の感度が高い。外部MiniLMは本体モデルの隠れ状態を読む必要がなく、より軽い前段の関連性判定器となり得る。分類器の比較結果は、ルータを導入すれば常に全種類の質問で誤判定がなくなるという主張ではない。

標準Cartridgesの文書外悪化は、学習を長く継続しても回復しない。文書外例を5〜10%混ぜた場合は、文書内の自己学習損失の改善を維持しつつ、文書外のDolci損失が低下する。逆に文書外例だけで学習する極端な条件では文書内の記憶が失われる。これは二つの能力が同じ限られたKV表現を取り合うという機構上の説明と整合する。

「文書が無関係なら無視せよ」という追加の自然言語指示だけを与える対照実験では、文書外正答率やIFEvalの安定した回復は得られなかった。干渉判定値が一部で改善しても、キャッシュを外した状態と同等にはならない。したがって問題は単なるプロンプトの書き方だけではなく、事前に学習されたKV状態をいつ活性化するかというシステム設計にある。

短いQuALITY文書では、間引き方式やテキスト要約が文書内の指標でCartridgesに匹敵または勝る条件がある。それでもCartridgesを有効化した無関係な質問では、一般知識・指示追従の悪化と干渉が残る。圧縮学習方式が文書内で常に最強だと断定できない点と、干渉問題が100Kトークン級に限られない点の双方を示す負の結果である。

## 既存研究との差

H2O、StreamingLLM、SnapKV、PyramidKV、KVzipなどは元のKV位置を選んで保持する。選択によって文書内の情報が欠落することはあるが、保持されたキー・値は元モデルが計算した状態に由来する。Cartridgesはこれと異なり、文書固有の仮想KVを自己学習で直接最適化するため、極端な圧縮下でも文書の質問へ適応しやすい。しかし最適化目標が文書内の分布再現だけに偏ると、無関係な質問に元モデルの分布を保つという別の要件が満たされない。

Attention Matchingは元のキーの一部を残し、注意の再現に向けてバイアスと値を適合させる中間的な方式である。原著では文書外の干渉もCartridgesと間引き方式の中間に位置する。Cartridges++は圧縮率そのものを新しい選別規則で改善する方式ではなく、**文書内に強い学習型記憶を、無関係な問い合わせ時にも安全に使えるようにする**ための学習目標・運用経路を追加する点が異なる。ルータはAttention Matchingにも適用できるが、その場合は元の文書内忠実度の限界まで解消するわけではない。

先行研究の「KV圧縮後の回答精度」評価は、主として元文書内で失われた情報を調べる。本研究はそれに加えて、文書が不要な質問で元モデルの能力を保持できるかを独立の要件とする。文書なしの元モデルと全文付きモデルを両方基準にしたことで、全文を読んだだけでも生じる干渉と、学習した圧縮KVに固有の追加干渉を区別する。この評価軸の追加が、二つの緩和方式の必要性を説明する。

## 限界と実装状況

本論文が主に扱うのは、一つの文書に対して一つの圧縮KVを学習し、後の複数質問へ再利用する場面である。文書群を同時に検索する大規模配信、頻繁に文書が更新される運用、複数Cartridgeを同時に組み合わせる場合、長時間の実運用トレースにおける遅延分布などを、この結果だけで保証できない。文書ごとの自己学習データ生成と最適化が必要なので、再利用回数が少ない文書では前処理費用を回収できない可能性がある。

学習時混合は推論時の分岐を増やさないが、混合データの分布にない文書外質問では干渉が残る可能性がある。混合率を上げれば文書内の忠実度が低下するため、利用場面に応じた調整が必要である。ルーティングは圧縮記憶を使うべき質問を誤って拒否すると文書内回答を失い、無関係な質問を誤受理すると干渉を残す。較正時のDolci負例に対する閾値の統計的性質を、分布の異なる実配信負荷へ無条件に外挿できない。

ルータが本体モデルの隠れ状態を使う場合、関連質問には追加の質問事前充填が必要になる。MiniLM変種はその費用を減らし得るが、別の符号器と参照集合の管理が必要である。原著のGPU環境はH100/B200であり、Windowsの単一消費者向けGPUにおける実測性能、キャッシュ構築時間、推論器への統合は直接検証されていない。圧縮率だけを根拠にVRAM削減率や生成速度を断定できない。

文書外評価はTinyMMLU、MMLU-Pro、IFEvalおよび説明文への判定モデルを中心とする。著者らは回答を控えるべきときに誤って答える失敗も補足するが、すべての安全性・頑健性を網羅していない。干渉はgpt-oss系列などの言語モデル採点器に依存するため、複数採点器で傾向が再現されても個別回答の判定に誤差があり得る。複数ターンの補足評価では単一ターンを超える追加崩壊は見られなかったが、ルーティングには各ターンの関連性を個別に扱う条件がある。

原著は既存のCartridgesとAttention Matchingの公式実装を使用したと明記するが、Cartridges++そのものの公式実装URLは本文から確認できない。実装状況を既存方式の公開コードと混同せず、`code: null` とした。論文の手順・学習条件・関連性判定の疑似コードは本文と付録B/Cに記載されている。
