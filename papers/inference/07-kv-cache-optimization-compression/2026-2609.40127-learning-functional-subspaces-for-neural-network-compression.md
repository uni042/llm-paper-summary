# Learning Functional Subspaces for Neural Network Compression

> 捨てる部分空間を層ごとの閉形式基準ではなく、出力分布へのKLで全層の直交射影をエンドツーエンドに学習して決める低ランク圧縮法で、注意では共有潜在だけをキャッシュしてKVキャッシュも細らせる。

## 概要

大きなTransformerは重みの総量がそのままメモリと計算を支配する。重み行列を2つの細い行列の積へ置き換える低ランク圧縮は、行列を稠密なまま保てるため通常のハードウェアで効率が良い。ところが既存法は、どの方向を捨てるかを層ごとに決める。活性値のエネルギーが小さい方向を捨てる方法、層の出力の再構成誤差が小さい方向を捨てる方法、損失の二次近似で判断する方法はいずれも、その層の中だけで完結する。ある層で小さく見えた誤差が後段の層を通るうちに増幅されるかどうかは見ていないため、圧縮率を上げるほど誤差が深さ方向へ積み重なり、性能が急に崩れる。

本論文のLSP（Learnable Subspace Projections、学習可能な部分空間射影）は、捨てる部分空間そのものを学習対象にする。各線形層、または同じ活性値を読む層の組に直交射影を1つ割り当て、学習済みの重みは凍結したまま、全射影をモデルの出力分布へのKLダイバージェンスという大域目的で同時に最適化する。初期値は活性値を白色化した特異値分解の切り捨てから作り、各単位が何方向捨てるかは、その単位だけを実際に切り捨てたとき出力KLがどれだけ増えるかを実測して配分する。学習が終われば射影は通常の低ランク因子へ畳み込まれ、推論時は余分な仕組みが残らない。注意ではキーとバリューが同じ入力を読むため射影を共有でき、キャッシュには元のキーとバリューではなく共有した狭い潜在表現だけを置ける。

代表結果は高圧縮側で際立つ。線形層のパラメータを70パーセント削ったLlama-2-7Bで、WikiText-2のパープレキシティは10.9、6つのゼロショット課題の平均正解率は42.2パーセントであり、最強の比較対象であるLoRA回復付きSVD-LLMの13.3と36.0パーセントを上回る。因数分解したモデルは小さいバッチで稠密モデルより最大で約1.6倍速くデコードし、バッチ8・文脈128kでは重みとKVキャッシュの合計が稠密モデルの524.6GiBから38.9GiBへ、13.5倍小さくなる。

## 問題設定

低ランク圧縮の難しさは、重み行列そのものの特異値が緩やかにしか減衰しないことにある。重みのスペクトルだけを見て小さい方向を捨てると性能が大きく落ちることが知られている。実際に冗長なのは重みではなく活性値の側で、層の間を流れる活性値は低次元の部分空間へ集中する。そこで既存法は活性値の統計から残すべき部分空間を読み取る。しかし読み取りの基準が層局所である点が限界になる。入力エネルギーが小さい方向でも、ネットワークの出力が強く依存していれば捨ててはならない。逆に再構成誤差の観点で最適な切り捨てでも、その残差が後段でどう伝播するかは分からない。損失を意識する従来法も、Fisher情報や曲率による局所的な代理指標にとどまり、有限の切り捨てが最終出力へ与える影響そのものは測っていない。

もう1つの問題は、重みを細らせても推論時のメモリが比例して減らないことである。通常の因数分解では第2の因子が出力を元の幅へ戻すため、キーとバリューのキャッシュは元の幅のまま残る。文脈が128kトークン級になるとキャッシュが重みを大きく上回り、重み圧縮の利得が薄れる。本論文はこの2つ、つまり「捨てる方向の決め方」と「キャッシュの幅」を同時に扱う。

## 手法のあらまし

処理は4段である。まず圧縮単位ごとに、校正データの活性値から白色化した基底を作り、末尾の方向を捨てる候補とする。次に、各単位について候補の切り捨てを実際に行い、稠密モデルの出力分布とのKLダイバージェンスを測り、節約できるパラメータあたりのKL増加が小さい単位から順に、目標の節約量へ達するまで方向を捨てる配分を決める。次に、重みを凍結したまま全単位の射影を同時に学習する。目的は稠密モデルの出力分布へのKLが標準で、モデルの元の訓練損失を使う変種もある。最後に、学習した射影の補空間から低ランク因子を作って重みへ統合する。同じ活性値を読む層の組、具体的には注意のクエリ・キー・バリューと、MLPのゲート・アップは射影を共有し、因子も1つを共有する。注意ではこの共有により、キーとバリューを再構成できる潜在表現だけをキャッシュする形が得られる。

## 手法

### 1. 直交射影の学習 — 捨てる方向を変数にする

観測対象は各層へ入る活性値であり、保持する状態は「どの入力方向を捨てるか」を表す直交射影である。線形層の重みに、捨てる方向の正規直交基底から作った射影を掛けると、重みのランクは捨てた方向の数だけ下がる。実装では制約のない行列を変数として持ち、前向き計算のたびに薄いQR分解の直交因子を取り出すことで直交性を構造的に保つ。射影そのものは基底の張る部分空間だけで決まるため、実効的な変数は部分空間である。出力側へ射影する形も用意し、層ごとに小さい側を選ぶ。

この形が減らすボトルネックは、局所基準の誤判断である。射影は層の再構成ではなく最終出力へのKLで訓練されるため、ある層で大きく見える方向でも出力が依存しなければ捨てられ、逆に小さく見える方向でも出力が依存すれば残る。追加で消費する資源は圧縮時の訓練計算であり、推論時の追加機構はない。失敗条件は、校正データと配備先の分布がずれると、学習した部分空間が配備先で効かなくなることであり、論文は視覚モデルで校正データの構成を変えた実験によりこの依存を測っている。訓練を安定させる工夫として、射影の強さを最初のエポックで0から1へ漸増させること、捨てる方向の一部をランダムに一時的に残すドロップアウト、変数の列間相関への直交性ペナルティが入る。また射影を掛けた重みを稠密行列として実体化せず、活性値側で「入力から捨てる成分を引く」形で計算し、融合したQRの後向き計算でメモリを抑える。

### 2. 白色化初期化 — 層の出力への影響で並べた基底から始める

学習の出発点は、校正入力のグラム行列で白色化した重みの特異値分解である。白色化により、方向の順序は重み自身の大きさではなく層の出力への寄与で決まる。末尾の方向を捨てる切り捨ては層別再構成誤差の意味で最適であり、出力側射影ではこの最適性がそのまま成り立つ。入力側では切り捨てが斜めの射影になるため、本論文は保持部分空間への直交射影へ置き換え、その際に生じる超過誤差が、保持した特異値と保持・除去部分空間の非直交性で書けることを命題として示している。結合した層の組については、重みを行方向へ積み重ねた白色化行列の部分空間が組全体の誤差を最小化する。初期化だけでも従来の切り捨て法と同等の出発点が得られ、学習はここから出力依存に合わせて方向を入れ替える。実際、学習後の除去はスペクトル全体へ広がり、特に先頭方向の扱いが未学習の初期化と最も大きく変わる。重みの特異値の順序は出力への重要さの順序ではない、というのがこの観測の読みである。

### 3. 実測KL配分 — 単位ごとに実際に切り捨てて測る

各単位が何方向捨てるかは、代理指標ではなく実測で決める。稠密モデルの出力は一度だけキャッシュし、各単位について初期基底の末尾を段階的に捨てたときの出力KLを、他の単位は稠密のまま測る。勾配も新しい特異値分解も要らない。測定した曲線は単調化したうえで、配分器が「次に捨てるまとまりのKL増加÷節約パラメータ数」が最小の移動を繰り返し、全体の節約目標へ達するまで進める。曲率に基づく推定が稠密な重みの近傍でしか成り立たないのに対し、こちらは有限の切り捨てをネットワーク全体へ通して測る点が違う。限界も明示されており、各単位を単独で測るため単位間の相互作用は入らず、大域最適の保証はない。相互作用の分は後段の同時学習が引き受ける設計である。配分の結果は一様から大きく外れる。Llama-2-7Bでは注意の入力側がMLPよりはるかに強く圧縮され、深いブロックほどランクを多く残し、圧縮率30パーセントでは128単位中53単位が、因子化するとかえって大きくなる損益分岐を理由に稠密のまま残る。

### 4. 統合と潜在キャッシュ — 推論時は通常の因子だけが残る

学習後の射影は、保持部分空間の基底を使って重みを2因子へ分解し、そのまま置き換える。QRもドロップアウトも輸出後には残らない。入力側で結合した組は第1因子を共有するため、その因子を活性値へ掛けた潜在表現は組の全層で共通になる。注意ではこの潜在表現からキーとバリューを両方再構成できるため、キャッシュには潜在表現だけを置けばよい。バリュー側の因子は出力射影へ吸収でき、キー側は回転埋め込みの都合でステップごとに潜在から再構成する費用が文脈長と潜在幅に比例してかかる。つまり潜在キャッシュは速度ではなく容量のための仕組みであり、論文もその位置づけを明示している。共有の効果は大きく、圧縮率70パーセントのLlama-2-7Bでトークン・層あたりのキャッシュ要素数は稠密の8192から556へ、非結合の因数分解の1228から1434と比べても半分以下になる。

## 評価

結論は3つある。第1に、精度では圧縮率が高いほどLSPの優位が広がり、4つの言語モデルの全12設定でLSPの2変種のどちらかが最小のパープレキシティを持つ。第2に、推論では結合した因子が小さい行列積の本数を減らすため、同じ圧縮率の他の因数分解より速く、稠密モデルよりも速い。第3に、潜在キャッシュにより長文脈の容量が非結合の因数分解の2倍以上へ伸びる。評価は実機測定で、精度は全比較対象を公式コード・同一校正データ・同一精度で走らせている。

パープレキシティの崩壊の仕方が対照的である。学習なしの特異値分解系は圧縮率70パーセントで軒並み3桁から4桁へ悪化し、同じ初期化・同じランクで学習だけを外した対照条件もLlama-2-7Bで222.8まで崩れる。学習したLSPは10.9に留まる。つまり効いているのは初期化や配分ではなく、部分空間を学習すること自体である。ゼロショットでも、Llama-2-7BとQwen3-4Bの全圧縮率で両変種が最強の学習なし比較対象を平均6.2から10.8ポイント上回る。

視覚モデルの実験は校正データへの依存を切り分けている。校正プールの大きさを揃えて構成だけを変えると、LSPは多様なプールから最も大きく転移精度の利得を得る。ラベルなしのKL目的は、配備先と違う分布のデータでも稠密モデルの振る舞いを写し取るため、校正分布のずれに比較的強い、という読みができる。

速度については注意が必要である。デコードの高速化はバッチ1・文脈512トークンでの測定で、圧縮率70パーセントで稠密比1.56倍、30パーセントでは1.21倍である。文脈が16kへ伸びると稠密が毎秒36トークン、LSPが40トークンと差は縮む。潜在キャッシュの容量利得は大きいが、これは収まる文脈長の話であり、速度の測定は通常の全幅キャッシュで行われている。2つの利得を混同しないことが読み方の要点である。

## 既存研究との差

ASVDやSliceGPTは活性値のエネルギーから、SVD-LLM（W）やSwift-SVDは層の再構成誤差から、捨てる部分空間を閉形式で読み取る。これらは「その層で何が要らないか」を決める研究である。LLM-Surgeonは損失の曲率近似を、Dobi-SVDは閉形式の基底の中でランクだけの学習を持ち込むが、基底そのものは学習しない。LSPが追加したのは、基底すなわち部分空間そのものを、ネットワーク全体の出力へのKLで学習することと、その実測KLでランク配分を決めることである。潜在キャッシュの考え方自体はMLAやPaluと同系だが、LSPでは重み圧縮の結合射影から副産物として得られ、別途キャッシュ圧縮法を組み合わせる必要がない点が異なる。

## 限界・実装状況

著者が付録で挙げる限界は3つある。第1に、実測KL配分は単位を単独で測る局所的な代理であり、単位間の相互作用を含まず、大域最適の保証もない。設定によっては一様ランクが好まれる場合もあるとされる。第2に、圧縮は無料ではなく、KL測定と射影訓練の費用がかかる。測定は再利用できるものの、モデルごとに1回の投資が要る。第3に、潜在キャッシュの利得はキーとバリューが入力側で結合した場合に限られる。Qwen3-4Bの最良設定は出力側の結合であり、精度と推論効率のトレードオフとして入力側結合を選ぶこともできる、という位置づけである。コードの公式公開先は論文中に示されておらず、上流の推論エンジンへ統合されたという記述もない。手法は近似であり、圧縮率を上げるほど品質は単調に下がるため、品質要件との照合なしに高い圧縮率を既定にはできない。

## 一般的な実装上の含意

圧縮の判断基準は、対象の層の中で測れる量ではなく、最終出力への実測の影響で置くべきである、というのが最も汎用的な含意である。代理指標が安くても、有限の変更を実際に適用して出力のずれを測る方が、高圧縮のような外挿域では信頼できる。また、重みを細らせる設計ではキャッシュの幅も同時に設計しないと、長文脈では全体のメモリが減らない。共有できる計算は因子の共有として表し、キャッシュには再構成可能な最小の潜在表現だけを置く形は、他の圧縮法や注意の変種にも応用できる。最後に、学習なしの対照条件を同じ初期化・同じランクで用意して初めて「学習が効いた」ことが言える、という評価設計も再利用できる。
