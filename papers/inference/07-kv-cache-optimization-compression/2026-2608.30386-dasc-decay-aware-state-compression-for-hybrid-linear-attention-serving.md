# DASC: Decay-Aware State Compression for Hybrid Linear-Attention Serving

> 重み由来の保持地平でKDA/GDN再帰状態を選別・ragged保存し、TP均衡化によりKimi-KDAで2.63倍のcheckpoint容量とTTFT 42.6%削減を実現する。
## 書誌情報
- **著者**: Yanqi Yu, Pingwei Sun, Jianchao Tan, Tao Zhang, Yuchen Xie, Xunliang Cai, Yao Liu
- **著者・所属**: East China Normal University; Meituan; South China University of Technology
- **公開**: arXiv
- **種別**: プレプリント
- **対象**: 線形注意、再帰状態checkpoint、prefix キャッシュ、状態圧縮、テンソル並列
- **実装**: SGLang上に実装。論文中ではTP8、ragged checkpoint store/load、variable-split all-to-all、DASC-NR/WRを評価するが、論文本文で独立公開コードURLは示されない。
## 概要
DASCはハイブリッド線形注意モデルのprefix キャッシュで、線形注意の再帰状態checkpointがHBMを圧迫する問題に対し、モデル重みから各head/channelの保持地平（retention horizon）を静的推定し、長寿命unitだけをragged配置で保存する。TP rank間のcheckpoint payloadも再配置して均衡化し、キャッシュ hit時は省略unitをzero-fillするDASC-NRか、bounded suffixを再実行して回復するDASC-WRを用いる。Kimi-KDAではWmax=16でcheckpoint容量2.63倍、固定HBM下で平均TTFTを42.6%削減し入力スループットを68.4%向上した。

DASCは、GDNではヘッド単位、KDAではチャネル単位に減衰速度が大きく異なることを利用し、要求ごとの入力観測を行わずモデル重みだけから静的な保持地平を算出する。最大再実行窓より長く情報を保持する長寿命単位だけを永続化し、層ごとに保持数が異なる状態を最大幅へ埋めず可変長の連続領域へ格納する。さらにテンソル並列ランク間の保存量偏りを、モデル読込時のヘッド束再配置と保存・読込時の可変分割全対全通信で均衡化する。省略した短寿命単位はゼロ補完する方式と、有限長の接尾辞だけを再実行して局所状態を回復する方式を使い分ける。

代表結果として、Kimi-KDA checkpoint capacityはragged + TP-balanced, complete checkpoint including BF16 convolution stateでdense mixed-precision state checkpointに対して2.63× at Wmax=16; up to 28.04× at Wmax=512。channel-grained KDAは層/head内のdecay heterogeneityを細粒度に除去でき、TP balanceでworst-rank ボトルネックも軽減する。
## 問題設定
ハイブリッド線形注意モデルでは、全注意層の鍵値キャッシュとは別に、線形注意層の境界再帰状態を接頭辞ごとに保存しなければ再利用できない。再帰状態はトークン処理のたびに上書きされるため過去境界が自然には残らず、再利用点を増やすには巨大な状態を多数複製する必要がある。ここが高帯域メモリ容量の主要なボトルネックとなり、保存点を減らせば今度は長い接頭辞の再事前充填が必要になって初回トークン待ち時間と入力処理量が悪化する。従来のページ化注意、鍵値量子化、鍵値追い出しはトークン単位の鍵値キャッシュを主対象とし、再帰状態内部で単位ごとに情報寿命が異なるという構造を利用しない。また単純に状態全体を量子化しても、層ごとの有効保持数の差やテンソル並列ランク間の保存量偏りは残る。このため、保存対象の選択、物理配置、並列負荷均衡、命中時の再構成を一体で扱う必要がある。
## 新規性
DASCは、GDNではヘッド単位、KDAではチャネル単位に減衰速度が大きく異なることを利用し、要求ごとの入力観測を行わずモデル重みだけから静的な保持地平を算出する。最大再実行窓より長く情報を保持する長寿命単位だけを永続化し、層ごとに保持数が異なる状態を最大幅へ埋めず可変長の連続領域へ格納する。さらにテンソル並列ランク間の保存量偏りを、モデル読込時のヘッド束再配置と保存・読込時の可変分割全対全通信で均衡化する。省略した短寿命単位はゼロ補完する方式と、有限長の接尾辞だけを再実行して局所状態を回復する方式を使い分ける。
## 手法
### 手法のあらまし
入力は学習済みハイブリッド線形注意モデル、接頭辞境界の再帰状態、最大再実行窓である。まずモデル読込時に各線形注意単位の減衰重みから、その単位の過去情報が閾値以下へ減衰するまでの保持地平を計算し、最大再実行窓より長寿命の単位を永続保存対象として固定する。次に接頭辞を保存するとき、選択された単位だけを層ごとの開始位置を持つ可変長連続バッファへ詰める。層ごとに保持数が違っても最大幅への埋め草を行わない。同時にテンソル並列群を共有保存プールとして扱い、モデル読込時のヘッド束再配置と保存時の可変分割全対全通信によってランクごとの保存量を均等化する。接頭辞が再利用されると、保存済み長寿命単位を正確に読み戻す。省略した短寿命単位は、追加計算を避ける設定ではゼロで初期化し、精度を優先する設定では各単位の保持地平に応じた有限長の接尾辞だけを一時状態から再実行して回復する。最後に復元済み再帰状態と変更していない全注意層の鍵値キャッシュを結合して通常の復号へ渡す。したがって入力から出力まで、寿命推定、選択、可変長保存、並列均衡化、読込、局所回復、復号再開という一連の経路で動作し、同じメモリ容量で常駐できる再利用接頭辞数を増やす。

### 重み由来の保持地平（重み-derived retention horizon）
入力は学習済み線形注意層の減衰関連重みと最大再実行窓である。要求ごとのゲート値を観測する代わりに、モデル読込時に減衰の代表値から各単位の寄与が所定閾値まで減る時間を計算する。GDNではヘッド単位、KDAでは鍵チャネル単位で保持地平を得て、最大再実行窓を超える長寿命単位だけを永続保存対象として固定する。出力は要求に依存しない選択マスクであり、実行時プロファイリングを不要にしながら保存すべき状態量を減らす。ShareGPTの32接頭辞で静的地平と経験的地平の順位相関中央値はGDNで0.801、KDAで0.856と報告される。

### 可変長状態チェックポイント（Ragged state checkpoint）
入力は前段で得た固定選択マスク、各層の時間方向再帰状態、畳み込み状態である。保存時には各層で実際に選択された単位だけを抽出し、層ごとの開始位置を表すオフセット表とともに一つの連続領域へ順番に詰める。全層を最大保持幅へ合わせる埋め草を行わないため、論理的に省略した単位が物理的な容量削減へ直接つながる。時間方向状態はFP32、畳み込み状態はBF16のまま保持し、圧縮率を過大評価しないよう非圧縮の畳み込み状態も容量計算へ含める。読込時にはオフセットから各層の保存範囲を特定して元の単位位置へ戻す。出力は層ごとに長さが異なっていても余分な埋め草を含まない密な保存表現であり、後段の並列配置と状態回復がこの表現を直接利用する。

### テンソル並列均衡配置（TP-balanced 配置）
入力は各テンソル並列ランクが担当する線形注意単位と、可変長化後に各単位が必要とする保存量である。まずモデル読込時にヘッド束の所有ランクを並べ替え、特定ランクへ長寿命単位が集中する恒常的な偏りを減らす。さらに保存時と読込時にはテンソル並列群全体を一つの共有保存プールとして扱い、可変分割の全対全通信によって詰めた単位をランク間へ再配分する。これにより最も保存量の多いランクが全体の実効容量を決める最悪ランク制約を緩和する。通常の事前充填と復号のトークン処理には追加通信を挿入せず、追加転送を接頭辞チェックポイントの保存・読込境界へ限定する。出力は各ランクの使用量がより均等になった物理配置であり、可変長保存で得た論理圧縮率を実際の分散メモリ容量へ反映できる。

### 省略状態の回復（DASC-NR / DASC-WR recovery）
入力は読込済みの長寿命状態、保存を省略した短寿命単位の位置情報、必要に応じて接頭辞末尾のトークン列である。追加計算なし方式では短寿命単位をゼロで初期化し、保存済み長寿命単位と結合して直ちに通常の復号へ渡すため、命中時の追加モデル計算を発生させない。窓再実行方式では各短寿命単位の保持地平を二の冪へ丸め、4から最大再実行窓までの有限範囲へ制限する。そのうえで必要な最大長の接尾辞だけをゼロ初期化した一時状態から再実行し、各短寿命単位へ必要な範囲の履歴を再注入する。前者は待ち時間を最小化し、後者は強い圧縮時の品質低下を回復する代わりに再実行時間を支払う。出力はいずれも保存済み単位と回復済み単位を組み合わせた再帰状態で、後続復号が通常のモデル状態としてそのまま利用できる。

### 全体のデータ／制御の流れ
全体設計は、何を保存するかという論理選択、どの形で格納するかという物理配置、テンソル並列ランク間でどこへ置くかという負荷均衡、命中時に省略部分をどう復元するかという再構成を一体化する。単なる圧縮率の改善ではなく、接頭辞キャッシュ一項目あたりの再帰状態バイト数を実際に減らし、同じ高帯域メモリ容量でより多くの再利用可能接頭辞を常駐させ、再事前充填を減らすことが目的である。選択だけを行っても最大幅への埋め草が残れば容量は減らず、可変長化だけを行っても一つの並列ランクへ状態が偏れば最悪ランクが容量上限になるため、四要素を連結することに意味がある。項目単位の受入・追い出し方針を改善する研究や、状態量子化、階層メモリ、接頭辞共有方式とは対象階層が異なるため併用できる。
## 評価条件
- **ハードウェア**: 正式評価はすべてHopper世代GPUを8並列のテンソル並列構成で実施する。Kimi-Linear-48B-A3B-Instruct（KDA層20個と全注意層7個）とQwen3-Next-80B-A3B-Instruct（GDN層36個と全注意層12個）を対象とする。
- **ソフトウェア**: DASCをSGLangへ実装した。モデル重みと通常実行は非量子化BF16、再帰状態の保存点はSGLang既定のFP32時間状態とBF16畳み込み状態を使う。基本設定は可変長格納と再実行なし方式である。
長文脈品質はRULER全13課題を4千、8千、16千トークンで評価し、各課題・長さにつき30例を用いる。端から端までの品質評価にはAIME 2026 I/II、HMMT Feb 2026、IMO-AnswerBench、GPQA-Diamond、MMLU-Pro、LoCoMoを用いる。同じ圧縮量の無作為選択を各層・最大窓設定ごとに5個固定して作り、減衰認識順位付けと比較する。メモリ容量を揃えた配信評価ではMMLU-Pro由来の接頭辞再利用負荷を使い、各並列ランクの状態保存予算を固定して、3乱数種の平均初回トークン待ち時間と入力処理量を測る。窓再実行方式では厳密なウォーム・再実行品質と固定スロットの接尾辞再計算費用を分離して評価する。
ハイブリッド注意の2系統、すなわちチャネル粒度KDAとヘッド粒度GDNに限定する。最大再実行窓16から512または1024までで圧縮と品質を走査し、テンソル並列負荷均衡、可変長配置、接尾辞再計算、8ビット状態量子化との併用も評価する。純粋な線形注意や状態空間モデル、8並列を超える構成、他世代GPUは未検証である。
## 主要結果
保守的Wmax=16ではKimi-KDAのragged + TP-balanced checkpoint容量がdenseの2.63倍になり、RULER平均はdenseとほぼ同等を維持した。固定HBMのprefix-reuse ワークロードではKimi-KDAのTTFTが567.6msから326.0msへ42.6%低下し、入力スループットが33.25kから55.98k トークン/sへ68.4%向上した。より強い圧縮ではNRの精度低下が増えるが、WR suffix refreshで大部分を回復する。

- Kimi-KDA checkpoint capacity / 2.63× at Wmax=16; up to 28.04× at Wmax=512 (比較対象: dense mixed-precision state checkpoint; 条件: ragged + TP-balanced, complete checkpoint including BF16 convolution state) — channel-grained KDAは層/head内のdecay heterogeneityを細粒度に除去でき、TP balanceでworst-rank ボトルネックも軽減する。

- Kimi-KDA mean TTFT / 567.6 ms → 326.0 ms (-42.6%) (比較対象: dense state checkpoint; 条件: Wmax=16, fixed matched-HBM state budget, TP8) — 1 checkpointあたりのbytes削減が常駐 prefix数を増やし、再プリフィルを減らす。

- Kimi-KDA input スループット / 33.25k → 55.98k トークン/s (+68.4%) (比較対象: dense state checkpoint; 条件: Wmax=16, fixed matched-HBM state budget, TP8) — 同じHBMでキャッシュ hitを増やす容量効果がinput処理量へ直結する。

- RULER aggregate quality / Kimi Wmax16 0.95/0.95/0.95 vs dense 0.95/0.96/0.95 at 4k/8k/16k (比較対象: dense checkpoint; 条件: 13 RULER subtasks, N=30 each) — 保守的thresholdではstate omissionの品質影響が小さい。

- Suffix refresh recovery / Wmax=128でNR比 +0.8〜7.4pt; MMLU-Pro WR 66.59〜67.19% vs dense 67.50% across sweep (比較対象: DASC-NR / dense; 条件: Kimi-KDA strict warm/replay) — aggressive omissionの精度損失をbounded replayで回復できるが追加TTFTを要する。

- GDN serving / Wmax=512: TTFT 614.4→374.5 ms; スループット 30.56→50.96k トークン/s (比較対象: dense; 条件: Qwen-GDN, TP8) — head-grained GDNでも効果はあるがKDAより圧縮粒度が粗く容量gainは最大2.48×。

### 負の結果・境界条件
- Kimi-KDAでWmax=1024までNRを強くするとRULER平均がdense比4k/8k/16kで0.04/0.06/0.07低下する。GDNはhead単位decayのためKDAほど圧縮できない。KDA Wmax=512では113-column headが不可分でremote ownershipを完全除去できず、all-to-allと長いsuffix replayがWRの容量利得を相殺する。pure linear/SSMとTP8超は未評価。

### 結果の読み方
DASCの主要なシステム利得はcheckpoint compressionそのものより、固定HBMで常駐 reusable prefixを増やしてrecomputeを減らす点にある。静的重み-derived selectionはonline profiling不要で、ragged layoutとTP balanceを組み合わせないと実容量gainがpadding/worst-rankで失われる。
## 品質への影響
Wmax=16ではend-task各行がdenseから1.3pt以内で、Kimi-KDAではdecay-aware DASCが15 reasoning comparisonsすべてで5-mask Random平均を上回り7件がHolm補正後も有意。強い圧縮ではNR劣化が増え、WRで精度と遅延を交換する。
## 既存研究との差
PagedAttentionやRadixAttentionはトークン索引型の鍵値キャッシュの割当と再利用を管理するが、DASCは全注意層の鍵値キャッシュを変更せず、ハイブリッド層の永続的な再帰境界状態の内部を圧縮する。Marconiはハイブリッド接頭辞項目の受入と追い出しを計算・メモリ効用で改善するのに対し、DASCは各項目の状態バイト数を削減するため補完関係にある。ReplaySSMは最近の状態空間モデル入力を保持して状態を必要時に再構成するが、DASCは長寿命単位を直接保存し短寿命単位だけを省略する。KVQuantやKIVIなどの量子化は値当たりのビット数を減らす一方、DASCは保持単位数を減らし、実際に8ビット量子化との併用で8.11倍の容量を示す。
## 限界
評価対象はQwen3-NextのGDNとKimi-LinearのKDAというハイブリッド構成に限られ、純粋な線形注意や状態空間モデルへの転移は未確認である。配信実験はすべて8並列のテンソル並列構成であり、より大きな並列度での負荷均衡や全対全通信費用は未検証である。GDNは減衰がヘッド粒度なのでKDAより容量利得が小さく、構成依存性が強い。窓再実行方式は再実行窓より前の局所状態履歴を復元しない近似であり、強い圧縮では追加計算と通信が利得を相殺し得る。
## 実装状態
著者らはSGLangへDASCを実装し、可変長状態プール、テンソル並列で均衡化した保存・読込、再実行なし方式と窓再実行方式をHopper世代GPUの8並列構成で評価している。arXiv初版は2026年8月31日提出。本文中に独立した公開実装リポジトリのURLは記載されていないため、公開コードの存在は確認済みとは扱わない。
## 研究上の位置づけ
ハイブリッド線形注意の配信において、再帰状態の保存点を鍵値キャッシュの付属物ではなく独立した階層メモリ資源として扱う研究である。特に重みだけから静的に寿命を推定して保存表現へ接続し、論理的な選択だけでなく可変長の物理配置とテンソル並列ランクのボトルネックまで最適化した点がシステム研究として重要である。項目単位のキャッシュ方針、状態量子化、階層型鍵値キャッシュと直交して組み合わせられる。
