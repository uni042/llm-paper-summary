# Eigen Attention: Attention in Low-Rank Space for KV Cache Compression

> 各層のキー・値をSVD由来の低ランク部分空間へ射影してKVキャッシュの特徴次元を縮め、トークン枝刈りや量子化と直交する形で長文脈推論のメモリと注意遅延を削減する。

## 概要

長文脈推論では、各過去トークンのキーと値を全層で保持するKVキャッシュが系列長とバッチに比例して増える。論文の例ではLlama-2 7Bを32K文脈・バッチ16で動かすと、重み14 GBに対してKVキャッシュは256 GBに達し得る。Eigen Attentionはトークンを捨てるのではなく、キー・値ベクトルの特徴次元に冗長性があることを利用し、注意計算を低ランク空間へ移す。

校正データから各層のキー・値表現を集め、特異値分解（Singular Value Decomposition; SVD）で主要部分空間を抽出する。推論時には射影後の低次元キー・値だけをキャッシュし、クエリも対応する部分空間へ写して注意を計算する。OPT、MPT、Llama系列で最大40%のKV削減を示し、OPT-66Bでは注意層遅延が1.57 msから0.62 msへ60%低下した。一方、回転位置埋め込み（Rotary Positional Embedding; RoPE）を使うLlamaではキーを高次元へ戻す処理が入り、Llama-3-70Bでは0.74 msから0.80 msへ8%悪化する条件も報告される。

## 問題設定

KV圧縮の代表的な方向は、古い・重要度の低いトークンを捨てる方法と、各要素のビット幅を下げる量子化である。前者は保持する時刻方向を削り、後者は数値精度を削る。Eigen Attentionは別の軸として、各トークンに保持する特徴次元そのものを縮める。したがってH2Oのようなトークン枝刈りやKV量子化と同時に使える余地がある。

## 手法

### 層ごとの低ランク部分空間

校正入力をモデルへ流し、各注意層のキーと値の表現行列を収集する。SVDの固有値スペクトルから、情報の大部分を保持するランク r を選び、キー用・値用の射影行列を構成する。キーは値より少ない次元で主要成分へ集中する層があり、層ごと・K/Vごとに圧縮可能性が異なる。

### 射影後のKVをキャッシュ

通常は次元 d のK/Vをトークンごとに保存するが、Eigen Attentionは r<d の座標へ射影してから保存する。クエリも同じキー部分空間へ写せば、注意の内積と値の重み付き和を低次元で行える。計算量は標準注意の O(4d²+2nd) に対し O(4dr+2nr) へ縮むと整理され、nが長いほどKV読出しと内積の削減が効く。

### RoPEモデルの扱い

Llama系列ではRoPEが固定次元のキーへ位置回転を適用するため、単純に低次元キーのまま全処理を完結できない。論文は低ランクで保存したキーを注意計算前に高次元へ戻す経路を用いる。この復元が追加計算となり、メモリは減っても注意演算の速度利得が小さくなる。OPT-66Bで大きな遅延短縮が出る一方、Llama-3-70Bで逆に8%遅くなる結果はこの制約を示す。

### 他の圧縮法との併用

特徴次元を縮めるため、時刻方向を削るH2Oや量子化と原理上直交する。論文ではEigen Attentionで次元を60%へ縮め、H2Oでトークンを40%残す組合せにより、元KVの0.24倍まで圧縮する例を示す。単独法を極端に設定するより、複数軸へ圧縮量を分散できる。

## 評価

### 代表的な評価条件

| 項目 | 代表設定 |
|---|---|
| モデル | OPT、MPT、Llama-2、Llama-3 |
| 品質 | WikiText系パープレキシティ、ゼロショット課題 |
| 圧縮率 | 0.8×、0.7×、0.6×など |
| 性能 | 生成時の注意層単体遅延 |
| 追加評価 | LoRA微調整、量子化、H2Oとの併用 |

| Llama-2-70B, 0.6× | 注意層遅延 | 0.79 ms | 0.77 ms | -3% | RoPE復元で利得が小さい |

LoRAで注意投影を2,000 step微調整すると、ある設定ではパープレキシティ差が2.56から1.55へ縮み、ゼロショット精度差も7%から2%以内へ改善する。ただし、これは追加学習なしの圧縮とは別条件である。

## 既存研究との差

H2OやSnapKVは保持トークンを選ぶため系列方向を削る。量子化は値のビット幅を削る。Eigen AttentionはK/Vの特徴次元を削るため、これらと競合せず積み重ねられる点が新しい。低ランク近似自体ではなく、KV保存形式と注意計算の双方を同じ部分空間へ移すことが推論時メモリ削減へ直結する。

## 限界・実装状況

RoPEを使う現代的モデルではキー復元が必要になり、速度面では悪化する例がある。圧縮率を強くするとパープレキシティとゼロショット精度が悪化し、追加微調整が必要になる場合もある。評価は注意層単体の遅延を含むため、60%という値をサービング全体の高速化とみなしてはいけない。コードは公開されているが、論文時点ではvLLM等の大規模サービング基盤への統合評価は中心ではない。
