# Visual Cache Reuse for Efficient Multimodal Inference

> 似た画像のKVキャッシュを、エントロピーの低いパッチは再利用し、注意の高い非一様パッチは再計算し、残りをマスクする近似再利用で活かし、完全一致と近似で階層管理を分けることで、視覚言語モデルのプリフィルを品質を保ちながら減らすサービング系。

## 概要

視覚言語モデル（画像を視覚トークン列へ変換し、テキストとつないで処理するモデル）の推論では、視覚入力が遅延とメモリの主因になる。高解像度の画像は数千の視覚トークンを生み、プリフィル（最初の出力の前に全入力を処理する段階）の注意計算は入力長の二乗で増え、そのKVキャッシュ（過去トークンのキーとバリューを保持して再計算を省く仕組み）はGPUメモリを圧迫する。著者らの測定では、32B級モデルでプリフィル遅延は入力長とともに急増し、視覚エンコードの約2.5倍へ達する。

再利用の既存手段はプリフィックスキャッシュと、その発展形である位置非依存キャッシュである。後者は画像が列のどこに現れても、同一画像ならKVを再利用し、位置の変化でずれる分だけ一部の視覚トークンを再計算する。しかしどちらも視覚トークン列の完全一致が前提であり、現実のワークロードに多い「大部分は同じだが一部だけ変わった画像」はミスとして扱われる。画面の一部部品だけが変わるスクリーンショット、体裁を保って内容の一部が変わる文書改訂、前景だけが動く連続フレームがその典型である。実運用トレースの標本では、類似度0.8を近似再利用の基準にすると、ヒット率はキャッシュ容量1024ギガバイトで35.6パーセントから56.1パーセントへ、8192ギガバイトでは63.5パーセントまで上がる余地があった。

ただし近似再利用は危うい。全体の類似度が高くても、変わった小さな領域が現在の質問の答えそのものかもしれない。再利用した視覚表現は、前に置かれたテキスト側プリフィックスとの相互作用も古いままである。本論文のVisMemoは、この危険を二つの信号の分離で扱う。パッチのエントロピー（画素のばらつきから測る情報量）で「再利用しても崩れにくい場所」を判定し、序盤の数層を通常実行して得た注意で「現在の質問に効く場所」を判定して再計算へ回す。残りはマスクして使わない。システム側では、完全一致ヒットと近似ヒットで読み取り方と保持方針を分け、大容量の階層に近似側の候補プールを広げる。実機のサーバーで実運用トレースと公開ベンチマークを使って評価した実機研究である。

**代表結果:** 実運用トレースで全体のキャッシュヒット率は27.78パーセントから61.45パーセントへ上がり、入力8Kトークンでは近似ヒットがミスのプリフィル遅延を最大48.3パーセント減らした。品質では、近似ヒットの回答品質がデータセットごとに強い比較対象より最大19.72ポイント高く、5データセット平均の総合スコアは70.81で最良の比較対象平均を4.77ポイント上回った。

## 問題設定

問題は、一致の粒度と品質リスクの不整合である。完全一致の世界では、画像単位のハッシュが再利用の可否を決めるため、99パーセント同じ画像でも1パーセントの差で全量プリフィルへ落ちる。一方で近似を許すと、可否の判定は画像単位では足りず、パッチ単位で「どこが同じで、どこが答えに効くか」まで降りる必要がある。著者らは素朴な方法の失敗を三つに整理している。第一に全量再利用は、変わったテキスト側プリフィックスとの相互作用を計算せず、変わった画像領域の古い表現もそのまま使う。第二に画素単位のパッチ照合は、画像全体が少しずれるだけで同じ内容が別のパッチへ移り、再利用できる場所を無いものと判定する。第三に注意スコアだけで再計算対象を選ぶ方法は、視覚トークンの吸収現象に弱い。余白のような情報の乏しいパッチが不釣り合いに高い注意を集めるため、予算が無情報な場所へ流れ、肝心の内容側の再計算が痩せる。

資源の観点ではもう一つの不整合がある。近似再利用が効くほど、保持すべき候補プールは大きくなる。完全一致ヒットは再利用間隔が短く、実測では約82パーセントが3分以内に再訪するのに対し、近似ヒットは間隔が長く裾が重く、6分以内は約46パーセントにとどまり、21分を超えるものが20パーセントを超える。同じ保持方針で扱うと、近似側の候補が上位階層を汚染し、完全一致側の強い局所性を壊す。さらに既存の階層構成では、エンジン側と保存側が同じKVのコピーを二重に持ち、OSのページキャッシュ経由の読み書きがメモリ圧迫と尾部遅延を生む。本論文の着眼点は、アルゴリズム側の「危険度と関連度の分離」と、システム側の「ヒット種別ごとの管理の分離」を対にして設計することにある。

## 手法のあらまし

VisMemoの流れは、検索、選択、管理の三段からなる。要求が届くと、まず画像ハッシュで完全一致を探し、外れた場合は符号器キャッシュに対して二段階の近似検索を行う。粗い段では画像を2掛ける2の4領域へ分け、領域ごとの平均埋め込みの類似度で候補を最大5件へ絞り、細かい段ではパッチ埋め込み同士の類似度の平均で最良の近似画像を1件選ぶ。近似が見つかると、エントロピー配慮の選択が働く。入力画像と近似画像の両方で一様かつエントロピーの低いパッチを再利用候補とし、最初の3層を通常実行して集めた注意で、非一様なパッチの中から注意の高いものを再計算率30パーセント分の再計算対象として先に確保する。残りの候補からエントロピーの低い順に再利用率分のパッチを再利用へ回し、それ以外は後段の層でマスクする。管理側では、完全一致ヒットは全量読み取りと優先保持、近似ヒットは再利用分だけのパッチ単位の疎な読み取りという別経路を通り、事前に置かれた定番画像向けにはCPU側に予約した犠牲キャッシュを別枠で保持する。保存の土台は、エンジンと保存側で分かれていたメモリを統合し、複製コピーとページキャッシュ経由の移動を消した統合バックエンドである。その後、全ての要求は通常のデコードへ合流する。

## 手法

### 1. 二段階の符号器キャッシュ検索 — 近似候補を安く見つける

この機構が観測するのは、視覚埋め込みの類似度である。全候補とパッチ単位で比べる方法は、符号器キャッシュが数千トークン規模になるためプリフィルの臨界経路には重すぎる。そこで保持する状態として、各画像について4領域の代表埋め込みだけを粗い検索用に用いる。行う動作は二段構えである。粗い段では、視覚トークン数と格子の縦横比が一致する画像群の中で、4領域全ての代表埋め込みの余弦類似度が閾値0.8を超えた候補だけを通し、平均類似度で最大5件を残す。細かい段では残った候補の全パッチ埋め込みを取り寄せ、対応位置同士の余弦類似度の平均が最も高い画像を近似相手として選ぶ。減るボトルネックは検索そのものの費用であり、4回の代表比較で大半の候補を落とせる。追加で消費する資源は、細かい段で候補最大5件分の埋め込み読み取りである。失敗条件は、格子の形が違う画像同士はそもそも比較対象にならないことと、閾値を超える候補が無い場合は通常のミスとして全量プリフィルへ落ちることであり、その場合は追加費用だけが残る。検索の遅延は近似ヒットのプリフィル内訳でも測られており、全体に占める割合は探索と序盤実行を合わせて入力1Kトークンで約10パーセント、8Kトークンで約19パーセントだった。

### 2. エントロピー配慮のKV選択 — 危険度の低い場所を残し、効く場所を作り直す

この機構が観測するのは二種類の信号である。一つ目はパッチの画素の最大チャネル範囲とグレースケールのエントロピーで、両画像で一様かつエントロピーの低いパッチだけが再利用候補に入る。入力側でも一様であることを必須にするのは、近似画像では空白だった場所へ入力側で文字や数値が新たに現れた場合に、古い表現を誤って残さないためである。二つ目は序盤3層を通常実行したときの最終層で、各視覚パッチが受けた注意を正規化した重要度である。正規化は、早い位置のパッチほど後続の多くから見えるという位置の偏りを除くために行う。行う動作の順序が要点で、まず再計算集合を決め、次に再利用集合を決める。再計算は非一様なパッチの中から注意の高い順に予算を取り、非一様パッチが予算に満たない場合だけ外側から補充する。これにより、注意を集めがちな一様な余白が再計算予算を食う吸収現象を構造的に避ける。再利用は、再計算集合を取り除いた候補の中から、両画像のエントロピー合計が低い順に選ぶ。後段の層では、再計算対象は現在のプリフィックスで計算し直し、再利用対象は保存済みKVを使い、どちらでもない視覚パッチは疎な注意マスクで除外する。再計算が再利用より優先されるため、エントロピーは低くても現在の質問で強く注意されるパッチは作り直される。減るボトルネックは視覚プリフィルの計算量であり、追加で消費する資源は序盤3層の通常実行と、エントロピー情報の保持である。失敗条件は、エントロピーが低くても意味の変わるパッチ、例えば均一な色面の差し替えであり、これは注意側の再計算で拾う設計だが、序盤層の注意に現れない変化は取りこぼしうる。感度分析では再利用率を上げすぎると比較的エントロピーの高いパッチまで再利用へ入り、品質が下がることが確認されており、再利用の積極さには明確な天井がある。

### 3. 差別化した階層管理 — ヒットの種類で読み方と残し方を変える

この機構が観測するのは、ヒットの種類ごとの時間局所性と転送量の違いである。保持と読み取りの動作は三つに分かれる。第一に読み取りの分離で、完全一致ヒットはKV全体を全量読み取りし、近似ヒットは再利用集合のパッチについて後段層分だけを疎に読み取る。転送量は、完全一致が層数とパッチ数に比例するのに対し、近似側は序盤層を除いた層数と再利用パッチ数にだけ比例する。保存側はパッチ優先の配置にしておき、CPU階層は選ばれたパッチだけを送り、SSD階層は対応するバイト範囲だけを読む。部分的に読まれた近似相手の項目は上位階層へ昇格させないため、完全な項目が部分アクセスで押し出される汚染が起きない。第二に保持の分離で、完全一致側には保護予算付きの優先保持を与える。追い出しの対象になっても予算の範囲で最近使用側へ戻し、近似でしか当たらない項目から先に追い出す。予算に上限があるため、古い完全一致項目が無期限に居座ることもない。第三に定番画像向けの予約枠で、事前に置かれる定番画像はアクセスが散らばって局所性が弱いため、通常のCPUキャッシュとは別の犠牲キャッシュへ入れ、保持の優先度をオフラインのワークロード事前分布とオンラインの再利用実績で決める。再利用実績のない項目には冷たい事前分布を、実績のある項目には繰り返し側の事前分布を使う。減るボトルネックは転送量と上位階層の汚染であり、追加費用は予約枠の容量と優先度管理である。失敗条件は事前分布が実ワークロードとずれる場合で、その場合は予約枠の保持が外れるが、通常経路の正しさには影響しない。

### 4. 統合メモリとストレージの土台 — 複製コピーとページキャッシュを消す

この機構が扱うのは、推論エンジンと保存バックエンドの間のメモリ経路である。既存構成では、保存側のSSD読み書きがOSのページキャッシュを通るため、明示管理するDRAMキャッシュとページキャッシュが同時に育ってメモリ上限へ近づき、ページの回収処理が推論を止める。また、保存側からエンジン側へ移したKVのコピーが両側に残って実効容量を減らし、符号器キャッシュには専用のメモリプールがなく、固定用の作業バッファを経由する余分なコピーが入る。行う動作は、KVキャッシュと埋め込みキャッシュを一つの統合メモリプールで管理し、可変長割り当てと索引、配置、追い出し、昇格を一元化することである。KVの書き込みは専用カーネルでGPUから最終配置へ直接送り、読み取りは復元カーネルが全体復元とパッチ選択復元の両方を行える形で返す。埋め込みはコピーエンジンで非同期に運び、中間の作業バッファを消す。SSD側は直接入出力でページキャッシュを迂回し、非同期のまとめ書きと複数シャードの並列入出力、明示的なDRAM受け入れ制御で運用する。減るボトルネックはメモリ圧迫による停止と無駄なデータ移動であり、効果は比較で測られている。近似ヒットのプリフィル遅延は、元の保存構成に対して入力2K、4K、8Kトークンでそれぞれ29.7パーセント、34.0パーセント、34.0パーセント程度下がった。失敗条件は明示管理の複雑さが実装側へ移ることであり、OSに任せていた緩衝を自前で持つ分、受け入れ制御の設計が性能を左右する。

## 評価

### まず見るところ

結論として、VisMemoは近似再利用を「品質を落として速くする」交換ではなく、選択の信号を分けることで品質側でも比較対象を上回った。近似ヒットの品質改善は、文書理解系で特に大きく、情報図表の質問で19.72ポイント、文書の質問で17.27ポイント、実運用会話で16.14ポイントを強い比較対象より上回った。完全一致ヒットの品質は最良の比較対象から0.68ポイント以内に収まり、近似の導入が完全一致側を壊していない。効率側の読み方として、利得は入力が長いほど大きい。8Kトークンでは近似ヒットがミス比で44.6パーセントから48.3パーセントのプリフィル削減になる一方、2Kトークンでは削減が1割前後にとどまり、1モデルでは2Kトークンで近似ヒットがミスより遅くなる逆転もあった。検索と序盤実行と再計算という固定費を、節約できるプリフィル量が上回るかどうかが分岐点であり、短い入力へそのまま外挿はできない。評価は実機であり、品質と効率の両方を同じ要求順序と比較条件で測っている点が強い。

内訳の読み方も重要である。近似ヒットのプリフィルでは選択的再計算が支配的で、視覚列1Kで67ミリ秒、8Kで128ミリ秒を占める。つまり近似再利用の費用の中心は読み取りではなく「作り直す分」であり、再計算率の設計が効率と品質の両方を決める。システム最適化の積み上げでは、定番保持で9.14パーセント、疎な読み取りで累積34.15パーセント、読み取りと序盤実行の重ね合わせで41.47パーセント、最終的なアクセス経路の最適化までで61.83パーセントの累積削減となり、アルゴリズム単体ではなく土台側の寄与が大きいことも分かる。

## 既存研究との差

視覚トークンの枝刈りや統合を行う先行研究は、要求内の計算を減らすのに対し、本論文は要求をまたぐ再利用の範囲を広げる。位置非依存キャッシュの先行方式は、同一画像の再利用でずれる分を再計算で吸収するが、一致の前提自体は完全一致のままだった。本論文は一致を近似へ広げ、その代償として必要になるパッチ単位の危険度判定を、エントロピーと注意という別々の信号へ分解した。階層KV管理の先行研究が汎用の階層を効率化するのに対し、本論文は完全一致と近似というアクセス形態の違いに合わせて読み取りと保持を分けた点が異なる。特に、部分的に読んだ項目を昇格させない、定番画像を別枠で保持するという判断は、近似アクセス特有の汚染と長い尾への対処として位置づけられる。

## 限界・実装状況

論文から読み取れる制約は次のとおりである。第一に、近似再利用は本質的に品質リスクを持ち、エントロピーと注意の二信号でも、序盤層の注意に現れずエントロピーも低い意味変化は取りこぼしうる。評価は5データセットの範囲であり、あらゆる画像種別での安全性を示すものではない。第二に、利得は入力長に強く依存し、短い入力では固定費が節約を上回って逆転する条件がある。第三に、再計算率や再利用率、類似度閾値は固定の超パラメータであり、最適な再利用率は既定値の10パーセントではなく15パーセント付近にあった。ワークロードに応じた自動調整は示されていない。第四に、近似検索は格子の形が一致する画像同士に限られ、解像度や縦横比の異なる画像間の再利用は対象外である。実装はSGLangとMooncake系保存の拡張として作られており、論文中に公式コード公開URLは確認できなかった。

## 一般的な実装上の含意

再利用できる原理は三つある。第一に、近似を許す場合は、一致の可否を一つの類似度で決めず、「崩れにくさ」と「現在の要求への効き具合」を別の信号で測って組み合わせるべきである。第二に、ヒットの種類で時間局所性と転送量が違うなら、読み取り方と保持方針も分けるべきであり、一様な階層方針は片方の性質に引きずられる。第三に、再利用率の拡大は容量の問題として現れる。近似側の候補プールは下位の大容量階層に置き、上位階層の局所性を守る配置が、ヒット率と遅延の両立に要る。
