# Compressing Long Context into Answer-Aligned Memory Embeddings for LLM Inference

## 書誌情報

Md Mostafizer Rahmanらによる2026年の研究で、一次資料は arXiv:2609.25537 である。長文脈そのものを短い連続埋め込み列へ圧縮し、凍結した任意のデコーダへ渡すことで、注意計算量とKVキャッシュ容量を同時に減らす文脈回答整合記憶圧縮を扱う。

## 概要

長文脈推論では自己注意の計算量が文脈長に対して二次的に増え、KVキャッシュは線形に増える。CMCは長文を少数の文脈記憶埋め込みへ変換し、質問に関係する記憶と直近の原文だけをデコーダへ与える。9通りのエンコーダ・デコーダ組合せと4質問応答ベンチマークで、SQuADの完全一致を比較対象より最大7.3点、F1を最大4.0点改善し、3,000生成トークン時に推論時間・エネルギーを最大20%、予約GPUメモリを最大50%削減した。

## 問題設定

既存の長文脈圧縮には、質問を見ずに固定的な記憶を作る方式、回答に必要な情報を直接教師として使わない方式、特定デコーダ内部へ圧縮器を密結合する方式がある。圧縮率だけを高めると回答根拠を失いやすく、逆に原文を多く残すとKV容量と注意計算の利点が小さくなる。

著者らは「何を記憶へ圧縮するか」と「質問時にどの記憶を使うか」を分離する。さらに圧縮表現をデコーダの入力埋め込み空間へ合わせれば、デコーダ重みを変更せずに異なるモデルへ接続できると考える。これにより圧縮器の再利用性と回答品質の両立を狙う。

## 手法

### 1. 文脈記憶埋め込みの生成

長い文書をエンコーダへ入力し、複数トークンの情報を少数の文脈記憶埋め込み（Context Memory Embeddings; CME）へ集約する。圧縮器の出力次元は凍結デコーダの入力埋め込み空間へ整合されるため、CMEを通常のトークン埋め込みに近い連続表現としてデコーダへ渡せる。

入力は長文脈、処理はエンコーダによる圧縮と射影、出力は短いCME列である。圧縮が強過ぎれば細部が失われるため、単に文書再構成を目指すのではなく、回答生成に必要な情報を優先する訓練目標を後段で加える。

### 2. 回答対象蒸留

凍結した教師LLMが回答生成時に示す情報を用い、圧縮器が回答に有用な表現を作るよう蒸留する。これにより、文書全体を均等に保存するのではなく、質問応答で必要になる意味情報をCMEへ集める。デコーダ本体は固定したままなので、学習対象は主として圧縮側になる。

この設計は圧縮率と回答品質のトレードオフを緩和するが、教師モデルが重要情報を正しく反映しない場合、その偏りも学習され得る。また質問応答向けの教師信号であるため、自由生成や厳密な全文復元など別用途への一般化は個別に確認する必要がある。

### 3. 質問誘導記憶選択

推論時にはすべてのCMEを無条件にデコーダへ渡さず、質問表現との関連度から必要な記憶を選ぶ。入力は質問とCME集合、処理は関連度計算と選択、出力は質問に対応する小さな記憶集合である。質問が変われば同じ文書でも選ばれるCMEが変わる。

この段階によって圧縮後の記憶数をさらに絞り、デコーダ側の注意計算とKV保持量を削減する。選択が外れれば必要根拠を失うため、圧縮器の表現品質だけでなく質問との照合品質が回答精度を左右する。

### 4. 二層KV構成

CMCは選択したCMEだけで全履歴を置き換えず、直近の原文トークンを保持する局所文脈窓を併用する。上位層は長距離情報を圧縮したCME、下位層は最近の高解像度トークンという二層構成になり、長距離の容量削減と局所的な詳細保持を両立する。

生成が進むと局所窓は最新トークンへ更新され、遠い情報はCME側から参照する。質問誘導選択が不完全でも直近情報は原文精度で残るが、必要な古い細部がCMEに保存されていなければ復元できない。この失敗形態が圧縮方式の本質的な限界になる。

## 評価条件

評価は9通りのエンコーダ・デコーダ組合せと4つの質問応答ベンチマークで行い、異なるモデル間でも圧縮表現が機能するかを確認する。SQuADなどで完全一致とF1を測り、品質だけでなく推論時間、エネルギー消費、予約GPUメモリのピークを測定する。

長い生成を続けたときのKV容量効果を見るため、3,000生成トークン条件も評価する。比較では圧縮なしだけでなく既存の軟圧縮方式を置き、質問誘導選択、回答対象蒸留、局所窓など各構成要素を除いたアブレーションも行う。

## 主要結果

SQuADでは比較対象に対して完全一致が最大7.3点、F1が最大4.0点改善した。単に文脈を短くするだけでなく、回答対象の蒸留と質問依存選択によって、圧縮表現の情報密度を高めたことが品質改善へ寄与する。9組合せで一貫した改善傾向を示し、特定デコーダだけへの密結合ではないことを確認する。

3,000生成トークン条件では、推論時間とエネルギー消費を最大20%削減し、予約GPUメモリのピークを最大50%削減した。長文脈を短いCMEへ置き換えることでデコーダが保持・参照するKV量を減らし、生成が長くなるほど容量面の利得が表れやすい。

## 既存研究との差

従来の軟圧縮は固定要約やデコーダ固有の圧縮トークンへ依存することがあり、推論時の質問に応じた記憶選択が弱い。CMCは回答を教師とした圧縮、質問誘導選択、局所原文窓を一つの構成へまとめ、さらに凍結デコーダの埋め込み空間へ出力を合わせることで接続性を高める。

## 限界と実装状況

質問応答を中心に評価しているため、長文生成、コード、厳密な引用、全履歴を逐語的に必要とする課題で同じ品質を保証するものではない。圧縮時に失われた情報は後からKVキャッシュだけでは復元できず、質問選択の誤りも回答へ直結する。また圧縮器自体の前処理コストがあるため、短い文脈では削減効果が小さくなる可能性がある。
