# GEAR: An Efficient KV Cache Compression Recipe for Near-Lossless Generative Inference of LLM

## 概要
KV行列を一様量子化すると外れ値と構造化誤差が自己回帰生成で蓄積する問題に対し、通常成分の低ビット量子化、量子化誤差の低ランク近似、外れ値誤差の疎行列補正を組み合わせる。4ビットKVで近損失品質を保ち、最大2.38倍のスループット、最大2.29倍のピークメモリ削減を報告する。

## 問題設定
KVキャッシュは文脈長とバッチに比例して増え、長文脈生成ではGPUメモリ容量と帯域を圧迫する。一様量子化は容量を直接減らせるが、KVには外れ値があり、単一スケールで低ビット化すると通常値の分解能か外れ値のどちらかを犠牲にする。さらに自己回帰生成では各ステップの注意出力誤差が次のクエリへ影響し、量子化誤差が連鎖する。

## 手法
GEARはKV行列の大部分を超低ビットへ量子化し、まず主要な容量削減を得る。その後、元行列と量子化行列の残差をそのまま高精度保存するのではなく、構造化された誤差を低ランク行列で近似する。量子化誤差に相関構造がある場合、少数ランクで多くを回収できる。

低ランク近似だけでは個別に大きい外れ値誤差を表現しにくいため、残る大振幅要素を疎行列として別に保持する。したがって表現は「低ビット量子化本体＋低ランク補正＋疎補正」となり、密な高精度KVを残すより小さい追加容量で誤差を抑える。

デコード時には量子化本体の注意計算へ補正成分を反映する。補正には追加演算が必要だが、KV読み出し量とピークメモリを減らす利得が長文脈・メモリ律速条件で上回る設計である。

## 評価
|項目|内容|
|---|---|
|対象|LLM自己回帰生成のKVキャッシュ|
|圧縮|代表設定4ビットKV|
|比較|一様量子化・トークン削除等のKV圧縮|
|指標|生成品質、スループット、ピークメモリ|

4ビットKV圧縮で近損失の生成品質を維持しながら、代替法に対して最大2.38倍のスループット改善、ピークメモリを最大2.29倍削減した。重要なのは、同じ低ビット化でも補正なし量子化より品質劣化を小さくする点であり、低ランクと疎補正が量子化単独の誤差モードを分担する。

## 既存研究との差
トークン削除法はKVそのものを捨て、量子化法は全要素を同じ低精度表現へ押し込む。GEARはKVを残したまま、量子化残差を「低ランクな共有構造」と「疎な外れ値」に分解して別形式で補正する。単一圧縮表現に全誤差を負わせない点が新規性である。

## 限界
低ランク分解と疎補正の作成・適用には追加計算とメタデータが必要で、短文脈や十分なHBMがある条件では速度利得が小さくなり得る。最適ランク、疎率、量子化ビットはモデルと層に依存する。近損失は評価範囲での結果であり、任意の長さ・タスクで完全精度と同一出力を保証しない。
