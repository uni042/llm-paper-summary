# GEAR: An Efficient KV Cache Compression Recipe for Near-Lossless Generative Inference of LLM

## 概要
GEARは、自己回帰生成で増え続けるKVキャッシュを高い圧縮率で保持しつつ、単純な低ビット量子化で生じる生成品質の崩壊を抑えるための圧縮法である。着眼点は、量子化誤差を一種類の補正だけで扱わず、誤差の性質に応じて「低ビット量子化本体」「低ランク補正」「疎な外れ値補正」の3成分へ分担させることにある。通常振幅の大多数の要素は超低精度へ量子化し、量子化後に残る相関した誤差を低ランク行列で近似し、さらに少数の大きな誤差だけを疎行列として保持する。

KVキャッシュは系列長・batch・層数に比例して増えるため、長文脈や高並列生成ではモデル重みよりもキャッシュがHBMを圧迫することがある。しかも自己回帰生成では、あるstepのKV近似誤差がattention出力を変え、その出力が次stepのquery生成へ影響する。したがって単発の再構成誤差が小さくても、長い生成では誤差が累積しやすい。GEARはこの「逐次誤差蓄積」を圧縮設計の中心問題として扱う。

## 問題設定
既存のKV圧縮には、重要でないtokenを捨てる方法と、全要素を均一またはgroup-wiseに量子化する方法がある。token削除は容量を直接減らせる一方、後段で必要になる情報を不可逆に失う。量子化は全tokenを残せるが、KVには通常値から大きく外れた要素や、層・head内で相関した誤差構造があり、単一の量子化表現へ押し込むと通常値の分解能と外れ値の表現を同時に満たしにくい。

GEARは「量子化で大半を安価に表現し、量子化が苦手な誤差だけを別形式で持つ」ことでこの衝突を避ける。圧縮率だけでなく、圧縮されたKVを使って生成を続けたときの最終task品質まで評価する点が重要である。

## 手法

### 1. 低ビット量子化本体
まずKVキャッシュの大多数の要素を低ビットへ量子化する。ここでの役割は容量削減の大部分を担当することであり、全誤差をこの量子化だけで吸収しようとはしない。低ビット化するとKV読み出し量が減るため、メモリ帯域律速のdecodeでは転送量削減がそのままスループット改善へつながりやすい。

一方でビット数を下げるほど量子化残差は増える。特に外れ値に合わせて量子化範囲を広げると通常値の刻み幅が粗くなり、通常値に合わせると外れ値が大きく崩れる。この残差を次の2成分へ分解する。

### 2. 低ランク補正
量子化後の残差には、headやfeature方向に共通する相関構造が含まれる。GEARはこの構造化誤差を低ランク行列で近似する。入力は元のKVと量子化KVとの差分で、内部では少数rankの因子へ圧縮し、decode時には低ビットKVにこの補正を加える。

低ランク補正が効くのは、誤差が完全な独立ノイズではなく少数の方向へ集中しているためである。密なFP16残差を保存するより大幅に小さい容量で広範囲の誤差を回収できる。ただしrankを増やすと再構成精度は上がる一方、追加メモリと行列演算が増えるため、圧縮率と計算量のtrade-offになる。

### 3. 疎な外れ値補正
低ランク近似は全体的な相関構造には強いが、少数だけ極端に大きい個別誤差を効率良く表現しにくい。そこで残差のうち大振幅な要素だけを疎行列として保持する。これにより低ランク因子を外れ値へ合わせて不必要に大きくする必要がなくなる。

この成分は「どの位置に補正が必要か」とその補正値を保持するため、疎率を上げれば品質は改善するがindex等のメタデータも増える。GEARの設計は、量子化・低ランク・疎補正を独立に最大化するのではなく、同じメモリ予算内で3成分を組み合わせる点にある。

### 4. decode時の復元
decodeでは圧縮されたKVを読み出し、量子化本体に低ランク・疎補正を反映してattention計算へ供給する。追加補正演算は発生するが、長文脈・大batchではKV転送量削減の利得が大きく、メモリ律速を緩和できる。逆に短文脈や小batchでは、元々KV帯域が支配的でないため補正演算の固定費が相対的に目立ちやすい。

## 評価

### 品質評価
論文はLLaMA系を含む生成モデルで、推論taskの最終精度とperplexityを用いて圧縮品質を比較する。重要なのは再構成誤差だけではなく、圧縮KVを逐次利用した生成結果そのものを測ることである。

arXiv版は4-bit KVでFP16に近い生成品質を保ちつつ、代替法より良い性能を報告する。後のNeurIPS EfficientNLP Workshop / PMLR版ではより厳しい2-bit圧縮でも、既存のstate-of-the-art KV圧縮法に対して最大24.42 percentage pointの精度改善を報告している。これは低ランク補正だけ、あるいは外れ値処理だけでは取り切れない誤差を3成分で分担する設計が、極低bit領域で特に効くことを示す。

### システム性能
arXiv版では4-bit設定で最大2.38倍のthroughput改善と最大2.29倍のピークメモリ削減を報告している。後のPMLR版ではFP16 KVキャッシュ比で最大2.39倍のピークメモリ削減、2.1〜5.07倍のthroughput改善が報告されている。版と実験設定が異なるため、これらの最大値を同一条件の単一結果として混同してはいけない。

機構との対応では、低ビット本体がKV転送量と容量を直接削減し、低ランク・疎補正が低ビット化で失われる品質を回復する。そのため「単純量子化より高い品質を維持しつつ、FP16より大きいbatchや長いcontextを収容できる」ことがシステム利得へつながる。

## 既存研究との差
token eviction型はKV要素そのものを捨てるため、将来必要になる情報を復元できない。単純量子化型は全要素を同一形式で表すため、通常値と外れ値を同時に低誤差で表現しにくい。GEARはKVを保持したまま、圧縮誤差を「広く分布する構造化誤差」と「少数の大きな局所誤差」に分け、それぞれ低ランク・疎表現へ割り当てる。

この意味でGEARの新規性は量子化そのものではなく、量子化残差の構造を利用した誤差削減レシピにある。

## 限界
GEARは低ランク因子の生成、疎補正位置の管理、decode時の補正適用を必要とするため、純粋な低ビットKVより実装が複雑である。rankや疎率を増やせば品質は改善しやすいが、メモリ削減率と追加演算の利得が減る。

また、throughput改善はKV読み出しが支配的な条件で大きい。短context、小batch、あるいは別のkernelや通信が支配的な環境では、同じ倍率を期待できない。近損失という表現も評価したモデル・task・bit幅の範囲での結果であり、任意の生成分布でFP16と同一出力を保証するものではない。
