# Grouped Value Attention: Efficient KV Caching via On-Demand Key Reconstruction

> 値だけをKVキャッシュへ保存し、内容キーを値から再構成してクエリ側へ吸収することで、GQAに近い精度を保ちながら永続キャッシュを約45〜47%削減する注意機構。
## 書誌情報
- **著者**: Vishesh Tripathi, Abhay Kumar, Ramsha Khan
- **公開**: arXiv
- **種別**: Preprint
- **対象**: KVキャッシュ、GQA、キー再構成、メモリ帯域
- **実装**: 専用デコードカーネルを開発済みだが推論性能評価中で、公開ソースは今後予定。
## 概要
Grouped Value Attention（GVA）は、グループ化クエリ注意（GQA）が各トークンでキーと値の両方を保存するため長文脈デコードのKVキャッシュ容量と読出し帯域が増える問題に対し、グループ化した値だけを永続保存し、各クエリヘッド固有の内容キーを値から線形写像で再構成する。推論時には固定写像をクエリ側へ吸収できるため内容キーを実体化せず、位置情報だけを小さな共有RoPEチャネルとして別保存する。評価構成ではGQA比で永続キャッシュスカラーを約45〜47%削減し、350Mモデルを30Bトークン学習した16次元位置チャネル版で5課題平均44.35%とGQAの44.36%にほぼ一致した。

GVAは値を注意出力に必要な永続内容状態として残し、内容キーを各値グループからヘッド固有の学習済み線形写像で再構成する。写像は推論時に固定なので内積の結合則によりクエリ側へ吸収でき、各過去位置の内容キーを生成・保存・読出しする必要がない。通常のRoPEは位置ごとの回転が写像吸収を壊すため、位置情報だけを小さな共有チャネルへ分離して保存する点まで一体で設計している。

代表結果として、永続キャッシュスカラー数は分離RoPE位置チャネルを持つGVA構成で同じGとd_hを持つGQAに対してGQA比約45〜47%削減。内容キーの永続ストリームを除き、値G本と共有位置キー1本だけを保存するため。
## 問題設定
自己回帰デコードでは新しいクエリだけを計算し、過去トークンのキーと値をKVキャッシュから毎ステップ読み直す。文脈長と同時要求数が増えると容量だけでなくメモリ帯域も支配的になる。GQAは複数クエリヘッドでキー・値ヘッドを共有してMHAより削減するが、各グループについてキーと値の2本のストリームを依然保存する。MQAはさらに共有を強めると品質や学習安定性を損ね得る。MLAは共同潜在表現へ圧縮できるが追加射影と複雑なデコード経路を伴う。そこで値の情報を保持したまま内容キーの永続保存だけを除けるかが課題になる。
## 新規性
GVAは値を注意出力に必要な永続内容状態として残し、内容キーを各値グループからヘッド固有の学習済み線形写像で再構成する。写像は推論時に固定なので内積の結合則によりクエリ側へ吸収でき、各過去位置の内容キーを生成・保存・読出しする必要がない。通常のRoPEは位置ごとの回転が写像吸収を壊すため、位置情報だけを小さな共有チャネルへ分離して保存する点まで一体で設計している。
## 手法
### 手法のあらまし
H個のクエリヘッドをG個の値グループへ割り当て、各トークンではグループ化値Vだけを内容キャッシュへ書く。ヘッドhの内容キーはK_h=V_g(h)M_hとして定義し、M_hをヘッドごとに学習するため、GQAのように同じグループ内で内容キーまで共有せずH個の異なるキー表現を得られる。デコード時のスコアqK^Tは(qM^T)V^Tへ厳密に変形できるので、現在クエリを一度変換して値キャッシュへ直接内積すればよい。位置情報については内容部分へ通常RoPEを適用すると位置ごとの回転がMとの間へ入り吸収不能になるため、内容スライスは非回転、短い位置スライスだけをRoPE回転し、その位置キーを全ヘッドで共有してキャッシュする。各デコードステップでは現在隠れ状態からクエリと新しいグループ値を計算し、その値だけを既存キャッシュ末尾へ追加する。同時に共有位置キーを1本追加する。各ヘッドは内容クエリへM_h^Tを掛け、過去の値列との内積を直接計算し、位置クエリと共有位置キーの内積を加算して注意スコアを得る。そのソフトマックス重みで同じ値キャッシュを集約するため、内容キーの一時テンソルも永続ストリームも不要になる。結果として永続状態はTGd_h+Td_rとなり、GQAの2TGd_hに対して約半分へ近づく。学習初期には二段射影で再構成キーの尺度が小さくなり注意が均一化したため、Mの初期分散をクエリとキーのRMSが合うよう補正する。単純K=V方式が失敗した場合はこのヘッド別写像が内容キーの役割分離を回復し、通常RoPEが吸収を壊す問題は位置チャネル分離が回避する。

### 値からのヘッド別キー再構成
各値グループV_gから、クエリヘッドhごとに異なる線形写像M_hを使って内容キーK_hを得る。値は注意出力へ集約されるため保存が不可欠だが、キーはスコア計算だけに使うので値から導出できれば永続化する必要がない。単純にK=Vとした初期案はキャッシュを半減できても学習損失がGQAへ追いつかなかった。ヘッド別写像を追加すると値を共有しながらキーの多様性を復元でき、GQAより少ない永続状態でH個の内容キー表現を維持する。写像パラメータは系列長に依存しないため、長文脈ほどキャッシュ削減効果が相対的に大きくなる。

### クエリ側への写像吸収
推論時にM_hは固定なので、q_h(vM_h)^T=(q_hM_h^T)v^Tという厳密な等式を利用する。現在トークンのクエリを一度だけ変換し、その後は過去全位置の値キャッシュへ直接内積するため、内容キーを位置ごとに再構成した一時テンソルすら作らない意図の融合デコード経路になる。これにより永続容量だけでなく、各デコードステップでメモリから読む内容ストリームもキー＋値の2本から値1本へ減らせる。ただし本論文では専用カーネルのエンドツーエンド速度をまだ報告しておらず、帯域削減が実測速度へどこまで変換されるかは今後の評価事項である。

### 分離RoPE位置チャネル
通常の回転位置埋め込みを再構成キー全体へ適用すると、クエリ位置と過去位置の相対回転がM_hとの間に入り、単一の変換済みクエリへ吸収できない。そこでクエリ・キーを非回転の内容スライスと短い回転位置スライスへ分ける。内容スライスは値から再構成してクエリ側へ吸収し、位置キーだけを各トークンで別途保存する。位置キーは全ヘッド共有なので追加量はTd_rだけで、G個分には増えない。16または24次元という小さな位置幅で位置情報を維持しつつ、GQA比約45〜47%の永続キャッシュ削減を実現する。

### 全体のデータ／制御の流れ
学習時は通常の因果注意として値射影、ヘッド別再構成写像、分離位置チャネルを共同学習する。デコードでは現在隠れ状態からクエリと値を計算し、新しい値をG本の値キャッシュへ追加する。位置キーを1本追加し、各クエリヘッドで内容クエリをM_h^Tにより変換する。変換済み内容クエリと値キャッシュの内積に、回転済み位置クエリと共有位置キーの内積を加え、ソフトマックス重みで同じ値キャッシュを集約する。出力形式は通常注意と同じで、上位Transformer層は変更を意識しない。
## 評価条件
- **ハードウェア**: 350Mパラメータ規模のデコーダ専用Transformerを評価。具体的GPU構成による推論性能は本稿では未報告。
- **ソフトウェア**: FineWeb-Edu 30Bトークンで一から学習。学習時の勾配スパイク抑制にZClipを使用。専用デコードカーネルは開発済みだが性能測定中。
GQA、MLA、単純なK=V共有方式、複数GVA変種を同じデータ順、トークン予算、最適化器、文脈長で比較する。各構成を異なる乱数種で3回学習し、HellaSwag、WinoGrande、OpenBookQA、ARC-Easy、ARC-Challengeのゼロショット精度を算術平均する。学習損失も追跡し、キャッシュ量はGQAの2TGd_hに対しGVAのTGd_h+Td_rとして理論スカラー数を比較する。
学習品質と永続キャッシュ表現の容量削減を実証する評価であり、実際の自己回帰サービングの遅延・スループット・ピークメモリは未評価である。著者は融合デコードカーネルを開発済みとしているが、GQAやMLAに対するエンドツーエンド速度比較は今後の課題として明示される。
## 主要結果
提案する分離RoPE版GVAは、GQAがキーと値の2ストリームを保存するのに対し、グループ化値と小さな共有位置キーだけを残すため、評価構成で永続キャッシュスカラーを約45〜47%削減する。16次元位置チャネル版の5課題平均精度は44.35%でGQAの44.36%との差は0.01ポイントに留まり、MLAの43.88%も上回った。ただし論文が実証したのは表現容量と学習品質までで、メモリ読出し削減が実際のデコード速度向上へ結び付くかは専用カーネル評価待ちである。

- 永続キャッシュスカラー数 / GQA比約45〜47%削減 (比較対象: 同じGとd_hを持つGQA; 条件: 分離RoPE位置チャネルを持つGVA構成) — 内容キーの永続ストリームを除き、値G本と共有位置キー1本だけを保存するため。

- 5課題平均ゼロショット精度 / 44.35% (比較対象: GQA 44.36%、MLA 43.88%; 条件: 350Mモデル、FineWeb-Edu 30Bトークン、位置幅16、3乱数種平均) — GQAとの差0.01ポイントで、著者は乱数種変動内と位置付け、品質勝利ではなく小キャッシュで近い品質を主張する。

- 最良GVA平均精度 / 44.41% (比較対象: GQA 44.36%; 条件: 尺度整合初期化＋クエリRMSNorm、分離RoPEなし) — キー再構成自体はGQA級品質を維持可能だが、この変種は推論時写像吸収を可能にする提案サービング構成とは異なる。

### 負の結果・境界条件
- 単純にK=Vとして同じベクトルへスコア計算と値取得の両役割を負わせる方式はキャッシュを半減できるが、学習損失がGQAへ回復しなかった。また標準初期化のGVAは再構成キーの尺度が小さく初期学習で悪化した。分離RoPE版も平均精度でGQAを上回っておらず、推論速度は未報告である。

### 結果の読み方
容量削減と品質維持の両立には、単なるキー削除ではなくヘッド別線形写像によるキー多様性の復元と、位置情報を小さな別チャネルへ逃がすことが必要だった。初期尺度を合わせることも学習安定性に重要である。
## 品質への影響
提案16次元位置版はGQAとの差0.01ポイントでほぼ同等だが、完全な無損失変換ではなく別アーキテクチャとして再学習するため、課題別精度には小さな増減がある。
## 既存研究との差
GQAはグループごとにキーと値を両方共有・保存するが、GVAは値だけをグループ化して保存し、各クエリヘッド固有の内容キーを線形写像で復元する。MLAはキーと値を共同の低次元潜在へ圧縮するのに対し、GVAは値そのものを永続内容状態として残すため値経路が直接的である。MQAのようにキー多様性まで単一共有へ落とさず、H個の再構成キーを維持する。
## 限界
本稿は350M規模・30B学習トークンでの品質評価であり、大規模LLMへ同じ精度差が維持されるか未確認である。最重要のシステム主張である自己回帰デコードの速度・実メモリ帯域・ピークメモリは専用カーネル評価中で未報告。分離RoPEの位置幅と内容幅の影響も完全には分離されていない。
## 実装状態
専用の融合デコードカーネルを開発済みでエンドツーエンド性能を評価中。著者はオープンソース公開予定としているが、確認時点では公開URL未提示。初期のK=V方式Lumma-0.6B-BaseはHugging Faceで公開されたが、最終GVAサービング実装とは異なる。
## 研究上の位置づけ
KVキャッシュ容量削減を量子化・枝刈り・オフロードではなく注意機構の表現そのものから行う系統に属する。GQAとMLAの間で、値のグループ共有による容量効率とヘッド別キー多様性を両立し、さらに推論時の線形写像吸収で内容キー読出しを消す。実測サービング速度が今後示されれば、KV容量とメモリ帯域を同時に減らすアーキテクチャとして重要になる。
