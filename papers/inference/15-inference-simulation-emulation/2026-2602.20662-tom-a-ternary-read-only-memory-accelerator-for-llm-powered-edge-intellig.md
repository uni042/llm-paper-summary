# TOM：三値重みを高密度ROM論理へ固定し、SRAM適応層を併用するエッジLLM専用アクセラレータ

## 概要

TOMは、三値重み（ternary weights）を持つ大規模言語モデル（LLM）をエッジ端末で低遅延・低消費電力に動かすための、読出し専用メモリ（ROM）と静的ランダムアクセスメモリ（SRAM）の混合専用回路である。重みを毎トークン外部メモリから転送する方式と異なり、**固定ベースモデルの重みをROMとしてオンチップへ焼き込み、各演算器の近くに分散配置する**。三値重みの0を物理的な記憶セルとして持たず、番地から非ゼロの出力ビットを生成する組合せ論理へ変換することで、高い記憶密度を狙う。

ROMへ固定したベース重みは製造後に書き換えられない。その制約を補うため、TOMはKVキャッシュと量子化された低ランク適応（LoRA）重みをSRAMへ保持し、ベース計算と適応計算を別経路で実行する。また、現在計算していない層のROMを細粒度に電源遮断し、電力を抑える。著者らのBitNet-2Bを用いた回路評価では、トークン間時間302.4マイクロ秒、すなわち理論上約3,306トークン/秒を報告する。**Verilogで記述した回路の論理合成・配置配線検証・サイクル精密シミュレーションの結果であり、量産チップやスマートフォン実機の測定ではない**ことが重要である。

本研究は量子化アルゴリズム単体の改善ではなく、重みの値域、記憶の物理実装、演算データフロー、適応重み、層単位の電源制御を共同設計する研究である。特に、三値化によって乗算を符号反転と加算に置き換えられる点と、重み0の多さをROM論理の簡素化に利用できる点を結び付ける。一方、固定ベース重みという性質、SRAMに収まる文脈長、モデルごとの回路再合成という制約が残る。

## 問題設定と設計上の前提

自己回帰復号では、各トークン生成時に全結合層の重みを繰り返し参照する。端末側のDRAM帯域と消費電力が制約となる場合、演算器の理論性能を高めても重み転送が律速になりやすい。オンチップSRAMは高帯域だが、数十億パラメータの重みを保存するには面積が大きすぎる。DRAMや高帯域メモリは容量を確保できても、低遅延の単一要求で必要な転送帯域と電力を同時に満たすことが難しい。

三値モデルでは重みが $\{-1,0,+1\}$ の三種類しかない。一般の2ビット符号化は各重みを固定幅で格納するが、ゼロ重みの多い行列を固定のROMセル配列へそのまま配置するとゼロにも面積が割かれる。著者らは三値の+1を`01`、-1を`10`、0を`00`と符号化することで、論理1を持つビットの割合を減らす。ゼロ重みの割合だけでなく、**符号化後のゼロビット率**が論理合成後の面積を左右する点が特徴である。

ROMの利点はベース重みが変化しない用途で最も大きい。頻繁な基盤モデル更新、利用者ごとのベース重み変更、学習中の全重み更新は想定外である。論文は「長期間固定する基盤重み」と「比較的頻繁に更新する適応重み」の二層に分けることで、この設計制約を緩和する。したがって、TOMの柔軟性はSRAM上のLoRA差分に限定され、ROMそのものが書き換え可能になるわけではない。

## 手法

### 1. 疎性認識ROM：重み行列を記憶セルではなく組合せ論理として表現

通常のROMマクロは固定サイズの行・列構造を持ち、ゼロビットであってもセル配置や配線が必要になる。TOMはROMを「入力番地から固定ビット列を返す論理関数」と見なし、Verilogの組合せ論理として重みを表現する。常に0となる出力はグラウンドへ直結し、論理1が必要な番地だけを合成する。EDAツールが共通部分式を統合することで、複数番地に共通するデコード条件も共有できる。

入力は固定された三値重みのビットパターンで、出力はアドレスに対応する重みビットである。追加のランタイム索引表を作って疎な位置を列挙するのではなく、**固定データそのものを回路最適化の対象**にするため、ゼロの位置を示すメタデータの読出しを避けられる。論文図6の例ではトランジスタ数を64から28へ減らす。ゼロビット率が高いほど効果が大きいが、論理の不規則性や配線の複雑化により面積改善が単純な比例にはならない。

ROMへ固定した値は書き換え不能であるため、モデルを更新する場合は新たな回路設計・製造、または別の適応経路が必要となる。製造後に生じる基盤重みの誤りを補正できる範囲もLoRAの表現力に依存する。これは汎用DRAM上に重みを置く実装とは本質的に異なる。

### 2. 分散処理レーンと行列ベクトル演算器

全重みを単一の巨大ROMへ集めると読出しポートが新しい帯域制約になる。TOMでは複数の処理レーン（processing lanes）へ重みを分割し、各レーン内に行列ベクトル演算器（MVU）を直列に並べる。各MVUは固有の重みROM、KVキャッシュ用SRAM、演算回路を持つ。活性ベクトルを順に流し、局所的な部分和を作る。各レーンは別の重み部分行列を処理し、全体の制御装置から同じ命令列を受ける。

各MVUの演算器は三値重み×FP8活性とFP8×FP8の二種類の行列ベクトル積を扱う。前者は主に全結合層、後者は注意演算を想定する。三値乗算は値が0なら加算せず、+1なら加算、-1なら符号反転して加算する。両経路は加算木を共有し、別々の大きな積和器を用意する面積を抑える。レーンごとのベクトル演算器（VU）は正規化、Softmax、活性化などに必要な除算・指数・平方根を処理する。

レーン間の通信を任意の全対全接続にせず、中央の縮約木（global reduction tree）を介して和や最大値を集約する。線形層では重みの入力次元を分割して局所積和を作り、縮約木で合算する。注意演算ではKVキャッシュを文脈方向に分割し、まず局所スコアと局所最大値を計算し、全体最大値を縮約してスコアを再尺度化する。その後、各レーンで重み付きVを計算し、最終和を全体縮約する。KVキャッシュがオンチップにある前提のため、GPU向けFlash-Decodingと異なり外部転送削減よりオンチップ演算・縮約を最適化する。

### 3. ROMベース重みとSRAM上LoRAの二経路実行

LoRAでは基盤重み $W$ に対し、低ランク行列 $A,B$ の積を差分として加える。TOMはROMにある $W$ を変更できないため、$Wx$ と $B(Ax)$ を別々に実行し、後段で足し合わせる。LoRAの二つの行列も三値に量子化し、KVキャッシュと共有するオンチップSRAMに置く。これにより適応重みを変更可能なまま、既存の三値×FP8演算器を再利用できる。

この構成は「ROMへ重みを固定しても、ある程度の個別化・補正を行える」という利点を持つ。しかしLoRAを実行するたびに追加の演算が発生し、SRAM容量をKVキャッシュと取り合う。さらにベース重みと差分を事前に合成してROMを書き換えることはできない。適応能力と追加のトークン間時間、面積、電力のトレードオフが残る。

### 4. 層ごとの動的電源遮断

全モデルの重みをオンチップROMへ置くと、実際には一層ずつ実行している間も他の層のROMが待機電力を消費する。TOMのROMは標準論理セルから作られているため、非使用層の電源を切り、次に使う層だけを事前に復帰させる。全体制御装置は層の実行順を把握しており、現在の層と次の層の電源を切り替える。論文はこの制御を「追加の推論遅延なし」で実現する設計として説明する。

この省電力機構は、単に計算器をクロック停止するのではなく、**重みを保持するROM論理ブロックの電源を層単位で遮断**する点に意味がある。ROMは固定論理なので電源を切っても重みデータが失われない。一方、同じ手法をSRAMのKVキャッシュへ適用すると保持内容が失われるため、SRAMとROMを同一視できない。省電力効果は層の活動率と電源制御の実装に依存する。

## 評価設定と再現可能性

主な評価モデルはBitNet-b1.58系の2Bパラメータモデルである。著者らはVerilog HDLで回路を記述し、Synopsys Fusion Compilerによる論理合成、PowerArtistによる電力推定、Verilatorによるサイクル精密シミュレーションを実施した。主要ROMモジュールには配置配線検証も実施し、面積・電力が合成見積りと5%以内の差であったと記す。ただし、これは全チップを製造して電力計で測定した結果ではない。

表Iの構成は500MHz、16処理レーン、レーン当たり10個のMVU、総ROM498.54MB、総SRAM37.5MB、各MVUの重み容量3180KB、KVキャッシュ容量240KB、重み三値、活性・KVキャッシュFP8である。表Iには**オンチップの最大文脈長1024トークン**と記載される。別の拡張実験では文脈長を2560トークンまで増やした場合も検討するが、同一の固定SRAM容量でそのまま対応できるという意味ではない。

汎用プロセッサの比較対象はIntel Core i5-12500Hで動くbitnet.cppと、NVIDIA A100 40GBで動くGPU最適化版bitnet.cppである。A100比較はTOMの狙う単一要求の低遅延用途に合わせ、バッチサイズ1を採用する。専用ASIC・メモリ内演算回路との比較では、モデル規模や工程が異なるため、演算処理量と電力を正規化した指標を使う。これらを同一条件のエンドツーエンド実測と混同してはならない。

## 主要結果

### ROM密度と面積

論文図9では2048×128のROMを対象に、ゼロビット率65%のとき記憶密度14.2MB/mm²、95%のとき25.3MB/mm²を報告する。別のバンク形状探索ではゼロビット率70%、幅128、深さ1024の構成で15.0MB/mm²が最大となる。同じ工程のメモリコンパイラで作った通常ROMとSRAMに比べ、それぞれ5.2倍、3.3倍の密度である。異なる工程との比較は7nm相当へ正規化しているため、実測面積を無補正で並べたものではない。

論文表IVでは全オンチップ容量536.04MB、集約内部帯域200TB/sを掲げる。これは多数のROMバンクを同時に読める**オンチップ集約帯域**であり、外部DRAMやPCIeを経由して200TB/s転送できるという主張ではない。全体のチップ面積は56.9mm²と見積もられ、ROMが58%、SRAMが24%、計算回路が18%を占める。

### 生成遅延とスループット

BitNet-2Bの単一トークン生成では、論文図11のトークン間時間が302.4マイクロ秒とされる。1秒を302.4マイクロ秒で割ると約3306であり、著者の最大3306トークン/秒という数字と整合する。時間の内訳はフィードフォワード層が44%、注意スコア計算・値ベクトル積が合計34%で、残りは他の演算や制御となる。極めて短いトークン間時間は重み転送の削減と並列演算によるものだが、モデルが異なるとレーン利用率や必要容量も変化する。

著者らはA100に対し最大465倍という表現を導入部で使う一方、評価節では入力・出力長を含む**エンドツーエンド遅延**の最大改善を63.7倍と報告する。両者は同じ指標ではなく、465倍を一律のリクエスト完了時間短縮と説明してはならない。比較対象のGPUもA100 40GB・bitnet.cpp・バッチ1であり、他の推論ランタイムやGPUとの直接比較を意味しない。

### 電源遮断の効果

動的電源遮断を無効にした条件の推定チップ電力は25.813Wで、うちROMが21.306Wを占める。層単位の電源遮断を有効にすると総電力は5.33Wまで下がり、削減率は約79.4%となる。これは明確な構成要素除去実験であり、ROMの密度改善だけでなく、**使っていないROMの待機電力を抑える制御**が実用電力に大きく寄与することを示す。電力は合成・解析に基づく推定である点は保持する。

### LoRAと長文脈での制約

論文図15ではLoRAをQ/Vのみ、Q/K/V/O、全重みなどへ適用する構成を比較し、SRAM面積・電力とトークン間時間の増加を評価する。定性的には追加の時間は比較的小さい一方、SRAMの増加が重要になる。文脈長を増やすとKVキャッシュ用SRAMが比例して増え、チップ面積と電力のコストが増す。TOMはオンチップKVキャッシュを前提とするため、長文脈を無制限に伸ばせるわけではない。

## 限界・適用条件・注意点

第一に、ROMを論理合成して重みを固定する方式は**モデル更新のたびに回路を変更する必要がある**。SRAM上のLoRAは差分更新の柔軟性を与えるが、基盤モデル全体を置き換える用途とは異なる。第二に、三値モデルを前提とするため、通常の4ビット量子化モデルやFP16モデルをそのままTOMへ載せても同じ面積・電力効率は得られない。重みのゼロビット率が変わるとROM密度も変わる。

第三に、評価はVerilog合成とシミュレーションであり、量産実機での温度、歩留まり、電源配線、動作変動、端末全体の電力、長時間稼働時の特性は未実証である。主要ROMモジュールの配置配線検証は行われているが、全システムの実装済み証明ではない。第四に、オンチップKVキャッシュ容量と最大文脈長の制約があり、文脈を増やすにはSRAMの増量が必要となる。第五に、CPU/GPUとの速度比較は異なるハードウェアと実装経路の比較であり、同じ消費電力枠・製造コスト・精度条件をすべて揃えた比較ではない。

ローカルLLM実行環境における直接の利用可能性も限定的である。論文中にbitnet.cppは比較対象として登場するが、**TOMそのものはbitnet.cppの新しいCPU命令やGPUカーネルではない**。GPUのVRAMを増設したり既存推論フレームワークの設定を変更したりするだけで200TB/sのオンチップ帯域や3306トークン/秒を再現できない。関連するのは将来のエッジ推論チップのアーキテクチャ選択と、三値重みの物理実装を含む設計上の知見である。

## 既存研究との位置付け

通常の量子化推論はDRAMから読む重みを小さくし、帯域を節約する。TOMはさらに一歩進めて、**重みをDRAMから読み出す行為そのものを固定ROMで置き換える**。ROMAなどの既存ROM系アクセラレータも重みをオンチップへ固定するが、TOMは三値重みの0を組合せ論理の削除へ反映し、局所MVU、グローバル縮約、LoRA用SRAM、層単位電源遮断を一体化する点が特徴である。EVAのようにベクトル量子化の演算形状を変える方式とも異なり、TOMの主な利点は三値重みの**記憶密度と読出し帯域**にある。

したがって本研究は、LLM推論基盤の中でもハードウェア専用設計、オンチップ重み配置、極低ビット推論、エッジ端末における適応重みの保持という系統に属する。数字の大きさだけで汎用GPUへの置換候補とするのではなく、固定ベースモデルの長寿命運用、製造可能性、SRAM容量と文脈長のトレードオフを併記して比較するのが適切である。
