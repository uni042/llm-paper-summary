# DyQ-VLA: Dynamic Quantization and Compensation for VLA models with Runtime Error Awareness

## 概要

DyQ-VLAは、視覚言語行動モデル（Vision-Language-Action model; VLA）の量子化を単なる「task successを保ちながら低bit化する」問題ではなく、**閉ループ実行中のruntime errorが次の観測・行動へどう伝播するか**という観点から設計し直す。2026年10月4日のarXiv v3では初期版から手法が大幅に改稿され、運動学proxyによるbit切替中心の方式ではなく、並進errorと回転errorの異なる時間発展を分析し、動的activation量子化と回転残差補償を組み合わせる方式になった。

分析では、並進errorは平均位置が比較的安定したまま分散が大きく、量子化するとさらに分散・outlierが増える。一方、回転errorは分散が小さいままdistribution centerが同じ方向へ徐々にshiftし、長期的なdriftとして蓄積する。DyQ-VLAはこの非対称性に合わせ、並進にはstepごとのactivation precision選択、回転には符号付きquantization residualの累積追跡とaction compensationを使う。

## 問題設定

VLAは実行したactionが次時刻のobservationを変えるため、各inferenceの誤差が独立ではない。現在の位置・姿勢errorが次のaction predictionを変え、そのactionがまたfuture errorを変える。taskが最終的に成功してもerror correctionのために余計なplanning/inference stepが増えれば、per-step latencyだけを短くしてもend-to-end completion timeは十分に下がらない。

著者らは同じ方向・同程度のperturbationを入れたrolloutを多数実行し、action deviationとruntime errorのjoint distributionをstepごとに比較する。full precisionでも並進と回転の分布進化が異なり、量子化はさらに並進側のvarianceとresponse sensitivityを増やす。一方、回転側は量子化によるsingle-step sensitivity変化は小さいが、center shiftが継続して累積誤差になる。したがって両componentへ同一の静的quantization/compensationを適用するのは非効率である。

## 手法

### 1. 並進error向け動的activation precision

weightは4-bitへ固定し、activationだけを候補precision間でstepごとに変える。weightをruntimeで入れ替えないため、巨大なweight tensorの再pack・転送costを避ける。

各precision `b` について、offline calibrationでtranslation/rotation errorの高quantile `E_d(b)` とinference latency `L(b)` を測る。runtimeでは直前の実行feedbackからresponse sensitivity `ŝ_{t,d}` を推定し、残留回転error `r_{t-1,R}` も考慮して、error constraintを満たす中でlatencyが最小のprecisionを選ぶ。つまり「低bitを使えるか」をactivation statisticsだけで決めず、現在のclosed-loop sensitivityとhistorical residualへ接続する。

候補評価をruntimeでmodel forwardし直すことはせず、offline profileのlookupとconstraint checkだけで決めるため、precision selection overheadを小さくする。条件を満たすcandidateがなければ高precision fallbackを使う。

### 2. 回転quantization residualの累積追跡

回転側ではactivationとそのquantized reconstructionとの差をrotation action componentへprojectionし、符号付き残差 `ζ_k^R` をstep間で同じcoordinate frameへ累積する。

`R_t^R = Σ ζ_k^R`

とすることで、異なるstepの誤差が同方向ならreinforce、逆方向ならcancelすることを保持する。単純なerror magnitude累積ではなくsign/directionを残すため、現在どちら向きへnet driftしているかをonlineに近似できる。一次論文の追加実験では、このcumulative residualがreference trajectoryに対する回転runtime errorの推移を追跡する。

### 3. residual-guided rotation compensation

推定した回転残差 `ê_t` と現在のrotation commandを共通coordinateへ揃え、残差と反対方向へ補正を加える。1回で全残差を打ち消すのではなく、現在roundで実行する `h` actionへ分散し、action boundを越えない最大補正率を求める。補正後は実際に適用した分をhistorical residualから差し引き、次roundへ残りだけを渡す。

これにより、並進側の「variance/outlierをprecisionで抑える」制御と、回転側の「center driftを履歴付きで相殺する」制御を分離する。

### 4. GPU runtime実装

W4 weight allocationは1個だけ常駐させ、A2/A4/A8/A16用の専用kernelを用意する。A2はstructured sparse INT4、A4はdense INT4、A8はW4 fragmentをregister内でINT8へ展開、A16はshared memoryでBF16 tileへ再構成する。global memory上で複数precisionのweight copyを持たずzero-copy viewを共有する。

さらにdequantizationと可能なRoPE、GELU、gating、residual operationをGEMM epilogueへfusionし、中間HBM read/writeを削減する。fixed-shape kernelとpreallocated bufferを使い、選択precision pathをCUDA Graphでreplayしてhost launch/scheduling overheadも抑える。

## 評価条件

v3では `π0.5` とGR00T-N1.5をLIBEROで評価し、`π0.5` はRoboTwin 2.0とAgilex Piper-X実機でも追加評価する。比較はBF16、GPTQ/AWQ/OmniQuant/SmoothQuant/DuQuantなど一般PTQ、ActQuant/QVLA/QuantVLA/HoloQ-VLAなどVLA向け量子化方式。全simulationはNVIDIA A100上で実施し、DyQ-VLAはW4 + dynamic A2/A4/A8/A16を用いる。

指標はtask success rateだけでなく、成功episodeのexecution steps、matched demonstrationに対するtranslation error（mm）・rotation error（degree）、inference latency/speedupを含む。これにより「成功率は同じでもcorrection stepが増えて遅い」ケースを区別する。

## 主要結果

LIBEROで `π0.5` のBF16は平均success 97.0%、159.7 steps、translation/rotation error 60.37 mm/14.19°。DyQ-VLAは**97.8%、149.5 steps、55.20 mm/13.23°**で、量子化しながら成功率とerrorをむしろ改善する。GR00T-N1.5でもBF16の86.1%、237.2 steps、85.40/18.35に対し、DyQ-VLAは**88.5%、219.8 steps、85.07/18.04**となる。

静的低bitでは失敗が大きい。例えば `π0.5` のW4A4 SmoothQuantは平均59.3%、GPTQ W4A16でも16.0%に落ちる一方、VLA専用方式は高いsuccessを保つがsteps/errorが増える例がある。DyQ-VLAはprecision adaptationとcompensationでこのclosed-loop costまで改善する。

全体では**1.88〜1.93倍のinference speedup**を保ちながら同等以上の平均success rateを達成し、平均execution stepsを**17.7〜19.8%削減**する。runtime errorはbaseline比でtranslationを78.5〜87.0%、rotationを59.4〜82.5%へ低減したと報告される。これはper-forward latencyだけでなく「error correctionのための追加forward回数」まで減らすという設計目的に対応する。

## 既存研究との差

一般PTQや既存VLA quantizationは主にweight/activationの統計、channel importance、task successと速度の交換条件を扱う。DyQ-VLA v3は量子化がclosed-loop action-error correlation自体を変えることを明示的に測り、translation distributionとrotation distributionへ別の制御を割り当てる。

初期版DyQ-VLAのkinematic proxy方式とも異なり、v3ではexecution feedbackとquantization residualを直接online signalとして使い、activation precision選択とaction compensationを結び付けている。

## 限界

offline error/latency profileはmodel、GPU、task distributionに依存し、別hardwareや大きく異なるrobot dynamicsでは再calibrationが必要である。runtime feedbackやreferenceに基づくerror推定もmeasurement noiseの影響を受ける。

またweightはW4固定なので、weight quantization自体がtaskを破壊するmodelではdynamic activationだけでは救えない。回転補償は推定残差とaction boundに依存し、未知の非線形dynamicsでresidual proxyが実errorと乖離すれば過補償・補償不足が起こり得る。主要結果はA100 simulationと限られたVLA/robot platformであり、全edge acceleratorへ同じ1.9倍が移るとは限らない。
