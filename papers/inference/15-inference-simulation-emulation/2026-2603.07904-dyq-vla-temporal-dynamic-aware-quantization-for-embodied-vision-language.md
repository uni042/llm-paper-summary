# DyQ-VLA: Dynamic Quantization and Compensation for VLA models with Runtime Error Awareness

## 概要

DyQ-VLAは、視覚言語行動モデル（Vision-Language-行動 モデル; VLA）の量子化を単なる「タスク 成功を保ちながら低ビット化する」問題ではなく、**閉ループ実行中の実行時 誤差が次の観測・行動へどう伝播するか**という観点から設計し直す。2026年10月4日のarXiv v3では初期版から手法が大幅に改稿され、運動学代理によるビット切替中心の方式ではなく、並進誤差と回転誤差の異なる時間発展を分析し、動的活性値量子化と回転残差補償を組み合わせる方式になった。

分析では、並進誤差は平均位置が比較的安定したまま分散が大きく、量子化するとさらに分散・外れ値が増える。一方、回転誤差は分散が小さいまま分布 中心が同じ方向へ徐々にshiftし、長期的なずれとして蓄積する。DyQ-VLAはこの非対称性に合わせ、並進には段階ごとの活性値 精度選択、回転には符号付き量子化 残差の累積追跡と行動 補償を使う。

## 問題設定

VLAは実行した行動が次時刻の観測を変えるため、各推論の誤差が独立ではない。現在の位置・姿勢誤差が次の行動 予測を変え、その行動がまた将来 誤差を変える。タスクが最終的に成功しても誤差 補正のために余計な計画/推論 段階が増えれば、per-段階 遅延だけを短くしてもエンドツーエンド completion timeは十分に下がらない。

著者らは同じ方向・同程度の摂動を入れた試行を多数実行し、行動 偏差と実行時 誤差の同時分布を段階ごとに比較する。全精度でも並進と回転の分布進化が異なり、量子化はさらに並進側の分散と応答感度を増やす。一方、回転側は量子化による単一段階 感度変化は小さいが、中心移動が継続して累積誤差になる。したがって両成分へ同一の静的量子化/補償を適用するのは非効率である。

## 手法

### 1. 並進error向け動的activation precision

重みは4-ビットへ固定し、活性値だけを候補精度間で段階ごとに変える。重みを実行時で入れ替えないため、巨大な重み テンソルの再再配置・転送コストを避ける。

各精度 `b` について、事前較正で並進/回転 誤差の高分位点 `E_d(b)` と推論 遅延 `L(b)` を測る。実行時では直前の実行フィードバックから応答感度 `ŝ_{t,d}` を推定し、残留回転誤差 `r_{t-1,R}` も考慮して、誤差 制約を満たす中で遅延が最小の精度を選ぶ。つまり「低ビットを使えるか」を活性値 統計だけで決めず、現在の閉ループ 感度と履歴 残差へ接続する。

候補評価を実行時でモデル forwardし直すことはせず、offline プロファイルの参照と制約 checkだけで決めるため、精度 選択 オーバーヘッドを小さくする。条件を満たす候補がなければ高精度 代替を使う。

### 2. 回転quantization residualの累積追跡

回転側では活性値とそのquantized 再構成との差を回転 行動 成分へprojectionし、符号付き残差 `ζ_k^R` を段階間で同じ座標系へ累積する。

`R_t^R = Σ ζ_k^R`

とすることで、異なる段階の誤差が同方向なら増強、逆方向なら相殺することを保持する。単純な誤差 大きさ累積ではなくsign/方向を残すため、現在どちら向きへ正味のずれしているかをオンラインに近似できる。一次論文の追加実験では、このcumulative 残差が参照軌道に対する回転実行時 誤差の推移を追跡する。

### 3. residual-guided rotation compensation

推定した回転残差 `ê_t` と現在の回転 指令を共通coordinateへ揃え、残差と反対方向へ補正を加える。1回で全残差を打ち消すのではなく、現在ラウンドで実行する `h` 行動へ分散し、行動 上限を越えない最大補正率を求める。補正後は実際に適用した分を履歴 残差から差し引き、次ラウンドへ残りだけを渡す。

これにより、並進側の「分散/外れ値を精度で抑える」制御と、回転側の「中心 ずれを履歴付きで相殺する」制御を分離する。

### 4. GPU runtime実装

W4 重み 割当は1個だけ常駐させ、A2/A4/A8/A16用の専用カーネルを用意する。A2は構造化疎 INT4、A4は密 INT4、A8はW4 断片をレジスタ内でINT8へ展開、A16は共有メモリでBF16 タイルへ再構成する。大域メモリ上で複数精度の重み 複製を持たずゼロコピー ビューを共有する。

さらに逆量子化と可能なRoPE、GELU、ゲーティング、残差 演算をGEMM epilogueへ融合し、中間HBM 読み書きを削減する。fixed-shape カーネルと事前確保バッファを使い、選択精度 経路をCUDA Graphで再実行してホスト起動/scheduling オーバーヘッドも抑える。

## 評価条件

v3では `π0.5` とGR00T-N1.5をLIBEROで評価し、`π0.5` はRoboTwin 2.0とAgilex Piper-X実機でも追加評価する。比較はBF16、GPTQ/AWQ/OmniQuant/SmoothQuant/DuQuantなど一般PTQ、ActQuant/QVLA/QuantVLA/HoloQ-VLAなどVLA向け量子化方式。全シミュレーションはNVIDIA A100上で実施し、DyQ-VLAはW4 + 動的 A2/A4/A8/A16を用いる。

指標はタスク成功率だけでなく、成功エピソードの実行 段階、matched 実演に対する並進 誤差（mm）・回転 誤差（degree）、推論 遅延/高速化倍率を含む。これにより「成功率は同じでも補正 段階が増えて遅い」ケースを区別する。

## 主要結果

LIBEROで `π0.5` のBF16は平均成功 97.0%、159.7 段階、並進/回転 誤差 60.37 mm/14.19°。DyQ-VLAは**97.8%、149.5 段階、55.20 mm/13.23°**で、量子化しながら成功率と誤差をむしろ改善する。GR00T-N1.5でもBF16の86.1%、237.2 段階、85.40/18.35に対し、DyQ-VLAは**88.5%、219.8 段階、85.07/18.04**となる。

静的低ビットでは失敗が大きい。例えば `π0.5` のW4A4 SmoothQuantは平均59.3%、GPTQ W4A16でも16.0%に落ちる一方、VLA専用方式は高い成功を保つが段階/誤差が増える例がある。DyQ-VLAは精度 適応と補償でこの閉ループ コストまで改善する。

全体では**1.88〜1.93倍の推論 高速化倍率**を保ちながら同等以上の平均成功 rateを達成し、平均実行 段階を**17.7〜19.8%削減**する。実行時 誤差は比較基準比で並進を78.5〜87.0%、回転を59.4〜82.5%へ低減したと報告される。これはper-forward 遅延だけでなく「誤差 補正のための追加forward回数」まで減らすという設計目的に対応する。

## 既存研究との差

一般PTQや既存VLA 量子化は主に重み/活性値の統計、チャネル重要度、タスク 成功と速度の交換条件を扱う。DyQ-VLA v3は量子化が閉ループ 行動-誤差 相関自体を変えることを明示的に測り、並進 分布と回転 分布へ別の制御を割り当てる。

初期版DyQ-VLAの運動学 代理方式とも異なり、v3では実行 フィードバックと量子化 残差を直接オンライン 信号として使い、活性値 精度選択と行動 補償を結び付けている。

## 限界

offline 誤差/遅延 プロファイルはモデル、GPU、タスク 分布に依存し、別hardwareや大きく異なるロボット力学では再較正が必要である。実行時 フィードバックやreferenceに基づく誤差推定も測定雑音の影響を受ける。

また重みはW4固定なので、重み 量子化自体がタスクを破壊するモデルでは動的 活性値だけでは救えない。回転補償は推定残差と行動 上限に依存し、未知の非線形dynamicsで残差 代理が実誤差と乖離すれば過補償・補償不足が起こり得る。主要結果はA100 シミュレーションと限られたVLA/robot プラットフォームであり、全端末向けアクセラレータへ同じ1.9倍が移るとは限らない。
