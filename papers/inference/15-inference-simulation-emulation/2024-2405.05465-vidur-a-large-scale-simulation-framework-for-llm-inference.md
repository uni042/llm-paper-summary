# Vidur: A Large-Scale Simulation Framework For LLM Inference

> 演算子別プロファイルと階層スケジューラでLLMサービングを高忠実度に模擬し、LLaMA2-70Bの配置探索を42K GPU時間相当からCPU約1時間へ縮小する。

## 概要

LLMサービングでは、テンソル並列数、パイプライン段数、GPU種類、スケジューラ、最大バッチ、チャンクサイズなどの組合せが多く、最適構成はモデルだけでなく要求長や到着分布にも依存する。ある負荷で最適な構成を別負荷へ流用すると、LLaMA2-70Bでコストが最大2倍違う例を論文は示す。実機で全組合せを試す方法は高価である。

Vidurはこの探索を高忠実度シミュレーションへ置き換える。モデルを少数の演算子へ分解し、実機で最小限の点だけプロファイルし、未測定点は演算子の性質に応じた予測器で補間する。さらに実際のバッチ形成、KVキャッシュ容量、要求到着、並列通信をイベント駆動で再現する。4モデルと複数GPU構成で要求遅延を9%未満の誤差で予測し、Vidur-SearchはLLaMA2-70Bの最適配置探索を96コアCPU約1時間で行う。実機総当たりなら42K GPU時間、約21.8万ドルと見積もられる探索である。

## 問題設定

学習シミュレータでは各反復の形が比較的一定だが、LLM推論ではプリフィルとデコードで演算特性が違い、各要求の文脈長も異なり、オンライン負荷に応じてバッチ構成が毎反復変わる。数ミリ秒級の予測誤差でも次のバッチ形成時刻がずれ、そのずれが後続要求へ連鎖する。

また、注意演算は履歴長に依存する一方、全結合や正規化は現在バッチのトークン数だけでほぼ決まる。全てを一つのブラックボックス回帰で予測すると必要データが増える。Vidurは演算子を依存関係で分類し、各分類に適した少数の説明変数だけを使う。

## 手法

### 1. 演算子の三分類と最小プロファイル

Vidurは演算子をトークン単位、系列単位、通信の三種類へ分ける。全結合や活性化は現在反復の総トークン数、注意は要求ごとの文脈、all-reduce/all-gather/send-recvは転送量と接続構成が主な入力になる。

プリフィル注意では各要求長p_iの二乗和に対応する等価長を使い、デコード注意ではメモリ律速であることからバッチ全体が読むKVキャッシュ総量を主説明変数にする。これにより、要求長の全組合せを実測せずに済む。

### 2. 実行時間推定器

測定点の間は小型のランダムフォレスト回帰で補間する。単純多項式ではCUDAカーネルのタイル量子化やウェーブ数による非線形な段差を捉えにくく、多層パーセプトロンでは大量の学習データが必要になるため、その中間としてランダムフォレストを選ぶ。

テンソル並列の各シャーディング構成もモデル仕様から自動生成するため、全並列構成を複数GPUで個別に測る必要がない。通信演算はモデル非依存として接続トポロジごとに別プロファイルする。

### 3. 三層の階層スケジューラ

イベント駆動シミュレータには、クラスタ全体の要求振分けを行う大域スケジューラ、各レプリカでバッチ形成とKVメモリ管理を行うレプリカスケジューラ、パイプライン段内のマイクロバッチを扱う段スケジューラがある。vLLM、Orca、FasterTransformer、Sarathi-Serve、LightLLM相当の方針を同じ枠組みで再現する。

メモリ計画器はモデル仕様と並列構成からKVキャッシュに使える容量を計算し、バッチ方針へ渡す。したがって演算時間だけを足し合わせるのではなく、メモリ不足がバッチ形成へ与える影響も時間軸上で再現する。

### 4. Vidur-BenchとVidur-Search

Vidur-BenchはLMSys-Chat-1M、Arxiv-Summarization、Bilingual-Web-Bookから異なる入力・出力長分布を作り、構成が負荷に依存することを比較できるようにする。Vidur-Searchは候補構成をシミュレータで評価し、先頭トークン時間やトークン間時間などのサービス品質制約を満たす中で、1ドル当たりスループットが高い構成を探す。

## 既存研究との差

Daydream、Habitat、Proteusなどは主にDNN学習の反復時間や並列化を模擬する。VidurはLLM推論特有のプリフィル/デコード差、動的バッチ、要求ごとのKV履歴、ミリ秒級の予測誤差が後続スケジュールへ連鎖する性質を明示的に扱う。単なるカーネル性能予測ではなく、要求到着から階層スケジューリングまで含める点が差である。

## 限界・実装状況

忠実度はプロファイルしたGPU世代、実装カーネル、対応スケジューラの範囲に依存する。未知の融合カーネルや非同期パイプラインなどは、その挙動を新たにモデル化しなければ再現できない。論文時点の段スケジューラは同期パイプラインを中心とし、非同期通信や投機的パイプラインは将来拡張として挙げる。コードは公開済みである。
