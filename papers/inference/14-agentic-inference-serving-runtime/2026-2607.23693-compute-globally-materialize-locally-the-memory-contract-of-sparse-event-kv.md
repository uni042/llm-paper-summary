# Compute Globally, Materialize Locally: The Memory Contract of Sparse Event-KV

## 書誌情報

Zefeng CaiとZerui Caiによる2026年の研究で、一次資料は arXiv:2607.23693 である。長期エージェントがKVキャッシュをイベント単位の記憶として再利用するとき、元の観測を削除した後に残されたKV行がどの情報を独立に保持できるかを、因果的な対照実験で調べる。

## 概要

疎なイベントKV管理は「残したイベントが、生成元の観測を捨てても役に立つ」と暗黙に仮定する。本論文は、配信トークンと位置を完全に同一にしたドナー対で、事前計算時の元値だけを変え、下流KVが見えない元値を保持する意味的具現化を確認した。Qwen3-8Bでは値を明示しない意図的な計算指示イベントで回復率が6%から51%へ上がる一方、二値状態93.4%に対して4択22.3%、8択15.6%、3桁数値0/192と保持能力は狭い。

## 問題設定

長期対話やエージェントでは全履歴のKVを残すと容量が増え続けるため、重要イベントだけを残す追い出し方式が使われる。しかし元イベントを削除しても精度が落ちなかった場合、元情報が不要だったのか、それとも後続イベントのKVへ既に書き込まれていたのかを通常の除去実験だけでは区別できない。

著者らは、表示テキストに答えが書かれていない下流イベントを残し、元の値を設定したイベントだけを配信集合から外す。二つの履歴で配信されるトークン列と位置を同一にし、事前計算時の元値だけを変えることで、回答差が残存KVに由来することを直接検証する。

## 手法

### 1. ドナー対による因果分離

元イベントがレジスタSの値を設定し、後続の根イベントが「MはSを反映する」のように値そのものを書かず参照する履歴を作る。事前計算では根イベントが元イベントへ注意できるため、根イベントのKV行は元値に依存して形成される。

読み出し時には元イベントを除去し、根イベントと固定デコイ、質問だけを配信する。二つのドナー履歴は配信テキストと位置がバイト単位で同じで、異なるのは除去済み元値が根KVを形成した履歴だけである。回答が元値に追随すれば、見えるテキストではなくKV状態が情報を運んだと判定できる。

### 2. 書き込み契約の分離

同じ意味を持つ文でも表現の仕方によってKVへの書き込み強度が大きく変わるかを調べる。単なる自然な言及、値を明示しない計算指示、値を直接書く上限条件など複数の表現を比較し、どの表現が元値依存の状態を下流KVへ残すかを測る。

Qwen3-8Bでは「今判定してここへ記録せよ」に相当する値非明示の指示が、ドナー整合回復率を6%から51%へ引き上げた。意味理解が同程度でも表面形で結果が変わるため、書き込みは意味だけで自動発生する安定した記憶APIではない。失敗時の確実な代替は値を明示したテキスト記録になる。

### 3. 着地点と参照鎖

元イベントを直接参照した根イベントと、さらに根を参照する後続辺イベントを分け、どのKV行に情報が実体化するかを測る。結果は根イベントが強い元値依存信号を持ち、後続の参照辺は同じ値を複製するより根へ読み出しを誘導する役割が強いことを示す。

したがってイベントグラフを圧縮するとき、参照鎖の末端だけを保存すれば十分とは限らない。入力はイベント依存関係、処理は全体文脈での事前計算、出力は根に局所化したKV状態であり、根を追い出すと辺だけでは回復できない場合がある。

### 4. アクセス容量と位置条件

保持できる情報量を二値、4択、8択、3桁数値へ広げる。二値状態は93.4%で偶然50%を大きく上回るが、4択22.3%、8択15.6%は偶然水準付近、3桁数値は192例中0件の完全回復だった。意味的具現化は大容量の一般記憶ではなく、コンパクト状態に向く。

また局所注意を持つモデルでは、保持行を詰め直して位置を変えると元の注意窓幾何が変わる。著者らは元位置を保持する配信と圧縮位置へ詰める配信を比較し、窓外では挙動が大きく異なることを確認する。したがってKV行を保存するだけでなく、位置と注意窓の契約も保存する必要がある。

## 評価条件

主にQwen3-8BとGemma系モデルを用い、合成イベント履歴でドナー対を作る。読み出しでは短答や選択式を使い、配信トークン、位置、デコイを統制する。値依存性、表現依存性、根・辺の着地点、情報量、局所注意位置の各軸を個別に検証する。

実会話への外挿も確認するため、長期対話データから自然に生じた言及を受動的に採取する条件を評価する。ここでは意図的に作った書き込みイベントのような検出可能な利得は得られず、合成実験で観測した機構が自然会話で自動的に十分強く働くとは限らないことを示す。

## 主要結果

Qwen3-8Bの値非明示計算指示ではドナー整合回復率が6%から51%へ上昇した。位置を固定した条件でも、共有レビュー行だけでは0だった回復が指示イベント追加で0.42へ上がり、単なる質問位置移動ではなく書き込みイベント自体の寄与を確認する。

情報容量には明確な上限があり、二値状態は93.4%回復する一方、4択22.3%、8択15.6%、3桁数値0/192だった。元イベントを削除しても回答が保たれる現象だけを見て「元イベントは不要」と結論できず、下流KVへの計算結果の実体化を考慮すべきだというのが実務的な結論である。

## 既存研究との差

KV圧縮やイベント追い出し研究は、どの行を残すか、どれだけ精度を維持するかを主に扱う。本研究は残されたKV行が元テキストにない計算状態を独立に運べるかを因果的に分離し、書き込み、着地点、読み出し容量、位置条件という「記憶契約」を測る点が異なる。

## 限界・実装状況

強い結果の多くは統制した合成履歴で得られ、自然会話から受動的に採取した言及では明確な利得が出ていない。保持できる情報もコンパクト状態に偏り、大きなペイロードは急速に偶然水準へ近づく。モデルや表現ごとの差も大きいため、一般的なKV記憶APIとして使うには明示テキストへの退避など安全策が必要である。
