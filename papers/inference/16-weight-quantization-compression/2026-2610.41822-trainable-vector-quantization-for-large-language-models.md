# Trainable Vector Quantization for Large Language Models

> 離散的な割当て行列を潜在重みとコードブックから決まる関数へ書き直し、直通推定で勾配を流す訓練可能なベクトル量子化で、2ビット量子化の品質を回復させ、Llama2-70B の質問応答では元のモデルとの差を 0.7% まで縮めた。

## 概要

大規模言語モデルの提供では、重みの読み出しが費用を支配する。例えば Llama3-70B のパラメータは 140GB を要し、一台の図形処理装置には収まらない。重みだけを低ビットで表す量子化は、モデルを数分の一に縮めてメモリの制約の中で動かすための実用的な手段だが、極端にビット数を落とすと品質が大きく落ちる。ベクトル量子化は、重みの値を一つずつ整数へ置き換えるスカラー量子化と違い、重みを固定長のベクトルにまとめ、コードブックと呼ばれる代表ベクトルの集合から最も近いものを選んで置き換える。ベクトルの組を一つの記号で表せるため、同じビット数でもスカラー量子化より小さくできる。

問題は、落ちた品質をどう取り戻すかである。量子化された重みの表現は、コードブックと、どの代表ベクトルを使うかを示す整数の割当て行列からなり、パラメータの大部分は割当て行列に集中する。この行列は整数値のため、勾配降下で直接最適化できない。既存の手法は、各層の出力の再構成誤差を層ごとに小さくすることに限られ、モデル全体の損失を直接最適化する手段を持たなかった。本論文は、訓練可能なベクトル量子化（TVQ）を提案する。割当てを潜在重みとコードブックから決まる関数として書き直し、直通推定で勾配を潜在重みへ流すことで、任意の損失関数に対する勾配最適化を可能にする。

代表結果として、Llama2-70B の 2ビット量子化では、質問応答の平均正解率が元のモデルと 0.7% の差まで迫り、ほぼ無損失に近い。Llama3-70B でも、元のモデルとの性能差が 4.5% から 2.6% へ縮んだ。TVQ は既存のベクトル量子化の方式である QuIP# や QTIP、AQLM の基礎方式と組み合わせられ、同じ方式で最適化方法だけを差し替えると、どの方式でも品質が上がった。学習費用は 100〜400 GPU時間程度と、既存の効率的な手法と同規模に収まる。

## 問題設定

低ビット量子化の品質回復には、二つの壁がある。第一に、割当ては離散的な選択である。重みの各ベクトルに対して、コードブックの中から最も近い代表を選ぶ操作は、潜在重みを少し動かしても選択が変わらない限り出力が変わらない階段状の関数であり、勾配はほとんどどこでもゼロになる。したがって、通常の勾配降下は潜在重みを更新できない。第二に、割当ての探索空間は巨大である。割当て行列の各要素が取る値の組み合わせは、層の数と重みの数を掛けた規模で爆発するため、総当たりやビーム探索のような離散探索では、層ごとにしか最適化できない。層ごとの再構成誤差は、層をまたぐ誤差の蓄積や、最終的な課題の正解率とのずれを直接扱えない。

さらに、困惑度のような言語モデルの損失だけでは、量子化の影響を十分に測れないことも本論文は示している。例えば Llama3-70B の QuIP# は、困惑度では悪くない値なのに、質問応答の平均正解率は 43.5% まで崩れた。つまり、層の出力の近さや困惑度を最適化するだけでは、下流の課題の品質を守れない場合がある。TVQ が目指すのは、割当ての最適化を、層ごとの近似から、ブロック単位の蒸留やモデル全体の損失への勾配最適化へ引き上げることである。

## 手法のあらまし

流れは二段階の学習である。まず、割当ての最適化を連続量の最適化へ置き換える再パラメータ化を行う。各層の重みについて、割当ては「潜在重みをコードブックで最もよく近似する代表を選ぶ」という関数で決まるとし、学習では潜在重みとコードブックを更新する。順方向では選ばれた代表から重みを復元して損失を計算し、逆方向では直通推定により、復元した重みへの勾配をそのまま潜在重みへ流す。次に、この仕組みでブロック単位の学習を一段目として行い、元のブロックの出力に量子化ブロックの出力を近づける。二段目では、層正規化の重みやコードブック、言語モデルの出力層といった連続パラメータの一部だけを対象に、元のモデルとの分布のずれを小さくする微調整を行う。割当ての再計算は費用が高いため、数ステップに一度だけ更新する計画更新と、近似最近傍探索による加速が用意されている。

## 手法

### 1. 割当ての再パラメータ化 — 離散的な選択を連続な重みの関数にする

この機構が観測するのは、連続な潜在重みとコードブックであり、保持する状態は、その二つから決まる割当て行列と、復元した重みである。動作は、重みの各ベクトルについて、コードブックの中で潜在重みに最も近い代表を選び、その番号を割当てとして記録することである。学習後の推論では、コードブックと割当てだけが保存され、元の重みは使われない。この再パラメータ化が減らすボトルネックは、割当ての離散性である。割当てそのものを直接動かす代わりに、連続な潜在重みを動かせば、それに連動して割当てが切り替わるため、勾配による最適化の枠組みに乗る。追加で消費する資源は、潜在重みを保持するメモリと、学習のたびに割当てを再計算する時間である。失敗時の挙動として、潜在重みが二つの代表の境界付近にあると、割当てが振動しやすくなるが、後述の計画更新がその頻度を抑える役割を持つ。

### 2. 直通推定による勾配 — 勾配がゼロになる壁を迂回する

第二の機構は勾配の流し方である。観測するのは、復元した重みに対する損失の勾配であり、保持する状態は、潜在重みとコードブックへの更新量である。動作は、順方向では割当てに基づく復元重みを使って損失を計算し、逆方向では、復元重みから潜在重みへの勾配を単位写像の勾配で置き換えることである。言い換えれば、復元重みへの勾配を、そのまま潜在重みへの勾配として扱う。この近似は、量子化の勾配を直通させる既存の直通推定の考え方を、ベクトル量子化の割当てへ適用したものである。この機構が減らすボトルネックは、勾配がほとんどどこでもゼロになるという学習不能の壁である。追加で消費する資源はほとんどなく、PyTorch や TensorFlow での実装も素直であることが論文の主張である。失敗時の挙動として、直通推定は近似であり、勾配の方向が真の勾配とずれる場合があるが、実験では品質の回復が一貫して観測されており、この近似が実用上十分であることが示された。

### 3. 第一段階：ブロック単位の学習後量子化 — 層ではなくブロックで出力を合わせる

第三の機構は一段目の学習である。観測するのは、元のモデルの各ブロックへの入力活性値と、量子化したブロックの出力であり、保持する状態は、ブロックごとの量子化パラメータである。動作は、モデルを先頭から順にブロック単位で最適化し、量子化したブロックの出力と、元のブロックの出力の差を小さくすることである。入力には、元のモデルが計算した活性値と、量子化した側が計算した活性値の両方が使われる。この機構が減らすボトルネックは、層ごとに独立に誤差を測る既存手法の限界である。ブロック単位にすることで、注意機構と多層パーセプトロンを含む一つのまとまりの出力のずれを直接扱える。追加で消費する資源は、ブロックごとの学習であり、全体では後述の表の通り、方式によって 40〜390 GPU時間程度かかる。失敗時の挙動として、一段目だけではモデル全体の分布のずれが残るため、二段目の微調整が別に用意されている。

### 4. 第二段階：部分的な端から端の微調整 — 連続パラメータだけを分布のずれで調整する

第四の機構は二段目の微調整である。観測するのは、量子化モデルと元のモデルの出力分布であり、保持する状態は、層正規化の重みやコードブック、言語モデルの出力層といった連続パラメータの一部である。動作は、この部分集合だけを対象に、元のモデルとの KL ダイバージェンス、つまり分布の食い違いを小さくする方向へ勾配で更新することである。割当て行列そのものはこの段階では更新しない。対象とするパラメータの選び方は、組み合わせるベクトル量子化の方式ごとに先行研究と同様に決める。この機構が減らすボトルネックは、一段目のブロック単位の最適化だけでは残る、モデル全体の出力分布のずれである。追加で消費する資源は 50 GPU時間程度と一段目より小さく、一段目の方式によらず共通である。失敗時の挙動として、調整できるのは連続パラメータの一部だけであり、割当ての質が一段目で決まっているため、二段目だけでは一段目の不足を補いきれない。

### 5. 学習の加速 — 割当ての再計算を間引きと近似探索で軽くする

第五の機構は学習の実用性を支える加速である。観測するのは、割当ての再計算にかかる時間と、それを間引いたときの品質であり、保持する状態は、割当てを更新する間隔である。動作は二つある。一つは、割当てを毎ステップではなく、数ステップに一度だけ更新する計画更新であり、間隔を S とすると、S を 8 や 16、32 へ広げても品質はほぼ変わらず、S を 64 まで広げると品質が崩壊した。もう一つは、基本のベクトル量子化の方式で、割当ての計算を近似最近傍探索へ置き換えることであり、FAISS ライブラリによるボロノイ分割に基づく探索で、99.99% の精度に到達する近似探索が厳密探索より 5倍速く、品質への影響は見られなかった。この二つが減らすボトルネックは、学習のたびに割当てを再計算する費用である。追加の費用として、計画更新の間隔を広げすぎると品質が崩れるという境界があり、QTIP と組み合わせる場合は間隔 16 が品質と費用の釣り合いがよいと報告された。

### 6. 一つの層が学習される流れ

ある層の重みについて、学習では潜在重みとコードブックから割当てが計算され、コードブックと割当てから重みが復元され、その重みで損失が計算される。損失の勾配は、直通推定により潜在重みとコードブックへ流れて両者を更新し、次のステップで割当てが計算し直される。一段目ではこの更新がブロック単位の出力のずれを小さくする方向に働き、二段目では連続パラメータだけが分布のずれを小さくする方向に更新される。学習が終わると、保存されるのはコードブックと割当てだけであり、推論ではこの圧縮表現から重みを復元して使う。

| 構成要素 | 入力・観測 | 具体的な動作 | 改善対象 | 主なトレードオフ |
|---|---|---|---|---|
| 割当ての再パラメータ化 | 潜在重みとコードブック | 最も近い代表を割当てとして選ぶ | 割当ての離散性 | 潜在重みの保持と再計算の費用 |
| 直通推定の勾配 | 復元重みへの勾配 | 勾配をそのまま潜在重みへ流す | 勾配がゼロで学べない壁 | 近似による勾配のずれ |
| ブロック単位の学習 | 元のブロックと量子化ブロックの出力 | ブロック単位で出力の差を小さくする | 層ごとの最適化の限界 | 一段目の学習費用 |
| 部分的な端から端の微調整 | 二つのモデルの出力分布 | 連続パラメータの一部を分布のずれで調整する | モデル全体の分布のずれ | 調整できるのは一部の連続量だけ |
| 学習の加速 | 再計算の時間と品質 | 割当ての更新を間引き、近似探索で置き換える | 割当て再計算の費用 | 間隔を広げすぎると品質が崩れる |

## 評価

### まず見るところ

結論は、割当ての最適化方法を変えるだけで、既存のベクトル量子化の方式の品質が一貫して上がり、2ビット量子化でも最先端の品質に達する、ということである。比較は、方式を固定して最適化方法だけを差し替える対で行われており、品質の向上が方式の違いではなく TVQ 自体の寄与だと切り分けられている。品質の指標は質問応答の平均正解率が主で、困惑度も併記される。評価の強さは、五つのモデルと三つの方式の組み合わせで一貫性を確認している点にある。弱さは、推論の速度や遅延そのものを測っていない点であり、高速化の主張は重みの縮小と先行研究の実行カーネルに依存する。

### 学習費用

| 指標 | 結果 |
|---|---|
| TVQ+QuIP#（Llama2-70B） | 一段目 54 GPU時間＋二段目 50 GPU時間＝合計 104 GPU時間 |
| TVQ+QTIP（Llama2-70B） | 一段目 390 GPU時間＋二段目 50 GPU時間＝合計 440 GPU時間 |
| TVQ+BasicVQ（Llama2-70B） | 一段目 212 GPU時間＋二段目 50 GPU時間＝合計 262 GPU時間 |
| PV-Tuning（比較対象） | 二段目だけで約 1,500 GPU時間、8台の Ampere100 が要る | 
| QuIP#・QTIP（比較対象） | 合計 90〜100 GPU時間で、TVQ と同規模 |

TVQ+QuIP# と TVQ+BasicVQ は、元の方式とほぼ同じ学習費用でよりよい品質に達した。TVQ+QTIP は最も費用がかかるが、それでも PV-Tuning より大幅に軽く、2〜4台の Ampere100 で済む。学習時間の多くは一段目にかかり、方式によって 40〜390 GPU時間と幅がある。

### 構成要素ごとの効果

| 構成 | 結果 | 読み取れること |
|---|---|---|
| 計画更新の間隔（TVQ+QTIP・一段目のみ） | 間隔 8・16・32 では品質はほぼ同等、64 では困惑度が 100 を超えて崩壊 | 間隔 16 が品質と費用の釣り合いがよい |

| 近似最近傍探索 | 99.99% の精度で厳密探索より 5倍速く、品質への影響は見られない | 探索の近似は安全に使える |

### 感度・ストレス条件

割当ての更新間隔を 8 から 32 へ広げても、Llama2-7B・Llama3-8B・Mistral-7B-v0.1 のいずれでも困惑度と正解率はほぼ変わらなかったが、64 まで広げると三つのモデルすべてで困惑度が 100 を超え、正解率が 10% を下回った。間隔 32 と 64 では学習時間がほぼ同じであり、間隔を広げる利得が頭打ちになる点も報告されている。モデル規模による感度として、Llama3-70B の QuIP# のような極端な崩れは大規模モデルで顕著であり、TVQ の回復幅もそこで最大になった。

### 評価上の制約

- 推論の速度や遅延、スループットの実測はなく、高速化は重みの縮小と既存の実行カーネルへの依存として論じられている。
- 評価は質問応答と困惑度に限られ、長文脈や生成課題での検証はない。
- 学習費用は Llama2-70B の 2ビット量子化を中心とした報告であり、他のモデルやビット数での費用は示されていない。

## 既存研究との差

ベクトル量子化の先行研究は、方式そのものの設計、つまりコードブックの構造や、どの代表ベクトルを選ぶかの規則を改良する方向で進んできた。AQLM、QuIP#、QTIP といった方式は、それぞれ異なるコードブック構造や格子の制約を持ち、最適化は層ごとの再構成誤差の最小化やビーム探索に限られていた。PV-Tuning は一段目の上に大規模な微調整を重ねるが、約 1,500 GPU時間という大きな費用が要る。本論文の違いは、方式の設計ではなく、割当ての最適化方法そのものを勾配ベースへ置き換えた点にある。同じ方式で最適化方法だけを差し替えると品質が上がるという対の比較により、寄与が方式の違いではなく最適化の違いだと示されている。さらに、直通推定による再パラメータ化は、任意の損失関数に適用できるため、ブロック単位の蒸留だけでなく、将来の別の目的関数にも使える汎用性がある。

## 限界・実装状況

- ハードウェアに特化した実行の工夫は本論文の対象外であり、ベクトル量子化モデルの高速な実行カーネルなどは提供されていない。ただし TVQ は最適化したモデルの構造を変えないため、既存の実行ソフトウェアと互換性があり、その高速化の恩恵はそのまま受けられる。
- 推論の速度や遅延の実測はなく、2ビット化による実行時の利得は論文内で測定されていない。
- 学習費用は方式によって大きく異なり、TVQ+QTIP は一段目だけで 390 GPU時間を要する。
- 計画更新の間隔を広げすぎると品質が崩壊するという境界があり、間隔の選択には注意が要る。
- 公式のコード公開先は本文中に示されていない。実装は PyTorch による素直なものだと述べられ、近似最近傍探索には FAISS を使う。

## 一般的な実装上の含意

離散的な選択を含む量子化の最適化では、選択そのものを直接動かすのではなく、選択を決める連続な量へ書き直して勾配を流すという設計が有効である。特に、割当てのようなパラメータの大部分を占める離散量は、層ごとの局所的な誤差ではなく、ブロックやモデル全体の損失で最適化する価値がある。また、困惑度のような代理の指標だけでは量子化の品質を測れない場合があるため、最終的な課題の正解率で評価することが重要である。学習の加速では、割当ての再計算を間引くときに品質が崩れる境界が鋭いため、間隔の感度を実測して選ぶべきである。
