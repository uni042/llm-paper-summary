# D²Quant：二重尺度と活性平均ずれ補正による低ビット重重量子化

## 概要

大規模言語モデルの重みだけを量子化する学習後量子化（weight-only PTQ）は、活性値を高精度で保ったままモデル保存量と重み転送量を減らせる。ただし2～3ビットでは、フィードフォワード層の出力射影（down-projection）に大きな量子化誤差が生じ、注意層の重み誤差が後段の活性値の平均をずらす。D²Quantは、出力射影の重み分布を二重尺度で整えるDSQと、注意後の正規化層へ補正バイアスを入れるDACを組み合わせる。

Qwen3-8Bの2ビット量子化では、WikiText2のパープレキシティーをGPTAQの20.24から14.10へ、7つのゼロショット課題平均をGPTQ+QuaRotの54.05から57.22へ改善した。追加の列尺度は前段の重みに吸収でき、活性補正も小さなバイアスで実現するため、推論時の重みビット予算と追加演算をほぼ増やさない。ただし量子化前処理には追加の反復最適化と校正データが必要で、実測の生成トークン毎秒を改善したと直接示した研究ではない。

## 背景と量子化誤差の所在

重みだけを低ビット化するGPTQやAWQは4ビットでは良好でも、2ビットまで下げるとパープレキシティーや下流精度が急激に悪化する。特にMLPのdown-projectionは入力の多数の中間特徴を隠れ次元へ戻すため、重みの外れ値と量子化尺度に敏感である。通常の行単位の尺度だけでは、入力チャネル方向の値域のばらつきを吸収しにくい。

また、活性値を直接量子化しなくても、注意の重みを量子化すると注意出力が変化し、その後の正規化層の入力・出力に系統的な平均ずれが現れる。MLPの量子化後のずれは相対的に不規則で、単純な平均バイアスでは修正しにくい。D²Quantは「重みの復元誤差を減らす」だけでなく、「重み誤差が活性値に伝わった結果を補正する」二つの問題を別々に扱う。

## 手法

### 二重尺度量子化器（Dual-Scale Quantizer; DSQ）

通常の均一量子化では、重み行列 `W` を各出力チャネルの尺度 `s` とゼロ点 `z` で整数 `W_q` に変換し、復元時は `s(W_q-z)` を用いる。DSQはdown-projectionに追加の入力列方向の尺度 `s_c` を導入し、復元重みを `Q(W)⊙s_c` と表す。目的は元重みと復元重みのフロベニウスノルムの二乗を小さくすることである。

まず整数化規則を固定して列尺度 `s_c` を閉形式で更新し、次に列尺度を固定して `W/s_c` を再量子化する。これを交互に繰り返し、実験では15回で概ね収束した。重要なのは、up-projectionとdown-projectionの間で相反する尺度変換を入れても、元の浮動小数点の計算を等価に保てることである。down-projection側で得た列尺度を、既に量子化したup-projectionの行尺度へ吸収できるため、追加の独立した列尺度を推論時に保持・乗算する必要がない。

この尺度変換はdown-projectionの量子化難度を下げるが、全層の重みが完全に復元されるわけではない。最適化するのは重みの復元誤差であり、生成確率分布そのものの厳密な保存ではない。静的に一度だけ平滑化する方式では十分でないことを原著の反復回数別比較が示している。

### 活性偏差補正（Deviation-Aware Correction; DAC）

注意モジュールを量子化する前後で、注意後の正規化層の出力 `Y_fp` と `Y_q` を校正データで比較し、偏差 `ΔY=Y_fp-Y_q` を得る。各特徴次元についてトークン方向の平均 `μ` と分散 `σ²` を計算する。平均ずれが大きい特徴では、量子化後の正規化出力に `μ` を加えるだけで系統的な誤差を除去できる。

誤差の二乗平均は `μ²+σ²` に分解でき、平均補正後には `σ²` が残る。したがって理想的な平均補正の誤差削減率は `μ²/(μ²+σ²)` である。著者はこの量を信号対雑音比（SNR）と結びつけ、平均ずれが支配的な注意後の正規化層へDACを適用する。MLP後のすべての正規化層へ一律に補正を入れるわけではない。

原著の数式には注意点がある。式(13)ではSNRを `|μ|/σ²` と表記する一方、式(19)の導出では `μ²/σ²` をSNRと定義している。誤差削減率の式 `μ²/(μ²+σ²)` は二乗誤差の分解から導けるが、二つのSNR定義はそのままでは同一でない。実装では補正バイアスの平均推定が中心であり、SNR表記の不一致を理論保証として過大解釈しない。

### 層ごとの量子化手順

各Transformer層で、まず元の注意後正規化出力を校正データから保存する。Q/K/V/Oの注意重みを量子化した後、量子化後の注意出力を求め、DACで正規化層へ平均偏差バイアスを加える。続いてMLPのup/gateを量子化し、down-projectionへDSQを適用する。得られた列尺度はup-projection側へ吸収し、更新済みの量子化層を通した校正活性を次の層へ引き継ぐ。

この順序により、前段の量子化誤差を含んだ活性分布で後段を校正できる。校正サンプルはWikiText2から128本、各2,048トークン、量子化ブロック幅128を基本とする。量子化対象モデルの重みを再学習する必要はないが、元の高精度モデルで校正出力を求める前処理が必要になる。

## 評価

### 実験設定と2ビット量子化結果

| 項目 | 条件 |
|---|---|
| GPU | NVIDIA A800 80GB。70Bの評価は3基、それ以外は主に1基 |
| モデル | LLaMA-3/3.1 8B・70B、Qwen3 8B・14B・32B |
| 校正 | WikiText2 128サンプル×2,048トークン、量子化ブロック幅128 |
| 比較 | GPTQ、GPTAQ、BoA、QuaRotを併用した各方式 |
| 指標 | WikiText2・C4のPPL、MMLU、7つのゼロショット課題平均 |

| モデル、2ビット方式 | WikiText2 PPL | C4 PPL | MMLU | 7課題平均 |
|---|---:|---:|---:|---:|
| Qwen3-8B GPTQ | 23.28 | 55.55 | 37.05 | 47.82 |
| Qwen3-8B GPTQ+QuaRot | 15.27 | 28.60 | 46.53 | 54.05 |
| Qwen3-8B D²Quant | **14.10** | **25.96** | **49.94** | **57.22** |
| Qwen3-32B GPTAQ | 10.78 | 24.12 | 62.54 | 61.21 |
| Qwen3-32B D²Quant | **9.71** | **17.10** | **64.31** | **64.56** |
| LLaMA3.1-8B GPTQ | 18.61 | 120.14 | 23.76 | 44.04 |
| LLaMA3.1-8B D²Quant | **11.54** | **27.19** | **28.85** | **51.04** |

Qwen3-8Bの2ビットではDSQ単独でMMLUが45.49から48.97、7課題平均が53.94から57.21へ改善する。DAC単独ではMMLU45.82、平均54.63で効果は小さい。両者を組み合わせるとMMLU49.94、平均57.22となり、DSQが主な改善を担い、DACが追加改善を与える構成である。モデル・課題ごとに改善幅は異なる。

### 校正サンプル数と反復回数の感度

Qwen3-8BでDACの校正サンプル数を16にするとWikiText2 PPL15.75、C4 PPL31.15、MMLU42.06となり、校正なし基準の14.72、27.47、45.49より悪化する。32サンプルではMMLU49.44、64サンプルでは48.39、128サンプルでは49.94、256サンプルでは49.67であり、サンプルを増やすほどすべての指標が単調改善するわけではない。128を標準とする判断は、校正費用と実測結果の折衷である。

DSQは反復0回でWikiText2 PPL15.73、15回で14.41へ改善する。静的な平滑化だけではPPL14.85、MMLU44.99と一部悪化する。二重尺度を量子化目的の中で反復更新することが重要だと分かる。量子化時間はGPTQやGPTAQより長くなるが、BoAより短いと報告される。ただし論文の図は量子化前処理時間であり、生成時の実測速度倍率ではない。

## 限界

本研究は重みだけの学習後量子化を扱い、活性値の低ビット化や専用整数演算器での速度を直接検証していない。追加の列尺度はup-projectionに吸収できるが、DACのバイアスは正規化層の実装へ組み込む必要がある。量子化形式を実際の推論エンジンへ移植する際は、保存形式、正規化カーネル、量子化演算器の対応が必要である。

評価は校正データの分布に依存し、16サンプルでDACが逆効果となる条件がある。2ビットでのPPLやゼロショット精度は改善するが、元のFP16精度にはなお及ばない。数式(13)と(19)のSNR定義不一致は、理論的な解釈の注意点として残る。3ビットの追加評価は付録にあるが、あらゆるモデルで無損失になるわけではない。
