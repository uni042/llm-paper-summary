# FlatQuant: Flatness Matters for LLM Quantization

> 層ごとの学習可能アフィン変換を小さなクロネッカー積へ分解し量子化と融合して、LLaMA-3-70BのW4A4で精度低下1%未満とプリフィル最大2.3倍高速化を両立する。

## 概要

4ビット重み・4ビット活性値（W4A4）のような強い量子化では、少数の外れ値へ量子化範囲を合わせると、多数の通常値が少数の量子化点へ押し込まれて誤差が増える。SmoothQuant系のチャネル別スケーリングやHadamard回転は外れ値を弱めるが、前者は重み側を急峻にする場合があり、後者は全層で同じ固定回転を使うため層ごとの分布差を取り切れない。

FlatQuantは、各線形層について量子化後出力と元の出力の誤差を小さくする可逆アフィン変換を学習する。ただし隠れ次元nの完全なn×n行列を層ごとに持つと、変換計算と保存量が大きすぎる。そこで変換行列を二つの小行列のクロネッカー積として表し、計算量と追加メモリを抑える。さらに変換と量子化はいずれもメモリ帯域律速になりやすいため、Tritonで単一カーネルへ融合して中間テンソルのHBM往復を消す。

LLaMA-2/3を中心とした評価では、LLaMA-3-70BのW4A4で精度低下を1%未満に抑え、SpinQuantより7.5ポイント高い精度を示す。FP16と比べた実行速度はプリフィル最大2.3倍、デコード最大1.7倍である。

## 問題設定

量子化誤差は一つの層で終わらず、Transformerの後段へ伝播する。FlatQuantの観測では、特に初期トークンの大きな外れ値と、層を進むにつれて増える誤差が問題になる。チャネル別スケーリングは活性値を平坦にできても重み分布を悪化させることがあり、Hadamard変換は外れ値をチャネル間へ分散できても、各線形層固有の最適な方向を選ばない。

理想的には、線形層Y=XW^Tに対して、X側へP、W側へP^-1を掛ければ関数を保ったまま座標系を変えられる。しかし完全なPを層ごとに使うと、前向き計算で巨大行列積が増え、保存量もほぼ倍増し得る。つまり「精度のために強い変換を使う」と「量子化で速度を得る」が衝突する。

## 手法のあらまし

FlatQuantは、校正データを128文、各2048トークンだけ用い、Transformerブロック単位で元ブロック出力と量子化ブロック出力の二乗誤差を最小化する。学習対象はアフィン変換、チャネル別スケール、重み・活性値のクリッピング閾値である。モデル本体を再学習するのではなく、量子化用変換だけを校正する後学習量子化である。

大きなPはP1⊗P2へ分解する。隠れ次元8192なら例として64×64と128×128の小行列を使える。論文ではLLaMA-2-7Bで変換の追加演算を全FLOPsの2.61%、追加メモリを3.41MBに抑える。

自己注意ではQ/K/V入力、出力射影、キー・値キャッシュへ異なる変換を割り当て、FFNでも入力側とdown projection側を分ける。最後にオンライン変換と量子化をTritonカーネルへ融合し、中間結果をSRAM内に保ったままINT4行列積へ渡す。

## 手法

### 1. 層固有の可逆アフィン変換

目的関数は、元の線形出力と、XPおよびP^-1W^Tを量子化して積算した出力との差を最小化する。Pは層ごとに異なるため、固定Hadamard回転よりその層の外れ値配置へ適応できる。

変換後の重み側はオフラインで事前計算できるが、活性値側は推論時に変換が必要である。したがって精度だけを最適化して完全行列Pを採用すると、量子化による高速化を変換費用が打ち消す。次の分解がこの問題を解く。

### 2. クロネッカー積分解

P=P1⊗P2とし、入力を小さな2次元形状へreshapeしてP1^T X P2として処理する。n1×n2=nとなる小行列を選び、n1+n2が小さくなる組合せを使う。n=8192では64と128の組が例示される。

この構造により完全行列に比べて保存量は最大n/2倍、計算量は√n/2倍の削減余地があると論文は整理する。重要なのは、固定直交行列ではなく学習可能性を残したまま、オンライン変換を小さくする点である。

### 3. スケーリングと学習可能クリッピング

アフィン変換だけで残る外れ値へ対し、チャネル別スケールcと、重み・活性値のクリッピング閾値αw、αaを同時最適化する。スケールは前段のLayerNormや線形層へマージできるため、推論時の追加演算を避ける。

校正は各Transformerブロックを順に行い、元ブロックと量子化ブロックの出力二乗誤差を最小化する。128×2048トークン、15 epoch、バッチ4の既定設定で、LLaMA-3-8Bは単一GPUで約26GB、約0.9時間の校正費用を要する。これは完全な再学習より軽いが、即時変換ではない。

### 4. Transformer内の配置

自己注意では入力Q/K/V用Pa、出力射影用Po、キー・値キャッシュ用Ph/Pvを使う。ヘッド次元は隠れ次元より小さいためPh/Pvは分解せず、PoとPvは融合して追加費用を減らす。FFNではPugとPdを使い、Pdのチャネルスケールをup projection重みへ吸収する。

この細分化により、層だけでなく線形部位ごとの分布差を扱える。一方、変換パラメータが増えるため校正工程と実装はHadamard固定回転より複雑になる。

### 5. 融合Tritonカーネル

クロネッカー変換と量子化はいずれも計算強度が低く、別カーネルにすると中間活性値をHBMへ書き戻して再読込みする費用が大きい。FlatQuantはP1/P2をSRAMへ置き、タイル化した活性値へ変換を施し、その場で量子化してから最終結果だけをグローバルメモリへ書く。

INT4行列積はCUTLASS、KV量子化はFlashInferを利用する。論文が報告する速度向上は、量子化方式だけでなく、この融合によって変換オーバーヘッドを抑えた結果である。

## 既存研究との差

SmoothQuant系は主にチャネルごとのスケールで重みと活性値の外れ値負担を移す。QuaRot/SpinQuantは回転で外れ値を分散するが、固定または制約された変換である。FlatQuantは各線形層に学習可能な一般アフィン変換を与えつつ、クロネッカー積で実行費用を抑える点が異なる。

また、精度だけを改善する量子化校正ではなく、変換を量子化と同一カーネルへ融合し、W4A4の実測プリフィル/デコード速度まで示している。

## 限界・実装状況

校正にはモデルごとに時間とGPUメモリが必要で、完全なcalibration-free方式ではない。オンライン変換を残すため、ハードウェアやカーネル実装が融合を十分利用できない環境では速度利得が小さくなる。

評価は主にLLaMA系とGPU低ビットカーネルを中心とする。4ビット量子化の品質はモデル分布に依存し、同じ設定を任意の新アーキテクチャへ無検証で適用できる保証はない。

## 一般的な実装上の含意

量子化では「外れ値を小さくする」だけでなく、重みと活性値の両方を同時に平坦化し、層ごとの誤差伝播を抑えることが重要である。また、数学的に良い変換でも推論時に別カーネルを増やせば利得を失うため、変換の構造化とカーネル融合を同時設計する必要がある。
