# A Unified Hessian-Guided Framework for Post-Training Quantization

> 層出力のFisher情報をクロネッカー分解で近似し、変換・スケール・丸め・クリッピングを単一の下流感度目的で統一的に決める学習後量子化で、4ビット条件の全対象モデルで最良のパープレキシティを達成した研究。

## 概要

低ビット量子化は、重みと活性値を少ないビット数で表すことでメモリ使用量と計算費用を下げ、大きな言語モデルの配備を現実的にする技術である。ビット数を固定したとき品質を決めるのは、値を表す格子の刻みと範囲を決めるスケール選択、表現の基底を変えて外れ値を均す線形変換、重みを格子の点へ割り当てる丸め、そして活性値の裾を切り落とすクリッピングである。従来手法はこれらを部品ごとに、層の出力の再構成誤差という局所的な目的で最適化してきた。しかし論文がLlama 3.2 1Bの全線形層で測ったところ、再構成誤差の大きさと最終出力のKLダイバージェンスの相関は弱く、局所的に小さい誤差が下流では大きく効くこともあれば、その逆もある。重みだけのヘッセ行列で下流影響を捉える近年の手法も、活性値量子化の誤差を取り込めない。

本論文は、層出力を摂動させたときの出力分布のKLダイバージェンスを2次形式で近似し、その2次形式の重みである層出力のFisher情報を、系列方向と特徴方向のクロネッカー積へ分解して扱える形にする。この単一の近似目的から、変換の設計、重みスケールと適応的丸め、活性値クリッピングのすべてを導く統合手順が本論文の提案である。代表結果として、重み・活性値・KVキャッシュをすべて4ビット化する粗い条件で、Llama 3.2 1BのWikiTextパープレキシティは全精度の13.16に対し16.05となり、変換を学習する最も強い比較対象の17.23、回転系と丸めの組み合わせの20.03を上回った。8B級の3モデルでも同様に全モデルで最良のパープレキシティを示し、32個単位のブロック量子化でも順位は維持された。

## 問題設定

量子化の難しさは、誤差の大きさと誤差の効き方が一致しないことにある。スケールを狭くすれば格子は細かくなるが大きな値が切り捨てられ、広くすれば切り捨ては減るが通常値の分解能が落ちる。変換で基底を変えれば重みと活性値の大きさの分布は均されるが、どの方向を均すべきかは下流への感度で決まるはずである。ところが再構成目的はすべての出力方向を等しく扱うため、最終予測に強く効く方向の誤差と、ほとんど効かない方向の誤差を区別できない。丸めについても、重みごとの誤差ではなく、丸め誤差が活性値と掛け合わされ、さらに後段の層を通って出力へ伝わる過程全体が問題になる。先行する下流感度型の手法は重み側の曲率だけを使うため、活性値を量子化したときの誤差が目的に入らず、重みと活性値を同時に低ビット化する条件では設計指針がずれる。本論文はこの欠落を、層の出力そのものに対する曲率を使うことで埋める。出力側の曲率は、誤差が重み由来でも活性値由来でも、出力の摂動として同じ土俵で測れるからである。ただし出力側のFisher行列は系列長と出力次元の積の2乗の大きさになり、そのままでは推定も保存もできないため、構造を持った近似が不可欠になる。

## 手法のあらまし

出発点は、1つの線形層を量子化版へ置き換えたときに生じる出力分布の変化を、その層の出力の摂動に対する2次展開で表すことである。発散を測る損失では展開の0次と1次は消え、残る2次項がヘッセ行列で重み付けした摂動のノルムになる。KLダイバージェンスを選ぶとこのヘッセ行列はFisher情報行列と一致する。本論文はこれを、出力勾配の系列方向の共分散と特徴方向の共分散のクロネッカー積で近似する。出力勾配がランク1に近いときこの分解は各サンプルの外積を正確に再現する。この近似が決まれば、量子化の各部品は同じ2次目的の部分問題になる。まず変換を、量子化範囲と変換後勾配ノルムの積で表される近似式から決める。次に変換後の座標で、重み側の曲率をブロック分解し、タイルごとにスケールを選びながら丸め誤差を未処理の重みへ伝播させて補正する。最後に活性値クリッピングの係数を、トークンごとの勾配の大きさで重み付けした誤差が最小になるよう候補から選ぶ。部品を足すのではなく、1つの近似から全部品を導く点が枠組みとしての主張である。

## 手法

### 1. 出力クロネッカーFisher — 下流感度を扱える大きさへ落とす

この機構が観測するのは、キャリブレーションデータに対する各層の出力勾配である。保持する状態は3種類で、出力特徴方向の曲率の期待値、重み入力方向の曲率の期待値、そしてトークンごとの勾配の大きさのベクトルである。入力特徴方向の曲率は、重み行列を両側から掛けることで出力側の曲率から実行時に導けるため、別に保存しない。クロネッカー分解により、保存量は系列長と出力次元の積の2乗から、それぞれの2乗の和の水準まで下がる。効く理由は2つある。第1に、重み量子化の誤差も活性値量子化の誤差も、層出力の摂動としては同じ2次形式で評価できるため、両方を同時に低ビット化する条件でも目的が一貫する。第2に、図で示された相関の通り、この重み付け誤差は素朴な再構成ノルムや重み側だけのFisher重み付けより、実際の出力KLと強く相関する。近似の代償として、出力勾配がランク1から大きく外れる層では分解の精度が落ちること、勾配を必要とするため勾配不要の再構成手法よりキャリブレーションの時間とメモリが増えることがある。

### 2. 変換の設計 — 勾配の幾何平均とアダマール回転

変換は、活性値に変換行列を、重みにその逆行列を掛けることで、全精度の層出力を変えずに量子化される表現だけを変える操作である。本論文は丸めノイズの仮定の下で2次目的を変換の関数として書き下し、量子化範囲の2乗と変換後勾配ノルムの積の和になることを示す。この式は直交変換に対して不変であり、対称正定値成分については、重み勾配と入力勾配の共分散の行列幾何平均として閉じた形の解が得られる。直感的には、重み側で敏感な方向と活性値側で敏感な方向の釣り合いが取れる基底へ回す操作である。実務上はメモリと計算を抑えるためブロック単位の近似を使い、最後にアダマール回転を掛けて量子化範囲をさらに均す。従来の変換設計が活性値と重みの共分散そのものを使っていたのに対し、本論文はその勾配版を使う点が異なる。出力勾配が等方的なら従来法と一致するため、従来法はこの枠組みの特殊な場合として位置づけられる。変換を外して素のアダマール回転へ戻すと除去実験で最も大きく劣化したことからも、この段階が全体の利得の最大の源泉であることが分かる。

### 3. 重みスケールと適応的丸め — 曲率で重み付けして誤差を先へ逃がす

変換が固定されれば、重み量子化の誤差は入力側曲率と出力側曲率のクロネッカー積で重み付けした重み誤差になる。本論文は両側の曲率を量子化タイルの大きさに合わせてブロック分解し、対角ブロックからタイルごとの曲率を取り出す。タイルごとに、曲率で重み付けした誤差が最小になるスケールを候補の格子探索で選び、そのタイルの丸め誤差を、分解から得られる三角行列を使ってまだ量子化していないブロックの重みへ加算して補正する。処理は対角と逆方向の順序で進み、曲率のトレースが大きいブロックから先に量子化する。これは適応的丸めの古典的な考え方だが、スケール選択まで同じ曲率で重み付けする点と、入力側だけでなく出力側の曲率も入る点が新しい。従来の範囲選択が再構成誤差の指数を選ぶハイパーパラメータ調整を要したのに対し、曲率重み付けの目的は調整なしで最良の再構成目的と同等以上だったと報告されている。失敗条件として、曲率推定に使うキャリブレーション分布が実際の入力分布とずれれば、重み付け自体がずれて利得は縮む。

### 4. 活性値クリッピング — トークンの感度で裾の切り方を決める

活性値は入力ごとに変わるため、重みのように固定のスケールは持てない。本論文は系列全体で共有するクリッピング係数を1つ持ち、実行時にその入力の最大値へ係数を掛けた範囲で格子を作る。この係数の決め方に同じ近似目的を使う。活性値の量子化誤差を、トークンごとの出力勾配の大きさで重み付けし、特徴方向は入力曲率で重み付けした誤差として表し、係数の候補の中からキャリブレーション上で誤差が最小のものを選ぶ。系列方向の曲率は対角成分だけを保持するため、追加の保存はベクトル1本で済む。論文はこの対角近似による誤差は小さいと実測で確認している。除去実験ではクリッピングを外す劣化は変換の次に大きく、特に重みと活性値を同時に4ビット化する条件で効く。逆に言えば、重みだけの量子化ではこの機構の寄与は相対的に小さい。

## 評価

### まず見るところ

結論は、統一目的の利得は部品の総和として現れる、ということである。最も粗いチャネル単位の4ビット条件で改善幅が最も大きく、32個単位の細かいブロック条件でも順位は崩れなかった。これは、細かい条件では範囲の均し直しの余地が減るにもかかわらず、スケールと丸めの下流感度化が効き続けるためと読める。一方で、評価はすべて品質指標であり、量子化で本来得られるはずの推論速度やメモリ削減の実測はない。ビット幅が同じ比較対象同士では速度はほぼ等しいはずだが、変換の融合方法によっては実行時費用が変わりうるため、速度の未評価は実務判断上の欠落として残る。

数値の読み方として、全面4ビット条件のパープレキシティは全精度との差が依然として大きく、例えば1Bモデルでは13.16から16.05への劣化は残る。本論文の主張は劣化の解消ではなく、同じビット幅で使える最良の設計を1つの目的から得ることにある。ブロック単位では劣化幅が小さく、1Bモデルで全精度13.16に対し13.53まで迫る。

### 品質・精度

## 既存研究との差

適応的丸めの系譜は、丸め誤差を後続の重みで補正する発想と曲率による重み付けを発展させてきた。変換の系譜は、回転や学習可能な変換で重みと活性値の大きさを均し、量子化しやすい基底を作ってきた。下流感度の系譜は、重み側のFisherで最終損失への影響を近似してきた。本論文の差は、この3系譜を部品の寄せ集めとしてではなく、層出力のFisherという1つの近似から全段を導く形に再構成した点にある。特に、変換の設計式が出力勾配の等方性を仮定すると従来の変換設計と一致することは、従来法を否定するのではなく特殊な場合として含む統合であることを示す。また活性値量子化の誤差を同じ目的に入れたことで、重みと活性値を同時に落とす条件でも設計が一貫するようになった。

## 限界・実装状況

枠組み自体が近似の積み重ねである点は著者らも明記している。前提には、出力変化の2次展開、Fisherのクロネッカーかつランク1型の分解、重み誤差と活性値誤差の分離、丸めノイズと共分散に関する仮定が含まれる。出力勾配の推定は勾配不要の再構成手法に比べてキャリブレーションの時間とメモリを増やす。非一様量子化、混合精度、ハードウェアを意識した量子化への拡張は今後の課題とされる。評価面では推論速度と実メモリが測られておらず、変換を実ランタイムへ融合した際の費用は不明である。公式コードの公開先は論文中に記載されていない。

## 一般的な実装上の含意

量子化ツールを選ぶ際は、部品ごとのベンチマーク順位より、目的関数が下流の何を近似しているかを見るべきである。局所再構成で勝つ部品の組み合わせが最終品質で勝つとは限らない。キャリブレーションに勾配を使える環境では、重みだけでなく層出力の感度まで取ることで、変換とクリッピングのような周辺部品の設計まで同じ物差しで決められる。逆にキャリブレーション費用が厳しい環境では、曲率モデルの質と費用の交換が設計の中心になる。
