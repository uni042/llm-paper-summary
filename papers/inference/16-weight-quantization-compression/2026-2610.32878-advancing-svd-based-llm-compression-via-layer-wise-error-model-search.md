# Advancing SVD-based LLM Compression via Layer-Wise Error Model Search

> 層ごとの誤差を形・較正・伝播バイアスでモデル化して整数線形計画で最適なランク配分を解き、フィッシャー因子はトークン単位の統計で推定してランク崩壊を防ぐSVD圧縮で、同じ予算でも精度を大きく保てるようにした。

## 概要

特異値分解（SVD）による低ランク圧縮は、重み行列を小さな2つの行列の積へ置き換え、パラメータ数と行列積の計算量を減らす圧縮である。疎な重みと違い結果は密な行列のままなので、専用カーネルなしに通常の推論基盤でそのまま速くなる利点がある。ただし品質は2つの設計で決まる。1つはランク配分、つまり固定のパラメータ予算の下で各層に何ランク残すかである。全層一律では、圧縮に弱い層を削りすぎ、強い層を残しすぎる。もう1つは分解の質、つまりどの方向の重みを残すかである。重みの再構成誤差を最小にする通常の特異値分解は、損失にとって大事な方向を優先しない。

従来法はどちらの設計でも詰まっていた。配分探索は、特異値スペクトルの尾のエネルギーのような代理指標を層間で比べるが、この指標は層の種類ごとに実損失への効き方が違い、較正されていないため順序がずれる。誤差を層間で均一にする方針も、全体の劣化を最小にすることとは違う。さらに、浅い層で生じた誤差は後段の層を通るたびに増幅されるのに、層ごとの誤差を独立に足すモデルでは全体を過小評価する。分解側では、損失の曲率を表すフィッシャー情報行列で重み付ける方式が有望だが、既存の推定は系列単位の勾配を少数集めて作るため、近似行列のランクがサンプル数以下に頭打ちになり、固有値スペクトルが潰れるランク崩壊を起こしていた。

本論文は2つの提案で対処する。配分側のLEMS（層別誤差モデル探索）は、層ごとの誤差を、スペクトルから得られる形、単一の参照圧縮率で実測した較正の尺度、深さに応じて浅い層を重くする伝播バイアスの3つの積としてモデル化し、総誤差を最小化する配分を整数線形計画（整数線形計画法; 離散的な選択を予算制約の下で大域的に解く最適化）で数秒で解く。分解側のKFAC-SVDは、フィッシャー行列のクロネッカー因子（大きな行列を2つの小さな行列の積で近似する因子）を、系列単位の勾配ではなくトークン単位の入力と出力勾配の二次の統計量から推定し、有効サンプル数を系列数からトークン数へ桁違いに増やしてランク崩壊を断つ。

**代表結果:** 保持率0.8（線形層のパラメータを8割残す）条件で、LEMSのゼロショット平均精度はMistral-7Bで57.61点、Llama 3-8Bで56.77点、Qwen3-8Bで59.03点となり、最良の従来探索より2.1から4.7ポイント高かった。分解側では、フィッシャー系の従来法GFWSVDがLlama 3-8BのWikiText2困惑度で2569.75まで崩れる条件でもKFAC-SVDは8.49に抑え、LEMSと組合わせると6.51まで下がった。

## 問題設定

問題を資源の観点で見る。低ランク圧縮の予算はパラメータ総量であり、層ごとに残すランクの合計が決まっている。同じ予算でも配分で品質が大きく変わるのは、層ごとに圧縮への弱さが違い、しかも誤差の効き方が独立ではないためである。浅い層の誤差は、その層の出力のずれとして後段全ての入力をずらし、深さとともに増幅される。したがって配分探索に必要なのは、層単体の感度ではなく、伝播まで含めた全体劣化の予測である。

予測の難しさは3つに分解できる。第1に粒度である。全層の全候補ランクについて実測で劣化を測るのは計算量が膨大になる。第2に尺度である。スペクトルの尾のエネルギーは層内での相対的な形は教えても、注意機構の射影で10パーセント失うことと全結合の射影で10パーセント失うことの実損失の違いを教えてくれない。第3に伝播である。層ごとの劣化を単純に合計すると、深い圧縮ほど全体を過小評価する方向にずれる。従来の探索はこの3つのうち一部しか扱えず、貪欲法は大域最適の保証がなく、均一誤差の方針は目的自体が全体最小化とずれ、勾配で学ぶ配分は調整が重い。本論文の誤差モデルは、この3つを別々の因子として分離し、それぞれ安い方法で埋める設計である。

分解側の問題は推定の統計量である。フィッシャー重み付き分解は、重みを白化（曲率で重み付けした座標へ変換すること）してから特異値で切ることで、損失に効く方向を残す。ところが白化に使う因子を系列単位の勾配の外積和から作ると、その和のランクは系列数以下に制限される。現実の校正では系列数は高々256程度で、層の次元は数千あるため、曲率はごく低次元の部分空間でしか観測されず、固有値が急速に減衰するスペクトル崩壊が起きる。切捨てのたびに曲率の情報が失われ、分解の質が崩れる。

## 手法のあらまし

処理は校正、因子推定、誤差モデルの構築、配分の求解、分解の適用の順に進む。まず校正データとしてWikiText2から長さ2048の系列を256本取り、各層について入力の共分散と、トークン単位の入力と出力勾配の二次の統計量を集める。これらからクロネッカー因子を推定し、白化した重みの特異値スペクトルを得る。次に層ごとに、保持率0.1のような強い圧縮の参照点でその層だけを圧縮したときの出力分布のKLダイバージェンス（元の出力分布とのずれ）を実測し、スペクトルの形を実損失の尺度へ較正する係数を求める。さらに深さ依存のバイアスを掛けて層別誤差モデルを完成させ、全層の候補保持率に対する誤差の表を作る。最後に、パラメータ予算の下で総誤差を最小にする保持率の組合せを整数線形計画で解き、決まったランクで各層を2つの低ランク行列へ分解して置き換える。推論時は通常の密な行列積として実行され、追加の仕組みは要らない。

## 手法

### 1. KFAC-SVD — トークン単位の統計でフィッシャー因子のランク崩壊を断つ

この機構が観測するのは、校正系列の各トークン位置における層への入力ベクトルと、出力に対する勾配ベクトルである。保持する状態は2つの二次の統計量、すなわち入力同士の外積の平均と出力勾配同士の外積の平均であり、これらがフィッシャー行列のクロネッカー因子になる。従来のGFWSVDが系列ごとの重み勾配を数百本集めて因子を作るのに対し、本方式は系列数×系列長のトークンを有効サンプルとして使う。例えば256系列×2048トークンで約52万サンプルとなり、因子のランクの上限が次元側で決まるようになる。行う動作は、この因子で重みを両側から白化し、特異値を小さい順に切って低ランク化し、白化を戻して2つの行列へ分けることである。減るボトルネックは曲率推定の潰れであり、白化の座標で本当に損失へ効く方向が残るため、同じランクでも再構成の質が上がる。追加で消費する資源は、校正時の勾配計算と統計量の蓄積であり、推論時の費用は変わらない。失敗条件も論文が認めており、トークン間の二次の相互作用を落とす近似であることと、勾配計算そのものが必要で校正の効率に限界があることである。ただし実測では、この近似の代償よりスペクトル崩壊を避ける利益が大きく、保持率0.7のLlama 3-8Bで従来のフィッシャー法が困惑度で桁違いに崩れる条件でも本方式は16.23に収まった。

### 2. LEMSの誤差モデル — 形、尺度、伝播バイアスを分けて層別誤差を予測する

この機構が観測するのは、白化した重みの特異値スペクトル、各層の参照点での実測KLダイバージェンス、その層が属するブロックの深さである。保持する状態は3因子の積で書かれる層別誤差関数である。第1の因子は形で、候補ランクで切ったときに失われる特異値エネルギーの割合であり、層内での劣化の増え方を細かい粒度で安く教えてくれる。第2の因子は尺度で、参照点における実測の劣化をその点のスペクトル値で割った較正係数であり、形を実損失の大きさへ引き上げる。第3の因子はバイアスで、浅いブロックほど大きく深さとともに滑らかに減る調和型の重みであり、誤差が下流へ伝播して増える分を先回りして罰する。その強さと減衰は軽量なハイパーパラメータ探索でモデル系列に合わせて決める。行う動作は誤差の予測であり、全候補保持率について層別誤差の表を前計算する。減るボトルネックは配分判断の誤りであり、特にスペクトルだけの指標では順序が逆転する層間比較と、伝播を無視した過小評価を直す。除去実験が示すように、スペクトルの形だけで配分を解くと一様配分より困惑度が8割から9割悪化し、較正を入れると一様配分を下回り、バイアスを加えて初めて大きく改善する。つまり3因子は飾りではなく、較正なしでは探索自体が有害になる。追加で消費する資源は参照点の実測であり、層ごとに1回の圧縮と評価が要る。初回は8B級モデルで20分から25分かかるが、結果は保持率を変えても再利用できるため、2回目以降の探索は約3分で済む。失敗条件はモデルの性質への依存であり、伝播の強いモデルではバイアスの効果が大きく、頑健なモデルではほぼ中立になるなど、補正の効き方は系列ごとに異なる。

### 3. 整数線形計画による大域配分 — 予算の下で総誤差最小の組合せを解く

この機構が観測するのは、全層の候補保持率ごとの予測誤差とパラメータ量である。保持する状態は、各層について候補を1つだけ選ぶ二値変数と、全体のパラメータ予算の制約である。行う動作は組合せ最適化であり、予測総誤差を最小化する候補の組合せを、市販ソルバーで数秒で大域的に解く。各層の保持率の探索範囲は0.3から1.0である。減るボトルネックは、貪欲法や均一化の方針が陥る局所解と目的のずれであり、配分の質が探索手続きではなく誤差モデルの正確さで決まる形に整理される。追加で消費する資源はソルバーの計算であり、誤差モデルの構築に比べれば小さい。失敗条件はモデルの誤差そのものであり、予測がずれれば最適解もずれる。だからこそ前段の較正とバイアスが本質であり、この求解器はそれを忠実に配分へ変える部品として位置づけられる。なお本方式は分解方法を選ばない。活性値基準のSVD-LLMにLEMSを組み合わせても大きな改善があり、むしろ改善幅はフィッシャー系より大きかったことは、配分の悪さが従来の劣化の主因だった場面が多いことを示す。

| 構成要素 | 入力・観測 | 具体的な動作 | 改善対象 | 主なトレードオフ |
|---|---|---|---|---|
| トークン単位の因子推定 | 各トークンの入力と出力勾配 | 二次の統計量からクロネッカー因子を作り白化する | フィッシャー推定のランク崩壊 | 校正に勾配計算が要る |
| 誤差モデルの較正 | 参照点での実測KLとスペクトル | 形に尺度係数を掛けて実損失の大きさへ直す | 層間比較の順序のずれ | 初回に層数に比例する実測費用 |
| 伝播バイアス | ブロックの深さ | 浅い層の誤差を割り増して罰する | 誤差増幅の過小評価 | 効き方がモデル系列に依存する |
| 整数線形計画 | 全層の誤差表と予算 | 総誤差最小の保持率の組合せを解く | 貪欲法の局所解 | 予測誤差がそのまま配分の誤差になる |

### 4. 1つの重み行列の流れ — 校正から置き換えまで

ある線形層の重みは次のように処理される。校正系列が流れると、その層の入力と出力勾配の統計が蓄積され、因子が作られる。因子で白化した重みの特異値スペクトルが誤差の形を与え、参照点でその層だけを強く圧縮したときの出力のずれが尺度を与える。深さのバイアスを掛けた誤差表が配分問題へ渡り、予算の下でその層に割り当てられる保持率が決まる。最後に白化座標でそのランクまで特異値を切り、逆白化して特異値の平方根を両側へ分けた2つの行列として実装される。バイアス項は元のまま保持される。本方式は近似手法であり、圧縮後の出力は元と一致しない。量子化とは直交するため、両者を組み合わせる余地が残ることも論文は述べている。

## 評価

結論は三点である。第1に、配分探索の比較ではLEMSが全6条件（3モデル×2保持率）で最高のゼロショット精度を取り、困惑度も一様配分比で26パーセントから75パーセント下げた。第2に、分解の比較ではKFAC-SVDが困惑度でほぼ全条件最良となり、特にフィッシャー系従来法の崩壊を完全に回避した。第3に、効果はモデル規模に広がり、Qwen3の4Bから32BとLlama 3.1-70Bでも一様配分への改善が続いた。評価は実機のH200での困惑度とゼロショット精度が中心で、推論高速化だけは別途A100で実測されている。

### 感度・スケーリング・ストレス条件

較正の参照点は強い圧縮側の0.1が選ばれており、0.3の方がゼロショット精度は最大0.9ポイント良いが困惑度は0.1が優るため、生成の忠実さを優先して0.1が既定になっている。較正指標はKLダイバージェンスが平均二乗誤差より精度で最大1.6ポイント優れた。校正データの量、乱数シード、データセット種別の感度も付録で検討されている。積極的な圧縮ほどLEMSの利得が大きく、保持率0.5では困惑度の削減がKFAC-SVDで約26パーセント、SVD-LLMで約57パーセントに達した。

## 既存研究との差

ASVDは層ごとの候補を評価し誤差の閾値を二分探索で揃える方式で、誤差の均一化を目指す。本論文は均一化ではなく較正済み総誤差の最小化を目指し、伝播バイアスまで入れる点が異なる。SVD-LLMv2は重みの種類ごとに圧縮を再配分するが、相対的な寄与の推定は取り除いた特異値に基づく。本論文は実測KLで尺度を合わせる。ATPは誤差伝播を理論的に扱うが、深さに対する線形な一様圧縮を仮定する。本論文は層と種類ごとの重要度の違いを残したまま伝播をバイアスとして入れる。ARSのような勾配で学ぶ配分に対しては、学習不要で求解が数秒という運用の軽さが差になる。分解側では、GFWSVDのクロネッカー因子推定を系列単位からトークン単位へ替えたことが差であり、同じ白化と切捨ての枠組みのまま推定だけを直している。同時期の研究との比較も付録で扱われている。

## 限界・実装状況

論文が結論で挙げる限界は二つある。第1に、KFAC-SVDは依然として勾配計算に依存するため、校正の計算効率に限界がある。第2に、LEMSの層別較正は深さに比例して費用が増え、大規模モデルでは初回の実測が重くなる。今後の方向として、誤差伝播の解析的な上限の定式化と、視覚言語モデルや混合専門家モデルへの拡張が挙げられている。読み手の注意点として、評価は英語の言語モデリングとゼロショット分類型の課題が中心であり、対話生成や検索拡張のような応用条件での品質は未評価である。実装状況としては、ICML 2026に採択され、公式プロジェクトページからコードへの導線が示されている。

## 一般的な実装上の含意

圧縮や量子化のような近似の配分問題では、代理指標をそのまま層間で比べず、必ず実測で尺度を合わせてから最適化すべきである。較正されていない探索は一様な配分より悪くなり得る。また、深いネットワークでは局所誤差の合計は全体劣化の予測にならず、伝播の補正が要る。推定側では、有効サンプル数が近似行列のランクを頭打ちにする設計は、サンプル単位を細かくするだけで大きく改善する場合がある。系列ではなくトークンを数えるという発想は、他の曲率推定や重要度推定にも通じる。
