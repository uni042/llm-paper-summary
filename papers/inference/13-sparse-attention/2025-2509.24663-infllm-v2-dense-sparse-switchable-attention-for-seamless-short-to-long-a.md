# InfLLM-V2: Dense-Sparse Switchable Attention for Seamless Short-to-Long Adaptation

> 密注意のK/V射影を再利用し、短文脈は密、長文脈はパラメータ追加なしのブロック疎注意へ切替えて、長文脈性能をほぼ保ちながら実推論を高速化する。

## 概要

標準自己注意は系列長に対して二次の計算・メモリ費用を持つ。学習可能な疎注意は長文脈を軽くできるが、Native Sparse Attention（NSA）のように密注意とは異なる複数K/V射影や分岐を追加すると、「短文脈で事前学習して長文脈で微調整する」一般的な工程で初期状態が揃わず、収束と実装効率の両方に負担が出る。

InfLLM-V2は密注意と疎注意で同じK/V射影を共有する。短い入力では元の密注意を使い、長い入力では局所ブロック、初期ブロック、重要度上位ブロックの和集合だけへ注意する疎モードへ切り替える。重要ブロックの選択には学習可能な追加射影を使わず、平均・最大プーリングによる多段圧縮で候補を絞る。

長文脈理解と思考連鎖評価では、密注意より4倍高速な注意処理で性能をそれぞれ98.1%、99.7%保持する。128K系列・8B・可視6Kトークンのエンドツーエンド測定では、RTX 4090でプリフィル2.13倍・デコード2.32倍、A100で1.99倍・1.82倍の高速化が報告される。

## 問題設定

疎注意では「どの過去ブロックを見るか」を決める検索処理が必要である。検索用に別のK/V表現を学習すると、既存密注意checkpointからその部分を初期化できず、長文脈微調整の初期損失が乱れる。また疎化判定がGPU上で非効率なら、理論的に読むトークン数を減らしても壁時計時間は縮まらない。

短文脈では密注意自体が十分速いため、常に疎注意を使う必要もない。したがって同一checkpointで短文脈の密モードと長文脈の疎モードを切り替え、両者のパラメータ分布を揃えることが狙いになる。

## 手法

### 共有K/V射影と切替可能な注意

密モードと疎モードは同じK/V射影を使う。短系列では通常の全注意を実行し、長系列では疎ブロック集合へ限定する。別checkpointや追加K/V投影を持たないため、短文脈事前学習済みモデルの重みをそのまま長文脈微調整の初期値にできる。

疎モードでは、文頭の初期ブロック、現在位置近傍の局所ブロック、内容に基づいて選んだ上位ブロックを統合する。これにより注意シンク・近傍依存・遠距離検索の三種類を一つの疎パターンで扱う。

### パラメータなしの多段ブロック選択

K/Vを平均・最大プーリングで粗い表現へ圧縮し、クエリとのスコアから候補を段階的に絞る。学習可能な圧縮器を別に置かないので、密注意からの移行時に未学習パラメータを増やさない。

ブロック選択は注意本体より軽くなければ意味がない。実装はヘッド群の集約、オンチップメモリ利用、選択と注意の融合を行い、正規化に必要な対数和指数（log-sum-exp; LSE）も近似する。128KのA100では、この近似によりブロック選択時間が75.36msから56.59msへ低下する条件が報告される。

### 短文脈から長文脈への適応

長文脈微調整では疎モードを学習するが、基礎K/V射影は密モードと共有される。推論時は系列長に応じて密・疎を切り替えるため、短い一般タスクで疎検索の固定費を払わず、長文脈だけ計算量を削減する。

## 評価条件・主要結果

| 項目 | 代表条件・結果 |
|---|---|
| モデル | 8B級、MiniCPM4.1の公開実装を含む |
| 長文脈 | 最大128K級の測定 |
| 疎モード | 代表例で96ブロック、約6K可視トークン |
| カーネル | A100でFlashAttention比最大7.4倍、RTX 4090で最大9.3倍 |
| エンドツーエンド RTX 4090 | プリフィル2.13倍、デコード2.32倍 |
| エンドツーエンド A100 | プリフィル1.99倍、デコード1.82倍 |
| 長文脈理解 | 密注意性能の98.1%を保持 |
| 思考連鎖 | 密注意性能の99.7%を保持 |

RULERでは疎モード82.62%に対し密注意84.26%、NSA 59.92%という条件が報告される。LongBenchでは42.54%で密注意42.30%と同程度である。カーネル単体の7〜9倍とモデル全体の約2倍は区別する必要があり、後者ではFFNなど非注意処理が残る。

## 既存研究との差

NSAは複数の注意分岐と追加K/V射影を持つのに対し、InfLLM-V2は密注意の投影を共有し、疎パターンの出力を一つへ統合する。元のInfLLMが学習なし長文脈外挿を狙うのに対し、V2は短文脈事前学習から長文脈微調整へ自然に移れる学習可能方式として設計されている。

## 限界

疎モードを有効にするには長文脈微調整が必要で、任意の既存モデルへ完全無学習で差し替える方式ではない。重要ブロック選択を誤ると完全注意で参照できた情報を失う。最大カーネル高速化は注意部だけの値であり、FFNが支配的になる条件ではエンドツーエンド倍率が小さくなる。
