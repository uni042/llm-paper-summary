# BOSCH：注意頭ごとのSWA化を黒箱探索する事後ハイブリッド化

## 概要

BOSCH（Black-Box Binary Optimization for Short-Context Attention-Head Selection）は、すでに学習された大規模言語モデル（LLM）を、全域因果注意（global causal self-attention）とスライディングウィンドウ注意（Sliding Window Attention; SWA）の混成構造へ変換する際、**どの注意頭を局所注意へ置き換えるか**を黒箱探索で決める手法である。SWAは直近の固定長ウィンドウだけを参照するため、長い系列に対するKVキャッシュの増大を抑えられるが、長距離の依存を担う注意頭を誤って置換すると検索や質問応答の性能が急落する。

従来の単純な方法は層単位で全頭をSWA化するか、事前に測定した各注意頭の「局所的らしさ」で並べて上位から置換する。しかし、ある頭の役割は他の頭の置換後に変化する。全域注意を残す頭の組合せによって、同じ頭でも局所化の影響が変わるという**頭間の絡み合い（entanglement）**が問題である。BOSCHは、全頭の二値選択を一度に解くのではなく、層の感度を小規模探索で測り、各層に局所化予算を割り当て、同じ予算群に属する複数層の頭を共同で最適化する。

ACL 2026の原著ではQwen3の1.7B、8B、14B、30Bを対象に、注意頭の25%、50%、75%、87.5%をSWA化した。たとえば8Bで75%をSWA化した場合、人工長文検索（NIAH）の平均スコアはBOSCH 72.7、FISHER 63.4、RAZOR 64.9であり、LongBench系の平均スコアも31.6対25.8/25.7であった。**これは長文脈の品質保持の比較であり、推論エンジンの実測速度が72.7倍になったという意味ではない。**

## 問題設定

層数をL、各層の注意頭数をH、合計N=LHとする。各注意頭に二値変数 `z_i` を割り当て、`z_i=1`なら元の全域因果注意、`z_i=0`ならSWAを使う。目標SWA化比率をρとすると、選択すべきマスクは `(1/N) Σ_i (1-z_i)=ρ` を満たす。較正集合Dで測定するモデルの損失 `L(M,z,D)` を最小化する二値組合せ最適化として表現できる。対象は**事後ハイブリッド化**であり、モデル全体を初めから混成構造で事前学習する方式ではない。

全域注意は過去の系列全体を参照し、系列が長くなるほどKVを多く保持する。SWAへ置換した頭は直近ウィンドウ内のKVのみ保持すればよいので、KV容量と注意計算の上限を抑えられる。ただしGrouped-Query Attention（GQA）では複数の問い合わせ頭が同じ鍵・値グループを共有するため、**同じKVグループの頭を一括してSWA化しなければ、KVメモリ削減が実現しない**。原著は共有グループの頭に同じ二値決定を課す制約を明記している。

探索の難しさは二重にある。第一に、性能を測るたびにLLMを実行する必要があり、評価関数が高価である。第二に、現代のLLMには数百〜数千の注意頭があり、全組合せ探索は不可能である。単純な1ビット反転近傍の黒箱探索は、変数数が大きくなるほど改善候補の発見率が下がる。BOSCHは大近傍探索（Large Neighborhood Search; LNS）という考え方で、探索空間を小さな部分問題へ分割する。

## 手法

### 1. 正規化性能とSWA予算違反の目的関数

著者は較正集合Dで測った性能スコア `S(M,z,D)` を、全頭SWAモデルの性能 `a=S(M,0,D)` と、元の全域注意モデルの性能に余裕係数γを掛けた `b=(1+γ)S(M,1,D)` を用いて `Ŝ=(S-a)/(b-a)` と正規化する。探索の目的関数は `-Ŝ + α(ρ(z)-ρ)^2` であり、性能を高く保つ一方で目標のSWA化比率からのずれを罰する。`α` は比率制約への重みであり、任意の設定で最適解が保証されるわけではない。

この性能関数は、理論上の演算量を最小化する目的関数とは異なる。SWA化率を外部から決め、与えられた容量・計算予算で品質をできるだけ維持する設計である。したがってρの大きさを変えた比較では、メモリ節約量と品質のトレードオフが現れる。予算違反の二乗罰則により探索中の近似的な候補を許し、最終的な頭選択は目標比率に整合させる。

### 2. 第1段：層の局所化感度を測る

最上層から下層へ順に進み、注目層以外の頭マスクを固定したうえで、その層のうち約 `ceil(ρH)` 個の頭をSWA化する小規模黒箱探索を実行する。すでに上位層で選んだ局所化を反映したモデルを使うため、各層を完全に独立評価する静的な重要度順位よりも相互作用を一部取り込める。各層で得た最高性能を `s_best` として保存し、次段階の予算配分へ渡す。

重要なのは、ここでの層重要度が「元のモデルでどの頭の注意重みが長距離へ向いていたか」という固定統計ではなく、**他層の局所化が進んだ状況での実測品質低下**から計算されることである。探索は完全な全頭同時最適化ではなく、逐次的な近似であるため、順序依存性は残る。

### 3. 第2段：層ごとに異なるSWA比率を割り当てる

第1段で測定した層ごとの性能低下を正規化し、局所化しやすい層と局所化に敏感な層を区別する。各層をいくつかの粗い比率バケットへ分類し、局所化しやすい層には大きなSWA比率を、敏感な層には小さな比率を割り当てる。その後、全層でのSWA化頭数が目標ρと整合するよう、隣接バケット間で層を移動させて予算を調整する。

均等に各層の頭の半分を置換する設計では、長距離情報を担う層へ過大な局所化を強いる可能性がある。BOSCHは層別比率 `r_l` を可変にし、全体の容量目標を維持しつつ品質劣化を受け入れやすい場所へ局所化を集中させる。ただしこの段階は、最終的にどの頭を置換するかまで確定するものではない。

### 4. 第3段：同じ比率群に属する複数層の頭を共同探索

同じ局所化比率を割り当てた層をグループ化し、局所化しやすい群から順に、複数層の注意頭の二値マスクをまとめて黒箱最適化する。処理済みグループのマスクは固定し、現在のグループに属する頭の組合せを探索する。グループごとの頭数・比率制約を守りながら、複数層の相互依存を反映した候補を評価し、得られたマスクを全体へ反映する。

第1段だけで終わる方式（B-single）、第1段の探索範囲を複数層に拡大する方式（B-multi）、層単位の二値探索（B-layer）を構成要素除去実験として比較している。三段階をすべて使うBOSCHが高い品質を示すことは、層別予算配分と共同頭探索が単なる追加処理ではなく、組合せ依存の軽減に寄与することを裏付ける。一方、計算予算の厳しい環境では、この黒箱評価の回数そのものが導入費用になる。

### 5. 推論時の挙動とKV容量の読み方

探索が終われば、得られた二値マスクに基づき各頭の注意機構を全域またはSWAへ固定してモデルを実行する。BOSCH自体は各トークン生成時に黒箱探索を繰り返すオンライン制御器ではない。実行時に必要な機構はSWAと全域注意の混成処理であり、GQAでは共有KVグループ単位で同じ注意方式にする必要がある。

理想化すれば、長さTの系列、ウィンドウW、SWA化率ρに対し、注意の履歴長は全域頭でT、局所頭で最大Wとなる。ただし実際のKVバイト数はGQAグループ構成、レイヤー別割当、実装が古いKVを解放するか、ページ管理の粒度に依存する。論文の品質スコアだけから特定GPUのVRAM節約率や推論速度を算出することはできない。

## 評価

### 実験条件と比較対象

| 項目 | 原著の設定 |
|---|---|
| モデル | Qwen3-1.7B / 8B / 14B / 30B（ベース系列） |
| SWA化比率ρ | 0.25、0.50、0.75、0.875 |
| SWA窓長 | 基本1,024トークン。モデルの最大系列長32Kに対して1/32 |
| 較正 | 人工NIAH。プレフィルのみの正解トークン予測率を評価関数とする |
| 主評価 | RULER由来のNIAH 6課題（4K〜32K）、LongBenchの長文脈QA 29課題とGSM8Kを含む平均 |
| 比較方式 | 層単位RAND/BME/INTR、静的頭選択DCAM/APL/PROXY/QADA/RAZOR/FISHER |
| 構成要素除去 | B-single、B-multi、B-layer |
| 繰り返し | 原著の主要結果は3回の実行平均 |

NIAHは長い入力から埋め込まれた情報を取り出す能力を測るため、KV削減により長距離参照が失われたときの劣化を検出しやすい。LongBench系の平均は複数のQA・推論課題を混ぜた指標で、NIAHの数値と同じ分母・尺度ではない。表1と表2の数値を単純合算して「総合精度」を作ることは避ける。

|---|---:|---:|---:|---:|---:|

| 8B / 75% | 99.1 | 72.7 | 63.4 | 64.9 | 41.9 |

局所化率が高いほど絶対性能は大きく落ちる。30Bで87.5%をSWA化したBOSCHのNIAHは26.9であり、元モデルの99.4からは大幅に劣化している。**BOSCHの利点は同じSWA化予算で他方式より品質を保つことであって、極端な圧縮でも品質が無損失になることではない。** 8Bの75%局所化ではFISHER比9.3ポイント、RAZOR比7.8ポイント高い。B-singleとの差30.8ポイントは、第2・第3段を含む探索の効果が大きいことを示す。

長文脈QAでも傾向は類似するが、元モデルからの絶対性能低下は残る。8B・75%ではBOSCH 31.6、元モデル57.1なので25.5ポイント低い。比較方式の中では良好でも、長文脈アプリケーションへ導入する際には許容品質低下を設定する必要がある。大規模モデルであれば局所化率を高めても常に強いとは限らず、モデル規模に対する単調な優位性は論文も主張していない。

### 構成要素除去実験と頭集合の入れ替わり

8B・SWA率75%のNIAHはBOSCH 72.7、B-single 41.9、B-multi 48.5、B-layer 40.6であった。14Bの同条件では83.6、31.2、60.1、56.4であり、単一層感度探索だけで決めるより、複数層をまたぐ最終選択が重要である。単純に全頭を独立順位付けして最も局所的な頭を選ぶ方法は、他の頭の変更に伴う役割変化を反映できない。

原著Table 3は、SWA化率を上げたとき**以前SWA化されていた頭が新しい集合から外れる割合**を測る。たとえば8Bではρ=0.25→0.5で26%、0.5→0.75で15%、0.75→0.875で7%が入れ替わる。14Bではそれぞれ28%、16%、5%。単調な静的順位なら、SWA化率を増やす際に先に選んだ頭は必ず残るはずなので、この非単調な集合変化は頭間相互作用の存在と整合する。ただし、これだけで因果的に性能改善が証明されたわけではない。

### 継続事前学習・評価指標の境界

原著は局所化後の継続事前学習による長文脈性能の回復も調べ、BOSCHの初期選択が静的手法より早く、より高い水準へ回復すると報告する。これは**探索自体は学習不要**という性質と矛盾しない。モデルを局所化した後に品質を追加回復させる別の段階であり、ゼロショットの表1・表2と混同しない。

また本論文は、SWA化でKV容量・注意演算量が減る設計上の動機を述べるが、主要表は長文脈の品質指標である。ハードウェア別のTTFT、トークン毎遅延（TPOT）、スループット、ピークVRAM、SWA用カーネルの実装費用を横並びで計測したサービング評価とは異なる。推論基盤へ実装する場合は、混成注意のカーネル選択、GQAグループごとのKV解放、プレフィルとデコードの別々の測定が必要になる。

## 既存研究との差

層単位のRAND、BME、INTRは、どの層を全域注意として残すかを粗く選ぶ。DCAM、APL、FISHER、QADA、RAZOR、PROXYは、元モデルで観測した頭の重要度や局所性に基づく静的な頭順位付けを使う。BOSCHは**置換後のモデルを実際に評価する黒箱関数**を中心に据え、他の頭がすでにSWA化されている状態での影響を最適化する。

そのため単なる注意スコアの可視化や、各頭の独立感度ランキングとは異なる。さらに全頭を同時に探索する代わりに、層の感度、層別予算、比率群の共同探索へ分割して、評価コストを実行可能な範囲に制限する。著者の頭集合比較ではBOSCHと静的方式のJaccard距離が大きく、近い性能を出す方式同士では選択集合が近い傾向も見られた。

本手法は量子化や投機的復号とは異なり、重み精度や出力候補の検証回数を直接変えるものではない。KVキャッシュの履歴長を注意頭単位で変える**モデル構造の事後ハイブリッド化**であり、推論エンジン側のSWA/GQA実装と組み合わせて初めてメモリ効率改善につながる。

## 限界と負の結果

- **高いSWA化率で品質は大きく低下する。** 30Bの87.5%局所化でNIAH 26.9、LongBench 19.3は元モデル99.4/54.9より大幅に低い。最良の相対方式であっても高い圧縮率を無条件には推奨できない。
- **探索コストはゼロではない。** 黒箱評価ではLLMのプレフィルを何度も実行する。探索時のGPU時間や較正集合の構成に依存し、導入前にモデルごとのオフライン探索費用を見積もる必要がある。全ての入力やモデルに対して最適マスクを保証しない。
- **較正と評価の分布差。** 人工NIAHで性能を測って選んだ頭が、専門文書、コード、長期会話、複数画像を含むすべての長文脈で最適とは限らない。LongBenchは追加の一般化検証だが、配備ワークロードの代替ではない。
- **実行時のKV節約率は未実証。** SWA化率ρは注意頭の割合であり、GQAのKVグループ数、実装のページ管理、既存KVの解放、窓長、モデルの層構成を無視してそのままVRAM節約率とはできない。
- **推論レイテンシの直接測定が中心ではない。** 主結果はゼロショット品質と継続学習後の回復であり、実際のTTFT・TPOT・スループットの向上倍率を主張するものではない。
- **後処理と継続学習の混同に注意。** マスク探索は追加学習なしで行うが、継続事前学習で品質を回復する実験は別途学習資源を必要とする。両者の費用を同じ「学習不要」の効果として数えない。
- **モデル範囲。** 4種類のQwen3系列での検証であり、別の注意構造や大幅に異なるGQA比率を持つモデルへの転用は再探索・再評価が必要である。

## 実装上の示唆

既存の推論エンジンでSWAと全域注意を同一モデルに混在させるには、頭ごとの注意マスクだけでなくKVキャッシュをグループ単位で保持・解放する仕組みが必要となる。Qwen3系のGQAでは問い合わせ頭ごとに異なるマスクを適用しても、共有KVグループの一部だけが全域注意を要求すればそのグループのKV履歴は残る。したがって実装の第一段階はGQA制約を保ったマスクを生成し、窓長1,024と32K文脈でのKVバイト数を検証することである。

次に、BOSCHの黒箱探索で使用した人工NIAHの較正集合と、実際のサービス入力の代表集合で品質を比較する。必要ならρ=25%→50%→75%の順に品質劣化曲線を作り、メモリ制約を満たす最小限の局所化率を選ぶ。探索のGPU時間はオフライン費用として計測し、配備後は通常のSWA混成推論だけが走ることを確認する。最後に、プレフィルとデコードを分離したレイテンシ、バッチサイズ別処理量、長い会話での正答率を測る。論文の品質表だけから性能改善倍率を推定してはならない。
