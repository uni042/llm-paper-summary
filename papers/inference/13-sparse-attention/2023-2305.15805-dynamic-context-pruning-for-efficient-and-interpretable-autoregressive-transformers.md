# Dynamic Context Pruning for Efficient and Interpretable Autoregressive Transformers

> 通常の疎注意は「直近kトークン」など固定パターンで計算を削るため、入力内容によって重要になる遠距離トークンまで捨て得る。本論文は各層へ小さな相互作用クエリ・キーを追加し、生成中に「この過去トークンを今後も保持すべきか」を学習する。一度不要と判定したKVは後続ステップから不可逆に削除できるため、注意演算だけでなくKVメモリも実際に縮む。

## 概要

自己回帰Transformerでは、各生成トークンが過去の鍵・値（Key/Value; KV）を参照する。通常のKVキャッシュを使えば過去を毎回再計算せずに済むが、保持KV数は系列長とともに増え、1トークンの注意計算も長くなる。

局所注意（local attention）は直近kトークンだけを見るため効率的だが、遠距離依存が必要な入力でも同じ窓を適用する。固定疎注意（static sparse attention）も同様に、内容ではなく位置規則で接続先を決める。本論文の狙いは、標準自己注意の表現力をなるべく残しながら、**内容に応じて不要になった過去トークンだけを恒久的に落とす**ことである。

各Transformer層に、通常の注意Q/Kとは別の低次元相互作用クエリ・キー (Q_{mathrm{int}},K_{mathrm{int}}) を追加する。これらから過去トークンを保持するゲートを作り、通常注意スコアへ対数ゲートを加える。学習中は勾配を流せる疎シグモイド（sparse sigmoid）を使い、推論時は0/1のステップ関数へ置換する。

重要なのはゲートを各注意演算だけのマスクで終わらせない点である。ある層でトークンjが不要と判定されたら、その層のKVバッファからjを消し、そのメモリ領域を後続トークンへ再利用する。後の生成ステップでjへ再び注意することはできないため、選択は不可逆だが、実メモリと読出し量を削減できる。

## 問題設定

一般的な疎注意では、現在トークンkが過去jを見ない場合でも、将来トークンk+1がjを見る可能性がある。そのため「今回の注意行列を疎にする」だけでは、jのKVをキャッシュから物理的に削除できない。

本論文はより強い決定を学ぶ。トークンjを「今後の生成にも不要」と判断した時点でjを文脈集合から外し、以後その層では参照不能にする。この制約により、注意計算の疎化をKVキャッシュ容量の削減へ直接変換できる。

ただし不可逆削除には危険がある。現在は不要でも数十トークン後に必要になる情報を落とせば回復できない。したがって単純な注意スコア閾値ではなく、次トークン予測の損失と疎性目標を同時に学習して、「何をどの時点で捨ててもよいか」をモデルへ適応させる。

## 手法

### 1. 各層に低次元の相互作用Q/Kを追加する

層 (ell) の隠れ表現 (X^ell) から、通常注意とは別の
[
Q^ell_{mathrm{int}}=X^ell W^ell_{Q_{mathrm{int}}},quad
K^ell_{mathrm{int}}=X^ell W^ell_{K_{mathrm{int}}}
]
を計算する。追加次元rは通常の隠れ次元dより小さく、実験ではr=64を使う。

この小さなQ/Kは「内容を生成する」ためではなく、トークンkから見て過去jを今後も保持するかを判断する専用信号である。各層が独立した行列を持つため、浅い層と深い層で異なる削除パターンを学べる。

論文は、ある層で落としたトークンをより深い全層でも落とす制約も試したが性能が悪化したとして採用していない。つまり削除状態は**生成方向には不可逆**だが、層方向には共有せず、各層が独立に文脈を持つ。

通常の自己注意には (log I^ell) を加える。I=0ならスコアは実質 (-infty) となりマスクされ、Iが0〜1なら学習中は滑らかに注意を弱められる。

### 3. α-sigmoidで学習時の勾配と推論時の二値化を両立する

0/1のステップ関数を最初から使うと勾配が流れず、どのトークンを落とすべきか学習できない。そこでTsallisエントロピー由来の**α-sigmoid**を使用する。

学習開始時はα=1付近で通常の滑らかなシグモイドに近くし、コサインスケジュールでαを増やす。αが大きくなるほど出力は0/1へ近づき、最後は疎な判断になる。推論ではα→∞に相当するステップ関数へ置き換え、曖昧な部分マスクをなくす。

層ごとのバイアス (eta^ell) は正側から始め、微調整開始時には「まず全トークンを残す」挙動にする。既存の事前学習済みモデルをいきなり破壊せず、徐々に削除を学習できる。

### 4. 言語モデル損失に疎性正則化を加える

微調整目的は通常の次トークン交差エントロピーに、

(gamma) を大きくすると保持ゲートを減らす圧力が強くなり、より多くの過去トークンを削除する。したがって運用者は別モデル構造を作らず、正則化強度で品質と疎性の交換条件を調節できる。

これは事後処理のKV追い出しではなく、**追加微調整が必要な学習型圧縮**である。その代わり、単純な最近性や注意スコアではなく、次トークン予測を維持するよう削除機構自体を学べる。

### 5. 穴を残さない動的KVバッファを使う

トークンを削除してもGPUメモリに穴が残れば、バッチ化した密な読み出しが崩れて実速度へつながりにくい。論文は自己注意が保持KVの順序そのものには依存しない集合演算であることを利用し、削除位置を空きスロットとして後続KVへ再利用する。

バッファには元の位置IDとKVを格納し、位置埋め込みで必要な論理順序はID側で保持する。物理メモリは高い充填率を保つため、削除後も連続に近い読み出しを維持できる。

この実装上の工夫が、理論上の注意要素削減を「より大きいバッチを同じGPUへ載せる」「長文時の1ステップ遅延を減らす」という実測効果へ変える。

## 評価

### 主な評価条件

| 項目 | 条件 |
|---|---|
| モデル | GPT-2 small / medium / large / XL |
| 微調整データ | English Wikipedia 20220301.en + BookCorpusのサブセット |
| 最大文脈 | GPT-2の1024トークン |
| 相互作用次元 | r=64 |
| 品質指標 | テストパープレキシティ、ゼロショット精度 |
| ゼロショット課題 | WinoGrande、HellaSwag、PIQA、LAMBADA |
| 比較 | 密注意、固定局所注意、固定疎注意 |
| 性能測定 | NVIDIA RTX A5000、最適バッチサイズでトークン/秒 |
| 主変数 | 疎性正則化係数γ、実際に削除された文脈率 |

### 品質と疎性

文脈長1000では80.35%の疎性でも、密モデルに対する平均パープレキシティ増加は約0.085と報告される。ゼロショット4課題でも、中程度〜高い疎性まで密モデルに近い精度を維持し、固定局所・固定疎注意より同じ疎性で劣化が遅い。

ただし90%近辺まで強く削るとパープレキシティ・ゼロショット精度は明確に悪化する。「80%まで削除可能」は全設定で無損失という意味ではなく、GPT-2評価で品質低下が小さい範囲の代表値である。

### 実測性能

| 条件 | 結果 | 読み取れること |
|---|---:|---|
| GPT-2 small、長文、高疎性 | 密モデル比でスループット約+98% | ほぼ2倍。KV削減で最適バッチを拡大できる |
| GPT-2 medium、文脈1000 | 最大約+189%スループット | モデルが大きいほどメモリ余裕増加がバッチ数へ効く |
| 上記medium代表点 | パープレキシティ損失0.084 | 速度増加と品質差を同じ点で併記 |
| 1ステップ実行時間 | 長文で最大約50%削減 | 短文では追加ゲート計算で逆に遅い領域もある |
| KVメモリ | 疎性にほぼ線形で削減 | 注意FLOPsよりメモリ削減の寄与が大きい |

論文自身が指摘する重要な負の結果は、**短い文脈では剪定モデルの方が遅い**ことである。追加Q/Kと削除判断の固定費用があるため、保持KVがまだ小さい領域では削減利益が上回らない。文脈長が増えるとKVメモリと注意読出し削減が支配的になり逆転する。

### 解釈可能性

生成例では、句読点や節の区切りを契機に、それ以前の局所情報をまとめて削除する挙動が多い。一方、削除タイミングと残す品詞は層ごとに異なる。

この可視化は性能指標ではないが、「固定位置ルールではなく内容に応じた判断を学んでいる」ことを検査する手掛かりになる。逆に、解釈可能性は削除判断が人間の意味的重要性と常に一致する保証ではない。

## 既存研究との差

局所注意やLongformer型の固定疎注意は、どの入力でも同じ幾何学的パターンを使う。Dynamic Context Pruningは標準注意の上に小さな学習モジュールを追加し、トークン内容と現在位置から保持集合を変える。

H2Oなど後発のKV追い出し方式と比べると、注意統計から事後的に重要KVを選ぶのではなく、追加微調整で「捨てても次トークン予測を維持できるか」を直接学習する点が異なる。代償として、学習不要のKV圧縮ではなくモデルごとの微調整が必要である。

また一回の注意だけを疎化せず、削除後のKVメモリスロットを再利用するため、逐次生成の実際のキャッシュ容量を下げられる。この不可逆性が速度・容量の利点と品質リスクの両方を生む。

## 限界・実装状況

主評価はGPT-2系列、最大1024トークンであり、現在の数十万トークン級LLMやグループ化クエリ注意（Grouped Query Attention; GQA）へそのまま結果を外挿できない。長文ほど利得が増えるという傾向は示すが、現代モデルで80%削減を保証する結果ではない。

追加微調整が必要で、モデル重みを変更せず導入できる方式ではない。一度落としたKVは後から戻せないため、将来参照される情報を早く削除する失敗モードも残る。

動的バッファはバッチ内の要求ごとに異なる削除位置を扱う必要があり、実装が単純な連続KVより複雑になる。論文のRTX A5000参照実装では速度向上を示すが、PagedAttentionやFlashAttention世代の現在のサーバーで同じ倍率になるとは限らない。

著者公式コードは `sanagno/adaptively_sparse_attention` として公開され、GPT-2の微調整・生成スクリプトを含む。
