## 概要

疎注意機構は長文脈の計算量を減らせるが、「どのトークンを残すか」を推定する代理指標が必要になり、その代理指標自体の費用と選択誤差が生じる。また計算対象トークンを減らしても各層が完全なKV キャッシュを保持すれば、生成時メモリは十分に減らない。HySparseは全体 注意機構を完全に捨てず、少数の全体-注意機構層を後続sparse層の理想条件兼KV供給元として使う。

一つのhybrid ブロックは全体-注意機構層と複数のsparse-注意機構層からなる。全体層がFlashAttention計算中にブロック単位重要度を取り、Top-K ブロック indexを後続層へ渡す。後続層の大域 sparse 分岐はそのindexだけへ注意機構し、KVも全体層のものを再利用する。局所 sliding-window 分岐だけは独自KVを保持する。80B MoEの49層構成では全体 注意機構を5層だけにし、KV キャッシュを約10分の1へ削減する。

## 問題設定

従来の動的疎注意機構では、問い合わせから重要KVを予測する補助ネットワーク、近似スコア、検索indexなどが必要になる。選択が外れると長距離依存を失い、選択器の計算が注意機構削減分を食うこともある。

もう一つの問題はcross-層 redundancyである。近接層が似た長距離情報を参照するにもかかわらず、各層が独自の大域 KVを保存するとキャッシュ容量は層数に比例する。HySparseは全体層で得た「選択結果」と「KV表現」の双方を複数後続層へ再利用する。

## 手法

### Full-attention oracle token selection

全体-注意機構層は通常の注意機構を計算しながらブロック単位の最大注意機構 スコアを生成する。完全なスコア matrixを別途materializeせず、FlashAttention経路を拡張してimportance スコアを得る。Top-Kで重要ブロック indexを選び、同じhybrid ブロック内の後続sparse層へ渡す。

この選択は代理指標による将来予測ではなく、直前全体層が実際に計算した注意機構を根拠にする。そのため選択器の別モデルを持たず、大域 トークン選択の誤差源を減らす。

### Cross-layer KV cache sharing

sparse層の大域 分岐は自身の大域 KVを新規保存せず、直前全体層のKV キャッシュから選択ブロックを参照する。複数sparse層が一つの全体-層 キャッシュを共有するため、全体層の割合を下げるほど大域 KV ストレージが減る。

ただしすべての表現を共有すると局所 modelingが弱くなる。そこで各sparse層は短いsliding-window 注意機構（SWA）分岐用の小さな独自KV キャッシュを保持する。

### Global/local gated fusion

sparse層は理想条件-selected ブロックへ向かう大域 sparse 注意機構と、直近トークンを見るSWAを並列に計算し、sigmoid ゲートで出力を融合する。大域 分岐は長距離情報、局所 分岐は層固有の短距離表現を担当する。

構成要素除去では、SWAまで全体層KVを共有する方式より、大域 sparse 分岐だけを共有してSWAを独立させる方が高い性能を示す。したがってキャッシュ sharingを最大化するより、表現役割に応じて共有範囲を限定する設計である。

## 評価条件

| 項目 | 条件 |
|---|---|
| モデル | 7B 密、80B MoE |
| 80B構成 | 49層中5層のみ全体 注意機構の設定を評価 |
| sparse選択 | ブロック単位Top-K、代表設定では1024 トークン相当 |
| 局所 path | 128-トークン級SWA 分岐 |
| タスク | MMLU、MMLU-Pro、GSM8K、coding、RULER等 |
| 長文脈 | 16K/32Kを含む |
| 比較 | 全体 注意機構、hybrid SWA |

## 主要結果

| 条件 | 結果 | 解釈 |
|---|---:|---|
| 80B MoE / 49層中全体 5層 | KV キャッシュ約10分の1 | cross-層 sharingがメモリを大幅削減 |
| 80B / RULER 32K | HySparse 87.4、全体 注意機構 82.1 | 長文脈で疎構成が品質を維持・上回る条件がある |
| 80B / RULER 16K | HySparse 90.6、全体 注意機構 93.6 | すべての条件で全体 注意機構を上回るわけではない |
| 7B / GSM8K キャッシュ-sharing ablation | 大域のみ共有36.7、大域+SWA共有30.2 | 局所 KVを独立保持する設計を支持 |

論文は主にモデル qualityとKV容量を評価しており、エンドツーエンド 推論提供 スループットやトークン 遅延の代表値は報告していない。したがって約10倍のKV削減を約10倍の速度向上とは解釈できない。

## 既存研究との差

代理指標-based sparse 注意機構は各層で重要トークンを推定し、cross-層 KV sharingを行わない方式が多い。HySparseは定期的な全体-注意機構層を「正確な選択器」と「共有KVのチェックポイント」として兼用し、その間の層だけをsparse化する。YOCO型のcross-層 キャッシュ共有と異なり、大域 sparse 分岐と局所 SWA 分岐の役割を分離している。

## 限界

全体-注意機構層は残るため、完全sparse 構成ではない。選択ブロックは直前全体層の注意機構 patternに依存し、層間で重要性が大きく変わる場合は不利になり得る。現論文は品質とKV容量の利点を強く示す一方、実推論提供のスループット/遅延は未評価である。
