# RIS-Kernel: A Model-Agnostic Architecture for Long-Context LLM Inference via Sparse Attention

## 概要

RIS-Kernelは、長文脈LLMの密自己注意が全トークン対を評価するため二次計算量と大きなメモリを要求する問題に対し、注意相互作用の一部だけを選ぶReduced Interaction Sampling（RIS）を推論時に適用する。モデル重みを再学習せず、Qwen2-1.5B-Instructを一般的なCPUメモリ上で長文脈処理することを狙う。

特徴は単一の決定的疎パターンだけに依存せず、確率的サンプリングを複数シードで繰り返して予測を統合する点にある。32,768トークンでは密注意も動くため品質上限と比較し、65,536トークンでは密注意がメモリ不足になる条件で疎注意の実用性を測る。

## 問題設定

密注意はNトークンに対してN×Nの相互作用を作る。GPUを使えないCPUサーバでは、長文脈ほど計算時間と中間メモリが急増し、65K級で実行不能になる。単純に注意辺を減らすと重要な遠距離関係を落とし、検索・推論品質が下がる。

RISは、すべての相互作用を正確に評価する代わりに、少数の相互作用集合を観測し、その複数サンプルから頑健な答えを得るという設計を取る。

## 手法

RIS-Stochasticは注意相互作用を低密度で確率的に選ぶ。1%や5%の密度で全N^2辺を保持せず、系列長とともに増えるサンプル数を制限してO(N log N)相当の計算・記憶へ落とす。各シードは異なる疎相互作用を観測するため、一回のサンプルで落とした関係を別シードが拾える可能性がある。

複数シードの結果をアンサンブルすることで、疎化による分散を抑える。低密度では不要な文脈相互作用も除かれ、論文ではこれが正則化のように働き、密注意を上回る条件が観測される。一方、シード数を増やすほど総計算量は増えるため、密度とアンサンブル数が主要な交換条件になる。

RIS-Structuralは確率的探索より小さい計算予算で、構造的に選んだ相互作用を使う変種である。最小予算条件では精度を一部犠牲にしつつ、ゼロ文脈より多くの長距離情報を回収する。

## 評価

| 観点 | 条件・結果 |
|---|---|
| モデル | Qwen2-1.5B-Instruct |
| ハードウェア | GPUなしCPUサーバ、16〜128GB RAM |
| 32K密注意 | 71.88% |
| RIS-Stochastic | 1%密度・70シードで75.00% |
| RIS-Stochastic | 5%密度・10シードで71.88% |
| RIS-Structural | 1%密度・10シードで68.75% |
| 65K | 密注意はOOM、RISはゼロ文脈床51.56%から最大14.06ポイント改善 |

32Kの1%・70シード条件が密注意を上回る結果は、疎注意が常に正確という意味ではなく、評価タスクで不要な相互作用を減らす正則化効果と複数サンプル統合が効いた結果として解釈される。65Kの改善はMcNemar検定でp=0.078とされ、通常の5%基準ではなく10%基準で周辺的有意という弱い統計的証拠である点に注意が必要である。

## 既存研究との差

学習時から疎注意を組み込むモデルと異なり、RISは重み変更なしの推論エンジンとして既存モデルへ適用する。また単一の固定疎パターンではなく、確率的相互作用集合を複数回評価することで、計算予算をシード数として調整できる。

## 限界・実装状況

主評価はQwen2-1.5B-InstructとCPU環境に集中しており、大規模モデル、GPUカーネル、実サービングでのTTFT/TPOTは未検証である。70シードのアンサンブルは一回の疎注意より計算を大きく増やすため、密注意より精度が高い条件がそのまま最速条件とは限らない。65K結果の統計的有意性も強くない。
