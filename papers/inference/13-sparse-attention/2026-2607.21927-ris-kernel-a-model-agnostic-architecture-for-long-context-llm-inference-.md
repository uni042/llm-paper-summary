# RIS-Kernel: A Model-Agnostic Architecture for Long-Context LLM Inference via Sparse Attention

## 概要

RIS-Kernelは、長文脈の自己注意（self-attention）が全トークン対を評価することで計算量・メモリ量が急増する問題に対し、推論時だけ注意相互作用を疎化するReduced Interaction Sampling（RIS）を実装した推論層である。モデル重み、トークナイザ、Transformer本体を再学習せず、実行時に注意メソッドを差し替えるため、論文では同一実装をLLaMA系とQwen2系へ適用できるとしている。中心的な狙いは「1個の固定疎パターンを正解とみなす」のではなく、局所窓・大域アンカー・確率的または構造的な疎相互作用を組み合わせ、複数シードの観測を統合して長距離情報の取りこぼしを減らすことである。

論文の見出し上は、密注意の二次計算量 (O(N^2)) を疎な幾何によって (O(N\log N)) 相当の算術量へ落とすことを主張する。ただし、実装詳細を読むと「計算量」と「マスク生成時のピークメモリ」を分けて理解する必要がある。各シードのマスクを同時保持せず逐次的にマスター構造へ統合するため、シード数に比例する巨大なメモリ増加は避ける一方、現実装はマスターのブール行列を用いるため幾何生成のピークメモリには (O(N^2)) 成分が残る。したがってRIS-Kernelは、現実装の全メモリ使用量そのものを厳密に (O(N\log N)) へした方式ではなく、注意演算を疎化し、複数シードを逐次構築して商品級CPUメモリへ収めるシステムとして読むのが正確である。

## 問題設定

密な因果注意では、長さ (N) の系列に対して各queryが多数の過去key/valueと相互作用する。文脈長を32Kから64Kへ伸ばすと、単純な密実装では中間状態と相互作用数が急増し、GPUを使わない環境では計算時間だけでなく主記憶容量が制約になる。一方、局所窓や固定ストライドだけに落とすと、答えの根拠となる遠距離トークンが疎パターンの外側に出た瞬間に復元手段がなくなる。

RIS-Kernelはこの問題を「全辺を保持する」対「単一の固定疎グラフを使う」という二択にせず、異なる疎射影を複数回用意して観測範囲を広げる。各シードで特定トークンを取りこぼしても別シードで回収でき、密度 (d) の独立サンプルを (N_s) 個重ねたときの被覆率は概ね (1-(1-d)^{N_s}) として増える。ただし被覆率が高ければ常に良いわけではなく、密度やシード数を上げすぎると、すでに見たトークンを重複して追加し、無関係な文脈まで再導入して正則化効果が弱くなる。論文はこの非単調性を主要な設計問題として扱っている。

## 手法

### 1. 実行時の注意層差し替え

入力は既存Transformerのquery、key、valueと系列位置である。RIS-Kernelは実行時のメソッド注入（runtime method injection）で標準注意呼び出しを差し替え、重みとトークナイザは変更しない。出力は通常の注意出力として元のTransformerブロックへ返るため、学習済みモデルの再微調整を必要としない。この構造が「モデル非依存（model-agnostic）」という主張の根拠であり、論文ではQwen2とLLaMA系で同じ実装経路を使う。

### 2. メモリ境界付きの幾何生成

65,536トークンで複数シードの二次元ブールマスクを同時に作ると、マスクだけで数十GB規模になり得る。RIS-Kernelはシードごとにインデックスを生成し、因果制約で無効な辺を除き、マスター構造へ統合した後、そのシード固有構造を捨てて次のシードへ進む。これにより「シード数×巨大マスク」の同時保持を避ける。

重要なのは、この逐次化が二次元マスター構造自体を消すわけではない点である。論文自身も幾何構築のピークメモリを (O(N^2)) のブール行列で記述している。利得は、アンサンブル数を増やしても各シードのマスクを累積保持しないこと、そして実際の注意演算では選択されたインデックスだけを使うことにある。したがって長文脈化で最終的に残る制約は、疎注意演算だけでなくこのマスク表現にも依存する。

### 3. RIS-StochasticとRIS-Structural

RIS-Stochasticは系列全体を一様な候補集合として扱い、各pivotに対する大域的な近傍を確率的に選ぶ。密度予算は主に大域サンプリングへ使われるため、密度やシード数を増やせば遠距離トークンの被覆率は単調に増えやすい。一方、極端に低い密度では必要なアンカー近傍を偶然拾えない分散が大きい。

RIS-Structuralは系列をブロックへ分け、各ブロック内をクリーク状に結合して局所的な共同体構造を必ず残したうえで、残余予算を大域的な冗長辺へ使う。ブロック幅は系列長の一部と上限値から決め、局所クリークが消費した密度を大域サンプリング予算から差し引くため、Stochasticと同じ有効密度予算で比較する。低密度ではアンカー周辺を確実に残せるため有利だが、密度を増やすと局所領域へ予算を重複投入し、遠距離事実への配分が不足する。このためStructuralは1〜2%付近で強く、より高密度ではStochasticへ優位が移る。

### 4. ハイブリッドアンカーと事前融合統一softmax

生成時に毎トークンすべての確率的インデックス集合を作り直すと、CPUではインデックス生成そのものが支配的になる。そこで最初の生成トークンで複数シード由来の確率的集合を一度統合し、「確率的アンカー（Stochastic Anchor）」としてキャッシュする。次のトークン以降は最近のトークンを覆う動的局所窓だけを更新し、キャッシュ済みアンカーと局所窓を一意化（unique）してからkey/valueを抽出する。

この統合集合に対してquery-key積を計算し、事前融合統一softmax（Pre-Fusion Unified Softmax; PFUS）を一度だけ適用する点が重要である。大域疎成分と局所密成分を別々に正規化して後で足す方式では、疎サンプルで偶然見つかった重要トークンが小さな部分分布の中だけで競争し、統合後に相対重みが弱くなることがある。PFUSは局所・大域、頻出・希少にかかわらず選ばれた全トークンを同じsoftmax母集団へ置き、回収した遠距離トークンが局所トークンと直接競争できるようにする。

### 5. 動的位置埋め込み拡張

Qwen2の32K上限を越えて64Kへ伸ばすときは、注意幾何だけでなく回転位置埋め込み（Rotary Position Embedding; RoPE）が有効でなければならない。RIS-Kernelはモデル読み込み時にQwen2やLLaMAのRoPE設定を差し替え、要求文脈長と学習時上限の比から拡張率を設定する。論文は線形補間（linear interpolation）とYaRNの両方を比較する。

この機構はRISの付加機能ではあるが、評価上は本質的な前提条件である。疎幾何が正しく遠距離key/valueを選んでも、そのkey/valueへ付与された位置情報が壊れていれば検索信号を復元できない。したがって「疎注意の被覆」と「位置表現の外挿」は別のボトルネックであり、後者が崩れる条件ではシード数を増やしても改善しない。

## 評価

### 実験条件

主モデルはQwen2-1.5B-Instructである。32,768トークンの制御実験では、正解選択肢A〜Eをほぼ均等にした32問を使い、ゼロ文脈、RIS、ネイティブ密注意を比較する。主にIntel Core i7、16GB RAM、4物理コア/8スレッドのデスクトップで実行した。65,536トークンでは64問へ拡張し、128GB RAM、20物理コア/40スレッドのCPUサーバで評価する。この64K条件ではネイティブ密注意がメモリ不足となるため、密注意との直接比較ではなくゼロ文脈床とRIS設定間の比較になる。

回答は自由生成ではなく、各選択肢へ割り当てられた対数確率を比較する識別的ロジット評価（discriminative logit analysis）で採点する。32Kのゼロ文脈床は59.38%、密注意は71.88%、64Kのゼロ文脈床は51.56%である。

### 32K: 密注意と直接比較できる条件

RIS-Stochasticは1%密度・70シードで75.00%となり、密注意71.88%を3.12ポイント上回った。5%密度では10シードで71.88%となり密注意と一致する。論文は1%・70シードの結果を、複数疎射影によって必要な遠距離アンカーを拾いつつ、密注意に含まれる無関係な相互作用を一部落とした正則化効果として解釈する。

ただしこれは「密度を下げるほど良い」という単純則ではない。1%を70シード重ねたときの理論被覆率は約50.5%であり、必要なアンカーを拾いながら約半分の文脈を落とす。一方5%を70シード重ねると被覆率は約97.2%となり、ほぼ密注意へ戻って不要な相互作用も再導入する。このためシード増加の精度曲線は凹型になり、過剰なシードでは飽和または小幅悪化が起こる。

Structuralは極端な低予算で有利で、1%・10シードで68.75%となり、ゼロ文脈59.38%から密注意71.88%までの差の75%を回復する。32Kで密注意相当へ到達するにもStructuralは40シード、Stochasticは60シードを要し、局所アンカーを保証する構造的バイアスが低密度でのサンプル効率を上げる。

### 64K: 位置外挿と疎化の相互作用

64Kでは線形RoPE補間が大きな負の結果となる。単一シードでは1%密度15.6%、2%で20.3%、5%で23.4%となり、5択のランダム水準付近まで低下する。シードを増やすと部分的に回復し、5%・40シードでは59.4%まで戻るが、追加のアンサンブル費用が必要になる。

YaRNでは位置幾何がより保たれ、同じ64Kで1%は57.8%（40シード）、2%は60.9%（40シード）、5%は62.50%（40〜60シード）へ改善する。各密度で線形補間のピークよりYaRNが3.1〜12.3ポイント高い。この結果は、RISの長文脈性能が注意辺のサンプリングだけで決まらず、ホストモデルの位置表現が外挿先でも意味を維持できるかに強く依存することを示す。

### StochasticとStructuralの使い分け

64K・YaRNで全完全試行を平均すると、Stochasticは1%/2%/5%で52.13%/54.97%/58.66%、Structuralは56.53%/56.25%/55.26%である。Structural 1%は最大65.62%を記録し、同密度のStochastic最大57.81%を上回る。これは局所クリークがアンカー近傍を確実に残すためである。

反対に5%ではStochasticの平均58.66%がStructuralの55.26%を上回る。Structuralは局所領域をすでに十分覆っているのに予算を割き続けるため、密度上昇に対して遠距離被覆が伸びにくい。つまりStructuralは極端な低密度、Stochasticはより広い大域被覆を許せる予算で有利という明確な適用域がある。

### 低密度感度と負の結果

Structuralを0.1〜0.9%まで振った64K実験では、0.3〜0.5%が低コスト域として比較的安定し、0.5%の平均は58.20%、最大59.38%である。0.8%は最大62.50%に達する一方、0.9%では最大57.81%へ落ち、密度に対して単調ではない。ブロック幅の離散値とTransformer内部の境界が噛み合う構成依存性が残る。

さらにTinyLlama-1.1Bでは、学習時の2K位置上限から4倍以上へ外挿すると、密度1〜5%、シード1〜100を変えても精度がほぼ改善しない。8Kで12.5%、16Kで6.25%、32Kで18.75%で、シード数への反応が消える。これはRISの失敗条件を明確にする結果であり、注意幾何を増やしても、元モデルの位置表現自体が意味を失った場合は回復できない。

## 既存研究との差

LongformerやBigBirdのように学習時から特定の疎パターンを組み込む方式に対し、RIS-Kernelは推論時に既存モデルの注意呼び出しを差し替える。固定局所窓だけでなく、複数の確率的射影を重ねることで、1回の疎パターンで見落とした遠距離アンカーを別シードから回収する点が特徴である。

また、単に「疎いインデックスを選ぶ」だけでなく、生成時の確率的アンカー再利用、動的局所窓、PFUSによる一括正規化、RoPE外挿を同じ推論経路へ入れている。したがって論文のシステム上の貢献は、疎注意の理論だけでなく、CPU上で長文脈を実行するためのインデックス生成・正規化・位置拡張の組み合わせにある。

## 限界・実装状況

評価の中心はQwen2-1.5B-Instructで、論文内の性能数値を大規模モデルやGPUサービングへそのまま外挿できない。公式実装はその後より大きなモデルへ拡張されているが、それは論文の主評価とは別である。論文は初回トークン時間（Time To First Token; TTFT）や出力トークン当たり時間（Time Per Output Token; TPOT）を主要なサービング指標として比較しておらず、70〜200シードを使う設定は精度が高くても実時間の最速点とは限らない。

さらに、現実装の幾何生成には (O(N^2)) のブールマスター構造が残るため、算術量を (O(N\log N)) に疎化したことと、全メモリ量が同じ次数へ落ちたことは同義ではない。超長文脈ではこのマスク表現自体が次のメモリ壁になり得る。

最も重要な失敗条件は位置外挿である。線形RoPEで64Kへ伸ばしたQwen2や、学習時上限から大きく外れたTinyLlamaでは、疎注意を増やしても位置情報の崩壊を完全には救えない。RIS-Kernelが有効に働くには、対象文脈長でホストモデルの位置埋め込みが少なくとも部分的に機能している必要がある。
