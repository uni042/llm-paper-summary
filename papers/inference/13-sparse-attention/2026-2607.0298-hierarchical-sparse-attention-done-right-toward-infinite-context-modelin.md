# Hierarchical Sparse Attention Done Right: Toward Infinite Context Modeling

> チャンク注意質量を学習可能なlandmark要約で近似し、検索スコアを階層softmaxへ直接組み込んで、疎注意の選択精度と超長文脈推論効率を両立する。

## 概要

長文脈の全注意は、系列長に対して注意計算が二次増加し、鍵値キャッシュ（KV
cache）の容量と読み出しも増える。チャンク単位の疎注意は遠方文脈から少数チャンクだけを選ぶことで計算とKVアクセスを抑えられるが、既存方式の平均プーリングや最大値ベースの要約は「そのチャンクが現在のクエリから受ける総注意質量」を安定して近似できず、必要なチャンクを落とすことがある。

HiLS-Attentionは、全注意で得られるチャンク質量のLogSumExpを一次近似し、その近似に必要な圧縮キーとエントロピーバイアスを各チャンクの学習可能なlandmark
tokenから生成する。さらに検索スコアを単なるtop-k選択の補助情報で終わらせず、チャンク間softmaxとチャンク内softmaxからなる階層softmaxの前向き計算へ入れる。これにより次トークン予測損失の勾配がチャンク要約器まで届き、検索器を別損失なしで学習できる。

345M規模では8K文脈で学習したモデルが4M文脈のneedle検索で90%以上を維持し、512倍の長さ外挿を示す。推論評価では単一NVIDIA
H800、bf16、バッチ1、チャンク64、top-k=32、局所窓512という条件で、512K文脈において同じTritonカーネル基盤の全注意よりprefill
13.5倍、decode 15.7倍高速になった。

## 問題設定

素朴なブロック疎注意では、各遠方チャンク内の全トークンに対する指数化注意logitを合計した「チャンク質量」を計算し、その上位Kチャンクだけへ注意すれば、全注意に忠実な選択ができる。しかし正確な質量を得るには結局すべてのquery-key積を計算する必要があり、疎化による計算削減が失われる。

平均キーをチャンク代表にすると、チャンク内logitがほぼ均一な場合にはLogSumExpを近似できるが、1トークンだけが強く一致する場合を表現しにくい。逆に最大logitだけでは均一分布時の質量を落とす。HiLSはこの分布依存性を、学習可能な代表キーと分布エントロピーの組として表現する。

## 手法

### 線形チャンク質量代理

チャンクcの正確な質量は、チャンク内の各keyに対する指数化logitの和である。HiLSはその対数をTaylor展開し、現在queryと圧縮キーの内積に、チャンク内部の注意分布エントロピーを加える線形代理へ落とす。

各チャンク末尾にlandmark
tokenを置き、そのqueryを使ってチャンク内keyへ注意する。得られた重み付きkey和が圧縮キーになり、同じ重み分布のエントロピーがバイアスになる。均一分布ならバイアスはおよそlog
Sへ近づき、単一keyが支配すれば0へ近づくため、平均と最大の両極を一つの表現で補間する。

### 階層softmaxによる直接学習

検索器がtop-k
IDだけを出して検索スコアを捨てる設計では、離散選択を越えて言語モデル損失を検索表現へ流しにくい。HiLSは、選ばれた各チャンク内でトークン注意を正規化し、その出力をチャンク質量代理に基づくチャンク間softmaxで融合する。

この構造では代理質量が最終attention
weightを直接変えるため、次トークン損失がlandmark要約へ逆伝播する。結果として「次の予測に役立つチャンクへ高い質量を割り当てる」検索がモデル本体と一緒に学習される。

### 実装上の補助機構

チャンク要約空間と通常queryのずれを補うため、隠れ状態から低ランク射影した差分をqueryへ加えるQ-Calを導入する。345Mの構成要素除去ではQ-Calなしで512KのRULER
variable-trackingが0まで落ちる一方、rank
64のQ-Calでは66を維持しており、長さ外挿で重要な構成要素である。

位置符号化にはHoPEを使い、長周期のRoPE次元を非位置符号化へ置き換える。通常RoPEのままでは8Kを越えたRULERが崩れる条件があり、疎注意の検索精度だけでなく位置外挿も別の制約であることを示す。

## 既存研究との差

平均プーリング型のチャンク検索は固定統計量を使い、検索スコアをtop-k決定後に捨てることが多い。HiLSはLogSumExp質量の近似という数理的な目標から圧縮キーとエントロピーバイアスを導き、検索スコア自体をattention
outputへ組み込む点が異なる。

また、推論時だけ既存全注意モデルのKVを選別する方式とは異なり、HiLSは疎注意を学習時からネイティブに使える。したがって検索器の追加だけではなく、モデルのattention機構そのものを疎な階層構造へ置換する方式である。

## 限界

HiLSは学習済み全注意モデルへ完全に無学習で差し込む方式ではなく、変換には継続事前学習が必要である。短文脈では疎検索・要約の固定費があり、H800評価では約16Kで全注意と速度が同等になってから長文脈側で優位になる。

報告された大きな速度倍率は、両方式を同じTriton基盤へ揃えたアルゴリズム比較であり、ベンダー最適化済みpaged
attentionとの直接比較ではない。さらに超長文脈能力は位置符号化とQ-Calに強く依存し、疎注意だけで自動的に外挿できるわけではない。
