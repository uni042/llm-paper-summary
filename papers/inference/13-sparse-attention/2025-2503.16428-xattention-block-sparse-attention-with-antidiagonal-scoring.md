# XAttention: Block Sparse Attention with Antidiagonal Scoring

> 反対角線標本の和で注意ブロック重要度を予測し、重要ブロックだけを残すことで256k級長文脈の注意計算を最大13.5倍高速化する。

## 概要
動的ブロック疎注意は重要ブロックだけ計算すれば二次計算を減らせるが、「どのブロックが重要か」を判定する処理自体が高価だと高速化を相殺する。XAttentionは、各注意ブロックの反対角線上の少数要素を足した値がブロック重要度の良い代理になるという観測を使う。RULER、LongBench、Video-MME、VBenchで全注意に近い品質を維持し、注意計算を最大13.5倍高速化する。

## 問題設定
長文脈プリフィルでは注意行列が系列長二乗で増える。固定疎パターンは入力ごとの重要位置を取り逃がし、既存の動的方式は重要度探索が重い。必要なのは、疎パターンを作るための追加計算が十分小さく、かつ縦方向・斜線方向の主要な注意構造を拾える代理指標である。

## 手法
XAttentionは注意行列をブロックへ分け、各ブロックの左下から右上へ走る反対角線上を一定strideで標本化する。その和をブロック重要度として使う。反対角線は縦方向と斜線方向の注意パターンを横切るため、ブロック全体を評価するより少ない要素で重要構造を検出できる。

得られたスコアを正規化し、累積重要度が閾値を超える最小集合のブロックを残す。固定Top-Kではなく重要度質量に応じてブロック数が変わるため、入力・ヘッドごとに必要な密度へ適応する。さらにヘッド別閾値を動的計画法で調整する構成も用意する。

## 評価条件・主要結果
| 観点 | 結果 |
|---|---|
| 長文脈言語 | RULER / LongBenchで全注意に近い品質 |
| 動画理解・生成 | Video-MME / VBenchでも評価 |
| 注意計算 | 最大13.5倍高速化 |
| 256k文脈 | 最大高速化条件として報告 |
| パターン選択 | 既存動的疎注意より低い探索負担 |

論文の主要結果は、疎化そのものだけでなく「疎パターン探索を軽くしたことで実際の注意高速化へつながる」点にある。

## 既存研究との差
MInferenceやFlexPrefillのような動的疎注意に対し、複雑なパターン探索ではなく反対角線の少数標本だけで重要度を近似する。モデル再学習を要求せず既存長文脈Transformerへ差し込める。

## 限界
反対角線スコアは代理指標なので、重要パターンが標本位置に現れない入力では誤選択し得る。高速化倍率は系列長・疎密度・カーネル実装に依存し、注意以外の層を含むエンドツーエンド倍率とは区別が必要である。
