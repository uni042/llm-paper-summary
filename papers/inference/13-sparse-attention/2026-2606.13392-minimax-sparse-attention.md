# MiniMax Sparse Attention

> 索引分岐でGQAグループ別にKVブロックを選び、専用GPUカーネルと組み合わせて1M文脈の注意計算28.4倍削減、H800でプリフィル14.2倍・デコード7.6倍高速化。

## 概要
100万トークン級の長文脈では、通常のソフトマックス注意（softmax attention）の計算量とKV読み出し量が二次的に増え、モデル本体を高速化しても注意が支配的になる。MiniMax Sparse Attention（MSA）は、既存のグループ化クエリ注意（Grouped Query Attention; GQA）を土台に、検索用の軽量な索引分岐と、選ばれたKVブロックだけを厳密計算する主分岐へ注意を分割する。モデル側の疎化だけでなくGPU実行経路も共同設計し、長文脈での理論削減を実測速度へ変換する。

## 問題設定
既存の疎注意には、検索器自体が高価、ヘッド間で同じ候補を強制して精度を失う、疎なアクセスがGPUのテンソルコアを使い切れない、といった問題がある。MSAは「どのKVブロックを見るか」をGQAグループごとに独立決定しつつ、選択粒度をブロックへ揃えてGPUで効率よく実行することを狙う。

## 手法
索引分岐（Index Branch）は各KVブロックの軽量表現を使って関連度を計算し、GQAグループ単位で上位kブロックを選ぶ。主分岐（Main Branch）はその候補だけに通常の注意を適用するため、最終attention値自体は選択範囲内で近似せず計算できる。グループ別選択により、異なるquery head群が別の長距離情報を必要とする場合にも対応する。

GPU側では指数関数を使わない上位k選択（exp-free Top-k）と、KV外積型の疎注意（KV-outer sparse attention）を用いる。疎ブロックを単純に個別処理するのでなく、テンソルコアの利用率とメモリアクセスを考えた配置にすることで、疎度が高い長文脈ほど実時間の利得が大きくなる。

## 評価条件・主要結果
| 項目 | 条件・結果 |
|---|---|
| モデル | 109Bパラメータ、ネイティブマルチモーダル学習 |
| 比較基準 | GQA |
| 最大文脈 | 1Mトークン |
| 注意計算量 | 1M文脈で1トークン当たり28.4倍削減 |
| GPU | NVIDIA H800 |
| プリフィル | 最大14.2倍の実時間高速化 |
| デコード | 最大7.6倍の実時間高速化 |
| 品質 | 評価した長文脈・一般能力でGQAと同等水準 |

計算削減28.4倍と壁時計14.2倍/7.6倍が異なる点は重要で、検索・インデックス処理や残存カーネル費用を含めた実装上のオーバーヘッドが存在する。それでもデコードでも大幅な速度向上を維持している。

## 既存研究との差
固定パターン疎注意と異なり、MSAは入力に応じてブロックを動的選択する。また検索器だけを提案する方式ではなく、上位k選択と疎attentionのGPU実装まで共同設計している。GQAグループ単位の独立検索により、全headで一つの候補集合を共有する方式より表現自由度を残す。

## 限界
索引分岐を含むモデルとして学習・適応する必要があり、任意の既存密注意モデルへ無変更で差し替える方式ではない。速度値はH800と論文のカーネル・形状条件に依存し、別GPUで同倍率を保証しない。疎検索が外したKVは主分岐で参照できないため、品質は索引分岐の学習と上位k設定に依存する。
