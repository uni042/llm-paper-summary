# MMInference: Accelerating Pre-filling for Long-Context VLMs via Modality-Aware Permutation Sparse Attention

## 概要
長動画や画像列を扱う視覚言語モデル（Vision-Language Model; VLM）では、最初の出力を生成する前のプリフィルで全入力トークン間の注意を計算するため、入力長が100万トークン級になると二乗計算量が支配的になる。テキストLLM向け疎注意をそのまま使うと、動画トークンの時空間構造や、テキストと映像の境界で注意パターンが変わる性質を取り逃す。

MMInferenceは、動画入力で一定間隔の位置へ注意が現れるGridパターンを観測し、散在した位置を置換によって連続ブロックへ並べ替える。これにより不規則な疎gatherではなくTensor Core向けブロック疎演算として実行できる。さらにヘッドごとにA字型、縦線・斜線、Grid、ブロック疎などの候補をオフラインで選び、実入力ではモダリティ境界を考慮して疎インデックスを構成する。モデル変更・追加微調整なしで、単一A100の1Mトークン条件においてエンドツーエンドのプリフィルを最大8.3倍、カーネルを最大12倍高速化し、評価した精度を維持した。

## 問題設定
動画では隣接フレーム・同一空間位置に対応するトークン間へ規則的な注意が生じる。元の系列順では重要位置が離散しているため、単純なブロック疎行列では多くの不要要素まで計算する。一方、細粒度のインデックスgatherで必要要素だけ読むとGPUの連続メモリアクセスとTensor Core利用を損ねる。

さらにVLM入力には映像、画像、テキストが混在する。同じ注意ヘッドでもモダリティ内とモダリティ間で疎分布が異なり、一つの固定疎パターンでは重要な注意を落とす。MMInferenceは「重要位置を探すこと」と「GPUが速く計算できる形へ並べること」を分ける。

## 手法
### ヘッド単位のパターン探索
校正入力を用いて各注意ヘッドがどの疎パターンに近いかをオフライン探索する。候補にはA字型、縦線・斜線、Grid、一般ブロック疎などがあり、ヘッドごとに異なる選択を許す。

この段階はモデル重みを変更せず、実行時に使う計算テンプレートを決める。固定した一種類を全ヘッドへ適用するより、視覚局所性を使うヘッドとテキスト依存ヘッドの差を残せる。

### Gridを置換でブロック化
動画のGridパターンは、元系列では一定間隔に離れた位置へアクセスするためGPUに不向きである。MMInferenceはQ/K/Vの順序を意味的対応を保ったまま置換し、同じGridに属する位置を隣接させる。置換後は重要領域が連続したブロックになり、規則的なブロック疎行列積へ落とせる。

計算後は対応する逆置換で元のトークン順へ戻せる。注意の対象集合を変えるのではなく表現上の並びを変えるため、Gridを細粒度gatherするよりメモリ局所性とTensor Core利用が改善する。

### モダリティ境界を考慮した動的疎分布
入力ごとに映像区間やテキスト区間の長さは異なる。MMInferenceは各モダリティ区間の末尾側クエリなど少量の観測から、現在入力で重要な列・斜線・Grid位置を推定し、オフラインで選んだヘッド型と組み合わせて疎インデックスを構築する。

これにより「動画内ではGrid、テキスト境界では別の重要列」という混在を扱う。推定処理自体とインデックス構築には追加費用があるが、長文脈では二乗注意を削る利得が上回る。

### 専用GPUカーネル
置換後のブロック構造を使う専用カーネルが、不要ブロックを読まずに注意を計算する。アルゴリズム上の疎性だけでなく、実GPUで連続アクセス可能な配置へ変換したことが、1Mトークンでの高速化へつながる。

## 評価
### 代表条件
|項目|内容|

|モデル|LongVila、LlavaVideo、VideoChat-Flash、Qwen2.5-VL|

### 主要結果
|条件|指標|結果|意味|
|---|---|---|---|
|1Mトークン|プリフィル速度|最大8.3倍|長文脈の二乗注意削減が全体時間へ反映|
|1Mトークン級|注意カーネル|最大12倍|置換＋ブロック疎実装の実GPU効果|
|複数VLM/タスク|精度|完全注意と同等水準|評価範囲では高速化のための顕著な品質損失なし|

## 既存研究との差
MInferenceなどテキスト中心の動的疎注意は縦線・斜線やブロック構造を利用するが、動画の時空間配置から生じるGridとモダリティ境界は中心対象ではない。MMInferenceはGridを新しい疎型として扱うだけでなく、置換でハードウェア効率の良い連続ブロックへ変換する点が追加される。

## 限界
主対象は長文脈VLMであり、純テキストLLMへ同じGrid利得があるわけではない。オフラインのヘッドパターン探索が必要で、モデルや注意特性が変われば再探索が必要になる。精度維持は評価した動画QA・キャプション・NIAH等の範囲での結果であり、あらゆる入力で完全注意と同一出力を保証するものではない。
