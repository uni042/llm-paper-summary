# Language model compression with weighted low-rank factorization

## 概要

低ランク因子分解は、Transformerの大きな線形重み行列を小さな2行列へ置き換え、パラメータ数と推論時の行列積を減らせる。しかし通常の特異値分解（SVD）は「元の重み行列を二乗誤差でどれだけ忠実に再構成できるか」だけを目的にし、その誤差が最終タスクの予測へどれだけ影響するかを区別しない。本論文はこの目的関数の不一致をBERTで実証し、タスク損失に対するパラメータ重要度を経験的Fisher情報で与えるFisher-Weighted SVD（FWSVD）を提案する。

重要なのは、FWSVDが単に通常SVDより小さい重み再構成誤差を作る方法ではない点である。むしろ再構成誤差自体が多少大きくても、タスク精度へ強く効く重みを優先して残す。BERT-baseを66.5Mパラメータへ圧縮した条件では、微調整なしの全タスク平均が通常SVDの39.0に対してFWSVDは58.2、微調整後は81.6対83.6となる。さらにTinyBERT、MiniLM、MobileBERT、DistilBERTなど既に小型化されたモデルにも追加圧縮を適用できる。

## 問題設定

通常SVDでは重み行列 W を U S V^T に分解し、小さい特異値に対応するrankを切り捨てる。正方に近い線形層なら保持rankを元次元の半分未満にすればパラメータ数を削減できる。しかし「特異値が小さい成分ほどタスクに重要でない」という保証はない。

著者は12層BERTのSTS-Bモデルで特異値を大きさ順に10群へ分け、各群だけを落として性能低下を測る。最小特異値側の第10群を落とした性能低下が第2群と同程度になる例を示し、特異値の大きさがタスク重要度の代理にならないことを確認する。これが、通常SVDが比較的小さな圧縮でも精度を急落させる原因だと位置付ける。

## 手法

### 経験的Fisher情報による重要度

対象タスクの学習データについて、各重みの損失勾配を二乗して平均し、経験的Fisher情報を推定する。絶対勾配が大きい重みほど、その変更がタスク目的関数へ大きく作用するという解釈である。

要素ごとの完全な重み付き低ランク近似には閉形式解がないため、FWSVDは同じ行に属する重みのFisher情報を合計し、行単位の重要度へ簡略化する。その平方根を対角行列 I とすると、通常の ||W-AB||² ではなく ||IW-IAB||² を最小化する。

### 標準SVDへ還元

重み付き行列 IW に通常SVDを適用して U* S* V*^T を得た後、左因子から I を逆変換する。したがって実装上は既存SVDを再利用でき、推論時には元の線形層を低rankの2線形層へ置き換えるだけで、Fisher計算を追加しない。

### 三つの圧縮経路

評価は、蒸留済み小型モデルを作る従来経路、タスク微調整済みBERTを直接因子分解する経路、既に小型化済みのモデルをさらに因子分解する経路を分ける。これにより、汎用事前蒸留を必要とせず直接圧縮できるか、また既存の小型化手法と重ねられるかを検証する。

## 評価条件

| 項目 | 条件 |
|---|---|
| 基準モデル | BERT-base 12層、109.5Mパラメータ |
| 主比較サイズ | SVD/FWSVDとも66.5Mパラメータ |
| タスク | CoLA、MNLI、MRPC、QNLI、QQP、SST-2、STS-B、CoNLL-2003 NER |
| 比較 | vanilla SVD、BERT-PKD、DistilBERT、MiniLMv2等 |
| 微調整 | 3 epoch、Adam、学習率2×10^-5、batch 32、1 GPU |
| 追加圧縮 | TinyBERT、MiniLM、MobileBERT、DistilBERT、ALBERT |
| 指標 | 各タスク標準指標とGLUE平均・全タスク平均 |

## 主要結果

| 条件 | 通常SVD | FWSVD | 読み取り |
|---|---:|---:|---|
| BERT 66.5M、微調整なし、全タスク平均 | 39.0 | 58.2 | Fisher重み付けだけで+19.2ポイント |
| BERT 66.5M、微調整あり、全タスク平均 | 81.6 | 83.6 | 同じ圧縮率でも初期化品質が改善 |
| DistilBERT | 83.3 | FWSVD+FT 83.6 | 高価な汎用蒸留なしでも同水準 |
| MiniLMv2 | 83.2 | FWSVD+FT 83.6 | 同上 |
| TinyBERT-STSB | 14.4M→11.8M (-18%) | 87.5→88.0 | 追加圧縮後も性能を維持 |
| MiniLM-CoNLL | 22.7M→18.4M (-19%) | 88.5→88.6 | 既圧縮モデルにも重ねられる |
| MobileBERT-MNLI | 24.6M→22.5M (-9%) | 83.6→82.5 | 小幅低下で追加削減 |
| DistilBERT-MRPC | 66.9M→46.7M (-30%) | 88.7→89.0 | 30%追加削減でも性能維持 |
| ALBERT-large 14%削減 | SVD+FT 77.1 | FWSVD+FT 84.3 | パラメータ共有モデルでも差が大きい |

微調整なしの比較ではFWSVDが通常SVDを平均17.5ポイント上回ると論文は報告する。特に通常SVDがCoNLLで12.0、STS-Bで26.8まで崩れるのに対し、FWSVDは49.6、68.6を残す。Fisher重要度が低rank成分の「タスク上の重要性」を補うという仮説と整合する。

## 既存研究との差

DistilBERTやMiniLMなどの知識蒸留は、小型モデルを汎用コーパス上で事前学習・蒸留してから対象タスクへ微調整する。FWSVDはタスク微調整済みモデルの重みを直接低rank化できるため、この汎用蒸留工程を必須としない。通常SVDとの差は分解形式ではなく、対象タスクのFisher情報を再構成目的へ入れる点にある。

また、枝刈りや蒸留とは競合せず、既にTinyBERTやALBERTなど別手法で小型化されたモデルへ追加適用できる。したがって本手法は独立した圧縮器というより、既存圧縮後の残余冗長性を削る後段処理としても使える。

## 限界

FWSVDは対象タスクの学習データと勾配を必要とするため、データなしで任意checkpointを圧縮する純粋な事後処理ではない。著者もこの適用範囲の制約を明記している。また要素ごとのFisher重み付き因子分解を解かず、同一行の重みを同じ重要度へ集約する近似を使うため、Fisher情報を完全には利用していない。

評価対象はBERT系のencoder言語モデルと分類・類似度・NERが中心であり、現代の自己回帰LLMにおける生成スループット、GPUカーネル効率、KVキャッシュ、量子化とのend-to-end併用は評価していない。パラメータ削減が実配備のレイテンシ短縮へどこまで直結するかも本論文の主要実測対象ではない。
