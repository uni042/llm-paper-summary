# EventPrune: Cascaded Event-Assisted Token Pruning for Efficient First-Person Dynamic Spatial Reasoning

> イベントカメラの動き信号で場面の固定とトークンの濾過と注意の補正を段階的に行う学習なし削減を提案し、2割の保持で全トークンを上回る精度と1.89倍の高速化、演算量52パーセント減を示した。

## 概要

一人称の視点で動きながら空間を推論する課題では、連続する動きと正確な幾何を追う必要がある一方、動画をそのまま大規模な視覚言語モデルへ入れると視覚トークンが膨れ、注意の費用が二乗で効く。学習なしの視覚トークン削減は有力な対策だが、既存の削減信号は一人称の激しい動きの前で弱い。場面の間では、外見の画素差分や特徴の類似で冗長を判定すると、速度や軌跡のような連続した動きの性質を捉えられず、費用もかかる。場面の中では、注意の重みで選ぶと構造の要のトークンを落としうる。本論文の分析では、視覚注意が画像の周縁へ強く偏る現象が見つかった。21920枚の画面と28層の分析で、周縁と中央の注意の比は全層で1を超え、中間の層では5.64倍に達した。注意の高い順に残す方式は、この偏りの産物を残し、中央の構造を捨てることになる。

本論文は、削減信号をモデルの外から持ち込む。イベントカメラは、画素ごとの明るさの変化が閾値を超えたときだけ、マイクロ秒の分解能で非同期に記録する感知器である。動きのある場所と、輪郭や質感のある場所で自然に発火するため、動きと幾何の両方の手がかりになる。提案する段階的削減は三段で構成される。第一段はイベントの活動量で要の場面を固定する。第二段はイベントの顕著さで動きのないトークンを落とす。第三段は注意とイベントの顕著さを順位の空間で融合し、周縁への偏りを層ごとに補正しながらさらに落とす。イベントは評点とマスクの計算にだけ使い、埋め込んでモデルへ入れることはしないため、既存モデルへ学習なしで後付けできる。

代表結果は次の通りである。公開資料集の13課題の平均では、視覚トークンを20パーセントだけ残す条件で37.62パーセントとなり、全トークンの36.31パーセントを上回った。推論は1.89倍速く、演算量は52パーセント減り、最大メモリも下がった。実物のイベントカメラで撮影した新しい実世界資料集では、保持率50パーセントで全トークンを2.68点上回った。イベントだけを信号にする単純な方式は強く崩れるため、利得はイベントの有無ではなく段階の設計にあることも示されている。実機測定に基づく研究である。

## 問題設定

一人称動画の削減が難しいのは、残すべき情報が動きと幾何の両方にまたがり、しかもその情報が通常の削減信号とずれていることにある。時間方向では、一様な間引きは一瞬の決定的な変化を取りこぼし、外見の差分は動きの速さや向きを持たず、速い動きやぼけで不安定になる。空間方向では、注意は課題への関連ではなく位置の偏りを含む量であり、多様性や統合で選ぶ方式は対象の境界をばらばらにして幾何の連続性を壊す。強い削減になるほど、予算が小さいために一つの誤った保持が他の要のトークンを押し出す形で効く。

イベント信号がこのずれを埋める理由は、その生成のされ方にある。イベントは明るさが変わった画素でだけ起きるため、静止した背景ではほぼ起きず、動く輪郭では密に起きる。つまりイベントの密度そのものが、動きの量と構造の所在の粗い地図になる。課題は、この非同期で疎な信号を、同期した格子状の特徴を持つモデルの推論へどう橋渡しするかである。信号の時間の細かさと、トークンの空間への対応付けと、注意との尺度の違いの三つを処理しなければ、外部の事前情報は使えない。本論文は、時間は活動量の窓、空間はトークンの担当領域への集計、尺度は順位への射影で処理する。

## 手法のあらまし

入力は通常の動画と、同期したイベントの流れであり、対象モデルは既存の動画言語モデルである。まずイベントの流れを一定の時間の窓へ分け、感知器の雑音を密度の濾過で抑えたうえで、窓ごとの活動量を数える。活動量の大きい窓と、活動量の変化が大きい窓の両方を候補にし、密集した低活動の候補を間引いたり大きな時間の隙間を埋めたりして、目標の数の場面を固定し、最も近い通常画像の場面へ対応付ける。次に、各場面について、対応する時間の窓のイベントをトークンの担当領域ごとに数え、正規化して動きの顕著さとし、保持率に応じた数だけ顕著さの高いトークンを残す。最後に、選ばれた削減層で、文章に条件付けられた視覚の重要度とイベントの顕著さを、それぞれ場面の中で順位へ直してから層ごとの重みで混ぜ、上位だけを残す。重みは、周縁への偏りの信頼度が高い浅い層でイベント側を強くし、深い層では意味の注意を残すよう小さくする。削減は時間、空間、表現の順に段階的に進み、各段の出力が次段の候補集合になる。

## 手法

### 1. イベントで要の場面を固定する — 活動量とその変化の二つの物差し

この機構が観測するのは、密度の濾過をかけたイベントの流れを時間の窓で数えた活動量である。保持する状態は窓ごとの活動量の列だけであり、重い特徴の照合は行わない。動作は二つの物差しの併用である。活動量そのものが大きい窓は動きの豊かな瞬間を表し、隣の窓との活動量の差が大きい窓は場面の力学が切り替わる転換点を表す。両方の上位を合わせて候補とし、低活動の候補が密集していれば間引き、時間の大きな隙間があれば埋めて、目標数へ整える。選ばれた窓は最も近い通常画像の場面へ対応付けられる。減るボトルネックは、時間方向の冗長と、決定的な瞬間の取りこぼしであり、場面数が減る分だけ後段すべての費用が下がる。追加で消費する資源はイベントの集計だけであり、外見の差分方式のような画像同士の処理は要らない。失敗時の挙動は、感知器の揺れに由来する。雑音の多いイベントでは活動量が膨らむため、密度の濾過で抑える設計になっている。除去実験では、この段は主に効率を担い、遅延を2.08秒から1.58秒へ下げつつ精度もわずかに上げた。後の段と組み合わせた場合に精度の土台になることも示されており、場面の対応がずれた状態では後段の融合がうまく働かない。

### 2. 動きの顕著さで落とす — イベントのないトークンを早い段で消す

観測するのは、各場面に対応する時間の窓の中で起きたイベントを、トークンの担当領域ごとに数えた数である。保持する状態はトークンごとの顕著さであり、場面の中で最小と最大で正規化した0から1の値である。動作は、保持率で決まる数だけ顕著さの高いトークンを残す単純な選択であり、これにより後段の注意の対象は候補だけに絞られる。視覚トークンの注意の費用は、保持率の二乗で下がるため、早い段で落とすほど利得が大きい。減るボトルネックは、静止した背景のような動きのない領域が注意と鍵値保存を占有する事態であり、追加の資源はイベントの集計と正規化だけである。失敗時の挙動は、静かだが重要な対象への弱さである。動いていない対象はイベントを生まないため、この段だけでは静的な手がかりを落としやすい。除去実験でも、この段の単独は推論や計画の課題で強い一方、背景の文脈を失って認知の課題では弱くなることが報告されている。そのため最終段で意味の注意と混ぜる設計になっており、この段は高い信号対雑音の濾過として位置付けられる。

### 3. 順位の融合で注意を補正する — 周縁の沈み込みを層ごとに弱める

観測するのは、削減層の直前の注意の図から読み取った、文章に条件付けられた視覚の重要度と、前段のイベントの顕著さである。保持する状態は層ごとの融合の重みであり、周縁への偏りの信頼度から決まる。偏りは、周縁と中央の注意の比と、その一貫性を表す効果量で測られ、浅い層で一貫性が高く、中間の層で偏りの大きさが最大になる。動作は、まず注意と顕著さを場面の中でそれぞれ順位へ射影し、最大値で割って0から1へ揃えることである。両方の信号は裾の長い分布を持ち、少数の極端なトークンが支配するため、値のまま混ぜると外れ値に引きずられる。順位へ直すことで尺度の違いを消す。次に、重み付きで混ぜた評点の上位を保持率に応じて残す。イベントの裏付けのない周縁のトークンは、注意の順位が高くてもイベントの順位が低いため、重みの分だけ評点が下がって落ちやすくなる。逆にイベントの裏付けのある周縁のトークンは残るため、一律に周縁を罰する設計ではない。減るボトルネックは、偏った注意で保持された産物が鍵値保存に残り続け、後段の注意を汚す連鎖であり、付録ではこの浄化の仕組みが解析されている。追加の資源は順位付けの計算だけであり、失敗時の挙動として、重みをイベント側へ寄せすぎると意味の注意が痩せる。重みの感度実験では、一様な重みで0.7まで上げるほど精度が上がるが、イベントのみの1.0ではわずかに下がり、偏りに合わせた浅い層で強い配分が最良だった。

## 評価

### まず見るところ

結論は、外部の動き信号を評点だけに使う段階設計で、強い削減でも精度を落とさず、むしろ全トークンを上回れることである。全トークンを上回る理由は、削減がノイズになるトークンを消し、注意の偏りの産物を鍵値保存から除くためと解釈されている。読み方で重要なのは二点ある。第一に、公開資料集のイベントは元の動画から生成した模擬イベントであり、実物の感知器の結果は新しい実世界資料集の側である。第二に、イベントだけを使う単純方式が大きく崩れるため、利得は感知器の追加そのものではなく、場面の固定と濾過と融合の段階設計に帰属させるべきである。評価の強さは、保持率三段階と比較方式七つ、効率の実測、構成要素と重みと層選択の除去実験まで揃っている点にある。一方で、対象モデルは一種類であり、同期したイベント入力という前提自体が配備の範囲を限る。

## 既存研究との差

動画の視覚トークン削減は、場面間の差分、注意、多様性、統合を信号にしてきたが、いずれも信号をモデルの内部か外見から作るため、一人称の動きでは動きの連続性と幾何の両方を落としやすい。イベントを使う視覚言語の研究は、イベント用の符号器や追加の学習でイベントを埋め込む方向であり、既存の通常動画モデルへそのままは使えない。本論文の差は、イベントを表現としてではなく評点だけの事前情報として使い、時間の固定、空間の濾過、表現の補正という三つの段に分解して差し込んだ点にある。あわせて、視覚注意の周縁への偏りを大規模に数量化し、その偏りの信頼度を補正の強さと層の選択へ直接つないだ点も、削減の設計論として独立した寄与である。何を動かす研究かで言えば、先行研究が内部の評点を磨くのに対し、本論文は評点の片方を物理的な感知器へ外注する。

## 限界・実装状況

- 同期した通常画像とイベントの入力が前提であり、イベントカメラを備えた環境でなければ使えない。感知器の普及は進んでいるが、通常のカメラだけの配備は対象外と論文自身が明記している。
- 対象モデルは一種類での検証であり、注意の偏りの形が違うモデルでも層の選択と重みの配分がそのまま効くかは未評価である。
- 公開資料集の結果は模擬イベントに基づいており、実物の感知器の雑音や同期のずれへの頑健さは、実世界資料集の範囲でしか確認されていない。
- 静的な場面の記憶に頼る課題では利得が小さく、動きの乏しい入力では外部の事前情報の価値が下がる。
- コードと実世界資料集は公開時に公開するとされ、現時点では本文中に公開先がない。再現は記述と付録の手順に依存する。
- 実世界資料集は一人称の撮影映像を含むため、公開にあたっての個人情報の除去や利用条件の整備が論文中で述べられており、配備時も同様の配慮が要る。

## 一般的な実装上の含意

削減の信号がモデルの内部の量だけで作られている場合、その量自体の偏りが削減の誤りになる。注意を使う設計では、まず注意の空間的、層的な偏りを数量化し、偏りの強い場所では外部の物差しや別の信号で補正するのがよい。尺度の違う信号を混ぜるときは、値のままではなく順位へ直すと、裾の長い分布の外れ値に引きずられにくい。削減は一段で決めず、時間、空間、表現の順に候補を絞る段階設計にすると、各段の失敗が次の段で回復できる余地が残る。あわせて、外部の感知器のような事前情報は、表現へ混ぜるより評点だけに使うほうが、既存モデルへの後付けと失敗時の切り分けが容易になる。
