# Same Beliefs, Different Policies: Learning Reusable Representations for Early Stopping in LLM Reasoning

> 凍結した推論モデルの隠れ状態から正答見込みの4つの信念を価格非依存に学習し、その上に線形の停止方策を当てはめることで、価格変更に再学習なしで追随しながら生成トークンを4割から5割減らす早期停止方式。

## 概要

推論モデルは、答えがすでに決まった後も思考を続けることが多い。余分な思考は生成トークンと遅延を増やすだけでなく、正しかった答えを誤答へ反転させることもある。そこで思考の途中で強制的に答えを出させる早期停止が研究されてきたが、学習型の方式には運用上の弱点があった。停止制御器を、正解率からトークンコストを引いた効用で直接学習すると、学習された表現そのものがそのときのトークン価格に結び付く。価格は運用側の都合で変わる量であり、価格が変わるたびに制御器を学び直すのは高くつくし、直接効用の学習自体も勾配の性質から崩壊しやすいことが論文で示されている。

BELTは、変わらない部分と変わる部分を分ける。変わらない部分は、モデルの内部状態から正答の見込みを読む能力であり、BELTはこれを4つの信念として定義する。今この瞬間に答えれば正答する確率、自然に完了するまで続ければ正答する確率、後の境界のどこかで正答する確率、そして自然完了時の答えと一致する確率である。これらを予測するプローブを価格に依存しない教師で一度だけ学習し、特徴として凍結する。変わる部分は価格と精度要求への適応であり、これは凍結した特徴の上の線形ロジスティック方策を当てはめ直すか、閾値を動かすだけで済む。代表結果として、分布外の数学5課題の平均で、精度を自然デコードと同等に保ちながら生成トークンをQwen3-1.7Bで41パーセント、OLMo-3-7B-Thinkで51パーセント削減した。精度を1ポイントまで許容する条件では、価格ごとに専用の制御器を学習した比較手法と同等以上の削減率を、はるかに小さい学習コストで達成している。さらに、数学で学習したプローブと方策は変更なしにコード生成とエージェント課題へ転移し、エージェント課題のScienceWorldでは自然なスコアを保ったまま思考トークンの85パーセントを削減した。

## 問題設定

過剰思考への対処は、大きく分けて固定の上限、確信度などの手作りの信号、そして学習型の制御器がある。固定の上限は問題の難しさに応じられず、確信度の閾値はモデルやタスクごとに調整が要る。学習型の代表であるOS-Prunerは、トークン価格を変えた効用ごとに別々のチェックポイントを学習する方式であり、価格の格子を細かくするほど学習コストが線形に増える。しかも価格は、APIの料金、バッチの混み具合、遅延の要求など、モデルの外側の事情で決まる量であり、モデルの表現へ焼き込むべきではないというのが本論文の立場である。

もう1つの問題は学習の安定性である。効用を直接最大化する学習では、停止判断の勾配が価格と結び付いた形になり、論文の勾配分析によれば、学習が停止側か継続側へ倒れ込む崩壊が起きやすい。対照的に、信念の予測は通常の教師あり学習であり、正答かどうかという観測可能な結果を教師にするため、目的関数が価格に依存せず、学習も安定する。本論文はこの分離を、同じ信念から異なる価格の方策が導けるという主張として定式化し、タイトルの「同じ信念、異なる方策」はその要約である。

## 手法のあらまし

BELTの推論時の流れは次の通りである。推論モデルは通常通り思考ブロックを生成し、ブロックの境界ごとにプローブが走る。プローブは凍結したモデルの中間層、Qwen3では第16層、OLMo-3では第18層の隠れ状態を受け取り、共有表現と4つの信念の予測を出す。方策は、信念のロジットと接頭辞の長さ、あるいは共有表現そのものを入力として、停止するかどうかを線形に判定する。停止と判定されれば、その時点で答えを強制的に出させて生成を終える。学習は2段階で、第1段階は信念プローブの学習であり、思考の途中で実際に強制回答させて得た結果からラベルを作り、価格を含まない二値交差エントロピーで学習する。第2段階は方策の当てはめであり、凍結した特徴に対して、効用を最大化する線形モデルを評価データ上で選ぶ。価格が変わった場合は、この第2段階だけをやり直すか、判定の閾値を価格に応じて動かす。

## 手法

### 1. 4つの信念 — 停止判断に必要な未来の情報を予測対象にする

信念の設計が本論文の中心的な工夫である。停止の判断は、本質的には「今止めた場合」と「続けた場合」の比較であり、現在の正答確率だけでは続ける価値が分からない。そこでBELTは4つの量を予測する。今答えれば正答する確率であるNow、自然に完了するまで続ければ正答する確率であるEnd、後のいずれかの境界で答えれば正答する確率であるLater、そして今の答えが自然完了時の答えと一致する確率であるSameである。Laterは続けることの上限の価値を与え、Sameは、たとえ正答率が変わらなくても答えの中身が安定しているかを見る。ラベルは、学習時に思考ブロック4つごとに実際に強制回答させ、その結果を記録することで得る。EndとSameのラベルは自然に完了した軌跡との比較から作られるため、追加の人手アノテーションは要らない。予測対象をこの4つに固定することで、プローブの学習は価格と無関係な純粋な予測問題になり、方策側は価格を含む効用をこれらの予測の上で組むことができる。

### 2. プローブ — 小さい系列モデルで隠れ状態を読む

プローブの構造は意図的に小さく保たれている。各トークンの隠れ状態を幅768へ射影し、思考ブロックの終端を示す学習可能な埋め込みを差し込み、因果的なトランスフォーマ2層で系列として読み、最後に4つの線形ヘッドとシグモイドで各信念を出す。損失は4信念の二値交差エントロピーの等重み和である。パラメータ数はQwen3用で約16M、OLMo-3用で約19Mであり、比較対象のOS-PrunerがQwen3で約101M、OLMo-3で約405Mのチェックポイントを価格ごとに持つのと対照的である。入力層の選択は検証で行われ、Qwen3は第16層、OLMo-3は第18層が使われた。アブレーションでは、信念で学習した特徴の上に同じ線形方策を当てはめると、生の隠れ状態、主成分分析で圧縮した特徴、平均プーリングした特徴、信念学習なしの事前学習済みプローブの特徴のいずれよりも、全ての価格で効用が高かった。4信念だけに線形プローブを当てはめた軽量版でも固定特徴の比較対象を全価格で上回り、利得の主因が構造よりも予測対象の設計にあることが示唆されている。

### 3. 方策の当てはめ — 価格適応を線形モデルの再当てはめと閾値に閉じ込める

第2段階では、凍結した特徴の上に線形のロジスティック停止方策を当てはめ、正解率から価格とトークン数の積を引いた効用を評価データ上で最大化する。方策の入力には2つの界面がある。1つは信念界面で、4信念のロジットと12,000で割った接頭辞長を合わせた低次元の特徴であり、解釈しやすくデータ効率が良い。もう1つは共有表現界面で、プローブ内部の768次元表現そのものを使う。価格への適応方法にも2通りあり、価格ごとに方策を当てはめ直す方法と、1つの方策の閾値を価格に応じて動かす方法である。当てはめ直しは価格ごとに数個から769個程度のパラメータを決めるだけで、CPUでも実行できる軽い処理であり、閾値方式なら再学習は完全に不要になる。論文の推奨構成は共有表現と閾値方式の組み合わせであり、価格の細かい格子でも1方向の重みと価格ごとの閾値だけで運用できる。精度の制約は、評価データ上で自然デコードの精度からの許容幅を指定して動作点を選ぶ形で扱われ、許容幅ごとに削減率が報告されている。

### 4. 転移 — 学習した信念は課題をまたいで使えるか

分離の主張が本物なら、数学で学習したプローブは他の課題でも停止判断に使えるはずである。論文は3方向の転移を検証している。コード生成のLiveCodeBenchでは、事前と事後の2つの分割で、精度許容1ポイントの条件で信念界面と閾値方式の構成が47.65パーセントの削減を達成し、価格ごとに学習した比較手法と同水準だった。エージェント課題では、行動の前に思考するエージェントの思考制御へ、OLMo-3のプローブと方策と比較手法のチェックポイントを無変更で移した。ALFWorldでは思考が成功率を4.5パーセントから33.6パーセントへ押し上げるため削減の余地は小さく、BELTは比較手法と同等で、再当てはめした共有表現の構成が全ての読み取りで最高の平均を示した。ScienceWorldでは思考の大半が不要であり、全てのBELT構成が自然なスコア以上を保ったままトークンの85パーセントを削減した。思考が要る環境と要らない環境の双方を、数学で学習した19Mパラメータのプローブ1つで覆えたことが、分離の実証になっている。

### 5. なぜ直接効用の学習は崩壊するのか

論文は、比較手法の方式である直接効用学習が不安定な理由を勾配の観点から分析している。効用最大化の勾配は、停止か継続かの離散的な選択に対する価格依存の項を含み、学習の初期条件や価格の大きさによっては、一方向へ倒れて全て止める、あるいは全く止めない解へ流れやすい。これに対して信念の学習は、観測された結果に対する通常の予測学習であり、勾配は価格を含まず、学習曲線も安定する。信念のアブレーションでは、NowとEndだけでも分布外の効用は完全な4信念にかなり近い値まで届く一方、LaterとSameを含めることで精度制約を満たす動作点のカバー範囲が広がることが示されており、4信念の役割は平均効用の底上げというより、制約付きの運用点を取りこぼさないことにあると読める。

## 評価

結論を先に述べる。BELTは、精度を保つ条件での生成トークン削減において、価格ごとに専用学習する比較手法と同等以上の性能を、1つの小さなプローブと安い価格適応で達成した。特にOLMo-3では自然精度の条件で51.59パーセントの削減を達成し、比較手法の45.92パーセントを上回る。評価の主指標はトークン削減率であり、壁時計時間の短縮は測定されていない。プローブ自体の推論コストはトークン当たりの演算量として報告されており、Qwen3では比較手法の約4.1分の1である。

## 既存研究との差

DEERは確信度が閾値を超えた時点で、CoDE-Stopは連続する区間の確信度から、思考を打ち切る学習不要の方式であり、信号の設計が手作業である。OS-Prunerは学習型の代表であり、効用を直接学習するため価格ごとにチェックポイントが要る。ROMやThought Calibrationも、停止の基準を特定の運用条件へ結び付ける点では同様である。BELTの差は、学習対象を価格非依存の信念予測へ限定し、価格と精度要求への適応を凍結特徴上の線形方策へ追い出した点にある。この分離により、制御器の式自体は単純なまま、再利用可能性と価格適応の安さが得られている。推論の予算配分や適応的計算の研究一般に対しては、適応の対象を推論時の計算量配分ではなく停止判断の表現設計に置いた研究として位置づけられる。

## 限界・実装状況

論文が認める限界として、精度制約の充足は評価した分布の上での話であり、新しい分布へ移した場合の保証にはならない。安全に関わる判断への適用は未評価であり、早期停止が誤った確信に基づいて働く場合のリスクは別途検証が要る。実務上の限界として、プローブの学習には思考の途中で強制回答させる軌跡の収集が必要であり、対象モデルごとに中間層の選択と学習を行わなければならない。転移は実証された範囲では無変更で成り立ったが、数学と大きく異なる様式の生成では信念の予測自体がずれる可能性がある。また主指標はトークン削減率であり、プローブ評価の上乗せを含めた壁時計時間の短縮は測定されていないため、遅延の改善幅は削減率から割り引いて読む必要がある。実装面では公式コードとチェックポイントが公開されており、再現と転移の検証が可能な形で示されている。

## 一般的な実装上の含意

第一に、推論時の制御器は、変わらない予測能力と変わる運用条件を分離して設計すべきである。価格や精度要求のような外側の量を表現学習へ焼き込むと、条件が変わるたびに再学習が発生する。第二に、停止や打ち切りの判断には現在の確信度だけでなく、続けた場合の見込みと、答えの安定性までを含む未来向きの予測が要る。現在の状態だけを見る制御は、続ける価値を系統的に見誤る。第三に、方策の側は線形モデル程度の単純さで十分な場合があり、複雑な制御器よりも、良い特徴と安い再当てはめの組み合わせが運用では強い。第四に、トークン削減率を遅延改善と同一視せず、制御器自体の推論コストを差し引いて評価する姿勢が必要であり、本論文がトークン当たりの演算量を併記した点は実務的な手本になる。
