# AQuaUI: Visual Token Reduction for GUI Agents with Adaptive Quadtrees

> 画面の情報密度に合わせて四分木で割り、各葉に代表トークンを一つ残す学習なしの削減を提案し、320億級モデルでトークン29.52パーセント減と性能の99.06パーセント保持、最大13.22パーセントの高速化を示した。

## 概要

画面を見て操作するエージェントは、対話の各段で高解像度の画面を取り込む。例えば携帯電話の画面は、ある系統のモデルでは約3000個の視覚トークンになる。視覚トークンは入力処理の遅延と注意の費用と鍵値保存の容量を同時に押し上げ、保持できる対話履歴の長さも削る。ところが画面の中身は一様ではない。背景や余白のような大きな均一領域は情報が少なく、文字や小さな図形の集まる場所は高い忠実度が要る。自然画像向けの圧縮の前提はこの偏りに合わない。

既存の削減は二つの方向に寄っていた。一つは注意の重みや類似度からトークンの重要度を推す汎用方式で、画面では注意が低いトークンでも表示名や座標の手がかりとして要る場合があり、位置の連続性を壊す危険もある。もう一つは画面向けの削減をモデルの学習と一体に行う方式で、特定のモデルでしか使えない。本論文は学習なしで推論時に後付けできる第三の道を取り、画面の空間構造そのものを分割の単位にする。適応的な四分木、つまり均一な領域は大きな葉のままにし、複雑な領域だけを再帰的に四つへ割る階層分割を画面へ構築し、各葉に代表トークンを一つだけ残す。残したトークンの位置情報は元の座標のまま運び、位置符号化の各段と整合させるため、モデルから見た画面の幾何は崩れない。

さらに、連続する画面の間では条件付きの構築を行う。前の画面と比べて静止している領域や、少しずれただけの領域では前の分割を引き継ぎ、細部の分割が段ごとに作り直されて揺れるのを防ぐ。代表結果は次の通りである。320億級の画面エージェントモデルでは視覚トークンを29.52パーセント減らし、全トークン時の性能の99.06パーセントを保ち、最大で13.22パーセントの高速化が得られた。新系統のモデル群では、約3割の削減で平均の精度低下が0.48から0.85点に収まった。実機測定に基づく研究である。

## 問題設定

視覚トークンの費用は、トークン数の増加に対して注意では二乗で効き、入力処理と鍵値保存でも比例して効く。画面操作ではこの費用が対話の段ごとに発生するため、一回あたりの削減がそのまま全体の応答性と履歴の長さに効く。問題は、何を落とすかの基準である。自然画像向けの重要度推定は、画像の中の目立つ対象を残す方向に働く。しかし画面操作の課題は、押すべき場所の座標を答えることであり、目立たない表示名や、対象の周囲の配置関係そのものが証拠になる。注意の低さは不要さと一致しない。

もう一つの難しさは位置である。トークンを間引いた後で、残りを詰めた格子としてモデルへ渡すと、モデルは画面が縮んだものとして位置を解釈し、座標の答えがずれる。削減しても幾何を保つには、残したトークンの本来の座標を、視覚側と文章側の両方の位置符号化へ正しく伝える必要がある。さらに多段の対話では、画面がほぼ同じなのに分割が毎回変わると、前の段で見えていた細部が次の段で消え、推論の一貫性が崩れる。削減の設計には、密度への適応、位置の保持、時間方向の安定の三つが同時に要る。本論文はこの三つを、四分木という一つの構造で担わせる。

## 手法のあらまし

処理は画面一枚ごとに行われる。まず画面を、モデルの統合済みトークンの格子に合わせる。対象の系統では視覚の小片の大きさと統合の倍率から、一つの文章側トークンが28画素四方に対応する。画面の寸法は2の冪とは限らないため、中央の正方形の塊で敷き詰められる領域と、端の余り領域へ分け、余りはトークン単位の葉としてそのまま残し、中央領域の各塊の中で四分木を独立に回す。各節点では、面積で重み付けした灰色値のばらつきを評点とし、評点が閾値以下になるまで再帰的に割る。閾値は係数で調整でき、大きくするほど圧縮が強くなる。勾配の最大値を使う評点も選べる。分割が止まった葉ごとに、葉の中央の塊を代表として選び、そのトークンだけを残す。残したトークンは元の座標とともに文章モデルへ渡される。連続する画面では、塊ごとに前の画面との類似を測り、静止なら前の葉をそのまま使い、ずれているなら粗い葉だけをずらして再利用し、どちらでもなければ作り直す。

## 手法

### 1. 格子への整列と分割条件 — 密度の高い場所だけを細かく割る

この機構が観測するのは、画面の灰色値そのものである。保持する状態は四分木の階層であり、各節点は自分の領域の評点を保持する。動作は二段ある。まず整列では、画面をトークン格子の倍数である正方形の塊へ敷き詰め、端数は壊さずに残すことで、後のすべての分割境界がトークンの境界と一致するようにする。次に分割では、各節点について面積と灰色値のばらつきの積を評点とし、閾値を超える節点だけを四つへ割る。面積で重み付ける意味は大きく、大きな領域はばらつきが中程度でも割る対象になり、小さな均一領域は早めに一つの葉へ畳まれる。代表の選択は葉の中央の塊であり、平均化した新しいトークンを作るのではなく、実在のトークンを一つ選ぶ。そのため視覚符号器の出力の性質は変わらず、位置もそのトークンの元の座標がそのまま使える。減るボトルネックは、言語モデルへ渡る視覚系列の長さであり、注意と鍵値保存と入力処理の費用が下がる。追加で消費する資源は、四分木の構築と、座標の情報を提供基盤の中を運ぶ仕組みである。失敗時の挙動は近似であることに由来する。均一と判定された領域の中に小さな手がかりが埋もれていると、その葉は一つの代表に畳まれ、手がかりが失われる。評点の選択で挙動は変わり、ばらつき型は安定しているが圧縮は控えめで、勾配型は強く圧縮できる代わりに精度の低下が大きいことが感度評価で示されている。

### 2. 位置の保持 — 間引いても画面の幾何を崩さない

観測するのは、各葉の代表トークンの元の格子座標である。保持する状態は四分木の情報として座標の対応であり、提供基盤を通じて視覚側と文章側の位置符号化へ渡される。動作は系統で違う。旧系統では、通常の前処理で得た密な小片の並びから代表に対応する行を選び、視覚符号器の後に削減する慎重な経路を既定とし、符号器の質を保ったまま文章側へ渡る系列だけを短くする。代表の座標は文章側の回転位置の構築へ注入され、間引かれたトークンが詰まった格子として解釈される事態を避ける。新系統では符号器の前に削減し、視覚側と文章側の両方の費用を下げる。その代わり、提供基盤の都合で必要な矩形の格子へ詰める際に余白へ複製を置きつつ、真の座標は四分木の情報で別に保持し、視覚側の回転位置と絶対位置の補間と文章側の回転位置のすべてを真の座標で直し、後続の文章トークンの位置のずれも再計算する。減るボトルネックは、座標のずれによる位置決めの誤りであり、これは削減そのものより致命的になりうる。追加の資源は系統ごとの位置符号化への手入れであり、失敗時の挙動として、この手入れを欠くとトークンは減っても幾何が壊れ、精度が大きく落ちる。論文が繰り返し強調する通り、この方式は学習なしではあるが実装なしではなく、位置を運ぶ経路の改造が前提になる。

### 3. 条件付きの四分木構築 — 前の画面の分割を条件付きで引き継ぐ

観測するのは、現在の画面と直前の画面について、塊ごとに作った凝縮した署名である。署名は塊をトークン単位の小格子へ分け、各小片の平均の灰色値を丸めたもので、画素単位の比較より安く安定している。保持する状態は前の画面の四分木の葉の集合である。動作は三つの場合分けである。署名の類似が0.97以上なら静止とみなし、前の葉をそのまま使う。静止でない場合は、小片単位のずれを上下左右に最大4つまで探し、重なる部分での類似が0.94以上で、かつずれなしより0.03以上良い場合に、ずれたとみなす。このとき再利用するのは粗い葉だけであり、細い葉は文字や図形の周りで小さなずれが害になりやすいため作り直す。どちらにも当てはまらなければ置換として、前の情報なしに新しく構築する。最後に、新しく作った分割の各葉について、その内部を前の葉が隙間なく覆う場合にだけ、葉を前の細かい分割へ置き換える。減るボトルネックは、段ごとの分割の揺れによる細部の喪失と、それによる多段推論の不安定さである。追加の資源は署名の計算と比較であり、失敗時の挙動は、変化の大きい画面では置換へ倒れて通常の独立構築に戻るため、誤った引き継ぎが長引くことはない。除去実験では、この仕組みを外すと対話型の移動課題の成功率が約2.6点落ち、圧縮率がほぼ同じであることから、利得はトークン数の差ではなく分割の保持によることが示されている。

## 評価

### まず見るところ

結論は、画面の密度に合わせた分割は、無作為な削減や汎用の削減より精度を保ち、その利得はモデルが大きいほど遅延の改善としても現れることである。小さいモデルや旧系統では、削減の追加処理が節約を食って遅延が増える場合がある。読み方で重要なのは、系統による実装経路の違いである。新系統は符号器の前で削減するため視覚側の費用まで下がるが、旧系統の既定経路は符号器の後であり、視覚側の費用は下がらない。同じ圧縮率でも遅延の意味が系統で違う。評価の強さは、位置決めの五課題と移動の二課題、複数のモデル系統と規模で一貫して測っている点にある。一方で、比較対象の画面向け方式は旧系統の実装しかなく、新系統での直接比較は行われていない。

## 既存研究との差

視覚トークンの削減は、重要度をどう推すかで発展してきた。注意を使う方式、グラフの伝播を使う方式、文章との類似を使う方式はいずれも、トークン単位の重要度を推して落とす発想である。鍵値保存の圧縮は、トークンが変換器に入った後の費用を下げる方向であり、系列そのものを短くする本論文とは直交する。画面向けでは、構造の規則性を使う学習一体型の方式と、指示に関連する小片を選ぶ方式があったが、主な結果はモデル固有の学習設定で得られたものだった。本論文の差は、重要度の推定をやめて画面の空間構造を分割の単位にしたこと、位置を元の座標のまま運ぶことで学習なしの後付けを可能にしたこと、そして連続画面で分割を引き継ぐ時間方向の仕組みを加えたことにある。何を動かす研究かで言えば、先行研究がどのトークンを残すかを推すのに対し、本論文は画面をどの粒度で見るかを決める。

## 限界・実装状況

- 学習なしではあるが実装は必要であり、正しい位置の保持にはモデル固有の位置符号化の経路の改造と、四分木の情報を提供基盤の中へ運ぶ仕組みが要る。現在の実装は二系統と一つの提供基盤に限られる。
- 削減の追加処理が節約を上回る条件があり、小さいモデルでは遅延の利得が出ない。追加処理のうち一部は高速化の余地があるが未実装と明記されている。
- 系統で削減の位置が違い、新系統では符号器の前、旧系統の既定では符号器の後である。旧系統では視覚符号器の費用は下がらず、遅延の利得は限られる。
- 対話型の長い課題では誤差が段をまたいで蓄積し、単段の位置決めより低下が大きい。
- 論文中に公式コードの公開先は示されておらず、再現は実装の詳述に依存する。
- メモリや鍵値保存の実測効果、同時実行時の挙動は未評価である。

## 一般的な実装上の含意

入力の情報密度が場所で大きく違う場合は、重要度の推定より先に、密度に合わせた空間の分割を検討する価値がある。トークンを間引く際は、残したトークンの位置を元の座標で運ぶことが精度の前提であり、位置符号化の各段へ一貫して伝える必要がある。削減の追加処理は固定費として効くため、利得はモデル規模と削減位置で判断すべきであり、符号器の前で落とせるかどうかが遅延の分かれ目になる。連続する入力では、分割や選択の結果を条件付きで引き継ぐと、段ごとの揺れによる細部の喪失を防げる。引き継ぎは、変化の種類を見分けて、危険な部分だけを作り直す形にすると安全である。
