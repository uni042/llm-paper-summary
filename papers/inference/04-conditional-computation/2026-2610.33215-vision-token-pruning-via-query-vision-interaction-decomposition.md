# Vision Token Pruning via Query-Vision Interaction Decomposition

> クエリと視覚の相互作用行列の低ランク構造を使い、上位の特異方向へ参加するトークンを残す学習なしの枝刈りQViDで、強い圧縮ほど既存手法より精度を保った研究。

## 概要

視覚言語モデルは、画像を視覚トークンの列へ変換し、文章のクエリと一緒に言語モデルへ通して答えを作る。画像1枚で数百から数千の視覚トークンが発生するため、推論の遅延とメモリは視覚トークンの数に強く引っ張られる。そこで、言語モデルへ渡す視覚トークンを途中の層で間引く枝刈りが使われてきた。従来の信号は大きく2系統ある。1つは注意のパターンから重要度を読む方式で、クエリを意識できる反面、文章に近い位置の視覚トークンへ点数が寄る位置の偏りを持つ。もう1つは隠れ状態の層間の変化量で読む方式で、位置の偏りは避けられるが、クエリとの関わりを直接は測っていない。どちらのクエリが来たかで残すべき画像領域は変わるはずなのに、信号の側がそれを正面から表していなかった。

本論文のQViDは、この隙間を埋める第三の信号を提案する。着眼点は、トランスフォーマーの注意に既にあるクエリ射影とキー射影から作れるクエリと視覚の相互作用行列が、実効的に低ランクだという観測である。少数の支配的な相互作用モードにクエリへ関わる意味が集中しており、各視覚トークンがそのモードへどれだけ参加しているかで重要度を測れる。QViDは序盤の層でこの行列を作り、特異値分解の上位方向への参加度でトークンを点数付けし、上位だけを残して残りの層へ渡す。学習は不要で、注意の重みそのものは使わない。

**代表結果:** LLaVA-1.5-7Bで視覚トークンを576個から64個へ約89%減らす条件でも、全面保持を100%とした正規化平均は90.4%に達し、最強の既存手法V2Dropの86.9%を3.5ポイント上回った。Qwen2-VL-7Bでは保持率11.1%で81.7%対62.7%と差が19ポイントへ開く。計算量は全面保持の8.86テラフロップスから2.53テラフロップスへ71.5%減り、実測のスループットも毎秒8.60枚から10.40枚へ上がる。

## 問題設定

視覚トークンの数が効く理由は2つある。第一に、言語モデルの各層は全トークンを処理するため、系列が長いほど計算量と活性値のメモリが増える。第二に、生成の前段である入力処理が長くなり、最初のトークンまでの遅延が伸びる。高解像度化と動画対応で視覚トークンは増える方向にあり、枝刈りは周辺的な最適化ではなく推論コストの主戦場になっている。

枝刈りの難しさは、落とす判断の信号にある。注意の重みから読む方式は、クエリへの関わりを測っているように見えて、自己回帰の位置関係による偏りを含む。文章の直前にある視覚トークンが、内容と無関係に高い注意を受けやすいためである。変化量で読む方式はこの偏りを避けるが、測っているのはトークン自身の活動量であり、目の前のクエリにとっての根拠かどうかではない。帽子をかぶった動物の画像でも、動物を問うクエリと背景を問うクエリでは残すべき領域が違う。クエリ条件付きでありながら注意の重みに依存しない信号が要る、というのが本論文の問題設定である。

## 手法のあらまし

処理の流れは単純である。画像とクエリを通常どおり言語モデルへ通し、序盤の層（主設定では第3層）に達した時点で、その層の隠れ状態からクエリ側と視覚側の表現を取り出す。凍結されたクエリ射影とキー射影を適用して相互作用行列を作り、注意ヘッドごとに特異値分解する。各視覚トークンのスコアは、上位の右特異ベクトルへの参加度の二乗和をヘッド平均したものとする。スコアの高い順に予算個数だけトークンを残し、以降の層は短くなった系列だけを処理する。位置埋め込みの回転は行列を作る際に外し、位置ではなく意味の合い方で相互作用を測る。分解の計算はクエリ長が視覚トークン数よりずっと短いことを利用して軽く抑えられ、削減できる後段の計算に比べれば小さい。

## 手法

### 1. 相互作用行列 — 既にある射影からクエリと視覚の合い方を取る

入力は枝刈り層における視覚トークンの隠れ状態と、クエリトークンの隠れ状態である。ここへ、その層の注意が持つクエリ射影とキー射影をそのまま適用し、クエリ側の射影結果と視覚側の射影結果の内積を行列にする。行列の各要素は、あるクエリトークンとある視覚トークンの表現空間での合い方を表し、列方向に見れば1つの視覚トークンがクエリ全体とどう関わるかの要約になる。注意スコアとの違いは、ソフトマックスを通す前の射影段階の量であり、後段の正規化や位置の回転の影響を受けないことである。論文は位置埋め込みの回転を意図的に外して行列を作っており、位置の近さではなく内容の合い方を測る設計になっている。追加の学習や外部のモデルは一切使わず、凍結された射影だけが材料である。

### 2. 低ランク観測と支配的モード — 意味が少数方向へ集中する

この行列を調べると、特異値が少数の方向へ集中する強い低ランク構造が観測される。つまり、クエリと視覚の関わりは全方向に均等に広がっているのではなく、少数の潜在的な相互作用モードでほぼ表せる。さらに、その支配的な成分だけを取り出すと、タスクに関わる構造、すなわち答えの根拠になる画像領域との対応が保たれることが確認されている。逆に、行列の列の大きさをそのまま重要度に使う単純な方法では、支配的な構造と残余のエネルギーが混ざってしまい、後の除去実験で大きく劣る結果になる。低ランクであること自体が発見であり、分解して上位だけを使うことが方式の核である。

### 3. スコア付けと枝刈り — 参加度で残すトークンを決める

各注意ヘッドで相互作用行列を特異値分解し、視覚側を表す右特異ベクトルを得る。視覚トークンのスコアは、上位の特異方向（主設定では16成分）に対するそのトークンの係数の二乗を合計したもので、支配的な相互作用モードへどれだけ参加しているかを表す。ヘッドごとに同じ計算を行い、平均したものを最終スコアとする。クエリが短くて使える特異方向が設定数より少ない場合は、クエリ長と視覚トークン数の小さい方に合わせて成分数を切り詰める。最後にスコア上位の予算個数だけを残し、残りの層はその短い系列で通常どおり処理する。枝刈りは序盤の第3層で行うのが主設定で、層の選択は付録の走査で精度と効率の釣り合いから決められている。落としたトークンは近似として失われるため方式は近似型だが、落とす対象をクエリの根拠から外れたトークンへ寄せることで品質の損失を抑える狙いである。

### 4. 効率化されたスコア計算 — 分解のコストを小さく保つ

素朴に大きな行列を分解すると枝刈りの利得を食いかねないため、実装ではクエリ側の小ささを生かした縮約を使う。クエリトークン数は視覚トークン数よりはるかに少ないので、分解の対象は実質的にクエリ長で決まる小さな問題になり、スコア計算全体の費用は5000万フロップス未満に収まる。視覚トークンを1個減らすと後段の言語モデル計算が約0.01テラフロップス節約できるため、数百個の削減で得られる節約はスコア計算の費用を大きく上回る。枝刈り層より前の層は全トークンを処理する点は既存方式と共通で、利得は枝刈り位置より後ろの全層に効く。

## 評価

### まず見るところ

- **結論:** 同じトークン予算なら、相互作用の低ランク構造で選ぶ方が、注意 ベースでも変化量 ベースでもない既存の信号より下流の精度を保てる。差は強い圧縮ほど大きい。
- **速度・効率:** 計算量は保持64トークンで全面保持比71.5%減、実測スループットは毎秒8.60枚から10.40枚へ改善する。ただし同じ予算のV2Dropよりは分解の分だけ遅延がわずかに大きい。
- **品質:** 近似型の枝刈りであり全面保持には届かないが、保持率の下げ幅に対して正規化平均の落ち方が最も緩やかである。幻覚に敏感な評価とキャプションでも強さを保つと付録で報告されている。
- **メモリ・入出力:** 系列が短くなる分、後段の活性値とKVキャッシュは減る方向だが、メモリ使用量そのものの実測表は論文にないため未評価として扱う。
- **評価の強さ／注意点:** 画像6ベンチマーク、動画2ベンチマーク、4つのモデルでの実機評価で、成分数・層・スコア規則の除去実験までそろっている。一方、比較対象の一部は先行論文の報告値の引用である。

**代表結果の読み方:** 保持192トークンではQViDとV2Dropの差は0.5ポイントしかないのに、64トークンでは3.5ポイント、Qwen2-VL-7Bの保持率11.1%では19ポイントへ広がる。予算が緩い条件ではどの信号でも根拠トークンを拾えるが、予算が厳しくなると、クエリと無関係なトークンを混ぜる余地が消え、信号の的確さがそのまま精度になるためである。逆に言えば、この方式の価値は余裕のある条件ではなく、メモリや遅延の制約が厳しい条件で最大になる。

| 特異成分数16個 | 96.5% | 主設定。頑健さのために採用 |
| 枝刈り層の走査（第1層から第5層、保持128個） | 平均96.1%から96.7%の範囲 | 層の選択に大きくは敏感でない |

- 実速度はハードウェア、バッチの組み方、系列長、注意カーネルの実装で変わり得る。

## 既存研究との差

注意 ベースのFastVやSparseVLMは、序盤の注意パターンで視覚トークンを選ぶが、位置の偏りと、高速な注意実装で重みを取り出しにくい問題を抱える。変化量 ベースのV2Dropはその両方を避けた強い方式だが、信号がクエリを直接は見ない。本論文は、注意の重みではなく射影段階の相互作用行列を使い、その低ランク分解でクエリ条件付きの信号を作る点で両系統と異なる。トークンを混ぜ合わせるマージ系とも異なり、選んだトークンの表現そのものは変えずに落とすだけである点も単純で、後段の処理へ手を入れない。

## 限界・実装状況

評価は公開モデルと標準的な画像・動画ベンチマークに限られ、閉じたモデル、独自の推論基盤、専門領域での振る舞いは論文自身も未確認としている。学習なしの方式であるため、土台のモデルの偏りや失敗様式はそのまま引き継ぐ。実速度はハードウェア、バッチ構成、系列長、注意カーネルの実装に依存し、論文の数値は単一GPUの特定条件のものとして読む必要がある。今後の方向として、トークン予算の適応化、成分数の動的選択、ハードウェアを意識した基盤との統合が挙げられている。公式コードの公開先は論文中に記載がなく、再現は論文の手順記述に依拠する。方式自体は枝刈り層に置く独立モジュールとして実装でき、既存の提供基盤へ組み込む際の変更範囲は小さい。

## 一般的な実装上の含意

枝刈りの信号は、最終段の注意の重みではなく、その手前の射影に眠っている場合がある。注意の重みは正規化と位置の事情を背負うため、関連性の代理指標としては汚れている。射影段階の量を使い、しかも生の大きさではなく低ランクな支配構造を取り出す、という手順は他の圧縮判断にも応用できる。また、圧縮率が高い条件ほど信号の質が精度を決めるため、枝刈り方式の比較は緩い予算だけでなく、実運用で本当に使いたい厳しい予算で行うべきだという評価上の教訓も得られる。追加計算を払って信号を良くする交換は、削減量が大きい条件では十分に見合う。
