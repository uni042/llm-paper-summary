# PoWER-BERT: Accelerating BERT Inference via Progressive Word-vector Elimination

## 概要

PoWER-BERTは、BERTの分類・回帰推論において、各層で処理する単語ベクトルの数を徐々に減らすことで、モデルの重みを削らずに推論時間を短縮する研究である。元のBERTは、入力系列の全トークンに対応する隠れ表現をすべてのエンコーダ層へ渡す。ところが自己注意によってトークン間で情報が混ざるため、後段では複数の表現が似た情報を含むようになり、分類に必要な情報を保持したまま一部を取り除ける。PoWER-BERTはこの冗長性を、注意重みの列方向合計による重要度採点と、各層の保持トークン数を学習する仕組みで利用する。

方式は二つの判断を分離する。第一に、**どの単語ベクトルを残すか**を入力ごとに注意行列から決める。第二に、**何個残すか**を、学習可能な軟選択層と計算量に相当する保持量の正則化を用いて決める。最終的な推論では、軟選択を離散的な抽出処理に置き換え、各エンコーダの自己注意処理の後、前向きネットワークへ進む前に低重要度の行を落とす。BERT_BASEの12層・隠れ次元768という骨格は維持し、層が進むほど系列長を短くする。

原著のK80 GPU、Keras、バッチ128（RACEのみ32）の評価では、BERT_BASE比で各課題2.0～4.5倍の推論時間短縮を報告する。代表例のCoLAは898→201ミリ秒、QQPは1833→405ミリ秒で、課題別の評価指標の低下をおおむね1ポイント以内に制限した。圧縮済みのALBERTに適用した場合もQQPで1950→287ミリ秒、約6.8倍を示す。ただし、これは**双方向エンコーダの分類・回帰推論**に対する結果であり、生成型LLMのトークン毎秒や自己回帰復号の高速化を直接示すものではない。

## 問題設定：重みではなく中間表現が冗長になる

BERT_BASEは12個のエンコーダ層、各層12個の注意ヘッド、隠れ次元768からなる。入力を最大長Nへパディングし、各トークンを768次元のベクトルへ変換した後、すべての層でN個のベクトルを処理する。分類では通常、最終層の先頭に置いたCLSトークンの表現から答えを作るが、それ以外のトークンも途中の層で注意計算や前向きネットワークに参加し続ける。入力が長いほど、注意行列の計算と各行の前向き変換の費用が増える。

従来の軽量化では、層を丸ごと削る蒸留、注意ヘッドの枝刈り、重みの量子化、パラメータ共有などが使われる。しかし、重み容量が小さくなっても推論時の演算数が同じなら速度は比例して上がらない。ALBERTはエンコーダ間で重みを共有してモデル容量を削減するが、同じ系列長・同じ層数の処理を繰り返す限り推論演算は大きく残る。PoWER-BERTは、**重み行列のサイズを維持したまま、各層へ渡す入力行数を減らす**点で異なる。

著者らはSST-2で、最終的な分類をCLS以外の位置のベクトルから行っても、平均の精度低下が1.2ポイント程度、標準偏差0.23ポイントである例を示す。これは各トークン表現が後段で類似することの兆候であり、層別の全トークン対の余弦類似度も後段ほど増えると報告する。もちろん、似ているだけで全トークンを無条件に削除できるわけではない。特に初期層では重要な情報が一部の位置に偏り得るため、入力ごとに残す位置を選ぶ必要がある。

## 手法

### 1. 保持構成：層ごとの残存ベクトル数

保持構成（retention configuration）を、12層それぞれの残存数の列 `(ℓ1, ℓ2, …, ℓ12)` として定義する。元の入力長を `ℓ0=N` とし、各層の出力で `ℓj` 個だけを次層へ渡す。削除済みのベクトルを後段で復活させないため、通常は `ℓj≤ℓj−1` の単調減少とする。論文の図に示された入力長128の例では、保持数は `(80,73,70,50,50,40,33,27,20,15,13,3)` と段階的に減る。隠れ次元768は最後まで変えない。

保持数を早い層で小さくすれば計算を多く削減できるが、情報がまだ十分に混ざっていない段階で重要な語を落とす危険が増す。逆に後段まで多く保持すると分類精度は守りやすいが、推論時間の短縮幅が小さくなる。保持構成は精度と計算費用の交換条件そのものであり、固定の一律削減率を与えるだけでは最適化できない。

### 2. 注意行列の列方向合計による重要度

各層の注意ヘッド `h` の注意行列を `A_h` とし、行 `w'` が問い合わせ側、列 `w` が参照される側のトークン位置を表す。トークン `w` が他のトークンからどれだけ参照されるかを、`Sig_h(w)=Σ_{w'} A_h[w',w]` と定義する。全ヘッドについて足した `Sig(w)=Σ_h Sig_h(w)` を、その層の単語ベクトルの重要度とする。単なるトークン頻度や埋込みノルムではなく、**実際の自己注意で他の位置の表現形成に寄与した重み**を集計する点が特徴である。

この値が高いベクトルを残すのは、後続の表現がそのベクトルから情報を受け取る割合が大きいと推定できるからである。著者らは、ある層で一つのベクトルだけを除いた場合に元モデルの分類結果とどれだけ一致するかを相互情報量で調べ、低スコアのベクトルを除く方が元モデルの予測を保ちやすいことを確認する。後段ほど高スコアの一部ベクトルを除いても元モデルとの一致が保たれるという傾向も、情報拡散の仮説と対応する。

### 3. 動的抽出層と静的選択の違い

保持数 `ℓj` が決まった層では、自己注意と前向きネットワークの間に抽出層（extract layer）を挿入する。入力ごとに `Sig(w)` を計算し、上位 `ℓj` 個の行だけを次の計算へ渡す。位置の選択は入力ごとに変わる。例えば先頭から一定数だけ残す静的方式（Head-WS）は、短い文のパディングを消すには有効だが、長い文では後半の重要語まで消す危険がある。ランダムな固定位置を残す方式（Rand-WS）も、語ごとの寄与を見ない。

注意に基づく動的方式（Attn-WS）は、同じ残存数なら静的方式より精度が高い。これは計算量を同一に揃えた構成要素比較であり、単に多くのベクトルを残したための差ではない。なお、CLSトークンは最終予測に使うため削除しないという制約を設けている。

### 4. 軟選択層による保持数の学習

入力ごとに「どの位置を残すか」は注意行列から求められるが、各層の「何個残すか」を全組合せ探索すると指数的に候補が増える。そこで学習時には、離散的に削除する代わりに、順位ごとの保持係数 `r_j[k]∈[0,1]` を持つ軟選択層（soft-extract layer）を挿入する。層 `j` で重要度順に `k` 番目のベクトルを、その係数だけ縮小して前向きネットワークへ渡す。係数が1なら保持、0に近ければ実質的に無効化する方向である。

保持量を `mass(j)=Σ_k r_j[k]` とし、元の分類・回帰損失に `λ Σ_j j·mass(j)` を加える。後段ほど係数 `j` が大きいので、後段の保持数削減を強く促す構成になっている。`λ` を大きくすると削減を優先し、小さくすると精度を優先する。係数は最初すべて1で初期化し、学習後に `ℓj=ceil(mass(j))` で離散的な保持数へ変換する。まれに単調減少を破る場合は、前層の残存数以下へ補正する。

この方法は推論時に連続係数を掛け続けることを目的としない。軟選択は**学習時に保持構成を求める代理操作**であり、最終的な推論では実際に行を取り除く抽出層へ置き換える。そのため、推論時には不要なベクトルの自己注意・前向き処理を本当に省ける。

### 5. 三段階の学習と推論の流れ

実行準備は、(1) 事前学習済みBERTを対象課題で微調整し、(2) 軟選択層を追加して保持数を探索し、(3) 軟選択を実際の抽出層に置き換えて再学習する、という三段階である。論文の実験では各段階に2～3エポックを用いる。したがってPoWER-BERTは「追加学習なしで任意のBERTへ即適用する方式」ではない。保持構成を学習し、削除後の情報経路に適応させる再学習が必要である。

推論時は、入力を埋め込み、最初のエンコーダで全入力行を処理し、自己注意の結果から重要度を算出して指定数の行を選ぶ。その出力が前向きネットワークへ入り、次の層は縮小した行集合だけを受け取る。これを12層で繰り返し、最後に保持されたCLS表現で分類する。入力に応じて重要度順位が変わっても、各層の保持**数**は事前学習した固定値なので、各層のテンソル形状を一定に保ちやすい。

## 評価条件

| 項目 | 条件 |
|---|---|
| 対象モデル | BERT_BASE：12層、12注意ヘッド/層、隠れ次元768。ALBERTへの追加適用も評価 |
| 対象課題 | GLUEの分類・回帰9データセット、IMDB感情分類、RACE読解 |
| 主な入力長 | CoLA/SST-2/STS-B 64、QQP/MRPC/MNLI/QNLI 128、RTE 256、IMDB/RACE 512 |
| 実行環境 | K80 GPU、Keras実装 |
| 推論時間の測定 | 原則バッチ128、RACEは4択のためバッチ32。100回平均 |
| 精度指標 | CoLAはMatthews相関、QQP/MRPCはF1、STS-BはSpearman相関、それ以外は正解率 |
| 比較対象 | 元のBERT_BASE、ALBERT、DistilBERT、BERT-PKD、注意ヘッド枝刈り（Head-Prune） |
| 精度制約 | 正則化係数λを調整し、BERT_BASEからの課題別評価指標低下を約1ポイント以内に抑制 |

入力長は、パディングが多いほど削減の見かけ上の利益が増えることを避けるため、データの99%程度を覆う長さに近い値を64・128・256・512から選んだ。学習用ハイパーパラメータは課題別の開発集合で調整し、GLUEのテスト精度は評価サーバーに提出した値である。実測値は2020年当時のK80 GPUとKerasに依存し、現在のGPUや推論ランタイムで同じ倍率になると主張するものではない。

### 削減した中間ベクトル数と演算量の因果関係

RTEの入力長256では、元のBERTは12層で合計 `12×256=3072` 個のベクトル行を処理する。PoWER-BERTの学習済み保持構成は `(153,125,111,105,85,80,72,48,35,27,22,5)` で、合計868行となる。前向きネットワークの行ごとの処理と注意行列の大きさが縮小するため、計算費用が減る。ここで3072→868という行数比は推論時間の実測倍率3.4倍と同一ではない。行の選択・並べ替え費用、GPUカーネルの固定費用、注意行列の二次的な計算量変化などがあるからである。

### ALBERTへの適用

| 課題 | ALBERT → PoWER-BERT時間（ms） | 時間短縮倍率 | 評価指標の変化 |
|---|---:|---:|---:|
| CoLA | 940 → 165 | 5.7倍 | 42.8 → 43.8 |
| RTE | 4210 → 1778 | 2.4倍 | 65.6 → 64.6 |
| QQP | 1950 → 287 | **6.8倍** | 68.3 → 67.4 |
| MNLI-m | 1960 → 589 | 3.3倍 | 82.6 → 81.8 |
| STS-B | 956 → 604 | 1.6倍 | 80.9 → 80.0 |

ALBERTは重みを共有して容量を減らしたモデルだが、PoWER-BERTは中間ベクトル数を削るため両者を重ねて適用できる。QQPで最大6.8倍の時間短縮を示す一方、STS-Bでは1.6倍にとどまる。これは「パラメータ共有だけでは計算量が減らない」という問題設定に対し、異なる冗長性を利用した結果である。

### 構成要素除去：入力ごとの重要度選択は必要か

| SST-2の条件 | 先頭固定選択 | ランダム固定選択 | 注意に基づく動的選択 |
|---|---:|---:|---:|
| 全データ | 85.4% | 85.7% | **88.3%** |
| 入力長が16超 | 83.7% | 83.4% | **87.4%** |

論文表4では、同じ保持構成を用いて削減数を揃えたまま、選択方法だけを変えている。注意による動的選択は全体で約2.6～2.9ポイント、長い入力では約3.7～4.0ポイント高い。長い文では先頭固定方式が重要な後半語を落としやすくなるため、入力ごとの注意行列から重要度を求める機構が精度維持に実際に寄与していることを示す。

### 既存方式との速度・精度の交換条件

DistilBERTとBERT-PKDはエンコーダ層数を3・4・6層に減らす設定で比較され、Head-Pruneは残す注意ヘッド数を変える。PoWER-BERTは正則化係数を変えて速度と精度の複数点を得ている。原著の精度対時間の比較では、同じ推論時間でCoLAの指標が最大16ポイント、RTEの正解率が最大6ポイント改善し、同じ評価指標でCoLA最大2.7倍、RTE最大2.0倍の時間短縮を報告する。これは**すべての課題でその差が出る**という意味ではなく、図の特定の比較点における最大差である。

## 既存研究との差

DistilBERTやBERT-PKDは層そのものを減らすため、削減後のモデルは元モデルとは別の浅い構造になる。Head-Pruneは注意ヘッドの一部を削るが、元のBERT_BASEのパラメータのうち注意ヘッドが占める割合には限界があり、前向きネットワークを含む全層の費用を十分に減らせない。PoWER-BERTは層数と重みの形状を維持し、**各層で処理するトークン行数を変える**ため、浅いモデルへの蒸留とは別の速度・精度の交換条件を実現する。

ALBERTはパラメータ共有により重み容量を削減するが、推論時の行列演算をそのまま残す。PoWER-BERTはこれと独立した中間表現の冗長性を対象にするので、圧縮済みのALBERTへも適用できる。後年の動的トークン削減方式と比較すると、PoWER-BERTは各層の保持**数**を学習して固定し、残す**位置**を入力ごとに選ぶという役割分担が明確である。

## 限界と適用範囲

PoWER-BERTの性能評価はBERT系の**双方向エンコーダ**による分類・回帰が中心である。CLSベクトルから答えを出すタスクでは、後段の多数の単語ベクトルを落としても精度が維持されやすい。一方、機械翻訳や文章生成のように全位置の表現が出力へ関わるタスクへ、同じ削減規則を直接適用できるとは限らない。原著も翻訳や要約への拡張を今後の課題としている。自己回帰LLMのKVキャッシュ削減や投機的復号の性能とは異なる研究対象である。

追加学習も必要である。微調整、保持数探索、削減構成での再学習の三段階を経て初めて推論時の高速化を得る。タスクや入力分布が変わると、学習済みの保持構成が最適でなくなる可能性がある。各層の注意行列を使った重要度採点と上位選択にも費用がかかるため、短い系列や小さいバッチでは実測の速度比が変わり得る。入力長を一律に大きく取ればパディング削除で有利な数字が出やすいが、原著は比較の公平性のため課題別の短い最大長を採用した。

報告されたK80 GPU上のKeras実測は2020年当時の実装条件に固有であり、FlashAttentionなどの現代的な注意カーネル、コンパイル済みグラフ実行、最新GPUへそのまま倍率を移せない。モデル重みを削らないため、重み容量自体を減らしたい端末では量子化・蒸留の代替ではなく、組み合わせを検討する技術である。

## サーベイでの位置付け

PoWER-BERTは、パラメータ圧縮ではなく**実行時のトークン表現数**を削減して推論を速くする初期の代表例である。注意の列方向集計による寄与推定と、学習した層別保持予算の組合せは、後の動的トークン削減や適応的な層内計算の設計を理解する際に有用である。ただし、BERT分類推論の研究であり、生成型LLMの配信スケジューリングやKVキャッシュ最適化の実測研究と同じ表に速度倍率を並べて比較すべきではない。
