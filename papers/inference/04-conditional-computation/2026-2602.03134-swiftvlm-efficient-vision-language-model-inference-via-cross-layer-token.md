# SwiftVLM: Efficient Vision-Language Model Inference via Cross-Layer Token Bypass

> 落選した視覚トークンを捨てずに迂回させ、次の枝刈り層で表現を補正して再評価する学習不要の枝刈りで、トークンを3分の1に減らしても位置特定の精度を無枝刈りの約87パーセントに保った。

## 概要

視覚言語モデル（画像を視覚トークンへ変換し、言語モデルがテキストと一緒に処理するモデル）では、1枚の画像が数百個の視覚トークンになる。トークン数が増えると注意計算は二乗、全結合計算は比例で膨らむため、視覚トークンの削減は推論効率の中心課題である。既存の削減は、テキストから視覚への注意（テキストのトークンがどの視覚トークンへ強く注目するか）の大きさで順位付けし、浅い層で下位を捨てるか統合するかだった。しかし本論文の層別分析では、重要度の順位は層によって大きく入れ替わる。浅い層で下位半分に入ったトークンの中に、深い層では上位1割に入るものがあり、浅い層の判定で捨てると、文字を読む課題や物体の位置を特定する課題で必要な細部が戻ってこない。

本論文の方式SwiftVLMは、捨てる代わりに迂回（バイパス）させる。最初の枝刈り層で落選したトークンは、そのまま保持して次の枝刈り層へ送る。同時に落選分は特徴の類似度で統合した代表トークンとして通常の推論にも参加させる。次の枝刈り層では、統合代表が中間の層で受けた変化量（隠れ状態のずれ）を落選トークンへ加えて表現空間をそろえ、テキストと一緒に再評価する。あわせて、どの層で枝刈りするかは、層ごとの選択能力を実測し、選択能力が単調に強くなる組合せを動的計画法で選んで固定する。**代表結果:** LLaVA-1.5-7Bで視覚トークンを576個から192個へ減らした条件で、位置特定課題（RefCOCO系3種）の平均正解率は無枝刈りを100とした相対値で86.9パーセントを保ち、FastVの40.3パーセント、PDropの27.6パーセントを大きく上回った。演算量は4.29テラ演算から1.75テラ演算へ減った。

## 問題設定

問題を資源と情報の観点で見る。視覚トークンを減らせば計算は減るが、削減の判断は「その層で不要に見えるか」で行われる。浅い層ではテキストとの対応付けがまだ弱く、細部を要する課題ほど判定を誤りやすい。捨てる方式では誤判定が不可逆であり、深い層は不完全な視覚証拠の上で推論することになる。統合する方式も、似た特徴同士を混ぜるため位置や文字のような細部が薄まる。つまりボトルネックは計算量そのものに加え、「早い段階の不確かな判定を確定させてしまう」構造にある。本論文は、判定を遅らせるのではなく、落選した情報を低コストで保持し、選択能力の強い深い層で判定し直すことで、この不可逆性を断とうとする。

## 手法のあらまし

処理は枝刈り層の事前決定と、推論時の迂回と再評価からなる。事前には、無枝刈りのモデルを走らせて各層で注意に基づく上位2割の視覚トークンを記録し、層ごとに上位だけを残したときの課題性能を測って、各層の選択能力を評価する。そのうえで、深くなるほど選択能力が単調に強くなる層の列を動的計画法で選び、モデル固有の枝刈り層として固定する。推論時は、最初の枝刈り層で選ばれたトークンが通常の経路を進み、落選トークンは類似度でグループ化して統合代表を作りつつ、元のトークン自体も保持して次の枝刈り層まで迂回させる。次の枝刈り層では、統合代表の隠れ状態の変化量をグループ内の落選トークンへ一律に加えて位置合わせし、テキストトークンと一緒に再順位付けする。ここで選ばれれば本流へ復帰し、落選すればさらに次の機会か最終的な除外へ進む。

## 手法

### 1. バイパス — 落選トークンを保持し、次の枝刈り層で再評価する

この機構が観測するのは、枝刈り層でのテキストから視覚への注意による順位である。保持する状態は、落選した視覚トークンそのものと、その類似度グループへの所属である。行う動作は削除ではなく転送であり、落選トークンを次の枝刈り層まで保持して再順位付けの対象に戻す。減るボトルネックは、浅い層の誤判定による不可逆な情報損失である。追加で消費する資源は、保持するトークンのメモリと再評価の計算だが、落選分は中間層の通常計算には参加しないため、全トークンを残すよりは安い。誤った場合の挙動として、再評価でも落選すれば情報は最終的に使われないが、少なくとも選択能力の強い層の判定を受けたうえでの除外になる。捨てる方式との本質的な差は、除外の確定を遅らせる点にある。

### 2. 統合と表現位置合わせ — 迂回中の代表の変化を落選トークンへ写す

この機構が観測するのは、落選トークン同士の特徴の類似度と、統合代表が中間層で受けた隠れ状態の変化である。保持する状態は、類似度で分けたグループと、各グループの統合代表（グループ内の隠れ状態の平均）である。行う動作は二つある。まず落選トークンを類似度で統合し、代表だけを通常の推論へ参加させて大まかな情報を伝える。次に次の枝刈り層で、代表の変化量をグループ内の各落選トークンへ同じ量だけ加え、現在の表現空間にそろえてから再評価する。なぜ効くか。迂回中のトークンは中間層の計算を受けていないため、そのままでは表現が古く、テキストとの比較がずれる。グループ平均の変化で近似的に追随させることで、個別に全層を計算し直す費用なしに比較可能性を回復できる。論文の分析では、細かいグループ分けのもとで、統合代表の変化量と実際のグループ平均の変化が低次元射影でほぼ重なることが確認された。追加費用は類似度計算と統合の演算で、演算量の式も示されている。失敗条件はグループ分けが粗い場合で、性質の違うトークンを同じ変化量で動かすと位置合わせが崩れる。

### 3. 枝刈り層の選択 — 選択能力が単調に強くなる層の列を選ぶ

この機構が観測するのは、層ごとに「上位2割だけを残して課題を解かせたときの性能」で測った選択能力である。保持する状態は、モデルごとに固定された枝刈り層の列である。行う動作は選択であり、選択能力が深さとともに単調に増えるという制約のもとで、最もよい組合せを動的計画法で求める。減るボトルネックは、選択能力の弱い層で枝刈りしてしまう誤りと、能力が上下する層で繰り返し判定する無駄である。中間層が最も強いなど能力は深さに単調ではないため、固定の浅い層で一度だけ捨てる既存方式とは前提が違う。追加費用は事前の層別測定であり、推論時の追加計算はない。失敗条件はモデルや課題の分布が変わる場合で、枝刈り層はモデル固有に決め直す必要がある。除去実験では、この層選択だけで位置特定の正解率が42.6から64.5へ大きく改善し、構成要素の中で最も効いた。

| 構成要素 | 入力・観測 | 具体的な動作 | 改善対象 | 主なトレードオフ |
|---|---|---|---|---|
| バイパス | 枝刈り層での注意順位 | 落選トークンを保持し次層で再評価 | 誤判定の不可逆な情報損失 | 保持メモリと再評価の計算が増える |
| 統合と位置合わせ | 特徴の類似度と代表の隠れ状態変化 | 統合代表を本流へ参加させ、変化量を落選分へ加える | 迂回中の表現の古さ | グループが粗いと位置合わせが崩れる |
| 枝刈り層の選択 | 層ごとの選択能力の実測 | 単調増加の制約で動的計画法により層列を固定 | 弱い層での誤った枝刈り | モデルごとに測り直しが必要 |

### 4. 1回の入力処理の流れ

画像は視覚トークン列になり、最初の枝刈り層までは全トークンが進む。そこで上位が本流へ残り、下位は統合代表を作って本流へ大まかな情報を渡しつつ、自身は迂回経路へ入る。中間層では本流のトークンと統合代表だけが計算される。次の枝刈り層で迂回トークンは代表の変化量で補正され、本流のトークンと一緒に再順位付けされる。復帰したトークンは残りの層を通常どおり進み、最終的にテキストの生成へ使われる。近似の区別として、本方式は情報を圧縮する近似であり無損失ではない。ただし除外の確定を強い層の再評価後へ遅らせるため、近似の誤り方は捨てる方式より穏やかである。

## 評価

結論は三点である。第1に、バイパスは細粒度の位置特定課題での崩壊を防ぎ、捨てる・統合する方式を大きく上回った。第2に、全体像の把握で済む非位置特定の課題では方式間の差は小さく、本方式も無枝刈りに近い水準を保った。第3に、効率は演算量で約2.4倍の削減、実測でも入力処理が約1.8倍速くなり、最も速い単回枝刈りの方式とほぼ同等だった。評価は実機測定と演算量計算の併用である。

### 感度・スケーリング・ストレス条件

トークン予算を128個まで絞ると全方式が悪化するが、本方式の相対的な優位はむしろ広がった。位置合わせの分析では、グループ数を増やして細かく分けるほど統合代表の変化と実際の平均変化の一致が保たれた。テキストを読む課題TextVQAでは、OCR用の指示文を除いた条件で評価されており、指示文ありの場合の結果は論文では報告がなく未評価である。

### 評価上の制約

- 対象モデルはLLaVA系の2種のみで、他の視覚言語モデルへの一般化は限定的である。
- 消費メモリの実測や、生成段階（デコード）の遅延への影響は論文では詳しく報告がなく未評価である。
- 枝刈り層はモデルごとに事前測定して固定する前提であり、未知モデルへの即時適用はできない。

全体として、本方式の価値は倍率そのものよりも、枝刈りの判断を「捨てるか残すか」から「いつ確定させるか」へ捉え直し、確定を強い層の再評価後へ遅らせた点にある。

## 既存研究との差

FastVは浅い層で一度捨て、PDropやSparseVLM、FEATHERは段階的に捨てるが、いずれも落選した時点で情報は戻らない。VisionZipなどの統合方式は情報を混ぜて残すが細部が薄まる。本論文は、落選トークンを元の形で保持する迂回と、統合代表による大まかな伝達と、代表の変化を使った表現位置合わせを組み合わせ、各枝刈り層が独立に再判定できるようにした点が異なる。また枝刈り層の決め方も、経験的な固定層ではなく、層ごとの選択能力の実測と単調性の制約に基づく点が新しい。

## 限界・実装状況

読み手の注意点として、枝刈り層の選択はモデル固有の事前測定を要し、測定に使う課題の選び方で層の列が変わり得る。また、迂回トークンの保持はメモリを使うため、画像を多数同時に処理する条件では保持量の管理が必要になる。論文は学習不要で追加の学習費用がないことを利点とする一方、対象はLLaVA系2モデルに限られる。公式コードの公開は一次資料では確認できなかった。位置情報の扱いについて、位置符号を更新しない方式では位置特定が崩れることが比較で示されており、実装では位置情報の保持が前提になる。

## 一般的な実装上の含意

不可逆な削減は、判定が最も不確かな早い段階で行うべきではない。落とした情報を安く保持し、強い判定ができる段階で再評価する設計は、視覚トークンに限らず文脈の削減一般へ応用できる。また、削減方式の評価は、情報の細部が要る課題と全体把握で済む課題を分けて行わないと、弱点を見落とす。層ごとの能力を実測して処理位置を決める進め方は、層の役割が深さに単調でないモデル全般で有効である。
