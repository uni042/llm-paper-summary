# MoH: Multi-Head Attention as Mixture-of-Head Attention

> 注意ヘッドを共有ヘッドとTop-Kルーティングヘッドに分け、トークンごとに必要なヘッドだけ使うMoH。LLaMA3-8Bで75%利用・14評価平均64.0%を達成。

## 概要

標準の多頭注意（Multi-Head Attention; MHA）は、入力トークンごとに全ての注意ヘッドを計算し、その出力を連結して出力射影へ渡す。しかし実際には、全ヘッドが全トークンに同程度重要ではない。既存のヘッド枝刈り研究は多数の冗長ヘッドを示してきたが、モデル全体で同じヘッドを固定的に削ると、入力によって必要なヘッドが変わる性質を利用できない。

MoH（Mixture-of-Head attention）は、MHAを「各ヘッド出力に対応する出力射影部分を足し合わせる形」へ書き換え、その各項にルーティング係数を掛ける。これにより注意ヘッドをMoEのエキスパートのように扱い、**トークンごとに必要なヘッドだけ計算する**。常に有効な共有ヘッド（shared heads）へ一般的な知識を持たせ、残りのルーティングヘッド（routed heads）はTop-Kで疎に選択する。

MoHはViT、DiT、LLMで評価され、全ヘッドの50〜90%だけを使いながら標準MHAと同等以上の精度を示す。既存のLLaMA3-8Bも継続学習でMoHへ変換でき、75%のヘッドを利用するMoH-LLaMA3-8Bは14ベンチマーク平均64.0%、元のLLaMA3-8Bより2.4ポイント高い結果を報告する。

## 問題設定

MHAの各ヘッドは異なる注意パターンを学習するが、入力ごとに見れば全ヘッドを毎回使う必要はない。固定枝刈りは平均的重要度の低いヘッドを削れる一方、ある入力では不要でも別の入力では必要なヘッドを区別できない。

単純に各トークンでTop-Kヘッドだけを選ぶ方式にも課題がある。MoEと同様、ルータが一部ヘッドへ偏ると他のヘッドが十分学習されず、また全てを動的ルーティングにすると文法や一般的な構造のように多くの入力で共通して必要な知識まで毎回競合させることになる。

そこでMoHは、常時使う共有ヘッドと入力依存で使うルーティングヘッドを明確に分け、さらに両群の寄与量までトークンごとに動かす。

## 手法

### 1. MHAをヘッド出力の加重和として再定式化する

標準MHAは各ヘッド出力を連結した後に出力行列を掛けるが、出力行列をヘッドごとのブロックへ分ければ、MHAは各ヘッド出力 (H_i) と対応する出力射影 (W_O^i) の和として表せる。

MoHはこの和へ係数 (g_i) を導入し、

[
mathrm{MoH}(X,X')=sum_{i=1}^{h} g_i H_i W_O^i
]

とする。選ばれないヘッドでは (g_i=0) なので、そのヘッド計算を省ける。標準MHAの「全ヘッドを同じように足す」構造から、トークンごとに異なる疎な重み付き和へ変わる。

### 2. 共有ヘッドは常時有効にする

全ヘッドをTop-K競争へ入れるのではなく、(h_s) 個を共有ヘッドとして必ず活性化する。著者らの意図は、複数文脈に共通する知識を共有ヘッドへ集め、ルーティングヘッドをより入力固有のパターンへ専念させることにある。

構成要素除去でも共有ヘッドは精度改善へ寄与した。共有ヘッド比率を極端にしなければ性能は比較的安定しており、評価では活性ヘッド中の共有ヘッド比率を広い範囲で変えても大きく崩れないことを確認している。

### 3. ルーティングヘッドをトークンごとのTop-Kで選ぶ

残りの (h-h_s) ヘッドについては、入力トークン (x_t) から射影 (W_r x_t) を計算し、スコア上位K個だけを有効にする。したがって同じ層でも、トークンAとトークンBが異なるヘッド集合を使える。

MoEで一部エキスパートへルーティングが集中する問題と同様の崩壊を避けるため、MoHはルーティングヘッドに負荷分散損失を加える。各ヘッドが選ばれた頻度と平均ルーティング確率を使い、少数ヘッドだけへトークンが集中することを抑える。

### 4. 二段階ルーティングで共有群とルーティング群の寄与も変える

MoHでは、共有ヘッド内部・ルーティングヘッド内部のスコアを決めるだけでなく、二つの群そのものの相対寄与も (alpha_1,alpha_2) で調整する。

[
[alpha_1,alpha_2]=mathrm{Softmax}(W_h x_t)
]

として、共有ヘッド側には (alpha_1)、Top-Kで選ばれたルーティングヘッド側には (alpha_2) を掛ける。これにより「このトークンでは共通知識側を強く使う」「別のトークンでは専門的なルーティングヘッド側を強く使う」という調整が可能になる。

この二段階ルーティングは、単なる0/1のヘッド選択ではなく、**どのヘッドを使うか**と**共有群／専門群をどの割合で使うか**を分離して学習する仕組みである。構成要素除去でも共有ヘッドと二段階ルーティングの双方が性能改善に寄与している。

### 5. 既存LLaMA3-8Bを継続学習でMoHへ変換する

MoHはゼロからの事前学習だけを前提にしない。既存LLaMA3-8Bの注意層をMoH化し、元の事前学習量の一部に相当する追加トークンで継続学習する実験を行っている。

学習初期には元モデルより性能が落ちるが、約10Bトークンで元性能の95%以上まで回復し、その後の継続学習で元モデルを上回る。これは、既存MHAモデルへ疎ヘッドルーティングを後付けできる可能性を示す。

## 評価

### 代表的な評価条件

| 項目 | 内容 |
|---|---|
| 対象アーキテクチャ | Vision Transformer、Diffusion Transformer、LLM |
| LLM基準 | LLaMA3-8B |
| MoH-LLaMA3-8B | 全注意ヘッドの75%を活性化 |
| LLM評価 | 14ベンチマーク |
| 継続学習 | 既存LLaMA3-8BからMoHへ変換して追加学習 |
| 構成要素除去 | 共有ヘッド、二段階ルーティング、共有ヘッド比率 |
| 比較 | 標準MHAおよび同系統モデル |

### 代表的な結果

| 条件 | 結果 | 読み取り |
|---|---:|---|
| MoH全般 | 50〜90%のヘッド利用でMHA同等以上 | 全トークンで全ヘッドを使う必要がない |
| MoH-LLaMA3-8B | 14評価平均64.0% | 75%のヘッドだけを利用 |
| 元LLaMA3-8Bとの差 | +2.4ポイント | 疎化しながら平均精度も改善 |
| 継続学習初期 | 約10Bトークンで元性能の95%以上へ回復 | 既存モデルからの変換が可能 |
| 共有ヘッド除去 | 性能低下 | 共通知識を常時使える経路が有効 |
| 二段階ルーティング除去 | 性能低下 | 群間の動的重み付けにも意味がある |

画像分類でもMoH-ViT-Bはヘッド利用率75%または50%でImageNet-1KのTop-1 84%台を維持し、標準的な高性能ViT系と競合する。したがってMoHの主張はLLM専用ではなく、注意ヘッド冗長性を異なるTransformer用途で利用できるというものになっている。

## 既存研究との差

固定的な注意ヘッド枝刈りは、学習後に一貫して重要度が低いヘッドを削る。MoHはヘッドを**入力トークンごとに動的選択**するため、平均的には不要なヘッドでも必要な入力では残せる。

一方、従来のMoEは主にFFNのエキスパートを疎に選択してモデル容量を増やす。MoHはFFNではなく注意ヘッド自体をエキスパートとみなし、パラメータ数を増やすことよりも既存ヘッドの条件付き実行へ焦点を当てる。また共有ヘッドを常時有効にすることで、全エキスパートを競争させる一般的なTop-K MoEとはルーティング構造も異なる。

## 限界・実装上の注意

論文の「75%のヘッドを利用」は、そのままエンドツーエンド推論時間が25%短くなることを意味しない。トークンごとに異なるヘッドを選ぶため、ルータ、Top-K、疎なヘッド実行を実機上で効率よくまとめるカーネルが必要になる。論文の中心評価はモデル品質と計算量削減であり、汎用LLMサービング基盤でのTTFT/TPOT短縮を直接保証するものではない。

また既存LLaMA3-8BをMoHへ変換するには継続学習が必要で、重みを置換するだけでは済まない。負荷分散損失、共有ヘッド比率、活性ヘッド数Kも学習・性能に影響するため、既存モデルへ導入する場合は追加学習予算と疎実行実装の両方が必要である。
