# You Only Sample (Almost) Once: Linear Cost Self-Attention Via Bernoulli Sampling

> ソフトマックス注意を、局所性鋭敏ハッシュの衝突によるベルヌーイサンプリングへ置き換え、系列長に比例する費用で長系列を学習できる注意機構YOSOを提案する。

## 概要

Transformerの自己注意は、各トークンが他の全トークンとの類似度を計算して重み付き和を取るため、系列長nに対して時間もメモリも二乗で増える。文が512トークン程度なら耐えられるが、数千トークンの文書や画素列を扱うと、注意行列そのものの生成と保持が学習の支配的な費用になる。効率化の先行研究は、注意を窓へ制限する、ランクを落とす、乱択特徴で近似するなど様々だが、局所性鋭敏ハッシュ（Locality Sensitive Hashing; LSH）で重要サンプリングを行う系譜は、標本同士の依存と再重み付けと重複除去のためにGPU上で素直に速くならないという問題を抱えていた。

本論文のYOSOは発想を変える。LSHを提案分布からのサンプリング道具として使わず、クエリとキーが同じバケットへ衝突する確率そのものを注意の依存度とみなす。衝突確率は類似度の関数として、ゼロ階・一階・二階の導関数がいずれも正であり、ソフトマックスの指数関数と定性的な形が一致する。各組は成功確率が衝突確率であるベルヌーイ変数として扱われ、1回のハッシュで全組の実現値を同時に決められる。衝突したキーの値だけを合計すれば注意出力の推定値が得られ、n行n列の行列を作る必要がない。

学習まで含めて成立させるため、逆伝播の推定も同じ枠組みで与える。値への勾配は転置したベルヌーイサンプリングで推定し、クエリへの勾配は類似度が1へ近づくと発散する項を下界で置き換えて安定させる。ハッシュ本数mを増やすほど推定は期待値へ近づき、精度と費用のつまみになる。

**代表結果:** BERT-base設定の事前学習では、期待値を直接使うYOSO-Eがマスク言語モデルのパープレキシティ4.54でソフトマックスの4.65をわずかに上回り、有限本でもハッシュ64本で4.79まで近づく。長系列ベンチマークのLRAでは、YOSO-32の平均正解率が58.32パーセントでソフトマックスの58.77パーセントとほぼ並び、深さ方向畳み込みを足したYOSO-C-16は59.87パーセントで比較した効率的注意の全てを上回った。費用は順伝播で系列長に比例する形へ落ち、長系列ほどメモリ節約が大きくなる。

## 問題設定

自己注意の二乗費用は二重に効く。計算量として全組の内積と重み付き和が必要なだけでなく、n行n列の注意行列をメモリへ保持し、逆伝播でもう一度使うため、長系列ではメモリが先に尽きる。推論だけなら近似の余地もあるが、学習では順伝播の近似に対応する勾配推定まで必要で、ここが多くの近似注意の弱点になる。

LSHによる重要サンプリングは一見自然だが、三つの依存が効率を壊す。第一に、バケットからキーを1つ選ぶ方式では、あるキーが選ばれる確率が同じバケット内の他のキーに依存する。第二に、提案分布とソフトマックスのずれを直す再重み付けがクエリごとに必要になる。第三に、重複を除くためのハッシュ表の保持と照合がGPUの単純な行列演算に乗らない。本論文の着眼点は、サンプリングの対象を「どのキーを1つ選ぶか」から「各キーが参加するか否か」へ変えれば、これらの依存が原理的に消えることである。

## 手法のあらまし

まず前提として、クエリとキーを単位長へそろえ、内積による類似度と角度による類似度を同じ土俵で扱えるようにする。次に、超平面ハッシュを複数連結したハッシュでクエリとキーをバケットへ振り分ける。同じバケットへ入った組だけが衝突として数えられ、そのキーの値が出力の合計へ加わる。これをm本のハッシュで繰り返して平均すると、衝突確率で重み付けした和の推定になる。mが無限大の極限がYOSO-Eであり、有限のmでは標本平均としての分散を持つ。逆伝播では、値への勾配を転置方向の同じサンプリングで推定し、クエリとキーへの勾配は衝突確率の導関数の下界を使った近似で計算する。ハッシュコードの計算自体が重くならないよう、近似ランダム射影で高速化する。

## 手法

### 1. 衝突確率を注意の重みとみなす — ベルヌーイサンプリングによる順伝播

この機構が観測するのは、単位長へそろえたクエリとキーと、ハッシュが決めるバケットの一致である。保持する状態は、各ハッシュについてのバケット割り当てであり、注意行列ではない。処理は、各クエリについて、衝突したキーの値をそのまま合計し、m本分を平均することである。成功確率が類似度で単調に増え、類似度が高い組ほど急峻に支配的になる性質が衝突確率にあるため、重み付けの再計算なしにソフトマックスに似た依存構造が得られる。これにより減るボトルネックは、全組の内積と行列の保持であり、順伝播の時間は系列長とハッシュ本数と次元に比例する形、メモリはバケット表の分だけになる。追加で消費する資源はハッシュ計算であり、射影を近似して抑える。失敗条件は分散である。ハッシュ本数が少ないと、衝突の実現値が期待から外れて出力がぶれ、特に類似度が中程度の組で誤差が残る。実験でもハッシュ16本では言語モデルのパープレキシティが5.14まで悪化し、本数を増やすほど期待値の挙動へ近づくことが確認されている。

### 2. 勾配のサンプリング推定 — 発散する項を下界へ置き換える

この機構が観測するのは、損失から戻ってくる出力側の勾配と、順伝播で使った衝突の構造である。保持する状態は順伝播と同じバケット割り当てであり、処理は三方向に分かれる。値への勾配は、キーとクエリの役割を入れ替えたベルヌーイサンプリングで推定する。クエリとキーへの勾配は衝突確率の導関数を含む形になるが、そのままでは類似度が1へ近づくとき分母が消えて発散する。そこで本論文は導関数の下界を使った推定へ置き換え、発散を避けながら同じサンプリングで計算できる形にする。この置き換え版で学習したモデルが本文のYOSOであり、元の導関数に近い推定を使う変種は星印付きで区別され、わずかに精度が良い代わりに扱いが難しい。追加費用として、クエリ側の勾配推定は次元方向の繰り返しを含むため逆伝播の時間は次元の二乗を含む形になるが、ハッシュ表の再利用でメモリ側の二乗項は消せることが示される。近似をさらに進めて次元にも比例させる方式も付録に用意される。誤った場合の挙動として、勾配推定の分散が学習の不安定さへ直結するため、本数と推定方式の選択が収束を左右する。

### 3. ハッシュ本数という調整つまみ — 検証時の期待値近似

この機構が観測するのは、学習時と検証時で許せる分散の違いである。保持する状態は学習済みモデルの重みだけであり、処理は、検証時に使うハッシュ本数を学習時より増やして期待値へ近づけることである。確率的なモデルであるため、推論を決定的にするには期待値を取るのが理想だが、期待値の直接計算は二乗費用へ戻ってしまう。そこで有限本の標本平均で近似し、本数を増やすほど検証の損失が下がることが実験で確かめられている。これにより、学習は安い本数で回し、評価だけ本数を増やすという非対称な使い方が可能になる。トレードオフは明確で、本数を増やせば費用は比例して増えるため、求める精度に応じて止めどころを決める必要がある。

| 構成要素 | 入力・観測 | 具体的な動作 | 改善対象 | 主なトレードオフ |
|---|---|---|---|---|
| ベルヌーイ注意 | クエリとキーのバケット一致 | 衝突したキーの値を合計し本数で平均 | 二乗の時間とメモリ | 本数が少ないと分散が出る |
| 勾配推定 | 出力側勾配と衝突構造 | 転置サンプリングと導関数の下界で推定 | 学習全体の成立 | 推定分散が収束へ効く |
| 本数調整 | 許容できる分散 | 検証時だけ本数を増やし期待値へ寄せる | 評価精度 | 費用は本数に比例 |

## 評価

結論は、衝突確率ベースの注意はソフトマックス注意の実用的な置き換えになり得て、長系列でも精度を大きく落とさずに線形費用で学習できる、というものである。BERT-baseの事前学習では、ソフトマックスのマスク言語モデルパープレキシティ4.65に対し、YOSO-Eは4.54、YOSO-64は4.79、YOSO-32は4.89、YOSO-16は5.14と、本数に対する単調な改善が見える。文順序予測の正解率も94.2パーセント前後で並ぶ。読み方として、この単調性は方式の正しさを裏付ける一方、安い設定では明確な精度税が残ることも示している。下流のGLUEでは、YOSO-64がSST-2で91.5パーセント、MNLIで81.6パーセントなど、ソフトマックスの91.1パーセントや82.4パーセントに近い水準を保つ。

長系列のLRAでは傾向が変わる。平均正解率はソフトマックス58.77パーセント、YOSO-E 59.17パーセント、YOSO-32 58.32パーセントで互角であり、深さ方向畳み込みを足したYOSO-C-16は59.87パーセントで、Nyströmformerの58.95パーセントやLongformerの58.97パーセントを含む全比較対象を上回る。特に画素レベルの画像課題では44から46パーセント台と他方式より高く、局所構造を拾う畳み込みとの相性が良い。効率の実測は6層の小モデルとランダム入力で、系列長を伸ばすほど実行時間とピークメモリの差が開く形が示される。未評価の点として、大規模言語モデルの生成推論への適用や、現在の高速注意カーネルとの実測比較は論文の範囲外である。近似誤差が系列長に対してほぼ平らに保たれることも別途確認されている。

## 既存研究との差

Reformer系のLSH重要サンプリングとの差は、LSHを標本抽出の道具ではなく重みそのものの定義へ使った点にある。これにより再重み付けと重複除去と標本間依存が消え、GPU向きの単純な集計になる。Longformerの窓注意との差は、遠距離の依存も衝突確率を通じて残せる点であり、Linformerの低ランク射影との差は、系列の内容に応じて参加するキーが変わる適応性である。Performerの乱択特徴近似とは、近似対象がカーネルではなく衝突確率である点で異なる。

## 限界・実装状況

限界は、有限本では推定分散による精度税が残ること、勾配推定が近似であり方式の選択で精度が揺れること、評価がBERT級の符号化モデル中心で生成モデルのデコードへの適用が示されていないこと、ハッシュ計算の高速化に近似射影の工夫が要ることである。実装状況は公式コードが公開され、前提とした単位長化は実験では単純なL2正規化で代替されている。近似注意であるため、品質が厳密に要求される用途では本数と検証手順の設計が前提になる。

## 一般的な実装上の含意

近似機構を学習系へ入れるときは、順伝播の近似だけでなく、それと整合する勾配推定と、その数値的な発散点の処理までを一組で設計する必要がある。また、確率的な機構は学習時と評価時でサンプリング量を変えられる非対称性を持ち、評価だけ期待値へ寄せる運用は他の確率的近似にも応用できる。依存関係のあるサンプリングを、独立な参加判定へ置き換えると並列化しやすくなるという設計原則も読み取れる。
