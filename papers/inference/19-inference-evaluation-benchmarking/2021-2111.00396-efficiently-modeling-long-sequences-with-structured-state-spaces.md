# Efficiently Modeling Long Sequences with Structured State Spaces

## 概要

構造化状態空間系列モデル（Structured State Space Sequence Model; S4）は、長い系列を扱う状態空間モデル（State Space Model; SSM）の理論上の利点を、実際に学習できる計算量とメモリ量で実現するためのモデルである。自己注意（self-attention）は系列長Lに対して二次の注意行列を作るため、1万〜数万ステップの系列では計算・メモリ負荷が大きくなる。状態空間モデルは固定次元の状態を更新しながら過去情報を要約できるが、長期記憶に有効な特殊な状態行列をそのまま使うと、行列のべき乗と逆行列計算が高価かつ数値的に不安定になる。

S4の中心は、HiPPO理論から得られる長期記憶向けの状態行列を、正規行列と低ランク補正の和（Normal Plus Low-Rank; NPLR）として表現することにある。正規部分は条件の良いユニタリ変換で対角化でき、低ランク部分はウッドベリー恒等式（Woodbury identity）で補正できる。さらに畳み込み核を直接列挙する代わりに、生成関数を周波数領域で評価してコーシー核（Cauchy kernel）の計算へ帰着させる。これにより長い畳み込み核をほぼ線形の計算量とメモリで生成できる。

学習時には状態空間層を畳み込みとして並列処理し、逐次推論時には固定次元の状態を再帰的に更新する。同じモデルが長系列の並列学習と低メモリの逐次生成の両方に対応する。論文はLong Range Arena（LRA）の全課題で当時の最良水準を更新し、長さ16,384のPath-Xで88%正解率を達成した。先行方式がほぼランダム推測の50%に留まった課題で長期依存を扱えることを示す。また系列化CIFAR-10で約91%の精度、音声分類で約1.7%の誤り率、画像・言語の自己回帰生成で従来方式比最大60倍の生成高速化を報告する。

## 問題設定

長系列モデリングでは、遠く離れた時刻間の依存を保持しながら、訓練をGPUで並列化し、推論時には過去の系列を再処理せずに次の出力を得る必要がある。Transformerは内容に基づく任意位置参照が得意だが、密な自己注意は系列長Lに対してO(L²)の注意行列を扱う。再帰型ニューラルネットワークは一定サイズの状態で逐次推論できるものの、学習時の系列方向並列化が難しく、長距離の勾配伝播にも課題がある。

連続時間の状態空間モデルは `x'(t)=Ax(t)+Bu(t)`、`y(t)=Cx(t)+Du(t)` で入力uを潜在状態xへ蓄積し、出力yを生成する。状態行列Aを適切に選べば長期記憶が可能になる。HiPPO理論は過去の入力を直交多項式基底で要約するための特殊なAを与え、先行する線形状態空間層（Linear State Space Layer; LSSL）はその有効性を示した。

しかしHiPPO行列は線形代数の意味で非正規（non-normal）であり、一般の対角化を直接使うと基底変換行列の要素が状態次元Nに対して指数的に大きくなる。数値誤差が増幅し、実際の浮動小数点演算では安定に計算できない。対角化せずに畳み込み核を素朴に作ると、系列長Lと状態次元Nに対してO(N²L)演算、O(NL)メモリが必要となり、状態空間層の理論的な効率が失われる。

S4は、長期記憶に適した状態行列の構造を壊さず、数値的に安定な表現へ変換して、学習用の畳み込み核と推論用の再帰更新を高速に実装する問題を解く。目的は自己注意の疎化ではなく、注意とは異なる系列演算を実用的な代替として成立させることである。

## 手法

### 連続時間から離散時間への変換

連続時間のSSMは状態行列A、入力行列B、出力行列C、直接結合Dで定義する。離散系列に適用するため、刻み幅Δを使う双線形変換（bilinear transform）で連続系を離散化する。離散状態行列は `Ā=(I-ΔA/2)^{-1}(I+ΔA/2)`、入力行列は `B̄=(I-ΔA/2)^{-1}ΔB` と表せる。離散状態は `x_k=Āx_{k-1}+B̄u_k`、出力は `y_k=Cx_k+Du_k` で計算する。

この再帰形式では、新しい入力を受け取るたび固定次元の状態を更新すればよい。過去全トークンの鍵値キャッシュ（KVキャッシュ）を保持して再読出しする自己注意とは異なり、履歴は状態ベクトルへ集約される。一方、学習で系列の全時刻をこの再帰だけで処理すると時間方向に逐次依存が生じ、GPUでの並列性が低い。

### 畳み込み表現への変換

初期状態をゼロとすると、再帰式を展開した出力は入力系列と畳み込み核Kの積になる。核は `K=(CB̄, CĀB̄, CĀ²B̄, …, CĀ^{L-1}B̄)` であり、`y=K*u` と書ける。Kが求まれば高速フーリエ変換（FFT）を用いて系列方向を並列化できる。これにより学習時には畳み込み、逐次推論時には再帰という二つの計算形態を同じパラメータから選べる。

問題はKの生成である。一般の密なĀをL回掛けるとO(N²L)の計算が必要になり、核の生成だけで学習の利点を失う。S4はKの各項を直接作る代わりに、有限長の生成関数 `Σ_{j=0}^{L-1}K_j z^j` を複素数の単位根で評価し、逆FFTで核を復元する。生成関数は行列の逆行列を含む有理関数へ変形できるため、Aの構造を利用した高速計算が可能になる。

### HiPPO行列のNPLR表現

HiPPO由来の状態行列はそのままでは非正規で安定に対角化できないが、正規行列と階数1または2の低ランク補正の和として表せる。具体的には `A=VΛV*−PQ*` の形を用い、Vはユニタリ行列、Λは対角行列、P/Qは少数列の低ランク因子である。ユニタリ変換は条件数が良く、変換による数値誤差の増幅を避けられる。HiPPO-LegS、LegT、LagTなどがこの構造を持つことを示す。

この表現では状態の基底を変えても入出力の線形作用素は同じである。Aを対角成分と低ランク補正に分けた後、生成関数中の逆行列をウッドベリー恒等式で計算すると、主要部分は対角行列の逆数と少数の低ランク行列演算へ還元できる。一般の密行列の逆行列を系列長ごとに繰り返し求める必要がなくなる。

### コーシー核による高速生成

生成関数を単位根上で評価すると、対角固有値と評価点の差の逆数 `1/(ω_j−λ_k)` に基づくコーシー核の計算が現れる。S4はこの既知の数値計算問題へ帰着させ、コーシー行列の高速乗算を利用する。論文のアルゴリズム1では、有限長に切った生成関数の係数を補正し、複数のコーシー核積から低ランク補正を計算し、最後に逆FFTで長さLの畳み込み核を復元する。

この構造により、核生成は対数因子を除いてO(N+L)の演算とO(N+L)のメモリへ近づく。再帰形式の1ステップ更新もO(N)で実行できる。これはすべての実装が自動的に線形時間になるという意味ではなく、コーシー核の高速・安定な計算とFFTの実装品質が必要である。論文は専用カーネルを利用して実測でも先行LSSLより大幅に高速・省メモリであることを確認する。

### 深いS4層の構成

一つのS4は1次元入力系列を1次元出力系列へ変換する線形演算である。実際の深いネットワークでは隠れ幅Hの各特徴に独立したSSMを置き、位置ごとの線形層で特徴間を混合する。さらに非線形活性化、正規化、残差接続を加え、複数層を積み重ねる。状態空間核そのものは線形でも、層間に非線形変換があるため全体のネットワークは非線形になる。

各特徴の状態行列はNPLRパラメータで保持され、層の学習時には畳み込み核を作って全時刻を並列計算する。推論時には状態を更新するため、生成済み系列の全注意行列を持たずに済む。これは注意ベースのTransformerとは異なる長期記憶の帰納バイアスを持つが、内容に基づいて任意の過去トークンを直接検索する仕組みではない。

## 主要結果

### 長距離依存課題

Long Range Arenaの全課題で当時の最良水準を更新し、効率的注意を含む比較方式に対して平均20ポイント以上の改善を報告する。特にPath-Xは長さ16,384の系列から経路情報を追跡する難しい課題で、従来方式はほぼランダム推測の50%に留まっていたが、S4は88%の精度を達成した。長い系列を低コストで処理するだけでなく、遠く離れた位置間の依存を実際に保持できることを示す。

系列化CIFAR-10では、二次元画像の空間構造を明示的に使わず、画素を長い一次元系列として入力して約91%の正解率を得る。追加のデータ拡張や補助損失を使わず、より大きい二次元ResNetに近い性能を示す。これは状態空間層が自然言語だけに特化した仕組みではないことを示す。

### 音声・言語・生成

長さ16,000程度の生音声系列の分類では約1.7%の誤り率を報告し、専門的な音声畳み込みモデルの誤り率を約半分へ下げた。同条件の一部RNNやTransformerの基準方式は70%以上の誤り率となり、長距離依存を学習できなかった。画像生成の密度推定ではCIFAR-10で2.85 bits/dimを報告し、WikiText-103の言語モデルでは当時の注意を使わない方式として高い品質を示す。

自己回帰生成では、固定次元状態を更新する再帰形式を使うことで、CIFAR-10やWikiText-103の実験で従来の自己回帰方式に対して最大60倍の生成高速化を報告する。これは特定の実験条件の結果であり、現代のGPU上で動く数十億パラメータLLMのトークン毎秒を60倍改善するという意味ではない。

### 計算・メモリの改善

素朴なLSSLの核生成はO(N²L)演算、O(NL)メモリを必要とする。S4はNPLR表現とコーシー核計算によって、対数因子を除きO(N+L)演算・O(N+L)メモリへ近づける。論文はLSSLに対し最大30倍の高速化、400倍のメモリ削減を報告する。再帰更新は状態次元Nに対してO(N)であるため、長さLの過去系列を保持する注意キャッシュと異なるメモリ増大特性を持つ。

| 観点 | 代表的な結果 | 意味 |
|---|---|---|
| Path-X、長さ16,384 | 正解率88% | 従来方式が難しかった長距離依存を学習 |
| 系列化CIFAR-10 | 約91% | 画像を一次元系列にしても高精度 |
| 生音声分類 | 誤り率約1.7% | 長い音声系列で高精度 |
| CIFAR-10生成 | 2.85 bits/dim | 生成モデルとしても競争力を示す |
| 自己回帰生成 | 最大60倍高速 | 固定次元の再帰状態による利得 |
| LSSLとの計算比較 | 最大30倍高速、400倍省メモリ | 構造化核生成の効果 |

## 既存研究との差

効率的Transformerは密な注意行列を疎化・近似して二次計算量を下げる。一方S4は注意行列そのものを作らず、状態空間モデルの連続時間・再帰・畳み込みという三つの表現を行き来する。したがって、注意の近似誤差を減らす研究ではなく、長期記憶を持つ別の系列演算を実用化する研究である。

先行LSSLもHiPPO状態行列を使って長期依存を保持するが、核生成が高価で数値的に不安定だった。S4はHiPPO行列のNPLR構造を利用し、条件の良い対角化、低ランク補正、コーシー核の高速計算を組み合わせることで、同じ理論的な記憶特性を実用的な計算へ変換する。この構造化パラメータ化が主要な新規性である。

通常のRNNは固定次元状態で逐次推論できるが、学習時に系列方向の依存が残る。S4は線形状態空間演算を畳み込みへ変換して学習を並列化し、推論では再帰へ戻す。二つの実行形態を同じ学習済みパラメータから得られる点が、RNNと畳み込みの利点を統合する。

## 限界

第一に、状態空間モデルは履歴を固定次元の状態へ要約するため、内容に応じて任意の過去トークンを直接検索する自己注意とは異なる帰納バイアスを持つ。長距離依存課題で高精度でも、知識検索や正確な文字列コピーなど、入力中の特定位置へ動的にアクセスする能力を自動的に保証しない。

第二に、論文の主評価はLong Range Arena、画像、音声、言語モデリングであり、現代的な大規模対話LLMの推論サービングを直接評価したものではない。初回トークン時間、連続バッチ処理、複数GPU通信、長文脈の質問応答品質などへ速度倍率を外挿することはできない。

第三に、NPLR表現とコーシー核計算は数値的な工夫を必要とする。理論上のほぼ線形計算量を実際の高速化へ変えるには、複素数演算、FFT、専用コーシー核の実装が重要であり、一般的な深層学習フレームワークの素朴な密行列演算だけでは同じ利得が出ない可能性がある。

第四に、モデルの学習設定と構造は課題ごとに調整されている。画像、音声、言語、時系列のすべてで単一の固定構成が最高性能だったわけではない。Long Range Arenaの平均性能も、個々のタスクの難易度や評価規約に依存するため、別の長文脈ベンチマークで同じ改善幅を保証しない。

第五に、固定次元状態は長さに対して有利だが、状態次元Nを増やすと演算・パラメータ量は増える。非常に複雑な依存を扱うために状態次元を大きくした場合の品質・速度交換条件は、対象タスクと実装に応じて測定する必要がある。
