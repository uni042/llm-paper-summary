# NASiC: 3D NAND-based CAM-Selected Multibit CIM Architecture for Efficient On-Device Mixture-of-Experts LLM Inference

> 三次元NAND内部で専門家番号の照合と選択専門家の計算を一体化し、多値記憶とブロック並列化によって専門家混合モデルを高密度に直接実行する。
## 書誌情報
- **著者**: Weikai Xu, Meng Li, Shuzhang Zhong, Tianyang Luo, Dongxue Zhao, Ling Liang, Zongwei Wang, Qianqian Huang, Yimao Cai, Ru Huang
- **著者・所属**: Peking University; Beijing Advanced Innovation Center for Integrated Circuits
- **公開**: arXiv:2605.23294v1
- **種別**: プレプリント
- **対象**: 専門家混合、三次元NAND、計算内メモリ、内容アドレスメモリ、端末内推論、多値フラッシュ
- **実装**: 提案は回路・システム設計であり、65ナノメートルの浮遊ゲート素子モデルを用いたSPICE回路シミュレーションとシステム解析で検証する。公開ソフトウェア、公開RTL、製造済み試作チップは本文から確認できない。
## 概要
NASiCは、専門家混合（Mixture-of-エキスパート; MoE）モデルを端末内へ置く際に、全専門家の重みを保存する巨大容量と、毎回ごく一部だけを使う疎な計算を同時に扱う三次元NAND型の計算内メモリ（computing-in-メモリ; CIM）である。従来の三次元NAND計算内メモリは密な行列積を前提とするため、同じページに並ぶ未選択専門家まで計算して電力と並列性を浪費する。NASiCは同じNAND文字列の上部を内容アドレスメモリ（content-addressable メモリ; CAM）、下部を計算領域として使い、経路選択器が指定した専門家番号に一致した文字列だけを導通させる。さらに、ブロック単位の並列計算、符号付き多値入力、複数しきい値状態を使う多値記憶セルを組み合わせ、高密度保存と疎な専門家計算を一体化する。回路シミュレーションとシステム解析では、比較対象に対して最大114.8倍の処理性能改善と最大70倍のエネルギー効率改善を報告する。

中心的な新規性は、同じ三次元NAND文字列の上部へ内容アドレスメモリを置き、下部へ専門家重みの計算領域を置くことで、専門家番号の照合と選択専門家の積和演算を一つの計算周期へ融合した点にある。専門家を交互配置しても照合結果が物理的な導通マスクとして働くため、未選択専門家を計算せず高い保存利用率を保てる。これに加え、複数選択線を同時に動かすブロック単位符号化、ソース線電圧を使う符号付き多値入力、複数しきい値状態を使う多値計算セルを共同設計し、構造・回路・記憶セルの三層で疎な専門家混合とNANDの不整合を解消する。

代表結果として、専門家照合だけの処理性能改善は細粒度の専門家交互配置、電流ばらつきを変化で従来三次元NAND計算内メモリに対して4–16倍。未選択専門家の冗長演算を照合段階で遮断し、入力次元制約下でも有効な計算並列性を維持する。
## 問題設定
専門家混合モデルは各トークンで少数の専門家だけを動かすため演算量を抑えられるが、端末内推論では全専門家の重みを保存する容量が必要になる。三次元NANDは大容量だが、従来の計算内メモリは密な行列ベクトル積向けで、横長のページに複数専門家を並べて同じ入力を配る。そのため上位k個だけを選ぶ疎な専門家混合でも未選択専門家まで通電・計算される。さらにNANDブロック構造は同時に選べるページ数を制限し、多値入力も時間方向へ逐次展開するため実効並列性が低い。従来設計が二値記憶セル中心であることも、三次元NAND本来の多値保存能力を生かせない原因になる。
## 新規性
中心的な新規性は、同じ三次元NAND文字列の上部へ内容アドレスメモリを置き、下部へ専門家重みの計算領域を置くことで、専門家番号の照合と選択専門家の積和演算を一つの計算周期へ融合した点にある。専門家を交互配置しても照合結果が物理的な導通マスクとして働くため、未選択専門家を計算せず高い保存利用率を保てる。これに加え、複数選択線を同時に動かすブロック単位符号化、ソース線電圧を使う符号付き多値入力、複数しきい値状態を使う多値計算セルを共同設計し、構造・回路・記憶セルの三層で疎な専門家混合とNANDの不整合を解消する。
## 手法
### 手法のあらまし
処理の入口は専門家混合層の経路選択器である。経路選択器が各トークンについて選んだ専門家番号を出すと、その番号をNAND平面の全ブロックへ問い合わせ信号として送る。事前配置では、各専門家の識別番号をNAND文字列上部の照合セルへ、対応する重みを下部の計算セルへ格納し、複数専門家の断片をページ方向へ交互配置しておく。問い合わせ番号と一致した文字列だけが導通するため、その文字列に属する選択専門家の重みだけが入力との積和演算へ参加し、未選択専門家は同じページに存在しても電流経路から外れる。照合セル自体も多値フラッシュのしきい値状態を利用するので、少ない物理層で複数ビットの専門家番号を保持できる。選択後の計算では、一つのブロック内にある複数の文字列選択線を同時に有効化し、複数セルのしきい値状態の個数を重みの大きさとして読む修正温度計符号を使う。正負の重みは相補的な二ブロックへ分け、ソース線電圧を複数段階に変えることで符号付き多値入力をその場で表現し、従来のビット逐次入力を避ける。さらに二状態だけでなく三状態、四状態以上のフラッシュセルへ重みを格納し、選択ワード線へ複数の読み出し電圧を与えて得たビット線電流を加算し、多値の積和結果を作る。最後にビット線電流を検出し、アナログ・デジタル変換器で量子化して選択専門家の出力を得て、専門家混合層の後段へ返す。読み出し段階が増えると追加遅延は生じるが、三次元NANDでは配線の事前充電時間が大きいため、状態数増加に対する総遅延の増加は演算数の増加より緩やかである。この一連の流れにより、専門家の保存、番号照合、疎な選択、積和演算、出力検出までをNAND内部で連続処理し、上位メモリへ専門家重みを移す経路を必要としない。

### 照合選択付き計算内メモリ
各NAND文字列の上部に専門家番号を保持する照合セル、下部に専門家重みを保持する計算セルを配置する。経路選択器から送られた番号と一致した文字列だけが導通するため、照合結果がそのまま積和演算の有効化信号になる。従来方式では同じページに置かれた未選択専門家まで入力が届き、疎な専門家混合でも密な計算を実行していた。NASiCでは未選択文字列を物理的に遮断するため、この無駄を計算開始前に除ける。さらに専門家断片を交互配置しても照合回路が干渉を防ぐので、空き領域を大量に残す必要がなく、保存利用率と計算並列性を同時に確保できる。専門家数が増えた場合は多値照合セルまたは複数照合層を直列に使い、識別番号の幅を拡張する。

### ブロック単位の並列計算と符号付き入力展開
従来の三次元NAND計算では一つのブロックから一つのページを選ぶため、同じブロックに複数の選択線があっても演算資源を同時利用できない。提案方式は複数選択線を同時に有効化し、各セルのしきい値状態の個数を重みの大きさとして読む修正温度計符号を採用する。正の重みと負の重みは相補的に設定した二つのブロックで表現し、入力側はソース線電圧を複数段階に変えることで符号と大きさを同一計算周期内へ埋め込む。これによりビットごとに時間分割して入力を与える従来方式を避けられる。単独でこの回路最適化を従来構造へ入れても入力側の並列性制約が残るため効果は小さいが、前段の専門家照合機構と組み合わせることで、選択済み専門家へ十分な入力並列性を与え、実効処理量の増加へ結び付ける。

### 多値NAND計算セル
従来の計算内メモリが単一レベルセルだけを使うと、三次元NANDが持つ多値保存能力を捨てることになり、全専門家重みを端末内へ置くという目的に反する。NASiCは三状態、四状態、さらに一般の多状態セルへ修正温度計符号を拡張し、一つの物理セルがより多くの重み状態を保持できるようにする。計算時には選択ワード線へ複数の読み出し電圧を順に与え、それぞれのビット線電流を合計して最終積を得る。読み出し段階が増えるため遅延と変換器消費電力は増えるが、NAND配線の固定的な事前充電遅延が大きいので、総遅延は演算能力ほど急には増えない。したがって保存密度と処理量を同時に伸ばせる一方、状態数を増やしすぎると後段のアナログ・デジタル変換器の負担が支配的になる。

### 全体のデータ／制御の流れ
経路選択器が出した専門家番号をNAND平面へ送り、文字列内の照合、選択された重みの積和演算、ビット線電流の検出と量子化へ連続して接続するフラッシュ内加速器である。専門家重みを上位メモリへ移してから計算するのではなく、高密度NANDへ常駐させたまま選択と演算を行う。
## 評価条件
- **ハードウェア**: 典型的な三次元NAND平面をモデル化し、浮遊ゲートトランジスタには65ナノメートル技術のVerilog-A小信号モデルを使う。配線や構造の寄生要素は既存文献から導入する。回路段階はSPICEで評価し、システム段階では素子ばらつきを含めて処理性能、エネルギー効率、面積効率を算出する。比較対象にはNVIDIA A100、Cambricon-LLM、AiF、従来三次元NAND計算内メモリを含む。NASiC自身は製造済み実チップではない。
- **ソフトウェア**: 評価の中心は回路シミュレーションとシステム解析である。専門家の活性化率、フラッシュ電流ばらつき、記憶セルの状態数を変え、専門家照合、ブロック並列化、多値計算セルの三技法を順に追加する除去実験を行う。公開実装は本文から確認できない。
まずフラッシュ電流ばらつきの標準偏差が専門家混合モデルのパープレキシティへ与える影響を調べ、精度を保てる入力次元を決める。主要評価では文献の実験値に基づく標準偏差0.15、入力次元128を使う。処理性能は三技法を順次追加して従来方式との差を測り、専門家活性化率と多値セルの状態数を変える。エネルギー評価では8ビット逐次比較型変換器を含むNAND配列と変換器の消費内訳を測る。面積効率と面積・エネルギー・遅延積も算出し、最後にGPU、近接NAND処理方式、従来NAND計算方式と比較する。
実機のSSDや製造済みPIMチップを用いた評価ではなく、回路・システムモデルによる評価である。専門家層の行列ベクトル積を主対象とし、注意計算、経路選択器そのものの計算時間、トークン到着処理、ホスト側スケジューラ、SSD入出力、耐久性や誤り訂正を含む完全な端末内推論時間は直接測定していない。
## 主要結果
専門家照合機構だけでも、素子ばらつきによって入力次元が制限される条件で従来方式より4〜16倍の処理性能を得る。さらにブロック単位並列化と多値計算セルを加えると、最終構成はNVIDIA A100、Cambricon-LLM、AiF、従来NAND計算方式に対して、それぞれ最大85倍、93.4倍、114.8倍、68倍の処理性能改善を報告する。未選択専門家の計算を最初に消すため、疎性が高いほど並列化の効果を実演算へ変換しやすい。

- 専門家照合だけの処理性能改善 / 4–16倍 (比較対象: 従来三次元NAND計算内メモリ; 条件: 細粒度の専門家交互配置、電流ばらつきを変化) — 未選択専門家の冗長演算を照合段階で遮断し、入力次元制約下でも有効な計算並列性を維持する。

- 最終構成の処理性能改善 / 5–85倍 / 5.5–93.4倍 / 6.8–114.8倍 / 4–68倍 (比較対象: NVIDIA A100 / Cambricon-LLM / AiF / 従来NAND方式; 条件: 三つの提案技法を統合) — 専門家照合、ブロック並列化、多値記憶の効果が累積し、比較対象を上回るシミュレーション結果を示す。

- エネルギー効率改善 / 53–70倍 / 17.5–23倍 / 3.9–5.1倍 (比較対象: NVIDIA A100 / Cambricon-LLM / 従来NAND方式; 条件: NASiC最終構成) — 未選択専門家に対する配列の事前充電と計算を削減することが主要因である。

- 面積・エネルギー・遅延積の削減 / 3.5–8.3倍 (比較対象: 従来NAND方式; 条件: 専門家活性化率を変化) — 照合層の面積費用とブロック並列化の保存密度低下を含めても総合指標は改善する。

- 照合層の面積損失 / 0.05未満 (比較対象: 照合層なし; 条件: 専門家活性化率1/32、3ビット照合セル) — 多値照合セルで専門家番号を少数層へ圧縮すれば、高い疎性でも保存面積の損失を小さくできる。

### 負の結果・境界条件
- ブロック並列化は保存密度の一部を計算並列性へ振り向けるため、単独では面積効率が低下する。多値セルを3ビットへ増やすと処理性能は上がるが、アナログ・デジタル変換器のエネルギーと遅延が急増し、2ビット構成よりエネルギー効率が下がる。したがって状態数を増やすほど常に優れるわけではなく、速度重視と省電力重視の設計選択が必要になる。また数値はシミュレーション結果であり、製造チップでの実測値ではない。

### 結果の読み方
効果の根本は、専門家混合の疎性を上位ソフトウェアだけで処理せず、NAND文字列の導通経路へ専門家選択マスクとして直接埋め込むことにある。高密度保存と疎な計算を同じ物理構造で両立した後、NAND固有のブロック構造と多値しきい値を追加並列性へ転用している。
## 品質への影響
フラッシュ電流ばらつきによるパープレキシティ悪化を避けるため入力次元を制限した上で性能を測る。提案はモデル精度を改善する手法ではなく、精度条件を守りながら不要計算を減らすハードウェア設計である。
## 既存研究との差
一般的なSSDやNVMeへの専門家退避は、選択された重みをNANDから主記憶やGPUへ転送してから計算するため、大量のデータ移動が残る。NASiCは専門家をNANDへ常駐させ、その場所で番号照合と積和演算を行う。従来の三次元NAND計算内メモリやAiFは密な計算を主眼とするため、専門家混合の疎な選択では未選択領域の計算や並列性低下が起こる。NASiCは内容アドレス照合をNAND文字列へ融合し、経路選択結果を物理的な導通マスクへ変える点が異なる。専門家予測や先読みを行うソフトウェア方式とは競合せず、記憶装置内部の計算方式として補完できる。
## 限界
65ナノメートルの素子モデルと文献由来の寄生要素を用いた回路・システム評価であり、製造済み三次元NAND計算チップやSSDによる実測ではない。ホスト接続、制御器、書換え寿命、読出し・書込み妨害、温度、誤り訂正、専門家経路選択器、注意計算を含む端末全体の費用は評価範囲外である。多値セルは処理性能を伸ばす一方、変換器の消費電力と遅延を増やすため、記憶状態を増やせば無条件に有利になるわけではない。照合層も少量ながら保存領域を使い、ブロック並列化は保存密度と計算並列性の交換を伴う。
## 実装状態
arXiv v1として公開された回路・計算機構研究である。本文はSPICE回路シミュレーションとシステムモデルを用いるが、公開RTL、公開コンパイラ、公開実行環境、製造済みチップは確認できない。再現には論文記載の素子モデル、NAND構成、寄生要素、評価仮定を再構築する必要がある。
## 研究上の位置づけ
専門家混合推論とNAND・SSD活用の交点に位置し、専門家退避を速くするのではなく、専門家を保存場所から動かさずに選択・計算する方向を示す。階層メモリの観点では最下位のNAND層を能動的な計算層へ変える設計であり、上位層で行う専門家キャッシュ、配置、先読みとは補完関係にある。実用化を評価する次段階では、SSD制御器、耐久性、誤り訂正、ホスト側スケジューリング、注意計算との統合、実チップでの性能と電力を確認する必要がある。
