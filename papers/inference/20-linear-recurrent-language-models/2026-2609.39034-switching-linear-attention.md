# Switching Linear Attention — 文脈依存の想起を固定長状態で実現する切替型線形注意

## 概要

ソフトマックス注意（softmax attention）は過去の各トークンの鍵と値を保持し、現在の問い合わせとの類似度に応じて必要な値を取り出す。異なる文脈で同じ鍵が別の意味を持つような検索に強い反面、自己回帰生成の鍵・値キャッシュ（KV cache）は系列長に比例して増加する。これに対して線形注意（linear attention）は過去を固定寸法の行列状態へ集約するため、長い系列でも再帰状態の容量は増えない。しかし単一の線形写像では、問い合わせの文脈によって答えを切り替える非線形な想起を表現しにくい。

本論文の切替型線形注意（Switching Linear Attention; SwiLA）は、単一の線形回帰器を複数の線形回帰器の混合へ置き換える。各出力次元がそれぞれ混合成分を選択できるようにし、鍵・値対の到着ごとに予測誤差に応じた責任度を計算して回帰器の状態を更新する。さらに時間的持続性、入力依存の忘却ゲート、負荷分散損失を組み合わせる。系列長ではなく混合成分数と特徴次元に依存する固定長状態を保ちながら、文脈に応じた非線形な問い合わせ応答を実現する。

論文はソフトマックス注意の関数近似、文脈依存の連想想起、文脈内言語学習、374Mパラメータ言語モデルの品質、1.3Bモデルの学習・推論速度を検証した。1.3Bモデルの単一H100上の生成ではTransformer基準に対して全体スループットが4〜5倍になる一方、より単純なゲート付きDeltaNetより推論で1.25〜1.5倍遅く、学習では約2倍遅い。したがって「ソフトマックスの精度と線形注意の速度を同時に完全達成した」という結論ではなく、**記憶容量・想起性能・演算費用の新しい交換点**を示した研究と位置付ける。

## 問題設定と必要な背景

### 履歴全体の保存と固定状態への圧縮

通常の自己注意では、時刻 t の問い合わせ q_t と各時刻 i の鍵 k_i の内積から重みを計算し、対応する値 v_i を加重平均する。過去の鍵・値をそのまま保持するため、系列長 T に比例したキャッシュ容量を使う。長文脈生成での問題は注意計算だけでなく、トークンを生成するたびに過去のKVを読み出す帯域と、同時実行数を増やす際の容量制約にも現れる。

線形注意やDeltaNet系の再帰注意では、履歴を行列 W_t に圧縮する。例えばDeltaNetは、現在の鍵に対する予測 W_{t-1}k_t と実際の値 v_t の差を使って、W_t = W_{t-1} + β_t(v_t − W_{t-1}k_t)k_t^T と更新し、問い合わせに対して W_t q_t を返す。再帰状態は特徴次元 D に対して概ね O(D²) で、T が伸びても保存する過去トークン数は増えない。ただし、一つの W_t から取り出す値は q_t の線形関数であり、同じ鍵が話題や文脈によって別の値を指す場合に干渉が生じる。

### テスト時回帰という見方

テスト時回帰（test-time regression; TTR）は、鍵 k_i から値 v_i を予測する写像 m_t を、推論中に到着した系列から逐次推定する考え方である。記憶は m_t を更新する操作、想起は m_t(q_t) を評価する操作に対応する。DeltaNetなら写像の関数族は単一の線形回帰器、ソフトマックス注意なら過去の全サンプルを使う非パラメトリックなカーネル回帰と解釈できる。SwiLAはこの間に位置する**複数の線形回帰器からなる区分的な写像**を採用する。

この設計は、同じ容量を使うなら線形回帰器を単に別ヘッドへ増やすより、ヘッド内部に複数の文脈別回帰器を持たせる方が、複雑な問い合わせに有利ではないかという仮説に基づく。ただし混合成分を増やせば各成分の次元を削る必要があるため、容量を無制限に増やせるわけではない。

## 手法

### 1. 出力次元ごとの混合線形回帰器

SwiLAは各ヘッド内に J 個の回帰行列を保持する。入力トークンから鍵 k_t、値 v_t、問い合わせ q_t を射影し、各混合成分 j、出力次元 d に対して重みベクトル w_{t,j,d} を用意する。混合成分 j が次元 d の値を説明する確率の事前値を π_{j,d}(k_t) とし、観測された v_{t,d} が平均 w_{j,d}^T k_t の正規分布から発生したと仮定する。これは論文の式(3.1)であり、混合成分ごとに異なる鍵→値の対応を学習するための確率モデルとなる。

重要なのは、**混合成分をトークン単位で一つだけ選ぶのではなく、出力次元ごとに割り当てる**点である。D 個の出力次元それぞれに J 通りの選択肢があるので、組合せとしては J^D 種類の写像を表現できる。一方、保存する回帰重みは J×D×D、すなわち O(JD²) にとどまる。ただし J^D は独立に保存された専門家数でも計算量でもなく、次元ごとの選択が作り得る組合せ数を表す。

### 2. 予測誤差に応じたオンライン更新

新しい鍵・値対が到着すると、まず成分ごとの予測誤差 δ_{t,j,d} = v_{t,d} − w_{t−1,j,d}^T k_t を求める。次に、事前確率 π と誤差の二乗に基づく尤度を組み合わせて、責任度 r_{t,j,d} を正規化する。概念的には r は「この観測を成分 j がどの程度説明したか」を表し、誤差が小さく事前確率が高い成分に大きな重みを与える。論文の式(3.4)では π×exp(−δ²/2) を全成分で正規化する。

回帰器の更新は論文の式(3.3)に従い、w_{t,j,d} = w_{t−1,j,d} + β_{t,j,d} r_{t,j,d} δ_{t,j,d} k_t と書ける。これは混合回帰モデルの周辺対数尤度に対する一段の確率的勾配更新で、オンライン期待値最大化（online expectation–maximization; online EM）の解釈を持つ。責任度が小さい成分はほとんど更新されないため、別文脈の対応を保持しやすい。反対に責任度が特定成分へ集中しすぎると、その成分ばかりが更新される専門家崩壊が生じる。

読み出しでは、現在の問い合わせ q_t に応じた事前確率 π_{j,d}(q_t) で各回帰器の予測 w_{t,j,d}^T q_t を重み付けして足し合わせる（式3.5）。入力に依存して混合比が変わるため、個々の回帰器は線形でも、合成した問い合わせ→出力の写像は非線形になる。なお**読み出し時の重みは問い合わせ側の事前確率**であり、鍵・値側で計算した事後責任度をそのまま出力に使うわけではない。

### 3. 時間的持続性を持つTemporal SwiLA

通常の混合割当は各トークンで独立に決まるため、ある話題を示す文脈トークンが一度だけ出現し、その後の問い合わせ列で省略されると、どの回帰器を選ぶべきか分からなくなりやすい。論文はこれを扱うため、混合成分の確率分布を再帰状態として保持し、新しい入力から得た分布と以前の分布を凸結合する時間的SwiLA（Temporal SwiLA）を導入する。

設計の発想は隠れマルコフモデル（hidden Markov model; HMM）の状態推定に近いが、各時刻で厳密な周辺化と正規化を繰り返す代わりに、計算可能な近似更新を使う。文脈を表すトークンが一度しか現れなくても、その後の問い合わせで同じ文脈の成分を使い続けやすくなる。論文の文脈依存連想想起課題では、この持続性が通常のSwiLAより大きな利点を持つ。

### 4. 忘却ゲートと更新順序

長い系列では過去の写像を無期限に残すだけでは、文脈が切り替わったときに不要な記憶が干渉する。ゲート付きSwiLA（Gated SwiLA）は、入力依存の減衰係数 α_{t,j,d} を回帰状態に掛ける。論文は減衰後に責任度を計算する方式と、責任度計算後に減衰する方式を比較し、実際のGated SwiLAには**減衰した状態から予測誤差と責任度を求める式(3.8)**を採用する。J=1では再パラメータ化で対応するが、複数成分では両者の挙動が異なる。

このゲートはテスト時回帰の観点では回帰重みへのガウス事前分布・正則化に対応し、古い記憶の影響を入力に応じて弱める役割を持つ。ただし減衰を強くしすぎれば長期記憶が消え、弱すぎれば新しい文脈への適応が遅れる。混合割当、時間的持続性、忘却の三者が相互作用するため、単純に混合成分を増やすだけでは性能が上がらない。

### 5. 混合成分の崩壊を防ぐ学習補助

混合成分の利用が偏ると、一部の回帰器だけが学習され、J 個用意した利点が失われる。そこで論文は、全トークンで平均した利用分布のエントロピーを大きくする項と、個別トークンの割当分布のエントロピーを小さくする項を組み合わせる。式(3.9)の補助損失 L_MI = −λ_marg H_marg + λ_cond H_cond は、**全体として成分を満遍なく使いながら、各入力では役割分担を明確にする**ためのものだ。鍵側と問い合わせ側の双方に適用する。

加えて学習時には、入力依存の強度を持つガウス雑音を混合成分のロジットに加える（式3.10）。これは特定成分への早期固定を抑え、複数成分が機能を分担できるようにするための探索を促す。推論時の問い合わせごとに乱数で成分を選ぶ仕組みと混同してはいけない。

### 6. 一つの生成ステップにおける処理順

各ステップでは入力から鍵・値・問い合わせと成分事前確率を計算し、必要なら以前の混合確率を時間的に引き継ぐ。忘却ゲートを使う構成では先に状態を減衰させ、その状態で各成分の鍵に対する予測誤差を出し、事後責任度を求める。責任度を乗じたデルタ則で J 個の回帰状態を更新し、問い合わせ側の成分重みで回帰器出力を合成して次層へ渡す。保存するのは各回帰器の行列状態と必要な確率状態であり、過去の各トークンのKV配列ではない。

この処理は系列長に依存しない状態容量という利点を持つが、J 個の誤差・責任度・行列更新を扱うため単一回帰器より演算量が増える。また更新が直前状態に依存する非線形再帰であり、現在の論文実験は逐次Tritonカーネルを用いている。Newton反復で非線形再帰を線形化し、チャンク単位で並列化する構想は論文付録Dに示されるが、**現行実測の速度にその並列実装の利得を加算してはならない**。

出典は論文表2。単純なDeltaNetの17.3%に対しGated Temporal SwiLAは20.6%で、固定長再帰状態の範囲では改善する。しかしFoXの33.7%とは依然として13.1ポイントの差がある。3再帰層に1ソフトマックス層を挿入したHybrid Temporal SwiLAは31.8%へ近づくが、その場合は**純粋な固定長状態ではなく、ソフトマックス層の系列長依存KVキャッシュも保持する**。この違いを省いて31.8%を完全固定メモリ方式の成果として引用してはいけない。

### 合成課題で機構を分離する

ソフトマックス関数近似の実験では、特徴次元32、同じ状態予算 B=H×J において、SwiLAの最良構成はすべての予算でDeltaNetより高い決定係数 R² を得た。特に B=2 では2ヘッドのDeltaNetより1ヘッド2混合成分のSwiLAが良く、B=4では2ヘッド2混合成分のようにヘッド数と混合数を両立させる構成が有利だった。これは単にパラメータを増やしたからではなく、固定予算内で混合に配分することの効果を示す。ただし図1Cの点を本文にない精密数値へ読み替えない。

文脈依存連想想起（CDAR）は、同じ鍵が異なる文脈で別の値を持つよう設計され、問い合わせ領域では文脈トークンを最初に一度だけ示す。通常の短い畳み込みや単一回帰器では、離れた問い合わせまで文脈を持ち越しにくい。Temporal SwiLAは文脈確率を状態として持ち越すため、この設定で通常のSwiLAより有利になる。RegBenchでは学習例が1,000個の少量条件でTemporal SwiLAと混合記憶方式がTransformerを上回るが、学習例を増やすとTransformerが最高精度になる。**少量学習条件の優位を大規模学習全体の優位と一般化しない**。

## 既存方式との差

DeltaNetは一つの線形回帰状態をデルタ則で更新する。SwiLAは各成分の予測誤差から事後責任度を算出するため、更新自体が状態に対して非線形となる。Mixture-of-Memories（MoM）も複数記憶を持つが、SwiLAは出力次元ごとの確率的混合回帰とオンラインEMに基づく更新を設計の中心に据える。ゲート付きDeltaNetやKDAは固定長状態の速度・品質面で強力な比較相手であり、SwiLAの改善があっても推論速度や常識推論で必ず勝てるわけではない。

ソフトマックス注意との本質的な差は、過去の鍵・値を全保存するか、固定個数の回帰状態へ圧縮するかである。SwiLAの混合回帰は単一線形写像より表現力が高いが、履歴を完全保存する方式と同等の想起容量を保証しない。混成構成では一部にソフトマックス層を残すため、品質とメモリの交換条件がさらに変わる。

## 限界・実装状況・再現性

**固定長記憶の容量限界。** 系列長が増えても状態サイズが増えないことは長所だが、保持できる情報量そのものは有限である。FoXの想起平均33.7%に対して純再帰SwiLA系の最高20.6%という差は、固定状態だけで完全なKV履歴の代わりになっていないことを示す。

**逐次非線形再帰の費用。** 論文実装は逐次Tritonカーネルを使用する。付録DはNewton反復によるチャンク並列化を論じるが、最適化済みの逐次実装を超える実測速度はまだ示していない。GDNより推論1.25〜1.5倍、学習約2倍遅いという負の結果は重要である。

**混合数と専門家崩壊。** 成分数を増やすほど個々の射影次元が減る。時間的持続性や負荷分散がないと未使用成分が生じ、PPLが大きく悪化する。推論で混合重みを求める追加計算も無視できない。

**実験規模と一般化。** 374Mモデルの品質、1.3Bモデルの単一H100での性能、合成プロンプト2,048/128という条件が主な証拠である。100B級モデル、実運用の可変長到着負荷、複数GPU分散配信、極端な長文脈での実測遅延は本文の主要実験では検証されていない。固定長状態は理論的性質だが、4〜5倍の性能値は測定条件に依存する。

**公開実装。** 著者の公開リポジトリ `lindermanlab/switching-linear-attention` はMITライセンスの実装を提供し、`swila.layers.SwitchingLinearAttention`、CPU参照再帰、GPU向けTriton再帰カーネル、言語モデル構成、合成実験とFineWeb-Eduの学習レシピを含む。公開READMEの動作前提はLinux x86-64、Python 3.12.12、CUDA 12.6対応NVIDIA GPUで、検証対象はH100。再帰カーネルの混合成分は最大8までと記載されている。論文の16成分の構成要素除去実験と、公開カーネルの対応上限を同一視しない。公開のクイックスタートはランダム重みの層動作確認であり、論文の品質・速度を再現するベンチマークではない。
