# Kalman Delta Networks: Uncertainty-aware Associative Memory

> 固定サイズの線形注意メモリに推定不確実性を持たせ、蓄積証拠に応じて上書き強度をカルマン利得から決めることで、長文脈検索と生成精度を改善する。
## 書誌情報
- **著者**: Ngoc Bui, Tinglin Huang, Rex Ying
- **著者・所属**: Yale University, Department of Computer Science
- **公開**: arXiv
- **種別**: Preprint
- **対象**: 線形注意機構、固定メモリ推論、カルマンフィルタ、関連記憶、長文脈検索
- **実装**: 著者実装を公開。対角KDNはチャンク単位のカルマン利得走査とcompact-WY型メモリ走査を分離し、等方KDNはヘッド当たり1個の不確実性状態でKDAに近い計算形を保つ。
## 概要
線形注意機構は過去を固定サイズの再帰メモリへ圧縮するため、デコード時のKVキャッシュを文脈長に比例して保持せずに済む一方、各トークンで既存の関連付けをどれだけ上書きするかを将来の問い合わせを知らないまま決める必要がある。Kalman Delta Networks（KDN）は、この再帰メモリを非定常なキー・値写像の推定問題として捉え、メモリ本体に加えて推定不確実性を状態として伝播する。カルマン利得により、証拠の少ない関連付けは新情報で強く更新し、繰り返し確認された関連付けは保護する。密な共分散をそのまま持つ方式はGPU向け並列走査に不向きなため、対角近似と等方近似を導入し、固定メモリのまま走査並列性を維持する。

KDNは再帰的なキー・値メモリを線形ガウス状態空間モデルとして定式化し、記憶行列の推定値だけでなくキー空間の共分散、すなわち各関連付け方向にどれだけ確信があるかを伝播する。新トークンは潜在的なキー・値写像の雑音を含む観測とみなし、予測共分散と観測雑音からカルマン利得を計算して差分書き込みの強さを決める。これにより従来のDeltaNet、Gated DeltaNet、KDAを、共分散追跡を省いてトークン依存ゲートを使う固定利得近似として同じ枠組みに位置付ける。さらに密な共分散更新をGPU向け走査へ載せるため、対角と等方の二つの近似を導き、確信度追跡と固定メモリ・並列走査を両立する。

代表結果として、750M再帰モデルのLAMBADAパープレキシティと平均ゼロショット精度は750M、FineWeb-Edu 500億トークン、再帰層のみでKDA 15.06 / 53.87%、Mamba-3 MIMO 15.67 / 54.39%に対して対角KDN 14.15 / 54.97%、等方KDN 14.68 / 54.41%。不確実性追跡を加えた両KDNが強い比較対象より低いパープレキシティを示し、対角版は平均精度でも最良となる。
## 問題設定
通常の自己注意機構は過去トークンのキーと値を保持するため、デコード時のKVキャッシュが文脈長とともに増える。線形注意機構は過去を固定サイズの行列へ圧縮してこの増加を避けるが、容量が固定なので新しいキー・値の関連付けを書き込むたびに既存情報との干渉が起こる。DeltaNet系は現在キーでメモリを読んだ予測と新しい値との差分だけを書き戻し、トークンから予測したゲートで上書き強度を決める。しかし、そのゲートは過去に同じ方向の証拠が何回蓄積されたかを状態として持たないため、十分確認された関連付けと不確かな関連付けを同じ仕組みで扱う。結果として固定メモリの限られた容量を、将来必要になる情報を知らずに更新する難しさが残る。
## 新規性
KDNは再帰的なキー・値メモリを線形ガウス状態空間モデルとして定式化し、記憶行列の推定値だけでなくキー空間の共分散、すなわち各関連付け方向にどれだけ確信があるかを伝播する。新トークンは潜在的なキー・値写像の雑音を含む観測とみなし、予測共分散と観測雑音からカルマン利得を計算して差分書き込みの強さを決める。これにより従来のDeltaNet、Gated DeltaNet、KDAを、共分散追跡を省いてトークン依存ゲートを使う固定利得近似として同じ枠組みに位置付ける。さらに密な共分散更新をGPU向け走査へ載せるため、対角と等方の二つの近似を導き、確信度追跡と固定メモリ・並列走査を両立する。
## 手法
### 手法のあらまし
各トークンではまず、前時刻の記憶行列を学習された減衰で遷移させ、同時に不確実性も遷移とプロセス雑音で次時刻へ予測する。次に現在キーを使って予測記憶から値を読み、新しい値との差をイノベーション、つまり現在の記憶では説明できない残差として求める。予測不確実性が大きく観測が信頼できる場合はカルマン利得が大きくなり、この残差を強く書き込む。逆に同じキー方向の観測が過去に繰り返され不確実性が小さくなっていれば、新しい一観測による上書きを弱める。正確なカルマンフィルタではキー次元の密な共分散行列を保持し、毎トークン状態依存のリカッチ再帰を行う必要があるため、線形注意機構の利点である軽量な並列走査を失う。そこで対角KDNでは予測共分散をキー各チャネルの対角成分だけに制限し、観測後に生じる密な事後分布を逆KL最小化による平均場変分推論で対角ガウスへ投影する。この投影は一段の事後平均を保つ一方、方向ごとの不確実性を近似的に保持する。等方KDNではさらに全チャネルをヘッド当たり一つの不確実性スカラーへ縮約する。どちらも不確実性更新が一次分数変換の合成として表せるため結合的な走査が可能で、利得を先にチャンク並列で求めた後、通常の差分型メモリ更新を別の走査で処理する。対角近似が同じキー方向を過度に上書きしやすい問題には情報スケールを導入し、現在の書き込みを変えずに保存する事後不確実性だけを縮め、将来の同方向書き込みを弱める。

### 不確実性を持つカルマン関連記憶
潜在状態を時間変化するキー・値写像とみなし、記憶行列の平均とキー空間共分散を同時に追跡する。学習された遷移は古い関連付けの保持や減衰を表し、プロセス雑音は遷移だけでは説明できない意味状態の変化を不確実性として追加する。現在トークンの値は現在キー方向から得られる雑音付き観測とみなし、予測値との差分を残差として計算する。カルマン利得は予測共分散と観測雑音から決まり、不確実な方向では残差を強く採用し、十分な証拠が蓄積した方向では新しい観測の影響を弱める。したがって書き込み強度を現在トークンだけから独立に予測するのではなく、過去の観測履歴が作った確信度を次の更新判断へ直接持ち越す。

### 対角・等方共分散近似
正確なカルマン更新はヘッドごとにキー次元の二乗サイズの密な共分散を必要とし、観測ごとに密な事後共分散が生じる。対角KDNは遷移、プロセス雑音、予測共分散を対角に制限し、密になった事後を逆KL最小化で対角ガウスへ射影する。この射影はその時点の正確な事後平均を維持しながら、チャネルごとに一つの不確実性だけを残すので補助状態はキー次元に比例する。等方KDNはさらに共分散を単位行列のスカラー倍へ制限し、ヘッド当たり一つの不確実性だけを持つ。精度と状態量の異なる二段階の近似により、共分散追跡を導入してもデコード時メモリを文脈長に依存させない。

### 結合的な不確実性走査と情報スケール
対角KDNの各チャネルの不確実性再帰は一次分数変換として書け、2×2行列の積へ持ち上げると結合則を満たす。この性質を使い、チャンク内の変換を要約し、チャンク間の接頭辞走査で入口状態を求め、各チャンクを並列再生して全トークンのカルマン利得を出す。利得が決まった後の記憶更新は入力だけに依存する非対称な差分更新となるため、compact-WY型のチャンク走査で処理できる。また対角射影は同じキー方向の事後不確実性を正確値より大きく残し、次回の上書きを強くし過ぎる場合がある。情報スケールは現在の利得や現在の記憶更新を変えず、保存する不確実性だけを縮めることで、将来の同方向書き込みを抑えて既存関連付けを保護する。

### 全体のデータ／制御の流れ
各KDN層は通常の線形注意機構と同様に固定サイズの記憶行列を持ち、追加で対角版はキー各チャネルの不確実性、等方版はヘッド当たり一つの不確実性を保持する。学習時は不確実性走査で全位置の利得を計算し、その利得を使う記憶走査で出力と次状態を得る。デコード時は同じ再帰を1トークンずつ更新するため、文脈が伸びても状態量は増えない。
## 評価条件
- **ハードウェア**: 750Mモデルと1.3Bモデルを比較し、ミキサ層の実行性能はH200 GPU 1基、バッチ4、モデル幅2048、BF16で測定する。対角KDNの不確実性計算はFP32/TF32x3を用いる。
- **ソフトウェア**: 著者実装のKDNミキサを、DeltaNet、Gated DeltaNet、KDA、Mamba-3 SISO/MIMO、GDN-2と同一骨格・同一学習条件で比較する。ハイブリッド1.3Bでは9個の再帰層と9個の2K窓スライディング注意層を交互に配置する。
FineWeb-Eduから750Mモデルを500億トークン、1.3Bモデルを1000億トークンでゼロから事前学習する。比較内ではデータ、周辺骨格、最適化設定、評価手順を固定し、非埋め込みパラメータ数を0.03%以内で一致させる。学習系列長は4K、全体バッチは50万トークン。言語モデル性能をWikiTextとLAMBADAのパープレキシティ、LAMBADA・PIQA・HellaSwag・WinoGrande・ARC-Easy・ARC-Challengeのゼロショット精度で測る。長文脈検索はRULERの単一・複数キーneedle-in-a-haystackと、2K入力に制限したSWDE、SQuAD、FDA、TriviaQA、Natural Questions、DROPで評価する。情報スケール、観測雑音・プロセス雑音をアブレーションし、ミキサ層のスループットは30回の中央値で系列長を掃引する。
主要な品質比較は750M/50Bと1.3B/100Bという制御された事前学習実験であり、より大規模な実運用モデルへのスケーリングは未検証。実行性能グラフはエンドツーエンド生成ではなく単一ミキサ層の測定で、系列長4Kを超える点は学習範囲外のスケーリング確認である。ハイブリッド層比率もGDN-2の設定を流用しており、KDNに最適化された構成探索は行っていない。
## 主要結果
KDNは固定サイズ再帰メモリに不確実性を追加しても、比較した線形時間ミキサより品質を落とさず、むしろ言語モデル性能と検索性能を一貫して改善する。750Mでは対角KDNがLAMBADAパープレキシティ14.15、六タスク平均54.97%でKDAの15.06、53.87%を上回る。1.3Bでも対角KDNはWikiText 15.04、LAMBADA 9.75、平均60.45%でKDAの15.40、10.09、60.28%より良い。特にRULERでは対角KDNが長い単一キー・複数キー条件で強く、チャネル別不確実性による既存関連付け保護という設計意図と整合する。

- 750M再帰モデルのLAMBADAパープレキシティと平均ゼロショット精度 / 対角KDN 14.15 / 54.97%、等方KDN 14.68 / 54.41% (比較対象: KDA 15.06 / 53.87%、Mamba-3 MIMO 15.67 / 54.39%; 条件: 750M、FineWeb-Edu 500億トークン、再帰層のみ) — 不確実性追跡を加えた両KDNが強い比較対象より低いパープレキシティを示し、対角版は平均精度でも最良となる。

- 1.3B再帰モデルのWikiText/LAMBADAパープレキシティと平均精度 / 対角KDN 15.04 / 9.75 / 60.45% (比較対象: KDA 15.40 / 10.09 / 60.28%、Mamba-3 MIMO 15.63 / 10.49 / 59.85%; 条件: 1.3B、FineWeb-Edu 1000億トークン、再帰層のみ) — 規模を上げても改善が維持され、固定メモリ方式で共分散由来の書き込み利得を使う効果が750Mだけの現象ではない。

- RULER長文脈検索 / 750M対角KDNはS-NIAH-1の8Kで100.0%、S-NIAH-3の4Kで32.2%。1.3B対角KDNはS-NIAH-3の4Kで48.6%、MK-NIAH-1の4Kで33.8% (比較対象: 750M KDAは同条件82.6%、13.6%。1.3B KDAは43.2%、26.6%; 条件: 各セル500例、単一・複数キーneedle-in-a-haystack) — 干渉が増える長い検索条件で差が拡大する例があり、蓄積証拠のある関連付けを過剰上書きから守る機構と整合する。

- 実世界検索6タスク平均 / 1.3B再帰対角KDN 34.86%、等方KDN 33.40% (比較対象: KDA 33.76%、Mamba-3 MIMO 32.23%、GDN-2 32.09%; 条件: 入力2K、SWDE/SQuAD/FDA/TriviaQA/NQ/DROP) — 合成検索だけでなく実データ由来の検索でも対角版が再帰モデル中の最高平均を示す。

### 負の結果・境界条件
- すべての指標でKDNが一様に勝つわけではない。ハイブリッド1.3Bでは等方KDN+SWAの実世界検索平均45.94%が最高で、対角版45.55%は2位になる。情報スケールも単調に全指標を改善せず、4dkはLAMBADAパープレキシティ13.91で最良だが、WikiTextと平均精度はdk設定の18.64と54.97%が良い。観測雑音やプロセス雑音を固定するアブレーションも指標ごとに改善と悪化が混在する。対角版はチャネル別不確実性走査の追加計算があり、ミキサ層スループットは等方版より重い。

### 結果の読み方
固定メモリでは新しい観測を強く書くほど新情報への適応は速いが、既存関連付けを壊しやすい。KDNはこのトレードオフを、過去の証拠量を反映した不確実性で調整する。対角版がRULERの干渉の強い条件で優位になることは、キー方向ごとの確信度を分けて保持する利点を示唆する。一方、情報スケールや雑音設定の最適値が指標依存であることから、カルマン的定式化だけで自動的に最適な保護強度が決まるわけではなく、近似共分散の校正が重要である。
## 品質への影響
生成品質を犠牲にした近似高速化ではなく、固定メモリという近似構造の中で比較対象よりパープレキシティと下流精度を改善している。ただし完全自己注意機構と同一出力を保証する無損失方式ではない。
## 既存研究との差
DeltaNet、Gated DeltaNet、KDAは予測記憶と新しい値の残差を書き込む点ではKDNと共通するが、書き込みゲートを現在トークンから直接予測し、過去観測から得た確信度を明示状態として伝播しない。GDN-2は消去と書き込みを分離し、Preconditioned DeltaNetは逆グラム行列に基づく曲率情報でオンライン最小二乗へ近づけるが、KDNは非定常な潜在写像と観測雑音を仮定して予測共分散を時間発展させる。Kalman Linear Attentionもベイズ的な不確実性を並列走査するが、時間不変のOU力学と特徴・状態展開方向の因子化を使うのに対し、KDNはDeltaNet/KDA型のキー条件付き残差更新へカルマン利得を直接組み込む。
## 限界
評価規模は最大1.3Bパラメータ・1000億学習トークンで、数十B〜数百B級の実運用LLMでの品質・安定性は未検証。対角KDNは密な事後共分散を平均場近似で捨てるため、キー各チャネル間の相関を表現できず、その近似誤差を情報スケールで経験的に補正している。等方版はさらにヘッド内の全方向を同じ不確実性で扱う。スループット評価は単一H200上のミキサ層であり、モデル全体のエンドツーエンド生成速度、メモリ帯域、分散学習通信を含まない。ハイブリッド層比率や情報スケールの最適化も限定的で、指標ごとに最良設定が異なる。
## 実装状態
著者コードが公開されている。対角版はチャンクごとの2×2変換要約、チャンク接頭辞走査、並列再生による利得計算の後、非対称差分更新をcompact-WY型カーネルで処理する。等方版はヘッド当たり一つの不確実性で既存KDAに近いスカラー利得形を保つ。論文ではH200上で実際のミキサ層スループットを測定しており、概念のみの方式ではない。
## 研究上の位置づけ
長文脈推論のメモリ削減にはKVキャッシュの圧縮・追い出し・階層退避とは別に、履歴全体を固定サイズの再帰状態へ畳み込む系統がある。KDNは後者で、保存容量を文脈長から切り離した後に生じる『限られた状態へ何をどれだけ上書きするか』という情報管理問題を、不確実性推定として扱う。したがってKVキャッシュ最適化の代替というより、KVキャッシュ自体を固定メモリへ置き換える線形注意機構の品質改善として位置付く。システム観点では対角版がキー次元に比例する追加状態、等方版がヘッド当たり定数の追加状態を必要とするため、品質向上と状態量・計算量の選択肢を提供する。
