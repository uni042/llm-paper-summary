# Kelle：eDRAMとKVキャッシュ管理の協調設計

## 概要

Kelleは、端末上で大規模言語モデル（LLM）を推論する際、鍵・値の中間表現（KVキャッシュ）を面積効率の高い組込みDRAM（eDRAM）へ置き、記憶内容の削除・再計算・リフレッシュ頻度・演算順序まで一体で最適化する方式である。静的RAM（SRAM）より大きな容量を確保しやすいeDRAMには、蓄積電荷を定期的に回復させる更新処理が必要であり、単に記憶媒体を置き換えるだけでは消費エネルギーが悪化する。Kelleはこの更新費用を下げるため、重要でないKVを消し、場合によってはKVの代わりに入力表現を残して後から再計算する。

論文は、注意重要度による削除・再計算（AERP）、トークン重要度とビット位置による二次元適応リフレッシュ（2DRP）、シストリック削除器、再構成可能な演算配列、データ寿命を短くするスケジューラを組み合わせる。原著の合成・モデル評価では、元のSRAM構成に対し平均3.94倍の遅延改善と4.46倍のエネルギー効率改善を報告する。一方、eDRAMのみの置換ではエネルギー効率が39%悪化した。**記憶媒体単独の効果と、アルゴリズム・ハードウェア協調の効果を分離することが重要**である。

## 問題設定と技術的背景

端末向けアクセラレータはチップ面積、メモリ容量、外部DRAM転送、電力に強い制約を受ける。LLMの自己注意では生成トークンごとに過去のKVへアクセスするため、系列が長くなるとオンチップ記憶だけでは保持できず、外部DRAMへのアクセスが増える。SRAMは高速で更新不要だが密度が低く、限られた面積に大量のKVを格納しにくい。eDRAMは密度に優れる一方、保持時間が有限でリフレッシュの電力が必要となる。

通常のKV削除は、過去トークンの鍵・値を丸ごと捨てるため、精度低下と容量削減の交換条件が生じる。Kelleは削除に加え、入力表現 `x_n` を残して必要な `K_n,V_n` を後から再計算する選択肢を持つ。KVの二つのベクトルの代わりに入力一つを保持することでeDRAMの記憶量と更新対象を減らせるが、再計算の行列演算は増える。この追加計算が、外部メモリアクセスや更新費用より安い場合に意味を持つ。

また、eDRAMの保持誤差は全ビットで同じ意味を持たない。数値の上位ビット（MSB）が反転すると、下位ビット（LSB）より表現値への影響が大きくなる。さらに、注意に繰り返し参照されるトークンのKV誤差は、ほとんど参照されないトークンより品質へ影響しやすい。Kelleは**トークンの重要度とビットの重み**を同時に使い、必要な箇所だけ高頻度でリフレッシュする。

## 手法

### 1. 注意重要度に基づく削除

注意スコアから各頭・各トークンの重要度を累積し、KV予算を超えると最も低い重要度のトークンを削除する。重要度は注意頭ごとに異なるため、全頭一律に同じトークンを捨てるのではなく、頭別に保持候補を選ぶ。入力プロンプトの処理段階では各頭の累積注意から上位のトークンを選び、初期トークンと直近トークンも重要性に基づいて保持する。生成段階では新しいKVが入るたびに低重要度候補と置き換える。

この処理の入力は各注意頭の注意情報とキャッシュ占有状態、出力は保持するKVの集合である。消したトークンの情報を完全に復元する方式ではないため、極端な削除は検索・生成品質を損なう。著者は保持予算を変えた品質評価と後段の再計算を組み合わせ、単純削除だけに依存しないようにする。

### 2. KVの代わりに入力表現を保持して再計算

削除候補のうち、再参照が見込まれるトークンについては鍵・値を保持する代わりに入力ベクトルを保存する。必要時にはその入力と `W_K,W_V` を用いて鍵・値を再計算する。KV二本分の長寿命記憶を入力一本分に置き換えられ、特に保持時間に応じて更新が必要なeDRAMで有効となる。ただし、入力ベクトルの保存容量と再計算の演算・重みアクセスはゼロではない。

Kelleの再計算判断は、注意による重要度、保持予算、行列演算器の利用状況を考慮する。再計算の対象を無制限に増やすと計算負荷が増えるため、著者は演算配列上で複数トークンの処理をまとめ、追加の行列積を効率的に行う。再計算はオフロードと異なり、消したKVをCPUやSSDから読み戻すのではなく、同じモデルの重みから作り直すという点が異なる。

### 3. 二次元適応リフレッシュ（2DRP）

eDRAMのリフレッシュ頻度を、(a) トークンの注意重要度と、(b) 数値内のビット位置の二軸で決める。例えば重要トークンの上位ビットは高頻度で更新し、重要度の低いトークンの下位ビットは低頻度で更新する。著者は重要度群とビット位置群を組み合わせ、各セルの必要保持精度に応じた更新周期を割り当てる。入力は注意重要度と格納ビットの位置、出力はeDRAMのセル群ごとの更新設定である。

重要度が変化するとリフレッシュ設定も変えるため、静的に全セルを最短周期で更新する方式より更新電力を抑えられる。反面、低頻度群では誤りが増え得るため、許容する精度劣化と保持時間の関係を実験で評価する必要がある。特に温度・製造条件によって保持時間が変わるので、論文のデバイスモデルをそのまま別の実チップへ適用することはできない。

### 4. シストリック削除器と再構成可能な演算配列

Kelleの演算器は32×32の再構成可能なシストリック配列（RSA）を中心に、特殊関数器とメモリ制御器を持つ。シストリック削除器（SE）は注意スコアの集約と最小重要度候補の探索を行列演算と重ね、最低重要度の索引をeDRAM制御器へ送る。独立した大きなCPU処理として後から走査するのではなく、注意計算のデータ流に削除判断を重ねる設計である。

重みは8ビット、活性とKVは16ビットという主構成で、2MB SRAMを重みに、256KB eDRAMを活性に、4MB eDRAMをKVに割り当てる。論文ではソフトマックスなどの非線形演算に特殊関数器を用い、重み転送とKVアクセスの待ちを考慮して配列の演算順序を調整する。削除器が出す索引とメモリ制御器の動作が直結するため、アルゴリズムとハードウェアを切り離して評価するだけでは総合効果を説明できない。

### 5. スケジューラで一時データの寿命を短縮

通常のQ、K、V射影を逐次実行すると、先に計算したQや入力活性は、後段の注意演算までeDRAMに保持され続ける。保持時間が長いほど更新回数が増えるため、Kelleは重みロード、行列積、KVアクセスの順序を組み替え、一時ベクトルが生成されてから消費されるまでの期間を縮める。スケジューラの出力は演算の実行順とデータ配置であり、追加の大容量メモリを要求する代わりに、既存の演算器とデータ寿命を協調させる。

## 評価

### 評価環境と比較の公平性

| 項目 | 一次論文の条件 |
|---|---|
| 演算器 | 32×32の8ビット演算配列、特殊関数器、SystemVerilog RTL |
| 合成 | 45nm NanGateセル、Synopsys Design Compiler、動作周波数1GHz |
| メモリモデル | 65nm eDRAM/SRAM、Destiny、105℃の保持特性。外部LPDDR4 16GB/64GB/sはCacti 7でモデル化 |
| 容量 | 重み用SRAM 2MB、KV用eDRAM 4MB、活性用eDRAM 256KB |
| 帯域 | SRAM 128GB/s、eDRAM 256GB/s（感度評価では128GB/s） |
| 主な課題 | LAMBADA、TriviaQA、Qasper、PG19 |
| 文脈長/生成長 | 順に128/512、512/2048、1024/5120、512/8192 |
| 主要バッチ | 16。追加で4、1を評価 |
| 比較 | Original+SRAM、Original+eDRAM、AEP+SRAM、AERP+SRAM、Kelle+eDRAM |

これらはRTL合成とメモリ・アクセラレータの性能モデルを用いた評価であり、量産済みチップの実機測定と同一視しない。SRAM基準は面積を揃えるため24×24演算配列、4MB SRAMとするなど、記憶媒体だけでなく面積制約も考慮している。

### 主な性能と構成要素の効果

Kelle+eDRAMはOriginal+SRAMに比べ、平均で**遅延3.94倍改善、エネルギー効率4.46倍改善**を報告する。ここで遅延改善倍率は同一評価条件での比較であり、実チップで3.94倍高速化したという測定ではない。eDRAMへ置き換えるだけのOriginal+eDRAMは速度が32%改善する一方、更新電力によってエネルギー効率が39%悪化する。これは更新制御を省いたeDRAM導入の負の結果として重要である。

削除だけを行うAEP+SRAMはOriginal+SRAMに対して遅延2.39倍、エネルギー効率2.41倍改善する。削除に再計算を加えたAERP+SRAMはAEP+SRAMに対して速度1.19倍、エネルギー効率1.27倍改善する。さらにKelle+eDRAMでは2DRPとスケジューラ・専用ハードウェアの効果が重なる。改善要因をeDRAM容量だけに帰属させないことが必要である。

### 精度・量子化との交換条件

論文は言語モデルの品質も測定する。例えばLLaMA2-7BのCNN/Truth/BBQの指標はFP16で40.58/34.28/95.21、Kelleでは38.54/33.26/93.75となり、完全に無損失ではない。別の量子化比較では、重み8ビット・活性16ビット（W8A16）に対して重み4ビット・活性8ビット（W4A8）で、WikiText-2のPPLが5.74から6.51へ悪化する。メモリ削減やエネルギー改善と品質は別に評価すべきである。

### 感度・悪化条件

PG19でバッチ16のエネルギー効率倍率はOriginal+SRAMを1としてKelle+eDRAM 6.67、バッチ4で2.23、バッチ1で1.71へ低下する。小バッチでは演算配列利用率と重み転送効率が下がるためであり、**バッチ16の改善率を単一要求の端末推論へそのまま適用できない**。また、eDRAMの保持時間を短くした場合のエネルギー効率も検証している。LLaMA3.2-3BのPG19では保持周期1050µsで8.07倍、525µsで7.31倍、131µsで6.05倍となる。温度上昇などで更新頻度が増えると利得が縮む。

KV予算を増やすと削除・再計算の機会が減るため、PG19のLLaMA3.2-3Bで予算2048トークンの8.07倍から8750トークンの4.55倍へ低下する。eDRAM帯域を256GB/sから128GB/sへ減らした条件でも、PG19とTriviaQAでAERP+SRAM比1.47倍・1.35倍のエネルギー利得が報告されるが、基準とモデル条件を明記して解釈する必要がある。

## 既存研究との差

StreamingLLMやH2OなどのKV削除は保存対象の選択に重点を置き、KIVIなどの量子化は表現ビット幅を下げる。KelleはeDRAMという記憶媒体の物理的な更新費用を設計目標に加え、削除・再計算・ビット重要度別のリフレッシュ・演算順序を協調させる。重みとKVの単なるオフロードではなく、保持寿命を減らして更新エネルギーを節約する点に特徴がある。CPU/GPUサービングの汎用KVキャッシュ制御を直接置換するものではなく、専用のエッジ推論アクセラレータの設計研究である。

## 限界・再現上の注意

主結果はRTL合成とデバイスモデルによる推定であり、実際の製造プロセス、温度分布、エラー率、電源制御、実装コストを含む実機検証は別途必要である。eDRAMの保持時間・帯域や演算配列の利用率が変わると利得も変わる。更新頻度を下げるため、重要度推定が誤る条件や、重要なトークンを削除する条件では品質劣化が起こり得る。モデル全体の重み容量をオンチップ2MBに収めるわけではなく、外部メモリからの重みアクセスも評価に含めている。

さらに、平均3.94倍・4.46倍は比較した複数モデル・課題・シミュレーション設定の平均であり、単一の実GPUやスマートフォンで保証される値ではない。主構成のW8A16と追加量子化W4A8を混同しないこと、エネルギー効率と遅延改善の倍率を同じ指標として扱わないことが重要である。公式の一般公開コードURLは今回確認した原著には記載されていない。
