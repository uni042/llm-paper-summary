# KV Cache is 1 Bit Per Channel: Efficient Large Language Model Inference with Coupled Quantization

> 鍵値活性のチャネル間依存を利用して複数チャネルを共同量子化し、極低ビットでも品質劣化を抑える連結量子化を提案する。
## 書誌情報
- **著者**: Tianyi Zhang, Jonah Yi, Zhaozhuo Xu, Anshumali Shrivastava
- **公開**: arXiv preprint
- **種別**: preprint
- **対象**: 鍵値キャッシュ量子化、連結量子化、チャネル間依存、フィッシャー誘導重心学習
- **実装**: 論文はPyTorchとHuggingFace Transformersに基づく実装で評価している。本文で公式コード公開先は確認できない。
## 概要
連結量子化（Coupled 量子化; CQ）は、鍵値活性埋め込みの異なるチャネルが強く依存し、複数チャネルの同時エントロピーが周辺エントロピー総和より遅く増える観測を利用する。連続チャネルを群に分け、各群を多次元重心へ共同量子化することで、独立なチャネル単位量子化より情報効率を高める。さらにフィッシャー情報行列の対角近似で重要活性を重み付けした重心学習を導入する。5モデル、WikiText-2、C4、WinoGrande、PIQA、ARC Challengeで評価し、特に1〜2ビットで既存の密量子化を大幅に上回り、1ビットでも実用的な品質を維持した。

論文は鍵値活性のチャネル同士が独立ではなく、複数チャネルの同時エントロピーが各チャネルの周辺エントロピー総和より遅く増えることをWikiText-2上で観測する。この依存を利用し、連続する複数チャネルを一つの多次元ベクトルとして同じ符号で量子化する連結量子化を提案する。さらにフィッシャー情報行列の対角近似を用いて重要な活性ほど量子化誤差を抑える重み付き重心学習を組み合わせる。

代表結果として、WikiText-2、LLaMA-7b、2ビット相当はCQ-4c8bでFP16 5.68、KVQuant 2ビット8.17に対してパープレキシティ5.97。チャネル共同符号化により2ビットでもFP16へ近い品質を保つ。
## 問題設定
自己回帰LLMの復号では、過去トークンの鍵と値をKVキャッシュとして保存して再計算を避ける。しかしキャッシュ量はバッチ数、文脈長、層数、KVヘッド数、チャネル数に比例して増え、長文脈や大バッチではGPUメモリ容量を圧迫する。さらに各系列のKVは基本的に共有できず、次トークンの注意計算では過去のKVを毎回グローバルメモリから読むため、演算量よりメモリ転送が支配するフォン・ノイマン型の帯域ボトルネックになる。既存のKV量子化は鍵をチャネル単位、値をトークン単位など、各スカラーや各チャネルをほぼ独立に符号化する。この前提でも4ビット程度なら圧縮効果を得られるが、16倍圧縮に相当する1ビット級まで下げると、利用可能な重心数が少なすぎて活性分布を表せず、量子化誤差と困惑度が急増する。単純な独立量子化では、同じ鍵・値埋め込み内のチャネル間に存在する相互情報を捨てているためである。極低ビットで容量と読出し帯域を同時に減らしつつ品質を保つには、チャネル間依存を共同符号へ取り込み、さらにモデル損失へ影響しやすい活性の誤差を優先的に抑える必要がある。
## 新規性
論文は鍵値活性のチャネル同士が独立ではなく、複数チャネルの同時エントロピーが各チャネルの周辺エントロピー総和より遅く増えることをWikiText-2上で観測する。この依存を利用し、連続する複数チャネルを一つの多次元ベクトルとして同じ符号で量子化する連結量子化を提案する。さらにフィッシャー情報行列の対角近似を用いて重要な活性ほど量子化誤差を抑える重み付き重心学習を組み合わせる。
## 手法
### 手法のあらまし
入力は事前学習済みLLM、校正データ、各層・各KVヘッドの鍵値活性、共同化するチャネル数c、群当たりの符号ビット幅bである。最初に校正データを流してKV活性を収集し、チャネルごとの周辺分布だけでなく複数チャネルの同時分布を観察する。論文ではLLaMA-7BのWikiText-2上で、共同化するチャネル数を増やしたとき周辺エントロピーの総和はほぼ線形に増えるのに対し、同時エントロピーはより遅く増えること、相関行列にも強いチャネル間依存が現れることを確認する。これは複数チャネルを別々の符号で保存するより、一つの多次元符号として共同化した方が同じ情報を少ないビットで表せる余地があることを意味する。

量子化では各鍵・値埋め込みの連続cチャネルを重ならない群へ分け、群ごとに2^b個のc次元重心を学習する。推論時にはc次元の活性ベクトルと各重心の距離を比較し、最も近い重心のbビット番号だけをKVキャッシュへ保存する。たとえば4チャネルを一群として8ビット符号を一つ保存するCQ-4c8bは、保存量では1チャネル当たり2ビットに相当するが、各チャネルへ独立した4値を割り当てるのではなく、256種類の4次元代表点から選べるためチャネル間依存を表現できる。鍵と値の双方に同じチャネル共同化を適用し、鍵は既存KV量子化と同様にRoPE適用前の活性を量子化する。

重心学習には通常のk-means++初期化によるL2再構成誤差最小化に加え、フィッシャー情報で重み付けする方式を用意する。校正データで言語モデル損失に対するKV活性の勾配を求め、その二乗をフィッシャー情報行列の対角近似として扱う。各活性の量子化誤差をこの重要度で重み付けして重心を更新することで、単純な平均二乗誤差だけでは同等に扱われる活性のうち、最終損失へ大きく影響する点を優先して近い重心へ寄せる。論文の除去比較では、共同チャネル数を増やすこととフィッシャー誘導重心の双方が1〜2ビット条件の困惑度を改善する。

校正完了後はモデル重みを再学習せず、各層・各チャネル群の重心表を固定する。生成時に新しいKV活性が生じるたび、群単位で最近傍重心番号へ符号化して小さな整数列として保存する。注意計算時には番号からc次元重心を引いてKVを復元し、通常の注意演算へ渡す。重心表の追加保存量はモデル重みに比べ小さく、密な符号表現なので外れ値を別の疎行列として保持・乗算する方式を避けられる。結果として、KVキャッシュ容量だけでなく復号時にGPUメモリから読むデータ量も減らし、演算器がメモリ待ちになりやすい注意処理の帯域ボトルネックを緩和する。

### チャネル間依存の利用
各鍵・値埋め込みのチャネルを確率変数とみなし、校正データから得た活性をビン分割して周辺エントロピーと同時エントロピーを推定する。独立なら複数チャネルの同時エントロピーは周辺エントロピー総和に近づくが、LLaMA-7Bでは共同チャネル数を増やしたとき同時エントロピーの増加が明確に遅い。さらに複数層の相関行列でも高い絶対相関が観測される。したがって独立チャネル量子化は既存の相互情報を符号化に使えておらず、複数チャネルを一つのベクトルとして表現すれば、同じ総ビット数でもより多くの実際の活性パターンを区別できる。この観測を極低ビットKV量子化の設計根拠にする。

### 多次元重心による連結量子化
c個の連続チャネルを一群とし、群ごとに2^b個のc次元重心をオフライン学習する。各活性群はユークリッド距離が最小の重心へ写像され、その重心番号bビットだけを保存する。CQ-4c8bなら4チャネル全体を256種類の4次元代表点で表し、保存量は1チャネル2ビット相当になる。独立2ビット量子化のように各軸4値の直積を機械的に使うのではなく、実データが集中する多次元領域へ符号を割り当てるため、チャネル間依存を利用できる。鍵・値の双方を同方式で扱い、鍵はRoPE前に量子化して位置回転による外れ値増加を避ける。

### フィッシャー誘導重心学習
通常のk-meansはすべての活性点の再構成誤差を同等に扱うが、LLMの最終損失に対する感度は点ごとに異なる。そこで校正データ上でKV活性に対する損失勾配を求め、勾配二乗をフィッシャー情報行列の対角近似として重要度に使う。重心更新では重要度の高い活性の距離誤差へ大きな重みを与え、損失へ敏感なKVをより正確に表現するよう代表点を移動させる。これにより単純なL2量子化誤差が最小でなくても、生成モデルとしての困惑度をより良く保てる。特に符号数が極端に少ない1ビット条件で、共同量子化だけより品質を押し上げる役割を持つ。

### オフライン校正と実行時復号
多次元重心は校正データを使って一度だけ学習し、推論時にモデル重みを更新しない。新しい鍵・値が生成されるとチャネル群ごとに最近傍重心番号へ符号化し、FP16活性の代わりに小さな整数コードをKVキャッシュへ蓄積する。注意計算で過去KVが必要になった時だけコードから対応する重心ベクトルを読み出して復号する。追加の重心表はモデル重みに比べ小さく、外れ値専用の疎表現を別途保持する方式と違ってKV本体を密なコード列として扱える。このため容量圧縮とメモリ読出し削減を同時に狙え、復号演算が増えても元々メモリ律速な注意では計算資源の余裕を利用しやすい。

### 全体のデータ／制御の流れ
モデル本体を再学習せずにKVキャッシュ経路だけを置き換える後学習量子化である。オフライン段階では校正データから層・KVヘッド・チャネル群ごとの多次元重心と、必要ならフィッシャー重要度を学習する。オンライン段階では新規KVを群単位の整数コードへ変換して保存し、注意カーネルが過去KVを読む際に重心表から復元する。圧縮対象をキャッシュそのものに限定するため重み量子化と併用可能で、容量制約によるバッチ上限と、復号注意のグローバルメモリ帯域の双方を直接減らす設計である。
## 評価条件
- **ハードウェア**: Ubuntu 20.04、AMD EPYC 7742 CPU 2基、1.5TB RAM、NVIDIA A100 40GB GPU 4基。重心学習は単一GPUでk-meansを100反復する。
- **ソフトウェア**: PyTorchとHuggingFace Transformersを基盤に連結量子化を実装。
- **データセット／トレース**: WikiText-2、C4、WinoGrande、PIQA、ARC Challenge
- **比較対象**: FP16鍵値キャッシュ、INT量子化、NormalFloat量子化、KVQuant、KVQuant 1%外れ値保持
LLaMA-7b、LLaMA-13b、LLaMA-2-7b、LLaMA-2-13b、Mistral-7bの5モデルを用いる。WikiText-2学習集合から2048トークンの16系列を校正に使い、評価集合とは分離する。WikiText-2とC4では各モデルの最大文脈長でパープレキシティを測り、WinoGrande、PIQA、ARC Challengeではゼロショット正解率を測る。FP16、整数量子化、NormalFloat、KVQuantと比較し、1、2、4ビット相当を評価する。チャネル連結数とフィッシャー誘導重心のアブレーション、重心学習時間と重心表容量も測る。
短〜中程度の最大文脈長2048〜8192で品質を中心に評価する。実サービングのエンドツーエンド遅延や処理能力は直接測定していない。
## 主要結果
連結量子化は同じ実効ビット幅の非疎量子化を一貫して上回り、特に1〜2ビットで差が大きい。WikiText-2のLLaMA-7bでは2ビット相当CQがパープレキシティ5.97で、KVQuantの2ビット8.17、一般的な2ビット整数・NormalFloatの破綻に対してFP16の5.68へ近い。1ビット相当CQでも8.09を保ち、KVQuant 1ビットの321.58より大幅に良い。

- WikiText-2、LLaMA-7b、2ビット相当 / パープレキシティ5.97 (比較対象: FP16 5.68、KVQuant 2ビット8.17; 条件: CQ-4c8b) — チャネル共同符号化により2ビットでもFP16へ近い品質を保つ。

- WikiText-2、LLaMA-7b、1ビット相当 / パープレキシティ8.09 (比較対象: KVQuant 1ビット321.58、KVQuant 1%外れ値9.93; 条件: CQ-8c8b) — 密な1ビット表現でも外れ値疎表現に匹敵する品質を得る。

- C4、LLaMA-7b、2ビット相当 / パープレキシティ7.52 (比較対象: FP16 7.08、KVQuant 2ビット10.28; 条件: CQ-4c8b) — 校正と異なる評価コーパスでも改善が維持される。

- アブレーション、Mistral-7b / 2ビットで97.76から5.11へ改善 (比較対象: 1チャネル・通常重心97.76; 条件: 4チャネル連結＋フィッシャー誘導重心) — チャネル連結と重要度誘導重心の両方が品質改善へ寄与する。

- 重心学習時間 / Mistral-7bで4〜13分、LLaMA-13bで22〜94分 (比較対象: 単一GPU、100回k-means; 条件: 連結数により変動) — オフライン校正費用はモデル推論とは分離できる。

### 負の結果・境界条件
- 1ビットCQは従来の密量子化より大幅に良いがFP16品質を完全には保持せず、例えばWikiText-2のLLaMA-7bで5.68から8.09へ悪化する。フィッシャー誘導重心は通常の量子化誤差そのものを増やす場合があるが、重要活性を優先するためパープレキシティは改善する。重心表はモデル重量の約0.232〜0.996%を追加し、校正には最大94分程度を要する。

### 結果の読み方
極低ビットで独立スカラー量子化が破綻する主因の一つは、チャネル間の相互情報を捨てることにある。複数チャネルを同じ符号へまとめると同じ総ビット数で多次元分布を表現でき、重要度をフィッシャー近似で重み付けすると言語モデル損失に効く領域へ重心を集中できる。
## 品質への影響
4ビットではほぼFP16相当、2ビットでも小さな劣化、1ビットでは明確な劣化が残るが従来密量子化よりはるかに安定する。
## 既存研究との差
KIVIやKVQuantのような既存法が鍵をチャネル単位、値をトークン単位など独立に量子化するのに対し、CQは複数チャネルを一つの多次元重心番号へ共同符号化し、チャネル間相互情報を直接利用する。KVQuantの外れ値保持版は密表現に加えて疎行列積が必要だが、CQは密な符号と重心表だけで極低ビット品質を狙う。H2OやScissorhandsのトークン削除とは直交し、CQは保持トークン数ではなく各鍵値要素の表現ビット数を減らす。
## 限界
評価モデルはLLaMA系とMistral-7bまでで、近年のGQA/MQAモデルや100K超の長文脈は扱わない。品質評価はパープレキシティと三つのゼロショット課題が中心で、実際のサービング処理能力、復号遅延、バッチ拡大効果は直接測っていない。重心学習には校正データと活性勾配が必要で、モデルごとに数分〜94分のオフライン処理がかかる。重心表もモデル重量の約0.2〜1%を追加する。1ビットでは従来法より良いがFP16との差は残る。

## 研究上の位置づけ
CQは鍵値キャッシュ圧縮のうち、トークン削除ではなく数値表現を極低ビット化する系統に位置する。中心的な発見は、鍵値活性をチャネルごとの独立スカラーとして扱う前提を外し、低ランク性や相関に由来するチャネル間依存を圧縮余地として使った点である。4チャネルを8ビット符号へまとめる2ビット相当、8チャネルを8ビット符号へまとめる1ビット相当のように、群サイズを増やしても一つの符号で多次元分布を表現する。

システム面では、復号注意が演算よりGPUメモリ読み出しに律速される状況で、鍵値を16ビットから1〜4ビットへ縮めることは容量だけでなく転送量削減にもつながる。論文はエンドツーエンド速度を測っていないため速度向上量は未検証だが、外れ値用の疎行列積を避ける設計はGPU上で規則的な密処理を維持しやすい。

フィッシャー誘導重心学習は、単純な再構成誤差ではなくモデル損失への感度を圧縮目標へ持ち込む。アブレーションではチャネル連結数の増加とフィッシャー誘導の双方がパープレキシティを改善しており、情報理論上の共同符号化とタスク感度に基づく誤差配分を組み合わせる構成である。

オフロードや階層メモリとは補完的である。CQで各鍵値のバイト数を減らせばGPU常駐量、CPU・SSD側の保存量、階層間転送量を同時に縮められる。一方、トークン削除法は位置数を減らすため、削除後の残存鍵値へCQを適用する二軸圧縮も概念上可能である。ただし削除誤差と量子化誤差が重なるため品質検証が必要になる。

リポジトリ内ではKIVI、KVQuant、QServe等の鍵値量子化研究と直接比較すべき手法であり、特に『1チャネルを何ビットにするか』から『複数チャネルを一つの符号でどう表すか』へ設計単位を変えた点が差別化である。
