# DPA-MoE: A Runtime Precision Control Framework for MoE Inference

> ルータが選んだ専門家への重み断片の配分を、ゲートスコアと事前計測した再構成残差から実行時に決め直すことで、同じ平均断片数の一律配分より出力分布のずれを最大4.5倍小さくし、同等の忠実度を22から44ギガバイト少ない重み量で達成した。

## 概要

混合専門家モデル（Mixture of Experts; MoE）は、トークンごとに全結合ネットワークの候補である専門家の一部だけを選び、選ばれた専門家だけを計算することで、総容量を増やしながらトークンあたりの計算を小さく保つ方式である。しかし従来の混合専門家モデルが制御しているのは「どの専門家を動かすか」までであり、いったん選ばれた専門家は固定の精度で評価される。専門家の全結合重みは現代の混合専門家モデルのパラメータの大半を占め、論文が例に挙げるモデルでは約95パーセントに達する。そのため、選ばれた専門家の中でどれだけの重みビットを読むかは、メモリ量と帯域の両方に効く大きな制御点でありながら、これまで固定値のまま置かれてきた。

本論文が提案する枠組みは、この固定を外す。まず各専門家の重みを、符号付きの二値平面と群ごとの尺度の組である「断片」の順序付き列として符号化する。先頭から数個の断片だけを使っても近似として成立し、断片を増やすほど元の重みに近づくため、断片の個数そのものがその専門家の精度になる。次に、専門家ごと・断片数ごとの再構成の残差、つまり全精度の専門家出力と断片数個で再構成した出力の差の大きさを、較正データで事前に測って表にしておく。推論時には、ルータが現在のトークンへ付けたゲートスコアの2乗をその残差へ掛けたものを費用とし、ディスパッチごとの断片総予算を守りながら費用の合計が最小になる配分を動的計画で厳密に求める。ルータ自体と専門家の同一性は変えず、再学習もしない。1つの符号化済みモデルが、平均断片数を動かすことで複数の有効重み量と品質の動作点をその場で出せるようになる。

代表結果は次の通りである。規模もルーティング幅も共有専門家の有無も異なる4つの混合専門家モデルで、同じ平均断片数の一律配分と比べて出力分布のずれが一貫して小さくなった。最も差が大きいのは中程度の圧縮域であり、あるモデルでは平均断片数4の条件でずれが最大4.5倍小さくなり、2つの主要モデルでは同等の忠実度を22から44ギガバイト少ない有効重み量で達成した。課題正解率でも同じ向きの改善があり、追加の2モデルではずれの削減率が26から69パーセントの範囲だった。一方で速度は無償ではなく、同じ平均断片数では試作実装の生成スループットが4から8パーセント下がり、最初のトークンまでの時間は約30から50パーセント増えた。品質をそろえて比べると、より小さい平均断片数で同等の正解率に届くため速度の不利の一部を取り戻せる、というのが論文の読みである。実機の試作で測った研究であり、提供システムそのものではなく精度配分の部品として位置付けられている。

## 問題設定

なぜ一律の精度が無駄になるかを、資源の側から見る。ルータは選んだ専門家へ均等な重みを付けない。ゲートスコアは専門家ごとに異なり、現在のトークンへの寄与の大きさが違うことを示している。さらに、断片を削ったときにどれだけ出力が壊れるかも専門家ごとに異なり、層によっても断片数によっても変わる。ところが一律配分は、寄与が小さく壊れにくい専門家にも、寄与が大きく壊れやすい専門家にも、同じ個数の断片を割り当て、同じ量の重みビットを読ませる。結果として、追加の断片がほとんど効かない起動へメモリと帯域を費やし、逆に精度が最も効く起動が不足する。重み読み出しはデコードの帯域を支配する費用の1つであり、この配分のずれはそのまま重み量と品質の交換効率の悪さになる。

既存の対策は、このずれを実行時に直せない。学習後の量子化は配布前に精度を固定し、専門家ごとの混合精度でも割当ては配布前に決まって現在の入力を反映しない。キャッシュの状態や長期のルータ統計で精度を変える方式は、現在のトークンにとっての各専門家の重要度を使わない。学習した方策でビット幅を選ぶ方式は追加の学習が要り、精度が分離可能な実行時変数として外へ出てこない。複数の精度を再符号化なしに出せる符号化の研究は土台を提供するが、専門家間で制御をどう振るかは決めていない。本論文の問題設定は、ルータを変えず、再学習もせず、選ばれた専門家内部の一律精度という仮定だけを取り除き、1つの符号化済みモデルから重み量と品質の動作点を細かく出せるようにすることである。特に端末側の推論では、他の応用にメモリを取られるなど拘束条件がモデル常駐中に変わるため、別の量子化済みファイルを読み直すのではなく、その場で動作点を動かせること自体に価値があると論文は位置付ける。

## 手法のあらまし

処理の流れは、符号化、事前計測、実行時配分の3段である。第1に符号化では、各専門家の全結合重みテンソルを断片の列として表す。各断片は二値の平面1枚と群ごとの尺度であり、群ごとのずれ量は全断片で共有される。精度は断片数で表され、既定の範囲は最小2個から最大8個である。先行方式では精度段階ごとに尺度を最適化し直すため段階数分の尺度表が要ったが、本論文の共有尺度方式は全段階で1つの尺度表を固定し、精度を上げる際は新しい平面とその尺度列だけを読めばよく、既に読んだ尺度は有効なまま残る。第2に事前計測では、推論の前に、層と専門家と断片数の組合せごとに、全精度の専門家出力と再構成した出力の差の2乗平均を較正データで測り、残差表としてモデルと一緒に保持する。この計測はゲートを使わず、専門家固有の圧縮誤差だけを捉える。第3に実行時配分では、ディスパッチのたびにルータのゲートスコアを取り、残差へゲートの2乗を掛けた費用のもとで、起動した専門家の集合に対する断片総数が予算と一致する配分を、多選択ナップサック問題として動的計画で解く。予算は起動専門家の数に目標の平均断片数を掛けて決まるため、平均断片数を非整数にすれば整数の段階の間を滑らかに補間できる。バッチ化されたプリフィルでは、ゲートの2乗をマイクロバッチ内のトークンについて合計し、起動専門家の和集合に対して同じ問題を解く。

## 手法

### 1. 共有尺度方式の段階的符号化 — 前から積み増せる断片列を作る

この機構が観測するのは、較正データに対する各層の全精度の入出力であり、入力は専門家の全結合重みテンソルである。保持する状態は、断片ごとの二値平面と、全精度段階で共有される尺度とずれ量の表である。再構成は、ずれ量に各断片の尺度と二値平面の積を断片数個だけ合計した形で与えられ、群の大きさは128である。符号化の進め方は、断片を1つずつ追加し、その都度、符号を固定したまま有効な全尺度を目的関数で共同に再最適化することである。目的関数は2項の和で、第1項は最大断片数で量子化した層の出力と全精度の層の出力の平均2乗誤差、第2項は中間の各断片数における重み再構成の平均2乗誤差の平均であり、重み係数で釣り合いを取る。第2項が効く理由は、最大精度だけに合わせると中間の精度が犠牲になるためであり、中間段階の保存を明示的に目的へ入れることで、全段階で1つの尺度表を共有する代償を埋めている。これにより減るボトルネックは2つある。保存側では、段階ごとに尺度集合を持つ先行方式が2から8ビットの範囲で35集合の尺度を要するのに対し、共有方式は8集合で済む。あるモデルの専門家1つあたりで比べると、尺度の保存量は2520キロバイトから576キロバイトへ減り、全体は7128キロバイトから5184キロバイトへ減る。実行側では、精度を上げる遷移のたびに累積した尺度集合を実体化し直す必要がなく、新しい平面1枚とその尺度だけを読めばよい。追加で消費する資源は符号化時の最適化計算であり、対象は専門家の全結合重みだけで、それ以外のテンソルは通常の8ビット量子化で扱われる。失敗時の挙動として、共有化で段階ごとの自由度は下がるため、段階別に最適化した符号化より再構成の上限は原理的に低くなり得る。論文はこの差を中間精度保存の項で抑える設計を示すが、段階別符号化との再構成品質の直接比較は主結果には含まれていない。

### 2. 残差の事前計測 — 専門家ごとの壊れやすさを表にする

この機構が観測するのは、較正データが各層の専門家へ入る入力分布であり、全精度の専門家出力と、各断片数で再構成した専門家出力の差である。保持する状態は、層、専門家、断片数を添字とする残差表であり、値は差の2乗ノルムの期待値である。計測は推論前に1回だけ行われ、モデルと一緒に保存される。具体的な較正条件は、標本512件、バッチ2件、系列長2048で、対象は最大16384トークン、専門家あたり最大256標本までとされる。ここで重要なのは、計測がゲートスコアを一切使わないことである。残差表は「その専門家が断片を削られたときにどれだけ壊れるか」という入力分布平均での性質だけを捉え、「現在のトークンにとってどれだけ大事か」は実行時の側へ分離する。この分離により、事前計測は再利用可能な静的な表で済み、トークンごとの重要度は配分時にだけ掛け合わされる。較正の雑音で断片数を増やしたのに残差が増えるような逆転が残る場合は、断片数方向に単調になるよう射影してから配分に使う。減るボトルネックは、実行時に再構成誤差を推し測る費用であり、配分器は表を引くだけで費用が得られる。追加で消費する資源は較正と計測の計算と表の保存である。失敗時の挙動として、較正データと実際の入力分布がずれれば残差の推定もずれ、配分の前提が崩れる。論文は単調射影で小さな逆転は処理するが、分布ずれそのものへの対処は示していない。

### 3. 動的精度配分器 — ゲートで重み付けした残差を予算内で最小化する

この機構が観測するのは、そのディスパッチで起動した専門家の集合と、ルータが出した現在のゲートスコアであり、保持する状態は単調射影済みの残差表である。選択されるのは専門家ごとの断片数であり、全専門家の断片数の合計が予算と一致し、各断片数は最小値と最大値の範囲に収まる。目的関数の導出は層出力の誤差から始まる。層出力の再構成誤差はゲートで重み付けした各専門家の誤差の和であり、その2乗を展開すると、ゲートの2乗と各専門家の誤差の積である対角項と、専門家同士の誤差の内積である交差項に分かれる。交差項を落とすと、費用は「現在のゲートの2乗」という実行時の係数と「残差表」という事前の値の積へ分離でき、配分問題が解ける形になる。この近似は絶対的な大きさは変えるが順位はほぼ変えず、論文の検証では正確な目的と近似した目的の順位相関が全精度水準で0.999以上だった。ただし最も小さい断片数では交差項が真の誤差の59.8パーセントを占める条件もあり、その水準は全専門家が既定で取る最小値で配分の判断が入らない、と論文は断っている。配分問題は、各専門家について断片数の選択肢から1つを選ぶ多選択ナップサック問題であり、専門家を1つずつ加えながら部分予算ごとの最小費用を保持する動的計画で解き、逆向きにたどって選択を復元する。動的計画は実現可能な全割当てを列挙するため、射影済み残差表に対する大域最適が得られる。減るボトルネックは、寄与と壊れやすさに釣り合わない一律配分による重み読み出しの無駄であり、同じ総予算でも層出力の近似誤差が小さくなる。追加で消費する資源は配分計算そのものである。計算量は起動専門家数と予算と断片数の範囲の積に比例し、単一トークンのデコードでは起動数がルーティングの選択数に等しい。論文の例では、選択数8、予算最大64、範囲7の条件でディスパッチあたり最大3584回の遷移評価である。バッチ化されたプリフィルでは起動集合がトークン全体の和集合になるため費用は増えるが、上限は層の専門家総数で抑えられ、費用はマイクロバッチのトークン数で割って償却される。失敗時の挙動として、最適なのはあくまで近似した代理目的に対してであり、真の下流損失に対してではない。またバッチが大きくなると配分費用が増える一方で専門家が多くのトークンで再利用されて利得が痩せるため、論文は配分が元を取れなくなるバッチ規模を超えたら一律配分へ戻す運用を勧めている。

### 4. 全体の流れ — 1回のディスパッチで何が起きるか

通常の混合専門家層では、ルータがトークンの状態から起動する専門家とゲートスコアを決め、選ばれた専門家の出力をゲートで重み付けて合計する。本枠組みはその直後に割当てを差し込む。まずルータの出力から起動集合とゲートが配分器へ渡る。配分器は残差表を引き、ゲートの2乗との積を費用として動的計画を解き、専門家ごとの断片数を返す。次に各専門家は、指定された個数の先頭断片だけから重みを再構成して計算する。読み出される重みビットは専門家ごとに異なるが、合計は予算どおりであり、有効重み量は平均断片数で決まる。平均断片数を2.5や4.5のような非整数に置けば、専門家間で断片数をずらすことで整数段階の間の動作点も作れる。ルータ、専門家の同一性、出力の合成方法はすべて従来どおりであり、変わるのは選ばれた専門家内部で読む量だけである。動的な選択数との組合せも付録で検証されており、累積確率の閾値で起動数を変える方式と同じ軌跡の上で比べても、配分の利得は平均で残った。さらに同じトークンあたり読み出し量で比べると、専門家を丸ごと落とすより、各専門家の精度を短くする方が品質の落ちが小さいことが示されている。

| 構成要素 | 入力・観測 | 具体的な動作 | 改善対象 | 主なトレードオフ |
|---|---|---|---|---|
| 共有尺度方式の符号化 | 専門家の全結合重みと較正入力 | 断片を追加するたびに共有尺度を共同最適化し、中間精度の保存を目的へ入れる | 尺度の保存量と精度遷移時の読み直し | 段階別の自由度を失う |
| 残差の事前計測 | 較正データでの全精度出力と再構成出力 | 層・専門家・断片数ごとの誤差の2乗平均を測り単調射影する | 実行時に誤差を推し測る費用 | 較正分布への依存 |
| 動的精度配分器 | 現在のゲートスコアと残差表 | ゲートの2乗で重み付けした費用を予算制約のもとで動的計画で最小化する | 一律配分による重み読み出しの無駄 | ディスパッチごとの計算と最初のトークンまでの時間の増加 |

## 既存研究との差

先行研究を「何を動かすか」で分けると、本論文の位置が見える。学習後の量子化の系譜は重みを配布前に圧縮する研究であり、専門家ごとの混合精度でも、動かすのは配布前に固定される割当てである。キャッシュの状態で代替精度を選ぶ方式は、動かす信号がキャッシュの当たり外れであり二値の切替えにとどまる。長期のルータ統計で高精度の常駐集合を保つ方式は、動かすのは常駐集合であり、現在のトークンへの寄与は使わない。学習した小さなネットワークでビット幅を選ぶ方式は、精度の決め方自体を学習へ埋め込み、追加の学習と引き換えに実行時の分離可能な変数として精度を外へ出さない。複数の精度を1つの符号化から出す系譜は、動かせる土台は作るが、専門家間でどう振るかは決めていない。本論文が追加したのは、この土台の上に、現在のゲートスコアと事前に測った残差という2つの信号を分離して保持し、その積を費用とする配分問題を実行時に厳密に解く層である。あわせて符号化側では、段階ごとに尺度を持つ先行の二値符号化を、精度遷移で尺度を読み直さない共有尺度方式へ改変した。論文の対照表では、再学習不要、ルータ不変、トークン単位の気付き、細かい断片予算、精度を上げる際の再取得なし、の5条件を同時に満たすのは本方式だけとされる。ただしこれは性質の対照であり、先行方式との実測の正面比較ではない点に注意が要る。

## 限界・実装状況

- 有効重み量は遅延の代理指標にすぎず、実際の提供性能はカーネルの融合、バッチ化、ディスパッチの上乗せ、装置ごとの調度にも依存するが、それらはモデル化されていない。
- 実行基盤はllama.cppの上の軽量な試作であり、配分器と可変断片の実体化は専門家のディスパッチ核へ融合されておらず、カスタムの調度器もない。観測された最初のトークンまでの時間の増加と生成速度の低下は、方式固有ではなく試作の費用として解釈すべきだと論文は述べる。
- 配分の目的は下流品質の代理であり、ゲートスコアは重要度の不完全な代理にすぎず、専門家同士の残差の相互作用は無視されている。動的計画が最適なのは射影済みの代理目的に対してであり、真の下流損失に対してではない。正解率で一律配分に負ける条件が実際に1つ観測されている。
- 残差の推定は有限の較正データに基づいており、小さな精度の逆転が生じるため単調射影で処理している。較正分布と実入力がずれた場合の挙動は検証されていない。
- 実験範囲は公開の混合専門家モデル4種と比較的絞った課題集合であり、あらゆる混合専門家構造、ルーティング設計、ハードウェア、課題領域への一般性は主張されていない。
- ルータのゲートスコアへアクセスできることが前提であり、重みが閉じた配布形態では使えない場合がある。
- 著者公式コードの公開先は一次資料に示されておらず、再現は論文の条件表と補足パッケージの記述に依存する。上流の提供基盤へ統合された実装ではない。

## 一般的な実装上の含意

推論基盤を設計する側への含意は3つある。第1に、疎な起動を持つ構造では「何を動かすか」と「動かすものをどれだけ読むか」は別の制御軸であり、後者は起動が決まった後でも独立に最適化できる。起動の判断を変えずに後段の配分だけを差し替えられる形にしておくと、既存のルーティングや学習済みモデルを壊さずに重み量と品質の交換効率を改善できる。第2に、実行時の配分は、現在の入力への寄与のような実行時信号と、圧縮のされやすさのような静的な性質を分離し、積の形で組み合わせると扱いやすい。静的な感度だけでは配分先を決め切れず、実行時信号が利得の主因だったという分離実験は、他の資源配分でも信号の寄与を分けて測るべきことを示す。第3に、精度を段階的に積み増せる符号化では、段階間で共有できる付随情報を共有し、遷移時に新しい分だけを読めば済む形にしておくことが、保存量と切替え費用の両方を下げる。あわせて、配分のような実行時制御は、バッチが大きくなると費用が増えて利得が痩せるため、元を取れる範囲を装置ごとに測り、外れたら単純な一律運用へ戻す逃げ道を最初から用意すべきである。
