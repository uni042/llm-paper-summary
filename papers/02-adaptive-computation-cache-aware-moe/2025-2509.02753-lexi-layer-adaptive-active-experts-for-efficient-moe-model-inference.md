# LExI: Layer-Adaptive Active Experts for Efficient MoE Model Inference

> 層ごとの重要度に合わせてactive expert数を変え、固定Top-kより少ない計算で品質維持を狙うMoE推論手法。

## 概要
LExIは、学習済みMoEの全層で固定top-kを使うことが冗長計算を生むとして、層ごとに異なるactive expert数を割り当てるデータ不要の最適化である。従来のinter-pruning（エキスパート全体を削除）やintra-pruning（各FFNの中間次元削減）はメモリを減らせても、vLLMなど最適化GPU実装では推論速度が伸びない場合がある。LExIは重みだけから層のtop-k感度を推定し、総active expert予算Bの範囲内で、影響の小さい層からkを下げ、敏感な層へ計算を残す。再学習やキャリブレーションデータを用いない点が特徴で、LLMだけでなくVLMにも適用する。一方、重みを削除しないため総モデルメモリは減らず、メモリ制約だけがボトルネックの端末には効きにくい。
LExIは、expert重みを削除してモデルを小さくするのではなく、同じ重みを残したまま層別の実行数を変える。したがってinter/intra pruningで生じるルータとexpert-token対応の変化を避けられる。データフリーという条件は、校正用の入力データを集めにくい配布済みモデルにも適用できることを意味する。層ごとの感度は一様ではなく、モデルによって初層・中間層・後層のどこがtop-k削減に弱いかが違うため、単一の固定kを選ぶ方式ではなく、全層の予算配分問題として定式化している。
この配分は実行時に毎回探索するものではなく、重みだけを使う一度きりのプロファイリング後に固定される。従って推論中のルータ追加遅延を抑えつつ、層別top-kという静的な実装へ落とせる。
## 手法のあらまし
第1段階では各MoE層に標準正規乱数の合成入力を与え、元のtop-k出力とk=1〜k_baseの出力との差をFrobeniusノルムで測る。これを数百万サンプルで平均し、層jの候補kに対する摂動損失D_j(k)を得る。第2段階では、Σ_j k_j=B、k_min≤k_j≤k_maxを満たす個体群を初期化し、適応度Σ_jD_j(k_j)を最小化する進化探索（トーナメント選択、均一交叉、±1変異、予算修復）を行う。したがって実モデルを何度もベンチマークせず離散配分を探索できる。評価で試すBはOLMoE 64/72/100、Qwen1.5 48/56/72/80、MiniCPM 50/60/70、Mixtral 40/48/56、DeepSeek 78/104/130などで、ベースラインtop-kを層一律に変えるのではなく、予算を層間で組み替える。感度形状はモデルごとに異なり、Mixtralは後層、Qwenは初期層、DeepSeekは鐘形となる。
Monte Carloの合成入力はモデルの実データ分布を近似するためのものではなく、top-kを変えた出力の相対的な摂動を層ごとに比較する代理である。これにより、各候補kの損失表を一度作れば、Bを変えた進化探索を再実行できる。探索は各層の整数kを変更するたび、別層で反対符号の変更を入れて総予算を固定する。性能を直接評価する勾配最適化ではないため高速だが、Frobenius距離の小ささがタスク精度・throughputの双方を保証するわけではない。トップk上限は元モデルのkで、専門家を削除せずゲート選択だけを調整する。
## 評価

### まず見るところ
- **結論:** 層ごとにtop-k感度が違うことを利用すると、一律pruningより同じ速度帯で品質を保ちやすい。
- **速度・効率:** 実throughputでもpruning baselineより良いPareto点を示す。
- **品質:** 同速度のinter/intra pruningより大幅に高い品質を示すモデルが多い。
- **メモリ:** **重み自体は削除しないためモデルメモリは減らない**。VRAM容量問題の解決策ではなくcompute削減手法。
- **評価の強さ／注意点:** **実機**。data-freeだが合成入力の摂動を品質代理にしており、top-k変更余地が小さいモデルでは効果も小さい。
