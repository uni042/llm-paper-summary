# DynaMo: Runtime Switchable Quantization for MoE with Cross-Dataset Adaptation（旧題 MoQa）

> データ分布に応じてexpertのbit群とsalient channelを実行時に切り替え、再較正コストを抑えるMoE量子化方式。

## 概要
版更新で実装の焦点も変わっており、v1のMoQaは閾値・Jenksによる二群分割を中心に説明するのに対し、v3 DynaMoは四bit群、FP16 channel cache、dataset-change時のswitchを追加する。v1の名称MoQaとv3のDynaMoは同一arXiv IDの版違いなので、文献DBでは原題・IDを保ちつつ参照版を明記する。
MoQaの問題設定は、単一データセットの代表較正で全expertを決める従来PTQに対し、データ分布が変わるたびに重要expertが入れ替わることを明示した点にある。したがって静的bit配分の平均精度だけでなく、新データへの切替コストとキャッシュ量も品質–コスト評価に含める。
MoQaは、MoEの「データ→expert→channel」がmany-to-manyで、データセットが変わるとexpert重要度も変わることを量子化設計に組み込む研究である。v1/v2の題名はMoQaだったが、v3（2026-01-09、DATE 2026採択）で「DynaMo: Runtime Switchable Quantization for MoE with Cross-Dataset Adaptation」に改題された。従来GPTQの単一較正データ固定やMoEPTQ-Rのランダムexpert分割では、WikiText2とC4のようなデータ分布差に適応できない。そこで、(1)データ分布、(2)データ–model対応、(3)expert間model–model相関を多段分析し、expert/channel significanceを推定する。静的にはexpert-level INT2/4/6/8 mixed precisionを複数データセットに共通化し、動的には新データセットに応じてsalient channel約1%だけFP16キャッシュから再量子化する。v1の名称MoQaとv3のDynaMoは同一arXiv IDの版違いであり、Notionでは版と改題を明記するのが望ましい。公式コードは検索で確認できず、論文のPyTorch実装記述のみである。
## 手法のあらまし
各clusterのbitは単にexpert頻度を順位付けしたものではなく、複数データセットでのsignificanceと相関を統合した結果である。そのため、あるデータで高頻度でも他データで低重要なexpertを一律に高bitへ固定することを避けられる。
Stage 1ではtop-K活性化を考慮したtoken utilizationをlong-tail分布でモデル化し、tailの過大影響をα=0.3で再重み付けする。Stage 2ではhookでMoEの出力logitとroutingを追跡し、各tokenがどのexpert/channelへ流れたかを分解する。Stage 3では複数データセットのexpert significanceをjoint distributionにフィットし、cosine similarityでexpert weight相関を確認する。v1の量子化はsignificance差が大きいPattern 1なら平均μを閾値にexpertを二群化、差が小さいPattern 2ならJenks segmentationで分割し、INT8/INT4などの高低bitを割り当てる。v3 DynaMoは四群のfuzzy clustering（INT8、INT6、INT4、INT2）に拡張し、最重要clusterをINT8、最低をINT2、境界expertは低bit優先にする。新データでは各expertのsignificanceを再計算し、FP16でキャッシュしたchannel約1%だけを該当bitへ再量子化するため、全重み再較正を避ける。低bit重みはINT32へpackし、CUDA上でunpack＋FP16 MMAを融合する。静的基準量子化と動的channel switchingを分離することが、expert-level割当とデータ適応を両立する要点である。
## 評価
v1はOLMoE（16層/64 experts/top-8、6.9B、1.3B active）、MoE-Girl（同構成）、Qwen1.5-MoE（24層/64 experts＋4 shared/top-4、2.7B）をPyTorchで評価し、GPTQとランダムexpert分割のMoEPTQ-Rを比較した。WikiText2/C4の約3 bitでは、OLMoEのGPTQ PPL 11.65/18.86に対しMoQa 10.59/18.42、MoE-Girlは12.77/21.38に対し11.24/20.89、Qwenは10.99/20.84に対し8.51/15.24だった。MoEPTQ-R比のPPL改善は各モデルで3.97/4.28程度まで達し、zero-shot（ARC、RTE、PIQA、COPA、CB等）平均もOLMoEでGPTQ比+1.58%、Qwen1.5-MoEでGPTQ比+1.91%、MoEPTQ-R比+8.91%となった。v3 DynaMoはDS-MoE-16Bも加え、約3 bitでGPTQ比PPLを2.78–4.54下げ、zero-shot精度を1.85–3.77%上げる。A100上の生成1024 tokenではFP16比2.91–3.08×、channel switchingのオンラインoverheadは7.73–10.68%、多段分析のoffline overheadは14.90–17.33%。キャッシュは7Bで152.8 MB（重みの1.02%）と小さい。従って品質-cost面の利得は大きいが、動的切替はデータセット変更時のみで、継続的token単位の再量子化ではない。
