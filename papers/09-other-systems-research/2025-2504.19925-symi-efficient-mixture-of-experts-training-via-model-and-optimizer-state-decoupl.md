# SYMI: Efficient Mixture-of-Experts Training via Model and Optimizer State Decoupling

> expert重みとoptimizer stateを分離し、動的なexpert複製・再配置時の状態移送を避けてMoE学習を効率化するシステム。

## 概要
SYMI（Symi）は、MoE expert の複製数・GPU配置をtoken人気度に合わせて毎イテレーション更新し、負荷偏りによる遅延とtoken dropを減らす学習システムである。固定複製では人気expertを持つGPUが遅れ、容量超過tokenのdropが収束・品質を損なう。GPT-Small（32 experts）では人気度が3イテレーションで16倍以上変動し、capacity factor 1の平均token survivalは44.90%、目標lossまで618 iterだった。SYMIの発見は、動的なexpert model weightと巨大なoptimizer stateを分離すれば、optimizerを移動せずに重みだけを再配置できることだ。Adam混合精度では重み2B、optimizer state 16B/parameterで、8Bモデルのoptimizerだけで96.6GB（勾配除外）となる。SYMIはactivationをNVMeに逃がす方式ではなく、expert weight／gradient通信を再設計し、optimizer stateを主にCPU host DRAMへ均等分割する。評価は最終タスク精度ではなく、drop削減と同一lossへの到達時間を品質・収束の代理として測る。
## 手法のあらまし
optimizer stateを全rank（host memory）へ均等・静的にシャードし、GPU上のexpert slot割当から切り離す。router後に集約した人気度を次iterの予測として、複製数を比例配分（各expert最低1）し、同一expertを同rankの連続slotへ置く。前iterのoptimizer passで更新重みを既存のweight通信に載せ替えるため、再配置に追加のデータ量はない。gradientはoptimizer shardごとに送信元を選び、local転送を優先、remoteはround-robinでhotspotを分散する。intra+inter-rank all-reduceでは同rankのslotを代表slotに集約してからrank間reduceし、GPU内複製も許す。動的group生成を避け、連続rankのgroupを初期化時に最大N(N−1)/2個登録する。GPT3-175B級（E=64、N=2048、s=2、PCIe64GB/s、network400Gbps）の例ではbaseline/SYMIとも通信量27TB/iter、SYMIの通信時間は約0.273秒対0.269秒（+1.52%）。optimizerをHBMやdisaggregated memoryに置く実装にも論理的には対応するが、CPU/NVMe pagingやGDSは扱わない。
## 評価
GPT Small/Medium/Large（125M/350M/760M）をMMLU、seq512、global batch64、16 GPUで学習。Top-k1、16 experts、4 slots/GPU、capacity1.0、auxiliary loss1e−5。DeepSpeedはZeRO-1（optimizerをCPU DRAM）、比較はFlexMoEの再配置間隔100/50/10 iter。GPT-Smallのloss4.0到達はDeepSpeed147.84分、FlexMoE-100/50/10は145.42/141.60/138.61分、SYMI102.68分（DeepSpeed比30.5%、FlexMoE比25.9〜29.4%短縮）。必要iterは28.5%少なく、token dropはDeepSpeed／FlexMoE-100/50/10比69/64/62/43%減。平均iter latencyもSmall/Medium/Largeで2.8/3.2/9.3%短縮、代表通信時間は0.269対0.273秒（+1.52%）。FlexMoE-10はiter数が同等でも再配置時latencyが大きい。loss曲線はDeepSpeedに近く、drop減少で同一token budgetのlossがやや低い。限界は前iter人気度予測が急変routerで外れる可能性、host DRAM・PCIe制約、最大760M GPTとMMLU中心で実LLMの最終精度を未測定な点。optimizerを移動しないためGPU/HBM・CPU・network配置は別途必要である。
