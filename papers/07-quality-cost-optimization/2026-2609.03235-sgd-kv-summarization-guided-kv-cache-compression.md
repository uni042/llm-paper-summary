# SGD-KV: Summarization Guided KV Cache Compression

> summarization能力の高いattention headへKV budgetを重点配分し、最大75%のKV cache削減でlong-context品質を維持するhead-aware圧縮方式。

## 書誌情報

- 公開日: 2026-09-03
- 状態: NeurIPS 2026 Efficient Reasoning Workshop Accepted
- arXiv: 2609.03235
- 著者: Zeyu Liuほか
- 主題: Quality-cost optimization / KV cache compression

## 概要

SGD-KVは、attention headごとの機能差を利用してKV cacheの保存量を非一様に割り当てるlong-context推論向け圧縮方式である。全headへ同じbudgetを配るのではなく、summarization能力が高いheadへより多くのKV budgetを割り当てる。

## 手法

Chunk summarizationの診断taskからhead別のsummarization scoreを計算し、総KV budgetをそのscore分布に応じてhead間へ配分する。各headの内部ではattention scoreに基づいて保持tokenを選択する。

追加のモデル学習を必要とせず、既存モデルへ後付けできる設計となっている。

## 評価

Qwen2.5-7B-Instruct-1MとQwen3-32Bを用い、MRCR、ETHIC、BABILongなどで最大1M contextを評価している。

- 最大 **75%のKV cache memory削減**を報告。
- 25% budget条件でも、ETHIC平均はQwen3-32BでFullKV **28.53** に対し **28.38** とほぼ維持。

## スコープと制約

- 主眼はhead間のKV budget allocationであり、weight offloadやMoE expert residencyは扱わない。
- CPU offload、SSD / NVMe offload、CXL memory、HBFは対象外。
- 論文中の主な効果はKV memory削減とlong-context品質維持であり、expert prefetchやrouting最適化とは別系統である。

## 実装上の含意

attention headごとの機能的重要度を明示的なresource allocation signalとして使えることを示す。serving engineへ実装する場合は、head別budget管理とhead内token selectionをKV cache managerへ組み込む必要がある。
