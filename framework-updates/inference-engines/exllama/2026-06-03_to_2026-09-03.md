# ExLlama — 2026-06-03〜2026-09-03

ExLlamaV2には期間内の本質的更新がない。後継のExLlamaV3を同じ系統として追跡する。

## 主要更新

- **2026-07-25 — ExLlamaV3 v1.2.0（released）**: experimental expert-layer CPU offloadとdynamic draft windowを追加。[release](https://github.com/turboderp-org/exllamav3/releases/tag/v1.2.0)
- **2026-07-31 — v1.3.0（released）**: 二層目のCPU KV cacheと、page／checkpointのeviction policyを追加。[release](https://github.com/turboderp-org/exllamav3/releases/tag/v1.3.0)
- **2026-08-06 — v1.4.0（released）**: AVX512 CPU offloadとprefillを高速化。公式数値なし。[release](https://github.com/turboderp-org/exllamav3/releases/tag/v1.4.0)
- **2026-08-23 — v1.4.3（released）**: partial CPU layer expert offloadを動的配置方式へ変更し、dynamic draft sizingに自己較正confidence thresholdを追加。TP時のCPU cache offloadにも対応。[release](https://github.com/turboderp-org/exllamav3/releases/tag/v1.4.3)
- **2026-08-31 — v1.4.5（released）**: MoE MTPを高速化し、MoE layerをslab allocation化してVRAMの形状不整列損失を削減。[release](https://github.com/turboderp-org/exllamav3/releases/tag/v1.4.5)
- **2026-09-02 — v1.4.6（released）**: Windows向けexperimental n-gram streamingを追加。[release](https://github.com/turboderp-org/exllamav3/releases/tag/v1.4.6)
