# ROCm — 2026-06-03〜2026-09-03

ROCm Core SDK、RCCL、AITER、Composable Kernelのうち、LLM推論・学習へ直接関係する更新をまとめる。

## GA／release済み

- **2026-07-16 — ROCm Core SDK 7.14.0**: HIP execution contextによるCU分割、batch async memory API、HIP Graph replay改善、hipFileのstorage→GPU direct transferを追加。RCCLにはhierarchical AllGather、direct reduce-scatter、Copy Engine collectiveが入った。数値なし。[release](https://github.com/ROCm/legacy-rocm-build/releases/tag/rocm-7.14.0)
- **2026-07-27〜09-02 — AITER v0.1.19〜0.1.21**: low-bit MoE、fused route／quant／scatter、FP4 KV compression、paged-MQA、sparse MLA backward、MXFP8 passthrough fused MoEを追加。[v0.1.19](https://github.com/ROCm/aiter/releases/tag/v0.1.19) [v0.1.20](https://github.com/ROCm/aiter/releases/tag/v0.1.20) [v0.1.21](https://github.com/ROCm/aiter/releases/tag/v0.1.21)
- **AITER #4307（merged）**: FP4 MoE decode GEMM2をMI355Xでtoken bucket別5〜22%改善。vLLM E2Eは2.4%向上。[PR #4307](https://github.com/ROCm/aiter/pull/4307)
- **AITER #4954（merged）**: EP all-to-all後のMXFP8 activationを再量子化せずscaleだけ再配置。DeepSeek-V4-Pro TP8／DP8／EP8でthroughput 6.4〜9.8%、TPOT 6.2〜9.3%改善。[PR #4954](https://github.com/ROCm/aiter/pull/4954)
- **AITER #4766（merged）**: sparse MLA training backwardを追加。MI355XでT=4096／top-k=1024時5.261 ms、522 TFLOPS。[PR #4766](https://github.com/ROCm/aiter/pull/4766)
- **AITER #4804（merged）**: gfx1250 BF16 GEMMを専用化し、120 shapesのkernel time geomean 6.82倍。[PR #4804](https://github.com/ROCm/aiter/pull/4804)
