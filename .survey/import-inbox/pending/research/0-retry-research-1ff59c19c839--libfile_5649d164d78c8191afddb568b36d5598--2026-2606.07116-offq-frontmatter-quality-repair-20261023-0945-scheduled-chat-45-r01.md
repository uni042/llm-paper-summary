# OffQ：構造的外れ値をオフセットへ変換するLLMの4ビット量子化

## 概要

低ビット量子化は、大規模言語モデル（LLM）の重み転送量と行列積の費用を削減する。しかし、重みだけを4ビットにしても、活性化値やキー・バリューキャッシュ（KVキャッシュ）が高精度のままなら、全体の転送量と実行形式は混在する。OffQが対象とするのは、重み・活性化値・KVキャッシュをすべて4ビットにする **W4A4KV4** という難しい条件である。活性化値の少数のチャネルに大きな外れ値があると、均一間隔の量子化格子の刻み幅が大きくなり、通常の値が粗く丸められてモデル品質が悪化する。

OffQの特徴は、外れ値を高精度の別経路に逃がすのではなく、**共通の加算オフセットへ変換して非対称量子化のゼロ点に吸収する**ことにある。最大外れ値を持つトークンだけで主成分分析を行い、外れ値方向を少数のチャネルへ集中させる。次にチャネルを群へ分け、各群の先頭に外れ値チャネルを配置して、先頭行がすべて同じ符号のアダマール変換をかける。これにより外れ値の寄与が群内の全チャネルに共通のずれとなり、残差の変動幅を小さくしたまま量子化できる。

一次論文の表1では、Llama 3-8BのWikiText困惑度が16ビットの6.1、比較方式ResQの7.1に対してOffQは6.98、8課題平均ゼロショット正解率はResQの63.91%に対して65.49%だった。Qwen 2.5-7BでもResQの困惑度8.2・正解率65.29%に対し、OffQは7.66・66.16%だった。ただしこれは**量子化後の品質指標**であり、論文は実配備時の遅延を測定していない。したがって「4ビットなので推論が何倍高速」とは結論できない。

## 問題設定と既存方式の不足

一様な$b$ビット非対称量子化は、実数値$x$を刻み幅$s$とゼロ点$z$を使って$\mathrm{clamp}(\mathrm{round}(x/s)+z,0,2^b-1)$へ写す。活性化値の大部分が小さくても、一部の値が極端に大きいと必要な表現範囲が広がり、4ビットの16段階では通常値の違いを保持しにくくなる。重みだけの量子化はこの活性化外れ値を解決せず、KVキャッシュを低ビット化する際にも別の誤差が生じる。

QuaRotやSpinQuantは直交回転で外れ値を分散し、量子化しやすい分布へ近づける。だが、回転後にも高い分散が残る。ResQは一部のチャネルを高精度で処理するため精度を改善できるが、均一4ビット演算という条件を緩める。学習可能な回転や非一様格子を使う方法は、最適化の追加費用や専用実装を要する。OffQは、回転で外れ値を単に薄めるのでなく、量子化器が元から持つゼロ点へ外れ値を吸収することで、混合精度や非一様格子なしの品質改善を狙う。

構造的外れ値の方向が層・トークン間で共有されるという観測を利用する点も重要である。個々の極端なトークンを動的に検出して別の行列積を行う方式ではなく、較正時に共通方向を求め、直交変換を重みへ可能な限り融合する。追加の前処理と群ごとの量子化メタデータを引き受ける代わりに、推論時の演算精度を揃える設計である。

## 手法

### 1. 最大外れ値トークンを使うTop-1 PCA

まず各線形層の入力活性化値を較正用の$N$系列・各$L$トークンから収集する。各系列についてチャネル方向の最大絶対値、すなわち$L_\infty$ノルムが最も大きい**1トークンだけ**を選び、$N\times D$行列を作る。これを使って共分散行列$C=X^\top X/N$を求め、固有ベクトル行列$U$で活性化値を回転する。第1主成分が極端な活性化の方向を捉え、$XU$の第1チャネルへ外れ値が集中する。

普通の主成分分析で全トークンを平均すると、大多数の正常トークンが統計を支配し、外れ値の方向がぼやける。Top-1選別はこの干渉を避けるための機構である。論文は正規化層のスケールを隣接重みへ融合した前正規化構造を前提に、外れ値トークンが大きな$L_\infty$ノルムを持つ理由を説明している。第1方向だけで全外れ値を捉えられない場合は、上位$G$方向を次段の複数群へ配る。

### 2. 群分割と外れ値チャネルの並べ替え

次に回転後の$D$チャネルを$G$個の群へ分割する。各群の先頭には外れ値の大きいチャネルを1つずつ配置し、残りの通常チャネルを並べ替えて充填する。群ごとに異なるスケールとゼロ点を持てるため、群の先頭チャネルから生じる大きな共通オフセットを別々に扱える。

この配置は単なる並べ替えの見栄えではない。後段の直交変換では**先頭チャネルの値が群内のすべてのチャネルに同じ符号で寄与する**必要がある。外れ値が先頭以外へ残ると、寄与の符号がばらけ、単一のゼロ点で吸収できない。通常チャネルを大きさ順に配る方式は、交互に配るジグザグ方式より実験で良好だった。群を細かくすれば吸収可能な外れ値方向は増えるが、スケール・ゼロ点の保存量と処理費用も増す。

### 3. アダマール回転によるオフセット吸収

群の先頭に外れ値$x_1$を置いた後、先頭行がすべて$+1$のアダマール行列$H$を$1/\sqrt{D_g}$で正規化して掛ける。群の次元を$D_g$とすると、外れ値の寄与は各出力チャネルに共通の$x_1/\sqrt{D_g}$となる。残りのチャネルの寄与だけが符号を変えて分布するため、出力は「共通のずれ＋比較的小さい残差」に分解される。

2次元なら$[x_1,x_2]H/\sqrt{2}=[(x_1+x_2)/\sqrt{2},(x_1-x_2)/\sqrt{2}]$である。両成分に共通の$x_1/\sqrt{2}$を量子化ゼロ点側で吸収できれば、量子化格子は主に$x_2$由来の小さな変動を表せばよい。この操作は外れ値の情報を無条件に捨てるのではなく、量子化器の**位置パラメータ**へ移すものである。ただしゼロ点の離散化・群単位表現による誤差が完全に消えるわけではない。

### 4. 注意・フィードフォワード・KVキャッシュへの統合

注意層とフィードフォワード層の共通入力では、複数層の入力を集約して共有回転$U_1$を求める。出力射影$W_O$や下降射影$W_D$の重みに回転・並べ替え・群アダマール変換を掛け、$W_Q,W_K,W_V,W_U,W_G$側には逆変換を融合する。対応する入出力の直交変換を対にすることで、量子化前のネットワーク機能を保ったまま活性化値の座標系を変える。

値キャッシュにはヘッドごとのランダム回転を重みへ融合する。キーキャッシュは回転位置埋め込み（RoPE）の後で扱うためオンライン変換が必要になる。Qwen 2.5のように注意層のバイアス由来の外れ値がある場合は、キー側にも層・ヘッドごとのTop-1 PCAを追加する。下降射影の入力は直前の要素ごとの乗算を越えて回転を押し込めないため、通常のTop-1 PCAではなくチャネル別最大絶対値で外れ値を選び、群アダマール変換をオンライン実行する。

最後に変換済み重みをGPTQで4ビット量子化する。論文の図2では、大半の回転を重みへ融合する一方、**3種類のオンラインアダマール変換は残る**と明示している。したがって「追加演算が完全にゼロ」ではない。実装上は、群ごとの非対称活性化量子化、KVキャッシュ量子化、オンライン変換に対応するカーネルが必要になる。

## 評価

評価は量子化後の困惑度（Perplexity）と8種類のゼロショット課題の平均正答率を中心とし、推論時間そのものの測定ではない。重み・活性化・鍵値キャッシュをいずれも4ビット化するW4A4KV4条件を統一し、同じモデル系列・同じ指標で比較する必要がある。特にLlama 3-70BではOffQの平均正答率70.63%がResQの71.14%より低く、全モデルで一律に最良という解釈は避ける。

### 評価条件

原著の表1・表2および実験節を照合した。実装はTransformersとPyTorchで、ResQの公開実装を土台とする。重みは各方式の比較設定に従って4ビット、活性化値とKVキャッシュも4ビットとする。OffQの活性化量子化は**群サイズ128の非対称群別量子化**、重みはチャネル別対称量子化である。比較方式の活性化量子化は公式実装に従うトークン別非対称方式であり、**量子化粒度が同一ではない**ことに注意する。GPTQはOSTQuantを除く比較方式にも適用されている。

| 観点 | 原著での設定 |
|---|---|
| モデル | Llama 2（7B、13B）、Llama 3（8B、70B）、Llama 3.2（1B、3B）、Qwen 2.5（1.5B、3B、7B、14B、32B、72B） |
| 量子化 | W4A4KV4、OffQ活性化群サイズ128、重みはチャネル別4ビット |
| 言語モデル指標 | WikiTextの困惑度（小さいほど良い） |
| 推論品質指標 | ARC-e、ARC-c、BoolQ、HellaSwag、OpenBookQA、PIQA、SIQA、WinoGrandeのゼロショット平均（大きいほど良い） |
| 主な比較 | 16ビット、GPTQ、QUIK、QuaRot、SpinQuant、DFRot、KurTail、OSTQuant、ResQ |
| 実装 | HuggingFace Transformers、PyTorch、ResQ実装ベース |
| 性能測定の範囲 | 困惑度と正解率を中心とする品質比較。GPU実機でのエンドツーエンド遅延は報告なし |

群サイズ128でスケールとゼロ点を各16ビット保存すると、活性化1要素当たりの平均記憶量は$(4\times128+16\times2)/128=4.25$ビットとなる。これは16ビットより小さいが、単純な4.00ビットと同一ではない。またResQは一部チャネルを高精度で保持し、有効ビット幅が4.5ビットとなるため、両者の品質比較は「完全に同じ精度・メモリ予算」の比較ではない。比較表の一部の既存方式の値は**先行論文から引用**されており、全行を著者が同一コードで再測定したと解釈しない。

### 主要結果と負の結果

以下は原著表1のW4A4KV4条件から選んだ値であり、困惑度（PPL）は小さいほど、8課題平均正解率は大きいほど良い。倍率は推論速度ではなく、品質差の比較である。

|---|---:|---:|---:|---|
| Llama 3-8B・PPL | 6.10 | 7.10 | **6.98** | ResQより0.12低いが、16ビットには未到達 |
| Llama 3-8B・8課題平均正解率 | 67.09% | 63.91% | **65.49%** | ResQより1.58ポイント高い |
| Llama 3-70B・PPL | 2.90 | 4.10 | **3.88** | 困惑度は改善 |
| Llama 3-70B・8課題平均正解率 | 73.09% | **71.14%** | 70.63% | **ResQより0.51ポイント悪い** |
| Qwen 2.5-7B・PPL | 6.80 | 8.20 | **7.66** | ResQより0.54低い |
| Qwen 2.5-7B・8課題平均正解率 | 68.45% | 65.29% | **66.16%** | ResQより0.87ポイント高い |
| Qwen 2.5-72B・PPL | 3.90 | 4.60 | **4.29** | 大規模モデルでも改善 |

単純なGPTQをW4A4KV4に適用するとLlama 3-8Bの困惑度は166.3、Qwen 2.5-7Bでは13,594まで悪化する。これに対してOffQはそれぞれ6.98と7.66であり、外れ値への対応が極低ビット量子化の成立条件であることが分かる。ただし表中のResQは高精度チャネルを併用するため、OffQの強みは単なる精度の一律優位ではなく、**均一4ビット演算を維持する条件下での品質**にある。

### 構成要素除去実験

Llama 3-8Bの表2では、完全版OffQの困惑度6.98、8課題平均65.49%に対し、Top-1トークン選別をなくして全トークンのPCAを使うと8.27、63.13%へ悪化する。つまり単に回転を加えるだけでなく、極端なトークンの方向を正しく抽出することが本質的である。通常チャネルの群割当をジグザグに変えると7.03、64.95%となり、群内配置も結果に寄与する。

アダマール構造を部分ランダム回転へ置き換えると困惑度7.00でほぼ同等だが、正解率は64.40%へ低下した。これはオフセットを作るという条件だけで全てが決まるわけではないことを示す。群を細かくすると外れ値方向を多く吸収でき、困惑度は改善しやすい一方、量子化メタデータと処理費用が増す。著者は群サイズ128を品質とメモリ費用の折衷として採用した。

## 既存研究との差と適用判断

QuaRotやSpinQuantは回転による外れ値の分散、ResQは高精度チャネルの保持、OSTQuantは回転とスケーリングの組合せに重きを置く。OffQは**外れ値を少数チャネルへ集中させてから共通オフセットに変える**という逆方向の発想で、ゼロ点を持つ標準的な非対称量子化器の表現力を活用する。Top-1 PCAによる外れ値方向の抽出、群への割当、先頭行制約付きアダマール回転、重みへの等価変換融合が連続して初めて機能する。

推論実装の観点では、W4A4KV4の品質維持とメモリ削減に有望だが、実配備速度を論文だけから見積もることはできない。群別非対称量子化の効率、オンライン変換、ゼロ点の扱い、低ビット行列積カーネルの実装状況が重要である。MXFP4やNVFP4へ同じ吸収法を適用するには、群・ブロックごとのゼロ点を持つ非対称形式への拡張が必要で、原著では今後の課題としている。

## 限界

第一に、著者は実環境の推論遅延を報告していない。論文の「低ビット演算を維持する」という設計上の性質と、実際のトークン毎秒・初回トークン遅延・消費電力・スループット改善は別物である。特に群別量子化とオンラインアダマール変換のカーネル費用を含めたエンドツーエンドの評価が必要になる。

第二に、比較の品質は全モデル・全指標で一律に勝つわけではない。Llama 3-70Bの8課題平均はResQより低く、Llama 2-13Bの困惑度も僅かに悪い。16ビットの品質にはなお差が残り、推論タスクやモデル規模に応じた検証を省略できない。第三に、モデルが前正規化構造や特定の外れ値分布を持つという仮定に依存する。極端な外れ値が多数の独立方向へ分散する場合、群数を増やす必要があり、メタデータと実行費用が増す。

第四に、非一様量子化、より新しい重み量子化、学習可能な回転との組合せ、視覚Transformerへの拡張は原著では未検証である。コードの公開URLも一次論文から確認できなかった。研究の主たる証拠は量子化後の困惑度とゼロショット精度であり、運用負荷やGPU間転送、長文脈サービング、量子化前処理の総費用に関する定量的な結論はここから導かない。
