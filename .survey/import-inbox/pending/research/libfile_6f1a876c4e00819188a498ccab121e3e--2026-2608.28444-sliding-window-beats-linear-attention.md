# Sliding-window beats linear attention

## 概要
標準softmax attentionではcontextが伸びるほど保持するkey/valueが増え、decode時のmemory trafficも増える。これを固定状態へ置き換えるlinear attentionは魅力的だが、既存checkpointをlinear architectureへ変換するには数千万〜数十億tokenのpost-trainingを要する場合がある。本論文は、より単純なSliding Window Attention (SWA)を十分強いbaselineとして比較していないことを問題視する。

提案というより再基準化研究であり、既存weightを変えず、各queryが直近w tokenと先頭4 tokenだけを見るSWA(w,4)を適用する。先頭4 tokenはattention sinkとして常に残す。短文脈では6 benchmark平均でfull-attention teacherの99.0%を回復し、長文脈reasoningでは比較対象linear attentionより2〜10倍高いaccuracyを報告する。

## 問題設定
linear attentionはKV cacheの長さ依存を除ける一方、pretrained softmax modelのattention functionを別形式へ近似する必要があり、post-training費用と品質損失がある。SWAは単に過去w tokenへsoftmax attentionを制限するため追加学習が不要だが、先頭tokenをwindowから落とすと既存modelで大きく品質が崩れることが知られている。

そこで先頭4 tokenを常時可視なsinkとして固定する。局所window外の情報は直接参照できないが、layerを重ねると情報は局所attentionを通じて伝播できる。これは固定sizeのKV working setを得る最小限の変更である。

## 手法
SWA(w,4)では各decode位置が直近w tokenとsequence先頭4 tokenにだけ通常のsoftmax attentionを行う。weight、attention kernelの意味、model architectureは変更せず、maskと保持KV範囲だけを変える。したがってlinearization用の蒸留やLoRA post-trainingを必要としない。

比較ではLoLCATs、Liger-GLA、QRWKV6等のpost-trained linear attention方式と、元のfull attention teacherを置く。短文脈一般能力だけでなく、needle retrievalとBABILongでwindowを越えた情報利用を測る。

## 評価条件
|項目|条件|
|---|---|
|model|Llama、Qwen、Phi等の複数pretrained LLM|
|SWA|局所window + 4 sink token|
|短文脈|MMLU、ARC-C/E、HellaSwag、PIQA、WinoGrande|
|長文脈|Single Needle-in-a-Haystack、BABILong|
|効率microbenchmark|4-layer、hidden 1024、16 heads、FP16、batch 1|
|GPU|RTX PRO 6000 Blackwell Max-Q|
|kernel|FA/SWAはFlashAttention、linear系はThunderKittens|

## 主要結果
|条件|結果|解釈|
|---|---:|---|
|6 benchmark平均|teacherの99.0%回復|追加学習なしでも短文脈能力をほぼ維持|
|MMLU 5-shot|teacherの93.2%|平均よりMMLUの低下は大きい|
|11 model case|9件で非teacher方式中最高平均|linear retrofitに対する強いbaseline|
|長文脈reasoning|linear方式比2〜10×のaccuracy|固定windowでもtested retrofitより高い|
|4K S-NIAH、window 512例|SWA 23.0%、LoLCATs(+SWA) 5.8%、full 99.8%|linear方式より良いがfull attentionとの差は大きい|
|効率microbenchmark|window超過後memoryほぼ定数、SWAがtested方式中最速|固定working setの利点を確認|

## 既存研究との差
linear attention研究はattention演算そのものを再設計し、固定size stateへ情報を畳み込む。本研究のSWAはsoftmax attentionを保持し、可視範囲だけを切るため学習不要である。新規architectureを提案するより、post-training linearizationが超えるべきbaselineを引き上げた点が主貢献である。

## 限界
短文脈比較の一部は各linear attention論文が報告したscoreを引用しており、prompt templateやevaluation harnessが完全一致しない。長文脈ではfull attentionを大きく下回る条件もある。効率測定は4-layer toy model中心で、production serving全体のthroughputを直接保証しない。hybrid full-attention layerやmultimodal workloadも主要評価範囲外である。
