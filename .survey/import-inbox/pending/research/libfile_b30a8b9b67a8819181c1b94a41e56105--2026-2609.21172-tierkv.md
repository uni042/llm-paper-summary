# TierKV: Long-Context On-Device LLMs via Predictive Multi-Tier KV Caching

## 概要
端末LLMではweightだけでなく、文脈長に比例するKV cacheがRAMを圧迫する。token evictionは不可逆、低ランク圧縮は再構築cost、flash offloadはI/O stallという別々の弱点がある。TierKVはこれらを排他的に選ばず、1 requestのKVを3 tierへ同時配置する。

Tier-0は重要・最近tokenをexact FP16でRAM保持、Tier-1はSVD低ランク表現をRAM保持、Tier-2は長尾KVをflashへ退避する。Predictive Multi-Tier Cache Optimization（PMCO）はprefill時のhidden stateと履歴から将来長を予測し、memory/accuracy budget下で境界とlayer別rankをdecode前に決める。

## 問題設定
reactive evictionは「将来必要になるtoken」を現在のattentionだけで決める循環問題があり、捨てたtokenを戻せない。flashだけではI/O、SVDだけではreconstructionが律速になる。TierKVはfull contextへのaccessを維持しつつ、hotnessに応じてtierを分担させる。

## 手法
### 3-tier placement
sequence軸上の境界(n,m)でexact/low-rank/flashを分ける。accuracy modelとdevice memory budgetを使い、compression levelごとのlayer rankも選ぶ。solverは小さい離散候補からclosed-formに近い形でruntime決定する。

### Predictive allocation
decode開始前にprompt fingerprint/entropyと利用履歴から将来output/cache需要を推定する。これにより、cacheが溢れてから追い出すのではなく、最初から必要RAM量を予約する。

### Fused attentionとI/O overlap
低ランクK/Vを完全復元してHBM/RAMへ書き戻すのではなく、split-path attention kernelでon-chip reconstructionとlatent-space accumulationを行う。flash prefetchはSVD計算等のidle bubbleへ重畳し、Llama-3.2-1B 2K decode例で94.4% prefetch hitを報告する。

## 評価条件
| 項目 | 条件 |
|---|---|
| model | text/vision/audioを含む8モデル |
| hardware | 3種mobile SoC |
| 比較 | MLC-LLM、llama.cpp等 |
| 指標 | prefill/decode throughput、RAM KV、最大context、accuracy |
| cache | FP16 exact + SVD low-rank + flash |
| quantization | Q8 weightとの直交性も評価 |

## 主要結果
RAM常駐KVを12.5〜34%削減し、同じ物理memory budgetで最大2.6倍長いcontextを扱う。prefill throughputは既存mobile framework比最大17.6倍。Llama-3.2-3BではFP16 baselineが約7K tokenでmemory limitへ達するのに対し、TierKVは12K超まで伸びる例を示す。

一方、accuracy低下は多くの条件で3 percentage point未満だが、Qwen2.5-3Bでは20% memory saving時にMMLU 7.0pp、ARC-C 6.6pp、GSM8k 7.0pp低下する条件があり、「常にminor」とは言えない。

## 既存研究との差
単一のtoken eviction、低ランクKV、flash offloadではなく、3方式を一つのallocation problemとして解く点が中心差である。特にdecode中のreactive policyではなくprefill時点で需要を予測し、tier boundaryとrankを同時決定する。

## 限界
length predictorはLMSYS/GSM8k/LongWriter-6k等限られた分布での評価で、distribution shift時の予測誤差がallocationへどう伝播するかは十分定量化されていない。accuracy constraintもoffline fitに依存し、Qwen2.5-3Bのように7pp級の低下が出る条件がある。mobile SoCではthermal throttlingも観測され、長時間実行の再現性には端末熱状態が影響する。
