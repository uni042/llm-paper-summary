# SemKV: Semantic Mixed-Precision KV Cache Quantization Guided by the Quality Cliff for Long-Context LLM Inference

## 概要
長文脈LLMではKVキャッシュが文脈長に比例して増えるため、低bit量子化は直接的な容量削減になる。しかしSemKVの中心的発見は、KV量子化品質がbit数に対して滑らかに落ちないことである。Llama-3.1-8B-Instructのaffine quantizerでは2.322 code bits/valueまでFP16との差を統計的に検出できない一方、2.0 bitで品質が崩れる。この「品質崖」をdeployment条件ごとに先に測る。

## 手法
SemKVはtokenを削除せず、model内部のimportance scoreでtokenを順位付けし、品質崖より上にある隣接二つの精度へ振り分ける。目的はimportance score自体の絶対的優劣ではなく、uniform quantizationでは選べない中間の平均bit数を二精度の混合で実現することにある。

論文は8種類のmodel-internal importance indicatorを比較し、崖より上では統計的にほぼ交換可能と報告する。したがって主要な利得は「重要tokenだけ高精度」という一般論より、品質が壊れる境界を測定し、その上側だけでprecision gridを補間する設計にある。affine quantizerを歪み最適化TurboQuant-MSEへ替えると崖自体が低bit側へ移る。

## 評価条件
|項目|条件|
|---|---|
|主モデル|Llama-3.1-8B-Instruct|
|転移確認|Mistral-7B|
|protocol|3 seeds、合計n=900の統計比較を含む|
|追加条件|generation-time quantization、multi-turn dialogue|
|比較|FP16 KV、uniform KV quantization、FP16 token pruning|

## 主要結果
Llama-3.1-8B-Instructでは品質崖が(2.0, 2.322] code bits/valueに観測される。SemKVは全tokenを保持したままKV storageを実測6.0倍削減し、FP16との差を統計的に検出できない。また1.5倍大きいmemory budgetを与えたFP16 token pruningより高品質だった。base quantizerをTurboQuant-MSEへ替えると、同じ「品質差を検出できない」運用点が7.9倍圧縮まで改善する。

## 既存研究との差
従来のimportance-aware KV圧縮はscore設計そのものを主役にしやすい。SemKVはまずuniform quantizationの品質崖を測り、崖より上ではscore間差が小さいことを示した上で、mixed precisionの価値をprecision-grid interpolationとして再解釈する。token pruningと違って履歴tokenを完全には捨てない。

## 限界
品質崖はmodel、quantizer、task、seed protocolに依存するため、2.322 bitという値を別deploymentへそのまま適用できない。方式は事前に対象環境で崖を測る校正を必要とする。また「統計的差を検出できない」は数学的な完全無損失を意味せず、採用したtaskと検定powerの範囲での結論である。
