# UniCAIM: A Unified CAM/CIM Architecture with Static-Dynamic KV Cache Pruning for Efficient Long-Context LLM Inference

> FeFETの統一アレイで動的枝刈り・静的枝刈り・厳密注意計算を3モード切替で実行するCIMアクセラレータ。定数時間の上位k選択と同一サイクルの累積で、AEDPを最大831倍改善する。

## 概要

文脈が長くなると、LLM推論ではKVキャッシュの容量と注意計算の遅延が支配的になる。メモリ配列の中で行列ベクトル積を行うメモリ内計算（compute-in-memory; CIM）はデータ移動を減らせるため、この領域の有力な基盤である。KVキャッシュの枝刈りにも2つの流儀がある。静的枝刈りは不要なトークンを恒久的に落としてメモリを減らし、動的枝刈りはデコードのステップごとに関連の高いトークンだけを選んで計算を減らす。しかし従来のCIMアクセラレータは片方しか支えられなかった。静的側は固定パターンしか実装できず文脈に適応できないため精度が落ち、累積注意スコアに基づく高度な静的方針は追加計算が高価だった。動的側は上位k選択に整列級の回路が要り、遅延と電力を食った。

UniCAIMは、強誘電体トランジスタ（FeFET）を用いた内容アドレス可能メモリ（content addressable memory; CAM）とCIMの統一アレイで、この両立を図る。FeFETはゲートの強誘電層の分極で閾値電圧を多段階に保持でき、符号つき多ビットのキーを1セルに格納できる。このアレイに3つのモードを持たせる。CAMモードでは、クエリとキーの類似度が高いほどセンス線の放電が遅くなる物理特性を使い、厳密なスコア計算なしに上位kトークンを定数時間で選ぶ。電荷領域CIMモードでは、同じサイクルでセンス線と累積容量の電荷共有により類似度を積算し、予約容量を超えた時点で累積最小のトークンを追い出す。電流領域CIMモードでは、選ばれたトークンだけについて電流を高精度に量子化し、厳密な注意スコアを計算する。代表結果として、面積・エネルギー・遅延の積（AEDP）は、枝刈り率80パーセント・3ビットセルの条件でCIMFormer比831倍、TranCIM比56.9倍、Sprint比34.6倍の改善を示した。応用面では、LongChat-7B-32kモデルで密な注意と同等の精度を低いKV保持率でも保ち、SnapKVやStreamingLLMを上回った。

## 問題設定

問題は、枝刈りのアルゴリズム要件とCIMハードウェアの得意不得意のずれである。静的枝刈りで精度を保つには、各トークンの累積注意スコアを継続的に集計し、それが低いものから落とす必要があるが、通常のCIMではこの集計が本体の注意計算に匹敵する追加作業になる。動的枝刈りでは、ステップごとに全キーとの近似スコアを出し、上位k件を選ぶ必要があるが、上位k選択は本質的に比較と整列の回路であり、アナログな配列計算の利点を相殺する。さらに、生成が進むほどKVキャッシュは増え続けるため、容量を固定する運用には、追い出しと新規トークンの書き込みを安価に行う仕組みも要る。本論文は、アルゴリズム側を回路で実現しやすい形、すなわちプリフィルでの一括静的枝刈り、デコードでの上位k動的選択、容量超過時の1件ずつの静的追い出しという構成へ寄せ、ハードウェア側は類似度の測定・累積・厳密計算を1つのアレイのモード切替で賄うことで、このずれを解く。

## 手法のあらまし

プリフィル段階では、入力トークンについて累積注意スコアを求め、最も低いトークンを恒久的に落として、重みのあるトークンだけをアレイへ格納する。あわせて、生成分として一定数の枠を予約する。デコードの各ステップでは、まずCAMモードで現在のクエリと全キーの近似類似度を測り、上位k件を選ぶ。同じサイクルで電荷領域モードが類似度を累積側へ加算する。生成数が予約枠を超えていれば、累積スコア最小のトークンを追い出し、その行へ新しいトークンを直接上書きする。最後に電流領域モードで、選ばれた上位k件だけ厳密な注意スコアを計算し、そのステップの注意出力とする。つまり、近似で候補を絞り、累積で退場者を決め、厳密計算は少数へ限定する、という3段の役割分担が各ステップで回る。

## 手法

### 1. ハイブリッド枝刈りアルゴリズム — 一括の静的、段階的な動的、容量固定の追い出し

アルゴリズムは3つの決定からなる。第1はプリフィルの一括静的枝刈りで、累積注意スコアの低いトークンを恒久的に除去し、推論全体のメモリと計算の母数を減らす。第2はデコード各ステップの動的選択で、注意スコアとしてクエリとキーのコサイン類似度に相当する内積を用い、上位k件だけを厳密計算の対象にする。注意は疎であり、クエリごとに見るべきトークンが違うため、この選択はステップごとにやり直す。第3は容量管理で、生成トークン数が予約枠を超えたら、累積注意スコアが最小のトークンを1件追い出し、新しいトークンをその位置へ直接書き込む。これによりKVキャッシュのサイズは固定され、メモリの付け替えや移動は発生しない。入力はモデルのキーとクエリの列、出力は各ステップで厳密計算されるトークンの集合と、固定容量のキャッシュである。近似である以上、動的選択で落としたトークンが実は重要だった場合はそのステップの注意が歪むが、恒久的な除去は累積スコアに基づくため、一時的な見落としと恒久的な喪失は区別されている。

### 2. FeFETセル — 符号つき多ビットのキー格納と局所乗算

アレイの単位セルは、1トランジスタ1FeFETの組を2つ組み合わせた構成である。符号つきキーの正負を、2つのFeFETの相補的な閾値状態で表し、クエリはビット線の読み出し電圧の相補ペアで与える。センス線電流の高低が符号つき乗算の結果に対応し、キーがゼロの場合は両方を中間の閾値にして中間の電流で表す。FeFETの分極を段階的に切り替えることで閾値を多段階にでき、たとえば正負0.5刻みの多ビットキーをその場で展開して格納できる。クエリ側もビット単位の展開方法を用意し、多ビット同士の符号つき乗算をセル内で実行できる。書き込みは電界駆動で低エネルギーであり、読み出しは分極を壊さない小さい電圧で行う。この性質が、同じセルを検索用のCAMと計算用のCIMの両方に使う土台になっている。デバイス間のばらつきについては、標準偏差54ミリボルトの条件でもセンス線電流と符号つき積和の線形性が保たれることが示されている。

### 3. CAMモード — 放電速度の競走による定数時間の上位k選択

動的枝刈りの実装が本論文の中心である。全行のセンス線をまず充電し、クエリに応じた電圧をビット線へ与えると、各行のセンス線はキーとクエリの類似度に応じた速度で放電する。類似度が高い行ほど電流が小さく、放電が遅い。電圧が半分まで下がった行から順に、その行の保持用のFeFETが切れていく。基準電流を、上位k件が保持する電流の合計より少し大きく設定しておくと、k件の行だけが電圧を保った時点で制御信号が反転し、放電全体が止まる。残った行がすなわち上位k件であり、スコアを数値として計算も整列もしていない。時間計算量は定数であり、kの値は保持用FeFETのプログラムで変えられるため、モデルや文脈に応じた調整に追加回路は要らない。選ばれた行のアドレスは局所レジスタへ記録され、後段の厳密計算で使われる。失敗条件は、類似度が接近した行同士では放電速度の差が小さく、境界付近の選択がばらつきの影響を受けやすいことである。近似選択であることは前提であり、厳密さは後段の計算で担保する設計である。

### 4. 電荷領域CIMモード — 同一サイクルでの累積と静的追い出し

静的追い出しに必要な累積スコアは、動的選択と同一サイクルで作る。上位k選択の後、スイッチを閉じるとセンス線の容量と累積用の容量の間で電荷共有が起き、そのステップの類似度が過去分の累積へ加わる。追い出しの判定も放電の競走で行う。累積が最小の行が最初にプログラム済みの切り替え電圧まで放電し、その行の保持素子が導通して基準電流を超え、制御信号が放電を止める。残った行のうち最初に落ちた行が追い出し対象であり、そのアドレスはレジスタへ記録される。追い出された行には、新しいキーをワード線とビット線の制御で直接上書きするため、データ移動なしに容量固定の運用が回る。入力は各ステップの類似度、出力は更新された累積と追い出し対象であり、追加のデジタル集計回路を持たないことが省電力の源泉である。

### 5. 電流領域CIMモード — 選ばれたトークンだけの厳密計算

最後に、選ばれた上位k件についてだけ、センス線電流をアナログ・デジタル変換器で精密に量子化し、厳密な注意スコアを得る。設計上の利点は2つある。1つは、変換器はアナログCIMの電力の主因であるため、変換対象を上位k件へ絞ること自体が大幅な省電力になることである。もう1つは、類似度が高い行ほどセンス線電流が小さいというセルの特性により、厳密計算の対象はちょうど電流が小さく変換の安い行にそろうことである。64行を64個の変換器で並列に読む構成が評価に使われている。

| 構成要素 | 入力・観測 | 具体的な動作 | 改善対象 | 主なトレードオフ |
|---|---|---|---|---|
| プリフィルの静的枝刈り | 累積注意スコア | 低スコアのトークンを恒久的に除去 | 全体のメモリと計算 | 落としたトークンは以後使えない |
| CAMモード | クエリと全キー | 放電速度の競走で上位kを定数時間選択 | 動的枝刈りの遅延と電力 | 境界付近は近似でばらつきに弱い |
| 電荷領域モード | 各ステップの類似度 | 電荷共有で累積し最小の行を追い出し | 静的枝刈りの追加計算 | 累積はアナログ量で精度に限界 |
| 電流領域モード | 上位k件の行 | 電流を精密に量子化し厳密スコアを計算 | 変換器の電力 | 並列数に上限があり遅延を決める |
| FeFETセル | 符号つき多ビットキー | 相補閾値で格納し局所乗算 | 面積効率 | デバイスばらつきと多値の保持特性に依存 |

## 評価

### まず見るところ

- **結論:** 回路レベルでは、静的枝刈りが面積とエネルギーを、CAMによる動的選択が遅延とエネルギーを、それぞれ大きく改善し、両者の併用でAEDPの改善が最大化する。応用レベルでは枝刈りアルゴリズムが密な注意と同等の精度を保つ。
- **速度・効率:** 遅延の改善は入力長と出力長の増加とともに4.2倍から16.7倍へ伸び、エネルギーの改善は5.3倍から27倍へ伸びる。いずれもシミュレーション上の値である。
- **品質:** 近似手法だが、LongBenchの2タスクでは低いKV保持率でも精度低下は小さく、既存の枝刈りアルゴリズムを上回った。
- **評価の強さ／注意点:** 全て回路シミュレーションであり実チップ測定はない。評価条件もKVキャッシュ576トークンと小さく、大規模構成への外挿は未検証である。

**数値の読み方。** AEDPの831倍という数値は、3ビットセル、枝刈り率80パーセント、CIMFormerとの比較という最も有利な条件の値であり、1ビットセル・枝刈り率50パーセントでは同じ相手に124倍である。倍率の大部分は、相手側が上位k選択や累積に払っている回路コストの大きさを反映しており、絶対的な面積や電力の値そのものとは分けて読む必要がある。

## 既存研究との差

TranCIM系は固定パターンの静的枝刈りを、CIMFormerは追加回路による上位k選択で動的枝刈りを、それぞれ実装してきた。本論文の差分は、静的と動的の両方を1つのアレイで支えるために、アルゴリズムと回路を互いに寄せた点にある。アルゴリズム側は、累積スコアによる除去と類似度による選択という、回路で競走として実装できる形に整理され、回路側は、類似度の大小を放電速度へ写すことで、計算と整列を経ずに選択と累積を物理過程として実行する。FeFETの多値性を使い、符号つき多ビットの格納まで同じセルへ寄せた点も、面積効率の差になっている。

## 限界・実装状況

最も大きな留保は、評価が回路シミュレーションのみで実チップの測定がないことである。評価規模もKVキャッシュ576トークン、隠れ次元128と小さく、長文脈の大規模構成では配線容量や変換器の並列上限が別の律速になる可能性がある。CAMモードの選択は近似であり、類似度が接近した境界ではデバイスばらつきの影響を受ける。応用精度の確認はLongBenchの2タスクに限られ、タスクの幅は狭い。FeFET自体の耐久性や保持特性といったデバイス成熟度も、実用化の前提として残る。ソフトウェアコードの公開先は示されていない。

## 一般的な実装上の含意

アナログなメモリ内計算では、選択や整列のようなデジタル的な操作をそのまま持ち込むと利得が消える。大小関係だけが必要な場面では、物理量の競走として実装し、数値化を最終段の少数へ限定するのが有効である。また、枝刈りのような近似アルゴリズムは、ハードウェアで実現しやすい決定の形、たとえば累積量の最小値の追い出しや、固定容量への上書きへ寄せて設計すると、回路コストと運用の単純さを両立できる。近似の測定と厳密な計算を分離し、厳密側の対象を絞る構成は、変換器が電力の主因であるアナログ計算一般に通じる。
