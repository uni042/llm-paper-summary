## 概要

自己整合性（self-consistency; SC）は同じ問題から複数の思考連鎖をsamplingし、最終回答の多数決を取ることで推論精度を上げる。しかし通常は問題の難しさに関係なく事前設定した本数をすべて生成するため、早い段階で回答が一致する容易な問題にも同じ推論費用を使う。

早期停止自己整合性（Early-Stopping Self-Consistency; ESC）は、sampling途中の回答分布を監視し、最終多数決が十分安定した時点で残りの生成を打ち切る。さらにtask/modelごとの性能と費用の交換条件を調整する制御方式を導く。通常SCと同等の性能を狙いながら、平均sampling数をGSM8Kで80.1%、Coin Flipで84.2%など削減した。

## 問題設定

SCの費用はおおむね「1本の思考連鎖生成費用 × sampling本数」で増える。固定本数Kは、難問で回答が割れている場合には有効でも、最初の数本が同じ回答へ集中した問題では冗長になる。

単純にKを小さく固定すると難問の多数決精度を失う。必要なのは、各問題について途中の合意状況から「これ以上sampleしても多数派が変わりにくい」ことを判断し、問題ごとに異なる本数で止める仕組みである。

## 手法

### 逐次sampling

ESCは通常SCと同様に独立した思考連鎖を順に生成し、各連鎖から最終回答を抽出する。ただしK本を一括生成せず、途中時点の回答頻度を更新する。

### 合意に基づく停止判定

得られた回答の集中度から現在の多数派が安定しているかを判定する。十分な合意が形成された問題はそこで停止し、まだ回答が分散する問題だけ追加sampleへ進む。したがって計算予算は容易な問題から難しい問題へ自動的に移る。

### 性能・費用制御

停止を早めればsampling数は減るが、偶然同じ誤答が初期に集中する危険が増える。論文は停止条件を調整する制御schemeを導き、taskやmodelに応じてaccuracyとcostの希望点を選べるようにする。

### 通常SCとの互換性

基礎となる生成モデルや思考連鎖promptを再学習する必要はなく、SCのsampling loopへ停止規則を追加する。したがって既存のreasoning pipelineへ比較的軽く導入できる。

## 評価条件

| 観点 | 内容 |
|---|---|
| task群 | arithmetic、commonsense、symbolic reasoning |
| benchmark | MATH、GSM8K、StrategyQA、CommonsenseQA、Coin Flip、Last Letters |
| 比較 | fixed-size self-consistency |
| 主指標 | task performance、平均sampling数 |
| モデル | 複数規模のlanguage model |

## 主要結果

| benchmark | 平均sampling数の削減 |
|---|---:|
| MATH | 33.8% |
| GSM8K | 80.1% |
| StrategyQA | 76.8% |
| CommonsenseQA | 78.5% |
| Coin Flip | 84.2% |
| Last Letters | 67.4% |

削減率がbenchmarkごとに大きく異なることは、回答収束の速さがtask依存であることを示す。Coin FlipやGSM8Kでは多くの問題が早期に安定する一方、MATHでは追加sampleが必要な問題が多く、削減率は33.8%に留まる。論文はこれらの削減を通常SCと比較可能な性能を保ちながら達成したと報告する。

## 既存研究との差

通常SCは多様なreasoning pathを固定本数生成して多数決する。ESCはSCの精度改善機構を変えず、途中の回答合意を停止信号として使う。単純な固定K削減と違い、問題ごとにsampling予算を変えるため、容易な問題で節約しつつ難問へ追加計算を残せる。

## 限界

初期sampleが同じ誤答へ偶然集中すると早過ぎる停止が起こり得る。回答抽出が不安定なtaskでは合意度そのものが信頼できない。実際のwall-clock短縮はsample生成を逐次行うschedulerやbatching方法にも依存し、sampling数の80%削減が必ず同じ割合のend-to-end latency削減になるわけではない。
