# DASH-Q：対角曲率を用いる超低ビット学習後量子化

## 概要

DASH-Qは、大規模言語モデル（LLM）の重みを学習後量子化（Post-Training Quantization、PTQ）する際、特に2ビット程度で生じる大きな品質劣化を抑える方式である。従来のGPTQ系では、少量の較正入力から推定したヘッセ行列の逆行列を使い、ある重みの量子化誤差を他の入力チャネルへ伝搬して補償する。ところが較正データが少ない場合、入力間の相関を表す非対角成分は推定雑音を多く含み、補償が誤差を減らすどころか過学習的に悪化させ得る。

DASH-Qは非対角成分を意図的に捨て、入力特徴量の二乗和から得た**対角曲率を重要度の重み**として使用する。各量子化グループで整数割当と尺度・ゼロ点の更新を交互に繰り返すため、重み付き最小二乗の閉形式解を利用できる。Llama-3.1-8B-Instructを2ビット・グループ32で量子化した表1では、ゼロショット8課題平均がDASH-Q 56.52%、OWQ 42.51%、GPTQ 35.66%となる。2ビット時の5モデル平均で、最強の比較方式を7.01ポイント上回ると著者は報告する。ただし、これはモデル推論の処理量が増えたという意味ではなく、量子化後の回答品質を測った結果である。

## 問題設定

LLMの重みを16ビットから4、3、2ビットへ減らすと、重み本体のメモリと転送帯域の要求を小さくできる。単純な丸め（RTN）は各グループの最小値と最大値から尺度を定めて近い整数へ写すだけで、量子化誤差が重要な入力特徴にどれほど影響するかを見ない。学習後に追加の大規模な勾配更新を行わず、少数の較正データから重要な重みを保護するのがPTQの役割である。

GPTQは層の再構成誤差 `||WX-W'X||²` を最小化する近似として、較正入力 `X` から `H≈XX^T` を推定し、逆ヘッセ行列の非対角項を使って列間で誤差補償する。理想的に十分なデータがあれば有用だが、有限サンプルで高次元の相関を推定すると、非対角成分の分散が大きくなりやすい。特に2ビットでは丸めの変位が大きく、誤った補償の影響が顕在化する。論文はこの雑音と量子化精度の関係を、較正サンプル数とヘッセ成分の変動分析から動機付けている。

## 手法

### 1. 曲率を対角近似して入力特徴の重要度を抽出

層の入力を `X`、重み行列を `W` とすると、従来の再構成損失は各出力行 `w_i` に対し `(w_i-w'_i) H (w_i-w'_i)^T` と書ける。DASH-Qは `H` を `D=diag(h_11,...,h_dd)` で置き換え、各 `h_jj=Σ_k x_jk²` を入力チャネル `j` の重要度とみなす。これにより行内の損失は `Σ_j h_jj(w_ij-w'_ij)²` となり、チャネル間の雑音を含む相関推定に依存しない。

この近似は「全ての入力チャネルを同等に扱う」という意味ではない。二乗活性値の大きな特徴は再構成誤差に重い罰則を受け、量子化器がその特徴に対応する重みを優先的に保護する。非対角成分を使わない代わりに、真の相関に基づく補償の可能性も放棄するため、精度が常に改善する数学的保証はない。提案は少数較正データでの頑健性を重視した設計である。

### 2. グループごとの尺度とゼロ点を回帰する

各量子化グループ `G` の元重み `w_j` を整数 `q_j` と尺度 `s`、ゼロ点に相当するオフセット `z` で近似する。目的関数は `Σ_{j∈G} h_jj (w_j-(s q_j-z))² + λs²` である。最後のリッジ項は、重要度重み付き分散が非常に小さいグループで尺度が不安定になるのを抑える。整数 `q_j` を固定すれば、尺度 `s` は重要度付き共分散を分散と正則化項の和で割る形、`z` は重み付き平均から閉形式で求められる。

ここでの重み付き最小二乗（weighted least squares）は、量子化前の重みと復元重みの差を、入力特徴の重要度に応じて最小化する計算である。元の学習データを用いたモデル再学習ではない。尺度とゼロ点はグループごとに保持し、推論時には通常の整数重みと量子化パラメータとして利用する。

### 3. 整数割当と回帰を交互更新する

整数 `q` 自体は `s,z` に依存するため、一回の回帰だけでは完結しない。初期尺度を重み範囲から設定した後、(a) 現在の尺度とオフセットで各重みを近い整数へ丸め、範囲外をクリップする、(b) その整数を固定して重み付き回帰から尺度とオフセットを再計算する、という二段階を反復する。著者は座標降下法（coordinate descent）として説明し、主実験では9回反復を採用した。

この処理は各グループの整数表現と量子化パラメータを更新する。GPTQのように量子化済み列の誤差を他の列へ順次配る必要がないため、非対角ヘッセの逆行列計算を避けられる。一方、反復回数が増えるほど較正・量子化の計算時間は増えるため、無制限に繰り返す設計ではない。論文では9回前後で品質がほぼ収束し、それ以降の改善が小さいことを確認する。

### 4. 層ごとの較正入力の伝搬

全モデルの各層を順に処理し、対象層の較正入力から対角重要度を計算する。量子化した層の出力を次層へ伝搬し、次の層はそれまでの量子化誤差を含む入力で較正される。これにより、全層を独立に元モデルの入力で較正する場合とは異なり、実際の量子化後推論に近い活性分布へ追従する。出力は通常の低ビット重みと尺度・ゼロ点であり、推論時に新たなルーティング機構を加える方式ではない。

## 評価

### 評価条件

| 軸 | 条件 |
|---|---|
| 評価モデル | Llama-3.1-8B-Instruct、Qwen3-14B、DeepSeek-MoE-16B、Phi-3.5-MoE、Mixtral-8x7B-Instruct-v0.1 |
| 較正 | WikiText-2学習分割から128系列、各2048トークン |
| 重み精度 | 4ビット/グループ128、3ビット/64、2ビット/32。重みのみ量子化 |
| 主要比較 | RTN、AWQ、GPTQ、QuIP、QuaRot、OWQ |
| 品質指標 | WikiText-2困惑度（PPL、低いほど良い）、8つのゼロショット課題平均正答率（高いほど良い） |
| 処理費用 | 量子化に要する秒数。生成トークン毎秒とは別の指標 |
| DASH-Qの設定 | 反復9回、平滑化係数0.5、リッジ係数0.01 |

### 2ビットでの品質差

Llama-3.1-8Bの2ビット・グループ32条件では、平均ゼロショット正答率がDASH-Q 56.52%、OWQ 42.51%、QuaRot 41.00%、QuIP 39.90%、GPTQ 35.66%となる。PPLはDASH-Q 16.98、OWQ 15.80であり、**PPLが僅かに良い方式が下流課題でも良いとは限らない**ことが分かる。量子化所要時間はDASH-Q 69.97秒、GPTQ 406.31秒、AWQ 4430.02秒で、特に較正・最適化費用が小さい。

Qwen3-14Bでは、DASH-QとQuaRotの2ビットPPLがそれぞれ11.38、11.79で近い一方、平均ゼロショット正答率には10.48ポイントの差があったと著者は報告する。DeepSeek-MoE-16B、Phi-3.5-MoE、Mixtral-8x7Bでは、最良の比較方式に対して平均正答率でそれぞれ2.72、4.03、4.11ポイントの改善とされる。論文の総括は5モデル平均7.01ポイント、最大14.01ポイントの改善であり、個別条件の数値と混同しない。

### 4ビット・3ビットと負の結果

4ビットのLlama-3.1-8Bでは、DASH-Q 66.90%に対してAWQ 67.07%で、DASH-Qが最高精度ではない。著者はAWQに比べ量子化時間が64.7倍短いと述べ、品質と準備費用の交換条件を強調する。3ビットの同モデルでは、DASH-QのPPL 8.52はOWQの8.10やQuaRotの8.19より悪いが、平均正答率64.99%は比較方式を上回る。したがって「全ビット幅・全指標で一律最良」という評価は正確でない。

### 較正サンプル数と反復回数

論文は較正データを減らした場合の安定性を分析し、少数サンプルでも対角近似が非対角相関の雑音に比較的強いことを示す。反復ごとのPPLは初期数回で大きく改善し、その後ほぼ飽和する一方、尺度の変化はさらに数回続く。主設定の9回は実験的な品質と処理時間の折衷であり、普遍的な最適回数ではない。著者は指示追従の品質も追加分析し、3ビットGPTQでPPLが8.33でも対話評価のMT-Bench得点が0.98まで落ちる条件を報告する。困惑度だけで量子化後の実用性を判断できないという注意点である。

## 既存研究との差

GPTQは非対角曲率を用いて列間の量子化誤差を補償する。AWQは活性値に基づく重み保護と探索を行う。QuaRotやQuIPは回転変換を組み合わせ、OWQは外れ値を高精度に残す。DASH-Qは**相関を精密に推定するより、安定して推定できる重要度だけを残す**という逆方向の設計を選ぶ。低ビット時に発生する品質劣化を、より複雑な相関補償ではなく、雑音に強い最小二乗問題へ還元する点が新規性である。

## 限界と導入上の注意

第一に、対角近似は本当に重要なチャネル間相関も捨てるため、相関が安定して測定できる環境や高ビット条件で常に優位とは限らない。第二に、本文の大きな倍率は主に**量子化作業時間**または**量子化後の品質**を示し、推論エンジンでの実測トークン生成速度ではない。第三に、著者は標準アフィン形式のため既存の重み専用量子化バックエンドと互換と述べるが、特定の配布モデル・カーネル・GPUで性能が実証されたことを意味しない。第四に、著者公式実装の公開URLは今回の一次資料確認では特定できていない。

また、2ビットでの高い相対改善は、比較方式が大きく品質崩壊する条件に依存する。元の16ビットモデルの品質を完全に回復したわけではなく、Llama-3.1-8BのFP16平均67.76%に対してDASH-Q 2ビットは56.52%である。運用時はメモリ削減率、推論速度、品質、較正費用を分けて測定する必要がある。
