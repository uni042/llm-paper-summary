# FastBERT: a Self-distilling BERT with Adaptive Inference Time

## 概要

FastBERTは、BERTのような固定深さの符号化器が「簡単な入力にも難しい入力にも全層を実行する」ことによる冗長計算を、入力単位の早期終了で減らす方式である。12層のBERT-base相当モデルを基盤とし、各中間Transformer層の後ろに軽量な中間分類器を追加する。中間分類器の予測分布が十分に確信的なら、その入力はそこで分類結果を確定して後続Transformer層を実行しない。判断が曖昧な入力だけをより深い層へ送るため、同じモデル重みを使いながら入力難度に応じて計算量を変えられる。

早期終了だけでは浅い分類器の品質が不足するため、FastBERTは最終層の分類器を教師分類器（teacher classifier）、各中間分類器を生徒分類器（student classifier）として自己蒸留する。対象タスクでBERT本体と教師分類器を微調整した後、それらを固定し、教師の出力確率分布をソフトラベルとして生徒分類器を学習する。別の教師モデルを用意せず、同一ネットワーク内の最終分類器から知識を移す点が自己蒸留である。

推論時には各生徒分類器の出力確率から正規化エントロピーを計算し、これを不確実性として使う。論文でSpeedと呼ぶ閾値より不確実性が小さければ早期終了し、大きければ次層へ進む。Speedを変えるだけで、品質を重視して深く計算する設定から、多少の精度低下を許容して浅く終了する設定まで連続的に切り替えられる。

ACL 2020論文は英語6、中国語6の計12分類データセットで評価し、精度をほぼ落とさない範囲ではBERTに対して概ね2〜3倍のFLOPs削減相当、許容精度低下を広げれば約1〜12倍の範囲で計算量を調整できると報告する。ここで「速度」は主として浮動小数点演算数（FLOPs）から算出した計算量比であり、GPU上の壁時計レイテンシを直接12倍改善したという意味ではない。

## 問題設定

BERT-baseは12個のTransformer層を直列に通した後、最終隠れ表現から分類する。固定深さモデルでは、ラベルが浅い層の特徴だけでほぼ明らかな入力でも12層すべてを実行する。一方、文脈解釈が難しい入力も同じ12層を使う。この「入力難度と計算予算を結び付けられない」ことがFastBERTの対象とする非効率である。

モデル蒸留は計算量を減らす代表策だが、DistilBERTのように6層などの固定深さの生徒モデルへ圧縮すると、すべての入力が同じ計算予算になる。1層で十分な入力にも6層を使い、6層では不足する入力にだけ元の12層を追加することもできない。したがって固定蒸留はモデル全体の平均計算量を下げられても、入力ごとの難しさに応じた適応性は持たない。

早期終了を使うには、中間層で「この入力はもう十分に分類できる」と判定する信号が必要である。単に中間層へ分類器を接続しただけでは、浅い分類器が最終分類器と同程度の判断能力を持つ保証がない。また、常に同じ層で終了すれば固定深さモデルと変わらない。FastBERTは、中間分類器の能力を自己蒸留で高め、各入力の予測分布の不確実性を終了判定へ使うことで、この二つを組み合わせる。

この設計は特にオンライン分類のように入力難度が混在する状況を想定する。簡単な入力が多いデータセットでは多数が浅い層で終了し、平均計算量が大きく下がる。難しい入力が多ければ後段まで進む割合が増え、速度向上は小さくなる代わりに判断能力を維持する。つまり、同じSpeed閾値でもデータ分布によって実際の平均実行層数とFLOPsが変わる。

## 手法

### 中間生徒分類器

FastBERTの基盤は12層BERTと最終教師分類器である。各Transformer層の出力に軽量な生徒分類器を接続し、中間層だけでラベル確率を出せるようにする。論文の分類器は、768次元の隠れ状態を128次元へ射影し、その後に軽量な自己注意と全結合処理を通してクラス分布を生成する。したがって、各枝は単なる線形ヘッドではなく、その層の系列表現から分類に必要な情報を集約する小規模な処理を持つ。

追加分類器にも計算費用はあるが、論文のFLOPs分析ではTransformer層1個が約1809.9M FLOPsであるのに対し、分類器は約46.1M FLOPsである。中間分類器を評価する費用はTransformer層を一つ省く費用より大幅に小さい。この差が、各層で終了可否を確認しても全体計算量を減らせる前提になる。

### 二段階学習と自己蒸留

学習の第1段階では、通常の事前学習済みBERTを対象分類タスクへ微調整する。この段階でBERT本体と最終教師分類器をタスクへ適応させる。教師分類器は最深層の表現を利用するため、後続の自己蒸留で各中間分類器が模倣すべき確率分布を生成する役割を持つ。

第2段階ではBERT本体と教師分類器を固定し、生徒分類器を学習する。各入力について教師分類器が出すクラス確率をソフトラベルとして保存し、生徒分類器の確率分布とのカルバック・ライブラー情報量（Kullback–Leibler divergence）を小さくする。正解ラベルだけを使う硬い教師信号と違い、教師が非正解クラスへどの程度確率を割り当てたかも伝えるため、浅い層の分類器が最終層の判断構造を模倣できる。

この段階では基盤表現を動かさないため、複数の生徒分類器を独立に学習できる。論文のBook Review例では、最初の3エポックで微調整し、その後5エポック自己蒸留する。図7では微調整で精度が上がった後、自己蒸留区間で精度をほぼ保ちながらSpeed=0.5時のFLOPsが大幅に下がる。自己蒸留は単に中間ヘッドの正解率を上げるだけでなく、より浅い層で確信的な出力を得て早期終了を増やす役割を持つ。

### 正規化エントロピーによる不確実性

推論時、層iの生徒分類器がクラス確率 `p_i` を出すと、その分布のエントロピーをクラス数で正規化した値を不確実性として計算する。あるクラスに確率が集中していればエントロピーは小さく、複数クラスへ分散していれば大きい。FastBERTは、この値を「中間分類器が自分の予測にどれだけ迷っているか」の代理指標にする。

不確実性がSpeed閾値を下回れば、その入力は現在層で終了する。閾値を上げるほど終了条件が緩くなり、より多くの入力が浅い層で終了するため計算量は下がる。ただし、浅い層で誤って確信的になった入力も終了しやすくなり、精度低下の危険が増える。閾値を下げれば確信度の高い入力だけを早期終了し、より多くの入力が深い層まで進む。

論文の層別分析では、一般に深い層ほど不確実性が低下する一方、後段分類器が前段の判断を覆す例もある。したがって不確実性は完全な難度判定器ではない。早期終了の利得は「浅い層で正しく確信できる入力が十分多い」ことに依存し、Speedを過度に大きくすると誤った浅い判断を確定する。

### サンプル単位の適応推論

バッチ推論では、各入力が同じ層数を実行する必要はない。層ごとに生徒分類器を評価し、終了条件を満たしたサンプルを以後のTransformer計算対象から外す。残ったサンプルだけを次の層へ渡す。このため、FastBERTの計算削減量は固定層数ではなく、データセット内で各入力がどの層で終了したかの分布によって決まる。

この仕組みは、単一の学習済みモデルから複数の計算予算を得られる点でも重要である。固定蒸留では1層、3層、6層など別モデルを用意しなければ計算量を変えにくいが、FastBERTはSpeed閾値を変えるだけで運用点を移せる。負荷が高い時間帯は閾値を上げて計算量を減らし、品質優先時は閾値を下げる、といった利用を想定できる。

一方で、FLOPs削減がそのまま実機速度向上になるとは限らない。サンプルごとに終了層が異なると、GPUではバッチ形状が層ごとに変化し、分類器評価やサンプル選別の制御も発生する。論文はFLOPsを環境非依存の主効率指標として採用しており、この動的制御を含む現代的な連続バッチサービングの実時間は主要評価していない。

## 評価条件

論文は英語6件、中国語6件の計12分類データセットを用いる。比較対象は元の12層BERTと固定深さのDistilBERT系で、DistilBERTについては6層だけでなく同様の蒸留方法による3層・1層も用意する。FastBERTはSpeed閾値を変え、精度とFLOPsの曲線として評価する。

浮動小数点演算数（FLOPs）は1回の推論で必要な演算量を表し、論文はCPU、GPU、TPUといった実行環境に依存しない比較指標として用いる。したがって論文中の「speedup」は原則としてBERTのFLOPsをFastBERTのFLOPsで割った計算量比である。メモリ帯域、カーネル起動、バッチ再編成などを含む壁時計時間の倍率とは区別する必要がある。

| 観点 | 条件 |
|---|---|
| 基盤モデル | BERT-base相当、12 Transformer層 |
| 比較対象 | 12層BERT、6/3/1層の固定深さDistilBERT系 |
| データセット | 中国語6件、英語6件の計12分類データセット |
| 適応判定 | 各中間分類器の予測分布から求める正規化エントロピー |
| 計算量指標 | FLOPsとBERTに対するFLOPs比 |
| 運用ノブ | Speed閾値。大きいほど早期終了しやすい |
| 構成要素除去 | 自己蒸留なし、適応推論なしをBook ReviewとYelp.Pで比較 |
| 実機時間 | 主評価ではなく、論文の主要倍率はFLOPsに基づく |

## 主要結果

論文全体の結論は、性能をほぼ維持する条件ではBERTより約2〜3倍少ない計算で推論でき、許容する精度低下を広げれば約1〜12倍まで計算量を調整できるというものである。この幅が生じるのは、Speed閾値とデータセット難度の双方で早期終了層の分布が変わるためである。

個別データセットでも同じ閾値が同じ倍率を生むわけではない。中国語ChnSentiCorpではSpeed=0.1で精度95.25%を維持しながら約2.02倍のFLOPs比を示す一方、THUCNewsでは同じSpeed=0.1で精度96.71%、約6.05倍となる。英語DBpediaではSpeed=0.1で精度99.28%、約10.57倍まで進む一方、Amazon Fullでは同じ閾値でも約1.03倍に留まる。これはFastBERTが固定深さ削減ではなく、各データセットで「浅い層で確信できる入力の割合」に応じて計算量を変える方式であることを直接示す。

Speedを高くするとさらに計算量を減らせるが、精度との交換条件が強くなる。論文は、ほぼ性能劣化なしで2〜3倍という領域と、精度低下を許容して最大約12倍という領域を分けて解釈している。したがって最大倍率だけを代表値として使うと、品質条件を取り落とす。

### 構成要素除去実験

Book ReviewとYelp.Pを使った構成要素除去実験は、自己蒸留と適応推論の双方が必要であることを検証する。Book ReviewではFastBERTのSpeed=0.2が精度86.98%、9725M FLOPs、2.23倍であるのに対し、自己蒸留なしは精度86.22%、9921M FLOPs、2.19倍となる。Speed=0.7ではFastBERTが85.69%、3621M FLOPs、6.01倍、自己蒸留なしが85.02%、4282M FLOPs、5.08倍である。同程度の計算予算で自己蒸留ありが高精度になり、自己蒸留が浅い分類器の判断能力を高めることが確認できる。

適応推論を外し、全入力を固定6層または固定2層で終了させると、Book Reviewでは6層が86.42%、11123M FLOPs、1.95倍、2層が82.88%、3707M FLOPs、5.87倍となる。FastBERTのSpeed=0.7はほぼ同じ約6倍の計算量削減で85.69%を保つため、同じ平均計算量でも簡単な入力を浅く、難しい入力を深く処理する方が固定2層より精度を維持できる。

Yelp.PでもFastBERTはSpeed=0.2で精度95.90%、5278M FLOPs、4.12倍、Speed=0.7で94.67%、2757M FLOPs、7.90倍を示す。適応推論なしの固定2層は93.11%、3707M FLOPs、5.87倍であり、5倍を超える高い計算削減領域で固定深さ方式の精度低下が大きくなるという論文の主張を支える。

### 自己蒸留の収束

Book Reviewの学習過程では、最初の3エポックを通常微調整、その後5エポックを自己蒸留に使う。Speed=0.5で観測すると、微調整段階で精度が上昇し、自己蒸留へ移った後は精度をほぼ保ったままFLOPsが約6分の1まで低下する。これは教師分類器の出力を模倣するにつれ、中間分類器がより早い層で確信的な予測を出せるようになり、終了位置が前へ移ることを示す。

| 条件 | 精度 | FLOPs / 比 | 読み取れること |
|---|---:|---:|---|
| Book Review, FastBERT, Speed=0.2 | 86.98% | 9725M / 2.23× | 低めの閾値で品質を保ちながら計算削減 |
| Book Review, 自己蒸留なし, Speed=0.2 | 86.22% | 9921M / 2.19× | 同程度の計算量で自己蒸留ありが高精度 |
| Book Review, FastBERT, Speed=0.7 | 85.69% | 3621M / 6.01× | 高速側でも適応終了で品質低下を抑える |
| Book Review, 固定2層 | 82.88% | 3707M / 5.87× | 同程度の計算量でも固定深さは精度低下が大きい |
| Yelp.P, FastBERT, Speed=0.2 | 95.90% | 5278M / 4.12× | データセットにより同じ閾値でも倍率が変わる |
| Yelp.P, FastBERT, Speed=0.7 | 94.67% | 2757M / 7.90× | 許容精度低下を広げるとさらに計算を削減 |
| Yelp.P, 固定2層 | 93.11% | 3707M / 5.87× | 高削減域で適応推論の利点が明確 |

## 既存研究との差

固定深さの知識蒸留は、教師BERTから小型の生徒モデルへ知識を移し、全入力を同じ小型モデルで処理する。FastBERTも蒸留を使うが、別ネットワークへモデル全体を圧縮するのではなく、同じ12層基盤の各中間分類器へ最終分類器の知識を移す。その結果、推論時にどの深さまで使うかを入力ごとに決められる。

早期終了型ニューラルネットワークはFastBERT以前にも画像認識などで提案されていたが、本方式はBERTの中間表現へ生徒分類器を配置し、自己蒸留と不確実性に基づく適応終了を組み合わせる。単に「中間層で分類できたら止める」のではなく、中間分類器自体を最終教師から学習させることで、早期終了に必要な判断能力を作る。

固定層数のDistilBERTと比較すると、FastBERTはSpeed閾値一つで複数の計算予算を選べる。構成要素除去実験で、約6倍の計算削減時に固定2層よりFastBERTの方が高精度だったことは、平均計算量を同程度にしても入力ごとに計算を配分する価値を示す。

## 限界

第一に、評価対象はBERT型の符号化器による分類タスクである。各入力に対して最終ラベルを一度出す設定では「この入力はここで終了する」という判断が自然だが、自己回帰型の大規模言語モデルは各トークン生成で過去状態を継続利用する。FastBERTの中間分類器と終了規則を、そのまま現代のdecoder-only LLM生成へ適用できるわけではない。

第二に、主効率指標はFLOPsである。論文自身もFLOPsをCPU、GPU、TPUなどの実行環境から独立した計算複雑度として扱う。実機では中間分類器のカーネル実行、サンプルごとの分岐、バッチから終了サンプルを取り除く処理、層ごとのバッチ縮小による並列効率低下があるため、FLOPs比と壁時計速度比は一致しない。特に現代GPUの大規模バッチでは、演算量が減ってもハードウェア利用率が下がれば倍率は小さくなり得る。

第三に、早期終了は不確実性閾値の校正へ依存する。Speedを高くすれば計算量は減るが、浅い層で誤って確信した入力も終了しやすい。論文の結果でも最大約12倍は品質低下を許容した領域であり、「12倍高速かつ同精度」と解釈してはいけない。運用時にはデータ分布と許容精度に応じて閾値を選ぶ必要がある。

第四に、論文の12データセットは英語・中国語の分類問題であり、長文生成、検索拡張生成、混合専門家モデル（Mixture of Experts; MoE）、鍵値キャッシュ（Key-Value cache; KVキャッシュ）制約、複数GPUサービングなどは評価対象ではない。FastBERTは適応計算という考え方の重要な先行例だが、現代LLMサービングのメモリ・通信ボトルネックまで直接解決するシステムではない。

第五に、入力難度の分布が利得を左右す。DBpediaのように浅い層で確信できる入力が多い条件では低いSpeedでも大きな削減が得られる一方、Amazon Fullでは同じSpeed=0.1で約1.03倍に留まる。したがって固定の閾値から得られる計算削減量を別データセットへそのまま外挿できない。
