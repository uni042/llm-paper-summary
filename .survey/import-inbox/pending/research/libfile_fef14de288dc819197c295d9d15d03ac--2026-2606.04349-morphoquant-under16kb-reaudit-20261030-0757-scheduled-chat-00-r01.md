# MorphoQuant：全モダリティLLMの外れ値補償と量子化境界の共同最適化

## 概要

MorphoQuantは、画像・動画・音声を同時に扱う大規模言語モデルの活性値を4ビットに圧縮するとき、モダリティごとに異なる分布の形状が原因で精度が低下する問題を扱う。重みと活性の両方を4ビットにするW4A4では、活性のごく一部に存在する大きな外れ値に量子化範囲を合わせると、値が密集する領域の表現間隔が広がり、通常の特徴量が粗く丸められる。逆に量子化範囲を狭くすると外れ値が切り詰められる。画像・動画・音声を一律の範囲で処理する方式では、両方の誤差を同時に抑えにくい。

著者らは、分布適応型バイアス補償（DABC）で少数の外れ値チャネルの切り詰め残差を高精度の別経路へ退避し、形状指向の量子化関数最適化（MDQFO）で多数派の活性値に適した量子化境界を学習する。Qwen2.5-Omni-3Bに対する実験では、W4A4のScienceQA正答率76.63%、MMMU 45.11%、Video-MME 54.33%、AIR-Bench総合点65.09を報告する。比較した単純W4A4のScienceQA 73.17%、MMMU 40.00%を上回る。ただし、GPUメモリは6.07GBでW4A16のQLoRA（5.54GB）より大きく、実測のトークン生成速度を改善した証拠として読むことはできない。

## 問題設定

通常の一様量子化は活性値を尺度で割って整数へ丸め、表現範囲外の値を端点へ切り詰める。切り詰め誤差と丸め誤差の関係が本研究の出発点である。極端な外れ値を保持するため尺度を大きくすると、ゼロ付近の密な活性値を表現する刻み幅が粗くなる。尺度を小さくすると多数派は細かく表現できるが、外れ値の情報が失われる。単純な再構成二乗誤差だけで閾値を選ぶと、まれな大きな値に引きずられやすい。

Qwen2.5-Omniのように画像・音声・動画を処理するモデルでは、各モダリティの活性分布に同じ外れ値パターンを仮定できない。あるモダリティではごく一部のチャネルに長い裾が現れ、別のモダリティでは異なるチャネルが突出する。そこで全チャネルを高精度で保持する混合精度方式も考えられるが、密な4ビット行列積へ16ビットの演算を混在させると、低ビット演算器の連続的な処理が難しくなる。MorphoQuantは、密な主経路を4ビットに保ちつつ、保護すべき残差だけを別経路で加算する設計を採る。

## 手法

### 1. 分散度に基づく保護チャネルの特定

DABCはまず較正データの各入力チャネルについて、最大値と最小値の差を平均絶対活性の大きさで正規化した分散度スコアを計算する。原著の式(5)は、チャネルの値域が大きく、通常の活性が小さいほどスコアが大きくなる形である。分母には数値安定化用の微小定数を加える。値域が広いだけのチャネルではなく、普段の大きさに対して異常な振幅が現れるチャネルを優先して特定する点が重要である。

チャネルを分散度の降順に並べ、閾値を超えたチャネルに二値マスクを立てる。主実験では128件のマルチモーダル較正例を用い、上位5%のチャネルを保護対象とする。このマスクは全チャネルのビット幅を上げる指定ではなく、後段で量子化によって失われた残差のうち、どのチャネルを別経路で回復するかを選ぶ指定である。較正時のモダリティ構成や外れ値の出現場所が変われば、この選択の有効性も変わり得る。

### 2. DABCの残差補償と密な演算の分離

量子化前の活性をX、量子化後の活性をX_Q、量子化重みをW_Q、保護チャネルのマスクをmとする。原著式(7)の補償付き出力は、概念的に `Y = W_Q X_Q + b + W_Q((X-X_Q)⊙m)` で表される。前半は密なW4A4行列積と通常のバイアスであり、最後の項は保護チャネルに限った量子化残差を重みで射影する補正である。入力の残差をいったん抽出してから射影するため、切り詰められた外れ値の影響を出力側で部分的に戻せる。

原著はこの最後の項を「バイアス補償」と呼ぶが、数式上は入力活性Xに依存する補償項である。任意の入力に対して事前に一つの固定バイアスへ吸収できると解釈するのは誤りである。設計上は、主経路を最適化された密な4ビット演算へ載せ、補償を少数チャネルに対する16ビットの疎行列積と加算に分離する。従来の混合精度方式のように密な行列積そのものを多精度混在にしないことが狙いである。

ただし疎な補償経路の演算とメモリアクセスはゼロではない。分散度の高いチャネルが増えたり、実行カーネルが小さな疎演算を効率よく扱えなかったりすると、低ビット主経路の利益が相殺される可能性がある。原著の「ハードウェアに適する」という設計上の説明と、特定GPUでの生成速度を実測したという主張は区別する必要がある。

### 3. MDQFOの量子化境界と複合損失

DABCで外れ値の残差を別経路に逃がした後、多数派の活性値はゼロ付近に比較的密集した対称的な分布として扱える。MDQFOは対称な量子化範囲 `[-α_c, α_c]` の境界α_cを学習可能にし、値域を外れ値だけで決めずに密な活性を細かく離散化できるよう調整する。境界が狭すぎれば保護対象外の値を切り詰め、広すぎれば丸め間隔が粗くなるので、補償対象のマスクと境界の双方が重要になる。

境界の目的関数は、原著式(8)の活性再構成損失と、式(9)のコサイン類似度に基づく方向整合損失を組み合わせる。式(10)は `L_total = L_p + λ_cos L_cos` と記述される。前者は補償後の活性が元の値にどの程度近いか、後者はトークンごとの特徴ベクトルが元の方向をどの程度保持するかを測る。画像・動画・音声を統合する際には、特徴の絶対値だけでなくベクトル方向の変化も後段の意味的な対応関係に影響し得るため、この二つを同時に最適化する。

この最適化は重みそのものを再学習する方法ではなく、事後量子化の較正と境界探索である。原著は全W4A4比較方式の重み量子化手法を揃え、活性側の変更の寄与を比較する。境界探索に使う128件の較正サンプル、損失の重み、保護するチャネル割合は再現に必要な条件であり、任意のモデル・入力分布に対して同じ値が最適とは限らない。

### 4. 推論時の処理順と追加費用

実行時には、較正で決めたマスクと境界を使って活性を4ビットへ量子化し、4ビット重みとの密な積を計算する。次に保護対象チャネルに生じた残差を抽出し、16ビットの疎な補償経路を通して出力へ加える。密な主経路と疎な補償を分離することで、外れ値保護のために全チャネルの演算精度を上げずに済む。一方、補償のための入力残差の保持、疎な演算、境界探索の較正費用は追加される。

従来の量子化で外れ値をそのまま切り捨てた場合と異なり、DABCはマスクされたチャネルに限りその損失を出力へ反映する。ただしマスクされなかったチャネルの誤差は残り、補償に用いる重み自体も4ビットであるため、完全な浮動小数点演算を再現するわけではない。実際の精度・メモリ・速度は補償対象の割合、カーネル実装、入力モダリティの構成によって左右される。

## 評価

### 実験条件と比較の意味

| 観点 | 原著で確認した条件 |
|---|---|
| 対象モデル | Qwen2.5-Omni-3B |
| 量子化 | FP16、W4A16、W4A4 |
| 重みの比較条件 | W4A4方式はQLoRA由来の同一4ビット重み量子化を使用 |
| 較正 | 128件のマルチモーダル例、分散度上位5%チャネルを保護 |
| 画像・言語 | ScienceQA、MMMU（正答率） |
| 動画 | Video-MME（正答率、字幕有無と長さ別内訳あり） |
| 音声 | AIR-Bench（総合スコア、正答率の百分率と混同しない） |
| メモリ | ScienceQA実行時の重みと稼働中バッファを含むGPU VRAM |

表のVRAMは重みファイルのサイズではなく、ScienceQAを実行する際のGPUメモリ使用量である。したがって量子化ビット幅が小さくても、補償経路や活動バッファの影響で比較方式より総メモリが大きくなり得る。原著はこの評価で、モデルの精度を保つという効果と実機での生成スループット改善を同一の指標として測定していない。

### パラメータ感度：原著Figure 6

方向整合損失の重みλ_cosは4ビット条件で0.75付近が良好で、0.5未満では方向整合の拘束が弱く、1.0を超えると再構成の大きさを保ちにくくなる。8ビット条件ではこの変化は比較的小さい。補償する外れ値の判定に使う拡張係数γを1.0から2.0へ増やすと、補償対象の割合が減り、ScienceQAの精度はおよそ77%から70%へ低下する。著者らはγ=1.5付近を妥協点とする。補償量を削るほど必ず良くなるわけではなく、疎補償の演算費用と切り詰め誤差との交換条件がある。

## 既存研究との差

一般的な一様量子化は一つの量子化格子で外れ値と多数派の値を表現しようとする。混合精度方式は外れ値チャネルを高精度に保持できるが、密な演算に異なる精度を混在させる場合がある。MorphoQuantは主経路の密なW4A4を維持し、保護対象チャネルの残差だけを別の疎な16ビット演算で補正する。さらに、量子化境界を単なる再構成誤差だけでなく特徴ベクトルの方向整合も使って最適化する点に特徴がある。

本研究の機構は、すべての活性を16ビットに戻すことでも、重みを追加学習して精度を回復することでもない。較正データから外れ値のチャネルを選び、出力に影響する残差を部分的に復元し、多数派の値に合う量子化範囲を探索する。原著の比較でW4A4方式の重み量子化を揃えているため、活性側の工夫が性能差を生むという説明と対応する。ただし実際の疎補償カーネルの性能は別途測定を要する。

## 限界

実験はQwen2.5-Omni-3Bを中心としており、別の全モダリティモデル、大規模なモデル、異なる入力分布で同じ効果が出るかは示されていない。較正データは128例、保護対象は分散度上位5%であり、これらの選択が変われば残差補償の費用と精度が変化する。音声・動画を含む実運用でモダリティ構成が変わると、固定マスクや境界が適切でなくなる可能性がある。

W4A4の密な演算と16ビットの疎補償を分離できるという設計は説明されているが、GPU上のトークン毎秒、TTFT、TPOT、P99遅延、電力、バッチ負荷に対する包括的な実測優位は原著の評価表からは確定できない。特にGPUメモリ6.07GBはW4A16 QLoRAの5.54GBより大きい。単純な「W4A4は常に高速・省メモリ」という結論をこの論文から導くべきではない。

原著のPCAによる特徴分布の可視化は表現の形状が比較的保たれることを示唆するが、それだけで後段の性能改善の因果を確定できない。MMMUでFP16を0.33ポイント上回る小差は測定誤差や試行差を排除した結果としては示されていない。動画長・字幕条件ではQLoRAに劣るケースもあるため、実装選定では精度指標だけでなく、メモリ、疎補償コスト、対象モダリティの構成を同一条件で検証する必要がある。
