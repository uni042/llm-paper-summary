# CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs

## 概要
CAT-Qは、量子化対応学習（quantization-aware training; QAT）を前提とせず、既存の高精度LLMを1.58-bit相当の三値重みへ変換する学習後量子化である。極低ビットでは通常のPTQが急激に崩れる原因を、重み分布と三値閾値の不整合、および硬い離散化による最適化不安定性として分解する。

中核は学習可能変調（LM）と軟化三値化（ST）である。LMは少数の学習可能因子で元重みと閾値を変調し、三値化誤差が小さくなる分布へ移す。STは軟らかな遷移関数から最終的な硬い三値へ移行し、較正時の勾配を安定化する。層を順次処理するため、元の事前学習データや100Bトークン級の再学習を必要としない。

1.7B〜8B級ではC4から512サンプル（約1Mトークン）だけを用い、100Bトークンで学習したBitNet 1.58-bit v1/v2系より高い平均精度を報告する。さらに14B〜235Bまでを8基のA100-80GBで8〜60時間に量子化し、極低ビットPTQを数百B級まで拡張した。

## 問題設定
三値化はFP16比で重みメモリを約10分の1まで縮小でき、{-1,0,+1}という構造は乗算削減にも適する。一方、2-bit未満では量子化誤差が大きく、既存PTQは性能崩壊しやすい。BitNet系はこの問題をQATや事前学習からの三値学習で回避するが、100Bトークン級のデータと計算が必要になる。

CAT-Qの目的は、学習済みモデルを少量較正だけで三値化し、モデル規模・アーキテクチャをまたいで実用的な精度を保つことである。

## 手法
### 学習可能変調
各層の高精度重みに対して複数の学習可能な変調因子を導入し、重み分布と三値閾値を共同調整する。固定閾値へ元重みを直接丸めるのではなく、三値表現に適した分布へ連続的に移してから離散化するため、外れ値や層ごとのスケール差への感度を下げる。

### 軟化三値化
硬いsign/threshold演算だけでは勾配が途切れるため、STは微分可能な遷移関数を使って軟らかな三値表現から最終的な{-1,0,+1}へ移行する。LMとSTは別々の後処理ではなく同じ較正目的で結合される。

### 少量較正と大規模化
較正には512サンプル、各2048トークン程度を用いる。全モデルを再学習するのではなく層単位に処理することで、235B級でも単一8-GPUノードで完了可能にする。MoEも評価対象に含み、密モデルだけに限定しない。

## 評価条件
| 項目 | 条件 |
|---|---|
| モデル規模 | 1.7B〜235B |
| 精度 | W1.58A16中心 |
| 較正 | C4 512サンプル、約1Mトークン |
| GPU | 8×NVIDIA A100 80GB |
| 評価 | PIQA、ARC-Easy/Challenge、HellaSwag、Winogrande等 |
| 比較 | BitNet 1.58-bit v1/v2、既存2-bit/PTQ方式 |
| 実装 | BitTern公開実装、CPU三値推論も評価 |

## 主要結果
| 観点 | 結果 |
|---|---|
| データ量 | BitNet系100Bトークンに対し約1Mトークン、約100,000倍削減 |
| Qwen3-8B | 5ベンチ平均61.76%、BitNet v1-7Bの57.42%を上回る |
| 大規模量子化 | 14B〜235Bを8〜60時間/8×A100-80GB |
| Llama2-70B | FP系からの平均精度低下約3.81ポイント |
| CPU例 | 三値Qwen3-4Bで37.35 token/sの報告 |

## 既存研究との差
BitNet系が三値表現を学習時から織り込むのに対し、CAT-Qは既存チェックポイントを少量較正で三値化する。一般的な4-bit PTQより量子化誤差が厳しい領域で、分布変調と軟化離散化を同時に最適化する点が差である。

## 限界
較正自体は軽量でも、235B級では8×A100-80GBで最大60時間を要し、単一GPU利用者には依然重い。極低ビット化の精度低下はモデル・タスク依存であり、MoEは活性パラメータが少ないため密モデルより敏感になり得る。W1.58のメモリ削減がそのまま実時間高速化になるには、三値演算を活かすランタイム/カーネル側の対応も必要である。
