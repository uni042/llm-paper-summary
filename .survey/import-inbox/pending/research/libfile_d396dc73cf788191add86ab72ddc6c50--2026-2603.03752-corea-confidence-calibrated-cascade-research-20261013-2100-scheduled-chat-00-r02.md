# Confidence-Calibrated Small-Large Language Model Collaboration for Cost-Efficient Reasoning

## 概要

本論文は、小型言語モデル（SLM）にまず問題を解かせ、答えへの自己申告確信度が低いときだけ大型言語モデル（LLM）へ委譲する二段推論方式COREAを提案する。小型モデル単独では難問で正答率が低下し、大型モデルだけを使うと長い推論過程の生成費用が高い。既存の振り分け方式は外部分類器や別の推定器を要することがあるが、COREAは小型モデルの回答生成と同時に確信度を出力させ、確信度を強化学習で較正してそのまま経路選択に用いる。

著者は、回答の正誤だけでなく「同じ問題を複数回解いた際に正解できる確率」に自己申告値を近づける確信度報酬を、検証可能な正答報酬と書式報酬へ加える。主構成はQwen2.5-7B-InstructとQwen2.5-32B-Instructである。大型モデル単独との比較で、領域外の数理問題では推定費用21.5%減・正答率1.7ポイント減、非数理問題では16.8%減・正答率1.7ポイント減となった。ここでいう費用はトークン数とモデル規模を使った論文内の推定値であり、GPUの実測稼働時間やクラウド請求額ではない。

## 問題設定

言語モデルの推論費用は、入力トークンに加え、長い推論過程として生成される出力トークンに強く依存する。小型モデルで十分に解ける問題にも大型モデルを毎回呼ぶと過剰な費用が発生する。一方、小型モデルの確信度が誤って高いと、難しい問題を自分で回答してしまい、カスケード全体の正答率が落ちる。特に、通常の正答率だけを最大化する強化学習では、回答の正しさと自己申告の確信度が一致する保証がない。

COREAが扱う意思決定は、各質問に対して小型モデルの回答を採用するか、より高価な大型モデルへ元の質問を送るかという二択である。確信度閾値を高くすると大型モデルの呼出しが増えて費用が上がり、低くすると小型モデルの誤答が増えやすい。したがって、単なる正答率ではなく、確信度の較正誤差、正誤識別能力、委譲率、全体正答率、推定費用の組合せで評価する必要がある。

外部の質問難易度推定器は追加のモデル推論と学習データを必要とし、難易度と実際の小型モデルの成功確率が一致しない場合がある。COREAは小型モデル自身の出力へ確信度を含めるため、別の判別器を推論時に呼ばずに委譲できる。ただし確信度の出力にも生成トークンが必要であり、小型モデルを一度実行した後に大型モデルへ委譲すると、その質問では両モデルの費用を支払う点が重要である。

## 手法

### 1. 小型モデル先行の二段カスケード

各質問を小型モデルへ入力し、推論過程、最終回答、0から1までの自己申告確信度を一続きの出力として生成させる。回答は指定された囲み書式、確信度は専用のタグ形式で抽出する。確信度が閾値T以上なら小型モデルの回答をそのまま返し、T未満なら同じ元質問を大型モデルへ渡して大型モデルの回答を最終結果とする。したがって委譲後の最終回答は、小型モデルの出力を大型モデルが検証・修正したものではなく、別モデルが質問を解き直した結果である。

この構成の入出力は「質問→小型モデルの回答と確信度→閾値判定→必要時だけ大型モデルの回答」であり、閾値判定は単純な比較なので経路選択自体の計算量は小さい。一方、閾値を誤ると大型モデルへの委譲が過少・過多になるため、推論経路選択の品質は小型モデルが出す確信度の較正に依存する。著者は独立の経路選択器、出力トークン確率の平均、隠れ状態から学習した予測器とも比較している。

### 2. 群単位の正答確率を目標にする確信度報酬

小型モデルを群相対方策最適化（GRPO）で学習する際、報酬を正答報酬・書式報酬・確信度報酬の和とする。正答報酬は最終回答が正解なら1、誤答なら0である。書式報酬は推論過程、回答、確信度の出力構造を守るように与える。確信度報酬は、モデルが宣言した確信度と実際に正解できる確率との差を小さくするように設計する。

本来の正解確率pは観測できないため、同じ質問についてN回生成した回答の正解割合を推定値として使う。例えば8回答中6回答が正解なら群の推定正答確率は0.75となり、その群の各回答が宣言した確信度を0.75へ近づける。これは個々の回答が正解なら確信度1、誤答なら0へ寄せる標本単位の報酬とは異なる。著者はL1距離の負値、二乗距離の負値、クリップ・正規化したKL型報酬を比較し、主実験ではL1距離を採用する。

群単位の目標は、回答がたまたま正解したかどうかではなく「その問題をこのモデルがどの程度安定して解けるか」を自己申告値に反映させる狙いがある。難問を偶然正解した単一標本だけで確信度1を学習させることを避けられる一方、群の標本数が少ないと推定値にばらつきが残る。報酬を増やせば常に較正が改善するわけではなく、後述するロールアウト数と報酬形の感度実験で不安定性が観測されている。

### 3. 学習と推論時の閾値設定

著者は正答のみの強化学習（RLVR）と、確信度報酬を追加する強化学習（RLCC）を分けて比較する。両者で同じ小型モデル系列を使い、回答能力向上の効果と確信度較正の効果を切り分ける。小型モデルが確信度を出せるようにするため、出力書式を守る報酬も加える。主実験の閾値は、大型モデル単独の評価正答率に合わせる設定であり、運用上必ず最適となる普遍的な閾値ではない。

大型モデルへ送るかどうかの判定には、回答の真の正誤は使用しない。あくまで小型モデルが推論時に出力した確信度だけで決める。このため確信度が過大なら誤答を採用し、過小なら大型モデルを余分に呼ぶ。学習時に使う群の正答割合は正解ラベルがある訓練問題から求めるもので、運用時に同じ問題を8回解く必要はない。学習の追加費用と推論時の経路選択費用は区別する。

## 実装・評価条件

| 項目 | 原著の条件 |
|---|---|
| 小型モデル | 主構成Qwen2.5-7B-Instruct。感度評価にQwen2.5-1.5B-InstructとLlama3.1-8B-Instruct |
| 大型モデル | Qwen2.5-32B-Instruct。大型側もL1確信度報酬を用いた強化学習で調整 |
| 訓練・同領域 | DeepMath-103Kから訓練16,000問、同領域評価500問 |
| 領域外の数理 | Math500、GSM8K、OlympiadBench |
| 領域外の非数理 | GPQA（448問）、CommonsenseQA（1,221問） |
| 学習装置 | AWS p5en.48xlarge、NVIDIA H200を8基。SimpleRL-reason上のGRPO |
| 主要学習設定 | 1質問当たり8ロールアウト、生成最大4,096トークン、学習率5×10^-7、方策更新バッチ256 |
| 推論時 | 生成温度0.6。原則として各評価を10回実行して平均 |
| 指標 | 最終回答のPass@1、較正誤差ECE、正誤識別AUROC、大型モデル利用率、推定費用 |

費用モデルは小型モデルの入力トークンを1とし、出力トークンの単価を入力の4倍にする。大型モデルの単価はパラメータ数の比で小型モデルから比例換算する。委譲しない質問の費用は小型モデルだけ、委譲する質問の費用は小型モデルと大型モデルの両方の合計である。したがって表の費用は論文固有の正規化尺度であり、実際のAPI料金、メモリ帯域、GPU稼働時間、電力量ではない。評価の解釈ではこの仮定が重要になる。

## 評価結果

### 1. 大型モデル単独と二段推論の比較

| 評価群 | 大型モデル単独 Pass@1 | COREA Pass@1 | 大型モデル単独費用 | COREA費用 | 大型モデル使用率 |
|---|---:|---:|---:|---:|---:|
| DeepMath500（同領域） | 69.0% | 67.5% | 14,882 | 13,882（6.7%減） | 59.9% |
| 領域外数理3集合 | 79.6% | 77.9% | 10,164 | 7,978（21.5%減） | 35.5% |
| 領域外非数理2集合 | 71.4% | 69.7% | 7,428 | 6,178（16.8%減） | 59.0% |

原著表1の主比較では、いずれも大型モデル単独からの正答率低下は1.5～1.7ポイントに収まる。ただし費用削減率は同領域6.7%、領域外数理21.5%、非数理16.8%と異なる。大型モデル利用率だけから費用を単純に推測できないのは、委譲時にも小型モデルの先行生成費用が加わるためである。非数理では大型モデル利用率が59.0%でも費用削減は16.8%にとどまる。元論文の費用式と呼出し順序を確認せず、単純な大型モデル呼出し回数削減率を「費用削減率」と呼んではならない。

比較方式の中には、より大幅な費用削減を示すものもある。しかし、正答率の悪化が大きい。例えば領域外数理でRLVR小型モデルの自己申告確信度を使う方式は費用を71.2%削減する一方、Pass@1は72.6%で大型モデル単独79.6%から7.0ポイント低い。COREAはこの領域で77.9%を維持しながら21.5%削減する。したがって最安の方式ではなく、一定の正答率を維持する領域での費用対精度の交換条件が主要な利点である。

### 2. 小型モデルの正答率と確信度較正

| 小型モデルの方式 | 平均Pass@1 | 較正誤差ECE（小さいほど良い） | 正誤識別AUROC |
|---|---:|---:|---:|
| 学習前・自己申告 | 52.8% | 0.45 | 0.50 |
| 正答報酬のみRLVR・自己申告 | 66.9% | 0.30 | 0.50 |
| 正答＋Brier型確信度報酬 | 67.5% | 0.17 | 0.72 |
| COREAのL1型確信度報酬 | 67.8% | 0.12 | 0.72 |

原著表2では、正答報酬だけの学習は小型モデルの正答率を大きく上げるが、自己申告確信度が正誤を識別する能力はAUROC 0.50のままである。確信度報酬を加えるとECEが0.12まで低下し、AUROCが0.72となる。つまり「解ける問題が増えた」ことと「解けない問題を自覚できる」ことは別の効果であり、COREAの経路選択改善には後者が重要である。これは小型モデル単独の回答品質を維持したまま確信度を改善できる可能性を示すが、確信度を完全な連続確率として学習できたことを意味しない。

### 3. 閾値・報酬関数・ロールアウト数の感度

DeepMath500で閾値を0.69から0.4へ下げると、L1型小型モデルの二段推論はさらに約14%の相対費用削減を得る一方、Pass@1が0.6ポイント下がる。閾値が1を超えると小型モデルが出せる確信度の上限1.0より大きくなるため、すべての質問を大型モデルへ委譲する。論文の図2では、COREAは全ての費用・精度領域でパレート最適ではないが、Pass@1が約0.62～0.67の高精度側で優位な交換条件を示す。

確信度報酬の形を変える比較（表3）では、L1型はPass@1 67.8%、ECE 0.12、AUROC 0.72である。二乗距離型はPass@1 67.5%でもECE 0.31、AUROC 0.62となり、報酬設計次第で較正が悪化する。群ごとのロールアウト数の比較（表4）では、4回はPass@1 67.2%・ECE 0.10、8回は67.8%・0.12、16回は66.7%・0.10、32回は68.3%・0.17である。32回の正答率が最大でも較正誤差は最悪であり、群の標本数を増やすだけでは最適な委譲判断にならない。

### 4. 小型モデルの種類と負の結果

Qwen2.5-1.5B、Qwen2.5-7B、Llama3.1-8B、Qwen2.5-32Bについて、著者は正答報酬だけの学習と確信度報酬付き学習を比較している。小型モデルが異なっても確信度較正の改善傾向がある一方、規模が大きいQwen2.5-32Bでは元から正答率が高く、正答率の改善幅は限定的だった。付録の1.5B＋32Bの組合せでは、学習を長く続けると小型モデルの確信度がほぼ0へ偏る過小確信が生じ、150ステップより30ステップのチェックポイントが適切と判断されている。学習報酬が収束しても、正答率と較正の両方が同時に最適化される保証はない。

## 既存研究との差

外部の難易度分類器による質問振り分けでは、別の判別器の実行費用と教師データが必要になり、小型モデル自身の誤答傾向を反映しない場合がある。COREAは小型モデルに推論と確信度出力を同時に行わせ、確信度報酬でその値を直接較正する。出力確率の平均を確信度とする方式、隠れ状態から別途学習する予測器、外部の質問経路選択器を比較対象としており、追加モジュールのない二段構成が特徴である。

また、小型モデルの正答率を上げる学習だけでは経路選択の精度は十分にならないことを、AUROCとECEで示している。提案の技術的貢献は、単に小型モデルを先に実行することではなく、同じ質問の複数回答から群単位の正答確率を推定し、その値へ自己申告確信度を合わせる報酬設計にある。したがって推論システム上の費用改善は、学習された確信度が難問の委譲を選別できることを前提としている。

## 限界・適用上の注意

第一に、費用はトークン単価とモデル規模の比例仮定から計算される。実際のGPU使用時間、処理量、メモリ占有、待ち時間、電力を測っているわけではない。小型モデルの先行生成と大型モデルの再実行が逐次になるため、委譲した質問の実時間遅延は大型モデル単独より長くなり得る。特に低遅延が重要な対話用途では、費用の改善だけでは導入判断できない。

第二に、自己申告確信度は学習後も離散的な値へ偏りやすい。原著自身が、閾値を滑らかに動かしても費用・正答率が連続的に変化しない点を限界としている。確信度の較正誤差が低いことは、全ての個別質問で正しい確率が出る保証ではない。データ分布や難易度が大きく変わる場合、閾値の再調整が必要になり得る。

第三に、強化学習は複数報酬の重み付けとチェックポイント選択に敏感である。二乗距離報酬では較正が悪化し、1.5Bモデルでは長時間学習による過小確信が観測された。訓練には正解ラベルと複数ロールアウトが必要で、学習の追加費用は推論時の費用削減率へ含まれていない。報酬を増やすだけで自己認識が改善するとは限らない。

第四に、主要な比較は数理問題と科学・常識質問であり、コード生成、長いツール利用、複数段階の対話、非定型の実運用要求での検証は十分ではない。主構成のモデルはQwen2.5系列であり、モデル間のサイズ差や価格体系が異なれば最適な閾値と節約率も変わる。小型モデルが既に大型モデルと同程度に正答する場合は委譲自体の意義が小さくなる。
