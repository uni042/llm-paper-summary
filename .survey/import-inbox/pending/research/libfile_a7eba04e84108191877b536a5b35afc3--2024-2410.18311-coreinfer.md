# CoreInfer: Accelerating Large Language Model Inference with Semantics-Inspired Adaptive Sparse Activation

## 概要
動的疎活性化は、各トークンで重要なFFNニューロンだけを計算することでLLM推論を軽くする。しかしDejaVuやPowerInfer系の方式では、各層・各トークンで小さな多層パーセプトロン（MLP）予測器を動かし、活性ニューロン集合を更新する。この予測器は追加計算を生み、トークンごとにアクセスする重み集合が変わるため、限られたGPU/CPUメモリ階層では不規則な資源呼出しも増える。

CoreInferは、同じ文のトークンが似たニューロンを繰り返し使うことに着目する。各トークンの正の活性値上位からtoken-wise core neuronを作り、それらに頻出するニューロンをsentence-wise core neuronとして集約する。プリフィル時にこの集合を決めた後、デコード中は同じ集合を固定利用するため、トークン単位予測器を不要にする。

## 問題設定
従来方式では、疎にするほどFFN計算量は減る一方、どのニューロンを呼ぶかを予測する処理と重み取得の不規則性が目立つ。論文は既存MLP予測器が追加計算を生む例を挙げ、疎演算そのものだけを減らしても実時間高速化が頭打ちになると指摘する。

一方、同じ文中のトークンは意味的に関連している。もし文全体で必要なニューロン集合が安定しているなら、毎トークン予測する必要はない。この仮説を活性パターンと意味類似度の測定から検証する。

## 手法
### token-wise / sentence-wise core neuron
第i層のあるトークンについて、正の活性値の上位割合αをtoken-wise core neuron集合 Cα と定義する。文に含まれる全トークンのCαを集め、出現頻度上位βのニューロンを文単位集合 Cαβ とする。

OPT-6.7BとC4で、α=0.4でもパープレキシティ増加は約2%、β=0.25でも約3%に留まると報告する。同じ文のtoken-wise集合がクラスタ化するため、少数の共通ニューロンで文全体を処理できる根拠になる。

### 安定性誘導予測
長く意味が安定した入力では、入力を少し延長してもcore neuron集合がほぼ変わらない。256トークン文へ8/64トークンを追加した例では、意味類似度が1のときcore neuronの変化はそれぞれ3%/6%だった。そこで要約、few-shot QA、翻訳など十分なプリフィル文脈がある場合は、プリフィルで得た集合をそのままデコードへ固定する。

### 類似性誘導予測
短い入力などプリフィル時の集合が不安定な場合は、訓練データを意味類似度でクラスタ化し、入力が属する意味グループ内で頻出する上位γニューロンを使う。AG Newsでは同一トピック文のcore neuronが層ごとに近くなり、深い層ほどクラスタが明瞭になることを確認している。

### 疎デコード
プリフィル終了時に各層のcore neuron集合を確定し、生成中はその集合だけを計算する。従来のような層ごとのMLP予測器やトークンごとの活性マップ更新がないため、予測器の計算と頻繁な重み切替を同時に削る。

## 評価条件
|項目|内容|
|---|---|
|モデル|OPT、LLaMA系列を含む複数モデル|
|分析モデル例|OPT-6.7B|
|データ/タスク|C4、AG News、TruthfulQAほか複数生成・QAタスク|
|GPU|NVIDIA TITAN XPを含むGPU|
|比較|Hugging Face密実装、PowerInfer|
|品質|パープレキシティ、下流タスク性能|
|性能|推論実時間、高速化倍率|

## 主要結果
|条件|結果|読み取り|
|---|---:|---|
|TITAN XP、対Hugging Face|10.33倍高速化|文単位疎活性化が密実装のFFN計算を大幅削減|
|TITAN XP、対PowerInfer|2.72倍高速化|トークン単位予測器と資源切替の削減が追加利得|
|OPT-6.7B/C4、α=0.4|PPL約2%増|token-wise coreを絞っても品質低下が小さい|
|OPT-6.7B/C4、β=0.25|PPL約3%増|文単位集合を小さくしても一定の品質を維持|
|256-token文+8/64 token|core集合変化3%/6%|意味が安定した長文で固定集合を使う根拠|

## 既存研究との差
DejaVuやPowerInferは各トークンの現在状態から活性ニューロンを予測するため、細かい適応性は高いが予測器とアクセス変更が発生する。CoreInferは適応単位を文へ引き上げ、意味安定性・意味類似性から「生成中に使い続けられる集合」を先に決める。静的枝刈りとも異なり、入力文ごとに集合は変わるため、モデル全体で同じニューロンを恒久削除するわけではない。

## 限界
短い入力や生成中に話題が大きく変化する場合、プリフィルで得たcore neuronが安定しないため類似性誘導方式が必要になる。意味クラスタの品質や訓練データとの分布差にも依存する。固定集合はトークン単位方式より適応粒度が粗く、生成途中で必要ニューロンが変わるケースでは品質低下の余地がある。評価は特定のOPT/LLaMA系とGPU環境であり、全アーキテクチャ・全カーネルへの一般化は未評価である。
