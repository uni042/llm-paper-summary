# CAT-Q: Cost-efficient and Accurate Ternary Quantization for LLMs

## 概要

CAT-Q（Cost-efficient and Accurate Ternary Quantization）は、既存の高精度な大規模言語モデル（LLM）を、重みが `{−1, 0, +1}` の三値だけを取るモデルへ変換する事後学習量子化（post-training quantization; PTQ）である。三値重みはFP16に比べて10倍超のメモリ削減余地を持ち、0による疎性も生じるため、乗算を加減算中心へ置き換えられる。しかし1.58-bit相当まで精度を落とすと情報損失が大きく、従来の高品質な三値LLMは量子化対応学習（quantization-aware training; QAT）に依存していた。

CAT-Qの狙いは、このQAT依存を外し、少量の校正データだけで任意の事前学習済みLLMを三値化することにある。論文は三値PTQの失敗原因を、(1) 元の高精度重みと三値化後の重み分布のずれ、(2) 非微分な三値化関数を直接最適化する際の不安定な収束、の二つに分解する。前者を学習可能変調（learnable modulation; LM）、後者を軟化三値化（softened ternarization; ST）で処理し、さらに隣接層の依存を使うスライディング層最適化へ組み込む。

評価ではQwen2.5/Qwen3/Llama系を含む10モデル、Denseと混合専門家（Mixture-of-Experts; MoE）の双方、1.7B〜235Bパラメータを扱う。標準設定は512校正系列、各2048 tokenである。1.7B〜8Bでは、100B tokenを用いて学習されたBitNet 1.58-bit v1/v2系列より良い性能を、約100万校正tokenで達成したと報告する。これは三値化のために必要な学習token量で約10万倍の差に相当する。さらに14B〜235Bの大規模モデルも8基のA100 80GBで三値化でき、処理時間はモデル規模に応じて約8〜60時間である。

## 問題設定

通常の事後学習量子化では、学習済み重みを低ビット表現へ写像しつつ、少量の校正データで量子化誤差を抑える。4-bit程度なら既存手法でも実用的な品質を維持しやすいが、三値化では各重みが三状態しか持てないため、表現能力が急激に減る。単純な三値化では、重み `W` をスケール `α` と三値行列 `T` の積 `αT` で近似し、閾値 `Δ` より大きい値を+1、小さい値を−1、その間を0へ写す。このとき `α` と `Δ` の選び方が再構成誤差を大きく左右する。

BitNet、TriLM、Tequilaなどはこの難しさをQATで吸収する。モデルが三値制約へ適応するまで大量のtokenで訓練するため品質は高いが、BitNet v2は100B token、TriLMは300B token、Tequilaも10B token規模を必要とする。しかも既存方式の評価は比較的小規模なモデルに偏る。CAT-Qは「元モデルを再訓練せず、512系列程度の校正だけで同じ問題を解けるか」を中心課題とする。

## 手法

### 学習可能変調

学習可能変調（LM）は、三値化前の重み分布そのものを変形する。元の重み `W` から平均 `μ0` と平均絶対偏差に相当する基準スケール `α0` を求め、学習可能な三つの係数 `δμ`、`δα`、`δΔ` を導入する。変換後の重みは `Ŵ=(W−μ)/α` とし、`μ=μ0+δμ α0`、`α=δα α0`、三値化閾値は `Δ=δΔ Δ0` とする。つまり単にスケールと閾値を直接学習するのではなく、中心位置、分布幅、0へ落とす境界を別々に動かせる。

重要なのは、変形後の `Ŵ` を三値の割当て決定に使う一方、復元値は `αT` として扱い、オフセット `μ` を実行時の復元式へ残さない点である。これにより、校正中は外れ値や分布の偏りを吸収しながら、配備時には従来の三値演算の単純さを維持する。論文の構成要素除去実験では、この分離した学習戦略が `αT+μ` としてオフセットを残す代案より良い三値化性能を示す。

### 軟化三値化

三値関数は本質的に離散で、閾値を跨ぐと出力が急変する。従来は直線通過推定器（straight-through estimator; STE）で勾配を近似するが、PTQでは長い再学習過程がないため、初期の誤った離散割当てから回復しにくい。軟化三値化（ST）はこの離散化を一度に行わない。

STの第一段階では、恒等写像から三値関数へ徐々に近づく微分可能な遷移関数 `f` を使う。鋭さを制御する係数を校正時間とともに増やし、連続値のまま三値に近い出力へ漸近させる。第二段階で初めて硬い三値化へ切り替え、第一段階末尾の勾配情報を引き継いでLMの三係数を更新する。既定では512校正サンプルに対して60校正epochを使い、遷移関数の初期鋭さパラメータ `s0` は30である。

この二段階リレーの役割は、三値境界を探索している最中に勾配が突然失われることを避けることにある。LMが「どの分布なら三値化しやすいか」を調整し、STが「そこへどう安定して到達するか」を担当するため、両者は独立な後処理ではなく同じ最適化問題の中で結合される。

### スライディング層最適化

CAT-Qは各層を完全に独立して量子化するのではなく、隣接層の依存を利用するスライディング層出力再構成を採用する。単一層だけの重み再構成では、その層で生じた誤差が後段へどう伝播するかを扱えない。複数の近接層を関連付けて出力再構成することで、前段の三値化誤差を後段との組合せで抑える。

処理はモデル全体を一度に最適化するのではなく、層を順次進むため、大規模モデルにも適用できる。これが235Bまで拡張できる実装上の要点である一方、モデル全体を一括最適化する方式ではないので、長距離の層間相互作用を直接最適化するわけではない。

## 評価条件

| 項目 | 条件 |
|---|---|
| 対象規模 | 1.7B〜235B parameters |
| モデル構造 | DenseおよびMoE |
| 校正データ | 512 sequences、各2048 token（約100万token） |
| 三値表現 | 重み `{−1,0,+1}`、1.58-bit相当 |
| 大規模量子化環境 | 8× NVIDIA A100 80GB |
| 比較の中心 | BitNet 1.58-bit v1/v2、TriLM、Tequila、およびPTQ系 |
| 評価観点 | 言語モデル性能、量子化コスト、モデル規模への拡張性、構成要素除去 |

## 主要結果

| 条件 | 比較・指標 | CAT-Qの結果 | 読み取れること |
|---|---|---|---|
| 1.7B〜8B | BitNet 1.58-bit v1/v2系列 | 512校正サンプルで同系列を上回る性能を報告 | 大規模QATなしでも三値化品質を維持できる |
| 校正量 | BitNet v2の100B training tokens | 約100万校正token | 三値化に必要なtoken量を約10万分の1へ縮小 |
| 14B〜235B | 三値PTQの拡張性 | 大規模事前学習済みLLMを直接三値化 | 小型モデル専用だった従来三値化の適用範囲を拡張 |
| 1.7B〜235B | 量子化時間 | 8×A100-80GBで約1〜60時間 | 再学習ではなく校正工程として実行可能な規模 |
| 重み三値＋活性8-bit | 重みのみ三値化 | 同程度の性能を報告 | 実行時の活性低ビット化とも組み合わせられる |

論文の強い主張は「三値モデルがFP16モデルと常に同品質」ということではない。比較の中心は、同程度のモデル規模で大量QATを行う既存三値モデルに対して、少量校正で競争力のある性能を得る点にある。また、10倍超の重みメモリ削減余地は表現形式から得られるが、実際のエンドツーエンド推論速度はハードウェアと三値カーネル実装に依存する。

## 既存研究との差

BitNet、TriLM、Tequilaは三値制約を学習過程へ組み込み、長いQATでモデルを低ビット表現へ適応させる。CAT-Qは既存チェックポイントを固定した出発点として、校正時に重み分布と離散化経路だけを最適化する。そのため元の訓練データや数十〜数百B token規模の再学習を要求しない。

一般的なGPTQ、AWQ、SmoothQuant等のPTQは4〜8-bitでは強いが、三値という極端な離散化では誤差が急増する。CAT-Qの差は、通常の量子化パラメータ探索だけでなく、分布変形LMと連続から離散へ移るSTを組み合わせて、三値PTQ固有の収束問題を直接扱った点にある。

## 限界

第一に、論文が示す大幅な削減は主として重み保存量と三値化に必要な学習・校正コストである。三値重みを持つだけで、既存GPU上のLLM推論が自動的に同じ倍率で高速化するわけではない。実効速度は専用の三値演算カーネル、メモリ転送、活性精度などに左右される。

第二に、CAT-Qは512系列を用いる校正型PTQであり、完全なデータフリー量子化ではない。校正分布が実利用分布を十分に代表しない場合の頑健性は、評価された範囲を超えて一般化できない。

第三に、235Bまで量子化できることは重要だが、最大規模では8×A100-80GBと最大約60時間を必要とする。QATより大幅に安価でも、単一の一般消費者向けGPUで即時変換できる処理ではない。

第四に、論文の主要貢献は量子化アルゴリズムであり、サービング・スケジューラ、KVキャッシュ、CPU/SSDオフロードなどのシステム層は扱わない。したがって実サービスでのTTFT、TPOT、同時要求スループットへの効果は、別途ランタイム統合後に評価する必要がある。
