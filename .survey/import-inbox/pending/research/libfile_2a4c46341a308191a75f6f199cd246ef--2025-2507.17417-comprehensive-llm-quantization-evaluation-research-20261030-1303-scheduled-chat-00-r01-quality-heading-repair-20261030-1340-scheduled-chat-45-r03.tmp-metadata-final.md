# LLM事後量子化の統一評価：変換・誤差補償・FP4形式・実機遅延

## 概要

LLMの量子化方式は、重み・活性値の精度だけでなく、外れ値をならす前処理、量子化後の誤差補償、対称・非対称、チャネル・グループ粒度、スケールの表現形式などを組み合わせている。異なる論文の精度を直接比較しても、複数の設計差が混在して原因を特定しにくい。本研究は代表的な事後量子化（PTQ）を、**量子化前の分布変換**と**量子化誤差の補償**に分解して共通条件で組み直し、W4A4を中心に精度と実装上の費用を評価したレビュー兼ベンチマークである。

LLaMA-3.2-1BのW4A4で、最適化した回転＋スケーリングにGPTQと低ランク補償を加えると、WikiText-2困惑度は11.73（BF16は9.76）となる。一方、最適化なしで回転にスケーリングを足すと逆効果になる場合がある。MXFP4/NVFP4ではINT4で効く回転の利得が小さく、スケールの形式が品質を左右する。さらにRTX 4090のINT4はプリフィルを約2倍高速化するが、バッチ1のデコードはBF16より遅い。これは**精度上の最良構成と、低遅延サービングでの最良構成が同じではない**ことを示す。

## 研究の狙いと分類軸

PTQでは、学習済みモデルの重みをそのまま低ビット化すると、活性値の一部チャネルに集中する極端な値が量子化レンジを広げ、通常値に割り当てられる有効な刻みが粗くなる。W8A8ではSmoothQuantのようなスケーリングで対処できても、W4A4では表現段階数が少なく、回転、シフト、スケーリング、誤差補償を重ねる方式が増えている。

著者らはPTQを二段階へ分ける。第1段階は重みと活性値の分布を、線形層の元の出力を保ちながら量子化しやすく変える。第2段階は量子化後に残る誤差を、元の重みの調整または追加の低ランク枝で補償する。この分解を使うと、たとえばQuaRotやSpinQuantの回転、SmoothQuantのスケーリング、GPTQの重み補償を別々の設計要素として比較できる。

評価対象は主にテキスト専用LLMであり、VLMの画像トークン、音声、動画を含むモデルへの直接の実験ではない。論文はW4A4を中心にするが、W4A16の重み専用量子化、W8A8、FP4形式の関連研究も整理している。これは新しい量子化アルゴリズム一つの提案ではなく、組合せ効果を統一条件で測る研究である。

## 手法：二段階フレームワークの具体的な処理

### 第1段階：量子化前変換

**シフト（shifting）**は、活性値Xのチャネル別中心Tを差し引き、線形層のバイアスへTWを加えて出力を保つ。式ではY=XW+B=(X−T)W+(TW+B)である。Outlier Suppression+は校正データの最小・最大値からTを求め、OmniQuantは勾配によってシフトを最適化する。活性分布がゼロ中心からずれたチャネルで量子化範囲を使いやすくするが、推定に使う校正分布が実入力と異なると効果が変わる。

**スケーリング（scaling）**はチャネルごとの対角行列Sを使い、Y=XW=(XS⁻¹)(SW)という等価変換を行う。活性側の大きな外れ値を縮める代わりに、重み側のスケールを増やす。SmoothQuantは活性・重みの最大値から比率を定め、AWQは重要な重みを守るために活性の平均大きさに基づいてスケールを探索する。FlatQuantとOSTQuantは回転とスケーリングの位置を変え、最適化可能な変換パラメータを導入する。

**回転（rotation）**は直交行列OでXをXOへ変え、WをOの転置倍へ変えて線形層の出力を保つ。QuaRotはランダムHadamard変換を用い、SpinQuantは回転行列を最適化する。回転は一部のチャネルに偏った外れ値を分散させ、低ビットでの再構成誤差を減らす。ただし最適化済み回転とランダム回転では分布が異なり、後段のシフトやスケールが常に有益になるわけではない。

この段階の要点は、**変換を重ねるほどよいとは限らない**ことである。最適化した回転にスケーリングを組み合わせると性能が改善しやすいが、ランダム回転の後に校正だけで推定したシフトやスケールを追加すると、外れ値がチャネル間へ平均化され、校正量が不正確になり、むしろ性能を落とす。大モデルでは最適化費用も無視できない。

### 第2段階：量子化誤差の補償

**自己補償（self-compensation）**は量子化による重み摂動の損失を近似し、元の重みを補正する。GPTQは校正入力に基づくHessian近似を使い、重みを逐次量子化しながら誤差を次の重みに伝搬させる。量子化前変換だけでは残る再構成誤差を抑えるため、同じ前処理でも単純丸め（RTN）よりGPTQの困惑度が良い場合が多い。

**低ランク補償（low-rank compensation）**は量子化誤差を小さい行列の積ABで近似し、線形層へ追加の計算枝を持たせる。著者の評価では重み誤差のSVDを使う方式であり、単独ではGPTQに劣ることが多い。GPTQと組み合わせると一部の条件で追加改善するが、ランクrの追加重み、行列積、校正費用が必要になる。損失を直接考慮した低ランク最適化なら違う結果もありうるが、この研究で測ったのはSVDに基づく補償である。

## 評価条件

| 項目 | 条件 |
|---|---|
| モデル | LLaMA-3.2 1B/3B、LLaMA-3.1 8B/70B、Qwen2.5 3B、Qwen1.5-MoE-A2.7B |
| 主な精度設定 | W4A4、チャネル単位とgroup-128、最適化あり/なし、GPTQ/RTN/低ランクの組合せ |
| 精度評価 | WikiText-2の困惑度、MMLU・SST2・MathQA・PiQA・HellaSwag・WinoGrande・BoolQ・Lambada・ARC-Cなど9ゼロショット課題 |
| 数値形式 | INT4、MXFP4、NVFP4、FP4、スケールのE8M0/E4M3等 |
| 実機INT4 | RTX 4090、CUDA 12.4、PyTorch 2.6 |
| 実機NVFP4 | RTX 5090、CUDA 13.0、PyTorch 2.12 |
| 速度計測 | LLaMA-3.1 8B、ブロック単位、prefill長2048、decode 256ステップ、B=1/4/16/32 |
| 計測反復 | ウォームアップ10回、ベンチマーク30回 |

速度計測は**ブロック単位の演算遅延**であり、分散サービング全体のトークン毎秒やネットワークを含むTTFTを直接測ったものではない。INT4とNVFP4の実機は異なるGPU・ソフトウェア環境なので、両者の数値を同一GPU上の方式間差として扱ってはならない。

## 評価結果：量子化前変換と誤差補償の組合せ

LLaMA-3.2-1BのWikiText-2 PPLはBF16で9.76。著者の表9では、5乱数シードにわたるチャネル単位の平均PPL±標準偏差は次のとおりである。

| 量子化前変換 | 誤差補償 | PPL（低いほど良い） |
|---|---|---:|
| 最適化回転 | RTN | 18.75 ± 0.814 |
| 最適化回転 | GPTQ | 13.00 ± 0.046 |
| 最適化回転＋スケーリング | RTN | 14.56 ± 0.139 |
| 最適化回転＋スケーリング | GPTQ | 11.78 ± 0.051 |
| 最適化回転＋スケーリング | GPTQ＋低ランク | 11.74 ± 0.028 |

同じ表のgroup-128では最適化回転＋スケーリング＋GPTQ＋低ランクが10.83 ± 0.011であり、チャネル単位より良い。最適化を追加すると平均精度だけでなく乱数シード間のばらつきも小さくなる。低ランク枝の追加は11.78→11.74のように小さい差に留まることもあり、追加メモリに見合うかを別途判断する必要がある。

最適化しないランダム回転では、表10のチャネル単位PPLが回転＋GPTQで13.31、回転＋スケーリング＋GPTQで13.80と悪化する。group-128でも11.96→12.20へ悪化した。対照的に最適化した回転＋スケーリングでは表11でGPTQのチャネルPPLが11.80、group-128が10.89となる。回転とスケーリングを組み合わせたという名前だけでは性能を予測できず、パラメータを最適化したかどうかが結果を左右する。

## 評価結果：モデル間の品質と負の結果

最適化回転＋スケーリング＋GPTQ＋低ランクのW4A4構成について、著者の表12は複数モデルのBF16との比較を示す。

| モデル | BF16 PPL | W4A4 PPL | BF16 9課題平均 | W4A4 9課題平均 |
|---|---:|---:|---:|---:|
| LLaMA-3.2-1B | 9.76 | 11.73 | 54.78 | 49.06 |
| LLaMA-3.2-3B | 7.82 | 8.90 | 63.53 | 58.93 |
| Qwen2.5-3B | 8.03 | 9.22 | 67.27 | 58.64 |
| Qwen1.5-MoE-A2.7B | 7.22 | 8.88 | 65.16 | 58.60 |
| LLaMA-3.1-8B | 6.24 | 7.23 | 69.40 | 63.82 |
| LLaMA-3.1-70B | 2.81 | 4.41 | 76.35 | 72.50 |

いずれもBF16からの品質低下が残る。Qwen2.5-3BのSST2は90.37→69.15と大きく悪化し、9課題平均だけではこの弱点が隠れる。70BでもPPLは2.81→4.41と相対的に大きく悪化するため、モデル規模が大きければW4A4を無条件に適用できるという結果ではない。量子化前処理の組合せによる改善と、非量子化モデルとの品質差を区別する必要がある。

### 対称性と粒度

表13では、最適化回転＋スケーリング＋GPTQのLLaMA-3.2-1Bで、重み・活性とも対称量子化したチャネル単位PPLは12.73、重みを対称・活性を非対称にすると11.80、両方非対称では11.70だった。ARC-C正答率も31.0→33.3→33.7と変わる。活性の非対称化による改善が大きい一方、重みまで非対称化する追加利得は小さい。重み対称・活性非対称は、復号負担を抑えながら精度を改善する妥協点になりうる。

グループを細かくするとスケールが局所分布へ適合し、困惑度が下がりやすい。しかしグループごとにスケール・ゼロ点等を保存する必要があり、量子化パラメータのストレージ費用は増える。論文は単純に「groupが細かいほど常に最良」とせず、追加メタデータと計算の負担を含めて粒度を選ぶべきだとする。

### MXFP4/NVFP4での注意点

FP4では単に仮数・指数の形式を4ビットへ変えるだけでなく、ブロックごとのスケーリング表現が品質を決める。LLaMA-3.2-1Bの表15では、前処理なし・GPTQ＋低ランクでMXFP4（group32、E8M0スケール）のPPLは12.69、FP4（group32、E4M3）は11.18、FP4（group16、E8M0）は12.25、NVFP4（group16、E4M3）は10.83だった。ブロック長とスケール形式が同時に異なるので、この表だけからE4M3単独の効果を切り出すことはできないが、表現形式が重要であることは明確である。

INT4では回転が外れ値対策として有効でも、MXFP4やNVFP4は小ブロックごとのスケーリングで外れ値をある程度吸収するため、追加回転の利得が小さい場合がある。表17ではNVFP4のGPTQ＋低ランクがPPL10.83なのに対し、スケールを重み・活性ともE2M1の4ビットへ制限した条件ではPPL3650に悪化した。これは量子化対象の重み・活性だけでなく、**スケールの精度を削りすぎるとモデルが実質的に破綻する**具体的な負の結果である。

## 評価結果：GPU実測のプリフィル高速化と小バッチデコードの逆転

LLaMA-3.1-8B、prefill長2048、decode 256ステップのブロック単位遅延（表18）。速度比はBF16遅延を低精度遅延で割った値で、1未満なら低精度側が遅い。

| GPU・段階・バッチ | BF16 | 低精度方式 | 低精度遅延 | 速度比 |
|---|---:|---|---:|---:|
| RTX4090 / prefill / B=1 | 8.75ms | INT4 | 3.96ms | 2.21倍 |
| RTX4090 / prefill / B=32 | 266.75ms | INT4 | 136.22ms | 1.96倍 |
| RTX4090 / decode / B=1 | 1.40ms/step | INT4 | 1.70ms/step | 0.82倍 |
| RTX4090 / decode / B=32 | 1.74ms/step | INT4 | 1.84ms/step | 0.94倍 |
| RTX5090 / prefill / B=1 | 4.98ms | NVFP4 | 2.45ms | 2.03倍 |
| RTX5090 / prefill / B=4 | 24.12ms | NVFP4 | 10.46ms | 2.31倍 |
| RTX5090 / decode / B=1 | 0.70ms/step | NVFP4 | 1.87ms/step | 0.37倍 |
| RTX5090 / decode / B=32 | 2.81ms/step | NVFP4 | 3.51ms/step | 0.80倍 |

低精度行列積の高い演算密度が活きるプリフィルでは約2倍の高速化が見られる一方、単一トークンずつ進む小バッチデコードではメモリ帯域、カーネルの起動・変換などの負担が優勢になり、低精度化が遅延改善に直結しない。論文の説明文は大バッチで逆転しうると述べるが、表18の**実測範囲B≤32ではINT4もNVFP4もデコード速度比が1を超えていない**。この表を「B=32で既にBF16より高速」と解釈してはならない。

オンラインHadamard回転を加えたINT4-Rotは4090のB=1デコードで2.00ms/step、速度比0.70倍となり、回転なしINT4の1.70msより遅い。論文は追加回転の計算費用を小さいと評価するが、低遅延用途ではこの差も検討対象となる。

## 量子化準備・追加パラメータのコスト

著者の低ランク補償はランク32を用いる。LLaMA-3.2-1Bの各デコーダ層で低ランク枝は約141万パラメータを追加し、対象線形層約6100万パラメータに対しFP16では約2.3%の追加メモリ、量子化後では約9.2%の追加メモリとなる。計算量はFP16基準で約3.1%増える。量子化モデルを小さくしたい場合、精度を補うための枝が削減したメモリの一部を取り戻すことになる。

LLaMA-3.2-1Bで最適化回転＋スケーリングの学習は約7〜8分、ピークGPUメモリ27.53GB、GPTQ校正は約2〜3分、低ランク校正は約1〜2分と報告される。これは量子化のオフライン準備費用であり、推論時のレイテンシに直接加算する数値ではない。ただしモデル更新が頻繁なサービスでは、再量子化の費用として効く。

## 限界：研究上の位置づけと制約

本研究の寄与は、QuaRot、SpinQuant、FlatQuant、OSTQuant、GPTQ等を単純な方式名の順位として比較するのではなく、前処理変換と誤差補償に分けて交差評価した点にある。回転・スケーリング・シフトの順序と最適化の有無、対称性・粒度、FP4スケール形式が精度を変えるため、別論文のheadline値だけを並べた比較は危険である。

ただし、W4A4の高品質構成を得るには最適化・校正が必要で、低ランク補償は追加の重みと計算を持つ。測定モデルは主にテキストLLMで、VLMや音声モデルへの適用は未実証である。RTX4090とRTX5090の異なる環境を横断してINT4とNVFP4を直接比較できない。速度はブロック単位の測定で、量子化を含むサービングシステム全体のTTFT、TPOT、同時要求スループット、電力効率を完全に評価したものではない。

特に、GPU上のW4A4は必ずしも低バッチデコードに有利でない。量子化の精度評価と、ユーザーが実際に体感する一トークン当たりの遅延を分離して検証する必要がある。またFP4の小ブロック形式ではINT4で有効だった外れ値対策が必ずしも有効でなく、スケールの形式を固定したうえで方法を比較すべきである。
