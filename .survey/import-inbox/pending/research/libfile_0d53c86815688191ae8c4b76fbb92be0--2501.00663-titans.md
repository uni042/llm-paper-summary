## 概要
Transformerのattentionは過去tokenを直接参照できるため正確だが、contextを保持するほどKV memoryとattention計算が増える。RNNやstate-space modelは履歴を固定stateへ圧縮できる一方、何を忘れるべきかを固定更新則で決める。Titansは長期memory自体を小さなneural networkとし、現在入力から得た驚き（surprise）を使って推論中にもそのparameterを更新する。

## 問題設定
長いcontextを全てattentionへ置く方式では二乗計算または巨大KV cacheが必要になる。一方、固定サイズstateは古い情報を不可逆に混ぜやすい。Titansは短期の精密参照をattentionへ任せ、長期情報を別memoryへ圧縮し、必要時にqueryで取り出す役割分担を行う。

## 手法
ニューラルmemoryはkey/valueを受け取り、現在memoryがvalueをどれだけ予測できなかったかをloss gradientで測る。このgradient magnitudeをsurprise signalとして、予測しにくい情報ほど強くmemoryへ書き込む。単純な1-step gradient descentではなく、過去のsurpriseを蓄積するmomentumと、古いmemoryを減衰させるforgetting gateを持つ。

Memory as Context（MAC）は長期memoryから取り出した表現をpersistent memory tokenと現在segmentへ連結し、attentionのcontextとして使う。Memory as Gate（MAG）はattention branchとmemory branchを並列に計算し、gateで混合する。Memory as Layer（MAL）はneural memoryをattentionとは別layerとして直列に配置する。

推論時更新をtoken単位で完全逐次実行すると遅いため、memory updateをchunk単位で並列化できる定式化を用いる。これにより「推論中に学習するmemory」でありながらGPU並列性を残す。

## 評価条件
|項目|内容|
|---|---|
|architecture|MAC / MAG / MAL + neural long-term memory|
|規模|約340M、760M等|
|比較|Transformer、Mamba等のmodern linear recurrent model|
|task|language modeling、common-sense reasoning、genomics、time series、needle-in-haystack|
|長文脈|2M token超まで評価|

## 主要結果
language modelingとcommon-sense reasoningでは複数のTransformer/linear recurrent baselineを上回り、340M級の代表値ではMAC perplexity 25.43、平均accuracy 47.36、MAG 25.07/47.54、MAL 24.69/46.55を報告する。

長文脈ではneedle-in-haystack型taskを2M token超へscaleし、baselineより高いretrieval accuracyを維持する。これは全履歴をattention KVとして残すのではなく、長期memory parameterへ圧縮して参照する設計が長さ拡張へ寄与することを示す。

## 既存研究との差
Mamba等は固定形式のrecurrent stateを更新するのに対し、Titansはmulti-layer neural network自体をtest timeに学習する。RAGのように外部vector databaseへ文書を保存する方式とも異なり、sequence処理中のinternal memory parameterへ情報を圧縮する。

## 限界
memory updateにも計算costがあり、長文脈で常に通常attentionよりwall-clockで速いことを保証する研究ではない。2M token結果は主にretrieval能力のscale評価で、production servingの同時要求・TTFT・TPOT評価ではない。memoryを推論中に更新するため、通常のstateless servingよりrequest state管理も複雑になる。
