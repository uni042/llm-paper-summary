## 概要

状態空間モデル（State Space Model; SSM）のS4系は、長い系列でTransformerより低い計算量を持ち、学習時には畳み込みや並列走査で並列化でき、推論時には再帰として定数状態を更新できる。一方、古典的な再帰型ニューラルネットワーク（Recurrent Neural Network; RNN）は同じく線形時間の推論が可能なのに、勾配消失・爆発と逐次学習のため長距離課題で弱い。本論文は「S4の性能は連続時間状態空間、HiPPO初期化、離散化といった固有構造が不可欠なのか」を、通常RNNから一要素ずつ変更する実験で分解する。

最終的な線形再帰ユニット（Linear Recurrent Unit; LRU）は、再帰内部の非線形性を外し、遷移行列を複素対角化し、固有値を単位円内へ保つ指数パラメータ化と状態分散を補償する正規化を組み合わせる。Long Range Arena（LRA）の6課題でS4/S4D/S5と同程度の精度を得る。A100上の学習速度はtanh RNNに対し課題により1.9〜29倍で、S4D/S5の再現実装とも同水準になる。

## 問題設定

通常RNNの状態更新 `x_k = σ(Ax_(k-1)+Bu_k)` は、非線形関数を含むため系列方向へ逐次実行する必要がある。長距離依存を保とうとして遷移行列の固有値を1付近へ置くと、勾配だけでなく前向き状態の大きさも不安定になりやすい。S4系は線形な状態更新と特殊な初期化・離散化を使うが、どの要素が本当に性能へ効いているかが不明瞭だった。

論文は同じ6層のNorm–Recurrence–GLU–Skip構造を保ったまま、再帰部分だけを段階的に変更する。これにより、アーキテクチャ全体の違いではなく、線形性、対角化、固有値表現、正規化それぞれの効果を切り分ける。

## 手法

### 1. 再帰を線形化する

最初の変更は、再帰内部のtanh/ReLUを除き `x_k = Ax_(k-1)+Bu_k` とすることだ。非線形性は再帰の外側にあるGLU/MLPへ残るため、深いネットワーク全体としての非線形表現力は維持できる。LRAではこの変更だけで、例えばListOps精度がtanh RNNの43.9から50.4、sCIFARが69.9から72.2へ上がる。

線形化のもう一つの利点は、状態更新を結合的な演算として並列走査できることにある。通常RNNの系列方向の逐次依存を学習時に外し、長い系列でもGPUを使いやすくする。

### 2. 複素対角遷移へ変換する

密な線形遷移行列を固有分解の観点から複素対角行列 `Λ` へ置き換える。対角化すると各状態次元の更新が独立になり、並列走査の計算が軽くなる。複素数を使うことで実行列が持つ共役固有値を自然に表現し、密行列から初期特徴分布を大きく変えずに簡略化できる。

この設計はS4D/S5にも似るが、LRUは連続時間状態空間を離散化して得るのではない。通常のRNNを直接パラメータ化し直し、どの性質が効くかを明示することが目的である。

### 3. 安定な指数パラメータ化

遷移固有値の絶対値が1を超えると状態が発散し、1から遠すぎると過去情報が急速に消える。LRUは固有値の半径を指数関数を介して表し、学習中も単位円内へ保ちやすくする。さらに初期半径を1付近のリングから選び、長い時間定数を持つ状態を確保する。

論文は、S4の特定のHiPPO行列そのものよりも「初期固有値がどの時間尺度を持つか」が長距離性能へ重要だと示す。PathXのような16K token課題では、固有値位相の初期範囲も狭める。

### 4. 前向き状態を正規化する

固有値半径を1へ近づけるほど過去入力が長く残るが、白色雑音入力の単純化では状態分散が `1/(1-|λ|²)` に比例して増える。LRUは入力射影へ `sqrt(1-|λ|²)` に対応する学習可能な係数を導入し、長い時間定数を持つ状態でも前向き活性が過度に増えないようにする。

この正規化を加えることで、それまで解けなかったPathXを含めLRA全課題でS4系へ追いつく。したがって「固有値を1へ寄せる」だけでなく、その結果生じる前向き分散の増大を同時に補償することが重要である。

## 評価条件

| 項目 | 条件 |
|---|---|
| ベンチマーク | Long Range Arena: sCIFAR, ListOps, Text, Retrieval, Pathfinder, PathX |
| 最大系列 | PathX 16K token |
| ネットワーク | 6層、残差接続、正規化、GLUを共通化 |
| 比較 | tanh/ReLU/linear RNN、S4、S4D、S5 |
| 反復 | 各実験3 seed、平均と標準誤差 |
| 学習速度 | NVIDIA A100、steps/sec |

## 主要結果

| 条件 | 比較 | LRU | 読み取れること |
|---|---:|---:|---|
| sCIFAR精度 | S4D 91.5 / S5 88.8 | 89.0 | SSM再現系と同程度 |
| ListOps精度 | S4D 60.2 / S5 58.5 | 60.2 | 単純RNNから長距離性能を回復 |
| Retrieval精度 | S4D 89.5 / S5 88.9 | 89.9 | 検索型長距離依存でも競争力 |
| Pathfinder精度 | S4D 94.2 / S5 95.7 | 95.1 | 空間的長距離課題でも同水準 |
| PathX精度 | S4D 97.5 / S5 96.0 | 94.2 | 16K系列を解けるまで改善 |
| A100学習速度 | tanh RNN比 | 1.9〜29倍 | 線形対角再帰の並列走査が効く |

速度の絶対値でも、sCIFARはLRU 15.9 steps/sに対しS4D 13.5、S5 15.9、TextはLRU 14.7に対しS4D 10.6、S5 14.4である。したがって性能だけでなく、長系列学習の計算効率もS4系へ近づく。

## 既存研究との差

S4は連続時間状態空間を離散化し、HiPPO由来の構造化遷移を出発点とする。DSS/S4D/S5はこれを対角化して単純化する。LRUは逆方向に、通常RNNから出発して線形化・対角化・安定化・正規化を順に加え、連続時間系や特定の構造化初期値がなくても同様の長距離性能を得られることを示す。

この分析は後続の再帰型LLM設計にとって、状態空間モデルの「形式」よりも、並列化可能な線形再帰、固有値時間尺度、安定なパラメータ化、状態分散制御が本質的設計軸であることを示す。

## 限界

主評価はLRAの比較的小規模な6層モデルで、数十億パラメータの自己回帰LLMや実運用サービングのtoken/sを直接評価していない。LRUは推論時に定数状態を更新できるが、本論文の速度表は主に学習steps/secである。またPathXでは固有値位相の追加調整が必要で、全長距離課題へ単一の初期化が無条件に最適という結果ではない。
