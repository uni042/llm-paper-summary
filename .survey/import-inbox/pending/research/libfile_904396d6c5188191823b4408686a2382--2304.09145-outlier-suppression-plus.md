## 概要

事後量子化（post-training quantization; PTQ）では、activationのごく大きい外れ値に量子化範囲を合わせると、多数の通常値へ割り当てられる整数段階が粗くなり誤差が増える。従来のOutlier SuppressionやSmoothQuantはchannelごとのscaleで外れ値負担をweightへ移すが、OS+は外れ値がchannelごとに正側・負側へ非対称に偏ることも問題だと分析する。

OS+は各channelの中心をshiftして正負範囲を揃えた後、channel-wise scalingでactivationとweightの量子化誤差を釣り合わせる。shift/scaleは後続linearやLayerNormのparameterへ代数的に吸収できるため、変換後modelは元modelと浮動小数点では等価で、inference graphへ追加operatorを残さない。

## 問題設定

per-tensor activation quantizationでは全channelが共通scaleを使うため、一部channelの巨大値が全体のstep sizeを決める。さらに最大値と最小値の絶対値が非対称なら、対称整数範囲の片側が使われず有効分解能がさらに落ちる。

単純にactivationを縮めると、その逆scaleをweightへ掛ける必要があり、weight側のdynamic rangeが広がる。したがって「activationだけを最小化するscale」ではなく、変換後のweight quantization errorまで含めて最終matrix multiplication出力の誤差を最小化する必要がある。

## 手法

### channel-wise shifting

各activation channelの正負端点から中心zを求め、`X-z`で分布を0付近へ移す。これにより非対称な外れ値が量子化範囲の片側を浪費する問題を減らす。

shiftは実行時に減算するのではなく、後続linearのbiasへ`zW^T`として吸収する。LayerNormをまたぐ場合もbeta/gammaへ代数的に移すため、浮動小数点modelの関数を変えずに推論追加costを0にする。

### channel-wise scaling

shift後も外れ値が集中するchannelにはscale sを与え、activationを割ってrangeを縮め、その逆scaleをweightへ掛ける。OS+はactivation tensor単体の誤差ではなく、量子化activationと量子化weightの積が元のmatrix multiplication出力へどれだけ近いかを目的関数にする。

探索空間を抑えるためoutlier thresholdを1次元grid searchし、各channelのscaleをthresholdから決める。attentionではQ/K/V単体ではなくsoftmaxを含む出力差を考慮し、局所tensor誤差だけを最適化して最終attention出力を悪化させるのを避ける。

### equivalent migration

決定したshift/scaleを隣接parameterへ書き換えることで、deployment時には通常の量子化linear/attentionだけが残る。calibration時の最適化costとinference時のcostを分離し、実行時にchannel-wise変換kernelを追加しないことがOS+の実装上の利点である。

## 評価条件

| 項目 | 条件 |
|---|---|
| models | BERT、OPT 13B〜175B、BLOOM、BLOOMZ、LLaMA |
|方式| post-training quantization |
| precision | 主に8/6/4 bit weight-activation量子化 |
| tasks | GLUE、language modeling perplexity、zero-shot NLP tasks |
| baseline | SmoothQuant、前身Outlier Suppression等 |
| calibration | 少量dataからshift/scaleを探索 |
| runtime overhead | parameterへ吸収するため追加operatorなし |

## 主要結果

標準量子化設定では8bitと6bitで小型Transformerから大規模LLMまで浮動小数点に近い性能を保つ。4bit BERT-baseでは平均GLUE 78.2を報告し、当時の比較法から15.5%改善する。

OPT-13B〜175Bでも8bitはほぼ元精度を維持し、6bitの平均accuracy低下は小さい。特にOPT-175Bの難しい条件ではSmoothQuantに対してHellaSwagで32.5%、PIQAで27.4%の改善が報告される。LLaMAでも6bitはほぼlosslessで、4bitではWinograndeやWikiText2 perplexityで既存法より改善する。

## 既存研究との差

SmoothQuantはactivation outlierのchannel集中をscaleでweight側へ移す。OS+はこれに「channel内の正負非対称」をshiftで補正し、さらにscaleをactivation rangeだけでなく最終matrix multiplication出力誤差から選ぶ。前身Outlier Suppressionよりも大規模decoder LLMと複数bit幅へ対象を広げている。

## 限界

OS+はcalibration dataを必要とし、shift/scale探索の事前処理がある。追加inference operatorはないが、実際のwall-clock speedupは利用するINT kernelとhardwareが低bit演算をどれだけ高速に実行できるかに依存し、本論文の中心は精度回復である。4bitではmodel/taskによって依然として精度低下が残り、8/6bitの「ほぼlossless」を4bit全条件へ一般化できない。
