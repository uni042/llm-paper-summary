# GEAR: An Efficient KV Cache Compression Recipe for Near-Lossless Generative Inference of LLM

> 低ビット量子化の残差を低ランク成分と疎な外れ値成分で補正し、KVキャッシュを高圧縮しながら自己回帰生成の誤差累積を抑える。

## 概要

KVキャッシュ量子化は、各トークンの鍵・値をFP16より少ないビットで保存して長文脈や大バッチを可能にする。しかしKV活性は重みと違って入力依存で、少数の大きな外れ値を含む。全要素を同じ低ビット格子へ丸めると、外れ値に量子化範囲を合わせて通常値の分解能を失うか、通常値へ合わせて外れ値を大きく誤差化する。

GEARは量子化誤差を一種類の補正で処理しない。まず大部分の値を低ビット量子化し、その復号値と元KVとの差を残差行列として考える。残差のうち行列全体に広がる相関構造は低ランク行列で近似し、個別に非常に大きい誤差は疎行列として別保存する。最終的な近似は「量子化値 + 低ランク補正 + 疎補正」になる。

この三成分は役割が異なる。量子化がキャッシュ本体の容量を大きく削り、低ランク成分が量子化誤差の共有方向を少数基底で回収し、疎成分が低ランクでは表しにくい外れ値を直接修正する。論文は4-bit KVでほぼ無損失の生成品質を示し、実装評価では最大2.38倍のスループット改善と最大2.29倍のピークメモリ削減を報告する。

## 問題設定

自己回帰生成では、一度圧縮したKVが後続すべての注意計算に使われる。単発の行列近似誤差が小さくても、誤った注意出力が次トークンの隠れ状態・クエリを変え、その次の生成へ連鎖する。このため重み量子化で許容できる平均二乗誤差が、そのままKV量子化でも安全とは限らない。

またKVキャッシュはトークンごとに増えるため、圧縮器の補助情報が大きいと意味がない。外れ値をすべてFP16で残せば品質は保ちやすいが圧縮率が落ちる。高ランク補正を使えば誤差は減るが、その行列自体が新しいキャッシュになる。GEARは量子化bit、低ランクrank、疎補正率を組み合わせ、補助情報込みの実効bit数で品質と容量を調整する。

## 手法

### 低ビット量子化を基底にする

まずKVの大多数の要素を低ビットで量子化する。量子化はキャッシュ全体に適用でき、復号も規則的なので容量削減の主役になる。しかしこの段階だけでは、分布の外れ値やチャネル間相関による誤差が残る。

GEARは量子化後の近似誤差 `E = X - Q(X)` を明示的な対象とする。つまり元KVを直接低ランク化するのではなく、「量子化で取り切れなかった情報」に補助容量を使う。このため低ランク・疎成分のrankや密度を小さく保ちやすい。

### 低ランク誤差補正

残差Eには、複数トークン・次元にまたがって共通する方向が存在する。GEARはこの部分を低ランク行列 `LR` で近似する。rankを小さくすれば、元のKV行列と同じ大きさの残差を保存せず、少数の因子行列だけで広範囲の量子化誤差を補正できる。

この補正は量子化格子を細かくするのとは異なる。全要素のbit数を1増やすとキャッシュ全体が膨らむが、低ランク補正は残差の主要方向だけへ容量を割く。KV残差が低ランク構造を持つ範囲で効率が良い。

### 疎な外れ値補正

低ランク近似でも、局所的に極端な誤差は残る。GEARは絶対誤差が大きい要素を疎行列として保持し、個別に修正する。これにより低ランクrankを外れ値のためだけに増やす必要を減らす。

疎補正率を上げれば品質は改善しやすいが、値と位置索引の保存量が増える。したがって「量子化だけ」「量子化+低ランク」「量子化+疎」「三者統合」の構成要素除去で、どの誤差をどの成分が回収するかを確認する設計になっている。

### 生成時の再構成

注意計算でKVを使うときは、量子化本体を復号し、低ランク補正と疎補正を加えて近似KVを得る。圧縮率の利得はキャッシュ常駐容量とメモリ転送量の減少から生じる一方、復号・低ランク積・疎補正という追加演算が入る。

小バッチの長文脈生成はKV読出し帯域に律速されやすいため、圧縮によるHBM転送削減が補正演算を上回ればスループットが上がる。論文の最大2.38倍という結果はこの領域での実測であり、純粋な圧縮率をそのまま速度倍率と解釈するものではない。

## 評価条件

| 項目 | 条件 |
|---|---|
| モデル | LLaMA系、OPT系の複数規模 |
| 主比較 | FP16 KV、低ビット量子化のみ、既存KV圧縮方式、GEAR構成要素除去 |
| 品質 | perplexity、下流生成・長文脈タスク等 |
| 圧縮 | 4-bitを主要なnear-lossless設定とし、より低い実効bitも検証 |
| システム指標 | 生成スループット、ピークGPUメモリ |
| 補正成分 | 量子化、低ランク残差、疎外れ値補正 |
| 公開実装 | HaoKang-Timmy/GEAR |

論文の主要主張は特定1タスクの最高精度ではなく、複数モデル・生成条件で「量子化単独より同じ容量で誤差を抑えられる」ことと、それが実メモリ・スループット改善へつながることにある。

## 主要結果

| 条件 | 指標 | 結果 | 読み取れること |
|---|---|---:|---|
| 4-bit KV中心 | 生成品質 | near-lossless | 低ランク+疎補正で量子化単独の誤差を回収 |
| システム評価 | 生成スループット | 最大2.38×改善 | KV読出し削減が補正演算を上回る条件がある |
| システム評価 | ピークメモリ | 最大2.29×削減 | 補助成分込みでもKV容量を削減 |
| 構成要素除去 | 近似誤差/品質 | 三成分統合が量子化単独・部分構成より良好 | 低ランクと疎補正が異なる誤差を担当 |
| 低bit・高圧縮側 | 品質 | 4-bit主要設定より誤差増大 | near-losslessという主張を任意の圧縮率へ外挿できない |

原論文の「near-lossless」は4-bit中心の設定についての実験的主張であり、補助成分のrankや疎率をさらに削って実効bit数を下げた場合まで同じ品質を保証するものではない。

## 既存研究との差

単純な一様KV量子化は、量子化格子だけで全誤差を表現しようとする。GEARは量子化を容量削減の基底とし、残差を構造化して別経路で保存するため、bit数を全要素一律に増やさず品質を回復する。

KIVIのような非対称KV量子化はキーと値の分布特性に合わせて量子化軸を変える。一方GEARの特徴は、量子化軸の工夫だけでなく「残った誤差」を低ランクと疎成分へ分解して補償することにある。トークン枝刈り方式と違い、KV位置そのものを削除せず各KVを近似して残すため、長距離情報を丸ごと捨てる危険とは別の品質・計算交換条件を持つ。

## 限界

低ランク補正と疎補正は追加メタデータ・演算を必要とする。圧縮率が低い、系列が短い、あるいは注意計算がメモリ帯域律速でない場合、復号と補正の費用が速度利得を相殺し得る。最大2.38倍は全条件で保証される値ではない。

「near-lossless」は設定依存である。原論文が代表値として強調する4-bit条件より補助情報を削れば近似誤差は増えるため、4-bitでの結果を2-bit級へそのまま外挿すべきではない。

また残差が十分低ランクか、外れ値が十分疎かという構造仮定はモデル・層・入力で変わる。最適rank・疎率を上げれば品質は改善しても実効bit数が増えるため、モデルごとの調整が必要になる。
