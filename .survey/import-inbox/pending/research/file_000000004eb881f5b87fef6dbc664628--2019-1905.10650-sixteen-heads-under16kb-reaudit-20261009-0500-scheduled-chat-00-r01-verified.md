# Are Sixteen Heads Really Better than One?

## 概要

Transformerの多頭注意は複数の注意ヘッドを並列に計算するが、学習後のモデルが全てのヘッドを推論に必要としているとは限らない。Michelらは、学習済みの翻訳用TransformerとBERTの各注意ヘッドを無効化して、品質の変化、ヘッド重要度の推定、構造的な枝刈り後の推論速度を実験した。ヘッドを単にマスクして正解率を調べる分析と、対応する行列の一部を物理的に削除して実行を速くする処理を区別している。

WMT14英仏翻訳のTransformerでは全ヘッドの約20%、MultiNLIに微調整したBERTでは約40%を重要度順に削っても顕著な品質低下が生じなかった。BERTで半数のヘッドを物理的に削除すると、GeForce GTX 1080 Tiのバッチ16・64では毎秒処理例数が最大17.5%増えたが、バッチ1では1.9%の増加にとどまる。一方、翻訳モデルのエンコーダ・デコーダ注意は自己注意よりも重要なヘッドが多く、最終層を1頭にするとBLEUが13.56ポイント低下した。したがって「16頭は常に1頭へ置換できる」という主張ではない。

## 問題設定と注意ヘッドの冗長性

多頭注意では問い合わせ・鍵・値の射影をヘッドごとに作り、各ヘッドの注意出力を出力射影で統合する。複数ヘッドは異なる位置や関係へ着目する表現力を提供する一方、学習済みの個々のヘッドが他ヘッドで代替できる場合、推論で計算しても出力品質への寄与は小さい。著者らの問いは、訓練時に多頭性が有用だったことと、推論時に全頭を保持する必要があることを分離できるか、というものである。

重み要素ごとの非構造的枝刈りでは、ゼロになった重みが不規則に分布し、通常の密行列演算が必ずしも速くならない。注意ヘッド単位で削れば、問い合わせ・鍵・値射影と出力射影の対応する部分をまとめて取り除ける。ただしどのヘッドを削るかは、層、注意の種類、学習状態に強く依存する。著者らはまず単独除去の影響を測り、次に損失勾配を利用してモデル全体で重要度の低いヘッドを選ぶ。

## 手法

### ヘッドのマスクによる寄与分析

多頭注意の出力を各ヘッド `Att_h(x)` の和として書き、ヘッドごとに二値変数 `ξ_h` を掛ける。`ξ_h=1` は元の出力を維持し、`ξ_h=0` はそのヘッドの寄与をゼロにする。学習済み重みを変更せず、推論時に一つずつゼロ化して翻訳のBLEUやBERTのMultiNLI正解率の差を測る。この操作はヘッドの重要性を観測するための介入であり、ゼロ化しただけでは行列演算の実行量は減らない。

WMT14英仏翻訳では6層・16頭のTransformer largeを使う。エンコーダ自己注意の96ヘッドのうち、単独削除で統計的に有意なBLEU変化を起こしたのは8ヘッドだけで、その半分は削除後にBLEUが改善した。さらに各層で最も有用な1ヘッドだけを残す試験を行い、自己注意では大きな品質損失を起こさない層が多い一方、エンコーダ・デコーダ注意の後段には単一ヘッドへ縮められない層があることを明らかにした。

### 損失感度による全層横断の重要度

一つずつ削除して品質を評価する方法を全ヘッドの全組合せに適用することはできない。そこで著者らは、ヘッドのマスク変数に対する損失勾配の絶対値を平均した `I_h = E_x |∂L(x)/∂ξ_h|` を重要度とする。連鎖律により、この値はヘッド出力と、その出力に対する損失勾配の内積の絶対値から計算できる。絶対値を取るのは、ある例では正、別の例では負に効くヘッドが単純平均で相殺されることを防ぐためである。

この重要度は順伝播と逆伝播で求められるため、全ての候補を一つずつ実際に削除してテストするより安価である。WMTではnewstest2009〜2012を重要度推定に用い、層ごとに二乗ノルムで正規化して層間の尺度差を抑える。モデル全体のヘッドを重要度順に並べ、下位10%ずつ段階的に削除して品質曲線を観測する。重要度は「削除したときの損失変化」の一次近似であり、複数ヘッドを同時に削ったときの相互作用を完全に予測するものではない。

### マスクと構造削除の区別

枝刈り順序を決めた後、速度を測る実験では削除対象ヘッドの問い合わせ・鍵・値射影と出力射影の対応部分を実際に取り除く。これにより注意演算の行列幅が縮小し、密行列演算で処理できる。単にマスク値をゼロにしたまま元の大きさの行列を計算しても、演算の削減を実測速度へ結びつけることはできない。

ただしBERTには注意以外の埋め込み、前向き層、正規化などの演算が残る。したがってヘッドの半数を削ったとしても、モデル全体の演算量や実行時間が半減するわけではない。実測はバッチによって変わり、GPUの計算が十分に大きいバッチで初めて利得が明確になる。

### 学習途中での重要度の形成

著者らは学習済みモデルの分析だけでなく、IWSLT14独英翻訳の6層・8頭モデルについて、各学習時点で同じ枝刈り手順を実施した。初期の第1〜2エポックでは削除率にほぼ比例して品質が落ち、ヘッド間の重要度差が小さい。第10エポック以降は、重要度の低いヘッドがまとまって現れ、約40%削っても元モデルBLEUの85〜90%を保つ場合がある。学習が進むにつれて役割分化と冗長性が形成されるという観察であり、学習前から常に固定の不要ヘッドが存在するという説明ではない。

### 重要度順位と品質曲線の読み方

一つのヘッドを消しても品質が変わらないという観察は、そのヘッドが学習中に何も学ばなかったことを意味しない。複数のヘッドが類似した情報を表現していれば、一つを無効化しても残りのヘッドが補える可能性がある。逆に、同じ層の複数ヘッドを同時に削れば、相互補完の余地がなくなり急激に品質が落ちる場合がある。原著の重要度順の反復枝刈りは、こうした相互作用がある状況でどこまで削れるかを測る実験である。

また、マスク勾配は現在の重みと評価用データに対する局所的な損失感度である。値が小さいことは、そのヘッドを恒久的に削除して再学習した後も不要であることを保証しない。翻訳のエンコーダ自己注意とエンコーダ・デコーダ注意で削除耐性が異なる結果は、同じTransformerの中でも機能上の役割が違うことを示す。ヘッドの重要度を比較する際には、注意の種類、層、評価データ、削除率をそろえて解釈する必要がある。

## 評価条件と主要結果

| 翻訳 | WMT14英→仏、6層16頭Transformer large、newstest2013 | BLEU、エンコーダ自己注意・デコーダ自己注意・エンコーダデコーダ注意を区別 |
| 言語推論 | BERT-base uncased、12層12頭、MultiNLI matched | 分類正解率、matched/mismatchedで分布ずれ確認 |
| 学習ダイナミクス | IWSLT14独→英、6層8頭 | エポック別の枝刈り耐性、元モデルに対する相対BLEU |
| 推論速度 | BERT、GeForce GTX 1080 Tiを搭載した2台で各3回 | 毎秒処理例数、バッチ1・4・16・64、合計6測定 |

| 実験条件 | 比較対象 | 原著の結果 | 解釈 |
|---|---|---|---|
| WMTのエンコーダ自己注意96頭を単独除去 | 無削除の翻訳モデル | 有意に変化したのは8頭、うち4頭は削除で改善 | 多数の頭が他頭と冗長だが、単独除去と多頭同時除去は別問題 |
| 各層で1頭のみ保持、WMT最終エンコーダ・デコーダ注意 | 元の16頭 | BLEU −13.56 | 注意種別によって多頭性への依存が極端に異なる |
| 重要度順に全体を反復枝刈り | 無削除 | WMT約20%、BERT約40%削除まで目立つ低下なし | 損失感度による順序付けが有効な範囲を示す |
| 注意種別ごとのWMT枝刈り | 自己注意とエンコーダ・デコーダ注意 | エンコーダ・デコーダ注意は60%超削除で破綻、自己注意は20%残存でもBLEU約30 | 一律の削除率を適用すべきではない |
| BERT、頭50%削除、バッチ1 | 元17.0例/秒 | 17.3例/秒、+1.9% | 小バッチでは実行固定費が残る |
| BERT、頭50%削除、バッチ4 | 元67.3例/秒 | 69.1例/秒、+2.7% | 小バッチでは改善が限定的 |
| BERT、頭50%削除、バッチ16 | 元114.0例/秒 | 134.0例/秒、+17.5% | 演算が支配的になると構造削除の効果が出る |
| BERT、頭50%削除、バッチ64 | 元124.7例/秒 | 146.6例/秒、+17.5% | 高バッチでの処理率改善であり単一要求のTTFT改善ではない |

重要度の転用可能性も調べている。WMTのnewstest2013と領域外MTNTの単独除去影響のPearson相関は0.56、BERTのMultiNLI matchedとmismatchedでは0.68であった。正の相関は重要ヘッドの傾向が別データにもある程度残ることを示すが、完全な一致ではない。重要度を算出したデータから別分布へ移したとき、削除の影響が変わり得る。

単独で各層を1頭へ縮める実験では、評価用の集合で最良の頭を選ぶと結果を過大評価する可能性があるため、別の検証集合で頭を選んでテスト集合へ持ち込む追試も行っている。この追試でも、WMTの半数の層とBERTの全層で、最良の単一頭を残しても統計的に有意な変化がないという傾向を報告する。ただしこれは「全層を同時に1頭へ縮めても品質を保てる」ことを意味しない。全体で枝刈りを進めると品質は急落する。

学習途中の実験では、初期にはヘッド削除率に比例してBLEUが低下するが、第10エポック以降には約40%のヘッドを削っても元のBLEUの85〜90%を維持する段階が現れた。重要度差が学習中に形成されるため、学習済みモデルで得た重要度順を訓練初期のモデルへそのまま適用することはできない。

## 既存研究との差

この研究の中心は、注意重みを可視化して言語現象との関係を論じるだけではなく、マスク介入による因果的な寄与の観測と、損失感度に基づく全層横断の枝刈りを接続した点である。ヘッド単位の構造削除によって、重み単位の不規則な疎化とは異なり、通常の密な行列演算の形を小さくできる。翻訳の3種類の注意を分離し、BERTでも推論処理率を測り、学習途中の重要度形成まで調べている。

## 限界

この論文の主な実験は2019年当時の翻訳用TransformerとBERTであり、現在のデコーダ専用LLM、グループ化問い合わせ注意、長文脈KVキャッシュ、高速注意カーネル、連続バッチ処理にそのまま同じ枝刈り率・高速化率が当てはまるとは言えない。特に翻訳のエンコーダ・デコーダ注意は自己注意より敏感であり、モデル全体を一律に1頭へ減らすことはできない。

50%の頭を削除したBERTでも、バッチ1での推論速度向上は1.9%にとどまった。頭数削減率を、そのまま要求遅延やモデル全体の高速化率へ読み替えてはいけない。大バッチの処理率改善は実測されているが、単一要求の初回応答やGPU以外のCPU・モバイル機器の利得は直接検証していない。

また、勾配感度は与えたデータ分布と学習済み重みに依存する。分布外データとの相関は正だが完全ではなく、重要度の移植に不確実性が残る。枝刈りを40〜50%より大きく進めると品質が急激に悪化する。学習初期には冗長性が小さいため、学習後の結果から訓練全体を同じ構造で効率化できるとは主張できない。原著は極端な枝刈り後の再訓練や、現代の大規模生成モデルでの復元品質を検証していない。
