# Harder Task Needs More Experts: Dynamic Routing in MoE Models

## 概要
混合専門家（Mixture-of-Experts; MoE）モデルは多数の専門家を持ちながら、各トークンではTop-K個だけを活性化して計算量を抑える。一般的なTop-2ルーティングでは、容易な機能語も複雑な推論に関わるトークンも同じ2専門家を通る。本論文は、ルータが出す専門家確率分布の「選択への確信度」を使い、トークンごとの活性化専門家数を変える動的ルーティングを提案する。

狙いは単純な専門家削減ではない。確信度が高い入力は少数専門家で処理し、曖昧な入力は追加専門家へ計算を割くことで、平均計算量を減らしながら必要箇所へ容量を寄せる。評価では固定Top-2より活性化パラメータを90%未満にしつつ平均0.7%性能を改善し、BBHのような複雑な推論タスクでより多くの専門家を使う傾向を観測する。

## 問題設定
固定Top-Kはサービング上扱いやすい一方、入力難度と計算量を切り離している。ルータ分布で第一専門家が圧倒的なら第二専門家の追加計算は寄与が小さい可能性がある。逆に複数専門家のスコアが拮抗するトークンでは、Top-1だけでは表現能力が不足する可能性がある。

既存の適応ゲーティング研究には学習時間削減を主目的とするものもあるが、本論文はタスク難度・層位置と必要専門家数の関係を分析し、動的専門家選択で性能と活性化計算の両方を改善することを狙う。

## 手法
### ルータ確信度による専門家数決定
通常どおりゲートが各専門家へのスコアを計算する。固定Top-2では順位上位2個を必ず選ぶのに対し、動的方式は上位スコアの集中度・確信度を見て必要数を決める。第一候補への確信が十分高いトークンは少数で止め、分布が曖昧なら追加専門家を通す。

### 入力難度への計算配分
この規則により計算量はトークンごとに変化する。重要なのは難度ラベルを別モデルで推定するのではなく、MoEルータがすでに計算する専門家選択分布を信号にする点である。追加の大規模な難度推定器を持たず、ルーティング判断そのものから計算予算を決める。

### 層ごとの不均一性
分析では、必要専門家数はタスク間だけでなくTransformer層間でも異なる。ある層は少数専門家で十分なトークンが多く、別の層では追加専門家が必要になる。この結果は、全層で同じTop-Kを固定する設計だけでなく、層ごとに異なる専門家容量を持つ異種MoE設計の余地を示す。

## 評価条件
| 項目 | 内容 |
|---|---|
| 比較 | 固定Top-2ルーティング |
| タスク | 複数NLPベンチマーク、BBHを含む推論タスク |
| 効率指標 | 活性化パラメータ量 / 専門家利用数 |
| 品質指標 | 各タスク性能と平均性能 |
| 分析 | タスク難度別・層別の専門家活性化傾向 |

## 主要結果
固定Top-2に比べ、動的ルーティングは活性化パラメータを90%未満へ抑えながら平均性能を0.7%改善する。これは「計算を減らしたため多少品質を失う」という単純な圧縮結果ではなく、不要な第二専門家を簡単な入力から外し、その予算を難しい入力へ配ることが品質にも寄与することを示す。

BBHでは他の比較的容易なタスクより多くの専門家が活性化される。さらに層別分布も一様でなく、計算需要がモデル深さ方向にも変化する。これらは動的ルータが単に全入力の専門家数を一律に減らしているのではない証拠として使われる。

## 既存研究との差
Switch Transformerや一般的Top-K MoEは各トークンのKを固定する。Adaptive Gating系も可変Kを扱うが、本論文は専門家選択の確信度とタスク難度の関係を明示的に分析し、難しいタスクへ追加計算を配る枠組みとして評価する。専門家枝刈りのようにモデルから専門家を永久削除する方式とも異なり、利用可能な専門家集合は保持したまま入力ごとに活性数を変える。

## 限界
可変専門家数は理論上の活性化計算を減らしても、GPU上の実時間が同率で減るとは限らない。トークンごとの専門家数が不均一になるとバッチ化、all-to-all通信、専門家負荷分散が難しくなる。本論文のheadlineは主に活性化パラメータとタスク品質であり、大規模分散サービングのエンドツーエンド遅延・スループットを中心に評価したシステム論文ではない。このため実運用利得には可変ルーティングを効率良く実行するランタイムが別途必要になる。
