# FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision

## 概要
FlashAttentionはattention matrixをHBMへmaterializeせず、tilingとonline softmaxでI/O量を減らした。しかしH100ではFlashAttention-2の利用率が約35%に留まり、最適化GEMMが達する80～90%級との間に大きな差がある。原因はalgorithmのI/O量だけでなく、Hopperで追加された非同期Tensor Core命令とTensor Memory Accelerator（TMA）を十分に重ねられていない点にある。

FlashAttention-3はHopperを明示的な対象にし、data movement、matrix multiply、softmaxの依存関係を再構成する。FP16では最大740 TFLOP/s、H100理論peakの約75%に達し、FlashAttention-2比1.5～2.0倍を報告する。FP8では約1.2 PFLOP/sまで上げながら、単純なFP8 attentionより数値誤差を2.6倍小さくする。

## 問題設定
attentionではQK^TのGEMM、online softmax、softmax結果とVのGEMMがblockごとに連鎖する。従来kernelではload→GEMM→softmaxの同期点が残り、Tensor Coreがsoftmaxやmemory待ちで停止する。HopperはTMAによる非同期global/shared memory転送とWGMMA系Tensor Core処理を持つため、warpごとに役割を分ければこれらを同時進行できる。

低precisionでは別問題がある。FP8はthroughputが高い一方、attention activationの外れ値でscaleを決めると通常値の有効精度が落ちる。したがって高速なFP8 Tensor Coreを使うだけでなく、block単位のscaleと値分布の整形が必要になる。

## 手法
### warp specialization
producer warp groupがTMAでQ/K/V tileをshared memoryへ運び、consumer warp groupがWGMMAで行列積を進める。load完了を全warpが待つ同期型ではなく、専用warpが次tileを先読みしている間に別warpが現在tileを計算する。これによりmemory movementとTensor Core実行を重畳する。

### GEMMとsoftmaxのping-pong
QK^T blockのGEMMが終わってから同じwarpがsoftmaxを処理する直列構造ではなく、複数warp groupが異なるblock段階を交互に担当する。一方がGEMMを進める間に他方が前blockのsoftmaxを処理し、Tensor Coreの空白時間を減らす。論文のablationでは非同期pipelineの組合せがthroughputを大きく引き上げる。

### FP8 block quantization
tensor全体で1つのscaleを使うのではなくblock単位で量子化scaleを持ち、局所的なdynamic rangeへ合わせる。これにより外れ値が全tensorの分解能を支配する問題を弱める。HopperのFP8 Tensor Core throughputを使うためのlayout変換もkernel内で処理する。

### incoherent processing
Hadamard変換のような直交変換でactivation energyを複数次元へ拡散し、極端なoutlierを量子化前に均す。attention結果を数学的に保ちながらFP8で表現しやすい分布へ変えることで、単純なper-tensor FP8より誤差を下げる。性能だけでなく低precision accuracyをkernel設計の一部として扱う点が特徴である。

## 主要結果
FP16ではFlashAttention-2に対して1.5～2.0倍高速化し、最大740 TFLOP/s、H100 peakの約75%利用率へ到達する。FlashAttention-2がH100で約35%利用率に留まるという出発点に対し、I/O削減済みalgorithmでもhardware pipelineの使い方に大きな余地があることを示す。

FP8 pathは約1.2 PFLOP/sに達する。block quantizationとincoherent processingを組み合わせることで、baseline FP8 attentionより数値誤差を2.6倍小さくする。つまりFP8化による速度向上を、単純なprecision低下と交換するだけではない。

## 既存研究との差
FlashAttention-1/2の中心はHBM↔SRAM traffic削減とwork partitioningだった。FlashAttention-3はそのexact-attention骨格を維持しつつ、Hopper固有の非同期TMA/WGMMAへexecution scheduleを合わせる。量子化attention研究とも異なり、FP8を単独の近似手法としてではなく、kernel pipeline・layout・数値安定化と一体で設計する。

## 限界
Hopper固有機能への依存が強く、Ampere等では同じkernel構造・性能をそのまま得られない。FP8 pathはblock scaleやHadamard処理など追加操作を持ち、sequence shapeによってoverhead比率が変わる。またこれはattention kernel単体の高速化であり、MoE、MLP、通信、schedulerを含むLLM serving全体が同じ倍率で速くなることを意味しない。
