# HD-MoE: Hybrid and Dynamic Parallelism for Mixture-of-Expert LLMs with 3D Near-Memory Processing


> 3D近傍メモリ処理上のMoEについて、offline TP/EP混成mappingとonline動的routing補正を組み合わせ、通信量とexpert負荷不均衡を同時に抑える。

## 概要

混合専門家モデル（Mixture-of-Experts; MoE）は各tokenが一部expertだけを実行するため演算量を抑えられる一方、全expert重みを保持する大容量メモリと、routing後のtoken移動に高帯域が必要になる。3D近傍メモリ処理（near-memory processing; NMP）はメモリと演算器をhybrid bondingで近接配置し、高帯域・高エネルギー効率を狙えるが、複数NMP tileに分散したメモリへMoEをどう配置するかが性能を左右す。

Tensor Parallelism（TP）は各expert演算を複数tileへ分けて計算利用率を揃えやすいが、中間tensorのcollective通信が増える。Expert Parallelism（EP）はexpertをtileへ丸ごと置いて通信を減らせるが、routingの偏りで一部tileだけが重くなる。固定hybridも平均負荷に合わせるだけではtokenごとのrouting変動へ追従できない。

HD-MoEはofflineで層・expertごとのTP/EP混成mappingを自動探索し、通信費と演算利用率を同時に見積もる。onlineでは実際のrouting loadに応じてscheduleを動的に補正する。TP比1.1〜1.8倍、EP比1.1〜1.5倍、compute-balanced hybrid TP-EP比1.0〜1.4倍のspeedupを報告する。

## 問題設定

NMPはメモリ帯域を増やしても、tile間通信が無料になるわけではない。TPを強くすると各層でcollectiveが増え、NMP内部networkが律速になる。

EPではtokenが選んだexpertを持つtileへdispatchされる。routing分布が均等でなければhot expertを持つtileのqueueが伸び、他tileがidleになり、全体stepは最遅tileを待つ。

MoE routingは入力依存で時間変化するため、offlineの平均profileだけで完全なload balanceを作れない。HD-MoEは静的mappingと動的scheduleを分離してこの二つの時間尺度を扱う。

## 手法

### offline hybrid mapping

モデル構造、expert配置候補、NMP tileの計算能力、tile間通信costを入力し、層ごとにTPとEPをどの程度使うかを探索する。目的は通信量だけを最小化せず、tileの計算利用率も含めた推定latencyを下げることである。

expertを丸ごと置くEPが有利な層と、分割して負荷を均すTPが有利な層を同一モデル内で使い分ける。結果はonline schedulerが使う基本mappingになる。

### routing-aware online scheduling

実際のtoken routingからexpertごとのwork量を観測し、offline想定から偏った場合に処理順・割当を調整する。hot expert側のtileだけが長いcritical pathを作るのを抑える。

この動的補正はモデルparameterを再配置する大規模remapではなく、現在のmapping上で利用可能な並列資源をrouting loadに合わせて使うことが目的である。

### 通信と計算の協調

TPはcollective通信、EPはtoken dispatchを発生させるため、単純なFLOPs均等化は最適でない。HD-MoEのcost modelは両通信経路とNMP計算時間を合わせてmappingを評価する。

online側も計算負荷だけでなく、通信待ちを含むtile completion timeを縮めるようscheduleする。これにより「計算だけ均等だがnetworkが詰まる」mappingを避ける。

## 評価条件

| 項目 | 内容 |
|---|---|
| 対象 | MoE LLM inference |
| ハードウェア | 3D stacked near-memory processing accelerator |
| 比較 | TP、EP、compute-balanced Hybrid TP-EP |
| 変動要因 | expert routingの動的不均衡 |
| 指標 | inference speedup、計算利用率、通信cost |
| 設計 | offline mapping + online scheduling |

## 主要結果

| 比較対象 | speedup | 意味 |
|---|---:|---|
| Tensor Parallelism | 1.1〜1.8倍 | collective通信を減らすhybrid配置が有効 |
| Expert Parallelism | 1.1〜1.5倍 | routing由来のload imbalanceを補正 |
| Compute-Balanced Hybrid TP-EP | 1.0〜1.4倍 | 平均計算量だけのhybridより通信・動的routing考慮が重要 |

## 既存研究との差

通常のTP/EP選択はGPUクラスタを主対象とし、NMP tileの分散メモリと内部通信構造を直接cost modelへ入れない。HD-MoEは3D NMPのmemory-compute配置を前提にmappingを作る。

固定hybrid方式に対しては、offlineで平均的に良い分割を選ぶだけでなく、入力依存routingをonline schedulerで追跡する点が追加される。

## 限界

主対象は提案3D NMP acceleratorであり、一般GPUクラスタで同じspeedupを保証しない。結果はhardware mappingの研究なので、実際の市販NMP製品上のend-to-end production servingとは区別する必要がある。

online schedulerはrouting変動へ追従できるが、極端なhot expertや物理配置そのものが不利な場合、scheduleだけで完全な均衡は作れない。モデル品質の改善を目的とする方式でもない。
