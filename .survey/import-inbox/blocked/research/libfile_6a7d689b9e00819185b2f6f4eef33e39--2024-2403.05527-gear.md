# GEAR: An Efficient KV Cache Compression Recipe for Near-Lossless Generative Inference of LLM

## 概要
長文脈・大batchのLLM推論では、各layer・各tokenのkey/valueを保持するKVキャッシュがHBM容量とmemory bandwidthを圧迫する。単純なtoken evictionは必要情報を捨て、uniform quantizationは外れ値に量子化rangeを引っ張られて通常値の分解能を失う。さらにdecodeは圧縮済みKVを次token計算へ繰り返し使うため、小さな近似誤差でも生成stepを通じて品質へ影響し得る。

GEARはKV行列Xを概念的に`Q + L + S`の三成分へ分ける。Qは大多数の値を低bitで保持し、Lは量子化後に残る構造的な誤差を低rankで回収し、Sは少数の大きな外れ値誤差を明示的に保持する。三者が異なる誤差モードを担当することで、4-bit級まで下げても生成品質を維持しやすくする。

## 問題設定
30B級モデル、長いsequence、大batchではKVだけでGPU memoryを超える規模になり得る。既存の一様量子化はstorageを減らせても、outlierに合わせたscaleでbulk値が粗く丸められる。token droppingはさらに強い近似で、長い推論chainや後から必要になる情報を不可逆に失う。GEARは「全entryを残すが、誤差構造に応じて表現方法を変える」方針を採る。

## 手法
### bulk値の低bit量子化 Q
大多数の似たmagnitudesのentryを低precisionへ量子化する。ここが主要な容量削減源で、denseなKV本体を4-bit級へ落とす。量子化自体はhardware-friendlyだが、この段階だけでは外れ値と系統的残差が残るため、GEARはQ単独を最終表現にしない。

### sparse外れ値補正 S
量子化誤差のうち大きな正負outlierを少数抽出し、sparse matrixとして高精度に保持する。外れ値を量子化rangeへ無理に押し込まず別経路へ逃がすため、bulk側scaleを通常値へ合わせやすい。代わりにindexと高精度valueのmetadata costが生じるので、保持率は小さく制限する。

### low-rank残差 L
`X-Q-S`に残る誤差にはtoken/feature間で相関した構造があるため、低rank matrixで近似する。論文実装は低rank solverを使い、rankを小さく保って追加storageと復元計算を抑える。Qが高周波のbulk値、Sが極端なcell、Lが構造的残差を担当することで、単一表現より誤差を小さくする。

### decode時の復元
attentionでK/Vを使う際は三成分の寄与を組み合わせる。圧縮率を上げるほどQのbit幅、Sの保持率、Lのrankが品質とstorageの交換条件になる。GEARの主張は、同じmemory予算ならこれらを一種類の近似へ全投入するより、誤差の性質に分担させた方がnear-losslessへ近づくというものだ。

## 主要結果
4-bit KV cacheでnear-losslessな生成品質を維持しつつ、代替圧縮方式に対してthroughputを最大2.38倍改善し、peak-memory sizeを最大2.29倍削減したと報告する。これはKV容量削減がより大きなbatchや長いcontextをHBMへ収める余地を作り、memory trafficも減らすためである。

構成要素の意味は品質側でも現れる。低rank補正またはsparse補正を外すと、低bit量子化の残差を一種類で吸収できず、複雑な推論taskで精度が大きく落ちる。したがってGEARの利得は「4-bit化」だけではなく、量子化誤差を構造的残差と外れ値へ分けて補正する組合せにある。

## 既存研究との差
KIVI等の量子化系は主にbit幅・grouping・scale設計で誤差を抑えるのに対し、GEARは量子化後残差そのものを低rankとsparseへ分解する。H2O等のtoken eviction系と違い、重要でないと予測したtokenを丸ごと捨てず、全tokenの情報を圧縮表現として残す。

## 限界
低rank factorとsparse outlierには追加storageと復元計算が必要で、KVが小さい短文脈では管理costが相対的に大きい。最適rank・outlier率はモデルやlayer、memory予算に依存する。near-losslessは評価したtask・圧縮設定での結果であり、すべての長文脈生成で完全なlosslessを保証するものではない。
