# Sliding-window beats linear attention

## 概要
標準softmax 注意機構では文脈が伸びるほど保持するkey/valueが増え、デコード時のメモリ 通信量も増える。これを固定状態へ置き換えるlinear 注意機構は魅力的だが、既存チェックポイントをlinear 構成へ変換するには数千万〜数十億トークンのpost-学習を要する場合がある。本論文は、より単純なSliding Window Attention (SWA)を十分強い比較対象として比較していないことを問題視する。

提案というより再基準化研究であり、既存重みを変えず、各問い合わせが直近w トークンと先頭4 トークンだけを見るSWA(w,4)を適用する。先頭4 トークンは注意機構 sinkとして常に残す。短文脈では6 ベンチマーク平均で全体-注意機構 teacherの99.0%を回復し、長文脈reasoningでは比較対象linear 注意機構より2〜10倍高いaccuracyを報告する。

## 問題設定
linear 注意機構はKV キャッシュの長さ依存を除ける一方、pretrained softmax モデルの注意機構 functionを別形式へ近似する必要があり、post-学習費用と品質損失がある。SWAは単に過去w トークンへsoftmax 注意機構を制限するため追加学習が不要だが、先頭トークンをwindowから落とすと既存モデルで大きく品質が崩れることが知られている。

そこで先頭4 トークンを常時可視なsinkとして固定する。局所window外の情報は直接参照できないが、層を重ねると情報は局所注意機構を通じて伝播できる。これは固定サイズのKV working setを得る最小限の変更である。

## 手法
SWA(w,4)では各デコード位置が直近w トークンと系列先頭4 トークンにだけ通常のsoftmax 注意機構を行う。重み、注意機構 カーネルの意味、モデル 構成は変更せず、maskと保持KV範囲だけを変える。したがってlinearization用の蒸留やLoRA post-学習を必要としない。

比較ではLoLCATs、Liger-GLA、QRWKV6等のpost-trained linear 注意機構方式と、元の全体 注意機構 teacherを置く。短文脈一般能力だけでなく、探索対象 検索とBABILongでwindowを越えた情報利用を測る。

## 評価条件
|項目|条件|
|---|---|
|モデル|Llama、Qwen、Phi等の複数pretrained LLM|
|SWA|局所window + 4 sink トークン|
|短文脈|MMLU、ARC-C/E、HellaSwag、PIQA、WinoGrande|
|長文脈|Single Needle-in-a-Haystack、BABILong|
|効率マイクロベンチマーク|4-層、隠れ 1024、16 heads、FP16、バッチ 1|
|GPU|RTX PRO 6000 Blackwell Max-Q|
|カーネル|FA/SWAはFlashAttention、linear系はThunderKittens|

## 主要結果
|条件|結果|解釈|
|---|---:|---|
|6 ベンチマーク平均|teacherの99.0%回復|追加学習なしでも短文脈能力をほぼ維持|
|MMLU 5-shot|teacherの93.2%|平均よりMMLUの低下は大きい|
|11 モデル case|9件で非teacher方式中最高平均|linear retrofitに対する強い比較対象|
|長文脈reasoning|linear方式比2〜10×のaccuracy|固定windowでもtested retrofitより高い|
|4K S-NIAH、window 512例|SWA 23.0%、LoLCATs(+SWA) 5.8%、全体 99.8%|linear方式より良いが全体 注意機構との差は大きい|
|効率マイクロベンチマーク|window超過後メモリほぼ定数、SWAがtested方式中最速|固定working setの利点を確認|

## 既存研究との差
linear 注意機構研究は注意機構演算そのものを再設計し、固定サイズ 状態へ情報を畳み込む。本研究のSWAはsoftmax 注意機構を保持し、可視範囲だけを切るため学習不要である。新規構成を提案するより、post-学習 linearizationが超えるべき比較対象を引き上げた点が主貢献である。

## 限界
短文脈比較の一部は各linear 注意機構論文が報告したスコアを引用しており、プロンプト templateやevaluation harnessが完全一致しない。長文脈では全体 注意機構を大きく下回る条件もある。効率測定は4-層 toy モデル中心で、production 推論提供全体のスループットを直接保証しない。hybrid 全体-注意機構 層やマルチモーダル ワークロードも主要評価範囲外である。
