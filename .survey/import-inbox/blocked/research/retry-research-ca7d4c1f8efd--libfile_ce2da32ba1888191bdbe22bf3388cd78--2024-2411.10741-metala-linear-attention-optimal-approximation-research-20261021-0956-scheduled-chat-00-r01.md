# MetaLA：softmax注意写像を近似する線形再帰モデルの統一的設計

## 概要

MetaLAは、従来別々の系列モデルとして説明される線形Transformer、状態空間モデル（State Space Model; SSM）、線形再帰ニューラルネット（Linear RNN）を、有限サイズの隠れ状態を更新する**線形注意（linear attention）**の共通形式で扱う研究である。著者らはsoftmax注意写像が持つ機能を有限状態の線形モデルで近似するための条件を整理し、入力依存の減衰とQueryの機構が重要である一方、Keyの独立した学習射影は必須ではないと論じる。この理論的動機に基づいて、Key射影を削除し、動的減衰、自己注意の補強、短い畳み込みを組み合わせたMeta Linear Attention（MetaLA）を設計する。

実験は連想記憶、言語モデル、長系列分類、画像分類を横断する。原著表8の360Mパラメータ・150億トークン学習条件では、ゼロショット常識推論の平均正答率42.52に対し、Key射影を復活させた変種は40.80、短い畳み込みを除いた変種は38.51である。ImageNet-1kでは約6.1MパラメータのMetaLAが75.33%で、HGRNの74.40%、Mambaの73.39%を上回る。一方、Long Range Arena（LRA）の平均86.67はS5の87.46やMegaの88.21に届かない。理論的な近似条件と実測の全タスク最良性を区別して読む必要がある。

## 背景：系列モデルの共通部分

### softmax注意の隠れ状態は長さに比例する

通常の自己注意は、入力列XからQ=XW_Q、K=XW_K、V=XW_Vを作り、出力をsoftmax(QK^T/√d_k)Vで計算する。学習時には系列長nに対するn×nの注意行列が現れ、単純実装の計算量はO(n²)となる。自回帰生成時には過去のK,Vを保持して新しいQueryと照合するため、履歴長が増えるほどキャッシュ量と1トークンの注意計算量が増える。これを「履歴長に比例して成長する隠れ状態」と見なすことができる。

線形注意では、カーネル特徴写像φを用いてφ(Q)φ(K)^Tという形に分解し、過去のK,Vの積を集約した有限状態S_tを更新する。状態サイズを固定すれば、生成の1トークン当たりの計算量・記憶量は系列長nに依存しない。これは長い文脈で有利だが、過去の全トークンを個別に保持しないため、何を記憶し何を忘れるかという表現能力の問題が生じる。

SSMはh_t=Ah_{t-1}+Bx_tのような状態遷移、線形RNNはh_t=f_t⊙h_{t-1}+i_t⊙c_tのようなゲート付き更新を使う。起源は異なるが、いずれも固定状態へ過去の情報を蓄積し、現在の入力から読み出す構造を持つ。著者らはこの共通性を、Query・Key・Valueと減衰を含む線形注意形式へまとめる。モデル間の主な差は、隠れ状態の次元、減衰の入力依存性、入力から各係数への射影方法にある。

### 三つの設計条件

論文は、softmax注意の機能を有限状態の線形モデルで近似する際に、次の観点を区別する。

1. **動的記憶能力（dynamic memory）**：入力内容と履歴に応じて、重要情報を保持し、不要情報を忘れられること。固定の減衰率だけでは異なる文脈の重要度に適応しにくい。
2. **静的近似能力（static approximation）**：固定された注意写像の関数を表現できること。読み出し側のQueryがないと、現在の問い合わせに応じて過去情報の寄与を変えることが難しい。
3. **最小パラメータ近似（least parameter approximation）**：同等の近似機能を達成するのに不要な射影行列を持たないこと。著者らはKey行列を独立に学習しなくても必要な近似機構を設計できると論じる。

これらは論文で定義された**機能的近似の必要条件・設計指針**であり、任意の系列長・任意の有限次元・任意の学習条件でsoftmax注意を完全再現できるという保証ではない。特に、有限状態が保持できる情報量には上限がある。論文は静的近似と動的記憶を同時に考える点に理論的価値を置いている。

## 手法：Meta Linear Attention

### 1. Queryと動的減衰を残し、Key射影を省く

線形注意の標準的な状態更新は、概念的にS_t=α_t⊙S_{t−1}+k_t⊗v_tと書ける。α_tは過去状態をどの程度保持するかを表す減衰、k_t⊗v_tは現在トークンから追加する情報である。現在のQuery q_tでS_tを読み出すことで出力を得る。多くの線形注意ではQuery、Key、Valueをそれぞれ入力から射影するが、MetaLAは**Keyの独立した学習行列を除き**、動的減衰と他の入力依存係数によって情報の書込み・保持を制御する。

著者らの理論は、Queryが現在の問い合わせに応じた読出しを担い、動的減衰が過去の記憶を選別する点を強調する。固定減衰やQueryを持たない設計では、対象とする注意写像を十分に近似できない場合がある。一方、Keyの追加射影はパラメータと演算を増やすが、理論上必要な機能を必ずしも増やさない。これがMetaLAのパラメータ削減の主要な動機である。

### 2. 自己注意補強と局所畳み込み

線形状態への集約では、長い履歴に多くのトークンが混ざると、現在トークンが自分自身へ向ける注意の寄与が薄まることがある。MetaLAは**自己注意補強（self-augmentation）**を加えて、現在トークン自身の情報を出力へ反映しやすくする。これは過去の記憶の読み出しを強くすることとは別の、局所的な信号保持である。

また、短い畳み込み（short convolution）を入力処理へ組み込み、隣接トークン間の相互作用を補う。固定状態の線形モデルは長距離の要約を得意とする反面、細かい局所パターンの表現が弱くなる場合がある。畳み込みはこの弱点を補うための設計であり、モデル全体をsoftmax注意へ戻すものではない。

### 3. 計算量上の意義

MetaLAの再帰状態は履歴長に依存しない大きさに保たれる。したがって自回帰生成では、過去の全K,Vをキャッシュする通常のsoftmax注意とは異なり、1トークン当たりの履歴参照計算を定数長の状態更新・読出しへ置き換えられる。学習時には線形再帰の並列走査やチャンク単位の演算を利用できる。理論的な系列長計算量の改善は、実GPUでのトークン毎秒が必ず比例して改善するという意味ではない。状態次元、カーネル効率、バッチサイズ、畳み込みなどの固定費用を含む実測が必要である。

MetaLAは既存の学習済みTransformerのKVキャッシュを後処理で圧縮する方法ではない。注意層の構造を変えたモデルを学習する必要があるため、既存の重みへ単純に差し替えるだけでは精度が維持されない。これは推論ランタイムへの無学習パッチとして利用する手法とは異なる。

## 主要結果

### 連想記憶と理論仮説

MQARでは、過去の複数のキー・値対を入力し、後から現れるQueryが対応する値を正しく取り出せるかを測る。論文図3ではMetaLAがMamba、GLA、Based、RWKV-4などの比較線形モデルより良好な成績を示す。通常のsoftmax注意は同図の二条件で99%超の正解率を示し、完全な過去KV参照がこの課題に有利であることも確認できる。MetaLAがsoftmax注意を全面的に上回ったと解釈すべき結果ではない。

### ImageNet-1k（原著表6）

| モデル | 約6Mパラメータ時の精度 | 約23Mパラメータ時の精度 |
|---|---:|---:|
| DeiT（Transformer） | 72.20%（5.7M） | 79.90%（22.0M） |
| HGRN | 74.40%（6.1M） | 80.09%（23.7M） |
| GLA | 72.47%（6.1M） | 79.23%（23.5M） |
| Mamba | 73.39%（6.1M） | 79.60%（23.7M） |
| **MetaLA** | **75.33%（6.1M）** | **80.14%（23.7M）** |

小規模モデルでは比較方式に対する優位が大きく、23M級ではHGRNとの差が0.05ポイントと小さい。これをもって統計的に有意な優越と断定する情報は表6にない。

### Long Range Arena（原著表7、平均スコア）

| モデル | LRA平均 |
|---|---:|
| Transformer | 47.81 |
| S4 | 86.09 |
| DSS-softmax | 81.88 |
| S5 | 87.46 |
| Mega | **88.21** |
| HGRN | 86.91 |
| Mamba | 66.59 |
| **MetaLA** | **86.67** |

MetaLAはMambaやS4を上回るが、S5、Mega、HGRNの平均を下回る。個別タスクではMetaLAのPathfinder 91.66、Path-X 96.57、Text 89.27などを報告する。著者の「線形モデルの中で優れた表現能力を示す」という結論は妥当だが、LRA全体の最高値ではないという負の結果を併記する必要がある。

### 構成要素除去（原著表8）

360Mモデルを150億トークンで学習したゼロショット常識推論の8課題平均は以下である。

| 変種 | 平均正答率 |
|---|---:|
| **MetaLA** | **42.52** |
| 自己注意補強なし | 42.16 |
| 短い畳み込みなし | 38.51 |
| Key射影を追加 | 40.80 |

短い畳み込みを除くと4.01ポイント低下し、局所的な相互作用が重要であることを支持する。自己注意補強を除いた低下は0.36ポイントと小さく、効果はあるがこの平均指標では限定的である。Key行列を戻しても精度が上がらず、むしろ1.72ポイント低下する。これは「Keyがどんな条件でも有害」という普遍的証明ではなく、原著のモデル構成・学習設定での結果である。

### 言語モデル・拡張実験の位置付け

原著§6ではPile上の360Mと1.4B級の言語モデルを学習し、SuperGLUEと常識推論で他の線形モデルやPythiaとの比較を行う。著者はMetaLAの優位を報告するが、異なる事前学習済み比較モデルが混在するため、単純なアーキテクチャ効果だけに帰属できない。付録では3B級モデルや長文検索の予備評価を追加するものの、これを商用の大規模推論サーバにおける実測スループットの証拠として扱うべきではない。

## 既存研究との違い

線形Transformerの多くはQ・Kの特徴写像を維持したまま、softmaxを置き換えて行列演算を線形化する。RetNetなどは減衰機構を使い、MambaなどのSSMは状態遷移の選択性を重視する。MetaLAはそれらを別系列のモデルとしてではなく、有限状態への書込み・忘却・読出しを担う共通の注意写像として再整理する。特に**Queryを残すこと、動的減衰を使うこと、Keyの独立した射影を省くこと**の組合せを理論上の設計条件として扱う点が特徴である。

また、自己注意補強と短い畳み込みは、理論上の最小パラメータ条件だけでは捉えにくい実用上の局所表現能力を補う。表8では畳み込みが精度に大きく寄与することが示されるため、MetaLAの性能を単に「Key削除」だけの効果と説明するのは不十分である。

## 限界と今後の課題

第一に、著者らの最適性は**論文が定義する機能近似条件とパラメータ数の枠内**であり、全タスク・全予算・全系列長で最良のモデルを意味しない。LRAではMetaLAより高い平均スコアの比較方式が存在する。第二に、有限状態へ履歴を圧縮する以上、任意の長文から個々のトークンを完全に復元できる保証はなく、情報の忘却は避けられない。第三に、学習済みsoftmax Transformerへ重みを変えずに置換できる推論最適化ではない。

第四に、評価にはモデル規模と学習条件が揃っていない比較があり、パラメータ数・学習トークン数・学習コード・ハードウェアを固定した全面的な速度品質曲線が必要である。第五に、MQARは人工的な連想記憶課題であり、実際の検索・推論・コード生成での長文品質を代替しない。第六に、著者ら自身が論文§7で、機能近似と値近似を組み合わせる可能性、線形注意がsoftmax注意を超える能力を持つ条件、有限状態の能力上限を未解決問題として挙げる。
