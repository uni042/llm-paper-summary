# VisCache: Visual KV Cache Pruning for Efficient Vision Large Language Model Inference

## 概要
Vision Large Language Model (VLM)では、画像や動画が多数のvisual トークンへ展開されるため、テキスト-only LLMよりプリフィル計算とKV キャッシュが膨らみやすい。既存のKV 枝刈りを全層・全visual トークンへ同じ比率で適用すると、時間的に重複したframeと意味的に重要なframe、または感度の異なる層を区別できず、少ないキャッシュ budgetで品質が落ちる。

VisCacheは粗粒度と細粒度の二段階でvisual KVを減らす。まず軽量VLMがvideo/frame列から意味的に有用なkeyframeだけを順伝播する。次にPruneKVがmain VLM内部で層別budgetを配り、keyとvalueを非対称に処理する。学習不要のplug-and-play方式として、KV retentionを19〜28%まで下げながら最大2.35倍の推論高速化を報告する。

## 問題設定
visual 文脈には隣接frameの時間的冗長性と、同一frame内のトークン冗長性が同時にある。入力前にframeだけを落とすと細粒度トークン冗長性が残り、KV 層内だけを一律pruneすると、そもそも不要なframeを全モデルへ通したプリフィル費用を回収できない。

またTransformer 層ごとにvisual情報への依存度が異なるため、一律budgetは重要層を過度に削る可能性がある。keyを削ると将来問い合わせが参照できる位置が減る一方、valueには内容情報があるため、単純破棄以外の保持方法が必要になる。

## 手法
### keyframe filtering
軽量VLMを前段に置き、時間的に類似するframe列からsemantic informationが大きいkeyframeを選ぶ。main VLMへ入るvisual トークン数自体を減らすため、後段KV キャッシュだけでなくプリフィル計算も抑える。

### parabolic layer-wise budget
PruneKVは全層へ同じ保持率を配らず、層位置に応じた放物線状budgetを使う。重要度が高い領域へ多くのKVを残し、圧縮耐性のある層からbudgetを削ることで、同じ総KV量で品質低下を抑える。

### asymmetric key pruning / value fusion
key側では将来注意機構候補を選択的にpruneする一方、対応valueを単純に捨てず融合する。これによりkey index数を減らして注意機構計算とキャッシュ 通信量を削減しつつ、除去トークンが持っていた内容情報の一部を残す。key/valueを同じ規則で消すuniform 枝刈りとの差がここにある。

|項目|条件|

|比較|uniform visual KV 枝刈り等|

## 主要結果
|条件|結果|解釈|
|---|---:|---|
|複数評価|KV retention 19〜28%|キャッシュの約72〜81%を削減|
|代表条件|最大2.35× 高速化倍率|visual トークン/KV削減が実時間へ反映|
|同程度budget|既存比較対象より高い品質|層配分と非対称処理の効果|
|学習|追加学習なし|既存VLMへ後付け可能|

## 既存研究との差
テキスト-only向けKV 枝刈りをvisual トークンへ一律適用する方式と異なり、VisCacheは入力frame選択とTransformer内部KV 枝刈りを分離する。またPruneKVはkey/valueを同時削除せず、keyを減らしvalue情報を融合する。層 budgetも固定率ではなくparabolicに変えるため、時間軸・層軸・KV役割の三つの非一様性を利用する。

## 限界
前段keyframe selector自体の計算費用があり、静止画像や時間冗長性の少ないvideoでは粗粒度filterの利得が小さくなる。19〜28% retentionでの品質維持は評価したVLM/ワークロードの範囲であり、細部認識や一度しか現れないvisual eventではframe/トークン 枝刈りが情報損失を起こし得る。学習不要である代わりにモデル自身が圧縮へ適応する学習は行わない。
