# WINA: Weight Informed Neuron Activation for Accelerating Large Language Model Inference

## 概要
学習不要の疎活性化は、事前学習済みLLMの重みを変えず、各tokenで重要なhidden dimensionだけを計算することでFLOPsを減らす。TEAL等の既存法は主にhidden stateの絶対値を基準にするが、同じ活性値でも接続先weightの大きさが違えば出力への影響は異なる。WINA（Weight Informed Neuron Activation）はこの欠落を補い、活性値とweight matrixのcolumn-wise L2 normを同時に使う。

理論上は線形層の出力近似誤差を直接小さくする選択則として導出され、列直交条件の下でより厳密な誤差境界を持つ。実験ではLlama-2-7B、Llama-3-8B、Qwen-2.5-7B、Phi-4-14B等に適用し、同一sparsityでTEALを平均最大2.94ポイント上回る。65%疎性ではGFLOPsを最大63.7%削減し、専用Triton kernelでA100上最大42%の速度改善を示す。

## 問題設定
hidden activationの絶対値だけでneuronをdropすると、値が小さくても非常に大きなweight columnへ接続する成分を捨てる可能性がある。逆に大きなactivationでもweightが小さければ出力誤差への寄与は限定的である。したがってactivation-only scoreは、実際に次の線形変換へ与える誤差を最小化する目的と一致しない。

MoEのような疎計算は学習時からarchitectureを変更する必要があるが、WINAはdense checkpointへ後付けできることを狙う。課題は、追加score計算のoverheadが削減FLOPsを相殺しないことと、高sparsityでもtask精度を保つことである。

## 手法
### weight-informed score
入力hidden vectorの各要素`x_i`に、対応するweight columnのL2 norm `||W_:,i||_2`を掛け、出力への影響を近似する。scoreが小さいdimensionをzero化し、残りだけをsparse matrix-vector/matrix演算へ渡す。column normはmodel load時に一度計算でき、tokenごとに必要なのは要素積とtop-k相当の選択である。

### 理論的誤差境界
線形変換`Wx`で一部dimensionを捨てたときの出力L2誤差を、activationとweight column normから上界化する。columnが直交する条件ではWINAの選択が最適な近似誤差を与える。実モデルでこの条件を近づけるため、必要に応じて変換を使い、理論と実用を接続する。

### layerごとのsparsity allocation
全行列へ同じ疎性を割り当てるだけでなく、実装ではactivation histogramを収集し、TEAL系のgreedy allocationを使ってmatrixごとのsparsityを配分できる。WINAのscoreはこのallocationと独立に使えるため、同じ総FLOPs予算で精度を上げる方向に働く。

### 実行kernel
疎性がFLOPs削減だけで終わらないよう、Triton kernelで選択dimensionのみを処理する。weight normは事前保存し、runtimeの追加要素積は大規模行列演算に対して小さい。量子化weightとの併用も評価され、4-bit/8-bit条件でもactivation-only baselineより高い精度を維持する。

## 評価条件
|項目|内容|
|---|---|
|モデル|Llama-2-7B、Llama-3-8B、Qwen-2.5-7B、Phi-4-14B等|
|baseline|TEAL、CATS、R-Sparse等|
|sparsity|25〜65%級を含む|
|task|PIQA、HellaSwag、MMLU、GSM8K、HumanEval、LongBench等|
|量子化|4-bit/8-bit併用評価あり|
|hardware|NVIDIA A100、RTX PRO 6000 Blackwell等|
|system指標|GFLOPs、kernel latency、task accuracy|

## 主要結果
同一sparsityで既存法を平均最大2.94ポイント上回る。65% sparsityのLlama-2-7BではTEALより約4.07ポイント高いcommonsense平均を示す例があり、高sparsityほどactivation-only選択との差が拡大する。LongBenchや量子化併用でも優位性が残る。

計算量では65% sparsityでLlama-2-7B/Mistral級に最大63.7%のGFLOPs削減を報告する。専用kernelではA100でdense実行比最大42%、RTX PRO 6000 Blackwellで最大57%の速度改善が報告され、理論FLOPs削減が実時間へ一部反映される。ただし速度倍率はsparsity、shape、hardwareに依存し、FLOPs削減率と同じにはならない。

## 既存研究との差
TEALやCATSなどの学習不要疎活性化はhidden state側の統計を中心にneuronを選ぶ。WINAは次段weightをscoreへ明示的に入れ、「どのactivationが大きいか」ではなく「捨てると出力をどれだけ変えるか」に近い目的を使う。MoEのような再学習も不要で、既存dense checkpointへplug-inできる。

## 限界
column normの事前計算・保存とruntimeの要素積が追加される。理論的な最適性はcolumn orthogonality等の条件に依存し、実モデルでは変換や近似が必要になる。高度なlayer-wise sparsity allocation自体はWINAの中心貢献ではなく、別heuristicへ依存する。また実速度はsparse kernelのhardware効率に左右され、高sparsityでもmemory accessが支配的なshapeでは理論FLOPsほど速くならない。
