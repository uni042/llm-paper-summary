# 全リポジトリの整合性点検記録

夜間の専用枠と、明示的に依頼された手動保守の検査結果を保持する。`latest.json` から最新の実行記録を参照する。手動検査と予定実行を混同しない。

- 全ファイル一覧の取得元変更識別子と、取得・検査できた範囲を残す。
- 修復前の指摘、実施した修復、修復後の再検査、保存確認版、未検査、残件を残す。
- 全体構造検査と論文の科学的な内容監査を区別する。
- 最新結果と未解決の途中記録は保持する。古い終了済み詳細記録だけ夜間に整理する。
